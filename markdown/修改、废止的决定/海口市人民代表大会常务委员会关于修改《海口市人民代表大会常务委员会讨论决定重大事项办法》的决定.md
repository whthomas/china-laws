# 海口市人民代表大会常务委员会关于修改《海口市人民代表大会常务委员会讨论决定重大事项办法》的决定

海口市人民代表大会常务委员会
关于修改《海口市人民代表大会常务委员会
讨论决定重大事项办法》的决定

（2026年6月18日海口市第十七届人民代表大会常务委员会第四十一次会议通过　2026年7月29日海南省第七届人民代表大会常务委员会第二十五次会议批准）

海口市第十七届人民代表大会常务委员会第四十一次会议决定，对《海口市人民代表大会常务委员会讨论决定重大事项办法》作如下修改：

一、将第一条中的“推进决策的民主化、科学化，根据宪法、地方组织法和监督法等有关法律的规定”修改为“推进决策的科学化、民主化、法治化，根据宪法和《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》、《中华人民共和国各级人民代表大会常务委员会监督法》等有关法律的规定”。

二、将第二条中的“环境和资源保护、民政、民族等工作的重大事项适用本办法”修改为“生态环境保护、自然资源、城乡建设、民政、社会保障、民族等工作的重大事项，适用本办法”。

三、将第三条中的“应当依照法律、法规的规定进行”修改为“应当坚持中国共产党的领导，坚持以人民为中心，坚持和发展全过程人民民主，坚持围绕中心、服务大局，坚持从实际出发，依照宪法和法律、法规规定行使职权”。

四、将第四条第一项修改为：“（一）保证宪法、法律、法规和上级人民代表大会及其常务委员会以及本级人民代表大会的决议、决定在本市得到遵守和执行的重大措施”。

增加一项，作为第二项：“（二）中共海口市委建议市人大常委会作出决议、决定的重大事项”。

第二项改为第三项，修改为：“（三）推进社会主义民主法治建设的重大决策和部署”。

增加一项，作为第四项：“（四）事关本市经济建设和社会发展全局的重大事项和项目”。

将第四项、第五项合并，作为第五项，修改为：“（五）市人民政府对国民经济和社会发展规划纲要、计划和本级预算的调整方案”。

将第六项修改为：“（六）上一年度市本级决算”。

删去第七项。

增加一项，作为第七项：“（七）撤销市人民政府不适当的决定、命令，撤销下一级人民代表大会及其常务委员会不适当的决议、决定”。

删去第九项。

将第十项、第十一项合并，作为第九项，修改为：“（九）法律、法规规定应当由市人大常委会讨论、决定或者市人大常委会认为有必要讨论、决定的其他重大事项”。

五、将第五条第二项中的“五年规划”修改为“规划纲要”。

增加一项，作为第五项：“（五）事关全市发展重要领域和长远发展的重大改革举措”。

增加一项，作为第六项：“（六）海南自由贸易港建设相关重大政策落实情况、重大改革举措实施情况”。

将第五项改为第七项，修改为：“（七）市人民政府法治政府建设情况”。

增加一项，作为第八项：“（八）环境状况和环境保护目标完成情况”。

将第六项、第八项、第九项、第十项合并，作为第九项，修改为：“（九）城乡建设和管理、教育、科学技术、文化、医疗卫生、体育、社会保障、社会救助、养老、物价、就业、收入分配、住房保障、食品安全、社会治安等涉及全市群众切身利益的重大决策和重大项目的实施，重大基础设施建设，重大财政支出项目”。

将第七项改为第十项，修改为：“（十）国土空间规划的实施情况”。

增加一项，作为第十二项：“（十二）地方政府债务管理情况”。

将第十二项改为第十三项，修改为：“（十三）关系人民群众切身利益的重要公用事业、公益性服务价格调整方案”。

将第十三项改为第十四项，修改为：“（十四）重大自然灾害和事故灾难、重大环境事件和公共卫生事件、重大社会安全事件等突发性事件的应对处置情况”。

删去第十五项。

在第十六项中的“市中级人民法院”前增加“市监察委员会”。

六、删去第六条。

七、将第七条改为第六条，在“市中级人民法院”前增加“市监察委员会”。

八、将第八条改为第七条，在第一款中增加一项，作为第四项：“（四）与该重大事项有关的公众参与、专家论证、风险评估、合法性审查、集体讨论决定以及与有关方面协商、协调的情况等”；删去第二款。

九、将第九条改为第八条，第二项修改为：“（二）市人民政府、市监察委员会、市中级人民法院、市人民检察院、海口海事法院或者市人民代表大会专门委员会向市人大常委会提出的议案、报告等，由市人大常委会主任会议决定提请市人大常委会会议审议，或者先交有关的专门委员会审议、提出报告，也可以先交市人大常委会有关工作机构研究、提出意见，再提请市人大常委会会议审议”；第三项修改为：“（三）市人大常委会组成人员五人以上联名，向市人大常委会提出的议案，由市人大常委会主任会议决定是否提请市人大常委会会议审议，或者先交有关的专门委员会审议、提出报告，也可以先交市人大常委会有关工作机构研究、提出意见，再决定是否提请市人大常委会会议审议”。

十、将第十条改为第九条，在“市中级人民法院”前增加“市监察委员会”；将“二十日前”修改为“十日前”；将“办公厅”修改为“办公室”。

十一、将第十一条改为第十条，修改为：“市人大常委会对提请审议的重大事项，应当自收到有关议案或者报告之日起三个月内进行审议。列入年度计划的，按照计划进行审议。”

十二、将第十二条改为第十一条，将“可以委托市人民代表大会有关专门委员会或者市人大常委会有关工作机构就该重大事项组织调查研究”修改为“可以组织市人民代表大会有关专门委员会或者市人大常委会有关工作机构就该重大事项进行调查研究”。

十三、将第十三条改为第十二条，修改为：“市人大常委会审议重大事项时，提出议案或者报告的机关负责人应当到会说明情况，回答询问。市人大常委会组成人员联名提出的议案，由联名提出议案的组成人员推选的代表向会议作出说明。”

十四、将第十四条改为第十三条，将第一款中的“并根据规定的期限报告执行情况”修改为“并按照规定的期限报告执行情况”，“可以分阶段报告”修改为“可以按照规定的期限分阶段报告”；将第二款中的“六个月”修改为“三个月”。

十五、将第十五条改为第十四条，将“市人大常委会应当组织跟踪检查或者委托市人民代表大会有关专门委员会或者市人大常委会有关工作机构组织跟踪检查”修改为“市人大常委会可以组织跟踪检查，也可以委托市人民代表大会有关专门委员会或者市人大常委会有关工作机构组织跟踪检查”；将“主任会议”修改为“市人大常委会主任会议”。

十六、将第十六条改为第十五条，将第二款中的“应当向市人大常委会报告或者备案的重大事项不报告或者不报备案的”修改为“应当向市人大常委会报告的重大事项不报告的”；将第三款中的“属于市人大常委会决定任命、任命的，市人大常委会可以建议有关机关追究其责任，情节严重的依法提出撤职案”修改为“市人大常委会可以建议有关机关追究其责任，属于市人大常委会任命的，情节严重的依法提出撤职案”；删去第四款。

十七、增加一条，作为第十六条：“市人大常委会讨论决定重大事项的有关情况，应当向市人民代表大会代表通报，并通过网络、报刊等媒体向社会公布。”

十八、将第十七条中的“可以参照本办法执行”修改为“可以参照本办法制定本级人大常委会的规定”。

本决定自公布之日起施行。

《海口市人民代表大会常务委员会讨论决定重大事项办法》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
