# 江苏省人民代表大会常务委员会关于修改《江苏省统计条例》的决定

江苏省人民代表大会常务委员会
关于修改《江苏省统计条例》的决定

（2026年9月30日江苏省第十四届人民代表大会常务委员会第二十五次会议通过）

江苏省第十四届人民代表大会常务委员会第二十五次会议决定对《江苏省统计条例》作如下修改：

一、增加一条，作为第四条：“地方各级人民政府、政府统计机构和有关部门应当树立和践行正确政绩观，严格执行统计法律、法规和国家有关规定，不得统计造假、弄虚作假。任何单位和个人不得利用虚假统计资料骗取荣誉称号、物质利益或者职务职级等晋升。

“县级以上地方人民政府、政府统计机构和有关部门应当根据国家有关规定，将防范和惩治统计造假、弄虚作假纳入依法行政、依法履职责任范围，依法对统计造假、弄虚作假行为追究法律责任。”

二、将第五条改为第六条，第二款修改为：“省人民政府统计机构应当会同有关部门对全省统计信息化建设进行统一规划，推动现代信息技术与统计工作深度融合，促进统计信息搜集、处理、传输、存储技术和统计数据库体系的现代化，加强电子统计台账软件系统开发应用管理，提高统计工作智能化、自动化水平。”

三、将第八条改为第九条，增加一款，作为第一款：“县级以上地方人民政府、政府统计机构及有关部门应当根据经济社会发展的新情况，将新产业、新业态、新商业模式等新经济新领域纳入统计调查范围。”

四、将第十六条改为第十七条，增加一项，作为第三项：“明示、暗示下级单位及其人员或者统计调查对象填报虚假统计数据”。

将第三项、第四项改为第四项、第五项，其中的“统计人员”、“人员”修改为“单位和个人”。

将第五项改为第六项，修改为：“对本地区、本部门、本单位发生的统计数据严重失实情况和严重统计违法行为失察”。

增加一项，作为第七项：“其他统计造假、弄虚作假行为”。

增加一款，作为第二款：“县级以上地方人民政府和有关部门不得将政府统计机构作为完成地方经济社会发展目标的责任单位。”

五、将第二十六条改为第二十七条，增加一款，作为第一款：“县级以上地方人民政府和有关部门不得随意调用政府统计调查对象报送的统计数据作为各项评比表彰和资格认定依据。”

六、将第三十五条改为第三十六条，删去其中的“及其监察机关”。

七、将第四十条改为第四十一条，其中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”，第三项中的“调查对象”修改为“调查对象或者其他机构、人员”。

八、将第四十二条改为第四十三条，修改为：“地方各级人民政府、政府统计机构或者有关部门、单位的主要负责人及其他负责人有本条例第十七条第一款规定行为的，由任免机关、单位或者监察机关依法给予处分，并由政府统计机构予以通报。”

九、将第四十五条改为第四十六条，其中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

此外，对有关条款作文字修改，并对条文顺序作相应调整。

本决定自2026年11月1日起施行。

《江苏省统计条例》根据本决定作相应修改，重新公布。
