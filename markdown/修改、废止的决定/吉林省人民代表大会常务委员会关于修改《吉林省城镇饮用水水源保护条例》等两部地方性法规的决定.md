# 吉林省人民代表大会常务委员会关于修改《吉林省城镇饮用水水源保护条例》等两部地方性法规的决定

吉林省人民代表大会常务委员会
关于修改《吉林省城镇饮用水水源保护条例》
等两部地方性法规的决定

（2026年9月29日吉林省第十四届人民代表大会常务委员会第二十五次会议通过）

按照开展生态环境法典涉及地方性法规等规范性文件集中清理工作的相关要求，现对下列地方性法规作出修改：

一、对《吉林省城镇饮用水水源保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第四条中的“土地利用总体规划、城乡规划、水污染防治规划”修改为“国土空间规划、生态环境保护规划”。

（三）将第六条修改为：“县级以上人民政府生态环境主管部门会同有关部门监督管理饮用水水源地环境保护工作；水行政主管部门指导饮用水水源保护工作。

“县级以上人民政府发展改革、自然资源、卫生健康、住房城乡建设、农业农村、林业草原、渔业渔政等有关部门按照职责分工，做好城镇饮用水水源保护的相关工作。”

（四）将第十三条中的“由省人民政府环境保护主管部门会同同级水利、国土资源、卫生、住房和城乡建设等部门提出划定方案”修改为：“由省人民政府生态环境主管部门会同同级水行政、自然资源、疾病预防控制、住房城乡建设等有关部门提出划定方案”。

（五）将第十九条中的“水利主管部门”修改为“水行政主管部门”，“主要污染物排放总量”修改为“重点污染物排放总量”。

（六）将第二十七条修改为：“县级以上人民政府应当根据保护城镇饮用水水源的实际需要，在城镇饮用水水源准保护区内采取工程措施或者建造湿地、水源涵养林等生态保护措施，积极开展河道疏浚和生态修复，防止水土流失、减轻库区淤积，避免水污染物直接排入饮用水水体，确保饮用水安全。”

（七）将第二十九条修改为：“省人民政府应当根据水生态环境保护的需要，在城镇饮用水水源保护区内，采取禁止或者限制使用含磷洗涤剂、化肥、农药以及限制种植养殖等措施，降低饮用水的化学元素残留指标。鼓励发展生态农业，控制农业面源污染，保障饮用水水源安全。”

（八）将第三十九条修改为：“设区的市、县级人民政府应当组织制定城镇饮用水安全突发事件应急预案，建立专业的应急机构和队伍，配备专业的应急救援设施设备，进行必要的物资储备。”

（九）将第四十条修改为：“发生事故或者其他突发性事件，造成或者可能造成城镇饮用水水源水污染事故的单位，应当立即启动本单位的应急预案，采取应急措施，排除或者减轻污染危害，及时向事故发生地设区的市、县级人民政府报告，并向社会公开。”

（十）删除第四十三条、第四十四条、第四十七条、第四十八条、第四十九条。

（十一）增加一条，作为修改后第四十三条，内容为：“违反本条例规定的行为，法律、行政法规已经规定法律责任的，从其规定。”

（十二）将第五十一条修改为第四十七条，“县级以上人民政府”修改为“各级人民政府”，“依法给予行政处分”修改为“依法给予处分”。

（十三）将第五十三条修改为第四十九条，具体内容修改为“对本条例第四十六条规定，由城镇饮用水水源管理机构管理和处罚的事项，没有设立饮用水水源管理机构的地方或者涉及违法行为情节严重、数额较大的，由相关主管部门按照管理职权进行处罚。”

（十四）对部门名称作出修改，将“环境保护主管部门”修改为“生态环境主管部门”，“水利主管部门”修改为“水行政主管部门”，“林业主管部门”修改为“林业草原主管部门”，“国土资源主管部门”“规划部门”修改为“自然资源主管部门”，“发展和改革部门”修改为“发展改革部门”，“住房和城乡建设部门”修改为“住房城乡建设部门”，“卫生部门”修改为“卫生健康部门”。

二、对《吉林省黑土地保护条例》作出修改

（一）将第三十四条第三款修改为：“禁止在黑土地上擅自倾倒废水及堆放、丢弃、抛撒、遗撒、焚烧固体废物。”

（二）将第四十条第一款修改为：“县级以上人民政府林业和草原、畜牧主管部门应当合理利用草原，严格落实草畜平衡制度，实行动态管理，采取多样化饲养方式，防止草原超载过牧。”

（三）将第五十八条修改为：“违反本条例第三十四条第三款规定，在黑土地上擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物，由县级以上人民政府生态环境主管部门、环境卫生主管部门按照职责分工责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。

“前款规定的固体废物为危险废物的，处二十万元以上二百万元以下的罚款；对直接负责的主管人员和其他直接责任人员处二万元以上十万元以下的罚款；造成严重后果的，处二百万元以上五百万元以下的罚款。

“个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾、建筑垃圾的，由环境卫生主管部门责令改正，处一百元以上一千元以下的罚款。”

（四）将第六十二条修改为：“违反本条例第四十七条第二款规定，因突发事件造成黑土地污染或者破坏的单位或者个人，有下列情形之一的，由县级以上人民政府确定的监督管理部门责令改正，处以罚款：

“（一）未及时报告；

“（二）未立即采取有效措施或者逃逸；

“（三）未采取必要应对措施，造成生态灾害危害扩大。

“有前款第一项情形的，处五万元以上五十万元以下的罚款，对直接负责的主管人员和其他直接责任人员处一万元以上十万元以下的罚款，并可以暂扣或者吊销相关任职资格许可；有前款第二项、第三项情形之一的，处二十万元以上二百万元以下的罚款。”

此外，对相应条款顺序作出调整。

本决定自公布之日起施行。

《吉林省城镇饮用水水源保护条例》《吉林省黑土地保护条例》根据本决定作相应修改，重新公布。
