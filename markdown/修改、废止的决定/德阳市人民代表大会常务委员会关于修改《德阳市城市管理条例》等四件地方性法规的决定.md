# 德阳市人民代表大会常务委员会关于修改《德阳市城市管理条例》等四件地方性法规的决定

德阳市人民代表大会常务委员会
关于修改《德阳市城市管理条例》等四件
地方性法规的决定

（2026年6月23日德阳市第九届人民代表大会常务委员会第三十九次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

德阳市第九届人民代表大会常务委员会第三十九次会议决定：

一、对《德阳市城市管理条例》作出修改

（一）将第二十一条第一款修改为：“任何单位和个人不得在市、县（市、区）人民政府禁止的区域和时段内燃放烟花爆竹、露天烧烤食品。”

（二）将第三十六条第一款修改为：“违反本条例第十四条第一款规定，依照《中华人民共和国生态环境法典》的规定处理。”

（三）将第三十八条修改为：“违反本条例第二十条第二项、第三项规定的，依照《中华人民共和国生态环境法典》的规定处理。”

（四）将第四十条第一款修改为：“违反本条例第十五条第三款，第十七条第二款，第十九条第二款、第三款，第二十条第一项，第二十一条第一款、第二款、第三款、第四款规定的，由城市管理主管部门依照《中华人民共和国生态环境法典》和相关法律法规的规定处理。”

二、对《德阳市华强沟水库饮用水水源保护条例》作出修改

将第一条修改为：“为了加强德阳市华强沟水库饮用水水源保护，保障饮用水安全，根据《中华人民共和国生态环境法典》和相关法律法规，结合德阳市实际，制定本条例。”

三、对《德阳市文明行为促进条例》作出修改

将第四十条修改为：“违反本条例规定，实施不按照交通信号规则通行，随地吐痰、便溺，乱扔垃圾，不清理犬便，乱贴小广告，露天焚烧秸秆等行为的，依照《中华人民共和国生态环境法典》《中华人民共和国治安管理处罚法》《中华人民共和国道路交通安全法》等法律法规的规定处理。”

四、对《德阳市大气污染防治条例》作出修改

（一）将第一条修改为：“为了保护和改善环境，防治大气污染，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》和相关法律法规，结合德阳市实际，制定本条例。”

（二）将第二十三条第一款修改为：“在市人民政府依法划定的禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁能源。”

（三）将第三十四条第二款修改为：“任何单位和个人不得在市、县（市、区）人民政府禁止的区域和时段内燃放烟花爆竹、露天烧烤食品；禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

本决定对《德阳市城市管理条例》《德阳市华强沟水库饮用水水源保护条例》《德阳市文明行为促进条例》《德阳市大气污染防治条例》所做的修改，自2026年8月15日起施行。

《德阳市城市管理条例》《德阳市华强沟水库饮用水水源保护条例》《德阳市文明行为促进条例》《德阳市大气污染防治条例》根据本决定作相应修改，重新公布。
