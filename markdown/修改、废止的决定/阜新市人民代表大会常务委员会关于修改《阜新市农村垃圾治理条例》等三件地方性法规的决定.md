# 阜新市人民代表大会常务委员会关于修改《阜新市农村垃圾治理条例》等三件地方性法规的决定

阜新市人民代表大会常务委员会
关于修改《阜新市农村垃圾治理条例》等三件
地方性法规的决定

（2026年6月26日阜新市第十七届人民代表大会常务委员会第四十二次会议通过　2026年7月29日辽宁省第十四届人民代表大会常务委员会第二十四次会议批准）

阜新市第十七届人民代表大会常务委员会第四十二次会议决定对《阜新市农村垃圾治理条例》等三件地方性法规作如下修改：

一、对《阜新市农村垃圾治理条例》作出修改

（一）将第一条修改为：“为了加强农村垃圾治理，促进宜居宜业美丽乡村建设，保障乡村振兴战略实施，加快农业农村现代化，根据《中华人民共和国生态环境法典》等法律法规，结合本市实际，制定本条例。”

（二）将第五条第三款修改为：“市、县生态环境行政主管部门负责指导、监督农村垃圾污染防治工作。”

（三）将第八条第一款修改为：“市、县、乡镇人民政府及其有关部门应当组织开展农村垃圾治理宣传教育，弘扬社会主义核心价值观，培育节约适度、绿色低碳、文明健康的生产生活方式，养成共建宜居宜业美丽乡村的良好习惯。”将第三款修改为：“工会、共青团、妇联等群团组织应当结合各自工作特点，组织开展农村垃圾治理知识宣传教育，推动社会参与农村垃圾治理活动。”

（四）将第十一条修改为：“市、县、乡镇人民政府及其有关部门在编制国土空间规划和相关专项规划时，应当统筹农村垃圾转运、集中处置等设施、场所建设需求，保障农村垃圾转运、集中处置等设施、场所用地。市、县、乡镇人民政府自然资源行政主管部门应当将农村垃圾处置体系规划中确定的农村垃圾治理基础设施、场所用地，纳入控制性详细规划，并依法向社会公布。”

（五）将第十二条修改为：“市、县、乡镇人民政府应当加强农村垃圾治理基础设施、场所建设，逐步配置与农村垃圾治理需求相适应的清扫、投放、收集、运输、处理等设备、场所。”

（六）将第十四条修改为：“禁止在农村地区随意倾倒、抛撒、丢弃、堆放、遗撒或者焚烧生活垃圾。”

（七）将第十五条修改为：“市环境卫生行政主管部门应当制定农村生活垃圾清扫、收集、贮存、运输和处理设施、场所建设运行规范，公布农村生活垃圾分类指导目录，加强监督管理。”

（八）将第二十二条第一款修改为：“市、县、乡镇人民政府应当科学精准加强秸秆等焚烧的组织、指导和管理。”

（九）将第二十七条修改为：“违反本条例规定，公职人员玩忽职守、滥用职权、徇私舞弊的，由有关机关依法给予处分；构成犯罪的，依法追究刑事责任。”

（十）将第二十八条删除。

二、对《阜新市清洁取暖促进条例》作出修改

（一）将第一条修改为：“为了有序促进清洁取暖，保障公众健康，改善大气环境质量，根据《中华人民共和国生态环境法典》等法律法规，结合本市实际，制定本条例。”

（二）将第六条第二款修改为：“市清洁取暖综合协调部门应当公布清洁取暖技术、工艺、设备和产品、使用指南等指导目录，并实行动态管理。”

（三）将第七条第二款修改为：“城市建成区实行集中供暖的，采取燃煤锅炉超低排放的方式，实现清洁取暖。”

（四）将第十一条第一款修改为：“市人民政府应当按照国家有关规定，划定高污染燃料禁燃区，并向社会公布。在高污染燃料禁燃区内，禁止销售、燃用煤炭及其制品等高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”，将第二款修改为：“鼓励和支持改建的燃煤集中供暖项目，以及在用燃煤集中供暖设备、设施，达到国家大气污染物超低排放标准。”

（五）将第十五条修改为：“违反本条例规定，在高污染燃料禁燃区内，销售煤炭及其制品等高污染燃料的，由市、县市场监督管理部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下的罚款。”

（六）将第十六条修改为：“违反本条例规定，公职人员玩忽职守、滥用职权、徇私舞弊的，由有关机关依法给予处分。”

三、对《阜新市城市市容和环境卫生管理条例》作出修改

（一）将第十三条第一款修改为：“物业服务企业或者乡镇人民政府、街道办事处应当在住宅区和相应公共场所设置信息发布栏，供有关单位或者个人发布便民信息，并负责维护管理。”

（二）将第十七条第三款修改为：“违反第二款规定的，由市容环卫主管部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

（三）将第十八条第三款修改为：“违反第二款规定的，由市容环卫主管部门责令停止违法行为，采取补救措施，并处二十元以上一千元以下罚款；对擅自关闭、闲置或者拆除生活垃圾处理设施、场所的，由市容环卫主管部门责令改正，没收违法所得，对单位并处十万元以上一百万元以下的罚款。”

（四）将第二十二条第（三）项修改为：“在禁止焚烧的区域和时段露天焚烧落叶等产生烟尘污染物质的”，删除第（四）项，将原条款的（五）（六）（七）项顺序调整为（四）（五）（六）项。

（五）将第二十三条修改为：“有关公职人员在城市市容和环境卫生管理工作中不依法履行职责的，由有关机关依法给予处分。”

本决定自公布之日起施行。

《阜新市农村垃圾治理条例》等三件地方性法规根据本决定作相应修改，并对条文顺序作相应调整，重新公布。
