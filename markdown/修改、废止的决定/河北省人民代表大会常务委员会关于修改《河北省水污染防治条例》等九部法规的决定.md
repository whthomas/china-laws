# 河北省人民代表大会常务委员会关于修改《河北省水污染防治条例》等九部法规的决定

河北省人民代表大会常务委员会
关于修改《河北省水污染防治条例》等
九部法规的决定

（2026年9月23日河北省第十四届人民代表大会常务委员会第二十三次会议通过）

河北省第十四届人民代表大会常务委员会第二十三次会议决定，对下列九部法规作出修改：

一、河北省水污染防治条例

（一）将第一条中的“水污染防治法”修改为“生态环境法典”。

（二）将第五条第一款修改为：“县级以上人民政府生态环境主管部门对本行政区域内水污染防治工作实施统一监督管理。”

将第二款修改为：“县级以上人民政府有关部门在各自的职责范围内对水污染防治实施监督管理。”

（三）将第十二条第一款修改为：“省人民政府生态环境主管部门应当会同有关部门按照国家确定的重要河流、湖泊的流域水生态环境保护规划和本省实际情况，编制本省行政区域内跨县河流、湖泊的流域水生态环境保护规划，报省人民政府批准后，报国务院生态环境主管部门备案。”

删去第二款。

将第三款修改为：“县级以上人民政府可以根据依法批准的流域水生态环境保护规划和实际需要，组织编制本行政区域的水生态环境保护规划。”

（四）将第十三条修改为：“设区的市、县（市、区）人民政府应当按照水生态环境保护规划确定的水生态环境质量改善目标的要求，制定限期达标规划，采取措施按期达标。

“设区的市、县（市、区）人民政府应当将限期达标规划报上一级人民政府备案。”

（五）将第十六条修改为：“饮用水水源二级保护区内禁止新建、改建、扩建排放污染物的建设项目；已建成的排放污染物的建设项目，由县级以上人民政府责令拆除或者关闭。”

增加一款，作为第二款：“在饮用水水源二级保护区内从事网箱养殖、旅游等活动的，应当按照规定采取有效措施，防止污染饮用水水体。”

（六）将第二十二条中的“禁止下列污染地表水体和地下水体的行为”修改为“禁止下列污染水环境的行为”，将其中第二项、第五项、第八项、第九项分别修改为：“（二）在水体清洗装贮过油类或者有毒有害污染物的车辆和容器；

“（五）排放未经消毒处理或者虽经消毒处理仍不符合国家有关标准的含病原体的污水；

“（八）在河流、湖泊、运河、渠道、淀库及其最高水位线以下的滩地和岸坡以及法律法规规定的其他地点倾倒、堆放、存贮固体废弃物和其他污染物；

“（九）通过渗井、渗坑、灌注、裂隙、溶洞、暗管，篡改、伪造监测数据，以逃避现场检查为目的的临时停产，非紧急情况下开启应急排放通道或者不正常运行水污染防治设施等逃避监管的方式排放水污染物”。

（七）将第二十四条第一款修改为：“化工园区和化工项目、矿山开采区、尾矿库、危险废物处置场、垃圾填埋场等的运营、管理单位，应当采取防渗漏等措施，并建设地下水水质监测井进行监测，防止地下水污染。”

（八）将第三十四条第一款修改为：“县级以上人民政府应当依据国土空间规划，推进山水林田湖草沙综合治理和生态修复。”

（九）将第三十六条第一款修改为：“船舶以及有关作业单位从事有水污染风险的作业活动，应当按照法律法规、标准和国务院有关部门的规定，采取有效措施，防止造成水污染。”

（十）将第四十四条修改为：“省人民政府应当推动与北京市、天津市和周边地区开展水污染防治上下游联动协作，推进水生态环境保护规划、防治政策措施和技术标准、重点工程、监督防控的协调工作，共同预防和治理水污染、保护水环境。”

（十一）将第五十三条改为第五十一条，将第一款中的“环境”修改为“生态环境”、第三款中的“环境保护”修改为“生态环境”。

将第二款修改为：“建设项目的水污染防治设施，应当与主体工程同时设计、同时施工、同时投入使用。水污染防治设施应当符合经批准的生态环境影响报告书、生态环境影响报告表的要求。”

（十二）将第五十五条改为第五十三条，第二款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照规定取得排污许可证，按照排污许可证载明的排放水污染物种类、浓度、总量和排放去向等要求排放水污染物。未取得排污许可证的不得排放污染物。”

（十三）将第五十八条改为第五十六条，修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，并与生态环境主管部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。

“实行排污许可重点管理的企业事业单位和其他生产经营者发现污染物排放自动监测设备传输数据异常，应当及时报告生态环境主管部门，并进行检查、修复。生态环境主管部门发现实行排污许可重点管理的企业事业单位和其他生产经营者的污染物排放自动监测设备传输数据异常，应当及时进行调查。”

（十四）将第六十二条改为第六十条，第一款修改为：“对超过重点水污染物排放总量控制指标或者未完成水生态环境质量改善目标的地区，省人民政府生态环境主管部门应当暂停审批新增重点水污染物排放总量的建设项目的生态环境影响报告书、生态环境影响报告表。”

将第二款中的“环境保护”修改为“生态环境”。

（十五）将第六十六条改为第六十三条，修改为：“各级人民政府、负有水生态环境保护监督管理职责的部门发现违法行为或者接到对违法行为的举报后不予查处，或者有其他未依法履行职责行为的，对负有责任的领导人员和直接责任人员依法给予处分。”

（十六）将第七十七条改为第六十五条，修改为：“违反本条例规定，依照《中华人民共和国生态环境法典》等法律法规的有关规定处罚；构成犯罪的，依法追究刑事责任。”

（十七）将第五十一条改为第五十条、第五十九条改为第五十七条、第六十条改为第五十八条、第六十三条改为第六十一条、第六十五条改为第六十二条、第六十九条改为第六十四条，以及将第四条、第八条、第九条、第十条、第十一条、第二十条、第二十七条、第三十条、第三十一条、第四十一条、第四十五条、第四十六条、第四十七条中的“环境”修改为“生态环境”、“环境保护”修改为“生态环境”、“卫生”修改为“卫生健康”、“农业”修改为“农业农村”。

（十八）删去第五十条、第五十二条、第六十四条、第六十七条、第六十八条、第七十条至第七十六条。

（十九）对部分条款作以下修改：

1.将第二十一条中的“设区的市”修改为“单一水源供水城市的”。

2.将第二十九条第一款中的“有毒污染物”修改为“有毒有害污染物”。

3.删去第四十三条中的“提出损害赔偿请求”。

4.将第四十九条中的“限期达标实施规划”修改为“限期达标规划”。

二、河北省河湖保护和治理条例

（一）将第一条修改为：“为了加强河湖保护和治理，改善河湖生态环境，恢复河湖生态功能，推进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等有关法律、行政法规，结合本省实际，制定本条例。”

（二）删去第三条中的“属地责任”。

（三）删去第四条第一款中的“统筹协调有关部门，制定河湖保护和治理的总体规划、实施方案和政策措施，建立部门责任清单，健全部门联动工作机制”和第四条第四款中的“湿地保护区”。

（四）将第十四条改为第二十八条，删去第二款，将第三款中的“按照编制标准”修改为“组织”。

（五）将第十五条改为第二十九条，删去第二款中的“并作为编制河湖保护和治理规划的基本依据”。

（六）将第十六条改为第三十条。

（七）将第十七条改为第十条，删去“按照河湖保护和治理规划开展河湖系统治理”。

（八）将第二十条改为第十三条，删去“在紧急防汛期，省防汛指挥机构有权对壅水、阻水严重的桥梁、引道、码头和其他跨河工程设施依法作出紧急处置”。

（九）将第二十六条改为第十九条，删去“结合城市总体规划”。

（十）将第二十七条改为第二十条，删去“依法依规退耕还河（湖）、退耕还湿”。

（十一）将第三十条改为第二十三条，其中的“税费”修改为“水价”。

（十二）将第三十九条改为第三十五条，删去“河湖保护和治理规划和”和“并依法报经批准”。

（十三）将第四十二条改为第三十八条，删去“县级以上人民政府应当”。

（十四）将第四十九条改为第四十五条，删去“联席会商”和“落实属地责任”。

（十五）将第五十五条改为第四十九条，第一款修改为：“各级总河（湖）长对本行政区域内河湖管理保护负总责，对河湖水资源保护、水域岸线管理、水污染防治、水环境治理、水生态修复等工作进行安排部署，组织协调河湖执法监管和联防联控，督导检查本级河（湖）长、下级总河（湖）长以及相关责任部门履行职责。”

删去第二款中的“依法组织对河湖违法侵占、采砂、堆放、倾倒、建设、排污等突出问题进行清理整治”。

（十六）将第五十六条改为第五十条，修改为：“省、设区的市、县（市、区）应当明确河（湖）长制工作机构，负责协助本级总河（湖）长、河（湖）长对下级河（湖）长和本级责任部门落实河（湖）长制工作任务进行指导、协调、督察，并定期通报相关情况；对督察中发现的突出问题进行督办，对整改不力的进行约谈，有关线索依法移送监察机关。”

（十七）将第五十九条改为第五十三条，删去第一款中的“河（湖）警长”和第二款中的“并向社会公开”，并将“绩效考核评价体系”修改为“综合考核评价体系”。

（十八）将第六十条改为第五十四条，修改为：“国家机关及其工作人员违反本条例规定，有下列行为之一的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任：

“（一）未制定河湖保护名录的；

“（二）未划定河湖管理范围的；

“（三）未履行监管职责的；

“（四）应当依法公开信息而未公开的；

“（五）对应当受理的投诉、举报不受理，或者对已受理的投诉、举报不调查、不处理的；

“（六）其他玩忽职守、滥用职权、弄虚作假、徇私舞弊的。”

（十九）将第六十一条改为第五十五条，修改为“违反本条例规定，未经许可从事河道采砂活动的，由县级以上人民政府水行政主管部门责令停止违法行为，限期采取修复补救措施，没收违法所得，可以并处违法开采砂石价值二倍以上四倍以下的罚款；构成犯罪的，依法追究刑事责任。未按照许可规定从事河道采砂活动的，由县级以上人民政府水行政主管部门责令停止违法行为，限期采取修复补救措施，没收违法所得，可以并处违法开采砂石价值一倍以上三倍以下的罚款；逾期不采取修复补救措施的，由许可机关吊销河道采砂许可证。”

（二十）删去第十条、第十一条、第十二条、第十三条、第五十条、第五十二条、第六十二条。

三、河北省固体废物污染环境防治条例

（一）将第一条中的“固体废物污染环境防治法”修改为“生态环境法典”。

（二）将第五条第一款修改为：“固体废物污染环境防治坚持损害担责的原则。”

（三）将第六条第二款改为第三款，修改为：“县级以上人民政府应当建立健全固体废物污染环境防治工作机制，组织、协调、督促有关部门依法履行固体废物污染环境防治的监督管理职责，将固体废物污染环境防治工作纳入国民经济和社会发展规划，制定和实施有利于固体废物污染环境防治的经济、技术政策和措施。

增加一款，作为第六条第二款：设区的市级以上人民政府编制固体废物污染防治规划，统筹规划、建设固体废物转运、集中处置等设施、场所，推动固体废物污染防治工作。”

（四）删去第十三条中的“及其环境执法机构”。

（五）将第十四条第一款修改为：“有下列情形之一，生态环境主管部门和其他负有固体废物污染环境防治监督管理职责的部门，可以对违法收集、贮存、运输、利用、处置的固体废物及设施、设备、场所、船舶、工具、物品予以查封、扣押：

“（一）可能造成证据灭失、被隐匿或者非法转移的；

“（二）造成或者可能造成严重污染环境、破坏生态等后果的。”

（六）将第十六条改为第十五条，将第一款修改为：“省人民政府应当加强对有关部门和下级人民政府、省属企业固体废物污染环境防治工作的生态环境保护督察。被督察单位应当配合督察工作，对督察发现的问题及时整改。”

（七）将第十八条改为第十七条，修改为：“产生、收集、贮存、运输、利用、处置固体废物的单位和其他生产经营者，应当采取防扬散、防流失、防渗漏或者其他防止污染环境的措施，不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧固体废物。

“禁止任何单位或者个人向河流、湖泊、运河、渠道、水库及其最高水位线以下的滩地和岸坡以及法律法规规定的其他地点倾倒、堆放、贮存固体废物和其他污染物。”

（八）将第十九条改为第十八条，修改为：“在生态保护红线区域、永久基本农田集中区域和其他需要特别保护的区域内，禁止建设工业固体废物、建筑垃圾、危险废物集中贮存、利用、处置的设施、场所和生活垃圾填埋场。”

（九）将第二十三条改为第二十一条，修改为：“实行排污许可管理的产生工业固体废物的单位执行排污许可管理相关规定，排污许可证应当记载工业固体废物种类、贮存、利用、处置要求等信息。”

（十三）将第三十五条改为第三十四条，删去第一款中的“在地下水严重超采区且无地表水替代的区域减少高耗水农作物种植，推行季节性休耕、旱作农业。在地下水一般超采区推广种植抗旱品种和低耗水农作物”。

（十四）将第四十条改为第三十九条，删去“推进退耕还湿”。

（十五）将第四十六条改为第四十五条，修改为：“县级以上人民政府水行政主管部门和其他有关部门应当依据各自职责建立健全地下水位、水量、水质监测系统，组织建设地下水管理平台，完善地下水监测站网，明确计量方式，及时采集、传输、处理、储存监测数据，推进地下水水文地质数字信息化，实现地下水的有效、动态和精准管理。

“单位和个人取用地下水量达到取水规模以上的，应当安装地下水取水在线计量设施，并将计量数据实时传输到有管理权限的水行政主管部门和相关部门。

“任何单位和个人不得侵占、损坏或者擅自移动地下水监测设备、取用水计量设施及其标志。”

（十六）将第五十条改为第四十八条，删去第二款。

（十七）将第五十二条改为第五十条，修改为：“各级人民政府、县级以上人民政府水行政主管部门或者其他有关部门有下列行为之一的，由其上级行政机关责令改正；情节严重的，对直接负责的领导人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任：

“（一）未按照规定编制地下水利用与保护规划、地下水超采区综合治理方案；

“（二）未按照规定在编制城市总体规划和开发区、工业园区规划以及重大建设项目布局时，开展规划水资源论证；

“（三）未采取有效措施导致本行政区域内地下水超采范围扩大，或者地下水污染状况未得到改善甚至恶化；

“（四）未完成本行政区域内地下水取水总量控制指标和地下水水位控制指标；

“（五）对地下水水位低于控制水位未采取相关措施；

“（六）对不符合地下水取水条件的单位或者个人批准取水；

“（七）发现违法行为或者对有关投诉、举报以及新闻媒体曝光的违法行为不予调查处理；

“（八）其他滥用职权、玩忽职守、徇私舞弊等违法行为。”

（十八）将第五十八条改为第五十一条，修改为：“违反本条例规定，依照《中华人民共和国生态环境法典》、《地下水管理条例》等有关法律法规规定给予处罚；构成犯罪的，依法追究刑事责任。”

（十九）删去第二十一条、第四十九条、第五十三条、第五十四条、第五十五条、第五十六条、第五十七条、第五十九条、第六十条。

九、河北省发展循环经济条例

（一）将第十九条改为第十六条，删去其中的“对重点行业、重点项目进行资源消耗限额，并实行年度资源消耗审核；对超过资源消耗限额的应当限期达标，逾期未达标的应当停产”。

（二）将第二十三条改为第二十条，删去第二款中的“不具备综合利用条件的，应当委托具备条件的单位进行综合利用或者无害化处理”。

（三）将第三十一条改为第二十八条，删去第一款中的“商品批发、零售场所的经营者应当销售或者提供可降解的塑料购物袋”。

将第三款修改为“有固定门店的餐饮服务企业不主动提供一次性木质筷子”。

（四）将第三十二条改为第二十九条，将第二款修改为“禁止违反国家强制性标准对产品进行过度包装”。

（五）将第三十四条改为第三十一条，删去第三款。

（六）将第三十九条改为第三十五条，删去第二款中的“有条件使用再生水的地方，禁止使用自来水”。

（七）将第四十一条改为第三十七条，删去第二款。

将第三款修改为“鼓励使用以无毒无害的工业废弃物、建筑垃圾等作为原料生产的新型建筑材料”。

（八）将第七十四条改为第六十一条，删去其中的“《中华人民共和国环境保护法》”。

（九）删去第十二条、第十三条、第十七条、第三十八条、第六十一条、第六十二条、第六十四条、第六十五条、第六十七条、第六十八条、第六十九条、第七十二条、第七十三条。
