# 怀化市人民代表大会常务委员会关于修改《怀化市城市市容和环境卫生管理条例》等地方性法规的决定

怀化市人民代表大会常务委员会关于修改
《怀化市城市市容和环境卫生管理条例》
等地方性法规的决定

（2026年6月25日怀化市第六届人民代表大会常务委员会第三十一次会议通过　2026年7月31日湖南省第十四届人民代表大会常务委员会第二十四次会议批准）

怀化市第六届人民代表大会常务委员会第三十一次会议决定对《怀化市城市市容和环境卫生管理条例》等地方性法规作如下修改：

一、对《怀化市城市市容和环境卫生管理条例》作出修改

（一）将第一条修改为：“为了加强城市市容和环境卫生管理，创造整洁、优美、宜居、文明的城市环境，根据《中华人民共和国生态环境法典》、国务院《城市市容和环境卫生管理条例》、《湖南省城市综合管理条例》和有关法律、法规，结合本市实际，制定本条例。”

（二）将第二十三条修改为：“任何单位和个人不得侵占、损坏和擅自关闭、闲置、拆除环境卫生设施，不得擅自改变环境卫生设施的用途。

因城市建设需要拆除环境卫生设施的，应当依法报请核准或者批准，采取防止污染环境的措施，并按照拆建平衡的原则负责重建。”

（三）将第二十九条修改为：“餐饮经营单位和机关、企业事业单位的食堂（餐厅）应当将厨余垃圾交给有资质的单位进行无害化处理。

禁止将厨余垃圾直接排入城镇排水管网。禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧厨余垃圾。”

（四）将第三十条第三款修改为：“任何单位和个人不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾。”

（五）删除第四十一条。

（六）将第四十二条修改为：“违反本条例第二十四条第一项、第三项规定的，责令改正，可以处警告或者二十元以上一百元以下罚款。”

（七）删除第四十五条。

（八）删除第四十六条。

（九）将第四十九条修改为：“城市管理工作人员有下列行为之一的，由所在单位或者上级主管部门、监察机关责令改正；情节严重的，对直接负责的主管人员和其他直接责任人给予处分；造成他人损害的，依法承担赔偿责任；构成犯罪的，依法追究刑事责任：

（一）对依法应当受理的许可申请、投诉、举报不受理，或者不依法处理的；

（二）故意损坏、擅自处理或者侵占当事人财物；

（三）辱骂、殴打当事人；

（四）截留、挪用、私分罚没款物；

（五）其他玩忽职守、滥用职权或者徇私舞弊行为的。”

二、对《怀化市扬尘污染防治条例》作出修改

将第一条修改为：“根据《中华人民共和国生态环境法典》、《湖南省大气污染防治条例》等法律法规，结合本市实际，制定本条例。”

三、对《怀化市文明行为促进条例》作出修改

将第二十二条第二款修改为：“违反本条例第七条第四项规定，开展广场舞等使用电子设备的活动产生噪声，干扰他人正常生活、工作和学习的，依照《中华人民共和国生态环境法典》等规定进行处理。”

本决定自公布之日起施行。

《怀化市城市市容和环境卫生管理条例》等地方性法规根据本决定作相应修改，重新公布。
