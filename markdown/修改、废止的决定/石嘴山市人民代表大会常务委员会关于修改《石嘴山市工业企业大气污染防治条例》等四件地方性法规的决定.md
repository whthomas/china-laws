# 石嘴山市人民代表大会常务委员会关于修改《石嘴山市工业企业大气污染防治条例》等四件地方性法规的决定

石嘴山市人民代表大会常务委员会关于修改
《石嘴山市工业企业大气污染防治条例》等
四件地方性法规的决定

（2026年6月22日石嘴山市第十五届人民代表大会常务委员会第三十二次会议通过　2026年7月31日宁夏回族自治区第十三届人民代表大会常务委员会第二十六次会议批准）

石嘴山市第十五届人民代表大会常务委员会第三十二次会议决定：

一、对《石嘴山市工业企业大气污染防治条例》作出修改

（一）将第一条修改为：“为了防治工业企业大气污染，推进生态文明建设，促进经济社会可持续发展，保障公众健康，根据有关法律法规等规定，结合本市实际，制定本条例。”

（二）将第三条修改为：“工业企业大气污染防治坚持统筹规划、源头防控、分类管理、社会共治，强化多污染物控制协同、区域治理协同，加强全过程监督管理，实现减污降碳协同增效，改善生态环境质量，保障公众健康。”

（三）将第七条第三款修改为：“发展改革、科技、工业和信息化、公安、自然资源、住房和城乡建设、交通运输、应急管理、市场监管、气象等有关部门在各自职责范围内对工业企业大气污染防治实施监督管理。”

（四）将第十条增加一款，作为第二款：“排放国家有关名录中所列有毒有害大气污染物的工业企业，应当按照国家规定建设环境风险预警体系，对排污口和周边环境进行定期监测，评估环境风险，排查环境安全隐患，并采取有效措施防范环境风险。”

将第二款改为第三款，修改为：“实行排污许可重点管理的工业企业应当按照国家规定安装、使用、维护大气污染物排放自动监测、监控设备，并与生态环境主管部门的监控设备联网，保证监测设备正常运行并依法公开污染物排放信息，保存原始监测记录，如实报告。”

将第三款改为第四款，修改为：“其他工业企业应当按照国家有关规定和监测规范，自行监测本企业排放的工业废气和有毒有害大气污染物，建立管理台账，并保存原始监测记录和台账，如实报告。”

将第四款改为第五款，修改为：“禁止通过侵占、损毁或者擅自移动、改变等方式干扰、破坏大气环境监测设施、设备或者指使干扰、破坏大气环境监测设施、设备。”

（五）将第二十一条第一款修改为：“市人民政府生态环境主管部门会同气象等有关部门建立健全重污染天气监测预警机制，制定重污染天气应对预案，报自治区人民政府生态环境主管部门备案，并向社会公布。”

第二款修改为：“市、县（区）人民政府应当依据重污染天气的预警等级，及时启动应对预案，根据应对的需要可以采取责令工业企业停产或者限产等应对措施。”

第三款修改为：“重污染天气预警信息由市人民政府统一发布或者根据自治区人民政府确定的信息。任何单位和个人不得擅自发布。”

（六）删去第二十四条。

（七）将第二十五条改为两条，作为第二十四条、第二十五条，修改为：

第二十四条：“违反本条例规定，以侵占、损毁或者擅自移动、改变等方式干扰、破坏大气环境监测设施、设备或者指使干扰、破坏生态环境监测设施、设备的，由生态环境主管部门或者其他负有相关监督管理职责的部门、机构按照职责分工责令改正，处二万元以上二十万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

第二十五条：“违反本条例规定，有下列行为之一的，由生态环境主管部门或者其他负有相关监督管理职责的部门、机构按照职责分工责令改正，处二万元以上二十万元以下的罚款；拒不改正的，可以责令限制生产、停产整治：

“（一）未对所排放的污染物自行监测，未制定自行监测方案，未建立管理台账，未保存原始监测记录和管理台账，以及未如实报告；

“（二）未安装、使用、维护、正常运行污染物排放自动监测、监控设备，未与主管部门的监控设备联网，未保存原始监测记录，以及未如实报告；

“（三）未对排放有毒有害污染物的排污口和周边环境进行监测，以及未公开有毒有害污染物信息。”

（八）删去第二十六条、第二十七条、第二十八条、第二十九条。

（九）将第三十条改为第二十六条，去掉“或者其他负有相关监督管理职责部门”表述，第一项修改为：“（一）生产和使用产生含挥发性有机物辅材料和产品，未在密闭空间或者设备中进行，未按照规定安装、使用污染防治设施，或者未采取减少废气排放措施的；”

二、对《石嘴山市饮用水水源保护条例》作出修改

（一）将第一条修改为：“为了加强饮用水水源保护，保障饮用水安全，根据有关法律法规规定，结合本市实际，制定本条例。”

（二）删去第三十四条。

三、对《石嘴山市市容和环境卫生管理条例》作出修改

（一）将第三十五条第一款修改为：“市、县（区）人民政府应当按照生态环境保护和环境卫生标准，合理布局、建设、完善垃圾转运站、垃圾处理厂、公共厕所等环境卫生设施、场所。”

第二款修改为：“垃圾分类收集站、转运站、公共厕所、洒水车加水点、环卫作业用房等公共环境卫生设施、场所，由市容和环境卫生管理部门负责管理。”

（二）将第三十六条第二款修改为：“任何单位和个人不得占用、关闭、闲置、拆除各类环境卫生设施及其附属设施，不得改变其功能。”

第三款修改为：“确有必要关闭、闲置或者拆除环境卫生设施的，建设单位应当事先提出方案，经市容和环境卫生管理部门商所在地生态环境主管部门同意后核准，并采取防止污染环境的措施。”

（三）将第四十一条修改为：“市、县（区）人民政府应当加快建立健全分类投放、分类收集、分类运输、分类处理的生活垃圾管理系统，实现生活垃圾分类制度有效覆盖。

“城市生活垃圾应当由具备相应资质的专业单位定时、定点收集和运送，做到日产日清。

“禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

四、对《石嘴山市工业固体废物污染环境防治条例》作出修改

（一）将第四条修改为：“工业固体废物污染环境防治坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责，遵循减量化、资源化、无害化的原则，加强全过程管控。”

（二）将第三十一条修改为：“违反本条例规定，工业固体废物贮存、处置场所运营管理单位未按照规定自行监测土壤、地下水环境，或者未将监测数据如实报告生态环境主管部门的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，可以责令限制生产、停产整治。”

本决定自2026年8月15日起施行。

《石嘴山市工业企业大气污染防治条例》《石嘴山市饮用水水源保护条例》《石嘴山市市容和环境卫生管理条例》《石嘴山市工业固体废物污染环境防治条例》根据本决定作相应修改（并对条文顺序作相应调整），重新公布。
