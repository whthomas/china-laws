# 德州市人民代表大会常务委员会关于修改《德州市生活垃圾分类管理条例》的决定

德州市人民代表大会常务委员会关于修改《德州市生活垃圾分类管理条例》的决定

（2026年6月24日德州市第十九届人民代表大会常务委员会第三十九次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

德州市第十九届人民代表大会常务委员会第三十九次会议决定对《德州市生活垃圾分类管理条例》作如下修改：

一、将第一条修改为：“为了推进生活垃圾分类管理工作，改善人居环境，保障公众健康，促进生态文明建设，根据《中华人民共和国生态环境法典》《山东省生活垃圾管理条例》等有关法律、法规，结合本市实际，制定本条例。”

二、将第三条修改为：“生活垃圾分类管理工作遵循政府推动、全民参与、城乡统筹、属地管理、因地制宜、简便易行的原则，推动实现生活垃圾全程分类、资源化利用、无害化处理。”

三、将第四条修改为：“市、县（市、区）人民政府应当将生活垃圾分类管理工作纳入国民经济和社会发展规划，加快建立分类投放、收集、运输、处理的生活垃圾分类管理系统，建立健全工作协调机制，所需经费列入本级财政预算。

“乡镇人民政府、街道办事处依照履职事项清单，配合做好本辖区生活垃圾分类投放、收集的宣传、监督等日常管理工作。”

四、将第八条第一款中的“产生生活垃圾的单位、家庭和个人应当依法履行生活垃圾分类投放义务，按照下列规定分类投放生活垃圾：”修改为：“产生生活垃圾的单位、家庭和个人应当依法履行生活垃圾分类投放义务，按照下列方式在规定的时间、地点分类投放生活垃圾：”

第二款修改为：“任何单位和个人不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾，不得将医疗垃圾、建筑垃圾、园林垃圾、工业固体废物、农业固体废物等与生活垃圾混合投放。”

五、将第十五条修改为：“产生、收集厨余垃圾的单位和其他生产经营者，应当将厨余垃圾交由具备相应资质条件的单位进行无害化处理；建立管理台账，记录厨余垃圾的种类、数量、去向等情况，定期向所在地生活垃圾分类管理主管部门报送相关信息。

“禁止畜禽养殖场利用未经无害化处理的厨余垃圾饲喂畜禽。”

六、删去第二十六条、第二十七条。

此外，根据机构改革职能调整情况对有关单位职责和名称进行调整，同时对相关条文顺序和个别文字作了修改。

本决定自2026年8月15日起施行。

《德州市生活垃圾分类管理条例》根据本决定作相应修改，重新公布。
