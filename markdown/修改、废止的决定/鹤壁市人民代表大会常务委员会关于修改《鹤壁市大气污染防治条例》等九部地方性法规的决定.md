# 鹤壁市人民代表大会常务委员会关于修改《鹤壁市大气污染防治条例》等九部地方性法规的决定

鹤壁市人民代表大会常务委员会关于修改
《鹤壁市大气污染防治条例》等九部
地方性法规的决定

（2026年6月26日鹤壁市第十二届人民代表大会常务委员会第三十次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

鹤壁市第十二届人民代表大会常务委员会第三十次会议决定：

一、对《鹤壁市大气污染防治条例》作出修改

（一）将第一条修改为：“为了加强大气污染防治，改善环境空气质量，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，全面推进美丽鹤壁建设，加快推进人与自然和谐共生的现代化，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）在第二条增加一款，作为第二款：“本条例未作规定的，适用有关法律、法规规定。”

（三）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（四）将第六条修改为：“严格落实生态环境保护目标责任制和考核评价制度。将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。”

（五）将第九条修改为：“市人民政府生态环境主管部门负责组织建设与管理本行政区域的大气环境质量和大气污染源监测网络，开展大气环境质量和大气污染源监测。

“禁止通过侵占、损毁或者擅自移动、改变等方式干扰、破坏大气环境监测设施、设备或者指使干扰、破坏大气环境监测设施、设备。”

（六）将第十五条第一款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照排污许可证的要求和有关标准规范，依法开展自行监测，建立管理台账，并保存原始监测记录和管理台账。原始监测记录和管理台账保存期限不得少于五年。”；将第二款中的“二十四小时”修改为“十二小时”。

（七）将第十九条修改为：“市人民政府可以划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。

“禁燃区内，禁止销售和燃用国家规定的高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”

（八）将第二十一条修改为：“市、县（区）人民政府应当按照国家和省规定要求，制定本行政区域锅炉整治计划，淘汰、拆除不符合规定的燃烧煤炭、重油、渣油以及直接燃用生物质的锅炉。锅炉污染物排放应当符合国家和省规定的污染物排放标准。”

（九）将第二十四条修改为：“有机化工、制药、电子设备制造、包装印刷、门窗家具制造等产生含挥发性有机物废气的生产和服务活动，应当按照国家规定在密闭空间、设备中进行并安装、使用污染防治设施，或者采取有效措施减少废气排放。”

（十）将第二十五条修改为：“加油站、储油库和油罐车、铁路罐车等应当按照规定安装油气回收装置并保持正常使用。”

（十一）将第二十七条第一款修改为：“生态环境主管部门可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测；在不影响正常通行的情况下，可以通过非接触式道路监测等技术手段对在道路上行驶机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测，公安机关交通管理部门予以配合。”

（十二）将第三十条第一款、第二款修改为：“建设单位应当将防治扬尘污染的费用列入工程造价，在施工合同中明确施工单位的扬尘污染防治责任。施工单位应当制定具体的施工扬尘污染防治实施方案，工程监理单位应当将扬尘污染防治纳入工程监理细则。

“施工单位应当在施工工地设置硬质围挡，并采取覆盖、分段作业、择时施工、洒水抑尘、冲洗地面和车辆等有效防尘降尘措施。工程渣土等建筑垃圾、建筑土方应当及时清运；在场地内堆存的，应当采取密闭式防尘网遮盖。工程渣土等建筑垃圾应当进行资源化处理。”

（十三）将第三十三条第二款修改为：“禁止在人口集中地区、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧秸秆。”

（十四）将第三十五条改为两条，作为第三十五条、第三十六条，修改为：“第三十五条各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

“排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用。禁止在居民住宅楼、未配套设立专用烟道的商住综合楼以及商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目。

“排放油烟污染物的餐饮服务业经营者应当采取有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染。

“任何单位和个人不得在人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。

“第三十六条从事服装干洗和机动车维修等服务活动的经营者，应当按照国家相关标准或者要求设置异味和废气处理装置等污染防治设施并保持正常使用，防止影响周边环境。”

（十五）将第三十九条改为第四十条，修改为：“市、县（区）人民政府应当制定重污染天气应对预案，向上一级人民政府生态环境主管部门备案，并向社会公布。

“市、县（区）人民政府应当依据重污染天气的预警等级，及时启动应对预案，根据应对的需要可以采取责令有关企业停产或者限产、限制部分机动车行驶和非道路移动机械使用、禁止燃放烟花爆竹、停止工地土石方作业和建筑物拆除施工、停止露天烧烤、停止幼儿园和学校组织的户外活动、组织开展人工影响天气作业等应对措施。

“应对响应结束后，市、县（区）人民政府应当及时开展应对预案实施情况的评估，适时修改完善应对预案。”

（十六）将第四十二条改为第四十三条，修改为：“违反本条例第九条第二款规定的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（十七）将第四十三条改为第四十四条，修改为：“违反本条例第十三条第一款规定，未依法取得排污许可证排放污染物的，由生态环境主管部门责令改正，处二十万元以上一百万元以下的罚款，并可以责令限制生产、停产整治；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。拒不停止排放污染物的，由生态环境主管部门将案件移送公安机关，由公安机关依法处罚。

“违反本条例第十三条第一款规定，未按照排污许可证载明的污染物排放种类，或者超过载明的许可排放浓度、许可排放量、许可排放限值排放污染物的，由生态环境主管部门责令改正，处十万元以上一百万元以下的罚款，并可以责令限制生产、停产整治；情节严重的，吊销排污许可证，报经有批准权的人民政府批准，责令停业、关闭。”

（十八）删去第四十四条。

（十九）将第四十五条修改为：“违反本条例第十九条第二款、第二十条第二款规定，有下列情形之一的，由生态环境主管部门没收燃用高污染燃料的设施、燃煤供热锅炉并组织拆除，处二万元以上二十万元以下的罚款：

“（一）在禁燃区内未停止燃用国家规定的高污染燃料；

“（二）在禁燃区内新建、扩建燃用高污染燃料的设施；

“（三）在城市集中供热管网覆盖区域内新建、扩建分散燃煤供热锅炉。

“违反本条例第十九条第二款规定，在禁燃区内销售国家规定的高污染燃料的，由市、县（区）人民政府市场监督管理部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下的罚款。”

（二十）删去第四十六条。

（二十一）将第四十七条改为第四十六条，修改为：“违反本条例第二十三条第一款规定，生产、销售挥发性有机物含量不符合质量标准或者要求的原辅材料和产品的，由市、县（区）人民政府市场监督管理部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下的罚款。”

（二十二）将第四十九条改为第四十八条，修改为：“违反本条例第二十五条规定，加油站、储油库、油罐车、铁路罐车等未按照规定安装油气回收装置并保持正常使用的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，责令停产整治。”

（二十三）将第五十条改为第四十九条，修改为：“违反本条例第二十八条第一款规定，在用重型汽车、非道路移动机械未按照规定加装、更换符合要求的排放控制系统或者采取其他有效措施的，由生态环境主管部门或者其他有关部门按照职责责令改正，处每辆五千元的罚款。

“违反本条例第二十八条第二款规定，在禁止使用高排放非道路移动机械的区域使用高排放非道路移动机械的，由生态环境主管部门责令改正，处每辆五千元的罚款。”

（二十四）将第五十一条改为第五十条，第二款修改为：“违反本条例第三十条第二款规定，施工工地未设置硬质围挡、未按照规定采取有效防尘降尘措施的，由市、县（区）人民政府住房和城乡建设主管部门责令改正，处二万元以上十万元以下的罚款；拒不改正的，责令停工整治。”

（二十五）将第五十四条改为第五十三条，修改为：“违反本条例第三十三条第二款规定，在禁止焚烧的区域和时段露天焚烧秸秆的，由市、县（区）人民政府农业农村等主管部门责令改正，可以处五百元以上二千元以下的罚款。”

（二十六）将第五十五条改为两条，作为第五十四条、第五十五条，修改为：“第五十四条违反本条例第三十五条第二款规定，排放油烟的餐饮服务业经营者未按照规定安装并正常使用油烟净化等污染防治设施或者未采取其他油烟净化措施，致使超过排放标准排放油烟污染物的，由市、县（区）人民政府城市管理主管部门责令改正，处五千元以上五万元以下的罚款；拒不改正的，责令停业整治。

“违反本条例第三十五条第二款规定，在居民住宅楼、未配套设立专用烟道的商住综合楼、商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目的，由市、县（区）人民政府城市管理主管部门责令改正；拒不改正的，责令关闭，并处一万元以上十万元以下的罚款。

“违反本条例第三十五条第四款规定，在人民政府禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地的，由市、县（区）人民政府城市管理主管部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。

“第五十五条违反本条例第三十六条规定，从事服装干洗和机动车维修等服务活动，未设置异味和废气处理装置等污染防治设施并保持正常使用的，由生态环境主管部门责令改正，处二千元以上二万元以下的罚款；拒不改正的，责令停业整治。”

（二十七）对部分条文作以下修改：

1.将第五条中的“市、县（区）人民政府生态环境主管部门”修改为“生态环境主管部门”，“水利”修改为“水行政”。

2.在第二十三条第一款中的“生产”后增加“进口”，将“原材料”修改为“原辅材料”。

3.将第二十八条第一款中的“柴油车”修改为“汽车”，在“非道路移动机械”后增加“等”，将“不得超过标准排放大气污染物”修改为“未按照规定安装排放控制系统或者排放控制系统不符合要求”，“污染控制装置”修改为“排放控制系统，或者采取其他有效措施”。

4.将第三十七条第一款中的“市人民政府”修改为“县级以上人民政府”。

5.将第四十八条、第五十二条、第五十七条、第五十八条中的“市、县（区）人民政府生态环境主管部门”修改为“生态环境主管部门”。

6.将第五十六条中的“市人民政府”修改为“县级以上人民政府”，“市、县（区）人民政府”修改为“县级以上人民政府”。

二、对《鹤壁市地下水保护条例》作出修改

（一）在第二条增加一款，作为第二款：“本条例未作规定的，适用有关法律、法规规定。”

（二）删去第五条。

（三）删去第十四条。

（四）将第二十三条改为第二十一条，第二款修改为：“禁止通过侵占、损毁或者擅自移动、改变等方式干扰、破坏地下水监测设施、设备或者指使干扰、破坏地下水监测设施、设备。”

（五）删去第二十八条。

（六）删去第三十条。

（七）将第三十一条改为第二十七条，修改为：“违反本条例第二十一条第二款规定，单位和个人以侵占、损毁或者擅自移动、改变等方式干扰、破坏地下水监测设施、设备或者指使干扰、破坏地下水监测设施、设备的，由水行政、自然资源、生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（八）对部分条文作以下修改：

1.将第十五条、第十六条中的“水利”修改为“水行政”。

2.将第二十六条中的“对直接负责的主管人员或者其他直接责任人员依法给予处分”修改为“对负有责任的领导人员和直接责任人员，依法给予处分”。

三、对《鹤壁市淇河保护条例》作出修改

（一）将第一条修改为：“为了保护淇河生态环境，推进生态文明建设，促进经济社会高质量发展，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等法律、法规，结合本市实际，制定本条例。”

（二）在第二条增加一款，作为第四款：“本条例未作规定的，适用有关法律、法规规定。”
