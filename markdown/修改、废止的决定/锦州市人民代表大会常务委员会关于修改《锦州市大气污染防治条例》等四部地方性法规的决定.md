# 锦州市人民代表大会常务委员会关于修改《锦州市大气污染防治条例》等四部地方性法规的决定

锦州市人民代表大会常务委员会关于修改
《锦州市大气污染防治条例》等四部
地方性法规的决定

（2026年7月1日锦州市第十七届人民代表大会常务委员会第四十次会议通过　2026年7月29日辽宁省第十四届人民代表大会常务委员会第二十四次会议批准）

锦州市第十七届人民代表大会常务委员会第四十次会议决定：

一、对《锦州市大气污染防治条例》作出修改

（一）将第一条中的“根据《中华人民共和国大气污染防治法》《辽宁省大气污染防治条例》等有关法律、法规”修改为“根据《中华人民共和国生态环境法典》等法律、法规”。

（二）将第三条第一款修改为：“市、县（市、区）人民政府应当将大气污染防治工作纳入国民经济和社会发展规划，加强组织协调和监督考核，加大对大气污染防治的财政投入。”

（三）将第四条修改为：“市人民政府生态环境主管部门对本行政区域大气污染防治工作实施统一监督管理。

“市、县（市、区）人民政府其他有关部门在各自职责范围内对大气污染防治工作实施监督管理。”

（四）将第五条修改为：“市、县（市、区）人民政府应当支持大气污染防治科学技术研究、开发和应用，对技术改造、设备更新、能源替代给予政策和资金支持。”

（五）将第六条中的“在编制国土空间规划等规划时”修改为“编制国土空间规划和相关规划”。

（六）将第七条修改为：“任何单位和个人有权对污染大气环境的行为、不依法履行监督管理职责的行为进行举报。

“市人民政府生态环境主管部门和其他负有大气环境保护监督管理职责的部门应当公布举报电话、电子邮箱等，保证举报渠道畅通，方便公众举报。

“接受举报的机关应当及时处理并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。

“举报人举报所在单位的，该单位不得以解除、变更劳动合同、聘用合同，或者以其他方式对举报人进行打击报复。”

（七）将第八条改为两款，修改为：“市、县（市、区）人民政府应当依法及时编制本行政区域大气环境质量限期达标规划，采取有效措施，按期达到规定的大气环境质量标准并逐步改善。

“大气环境质量限期达标规划应当向社会公开，按照规定备案，并根据大气污染防治的要求和经济、技术条件适时进行评估、修订。”

（八）删去第九条。

（九）将第十条改为第九条，修改为：“向大气排放污染物的企业事业单位和其他生产经营者，应当保持大气污染物防治设施的正常使用，不得擅自拆除、闲置。”

（十）删去第十一条。

（十一）将第十二条改为第十条，第一款修改为：“市、县（市、区）人民政府应当组织、协调、督促有关部门依法履行大气环境保护监督管理职责。”

（十二）删去第十三条。

（十三）将第十四条改为第十一条，修改为：“市人民政府可以划定高污染燃料禁燃区，并根据大气环境质量改善要求逐步扩大范围。划定的高污染燃料禁燃区应当向社会公布并按照规定备案。”

（十四）删去第十六条、第十七条。

（十五）将第十八条改为第十三条，将其中的“新能源汽车”修改为“新能源机动车”。

（十六）将第十九条改为第十四条，第一款中的“住房和城乡建设、城市管理执法等部门”修改为“市、县（市、区）人民政府住房和城乡建设、水行政、城市管理执法等部门”。

删去第三款。

（十七）将第二十条改为第十五条，分为两款，修改为：“市、县（市、区）人民政府应当加强道路、广场、停车场和其他公共场所的清扫保洁管理，推行清洁动力机械化清扫和其他科学合理的低尘作业方式，防治扬尘污染。

“环境卫生部门应当按照清扫保洁作业标准和规范要求，合理安排作业时间，适时增加作业频次，做好扬尘污染防治工作。”

（十八）将第二十一条改为第十六条，修改为：“市、县（市、区）人民政府农业农村等有关部门应当在各自职责范围内推广高效低毒低残留农药和测土配方施肥技术，指导农业生产经营者科学合理使用农药和化肥，减少大气污染物排放。

“园林绿化部门应当采用高效低毒低残留农药防治园林病虫害，并合理安排施药时间。”

（十九）将第二十二条改为第十七条，修改为：“从事畜禽养殖和屠宰的单位和个人应当采取有效措施，及时对畜禽粪污、尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，防止污染环境。”

（二十）将第二十三条改为第十八条，修改为：“违反本条例规定的行为，依照有关法律、法规的规定追究法律责任。”

（二十一）增加一条，作为第十九条：“本条例所称县（市、区）人民政府包括具有社会管理职能的国家级经济技术开发区管理委员会、高新技术产业开发区管理委员会。但法律、法规规定应当由县级人民政府履行的职责，依照相关规定执行。”

二、对《锦州市文明行为促进条例》作出修改

（一）删去第三条第二款中的“含滨海新区管理委员会、松山新区管理委员会，下同”。

删去第三款。

（二）将第七条第三项修改为：“（三）不在县级以上地方人民政府禁止的时段和区域燃放烟花爆竹，不违法焚烧产生烟尘、有毒有害气体、恶臭气体的物质，不在当地人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地；”

（三）将第八条第五项修改为：“（五）不擅自在公共绿地种植农作物和在城市建成区内饲养鸡、鸭、鹅、兔、羊、猪等家禽家畜与食用鸽；饲养信鸽应当符合体育行政部门的有关规定，具备相应的条件，并采取措施防止扰民和影响环境卫生；”

（四）删去第十八条至第二十二条。

（五）将第二十三条、第二十四条合并，作为第十八条，修改为：“违反本条例规定的行为，依照有关法律、法规的规定追究法律责任。”

（六）增加一条，作为第十九条：“本条例所称县（市、区）人民政府包括具有社会管理职能的国家级经济技术开发区管理委员会、高新技术产业开发区管理委员会。但法律、法规规定应当由县级人民政府履行的职责，依照相关规定执行。”

修改后的《锦州市文明行为促进条例》不再分章。

三、对《锦州市生活垃圾分类管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》《城市市容和环境卫生管理条例》等有关法律、法规”修改为“《中华人民共和国生态环境法典》等法律、法规”。

（二）将第三条修改为：“市、县（市、区）人民政府应当把生活垃圾分类管理工作纳入国民经济和社会发展规划，建立健全工作协调机制，并将所需经费纳入本级财政预算。

“市、县（市、区）人民政府及其有关部门和乡镇人民政府应当组织开展生活垃圾分类宣传，教育引导公众养成生活垃圾分类习惯，督促和指导生活垃圾分类工作。

“乡镇人民政府、街道办事处应当按照职责做好生活垃圾分类管理相关工作。”

（三）将第四条第一款、第六条中的“市容环境卫生行政主管部门”修改为“环境卫生主管部门”。

删去第四条第二款中的“市、县（市、区）人民政府”，该款中的“水利”修改为“水行政”、“林草”修改为“林业草原”。

第六条中的“专项规划”修改为“相关规划”。

（四）将第五条修改为：“市、县（市、区）人民政府应当加快建立健全分类投放、分类收集、分类运输、分类处理的生活垃圾管理系统，实现生活垃圾分类制度有效覆盖。

“市人民政府环境卫生主管部门应当制定生活垃圾清扫、收集、贮存、运输和处理设施、场所建设运行规范，公布生活垃圾分类指导目录，加强监督管理。”

（五）删去第七条。

（六）将第八条改为第七条，第二款修改为：“任何单位和个人都应当依法在指定的地点分类投放生活垃圾。禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

删去第三款。

（七）将第九条改为第八条，删去第二项中的“并发挥居民委员会、村民委员会作用”。

（八）将第十条改为第九条，删去第一项中的“以及分类标准”、“按照生活垃圾分类标准”。

第二项修改为：“（二）设置生活垃圾分类收集容器并保持生活垃圾分类收集容器完好和整洁，出现破旧、污损或者数量不足的，及时维修、更换、清洗或者补设；”

（九）将第十一条改为第十条，修改为：“市、县（市、区）人民政府环境卫生等有关部门应当在各自职责范围内组织对城乡生活垃圾进行清扫、收集、运输和处理，可以通过招标等方式选择具备条件的单位从事生活垃圾的清扫、收集、运输和处理。”

（十）将第十四条改为第十三条，修改为：“违反本条例规定，未在指定的地点分类投放生活垃圾的，由市、县（市、区）人民政府环境卫生主管部门或者行使相对集中行政处罚权的部门按照职责分工，责令改正；拒不改正的，对单位处五万元以上五十万元以下的罚款，对个人处一百元以上五百元以下的罚款。”

（十一）增加一条，作为第十四条：“本条例所称县（市、区）人民政府包括具有社会管理职能的国家级经济技术开发区管理委员会、高新技术产业开发区管理委员会。但法律、法规规定应当由县级人民政府履行的职责，依照相关规定执行。”

四、对《锦州市畜禽养殖污染防治条例》作出修改

（一）将第一条中的“根据《中华人民共和国环境保护法》、《中华人民共和国固体废物污染环境防治法》等法律、法规”修改为“根据《中华人民共和国生态环境法典》等法律、法规”。

（二）将第三条第一款中的“市、县（市、区）人民政府”修改为“市、县（市、区）、乡镇人民政府”。

第二款与第四条第三款合并，作为第四条第三款，修改为：“市、县（市、区）人民政府其他有关部门和乡镇人民政府、街道办事处按照各自职责，做好畜禽养殖污染防治相关工作。”

（三）将第五条、第九条第一款和第二款、第十一条中的“综合利用和无害化处理”修改为“无害化处理和资源化利用”。

第七条、第十一条第二项、第十四条中的“粪便和污水”修改为“粪污”。

第九条中的“应当符合标准”修改为“应当符合标准和要求”。

（四）将第六条修改为：“任何单位和个人有权对畜禽养殖污染环境的行为、不依法履行监督管理职责的行为进行举报。

“生态环境主管部门和其他负有畜禽养殖污染防治监督管理职责的部门应当公布举报电话、电子邮箱等，保证举报渠道畅通，方便公众举报。

“接受举报的机关应当及时处理并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。

“举报人举报所在单位的，该单位不得以解除、变更劳动合同、聘用合同，或者以其他方式对举报人进行打击报复。”

（五）将第八条修改为：“畜禽养殖专业户、散养户应当及时对畜禽粪污等废弃物进行收集、贮存、清运，防止畜禽养殖废弃物渗出、泄漏和恶臭污染。”

（六）将第十条中的“应当符合国家和地方有关畜禽养殖污染物排放的标准”修改为“应当符合排放标准和要求”。

（七）将第十五条修改为：“根据畜禽养殖污染防治需要，畜禽散养密集区所在地县（市、区）人民政府应当规划建设畜禽粪污处理中心。

“畜禽散养密集区所在地县（市、区）及乡镇人民政府应当及时组织对畜禽粪污进行分户收集、集中处理利用。”

（八）将第十八条第二款修改为：“排放畜禽养殖废弃物，违反法律、法规关于水污染防治、土壤污染防治、海洋环境保护、动物防疫等规定的，依照其规定执行。”

（九）将第十九条中的“开发区管委会、高新区管委会”修改为“具有社会管理职能的国家级经济技术开发区管理委员会、高新技术产业开发区管理委员会”。

（十）将第二十条修改为：“本条例所称的养殖专业户是指达到辽宁省人民政府确定的畜禽养殖规模的养殖户；散养户是指畜禽养殖规模在养殖专业户以下的养殖户。”

本决定自2026年8月15日起施行。

《锦州市大气污染防治条例》、《锦州市文明行为促进条例》、《锦州市生活垃圾分类管理条例》、《锦州市畜禽养殖污染防治条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
