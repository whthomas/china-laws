# 杜尔伯特蒙古族自治县人民代表大会关于废止《黑龙江省杜尔伯特蒙古族自治县动物防疫管理条例》的决定

杜尔伯特蒙古族自治县人民代表大会
关于废止《黑龙江省杜尔伯特蒙古族自治县
动物防疫管理条例》的决定

（2025年6月20日杜尔伯特蒙古族自治县第十七届人民代表大会第五次会议通过　2025年7月31日黑龙江省第十四届人民代表大会常务委员会第二十三次会议批准）

杜尔伯特蒙古族自治县第十七届人民代表大会第五次会议决定废止《黑龙江省杜尔伯特蒙古族自治县动物防疫管理条例》。

本决定自公布之日起施行。
