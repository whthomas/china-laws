# 淮北市人民代表大会常务委员会关于修改《淮北市文明行为促进条例》的决定

淮北市人民代表大会常务委员会关于修改
《淮北市文明行为促进条例》的决定

（2026年6月30日淮北市第十七届人民代表大会常务委员会第四十三次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为维护国家法治统一、尊严、权威，根据《中华人民共和国生态环境法典》相关规定，淮北市第十七届人民代表大会常务委员会第四十三次会议决定对《淮北市文明行为促进条例》作如下修改：

第十条第十四项修改为“（十四）在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质”。

本决定自2026年8月15日起施行。

《淮北市文明行为促进条例》根据本决定作相应修改，重新公布。
