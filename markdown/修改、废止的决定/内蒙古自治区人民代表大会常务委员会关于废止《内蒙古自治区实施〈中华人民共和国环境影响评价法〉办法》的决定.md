# 内蒙古自治区人民代表大会常务委员会关于废止《内蒙古自治区实施〈中华人民共和国环境影响评价法〉办法》的决定

内蒙古自治区人民代表大会常务委员会关于
废止《内蒙古自治区实施〈中华人民共和国
环境影响评价法〉办法》的决定

（2026年7月29日内蒙古自治区第十四届人民代表大会常务委员会第二十九次会议通过）

内蒙古自治区第十四届人民代表大会常务委员会第二十九次会议，决定废止2012年5月30日内蒙古自治区第十一届人民代表大会常务委员会第二十九次会议通过，2018年12月6日内蒙古自治区第十三届人民代表大会常务委员会第十次会议修正的《内蒙古自治区实施〈中华人民共和国环境影响评价法〉办法》。本决定自公布之日起生效。
