# 东营市人民代表大会常务委员会关于修改《东营市大气污染防治条例》等四件地方性法规的决定

东营市人民代表大会常务委员会关于修改
《东营市大气污染防治条例》等四件
地方性法规的决定

（2026年6月25日东营市第九届人民代表大会常务委员会第三十二次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

东营市第九届人民代表大会常务委员会第三十二次会议决定：

一、对《东营市大气污染防治条例》作出修改

1.将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，推进生态文明建设，根据《中华人民共和国生态环境法典》《山东省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

2.将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责的原则，落实污染物总量控制和区域联防联控制度。”

3.将第四条第二款、第三款修改为：“市、县（区）人民政府应当将大气污染防治工作纳入国民经济和社会发展规划，统筹解决大气污染防治中遇到的重大问题。

“乡镇人民政府、街道办事处按照职责做好大气污染防治相关工作。”

4.将第十五条改为第十二条，修改为：“企业事业单位和其他生产经营者应当按照国家规定制定突发生态环境事件应急预案，并定期组织演练。应急预案应当报生态环境等有关部门备案。因发生或者可能发生生产安全事故等紧急情况，需要通过应急排放通道排放大气污染物的，排污单位应当立即采取必要措施，减轻或者消除危害，并向生态环境主管部门报告。”

5.将第十六条改为第十三条，第二款修改为：“公民、法人和其他组织发现任何单位和个人有污染大气环境行为的，有权向负有大气环境保护监督管理职责的部门举报；发现本市各级人民政府或者负有大气环境保护监督管理职责的部门不依法履行职责的，有权向其上级机关或者监察机关举报。接受举报的机关应当依法及时处理并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。举报人举报所在单位的，该单位不得以解除、变更劳动合同、聘用合同或者其他方式对举报人进行打击报复。举报内容经查证属实的，应当按照规定给予举报人奖励。”

6.将第十八条改为第十四条，修改为：“市人民政府以及可能发生重污染天气的县级人民政府应当制定并及时更新重污染天气应对预案，报上一级人民政府生态环境主管部门备案并公布。

“市、县（区）人民政府依据重污染天气的预警等级，及时启动应对预案，并采取相应的应对措施。

“市、县（区）人民政府应当制定并及时更新污染源应急减排清单，向上一级人民政府报告并公布。纳入应急减排清单并应采取应急减排措施的企业事业单位，应当根据重污染天气应对预案的要求，编制重污染天气应对响应操作方案，向生态环境主管部门报告，并按照规定执行相应的应急措施。”

7.将第二十一条改为第十七条，修改为：“禁止销售、进口或者燃用不符合质量标准的煤炭。

“市、县（区）人民政府应当建立完善的清洁煤炭配送中心和销售网络。

“市场监督管理部门负责销售不符合质量标准煤炭的查处工作。”

8.将第二十二条改为第十八条，第二款修改为：“新建直接燃煤、重油、渣油锅炉和直接燃用生物质的锅炉，应当严格执行国家和省有关规定。”

9.将第三十三条改为第二十七条，第一款修改为：“禁止生产、进口或者销售不符合标准的机动车船、非道路移动机械用燃料和氮氧化物还原剂；禁止向机动车、非道路移动机械、内河和江海直达船舶销售非机动车船用燃料；禁止机动车、非道路移动机械、内河和江海直达船舶使用非机动车船用燃料。”

10.将第三十四条改为第二十八条，修改为：“在用机动车应当按照规定，由机动车排放检验机构定期对其进行排放检验。经检验合格的，方可上道路行驶。生态环境主管部门可以会同公安机关交通管理部门、交通运输主管部门，通过非接触式道路监测等技术手段对在道路上行驶的机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测。

“在用机动车排放大气污染物超过标准的，应当进行维修；经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。”

11.将第三十六条改为第三十条，修改为：“非道路移动机械应当达标排放。禁止使用有明显可见烟以及其他不符合大气污染物排放标准的非道路移动机械及其发动机。

“建设单位、施工单位和其他生产经营单位应当使用符合前款规定的非道路移动机械。

“非道路移动机械所有人或者使用人应当按照规范对在用非道路移动机械进行维护检修。对超过标准排放大气污染物的，应当维修、加装或者更换符合要求的污染控制装置，使其达到规定的排放标准。

“在用非道路移动机械经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。”

12.将第三十八条改为第三十二条，修改为：“新建码头应当按照规定规划、设计和建设岸基供电设施，已建成码头应当按照规定逐步实施岸基供电设施改造。具备岸电使用条件的船舶靠港应当按照国家规定使用岸电，但是使用清洁低碳能源的除外。

“船舶进入本市水域后应当使用符合标准或者大气污染物控制要求的燃油。”

13.将第四十二条改为第三十五条，修改为：“码头、矿山、填埋场和消纳场应当实施分区作业，并采取有效措施防治扬尘污染。

“港口、道路运输站（场）应当对物料堆放场所采取抑尘措施；具备条件的，实施分区作业，采取密闭运输、密闭储存等有效措施防治扬尘污染。”

14.将第四十五条改为第三十八条，第一款修改为：“从事畜禽养殖和屠宰的单位和个人应当采取有效措施，及时对污水、畜禽粪便和尸体等进行收集、贮存、清运、无害化处理和资源化利用，防止污染环境。”

15.将第四十六条改为第三十九条，修改为：“本市各级人民政府应当科学精准加强秸秆、落叶等焚烧的组织、指导和管理。禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

16.将第五十条改为第四十三条，修改为：“本市各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

“餐饮服务业经营者应当使用清洁能源作为燃料。排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用；采取有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染。油烟净化设施每季度至少进行一次清洗维护。

“禁止在居民住宅楼、未配套设立专用烟道的商住综合楼以及商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目。

“任何单位和个人不得在市、县（区）人民政府划定的禁止时段和区域露天烧烤、骑墙（窗）烧烤或者为露天烧烤、骑墙（窗）烧烤提供场地。在其他区域内烧烤的，应当使用无烟烧烤炉具。”

17.将第五十八条改为第四十六条，修改为：“违反本条例规定，石油勘探、开发、储运单位有下列行为之一的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，责令停产整治：

“（一）对石油开发作业产生的套管气（伴生气）及其他可燃性气体未进行回收、处理或者综合利用；

“（二）在联合站、接转站、计量站、注水站、钻井废液处理站、作业废液处理站未采取地面管线防渗漏、防溢流等措施；

“（三）油气集输过程未采用密闭集输工艺、未安装套管气回收装置；

“（四）原油储罐未设置浮顶罐或者采取其他措施减少油气无组织排放；

“（五）油泥砂贮存设施未采取防风、防渗、防雨、防晒措施。”

18.将第六十条改为第四十七条，修改为：“违反本条例规定，储油库、加油站、油罐车等所配备的油气回收装置未进行定期检测的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，责令停产整治。”

19.将第六十三条改为第四十八条，修改为：“违反本条例规定，在禁止焚烧的区域和时段露天焚烧秸秆的，由农业农村主管部门责令改正，可以处五百元以上二千元以下的罚款；在禁止焚烧的区域和时段露天焚烧落叶等产生烟尘污染的物质的，城市建成区内由城市管理主管部门、城市建成区外由市或者县（区）人民政府确定的主管部门责令改正，可以处五百元以上二千元以下的罚款。”

20.将第六十四条改为第四十九条，修改为：“违反本条例规定，在城市建成区内人口密集区域未密闭或者未使用烟气处理装置加热沥青的，由城市管理主管部门责令改正，对单位处一万元以上十万元以下的罚款，对个人处五百元以上二千元以下的罚款。”

21.将第六十五条改为第五十条，修改为：“各级人民政府和有关部门及其工作人员在大气污染防治监督管理工作中，滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分。”

22.删去第六条、第九条、第十一条第二款、第十四条、第十七条、第二十七条、第二十八条、第三十三条第二款、第四十一条、第五十二条、第五十三条、第五十五条至第五十七条、第五十九条、第六十一条、第六十二条。

二、对《东营市海岸带保护条例》作出修改

1.将第一条修改为：“为了加强海岸带综合管理，保护海岸带生态环境，发挥海岸带在经济、社会、文化和生态文明建设中的重要作用，根据《中华人民共和国生态环境法典》《中华人民共和国海域使用管理法》等有关法律、法规，结合本市实际，制定本条例。”

2.将第五条第三款修改为：“沿海乡镇人民政府、街道办事处按照职责做好有关工作。”

3.将第十五条和第二十五条合并，作为第十五条，修改为：“海岸带根据保护规划实行分区保护。市人民政府应当设立海岸带标识，明确海岸带及其内部区域的边界。

“重点保护区除国家能源安全和国防安全等公共利益需要外，禁止矿产资源开采、拦蓄地表水等损害海岸带地形地貌和生态环境的活动。禁止工业生产和商品房建设。禁止设置排污口，已设置的排污口，应当清理拆除。

“一般保护区应当依法严格审批、科学布局建设项目，合理确定建设项目规模，严格控制占用海岸线长度，提高海岸带开发的投资强度和利用效率。设置排污口应当严格遵守相关规定、标准，科学论证，并与重点保护区保持合理的防护距离。

“经依法确定为国家公园、自然保护区、海洋公园、水产种质资源保护区、海洋特别保护区、饮用水水源保护区、湿地公园的，依照有关法律、法规的规定进行保护和管理。但是，其他法律、法规有更严格规定的从其规定。”

4.将第十六条修改为：“任何单位和个人不得破坏自然岸线保护范围内的地形地貌和景观，不得改变自然岸线属性。”

5.将第二十一条修改为：“市、沿海县（区）人民政府应当划定海岸带范围内水产养殖限养区和养殖区。

“限养区内严格控制新增水产养殖项目，禁止擅自扩大养殖规模。市、沿海县（区）人民政府可以划定一定的范围禁止设施养殖。

“从事养殖生产应当保护水域、滩涂生态环境，科学确定养殖密度、规模等，合理投饵、投饲、使用药物，养殖排放尾水应当符合有关污染物排放标准，不得造成水域、滩涂的环境污染、生态破坏。”

6.将第二十六条改为第二十五条，第一款修改为：“禁止在海岸带范围内倾倒、堆放、丢弃、抛撒、遗撒或者焚烧垃圾等废弃物。”

7.增加一条，作为第三十六条：“违反本条例第十六条规定，破坏自然岸线保护范围内地形地貌、景观，改变自然岸线属性的，由负有生态环境保护监督管理职责的部门、机构责令改正，处每米五百元以上一万元以下的罚款。”

8.删去第五条第二款、第二十条第二款、第三十七条至第三十九条、第四十一条。

三、对《东营市生活垃圾分类管理条例》作出修改

1.将第一条修改为：“为了加强生活垃圾分类管理，改善人居环境，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》《中华人民共和国循环经济促进法》《山东省生活垃圾管理条例》等法律、法规，结合本市实际，制定本条例。”

2.将第十八条改为第十七条，第二款修改为：“禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

3.将第三十八条改为第三十六条，修改为：“违反本条例第十七条规定，未在指定的地点分类投放生活垃圾的，由生活垃圾分类管理主管部门责令改正；拒不改正的，对单位处五万元以上五十万元以下罚款，对个人处五十元以上二百元以下罚款。”

4.删去第六条、第二十六条、第四十一条。

四、对《东营市危险废物管理条例》作出修改

1.将第一条修改为：“为了加强危险废物管理，防治环境污染，保障公众健康，维护生态安全，推进生态文明建设，服务和保障黄河流域生态保护和高质量发展，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

2.将第三条修改为：“危险废物的监督管理和污染防治应当坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责，遵循减量化、资源化、无害化的原则，加强产生、收集、贮存、运输、利用、处置等全过程管控。”

3.将第四条修改为：“各级人民政府应当加强危险废物污染防治工作，对本行政区域危险废物污染防治负责。

“市、县（区）人民政府应当将危险废物污染防治作为固体废物污染防治工作的重点内容，纳入国民经济和社会发展规划，制定、落实有利于危险废物污染防治的经济、技术等政策措施，鼓励、支持危险废物污染防治的科学研究、先进技术开发与推广，建立多元化资金投入和保障机制，统筹解决污染防治工作中的重大问题，提高危险废物源头减量、综合利用和污染防治能力。”

4.将第八条第一款修改为：“国家机关、企业事业单位和新闻媒体应当加强危险废物污染防治宣传教育和科学普及，推行绿色发展方式，倡导无废理念和简约适度、绿色低碳、文明健康的生活方式、消费模式。”

增加一款，作为第八条第二款：“鼓励基层群众性自治组织、社会组织、生态环境保护志愿者等开展生态环境法律法规和生态环境保护知识的宣传，营造保护生态环境、建设生态文明的良好风气。”原第二款改为第三款。

5.将第十四条修改为：“建设对生态环境有影响的产生、贮存、利用、处置危险废物的项目，应当依法进行生态环境影响评价。

“建设项目中的危险废物污染防治设施，应当与主体工程同时设计、同时施工、同时投产使用。危险废物污染防治设施应当符合经批准的生态环境影响报告书、生态环境影响报告表的要求，不得擅自拆除或者闲置。”

6.将第十八条修改为：“从事收集、贮存、利用、处置危险废物经营活动的单位（以下简称危险废物经营单位），应当按照国家规定取得许可证。

“禁止伪造、变造、转让许可证。

“禁止无许可证或者不按照许可证的要求从事危险废物收集、贮存、利用、处置的经营活动。

“禁止将危险废物提供或者委托给无许可证的单位和个人从事收集、贮存、利用、处置活动。”

7.将第二十一条第二款修改为：“禁止在运输途中倾倒、堆放、丢弃、抛撒、遗撒或者焚烧危险废物。”

8.将第三十二条修改为：“乡镇人民政府、街道办事处应当按照职责开展日常巡查，发现涉及危险废物问题的，及时向生态环境、公安等有关部门报告。”

9.将第三十六条修改为：“违反本条例第十八条第三款规定，企业事业单位无许可证从事收集、贮存、利用、处置危险废物经营活动的，由生态环境主管部门责令改正，没收违法所得，对收集、贮存危险废物经营活动并处二十万元以上一百万元以下的罚款，对利用、处置危险废物经营活动并处一百万元以上五百万元以下的罚款，报经有批准权的人民政府批准，责令停业、关闭；对法定代表人、主要负责人、直接负责的主管人员和其他直接责任人员，处十万元以上一百万元以下的罚款。

“企业事业单位未按照许可证规定从事收集、贮存、利用、处置危险废物经营活动的，由生态环境主管部门责令改正，没收违法所得，限制生产、停产整治，对收集、贮存危险废物经营活动并处十万元以上五十万元以下的罚款，对利用、处置危险废物经营活动并处五十万元以上二百万元以下的罚款；对法定代表人、主要负责人、直接负责的主管人员和其他直接责任人员，处五万元以上五十万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭，由发证机关吊销许可证。

“其他生产经营者有前两款违法情形的，由生态环境主管部门责令改正，没收违法所得，并处二万元以上十万元以下的罚款；情节严重的，并处十万元以上五十万元以下的罚款。”

10.将第三十七条修改为：“违反本条例第十八条第四款规定，将危险废物提供或者委托给无许可证的单位或者其他生产经营者从事相关活动的，由生态环境主管部门责令改正，没收违法所得，并处二十万元以上二百万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

11.删去第三十八条。

此外，根据机构改革职能调整情况对有关单位职责和名称进行调整，同时对相关条文顺序和个别文字作了修改。

本决定自2026年8月15日起施行。
