# 达州市人民代表大会常务委员会关于修改《达州市集中式饮用水水源保护管理条例》等四件地方性法规的决定

达州市人民代表大会常务委员会关于
修改《达州市集中式饮用水水源保护管理条例》
等四件地方性法规的决定

（2026年6月30日达州市第五届人民代表大会常务委员会第三十九次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

达州市第五届人民代表大会常务委员会第三十九次会议决定：

一、对《达州市集中式饮用水水源保护管理条例》作出修改

（一）将第一条修改为：“为了加强达州市集中式饮用水水源保护，保障饮用水安全，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《四川省饮用水水源保护管理条例》等法律、法规的规定，结合达州市实际，制定本条例。”

（二）将第十九条第八项修改为：“集中式地表水饮用水水源准保护区内，应当遵守下列规定：（八）禁止建设工业固体废物、建筑垃圾、危险废物集中贮存、利用、处置的设施、场所和生活垃圾填埋场。”

（三）将第三十六条修改为：“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（四）将第三十八条修改为：“违反本条例第十九条第八项规定的，由所在地生态环境主管部门责令停止违法行为，处十万元以上五十万元以下的罚款，并报经有批准权的人民政府批准，责令拆除或者关闭。”

（五）删除第四十条。

二、对《达州市莲花湖湿地保护条例》作出修改

（一）将第三条修改为：“莲花湖湿地保护应当坚持保护优先、严格管理、系统治理、科学修复、合理利用的原则。”

（二）将第九条修改为：“达州市人民政府林业主管部门应当会同有关部门编制莲花湖湿地保护规划，报达州市人民政府批准后组织实施。

“莲花湖湿地保护规划应当符合国土空间规划，并与水利和水土保持总体规划、生态环境保护规划、防洪规划等专项规划相衔接。

“经批准的莲花湖湿地保护规划应当严格执行；未经批准不得调整或者修改。

“保护范围内的各项建设应当符合莲花湖湿地保护规划。”

（三）将第十二条修改为：“保护范围内应当实施湿地保护修复工程，坚持自然恢复为主、自然恢复与人工修复相结合的方式，开展植被修复和水土治理，维持湿地生态系统健康，提升生态系统自我修复能力，统筹协调水资源平衡，维护湿地的生态用水需求。”

（四）将第二十四条修改为：“保护范围内从事经营、服务的单位和个人应当依法文明经营，不得擅自搭建经营设施、摆摊设点，不得擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物，排放废水废气。”

（五）删除第二十八条。

（六）将第三十二条修改为：“违反本条例第二十四条规定，擅自搭建经营设施、摆摊设点的，责令停止违法行为，限期拆除或者清理，恢复原状，有违法所得的，没收违法所得，情节严重或者造成严重后果的，并处个人五十元以上两百元以下的罚款，单位五百元以上二千元以下的罚款。”

三、对《达州市巴遗址遗迹保护条例》作出修改

（一）将第十四条第五项修改为：“擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物，排放污染物等。”

（二）删除第二十四条。

四、对《达州市市容和环境卫生管理条例》作出修改

（一）将第四十六条修改为：“清扫、收集、运输、处置生活垃圾应当遵守国家有关环境保护和环境卫生管理规定，防止污染环境。任何单位和个人不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（二）将第六十条修改为：“违反本条例第四十二条第二款规定的，由市容环境卫生主管部门责令改正，可以处五百元以上二千元以下罚款。”

（三）删除第六十一条。

本决定自2026年8月15日起施行。

《达州市集中式饮用水水源保护管理条例》、《达州市莲花湖湿地保护条例》、《达州市巴遗址遗迹保护条例》、《达州市市容和环境卫生管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
