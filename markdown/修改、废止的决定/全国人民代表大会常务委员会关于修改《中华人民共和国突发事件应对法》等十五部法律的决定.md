# 全国人民代表大会常务委员会关于修改《中华人民共和国突发事件应对法》等十五部法律的决定

全国人民代表大会常务委员会关于修改
《中华人民共和国突发事件应对法》
等十五部法律的决定

（2026年11月6日第十四届全国人民代表大会常务委员会第二十五次会议通过）

第十四届全国人民代表大会常务委员会第二十五次会议决定：

一、对《中华人民共和国突发事件应对法》作出修改

将第二十九条中的“县级以上人民政府有关部门”修改为“省级以上人民政府有关部门”。

二、对《中华人民共和国安全生产法》作出修改

将第八条第一款修改为：“国务院和县级以上地方各级人民政府应当将安全生产工作纳入国民经济和社会发展规划。”

三、对《中华人民共和国海岛保护法》作出修改

（一）将第十一条修改为：“沿海设区的市级人民政府有关部门可以根据实际需要组织编制海岛保护专项规划。

“编制前款规定的海岛保护专项规划，应当征求上一级人民政府海洋主管部门的意见。”

（二）将第十三条修改为：“修改海岛保护规划，应当依照本法第九条、第十条规定的审批程序报经批准。”

（三）将第四十六条中的“《中华人民共和国海洋环境保护法》”修改为“《中华人民共和国生态环境法典》”。

四、对《中华人民共和国职业病防治法》作出修改

将第十条第一款修改为：“国务院和省、自治区、直辖市人民政府应当制定职业健康保护规划并组织实施。”

五、对《中华人民共和国基本医疗卫生与健康促进法》作出修改

（一）将第二十三条第一款修改为：“国家加强职业健康保护。县级以上人民政府应当建立健全职业健康工作机制，加强职业健康监督管理，提高职业病综合防治能力和水平。”

（二）将第三十七条第一款修改为：“县级以上人民政府应当科学配置医疗卫生资源，举办医疗卫生机构，为公民获得基本医疗卫生服务提供保障。”

（三）将第四十条第一款修改为：“政府举办的医疗卫生机构应当坚持公益性质，所有收支均纳入预算管理，合理规划设置并控制规模。”

六、对《中华人民共和国野生动物保护法》作出修改

（一）将第五条第一款修改为：“国家保护野生动物及其栖息地。县级以上人民政府应当将野生动物及其栖息地保护纳入相关规划，并将野生动物保护经费纳入预算。”

（二）将第六十三条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

七、对《中华人民共和国森林法》作出修改

（一）将第二十五条修改为：“省级以上人民政府林业主管部门应当根据森林资源保护发展目标，编制林业发展规划。设区的市、县级人民政府林业主管部门可以根据实际需要编制林业发展规划。下级林业发展规划依据上级林业发展规划编制。”

（二）将第七十四条第三款中的“《中华人民共和国土壤污染防治法》”修改为“《中华人民共和国生态环境法典》”。

八、对《中华人民共和国草原法》作出修改

将第十七条第二款修改为：“县级以上地方人民政府草原行政主管部门可以根据实际需要，会同同级有关部门依据上一级草原保护、建设、利用规划编制本行政区域的草原保护、建设、利用规划，报本级人民政府批准后实施。”

九、对《中华人民共和国湿地保护法》作出修改

（一）将第二条第三款中的“《中华人民共和国水法》、《中华人民共和国防洪法》、《中华人民共和国水污染防治法》、《中华人民共和国海洋环境保护法》”修改为“《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国防洪法》”。

（二）将第十五条第二款修改为：“县级以上地方人民政府林业草原主管部门可以根据实际需要，会同有关部门依据本级国土空间规划和上一级湿地保护规划编制本行政区域内的湿地保护规划，报本级人民政府批准后组织实施。”

（三）删去第三十四条第一款。

（四）删去第三十五条第一款。

十、对《中华人民共和国防沙治沙法》作出修改

（一）将第十一条第二款、第三款合并，作为第二款，修改为：“县级以上地方人民政府可以根据实际需要，组织编制本行政区域的防沙治沙规划，报上一级人民政府或者其指定的部门批准后实施。”

（二）将第四十六条中的“《中华人民共和国森林法》《中华人民共和国草原法》《中华人民共和国水土保持法》《中华人民共和国土地管理法》《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》、《中华人民共和国森林法》、《中华人民共和国草原法》、《中华人民共和国水土保持法》、《中华人民共和国土地管理法》”。

十一、对《中华人民共和国水土保持法》作出修改

将第十四条第一款修改为：“县级以上人民政府水行政主管部门可以根据实际需要，会同同级人民政府有关部门编制水土保持规划，报本级人民政府或者其授权的部门批准后，由水行政主管部门组织实施。”

十二、对《中华人民共和国黑土地保护法》作出修改

将第十条第三款分为两款，作为第三款、第四款，修改为：“省级人民政府农业农村主管部门会同有关部门编制黑土地保护规划；设区的市、县级人民政府农业农村主管部门可以根据实际需要，会同有关部门编制黑土地保护规划。编制黑土地保护规划应当以调查和监测为基础、体现整体集中连片治理，与国土空间规划相衔接，明确黑土地保护范围、目标任务、技术模式、保障措施等，遏制黑土地退化趋势，提升黑土地质量，改善黑土地生态环境。

“县级人民政府应当将黑土地落实到具体地块，并向社会公布。”

十三、对《中华人民共和国动物防疫法》作出修改

将第八条第一款修改为：“县级以上人民政府对动物防疫工作实行统一领导，采取有效措施稳定基层机构队伍，加强动物防疫队伍建设，建立健全动物防疫体系，根据需要制定并组织实施动物疫病防治规划。”

十四、对《中华人民共和国环境保护税法》作出修改

将第二十三条中的“《中华人民共和国税收征收管理法》、《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》、《中华人民共和国税收征收管理法》”。

十五、对《中华人民共和国航道法》作出修改

将第四十四条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

本决定自公布之日起施行。

《中华人民共和国突发事件应对法》、《中华人民共和国安全生产法》、《中华人民共和国海岛保护法》、《中华人民共和国职业病防治法》、《中华人民共和国基本医疗卫生与健康促进法》、《中华人民共和国野生动物保护法》、《中华人民共和国森林法》、《中华人民共和国草原法》、《中华人民共和国湿地保护法》、《中华人民共和国防沙治沙法》、《中华人民共和国水土保持法》、《中华人民共和国黑土地保护法》、《中华人民共和国动物防疫法》、《中华人民共和国环境保护税法》、《中华人民共和国航道法》根据本决定作相应修改，重新公布。
