# 厦门市人民代表大会常务委员会关于修改《厦门经济特区水资源条例》等三部法规和废止《厦门大屿岛白鹭自然保护区管理办法》的决定

厦门市人民代表大会常务委员会
关于修改《厦门经济特区水资源条例》等三部
法规和废止《厦门大屿岛白鹭自然保护区管理
办法》的决定

（2026年8月27日厦门市第十六届人民代表大会常务委员会第三十八次会议通过）

厦门市第十六届人民代表大会常务委员会第三十八次会议决定：

一、对《厦门经济特区水资源条例》作出修改

（一）将第四条修改为：“水资源管理应当遵循全面规划、生态优先、统筹兼顾、标本兼治、综合利用、科学配置、讲求效益的原则。

“市、区人民政府应当将水资源保护、开发、利用、节约列入本级国民经济和社会发展规划。国土空间规划、重大建设项目布局和产业结构调整，应当与水资源条件和防洪要求相适应，并进行科学论证。”

（二）将第六条中的“河长”修改为“河湖长”。

（三）将第七条第一款修改为：“市水行政主管部门应当会同有关部门和区人民政府依法编制水资源相关规划。”

（四）删去第七条第二款、第八条、第十一条第一款、第二十八条、第二十九条第一款和第三款。

（五）将第十条改为第九条，“再生水”修改为“非常规水”。

（六）将第十三条改为第十二条，修改为：“市、区人民政府应当依法提出饮用水水源一级保护区和二级保护区划定方案，经省人民政府批准后在水源地醒目位置公告，并在饮用水水源保护区边界设置明确的地理界标和明显的警示标志。”

（七）将第二十九条改为第二十七条，第二款修改为：“中型水库、跨区引水、区域外调入水等水工程管理单位应当根据供水片区内用水单位的用水需求、行业用水水平、经济技术条件等预测本工程的年度用水量，按照有关规定报批，取得年度用水指标。”

（八）将第三十七条改为第三十五条，“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

二、对《厦门经济特区生活垃圾分类管理办法》作出修改

（一）将第十一条第一款修改为：“单位和个人应当按照规定的时间、地点，用符合要求的垃圾袋或者容器分类投放生活垃圾，不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（二）删去第四十四条、第五十条。

三、对《厦门经济特区机动车排气污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第十条第一款中的“检验合格标志”修改为“安全技术检验合格标志”。

（三）将第十条、第十一条、第十五条、第十八条第一款、第二十四条中的“检测”修改为“检验”。

（四）将第十一条中的“排气检测机构”和第十五条中的“从事机动车排气污染检测的机构”修改为“机动车排放检验机构”，第十八条第二款中的“综合性能检测机构”修改为“检验检测机构”，第十八条第二款、第二十四条第一款中的“排气检测机构”修改为“排放检验机构”。

（五）将第十四条中的“下列检测”修改为“下列检验”，“其他检测”修改为“其他检验”。

（六）将第二十二条修改为：“违反本条例规定，拒绝市生态环境主管部门对机动车进行排气污染监督抽测的，由市生态环境主管部门责令改正，并对机动车所有人或者使用人处以二百元以上二千元以下罚款。”

（七）将第二十三条修改为：“违反本条例规定，机动车驾驶人驾驶排放检验不合格的机动车上道路行驶的，由公安机关交通管理部门依法予以处罚。”

四、废止《厦门大屿岛白鹭自然保护区管理办法》

（1995年11月1日厦门市第十届人民代表大会常务委员会第十九次会议通过根据2017年10月31日厦门市第十五届人民代表大会常务委员会第七次会议《关于修改〈厦门大屿岛白鹭自然保护区管理办法〉的决定》修正）

本决定自公布之日起施行。

《厦门经济特区水资源条例》《厦门经济特区生活垃圾分类管理办法》《厦门经济特区机动车排气污染防治条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
