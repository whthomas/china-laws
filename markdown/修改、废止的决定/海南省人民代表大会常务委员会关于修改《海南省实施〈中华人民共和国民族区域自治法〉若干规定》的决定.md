# 海南省人民代表大会常务委员会关于修改《海南省实施〈中华人民共和国民族区域自治法〉若干规定》的决定

海南省人民代表大会常务委员会关于
修改《海南省实施〈中华人民共和国民族区域
自治法〉若干规定》的决定

（2026年7月29日海南省第七届人民代表大会常务委员会第二十五次会议通过）

海南省第七届人民代表大会常务委员会第二十五次会议决定对《海南省实施〈中华人民共和国民族区域自治法〉若干规定》作如下修改：

一、将第一条修改为：“为了帮助民族自治地方加快经济和社会发展，促进民族团结进步，铸牢中华民族共同体意识，根据《中华人民共和国民族区域自治法》和《国务院实施〈中华人民共和国民族区域自治法〉若干规定》等法律、法规的规定，结合本省实际，制定本规定。”

二、将第九条第三款修改为：“经省人民政府批准，对民族自治地方的企业依法减征或者免征应缴纳的企业所得税中属于地方分享的部分。”

三、将第十四条第二款修改为：“省人民政府教育主管部门按照国家考试招生制度改革要求，结合经济社会发展实际，制定和调整高等学校和中等职业技术学校招收少数民族考生的具体办法。本省已制定的其他关于少数民族考生的规定与本规定的要求不一致的，依照本规定执行。”

四、将第十五条第三款修改为：“省人民政府安排少数民族教育专项补助资金，依照规定对民族自治地方义务教育阶段的少数民族学生补助住宿费、生活费和交通费；对家庭经济困难的普通高中教育少数民族学生免除学费、住宿费和教材费，对生活费给予补助；实行免费中等职业教育，逐步提高补助标准；为考取高等学校的少数民族特困学生提供助学金。”

五、将第二十一条修改为：“省人民政府应当按照国家有关规定，健全民族自治地方资源开发和生态保护补偿的具体制度”。

六、对部分条文中的有关表述作以下修改：

（一）将第八条第一款、第二十条第二款中“国家扶贫开发工作重点自治县”修改为“民族自治地方的省级乡村振兴重点帮扶县”。

（二）将第八条第二款中“扶贫开发”修改为“乡村振兴”。

（三）将第十七条第一款中的“新型农村合作医疗”修改为“城乡居民基本医疗保险”。

（四）将第二十四条第二款中的“黎族苗族”修改为“民族”。

本决定自公布之日起施行。

《海南省实施〈中华人民共和国民族区域自治法〉若干规定》根据本决定作相应修改，重新公布。
