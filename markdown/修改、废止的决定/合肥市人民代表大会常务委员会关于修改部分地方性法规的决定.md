# 合肥市人民代表大会常务委员会关于修改部分地方性法规的决定

合肥市人民代表大会常务委员会关于
修改部分地方性法规的决定

（2026年6月25日合肥市第十七届人民代表大会常务委员会第三十六次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为了贯彻实施《中华人民共和国生态环境法典》，维护国家法制统一、尊严、权威，合肥市第十七届人民代表大会常务委员会第三十六次会议决定对《合肥市水环境保护条例》等六件地方性法规作出如下修改：

一、对《合肥市水环境保护条例》作出修改

（一）将第一条修改为：“为了保护和改善水环境，促进经济社会全面、协调、可持续发展，根据《中华人民共和国生态环境法典》等有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第五、九、十三、二十三、二十四、二十七、三十、三十四、三十八、三十九、四十、五十条中的环境保护行政主管部门统一修改为生态环境主管部门。

（三）删去第七条第二款。

（四）将第八条第二款修改为：“违反前款规定的，由市、县（市）区人民政府生态环境主管部门责令改正，处以十万元以上一百万元以下的罚款，可以责令限制生产、停产整治；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

（五）将第二十五条第二款修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当安装与市环境监测监控系统联网的污染源自动监控装置，并确保其正常运行，不得改动污染源自动监控装置的参数和监测数据、停用污染源自动监控装置。”

（六）将第二十六条第一款中的“环境保护行政主管部门”修改为“生态环境主管部门”，并删去第二十六条第二款。

（七）将第三十二条第一款修改为：“实行排污许可管理的企业事业单位和其他生产经营者，应当依法向生态环境主管部门申请排污许可证，未取得排污许可证的不得排放污染物”，并删去第三十二条第三款。

（八）删去第三十三条。

二、对《合肥市机动车和非道路移动机械排放污染防治条例》作出修改

（一）将第一条修改为：“为了防治机动车和非道路移动机械排放污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》等有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第六条修改为：“禁止生产、进口、销售不符合大气污染物排放标准的机动车和非道路移动机械及其发动机。”

（三）将第八条第一款修改为：“在用机动车、非道路移动机械及其发动机不得超过本市执行的标准排放大气污染物。”

（四）将第十二条第一款修改为：“本市在用重型柴油车和非道路移动机械的所有人、使用人，应当确保装载的污染控制装置、车载排放诊断系统、远程排放监控设备等装置的正常使用，不得破坏、拆除、停用、篡改、屏蔽、伪造污染控制装置。”

（五）将第十八条第一款修改为：“生态环境行政主管部门可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况进行监督抽测；在不影响正常通行的情况下，可以采取在线监控、摄像拍照、遥感监测、车载排放诊断系统检查等方式，对在道路上行驶的机动车的大气污染物排放状况进行监督抽测，公安机关交通管理部门予以配合。”

（六）将第二十五条修改为：“违反本条例第八条规定，在禁用区域使用高排放非道路移动机械的，由生态环境行政主管部门责令改正，并处以每辆五千元的罚款。”

三、对《合肥市大气污染防治条例》作出修改

（一）将第一条修改为：“为防治大气污染，保护和改善环境，保障人体健康，促进经济和社会的可持续发展，根据《中华人民共和国生态环境法典》等有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第四、五、六、八、十一、二十八、三十一条中的环境保护行政主管部门统一修改为生态环境主管部门，第二十六条中的工商行政管理、质量技术监督部门修改为市场监督管理部门。

（三）将第十条修改为：“企业事业单位和其他生产经营者违反法律法规规定排放大气污染物，造成或者可能造成严重大气污染，或者有关证据可能灭失或者被隐匿的，市、县（市）区人民政府生态环境主管部门和其他负有大气环境保护监督管理职责的部门，可以依法查封、扣押有关场所、船舶、设施、设备、工具、物品。”

（四）将第十二条修改为：“市人民政府可以划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。

“在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。

“县级以上人民政府应当合理规划能源发展布局，控制煤炭产能和消费总量。禁止进口、销售或者燃用不符合质量标准的煤炭，鼓励燃用优质煤炭。”

（五）将第十四条第二款修改为：“在集中供热管网覆盖地区，禁止新建、扩建分散燃煤供热锅炉；已建成的不能达标排放的燃煤供热锅炉，应当在市人民政府规定的期限内拆除。”

（六）将第十七条修改为：“在人口集中地区和其他依法需要特殊保护的区域内，禁止从事橡胶制品生产、经营性喷漆、制骨胶、制骨粉、屠宰、畜禽养殖、生物发酵等产生恶臭、有毒有害气体和粉尘的生产经营活动以及焚烧油毡、沥青、橡胶、塑料、皮革、垃圾或者其他可能产生大气污染的物品。

“禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

（七）在第十九条中增加一款作为第一款：“市、县（市）区人民政府及其有关部门应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。”

（八）将第二十条修改为：“加油站、储油库、原油成品油码头、原油成品油运输船舶和油罐车、铁路罐车等，应当按照国家规定安装油气回收装置并保持正常使用。”

（九）将第二十一条第一款和第二款修改为：“机动车船、非道路移动机械及其发动机不得超过标准排放大气污染物。

“禁止生产、进口或者销售不符合大气污染物排放标准的机动车船、非道路移动机械及其发动机。”

（十）将第二十三条修改为：“公安机关交通管理部门应当配合生态环境主管部门对行驶中的机动车污染物排放状况进行抽测。

“市、县（市）区生态环境主管部门可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车污染物排放状况进行抽测。

“在用机动车车主或者驾驶人应当配合公安机关交通管理部门、生态环境主管部门的监督抽测，不得拒绝、阻挠。”

（十一）将第二十五条修改为：“机动车、非道路移动机械的维修单位，应当按照国家有关技术标准进行维修。维修后机动车的污染物排放应当达到规定的标准。”

（十二）将第二十九条修改为：“违反本条例第十二条第二款规定，在禁燃区内的企业事业单位和其他生产经营者，未在规定的期限内停止使用高污染燃料的，由市、县（市）区人民政府生态环境主管部门没收燃用高污染燃料的设施、燃煤供热锅炉并组织拆除，处以二万元以上二十万元以下罚款。

“违反本条例第十二条第三款规定，进口、销售、燃用不符合质量标准的煤炭的，按照《中华人民共和国生态环境法典》等有关法律、法规的规定予以处罚。”

（十三）将第三十条修改为：“违反本条例第十七条第一款规定，在人口集中地区和其他依法需要特殊保护的区域内，从事橡胶制品生产、经营性喷漆、制骨粉、屠宰、畜禽养殖、生物发酵等产生恶臭、有毒有害气体和粉尘的生产经营活动，以及焚烧油毡、沥青、橡胶、塑料、皮革、垃圾或者其他产生有毒有害烟尘和恶臭气体物质的，由市、县（市）区人民政府确定的监督管理部门责令改正，对单位处以一万元以上十万元以下罚款，对个人处以五百元以上二千元以下罚款。

“违反本条例第十七条第二款规定，在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染物质的，由市、县（市）区人民政府生态环境主管部门或者其他依法行使监督管理权的部门责令改正，可以处以五百元以上二千元以下罚款。”

四、对《合肥市市容和环境卫生管理条例》作出修改

（一）将第三十条第二项修改为：“（二）在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧树枝落叶、冥纸等”，并删去第三十条第三项中的“垃圾”，增加一项作为第三十条第五项：“（五）法律、法规规定的其他禁止行为。”

（二）将第五十条第二款中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（三）将第五十二条中的“并可以按照下列规定处以罚款”修改为“可以按照下列规定处以罚款”，并将第五十二条第六项修改为：“（六）违反本条例第三十条第（一）项、第（二）项规定，在公共场所随地便溺、吐痰、乱扔皮壳、纸屑和烟蒂的，处以二十元的罚款；在禁止焚烧的区域和时段露天焚烧树枝落叶、冥纸等，产生烟尘污染物质的，处以五百元以上二千元以下的罚款；违反第（四）项规定，占用城市道路或者公共场所从事机动车辆清洗、维修经营活动，影响环境卫生的，处以二百元以上一千元以下的罚款。”

（四）将第五十三条第二项至第六项修改为：“（二）违反第三十条第（三）项规定，违反规定倾倒粪便、污水，按照有关法律、法规的规定予以处罚；

“（三）违反本条例第三十六条规定，运输垃圾、砂石、灰浆等散装、流体物料的车辆，未采取密闭或者其他措施防止物料遗撒的，处以二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶；

“（四）违反本条例第三十八条规定，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的，按照《中华人民共和国生态环境法典》等有关法律、法规的规定予以处罚；

“（五）违反本条例第三十九条规定，未按照规定收集、存放厨余垃圾并交城市生活垃圾收集、运输企业运至规定的城市生活垃圾处理场所的，按照《中华人民共和国生态环境法典》等有关法律、法规的规定予以处罚；

“（六）违反本条例第四十一条第一款规定，擅自处置或者超出核准范围处置建筑垃圾的，处以五千元以上三万元以下的罚款；违反第二款规定，建设单位或者施工单位将建筑垃圾交给未经核准从事建筑垃圾运输的单位运输的，处以一万元以上五万元以下的罚款；违反第三款规定，未按照规定的路线、时间、地点运输和倾倒建筑垃圾的，按照《中华人民共和国生态环境法典》等有关法律、法规的规定予以处罚。”

五、对《合肥市文明行为促进条例》作出修改

将第十一条第三项修改为“在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质”。

六、对《合肥市制止餐饮浪费行为条例》作出修改

将第二十五条修改为：“违反本条例第十五条规定，餐饮经营者未在显著位置张贴或者摆放节约食物、杜绝浪费的宣传画或者提示牌的，由市场监督管理部门责令改正，给予警告。”

此外，还对上述法规中个别文字、条文顺序作了相应调整。

本决定自2026年8月15日起施行。

《合肥市水环境保护条例》《合肥市机动车和非道路移动机械排放污染防治条例》《合肥市大气污染防治条例》《合肥市市容和环境卫生管理条例》《合肥市文明行为促进条例》《合肥市制止餐饮浪费行为条例》根据本决定作相应修改，重新公布。
