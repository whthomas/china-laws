# 亳州市人民代表大会常务委员会关于修改部分地方性法规的决定

亳州市人民代表大会常务委员会关于修改
部分地方性法规的决定

（2026年6月26日亳州市第五届人民代表大会常务委员会第四十三会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为贯彻落实全国人大、省人大关于生态环境法典涉及地方性法规集中清理的工作部署，理顺法规制度衔接关系，保证我市地方性法规与《中华人民共和国生态环境法典》协调一致，切实维护国家法治统一，亳州市第五届人民代表大会常务委员会第四十三次会议决定对《亳州市城市市容和环境卫生管理条例》、《亳州市城市绿化条例》、《亳州市文明行为促进条例》、《亳州市湿地保护条例》、《亳州市爱国卫生条例》作如下修改：

一、对《亳州市城市市容和环境卫生管理条例》作出修改

（一）将第一条修改为：“为了加强城市市容和环境卫生管理，创造整洁、优美、文明的城市环境，根据《中华人民共和国生态环境法典》、国务院《城市市容和环境卫生管理条例》和有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第三十三条第一款修改为：“宾馆、饭店、餐馆以及机关、院校等产生餐厨废弃物的单位，应当按照有关规定清扫、收集、运输、处理，不得随意倾倒、抛撒、堆放。”

（三）将第三十四条修改为：“运输垃圾、渣土、砂石以及液体、散装货物的车辆应当保持车体整洁，采取密闭、覆盖等有效措施，防止遗撒、泄漏，并按照规定路线行驶。”

（四）将第三十五条第三项修改为：“违反本条例第二十八条规定，随地吐痰，乱扔瓜果皮（核）、纸屑、烟蒂、包装物、口香糖等废弃物的，处二十元罚款；随地便溺的，处二十元以上五十元以下罚款；违反规定倾倒垃圾、粪便的，按照有关法律、法规的规定予以处罚；占用城市道路、街巷经营机动车辆修理、清洗业务，影响环境卫生的，处二百元以上一千元以下罚款。”

（五）将第三十八条修改为“违反本条例第三十四条规定，未采取密闭、覆盖等有效措施防止遗撒、泄漏的，或者未按照规定路线行驶的，由城市管理行政主管部门责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶；造成遗撒、泄漏的，责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上五十万元以下罚款。”

二、对《亳州市城市绿化条例》作出修改

（一）将第一条修改为：“为了促进城市绿化事业的发展，保护和改善城市生态环境，根据《中华人民共和国生态环境法典》、国务院《城市绿化条例》和有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“城市绿化应当坚持科学规划、因地制宜、生态优先、绿色发展、植护并重、全民参与的原则。”

三、对《亳州市文明行为促进条例》作出修改

（一）将第十一条第四项修改为“不违反规定露天焚烧秸秆、落叶、垃圾等产生烟尘污染的物质；”

（二）将第二十四条修改为“违反本条例规定，有占用、堵塞疏散通道、安全出口、消防车道和无障碍设施，随地吐痰、便溺，乱扔垃圾、倾倒污水，占用公共设施、公共区域，私搭乱建、私拉乱接管线，侵占、损毁公共绿地，从建筑物中抛掷物品等行为的，依照《中华人民共和国生态环境法典》、《中华人民共和国治安管理处罚法》、《中华人民共和国消防法》、《安徽省物业管理条例》、《亳州市城市市容和环境卫生管理条例》、《亳州市城市绿化条例》等法律、法规的规定处理。”

四、对《亳州市湿地保护条例》作出修改

（一）将第一条修改为：“为了加强湿地保护，维护湿地生态功能和生物多样性，改善生态环境，促进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国湿地保护法》和有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第八条第三款修改为：“除因防洪、航道、港口或者其他水工程占用河道管理范围及蓄滞洪区内的湿地外，经依法批准占用重要湿地的单位应当提交湿地保护与恢复方案，按照先补后占、占补平衡的原则，恢复或者重建与所占湿地面积和质量相当的湿地。”

（三）将第十一条第二项修改为：“（二）擅自填埋自然湿地，擅自采砂、采矿、取土；”

（四）删除第十六条第三款：“对破坏、污染湿地生态环境的行为，检察机关、法律规定的其他机关和符合条件的社会组织，可以依法提起环境公益诉讼。”

五、对《亳州市爱国卫生条例》作出修改

（一）将第一条修改为：“为了加强爱国卫生工作，提高公民健康水平，推进健康亳州建设，根据《中华人民共和国生态环境法典》、《中华人民共和国基本医疗卫生与健康促进法》和有关法律、行政法规，结合本市实际，制定本条例。”

（二）将第八条第三款修改为：“餐饮外卖行业应当减少包装物的使用，优先采用环保可降解的容器包装。餐饮外卖送餐人员应当保持个人卫生，外卖箱（包）定期进行清洗消毒。”

本决定自2026年8月15日起施行。

《亳州市城市市容和环境卫生管理条例》、《亳州市城市绿化条例》、《亳州市文明行为促进条例》、《亳州市湿地保护条例》、《亳州市爱国卫生条例》根据本决定作相应修改，重新公布。
