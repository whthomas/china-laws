# 无锡市人民代表大会常务委员会关于修改《无锡市水环境保护条例》等六件地方性法规的决定

无锡市人民代表大会常务委员会
关于修改《无锡市水环境保护条例》等六件
地方性法规的决定

（2026年6月26日无锡市第十七届人民代表大会常务委员会第三十九次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

无锡市第十七届人民代表大会常务委员会第三十九次会议决定：

一、对《无锡市水环境保护条例》作出修改

（一）将第一条修改为：“为了保护和改善水生态环境，保障饮用水安全，维护公众健康，推动绿色低碳发展，根据《中华人民共和国生态环境法典》、《中华人民共和国长江保护法》、《江苏省水污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条中的“科学规划、保护优先、预防为主、综合治理”修改为“预防为主、系统治理、生态优先、绿色发展”。

（三）将第四条第一款修改为：“市、县级市、区人民政府应当将水生态环境保护工作纳入国民经济和社会发展规划，加大水生态环境保护工作的财政投入；建立水生态环境保护工作协调联动机制，协调解决水生态环境保护工作中的重大事项；按照生态环境保护目标责任制和考核评价制度有关要求，将水生态环境保护目标完成情况纳入本级人民政府有关部门和下一级人民政府及其负责人考核评价的内容。”

（四）将第六条修改为：“全面实行河湖长制。

“市、县级市（区）、镇（街道）河湖长负责组织领导相应江河湖泊的水资源保护、水域岸线管理、水污染防治、水生态环境治理等工作。

“市、县级市、区人民政府应当在国家和省、市地表水控制断面建立健全水生态环境质量改善责任体系和以控制单元为基础的水生态环境管理机制。断面水生态环境质量改善责任落实情况纳入市、县级市（区）河湖长履职范围。”

（五）将第七条第三款修改为：“对在水生态环境保护工作中做出显著成绩的单位和个人，按照国家和省有关规定给予表彰、奖励。”

（六）将第九条修改为：“生态环境部门应当按照规定向社会公开水生态环境质量等信息。

“实行排污许可重点管理和其他法定的应当披露生态环境信息的企业事业单位和其他生产经营者，应当依法及时、真实、准确、完整披露本单位生态环境信息，接受生态环境部门核查和社会监督。”

（七）将第十条修改为：“各级人民政府应当坚持绿色发展，实施生态环境分区管控，严守生态保护红线、环境质量底线、资源利用上线，科学指导各类开发保护建设活动。禁止违反生态环境准入清单规定进行生产建设活动。”

（八）将第十三条修改为：“收集、贮存、运输、利用、处置危险废物的单位，应当按照规定投保环境污染责任强制保险。

“鼓励其他企业投保环境污染责任保险。”

（九）将第十四条第二款修改为：“排放水污染物，应当符合国家和地方规定的水污染物排放标准、重点水污染物排放总量控制指标、排污许可管理和有关法律、法规、规章的要求。”

（十）将第十六条中的“环境影响评价”修改为“生态环境影响评价”。

（十一）删去第十七条第一款中的“工业集聚区的管理机构”。

将第二款修改为：“鼓励实行排污许可重点管理的企业事业单位和其他生产经营者开展水平衡核算。”

（十二）删去第十八条。

（十三）将第二十一条改为第二十条，第二款修改为：“市、县级市、区人民政府应当对本行政区域的入河排污口组织开展排查整治，明确责任主体，实施分类管理。”

增加一款，作为第三款：“入河排污口的责任主体应当加强源头治理、排污通道巡查维护和入河排污口整治、规范化建设、维护管理等。”

（十四）将第二十三条改为第二十二条，第一款修改为：“市、县级市、区人民政府应当组织相关部门，依法编制本行政区域的城镇污水处理设施建设相关规划，并按照规划组织建设城镇污水集中处理设施及配套管网、污泥无害化处理处置等设施。”

（十五）将第二十四条改为第二十三条，第二款中的“排污单位”修改为“企业事业单位和其他生产经营者”。

（十六）将第二十五条改为第二十四条，第一款修改为：“高耗水行业和实行排污许可重点管理的企业事业单位和其他生产经营者应当采取措施加强污水处理回用。”

将第三款中的“单位”修改为“企业事业单位和其他生产经营者”。

（十七）将第二十八条改为第二十七条，删去第一款。

将第二款中的“如实进行环境管理台账记录”修改为“如实进行管理台账记录”。

（十八）将第三十一条改为第三十条，第一款中的“污泥安全处置设施”修改为“污泥无害化处理处置设施”。

删去第二款中的“或者”、“有关”。

将第三款中的“污水处理设施的运营单位或者污泥处理处置单位”修改为“污水处理设施的运营单位和污泥无害化处理处置单位”。

（十九）将第三十四条改为第三十三条，第一款中的“绿色生态肥料和高效、低毒、低残留农药”修改为“绿色生态肥料、高效低毒低残留农药和测土配方施肥技术”。

（二十）将第三十五条改为第三十四条，第一款中的“船舶向水体排放污染物应当符合船舶水污染物排放标准”修改为“船舶排放污染物应当符合船舶污染物排放标准”。

（二十一）将第三十八条改为第三十七条，修改为：“鼓励和支持用水单位实施节水改造，提高水资源利用效率。”

（二十二）将第四十三条改为第四十二条，修改为：“市、县级市、区人民政府应当组织制定饮用水安全突发事件应急预案。

“饮用水供水单位应当根据所在地饮用水安全突发事件应急预案，制定相应的突发事件应急预案，报所在地市、县级市人民政府备案，并定期进行演练。

“饮用水水源发生水污染事故，或者发生其他可能影响饮用水安全的突发性事件，饮用水供水单位应当采取应急处理措施，向所在地市、县级市、区人民政府报告，并向社会公开。有关人民政府应当根据实际情况及时启动应急预案，采取有效措施，保障供水安全。”

（二十三）将第四十四条改为第四十三条，修改为：“在地下水禁采区，除法律、法规规定的情形外，禁止任何单位和个人取用地下水。

“市、县级市、区人民政府应当组织有关部门开展地下水状况调查评价，包括地下水资源调查评价、地下水污染调查评价和水文地质勘查评价等，并采取相应风险防范措施，保障地下水资源安全。地下水状况调查评价结论应当依法向社会公开。”

（二十四）将第五十六条改为第五十五条，第一款中的“部门”修改为“部门和机构”。

（二十五）将第五十七条改为第五十六条，第二款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照排污许可证的要求和有关标准规范，依法对所排放的水污染物开展自行监测，建立管理台账，并保存原始监测记录和管理台账。原始监测记录和管理台账保存期限不得少于五年。”

（二十六）将第五十八条改为第五十七条，修改为：“负有水生态环境监督管理职责的部门有权依法对污染环境、破坏生态等的企业事业单位和其他生产经营者以及生态环境技术服务机构等进行现场检查。被检查者应当如实反映情况，提供必要的资料。实施现场检查的部门及其工作人员应当为被检查者保守商业秘密、个人隐私和个人信息。”

（二十七）将第五十九条改为第五十八条，其中的“应急准备、应急处置和事后恢复等工作”修改为“预防准备、监测预警、应急处置、调查评估和事后恢复等工作”。

（二十八）将第六十条改为第五十九条，删去其中的“约谈”。

（二十九）将第六十一条改为第六十条，修改为：“负有生态环境保护监督管理职责的部门应当依法将企业事业单位和其他生产经营者有关生态环境违法信息记入信用记录。

“企业事业单位和其他生产经营者纠正失信行为、消除不良影响、符合信用修复条件的，可以提出信用修复申请，有关部门应当按照规定开展信用修复。”

（三十）将第六十二条改为第六十一条，修改为：“人民检察院在履行职责中发现地方人民政府或者负有水生态环境保护监督管理职责的部门、机构违法行使职权或者不作为，给国家造成损失或者损害社会公共利益的，可以依法提起诉讼。”

（三十一）删去第六十五条。

（三十二）将第六十六条改为第六十四条，修改为：“违反本条例第五十六条第二款规定，实行排污许可管理的企业事业单位和其他生产经营者未对所排放的水污染物开展自行监测，或者未保存原始监测记录和管理台账的，由生态环境部门责令改正，处以二万元以上二十万元以下的罚款；拒不改正的，可以责令限制生产、停产整治。”

（三十三）将第六十七条改为第六十五条，删去第二款中的“单位和个人”，“损害结果发生地人民政府”修改为“市人民政府”，“造成环境污染和生态破坏的单位和个人”修改为“责任人”。

增加一款，作为第三款：“前款规定的市人民政府、部门、机构不进行磋商，或者磋商未达成一致且不提起诉讼的，人民检察院可以对责任人依法向人民法院提起诉讼。”

（三十四）将有关条款中的“环境”修改为“生态环境”，“企业事业单位”修改为“企业事业单位和其他生产经营者”，“维护运营单位”修改为“运营单位”。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

二、对《无锡市禁止燃放烟花爆竹条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第六条修改为：“生产、储存、经营、运输烟花爆竹的单位和个人，应当遵守国家和省、市有关烟花爆竹安全管理的规定。”

三、对《无锡市排水管理条例》作出修改

（一）将第八条第二款修改为：“对在排水工作中做出突出贡献的单位和个人，按照国家和省有关规定给予表彰、奖励。”

（二）将第二十二条第四项中的“列入重点排污单位名录的排水户”修改为“实行排污许可重点管理的排水户”。

（三）将第二十六条修改为：“根据排水户排放水质、水量等情况，排水户分为实行排污许可重点管理的排水户和其他排水户。

“排水行政主管部门会同生态环境行政主管部门依法确定并向社会公布实行排污许可重点管理的排水户的名录。”

（四）删去第二十八条。

（五）将第三十一条改为第三十条，第一款中的“列入重点排污单位名录的排水户”修改为“实行排污许可重点管理的排水户”。

将第二款修改为：“排水户安装的水质自动监控装置所测数据，由排水行政主管部门依法审核后，可以作为监管执法工作的事实依据。”

（六）将第三十八条改为第三十七条，第一款修改为：“建设工程施工范围内有排水管网等排水设施的，建设单位应当在施工前与施工单位、排水设施运行维护单位共同制定保护方案，并征求排水管理机构的意见，采取相应的安全保护措施。”

（七）将第四十六条改为第四十四条，修改为：“对违反本条例规定的行为，法律、法规已有处罚规定的，从其规定。”

此外，对条文顺序作相应调整。

四、对《无锡市市容和环境卫生管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三十三条第一款中的“任何单位和个人不得随意倾倒、抛撒、堆放”修改为“任何单位和个人不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧”。

（三）将第五十三条第三项修改为：“停车设施，是指用于机动车停放的场所，包括公共停车设施和专用停车设施。其中公共停车设施，是指向社会开放、为不特定对象提供停车服务的机动车停放场所，包括独立建设的公共停车场、配套建设的公共停车场、占用其他公共场地设置的临时停车设施和占用城市道路设置的机动车停车泊位；专用停车设施，是指供本单位、本居住小区机动车停放的场所”。

五、对《无锡市生活垃圾分类管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二条第二款修改为：“本条例所称生活垃圾，是指在日常生活中或者为日常生活提供服务的活动中产生的固体废物，以及法律、行政法规规定视为生活垃圾的固体废物。”

（三）将第三条中的“政府主导、全民参与、城乡统筹、属地管理的原则”修改为“政府推动、全民参与、城乡统筹、属地管理、因地制宜、简便易行的原则”。

（四）删去第五条第一款。

（五）将第十四条修改为：“生活垃圾分类收集、转运、处理设施、场所建设应当符合有关生态环境保护和环境卫生标准，采取密闭、渗沥液处理、防臭、防渗等污染防控措施。

“建设生活垃圾转运、处理设施、场所，应当依法进行生态环境影响评价，确定生态环境保护措施；生态环境影响评价文件报批前，建设单位应当征求社会公众意见，并公示生态环境影响评价结论。”

（六）将第十七条第一款修改为：“生活垃圾分类收集容器按照以下要求设置：

“（一）集中供餐单位、宾馆、饭店和集贸市场、农产品批发市场等设置有害垃圾、可回收物、厨余垃圾、其他垃圾收集容器；

“（二）居民区、农村居民点、非集中供餐单位设置有害垃圾、可回收物、厨余和其他垃圾收集容器，有条件的按照有害垃圾、可回收物、厨余垃圾、其他垃圾设置收集容器；

“（三）广场、道路等开放型公共场所设置可回收物、其他垃圾两类或者两类以上收集容器；

“（四）港口、码头应当设置分类收集容器，接收各类船舶生活垃圾。”

（七）将第十九条修改为：“产生生活垃圾的单位、家庭和个人是生活垃圾分类投放的责任主体，应当减少生活垃圾的产生，履行生活垃圾源头减量和分类投放义务。

“任何单位和个人都应当依法在指定的地点分类投放生活垃圾。禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（八）在第二十条第三款第二项中增加“没有经营管理单位的，由经营者负责”，将第四项修改为：“建设工程的施工现场，施工单位为责任人；尚未开工的，建设单位为责任人”。

在第四款中的“确定责任人”后增加“并公布”。

（九）将第二十一条修改为：“生活垃圾分类投放管理责任人应当履行下列责任：

“（一）建立生活垃圾分类日常管理制度，公示生活垃圾的投放地点、投放方式、投放时间等；

“（二）在责任范围内开展生活垃圾分类宣传；

“（三）按照有关规定设置生活垃圾分类收集点和收集容器；

“（四）指导、监督责任区内的单位和个人进行生活垃圾分类投放；

“（五）将分类投放的生活垃圾交由符合规定条件的生活垃圾收集、运输单位收集、运输；

“（六）对不按照分类规定投放生活垃圾，或者混合收集、运输已分类的生活垃圾的单位和个人，予以劝导，并督促改正；拒不改正的，及时向所在地镇人民政府（街道办事处）或者环境卫生行政管理部门报告。”

（十）将第二十四条第二款修改为：“可回收物和有害垃圾应当定期收集；厨余垃圾和其他垃圾应当每天定时定点收集。”

（十一）将第五章章名修改为“分类处理”。

（十二）将第四十条修改为：“产品的生产者、销售者和有关服务者应当严格执行国家、省、市对限制产品过度包装的标准和要求，减少包装性废物的产生；对列入国家强制回收名录的产品和包装物按照国家有关规定进行回收。”

（十三）将第六十条改为第五十五条，修改为：“对违反本条例规定的行为，法律、法规已有处罚规定的，从其规定。”

（十四）将第五十五条改为第五十六条，修改为：“违反本条例第十九条第二款规定，未按照规定要求分类投放生活垃圾的，由环境卫生行政管理部门责令改正；拒不改正的，对单位处以五万元以上五十万元以下罚款，对个人处以二十元以上二百元以下罚款。”

（十五）将第五十六条改为第五十七条，修改为：“违反本条例第二十一条规定，有下列情形之一的，由环境卫生行政管理部门责令限期改正；逾期未改正的，按照下列规定进行处罚：

“（一）违反第三项规定，生活垃圾分类投放管理责任人未按照有关规定设置生活垃圾分类收集点和收集容器的，处以一千元以上一万元以下罚款；

“（二）违反第五项规定，生活垃圾分类投放管理责任人未将分类投放的生活垃圾交由符合规定条件的生活垃圾收集、运输单位收集、运输的，处以二千元以上二万元以下罚款。”

（十六）将第五十七条改为第五十八条，修改为：“违反本条例第二十四条、第二十五条规定，将已经分类的生活垃圾混合收集、运输的，由环境卫生行政管理部门责令改正，处以五千元以上五万元以下罚款。”

（十七）将第六十二条第三项修改为：“厨余垃圾，包括家庭厨余垃圾、餐厨垃圾（餐厨废弃物）以及农贸市场、果品批发市场等产生的其他厨余垃圾”。

（十八）将第十一条第二款、第十二条、第十五条中的“设施”修改为“设施、场所”，有关条款中的“处置”修改为“处理”，“物业服务企业”修改为“物业服务人”，“城市总体规划和土地利用总体规划”修改为“国土空间总体规划”，“易腐垃圾”修改为“厨余垃圾”。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

六、对《无锡市建筑垃圾管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第十四条第一款修改为：“建设单位应当明确建筑垃圾源头减量目标和措施，按照规定将建筑垃圾污染防治费用列入工程造价，在施工合同中明确工程施工单位的建筑垃圾污染防治责任。”

（三）将第二十四条中的“不得沿途倾倒、泄漏、遗撒建筑垃圾”修改为“不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾”。

（四）将第三十八条第三款修改为：“接受举报的部门应当及时处理并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。”

（五）将第四十一条中的“对直接负责的主管人员和其他直接责任人员依法给予处分”修改为“对负有责任的领导人员和直接责任人员依法给予处分”。

本决定自2026年8月15日起施行。

《无锡市水环境保护条例》、《无锡市禁止燃放烟花爆竹条例》、《无锡市排水管理条例》、《无锡市市容和环境卫生管理条例》、《无锡市生活垃圾分类管理条例》、《无锡市建筑垃圾管理条例》根据本决定作相应修改，重新公布。
