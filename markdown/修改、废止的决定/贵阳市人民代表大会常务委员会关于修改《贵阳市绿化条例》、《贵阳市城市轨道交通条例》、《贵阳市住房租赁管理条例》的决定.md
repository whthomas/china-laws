# 贵阳市人民代表大会常务委员会关于修改《贵阳市绿化条例》、《贵阳市城市轨道交通条例》、《贵阳市住房租赁管理条例》的决定

贵阳市人民代表大会常务委员会
关于修改《贵阳市绿化条例》、《贵阳市
城市轨道交通条例》、《贵阳市住房租赁
管理条例》的决定

（2026年8月27日贵阳市第十五届人民代表大会常务委员会第三十七次会议通过　2026年9月23日贵州省第十四届人民代表大会常务委员会第二十六次会议批准）

贵阳市第十五届人民代表大会常务委员会第三十七次会议决定：

一、对《贵阳市绿化条例》作出修改

（一）将第八条第一款修改为：“县级以上人民政府根据实际需要，可以组织编制生态林业发展规划、绿地系统规划、山体保护利用规划等绿化专项规划”。

（二）将第十五条第一款第一项修改为：“（一）居住区不低于30%”；增加一项作为第二项：“（二）城市道路红线宽度大于45米的不低于30%，红线宽度大于30米小于等于45米的不低于25%，红线宽度大于15米小于等于30米的不低于20%，红线宽度小于等于15米的因地制宜，合理实施”；在第二项“疗养院”后增加“广场”；删除第三项中的“工业企业、仓储”；在第四项中增加“工业企业、仓储按照国家有关标准规范执行”；将第二款修改为：“除前款第五项外，属于棚户区、城中村等城市旧区改造的，前款规定比例可以适当降低，但降低幅度不得超过5%”。

（三）新增一款作为第二十条第四款：“公共建筑建设项目实施立体绿化建设的，可以按照国家和省有关立体绿化技术规范折算绿地面积，具体规定由市人民政府制定”。

（四）将第二十二条第一项修改为：“（一）居住区内属于业主共有的绿地，实行物业管理的，由物业服务人依照物业服务合同的约定保护管理”；删除第二项；删除第三项中的“和门前三包责任制”。

（五）将第二十三条第二款修改为：“管护责任主体应当建立管护制度，落实管护责任人，设置管护责任标牌，加强巡山护林。公共区域的绿地管护责任主体应当按照园林绿化有关技术标准进行管护”。

（六）删除第三十三条第二项。

（七）将第三十四条修改为：“违反本条例第二十五条第一款规定的，由综合行政执法部门责令限期退还、恢复原状，可以并处每日每平方米30元以上100元以下的罚款，造成损失的，应当负赔偿责任”。

二、对《贵阳市城市轨道交通条例》作出修改

（一）将第三条第一款修改为：“本条例所称城市轨道交通，是指地铁、轻轨等采用专用轨道导向运行的公共客运系统”。

（二）将第五条第三款中的“综合行政执法（城市管理）、园林绿化”修改为“综合行政执法（城市管理、园林绿化）”。

（三）将第十条中的“城市综合交通规划和环境保护规划”修改为“城市综合交通体系规划和生态环境保护规划”。

（四）将第二十条中的“控制保护区”修改为“线路安全控制保护区”，“重点保护区”修改为“线路安全重点保护区”；将第二款第三项修改为：“（三）出入口、通道、通风亭、消防水池、无障碍电梯、车辆基地、控制中心、变电站、冷却塔等建（构）筑物结构外边线外侧10米内”；将第三款第三项修改为：“（三）出入口、通道、通风亭、消防水池、无障碍电梯、车辆基地、控制中心、变电站、冷却塔等建（构）筑物结构外边线外侧5米内”；增加一款作为第五款：“城市轨道交通经营单位可以在城市轨道交通线路安全控制保护区设置边界标志和安全警示标志，控制保护区内物业的所有权人、使用权人应当予以配合”。

（五）将第二十一条第一款修改为：“城市轨道交通线路安全重点保护区内除必需的接驳通道和市政、水利、园林、环卫、人防等工程外，不得进行其他建设活动”；将第二款中的“控制保护区”修改为“线路安全控制保护区”；删除第三款。

（六）在第二十一条之后增加一条作为第二十二条：“在城市轨道交通线路安全控制保护区内，按照相关技术规范实施对城市轨道交通安全有重大影响作业的，作业单位或者个人，应当采取下列措施：

“（一）委托有资质的第三方机构对作业影响的城市轨道交通区域进行安全评估，并将安全评估结果报给城市轨道交通经营单位；

“（二）在施工前与城市轨道交通经营单位签订安全生产管理协议，并委托具备监测资质的第三方机构对作业影响区域的城市轨道交通区域进行动态监测和安全监控。”

（七）将第二十二条中的“控制保护区”修改为“线路安全控制保护区”；在“危及”后增加“或者可能危及”；“有权要求停止施工作业、采取补救措施”修改为“应当要求作业单位停止施工作业、采取补救措施消除隐患”。

（八）将第二十四条第一款第一项修改为：“（一）擅自进入列车驾驶室、控制中心、车辆基地、轨道、隧道或者其他禁止非工作人员进入的区域”；将第二项修改为：“（二）在车站、车厢和其他与城市轨道交通运行相关的区域携带国家管制的器具，携入或者放置易燃、易爆、有毒和放射性、腐蚀性以及其他可能危及人身和财产安全的危险物品”；在第七项“擅自移动”前增加“故意损坏或者”；增加一项作为第十三项：“（十三）在城市轨道交通地面线路或者高架桥线路轨道两侧各100米范围内升放风筝、气球等低空飘浮物体和无人机等低空飞行器”。

（九）将第三十一条第一款修改为：“城市轨道交通票价依法实行政府定价。城市轨道交通经营单位应当执行政府确定的票价和票价相关政策，不得擅自调整”；增加一款作为第二款：“市人民政府应当统筹考虑企业运营成本、社会承受能力、交通供求状况等因素，建立票价动态调整机制并依法履行定价成本监审等程序”。

（十）增加一款作为第三十二条第三款：“市公安机关、交通主管部门制定并公告乘客限带物品目录，由城市轨道交通经营单位在显著位置公示”。

（十一）将第三十三条第二款中的“乘客乘车应当持有效车票，并接受票务稽查。不得无票、持无效车票或者采取其他逃票方式乘车”修改为“乘客乘车应当持有效乘车凭证，并接受票务稽查。不得无乘车凭证，使用无效、伪造、变造的乘车凭证，冒用他人优惠乘车凭证或者采取其他逃票方式乘车”；将第三款修改为：“乘客无乘车凭证，使用无效、伪造、变造的乘车凭证，冒用他人优惠乘车凭证或者采取其他逃票方式乘车三次以上的，逃票信息可以纳入个人信用信息系统”。

（十二）将第三十四条第一款第一项中的“擅自”调整到“停放车辆”之前；将第二项修改为：“（二）在车站、车厢或者其他设施内吸烟（含电子烟）、随地吐痰、便溺、乱吐口香糖、乱扔果皮、纸屑等废弃物，躺卧或踩踏座席”；在第四项中的“电视剧拍摄”后增加“歌舞表演、推销产品及从事营销活动”；将第七项中的“饮食”修改为“进食”；将第八项修改为：“（八）在车厢内大声喧哗、使用电子设备时外放声音”；将第十项修改为：“（十）携带宠物、家禽等动物，有严重异味、刺激性气味的物品进站、乘车，盲人携带导盲犬除外”；删除第十一项中的“电动平衡车”；将第十二项修改为：“（十二）携带电动代步工具、自行车进站、乘车，无障碍用途的电动轮椅和妥善包装且符合携带行李规定的自行车除外”。

（十三）将第四十三条第一款修改为：“城市轨道交通经营单位负责编制本单位城市轨道交通应急预案，报市交通主管部门、应急管理部门、消防救援机构审定备案，并定期组织演练”。

（十四）删除第四十七条中的“违反本条例第二十二条规定”表述；将“控制保护区”修改为“线路安全控制保护区”。

（十五）将第四十八条第一款修改为：“违反本条例第二十五条第一款第一项至第十项、第十三项、第十四项规定之一的，由城市轨道交通经营单位对行为人进行劝阻和制止，并由公安机关等有关部门依法给予处罚”；删除第二款；将第三款“对单位可处以5000元以上5万元以下罚款”修改为“对单位可处以5000元以上3万元以下罚款”。

（十六）将第五十一条中的“乘客无票、持无效车票或者采取其他逃票方式乘车的”修改为“乘客无乘车凭证，使用无效、伪造、变造的乘车凭证，冒用他人优惠乘车凭证或者采取其他逃票方式乘车的”。

（十七）将第五十五条修改为：“违反本条例规定的其他行为，法律、法规有处罚规定的，从其规定”。

三、对《贵阳市住房租赁管理条例》作出修改

（一）将第十一条修改为：“出租人和承租人应当使用实名依法签订住房租赁合同。鼓励租赁当事人使用住房租赁合同示范文本”。

（二）将第十六条第一款修改为：“从事住房租赁业务的房地产经纪机构（以下简称住房租赁经纪机构）、住房租赁企业应当自领取营业执照之日起三十日内，通过住房租赁管理服务平台或者到所在地县级人民政府住房城乡建设主管部门报送开业信息”；将第二款修改为：“报送的开业信息变更的，应当自变更之日起三十日内报送变更信息”。

（三）将第十七条修改为：“自然人转租他人住房开展住房租赁经营业务，经营规模达到国家有关部门规定标准的，适用有关法律、法规的规定”。

（四）在第十八条“经营场所”后增加“醒目位置”；将“营业执照、备案证明文件、服务内容和标准、收费事项和标准、办公地址、从业人员信息、投诉受理电话等内容”修改为“本企业开业信息、服务规范和标准等”。

（五）将第二十一条第二款修改为：“出租人和承租人通过住房租赁经纪机构签订住房租赁合同的，由住房租赁经纪机构办理住房租赁合同备案”；增加一款作为第三款“住房租赁经纪机构应当推荐租赁双方使用住房租赁合同示范文本”。

（六）删除第二十三条。

（七）将第二十四条增加一款作为第三款“对已租赁的房源，发布主体应当自租赁合同签订之日起三个工作日内将房源信息从发布渠道上撤除；互联网信息服务平台经营者应当定期核查并提醒发布主体撤除”。

（八）将第二十六条中的“未备案”修改为“未报送开业信息”。

（九）将第二十九条第二款修改为：“市人民政府住房城乡建设主管部门应当将住房租赁经纪机构及其分支机构的开业信息及经纪人员名单备案信息向社会公示”。

（十）删除第三十一条中的“住房城乡建设主管部门”；将“制度”修改为“机制”。

（十一）将第三十四条修改为：“违反本条例第八条、第九条规定，有下列情形之一的，由综合行政执法部门责令限期改正，给予警告；逾期不改正的，对单位处二万元以上十万元以下罚款，对个人处二千元以上一万元以下罚款；有违法所得的，没收违法所得：

“（一）不以原规划设计的房间为最小出租单位，打隔断改变房屋内部结构；

“（二）原规划设计为客厅、餐厅、厨房、卫生间、阳台、过厅、过道、储藏室、车库、地下室、半地下室等非居住空间，单独出租用于居住；

“（三）每间房间人均建筑面积不符合本条例规定。”

（十二）删除第三十五条。

（十三）将第三十六条修改为：“违反本条例第十二条第一款、第十六条第一款、第十八条、第二十一条第二款规定，住房租赁企业、住房租赁经纪机构有下列情形之一的，由综合行政执法部门责令限期改正，给予警告；逾期不改正的，处二万元以上十万元以下罚款：

“（一）未按照规定报送开业信息；

“（二）未在其经营场所醒目位置或者网络服务平台如实公示本企业开业信息、服务规范和标准等；

“（三）未按照规定办理住房租赁合同备案。”

（十四）新增一条作为第三十五条：“违反本条例第十六条第二款，第十九条第二款规定，有下列情形之一的，由综合行政执法部门责令改正；逾期不改正的，处一千元以上一万元以下的罚款：

“（一）未按照规定报送变更信息的；

“（二）未办理执业信息卡的。”

（十五）删除第三十七条。

（十六）删除第四十条。

本决定自2026年10月1日起施行。

《贵阳市绿化条例》、《贵阳市城市轨道交通条例》、《贵阳市住房租赁管理条例》根据上述决定内容作相应修改，并且按照立法技术规范对部分文字作技术处理，涉及到条文顺序变化的作相应调整，重新公布。
