# 山西省人民代表大会常务委员会关于修改《山西省开发区条例》的决定

山西省人民代表大会常务委员会
关于修改《山西省开发区条例》的决定

（2026年9月24日山西省第十四届人民代表大会常务委员会第三十次会议通过）

山西省第十四届人民代表大会常务委员会第三十次会议决定对《山西省开发区条例》作如下修改：

一、将第三条修改为：“开发区工作坚持中国共产党的领导，牢固树立和践行正确政绩观，完整准确全面贯彻新发展理念，坚持改革创新、开放合作、规划引领、集聚集约、绿色低碳、特色发展的原则，因地制宜发展新质生产力，优化提升传统产业，培育壮大新兴产业，前瞻布局和发展未来产业。”

二、将第四条和第十三条合并，作为第四条，修改为：“省人民政府应当加强对开发区工作的领导，制定促进开发区发展的政策措施，解决有关重大问题；制定开发区综合发展水平考核评价办法，加强考核结果运用，落实退出机制。

“设区的市、县（市、区）人民政府应当将开发区的建设和发展纳入国民经济和社会发展规划，制定促进开发区改革创新发展的具体措施，落实目标责任和奖惩制度，推进开发区健康发展。”

三、将第五条第三款修改为：“县级以上人民政府发展改革、科学技术、工业和信息化、财政、人力资源和社会保障、自然资源、生态环境、住房和城乡建设、交通运输、水利、农业农村、文化和旅游、应急管理、外事、国有资产监督管理、市场监督管理、统计、行政审批服务管理、能源、文物、林业和草原以及其他相关部门，按照各自职责做好开发区相关工作。”

四、删去第六条第二款。

五、删去第七条。

六、将第八条改为第七条，删去第一款中“依据开发区用地和建设规划”的表述。

将第二款修改为：“县级以上人民政府应当建立健全开发区用地保障机制，健全节约集约用地制度，提高亩均效益，将开发区重大基础设施和公共服务设施用地纳入国土空间规划，支持开发区合理用地，统筹保障开发区重点项目建设用地。”

增加一款，作为第三款：“县级以上人民政府、开发区管理机构应当建立健全存量用地盘活机制，依法分类处置开发区批而未供、闲置土地和低效用地。”

七、将第十二条改为第十一条，修改为：“开发区更改名称、变更类型、调整区域、扩大区域或者撤销开发区的，由设区的市人民政府提出申请，按照设立程序办理。”

八、将第十四条改为第十二条，第二款修改为：“开发区管理机构应当按照优化协同高效的原则，科学合理设置内设机构。”

九、将第十五条改为第十三条，第二款修改为：“开发区所在地县级以上人民政府应当对授权事项实行目录管理、动态调整，向本级人民代表大会常务委员会备案，并向社会公布。”

十、将第十六条改为第十四条，修改为：“开发区管理机构履行下列职责：

“（一）依法制定和实施开发区各项管理制度和政策措施；

“（二）受所在地设区的市人民政府委托，向省人民政府申报农用地转用和土地征收；经所在地设区的市、县（市、区）人民政府同意，办理土地出让（划拨）、收回、处置事项；

“（三）统筹产业布局和开发建设，按照规定权限、程序负责企业投资项目的核准、备案；

“（四）依法制定招商引资政策，健全招商引资机制，开展招商引资工作；

“（五）依法组织编制开发区规划环境影响报告书；

“（六）节约集约利用资源，盘活闲置资产，并按照国家和省有关规定，协调落实开发区内基础设施和公共服务设施的建设和管理；

“（七）协助县级以上人民政府有关部门或者按照授权依法做好安全生产、生态环境保护等相关工作；

“（八）所在地县级以上人民政府依法赋予的其他职责。”

十一、将第十七条改为第十五条，修改为：“开发区管理机构应当按照国家和省有关规定，制定并公布权力清单、责任清单。”

十二、将第十八条改为第十六条，修改为：“县级以上人民政府应当明确开发区与行政区的关系，坚持开发区发展经济为主的功能定位，推动具备条件的开发区管理机构剥离社会事务管理职能，剥离的社会事务管理职能由所在地人民政府依法承担；对暂未剥离的社会事务管理职能，应当编制清单并向社会公布。”

十三、将第十九条改为第十七条，第二款修改为：“设区的市、县（市、区）人民政府应当与开发区建立合理的投入和收益分配制度，支持和促进开发区可持续发展。”

增加一款，作为第三款：“县级以上人民政府应当建立健全开发区资产、负债登记管理制度，加强对开发区管理机构以及运营公司举债、融资的约束和监督，防范化解债务风险。”

十四、删去第二十一条、第二十二条。

十五、将第二十五条改为第二十一条，删去第一款中“省或者设区的市机构编制部门”的表述。

删去第二款。

将第三款修改为：“按照规定程序采取市场化方式选聘的开发区高级管理、技术人员，实行合同管理。”

十六、增加一条，作为第二十三条：“省、设区的市人民政府应当加强对开发区产业发展的统筹指导，根据各地资源禀赋、产业基础和区位条件等特点，因地制宜确定各开发区主导产业，推动开发区产业特色化、差异化发展。

“开发区应当聚焦发展规划目标，围绕主导产业定位，引进和培育关联度大、带动力强的龙头企业，吸引上下游企业集聚，延长、补齐、做强重点产业链，推动产业集聚发展。”

十七、将第二十九条第一款改为第二十六条，修改为：“县级以上人民政府应当支持开发区加快发展先进制造业和现代服务业，重点发展科技服务、现代物流、现代金融、商务服务等生产性服务业，推动现代服务业与先进制造业融合发展。支持开发区加强新型基础设施建设，推动产业数字化、智能化发展，促进数字经济与实体经济深度融合。”

删去第二款。

十八、将第三十条改为第二十七条，增加一款，作为第一款：“县级以上人民政府应当支持开发区依法开展招商引资，规范开发区招商引资行为。”

十九、将第三十二条改为第二十九条，第二款修改为：“鼓励开发区探索制度型开放，健全外商投资管理服务体系，引进高技术、高附加值外资项目和外资功能性机构，加快培育壮大外向型经营主体，发展外贸新业态新模式。”

增加一款，作为第三款：“支持有条件的开发区建设国际合作产业园区，用好综合保税区、跨境电子商务综合试验区等对外开放平台。”

二十、将第三十四条改为第三十一条第一款，修改为：“开发区应当培育和引进高新技术企业、科技型中小企业等创新主体，引导企业加大研发投入，与高等院校、科研机构建立长期合作机制，加强企业主导的产学研深度融合，推动科技成果转化。”

增加一款，作为第二款：“支持有条件的开发区建设重点实验室、工程研究中心、技术创新中心等国家级和省级科技创新平台。”

二十一、增加一条，作为第三十四条：“县级以上人民政府应当支持开发区建设配套服务设施，为开发区从业人员提供便利生活环境。”

二十二、将第三十七条改为第三十五条，修改为：“县级以上人民政府、开发区管理机构应当畅通政企联系渠道，及时听取经营主体的反映和诉求，依法协调解决困难和问题，并反馈结果。

“开发区应当建立健全投诉协调机制，受理并及时处理企业和投资者对各类违法、违规行为的投诉和举报。”

二十三、将第四十条改为第三十八条，修改为：“本省行政区域内经国务院或者省人民政府批准设立的农业高新技术产业示范区、生态文化旅游示范区、现代农业产业示范区等，参照本条例执行。”

本决定自公布之日起施行。

《山西省开发区条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
