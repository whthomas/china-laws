# 荆门市人民代表大会常务委员会关于集中修改、废止涉及生态环境法典地方性法规的决定

荆门市人民代表大会常务委员会关于
集中修改、废止涉及生态环境法典
地方性法规的决定

（2026年6月30日荆门市第十届人民代表大会常务委员会第三十五次会议通过　2026年7月30日湖北省第十四届人民代表大会常务委员会第二十五次会议批准）

荆门市第十届人民代表大会常务委员会第三十五次会议决定：

一、对《荆门市城市管理条例》作出修改

（一）将第三十一条第二款中的“取得住房和城乡建设主管部门的证明”修改为“依法取得住房和城乡建设主管部门出具的连续施工作业证明”。

（二）将第三十三条第三款中的“区域”修改为“时段和区域”。

（三）将第四十六条第一款中的“环境噪声”修改为“噪声”；删去第二款。

（四）删去第五十八条。

（五）将第六十六条改为第六十五条，在其中的“未采取密闭或者其他措施防止物料遗撒”后增加“或者未按照规定路线行驶的”。

（六）将第六十八条改为第六十七条，其中的“未按照规定取得证明”修改为“未依法取得住房和城乡建设主管部门出具的连续施工作业证明”。

（七）将第六十九条改为第六十八条，第二项修改为：“（二）在县级人民政府禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地的，责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下罚款；拒不改正的，处五千元以上二万元以下罚款”。

（八）增加一条，作为第七十四条：“市人民政府派出的区域性管理委员会按照本条例有关县级人民政府的规定执行。”

二、对《荆门市城市建筑垃圾管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二条中的“收集、运输、利用、填埋等处置活动”修改为“产生、收集、贮存、运输、利用、处置等活动”。

（三）将第三条修改为：“建筑垃圾管理应当遵循减量化、资源化、无害化和谁产生、谁承担处置责任的原则。”

（四）增加一条，作为第七条：“市城市管理主管部门应当会同相关主管部门和县级人民政府，建立建筑垃圾全过程电子联单管理机制。建筑垃圾产生、运输、处置单位应当通过电子联单如实记录建筑垃圾的种类、数量、流向、贮存、利用、处置等信息。”

（五）将第七条改为第八条，第一款第一项中的“编制建筑垃圾处理方案”修改为“按照规定编制并实施建筑垃圾处理方案”。

（六）将第二十二条改为第二十三条，删去第四项、第五项。

（七）将第二十五条改为第二十六条，第二款中的“二百元以上五百元以下”修改为“一百元以上一千元以下”。

（八）删去第二十七条。

三、对《荆门市农业面源污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二十七条中的“依照《中华人民共和国土壤污染防治法》《农药管理条例》等法律、法规的规定执行”修改为“依照国家有关法律、法规的规定执行”。

四、对《荆门市人民代表大会常务委员会关于加强生物多样性协同保护的决定》作出修改

将决定中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

五、对《荆门市长湖保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第七条修改为：“市人民政府应当完善长湖流域生态保护补偿机制，依法制定生态保护补偿办法，对按照规定或者约定开展生态环境保护的地区、单位和个人予以补偿。”

（三）将第十条修改为：“人民检察院或者法律规定的社会组织对污染长湖流域水环境、破坏长湖流域水生态等损害社会公共利益的行为，可以依法提起诉讼。

“人民检察院对在长湖流域生态环境和资源保护领域负有监督管理职责的行政机关和法律、法规授权的其他组织违法行使职权或者不作为，致使社会公共利益受到侵害的，可以依法提出检察建议、提起诉讼。”

（四）将第十八条第一款中的“环境影响评价”修改为“生态环境影响评价”。

（五）将第二十六条第一款中的“划分畜禽养殖禁养区、限养区和适养区”修改为“依法划定畜禽养殖禁养区”。

（六）将第二十七条中的“应当符合水环境管理要求，不得直接排放和污染生态环境”修改为“应当符合污染物排放标准，防止污染水环境”。

（七）将第三十条第一款中的“保障城乡生活用水和生态用水，科学安排生产用水”修改为“优先满足城乡居民生活用水，保障基本生态用水、粮食安全用水，统筹农业、工业、生态修复用水等需要”。

（八）将第四十三条第一项修改为：“（一）在水体清洗装贮过油类、有毒有害污染物的车辆或者容器的，责令停止违法行为，采取治理措施消除污染，处二万元以上二十万元以下罚款，可以责令采取限制生产、停产整治等措施；拒不采取治理措施的，可以指定有治理能力的单位代为治理，所需费用由违法者承担；情节严重的，报经有批准权的人民政府批准，责令停业、关闭”。

六、对《荆门市沮漳河流域保护条例》作出修改

（一）将第一条中的“《中华人民共和国水法》、《中华人民共和国水污染防治法》、《中华人民共和国长江保护法》”修改为“《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国长江保护法》”。

（二）将第九条修改为：“县级以上人民政府组织编制的本行政区域水生态环境保护规划，应当与沮漳河流域水生态环境保护规划相衔接。”

（三）将第十三条中的“保障基本生态用水，统筹农业、工业用水”修改为“保障基本生态用水、粮食安全用水，统筹农业、工业、生态修复用水等需要”。

（四）将第二十三条第一款中的“工业集聚区”修改为“工业园区等区域”，“监测系统”修改为“监控设备”。

第二款修改为：“向污水集中处理设施排放工业废水的，应当按照国家规定进行预处理，达到集中处理设施处理工艺要求后，方可排放。”

（五）删去第四十一条第一款第三项中的“或者其他可能污染水体的”。

（六）增加一项，作为第四十二条第一款第四项：“（四）垂钓”。

（七）将第五十一条修改为：“人民检察院或者法律规定的社会组织对污染沮漳河流域水环境、破坏沮漳河流域水生态，损害社会公共利益的行为，可以依法提起诉讼。”

（八）将第六十一条修改为：“违反本条例第二十八条第二款规定，排放不符合标准的水产养殖尾水的，由生态环境主管部门责令改正，处十万元以上一百万元以下罚款，可以责令限制生产、停产整治；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

（九）将第六十四条第二款中的“二万元以上十万元以下”修改为“一万元以上五万元以下”。

（十）将第六十六条修改为：“违反本条例第四十七条第一款规定，在漳河水库饮用水水源一级保护区内组织进行游泳的，由生态环境主管部门责令停止违法行为，处二万元以上十万元以下罚款；个人在漳河水库饮用水水源一级保护区内游泳的，由生态环境主管部门责令停止违法行为，可以处五百元以下罚款。

“在漳河水库饮用水水源一级保护区外组织进行游泳的，由生态环境主管部门责令停止违法行为，处一万元以上五万元以下罚款；个人在漳河水库饮用水水源一级保护区外游泳的，由生态环境主管部门责令停止违法行为，可以处二百元以下罚款。”

七、废止《荆门市生态环境保护条例》

本决定自2026年8月15日起施行。

相关法规根据本决定作相应修改，条款顺序作相应调整，并重新公布。
