# 阿克塞哈萨克族自治县人民代表大会关于废止《甘肃省阿克塞哈萨克族自治县施行〈中华人民共和国婚姻法〉部分条款的变通规定》的决定

阿克塞哈萨克族自治县人民代表大会
关于废止《甘肃省阿克塞哈萨克族自治县
施行〈中华人民共和国婚姻法〉部分条款
的变通规定》的决定

（2026年1月30日阿克塞哈萨克族自治县第十九届人民代表大会第六次会议通过　2026年3月25日甘肃省第十四届人民代表大会常务委员会第二十二次会议批准）

阿克塞哈萨克族自治县第十九届人民代表大会第六次会议决定，废止《甘肃省阿克塞哈萨克族自治县施行〈中华人民共和国婚姻法〉部分条款的变通规定》，依法报请省人大常委会批准后公布施行。
