# 江苏省人民代表大会常务委员会关于废止《江苏省环境噪声污染防治条例 》等三件地方性法规的决定

江苏省人民代表大会常务委员会关于废止
《江苏省环境噪声污染防治条例》等三件
地方性法规的决定

（2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议通过）

江苏省第十四届人民代表大会常务委员会第二十三次会议决定，废止《江苏省环境噪声污染防治条例》、《江苏省生态环境监测条例》、《江苏省人民代表大会常务委员会关于促进农作物秸秆综合利用的决定》。

本决定自公布之日起生效。
