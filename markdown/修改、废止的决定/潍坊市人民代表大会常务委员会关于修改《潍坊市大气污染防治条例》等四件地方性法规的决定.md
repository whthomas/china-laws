# 潍坊市人民代表大会常务委员会关于修改《潍坊市大气污染防治条例》等四件地方性法规的决定

潍坊市人民代表大会常务委员会关于修改
《潍坊市大气污染防治条例》等四件
地方性法规的决定

（2026年6月25日潍坊市第十八届人民代表大会常务委员会第三十四次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

潍坊市第十八届人民代表大会常务委员会第三十四次会议决定：

一、对《潍坊市大气污染防治条例》作出修改

1.删去第四条第二款、第五条、第六条第三款和第五款、第七条、第八条、第九条、第十一条第二款、第十三条第三款、第十四条、第十六条第二款和第三款、第十九条、第二十五条、第二十八条、第三十二条、第三十四条、第三十五条、第三十六条第二项、第三十九条。

2.将第六条改为第五条，增加一款作为第一款：“市人民政府根据本行政区域的生态环境状况，制定和调整生态环境分区管控方案，报省人民政府生态环境主管部门备案后公布实施。”

将第一款改为第二款，修改为：“禁止新建、改建、扩建严重污染大气环境的项目。”

3.将第十一条第三款改为第七条第二款，修改为：“新建、改建、扩建用煤项目的，应当实行煤炭的等量或者减量替代。”

4.将第十三条改为第九条，第二款修改为：“除国家和省另有规定外，本市禁止新建燃煤、重油、渣油锅炉，燃料类煤气发生炉，额定蒸发量三十五吨以下的直接燃用生物质的锅炉和单机容量三十万千瓦以下的燃煤机组。”

5.将第二十二条改为第十六条，修改为：“各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

“排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用。禁止在居民住宅楼、未配套设立专用烟道的商住综合楼以及商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目。

“排放油烟污染物的餐饮服务业经营者应当采取有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染。”

6.将第三十条改为第二十二条，修改为：“各级人民政府应当科学精准加强秸秆、落叶等焚烧的组织、指导和管理。禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。

“禁止在人口密集区域和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。

“禁止在人口密集区域和其他依法需要特殊保护的区域未密闭或者未使用烟气处理装置加热沥青。”

7.将第三十三条改为第二十四条，修改为：“违反本条例规定，对已建成的燃煤、重油、渣油锅炉，燃料类煤气发生炉和直接燃用生物质的锅炉，未按照规定淘汰、拆除、进行超低排放改造，或者新建燃煤、重油、渣油锅炉，燃料类煤气发生炉，额定蒸发量三十五吨以下的直接燃用生物质的锅炉的，由生态环境主管部门没收相关设施并组织拆除，并处二万元以上二十万元以下罚款。

“违反本条例规定，对已建成的燃煤机组未按照规定淘汰、拆除，或者新建单机容量三十万千瓦以下燃煤机组的，由发展改革主管部门没收相关设施并组织拆除，并处二万元以上二十万元以下罚款。”

二、对《潍坊市海岸带保护条例》作出修改

1.将第四条修改为：“海岸带的保护、利用与管理应当遵循科学规划、生态优先、绿色发展、陆海统筹、严格管理的原则。”

2.将第五条改为第六条，第一款修改为：“市、沿海县级市人民政府应当加强对海岸带保护、利用与管理工作的组织领导和统筹协调，研究解决海岸带保护工作中的重大问题。”

第二款修改为：“沿海县级市人民政府应当全面做好本行政区域内的海岸带保护各项工作。内陆县（市、区）人民政府应当协同做好海岸带保护有关工作。”

3.将第九条修改为：“市、沿海县级市人民政府应当建立海岸带保护跨区域、跨部门综合执法和日常巡查机制，及时发现并制止违法行为。”

4.删去第十一条第二款、第十四条、第二十三条、第三十六条、第三十八条、第四十一条、第四十三条、第四十四条、第四十五条。

5.将第十五条改为第十四条，第一款修改为：“编制海岸带保护专项规划应当遵循国土空间规划，落实生态保护红线、环境质量底线、资源利用上线目标，并与其他有关专项规划相衔接。”

6.将第二十八条改为第二十六条，修改为：“科学管控天然卤水开采活动。天然卤水开采应当符合《中华人民共和国矿产资源法》等法律、法规规定的条件。”

7.将第二十九条改为第二十七条，删去第二款。

8.将第三十四条改为第三十二条，修改为：“化工项目（溴素除外）应当按照国家和省有关规定进驻省政府认定公布的化工园区或者化工重点监控点。按照国家和省有关规定不需要进入化工园区的新建化工项目，可以在工业园区（集聚区）集中。

“化工园区、工业园区（集聚区）应当配套建设相应的污水集中处理设施，按照规定安装自动监测设备，建立完善的环境管理档案，保证园区内企业废水得到全部收集、全部处理、全部稳定达标排放。”

9.将第三十七条改为第三十四条，修改为：“沿海县级市人民政府应当对海岸带陆域范围内畜禽养殖布局进行整体规划，科学划定禁养区和限养区。限养区内不得擅自新建畜禽养殖场。

“限养区内现有畜禽养殖场应当采取必要的污染防治措施，建设与养殖规模和污染防治需要相适应的养殖废弃物综合利用和无害化处理设施并保持正常运行。

“限养区内现有畜禽养殖场未建设的或者建设的配套设施不合格的，不得开展畜禽养殖活动。”

10.将第三十九条改为第三十五条，修改为：“市、沿海县级市人民政府因地制宜依法编制并组织实施养殖水域滩涂规划，确定可以用于养殖业的水域和滩涂，科学划定海水养殖限养区和养殖区。

“限养区内不得进行高强度开发利用，对养殖方式、品种、容量进行限制，可以开展生态养护型增殖放流活动。”

11.将第四十六条改为第三十八条，第二款修改为：“市、沿海县级市人民政府应当组织建立海洋垃圾监测、收集、运输及处置机制，落实属地管理责任，对海洋垃圾进行治理。生态环境、城市管理等有关部门在各自职责范围内加强海洋垃圾污染防治的监督指导和保障。”

12.删去第五章。

三、对《潍坊市海洋牧场管理条例》作出修改

1.将第一条修改为：“为了规范海洋牧场管理，维护海洋生态安全，推动海洋经济高质量发展，根据有关法律、法规，结合本市实际，制定本条例。”

2.删去第五条第五款、第六款和第九条、第十条、第二十三条、第三十四条。

3.将第八条修改为：“市人民政府可以结合实际需要，科学编制本市海洋牧场发展规划。”

4.将第三十三条改为第三十条，修改为：“违反本条例第十一条第三款规定，海洋工程建设项目未建成生态环境保护设施、生态环境保护设施未经验收或者经验收不合格即投入生产、使用的，由生态环境行政主管部门责令改正，处二十万元以上一百万元以下的罚款，拒不改正的，处一百万元以上二百万元以下的罚款；对直接负责的主管人员和其他直接责任人员处五万元以上二十万元以下的罚款；造成重大环境污染、生态破坏的，责令其停止生产、使用，或者报经有批准权的人民政府批准，责令停业、关闭。”

5.将三十六条改为第三十二条，第一项修改为：“海洋牧场，是指在特定海域通过采取投放人工鱼礁等措施，构建的供水生生物繁殖、生长的良好场所。”

四、对《潍坊市文明行为促进条例》作出修改

1.将第四条第一款修改为：“市、县（市、区）应当加强对精神文明建设工作的组织领导，统筹推进本行政区域内的文明行为促进工作。”

2.将第七条第一款修改为：“市、县（市、区）精神文明建设工作机构应当组织制定市民公约、文明行为规范。”

3.删去第十四条、第二十三条第二项、第二十七条、第三十三条、第四十三条、第四十四条、第四十五条、第四十六条、第四十七条、第四十八条、第五十条和第五十一条。

4.将第三十四条改为第三十一条，第一款修改为：“市、县（市、区）精神文明建设工作机构应当健全完善潍坊好人、道德模范等先进人物的举荐、评选、宣传等制度，按照有关规定对文明行为以及文明行为促进相关工作先进单位和个人予以表扬。”

此外，根据机构改革职能调整情况对有关单位职责和名称进行调整，同时对相关条文顺序和个别文字作了相应修改。

本决定自2026年8月15日起施行。

《潍坊市大气污染防治条例》《潍坊市海岸带保护条例》《潍坊市海洋牧场管理条例》《潍坊市文明行为促进条例》根据本决定作相应修改，重新公布。
