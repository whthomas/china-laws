# 国务院关于废止部分行政法规和文件的决定

国务院关于废止部分行政法规和文件的决定

为进一步推进"放管服"改革，促进境内企业依法合规利用境外资本市场规范发展，国务院决定废止以下行政法规和文件：

一、国务院关于股份有限公司境外募集股份及上市的特别规定（1994年8月4日中华人民共和国国务院令第160号发布）

二、国务院关于进一步加强在境外发行股票和上市管理的通知（国发〔1997〕21号）

本决定自2023年3月31日起施行。
