# 贵州省人民代表大会常务委员会关于修改《贵州省反不正当竞争条例》的决定

贵州省人民代表大会常务委员会关于修改
《贵州省反不正当竞争条例》的决定

（2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议通过）

贵州省第十四届人民代表大会常务委员会第二十五次会议决定，对《贵州省反不正当竞争条例》作如下修改：

一、增加一条，作为第二条：“本省行政区域内生产经营活动中的不正当竞争行为及其监督管理，适用本条例。”

二、增加一条，作为第三条：“反不正当竞争工作坚持中国共产党的领导，坚持政府监管、行业自律、社会共治、惩防并举的原则。

“本省健全完善反不正当竞争和公平竞争审查制度，依法加强公平竞争审查工作，加强反不正当竞争执法司法，维护市场竞争秩序，保障各类经营者依法平等使用生产要素、公平参与市场竞争。”

三、将第三条改为第五条，修改为：“省人民政府建立健全反不正当竞争工作协调机制，统筹全省反不正当竞争工作，协调处理维护市场竞争秩序的重大问题。

“市州、县级人民政府建立健全本行政区域反不正当竞争工作协调机制，协调处理本行政区域维护市场竞争秩序的重大问题和跨部门反不正当竞争执法等工作。”

四、将第七条改为第九条，修改为：“经营者不得实施下列混淆行为，引人误认为是他人商品或者与他人存在特定联系：

“（一）擅自使用与他人有一定影响的商品名称、包装、装潢等相同或者近似的标识；

“（二）擅自使用他人有一定影响的名称（包括简称、字号等）、姓名（包括笔名、艺名、网名、译名等）；

“（三）擅自使用他人有一定影响的域名主体部分、网站名称、网店名称、网页、新媒体账号名称、节目栏目名称、应用程序名称或者图标等；

“（四）其他足以引人误认为是他人商品或者与他人存在特定联系的混淆行为。

“擅自将他人注册商标、未注册的驰名商标作为企业名称中的字号使用，或者将他人商品名称、企业名称（包括简称、字号等）、注册商标、未注册的驰名商标等设置为搜索关键词，引人误认为是他人商品或者与他人存在特定联系的，属于前款规定的混淆行为。

“前两款所称引人误认为，应当以相关公众的一般注意力为标准，根据标识等使用的范围、持续时间、商业投入等，同时结合标识等的知名度、影响力、显著性、相似度以及商品的类似程度等因素进行综合认定。

“经营者不得帮助他人实施混淆行为。”

五、将第八条改为第十条，修改为：“经营者不得采用给予财物或者其他手段贿赂下列单位或者个人，以谋取交易机会或者竞争优势：

“（一）交易相对方的工作人员；

“（二）受交易相对方委托办理相关事务的单位或者个人；

“（三）利用职权或者影响力影响交易的单位或者个人。

“前款规定的单位和个人不得收受贿赂。

“经营者在交易活动中，可以以明示方式向交易相对方支付折扣，或者向中间人支付佣金。经营者向交易相对方支付折扣、向中间人支付佣金的，应当如实入账。接受折扣、佣金的经营者也应当如实入账。

“经营者的工作人员进行贿赂的，应当认定为经营者的行为；但是，经营者有证据证明该工作人员的行为与为经营者谋取交易机会或者竞争优势无关的除外。

“本条第一款所称财物，包括金钱、实物以及代币卡（券）、含有金额的会员卡、网络虚拟财产、礼券、基金、股份、债务免除等可以用金钱计算数额的财产性利益。

“本条第一款所称其他手段，包括提供各种名义的旅游、留学、考察、房屋使用权、房屋装修、设备设施使用等使本条第一款规定的相关单位和个人受益的手段。”

六、将第十一条改为第十三条，在第二款第一项中的“计算机程序”后增加“代码”；删去第三款。

七、将第十二条改为第十四条，修改为：“经营者进行有奖销售不得存在下列情形：

“（一）所设奖的种类、兑奖条件、奖金金额或者奖品等有奖销售信息不明确，影响兑奖；

“（二）有奖销售活动开始后，无正当理由变更所设奖的种类、兑奖条件、奖金金额或者奖品等有奖销售信息；

“（三）采用谎称有奖或者故意让内定人员中奖等欺骗方式进行有奖销售；

“（四）抽奖式的有奖销售，最高奖的金额超过五万元。

“前款第四项规定的最高奖的金额超过五万元，包括：

“（一）最高奖设置多个中奖者的，其中任意一个中奖者的最高奖金额超过五万元；

“（二）同一奖券或者购买一次商品具有两次或者两次以上获奖机会的，累计金额超过五万元；

“（三）以服务、物品使用等形式作为奖品的，该服务、物品使用等的市场价格超过五万元；

“（四）其他最高奖的金额超过五万元的情形。”

八、将第十四条改为第十六条，其中的“技术手段”修改为“数据和算法、技术、平台规则等”，并删去第四项。

增加两款，作为第二款、第三款：“经营者不得以欺诈、胁迫、避开或者破坏技术管理措施等不正当方式，获取、使用其他经营者合法持有的数据，损害其他经营者的合法权益，扰乱市场竞争秩序。

“经营者不得滥用平台规则，直接或者指使他人对其他经营者实施虚假交易、虚假评价或者恶意退货等行为，损害其他经营者的合法权益，扰乱市场竞争秩序。”

九、将第二十条改为第二十二条，修改为：“有关单位违反本条例第十条规定贿赂他人或者收受贿赂的，由监督检查部门没收违法所得，处十万元以上一百万元以下的罚款；情节严重的，处一百万元以上五百万元以下的罚款，可以并处吊销营业执照。

“经营者的法定代表人、主要负责人和直接责任人员对实施贿赂负有个人责任，以及有关个人收受贿赂的，由监督检查部门没收违法所得，处一百万元以下的罚款。”

十、将第二十三条改为第二十五条，修改为：“妨害监督检查部门依法履行职责，拒绝、阻碍调查的，由监督检查部门责令改正，对个人可以处一万元以下的罚款，对单位可以处十万元以下的罚款。”

十一、对部分条文作以下修改：

（一）在第一条中的“鼓励和保护公平竞争”后增加“预防和”；将“有关法律、法规的规定”修改为“有关法律、行政法规的规定”。

（二）将第四条改为第六条，其中的“查处”修改为“监督检查”。

（三）将第六条改为第八条，其中的“行业协会、商会等组织”修改为“行业组织”，“自律管理”修改为“行业自律”，“会员”修改为“本行业的经营者”。

（四）将第九条改为第十一条，在“欺骗、误导消费者”后增加“和其他经营者”。

（五）将第十条改为第十二条，其中的“虚构评价”修改为“虚假评价”。

（六）将第十三条改为第十五条，其中的“竞争对手”修改为“其他经营者”。

（七）将第十五条改为第十七条，在第三款中的“并应当”后增加“依法”。

（八）将第十六条改为第十八条，第一款中的“2人”修改为“两人”，“合法证件”修改为“执法证件”；第二款中的“个人信息和商业秘密”修改为“商业秘密、个人隐私和个人信息依法”。

（九）将第十九条改为第二十一条，在第二款中的“应当将处理结果”后增加“及时”。

（十）将第二十四条改为第二十六条，其中的“监督检查部门及其工作人员”修改为“监督检查部门的工作人员”，在“商业秘密”后增加“个人隐私或者个人信息”。

（十一）将第二十五条改为第二十七条，删去其中的“给他人造成损害的，应当依法承担民事责任”。

本决定自2026年8月1日起施行。

《贵州省反不正当竞争条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
