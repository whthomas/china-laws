# 定西市人民代表大会常务委员会关于废止《定西市河道生态环境保护条例》的决定

定西市人民代表大会常务委员会
关于废止《定西市河道生态环境保护
条例》的决定

（2026年7月6日定西市第五届人民代表大会常务委员会第三十六次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

定西市第五届人民代表大会常务委员会第三十六次会议决定，废止《定西市河道生态环境保护条例》（2018年12月14日定西市第四届人民代表大会常务委员会第二十次会议通过　2019年3月28日甘肃省第十三届人民代表大会常务委员会第九次会议批准　根据2020年12月29日定西市第四届人民代表大会常务委员会第三十八次会议通过　2021年3月31日甘肃省第十三届人民代表大会常务委员会第二十二次会议批准的《定西市人民代表大会常务委员会关于修改〈定西市河道生态环境保护条例〉的决定》修正）。

本决定自2026年8月15日起施行。
