# 福州市人民代表大会常务委员会关于修改《福州市环境噪声污染防治若干规定》等九项地方性法规的决定

福州市人民代表大会常务委员会
关于修改《福州市环境噪声污染防治若干规定》
等九项地方性法规的决定

（2026年8月25日福州市第十六届人民代表大会常务委员会第三十三次会议通过　2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

福州市第十六届人民代表大会常务委员会第三十三次会议决定对《福州市环境噪声污染防治若干规定》等九项地方性法规作如下修改：

一、福州市环境噪声污染防治若干规定

（一）将第一条修改为：“为了防治环境噪声污染，创造安静适宜的人居环境，根据《中华人民共和国生态环境法典》等法律法规，结合本市实际，制定本规定。”

（二）将第十条修改为：“在噪声敏感建筑物集中区域，禁止新建排放噪声的工业企业，改建、扩建工业企业的，应当采取有效措施防止工业噪声污染。”

（三）将第十三条修改为：“在噪声敏感建筑物集中区域，禁止在午、夜间进行产生噪声污染的施工作业，但是抢修、抢险施工作业，因生产工艺要求或者其他特殊需要必须连续施工作业的除外。

“因特殊需要必须连续施工作业的，应当取得县（市、区）生态环境主管部门的证明，并在施工现场显著位置公示或者以其他方式公告附近居民。”

（四）删除第十八条、第十九条、第二十条、第二十一条、第二十二条、第二十三条。

（五）增加一条，作为第十八条：“违反本规定的行为，法律法规已有法律责任规定的，从其规定。”

（六）将第二十五条改为第二十条，第一项修改为：“（一）‘噪声敏感建筑物’：是指用于居住、科学研究、医疗卫生、文化教育、机关团体办公、社会福利等需要保持安静的建筑物。”

删除第二项。

（七）对部分条文表述作以下修改：

1.将第三条第一款、第四条第三款、第五条、第六条、第十五条、第二十四条中的“环境保护行政主管部门”修改为“生态环境主管部门”。

2.将第九条中的“环境保护行政主管部门”修改为“生态环境等相关部门”。

此外，根据修改，对条文顺序作相应调整。

二、福州市大气污染防治办法

（一）将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康，促进生态文明建设，根据《中华人民共和国生态环境法典》、《福建省大气污染防治条例》等有关法律、法规，结合本市实际，制定本办法。”

（二）将第三条修改为：“防治大气污染，坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责的原则。”

（三）将第十八条修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者应当按照有关规定，安装、使用、维护大气污染物排放自动监测设备，开展监控、自动监测，保存原始监测记录，并与生态环境主管部门的监测监控网络联网。”

（四）将第十九条中的“重点排污单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”。

（五）将第三十二条修改为：“市、县（市、区）人民政府应当制定污染天气应急方案，根据预警等级和应急需要，可以依法采取下列相应的应急响应措施：

“（一）加大机动车通行和露天焚烧监管力度；

“（二）加强道路保洁或者施工扬尘管理；

“（三）禁止燃放烟花爆竹；

“（四）加强巡查重点污染源和建筑垃圾运输过程中物料的抛洒滴漏；

“（五）组织开展人工影响天气作业；

“（六）法律、法规规定的其他措施。

“市、县（市、区）人民政府应当依据重污染天气的预警等级，及时启动应急方案，除可以采取前款所列应急响应措施外，根据重污染天气重点行业绩效分级水平和应急需要，还可以采取责令有关企业停产、限产、调峰错峰生产或者停止工地土石方作业和建筑物拆除施工等差异化管控措施。

“采取应急响应措施应当预先通知相关单位和人员。”

（六）将第三十六条修改为：“违反本办法第二十六条第一款规定，在禁止的区域内使用高排放非道路移动机械的，由市生态环境主管部门或其派出机构责令改正，处每辆五千元罚款。

“违反本办法第二十六条第二款规定，使用未完成编码登记的非道路移动机械的，由市生态环境主管部门或其派出机构责令改正；拒不改正的，处每辆二千元罚款。”

（七）删除第三十九条第一款。

（八）对部分条文表述作以下修改：

在第三十四条、第三十五条、第三十七条、第三十八条中的“由市生态环境主管部门”后增加“或其派出机构”。

三、福州市市容和环境卫生管理办法

（一）将第十五条第二款修改为：“非机动车应当在划定的停车点停放。”

（二）增加一条，作为第三十条：“违反本办法规定的行为，法律、法规已有法律责任规定的，从其规定。”

（三）将第三十条改为第三十一条，修改为：“违反本办法规定，非机动车未在划定的停车点停放的，由有关主管部门处警告或者五元以上五十元以下罚款。”

（四）将第三十一条改为第三十二条，第一项修改为：“（一）乱倒粪便，随地便溺；”

（五）将第三十二条改为第三十三条，删除第一款第八项、第九项、第十项、第十一项、第十六项。

第十二项改为第八项，修改为：“（八）园林绿化作业，未按时清理场地和枝叶的；”

第十三项改为第九项，修改为：“（九）责任单位或者受委托单位未按规定组织清扫、保洁的；”

第十四项改为第十项，修改为：“（十）擅自悬挂标语条幅等宣传品，或者在公共广告栏外张贴标语、启事、招贴广告的；”

删除第二款。

（六）删除第三十四条第二款。

此外，根据修改，对条文顺序作相应调整。

四、福州市建筑垃圾管理规定

（一）将第一条修改为：“为了加强建筑垃圾管理，维护城市市容环境卫生，保护和改善生态环境，根据《中华人民共和国生态环境法典》等有关法律法规，结合本市实际，制定本规定。”

（二）将第二条第二款修改为：“本规定所称的建筑垃圾是指建设单位、施工单位新建、改建、扩建和拆除各类建筑物、构筑物、管网等，以及居民装饰装修房屋过程中产生的弃土、弃料和其他固体废物。”

（三）增加一条，作为第二十一条：“违反本规定的行为，法律法规已有法律责任规定的，从其规定。”

（四）删除第二十四条、第二十五条。

此外，根据修改，对条文顺序作相应调整。

五、福州市生活垃圾分类管理条例

（一）将第一条修改为：“为了加强生活垃圾分类管理，提高生活垃圾减量化、资源化、无害化水平，促进城乡精细化管理，改善城乡生态环境，推进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国循环经济促进法》、《福建省城乡生活垃圾管理条例》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第二条第二款修改为：“本条例所称生活垃圾，是指在日常生活中或者为日常生活提供服务的活动中产生的固体废物以及法律、行政法规规定视为生活垃圾的固体废物。”

（三）将第十一条第二项修改为：“（二）厨余垃圾，是指易腐烂的、含有有机质的生活垃圾，主要包括家庭厨余垃圾、餐厨垃圾、其他厨余垃圾等；”

（四）将第十三条第一款修改为：“任何单位和个人应当按照规定的要求将生活垃圾分类投放到有相应标识的收集容器内或者指定的收集点，禁止随意倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾。”

（五）将第十九条第二款修改为：“运输属于危险废物的有害垃圾，应当采取防止污染环境的措施，并遵守国家有关危险货物运输管理的规定。”

（六）将第二十三条第四款修改为：“属于危险废物的有害垃圾应当由依法取得相应许可证的企业进行无害化处置。”

（七）将第二十五条第九项修改为：“（九）不得擅自关闭、闲置或者拆除处置设施、场所，确需关闭、闲置或者拆除的，应当依法核准，并采取防止污染环境的措施；”

（八）将第四十九条修改为：“违反本条例规定，未在指定地点分类投放生活垃圾的，由市容环境卫生行政主管部门责令改正，拒不改正的，对单位处五万元以上五十万元以下的罚款，对个人处五十元以上二百元以下的罚款。”

（九）将第五十一条第五项修改为：“（五）未按照规定的时间、频次、地点分类收集、运输的，处一万元以上三万元以下的罚款；”

第六项修改为：“（六）进行敞开式分拣、压缩的，处二万元以上五万元以下的罚款；”

删除第七项。

（十）对部分条文表述作以下修改：

将第十三条、第十八条第二款、第十九条第四款、第二十三条第三款、第二十九条第一款中的“易腐垃圾”修改为“厨余垃圾”。

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

六、福州市城市排水设施建设与管理办法

（一）删除第二十八条、第二十九条。

（二）增加一条，作为第二十八条：“违反本办法规定的行为，法律、法规已有法律责任规定的，从其规定。”

此外，根据修改，对条文顺序作相应调整。

七、福州市水工程管理条例

（一）增加一条，作为第二十六条：“违反本条例规定的行为，法律法规已有法律责任规定的，从其规定。”

（二）删除第三十一条。

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

八、福州市园林绿化管理条例

（一）删除第二十三条。

（二）增加一条，作为第三十四条：“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（三）删除第三十六条。

（四）删除第三十八条第三项。

此外，根据修改，对条文顺序作相应调整。

九、福州市湿地保护办法

将第四十三条修改为：“违反本办法第二十条第二款、第三十条第二款规定，有下列行为之一的，由市、县（市、区）人民政府有关部门根据职责分工责令改正，并按照下列规定予以处罚；造成损失的，依法承担赔偿责任：

“（一）毁坏湿地监测设施的，处二万元以上二十万元以下罚款；

“（二）擅自移动或者破坏湿地保护标志的，处五百元以上二千元以下罚款。”

本决定自公布之日起施行。

《福州市环境噪声污染防治若干规定》等九项地方性法规根据本决定作相应修改后，重新公布。
