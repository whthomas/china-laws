# 遵义市人民代表大会常务委员会关于修改《遵义市湘江保护条例》等四件地方性法规部分条款的决定

遵义市人民代表大会常务委员会关于修改
《遵义市湘江保护条例》等四件地方性
法规部分条款的决定

（2026年6月23日遵义市第六届人民代表大会常务委员会第四十六次会议通过　2026年7月29日经贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

遵义市第六届人民代表大会常务委员会第四十六次会议决定对下列四件地方性法规部分条款作出修改：

一、对《遵义市湘江保护条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第八条第二款修改为：“市人民政府生态环境行政主管部门应当会同其他有关部门将湘江水污染防治纳入水生态环境保护规划。”

（三）删去第十条、第二十条中的“符合湘江水资源保护规划并”、第二十三条第二款中的“退耕还林”、第三十三条、第三十九条中的“住房与城乡建设部门”“会同生态环境、水行政主管部门”、第四十条第二款中的“纳入重点排污单位进行管理，运营维护单位应当”、第四十八条第一款中的“和养殖小区”“养殖小区”。

（四）将第十五条中的“重点排污单位”和第四十六条中“排污单位”修改为“实行排污许可管理的企业事业单位和其他生产经营者”。

（五）将第四十三条第一款中的“开发区、工业园区等工业集聚区”和句末的“工业集聚区”，以及第二款中的“工业集聚区”修改为“工业园区等区域”。

（六）将第四十四条修改为：“湘江沿岸企业事业单位和其他生产经营者应当依法建立完善环境保护责任制度，建设、完善企业污水处理设施并保持处理设施正常运行。禁止通过暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行水污染防治设施等逃避监管的方式排放水污染物。”

（七）将第四十五条第二款修改为：“湘江沿岸实行排污许可重点管理的企业事业单位和其他生产经营者应当按照管理要求安装水污染物排放自动监测设备，与县级以上人民政府生态环境行政主管部门在线监控平台联网，并保证监测设备正常运行。”

（八）将第五十二条修改为：“建立健全湘江突发生态环境事件监测预警机制，流域范围内各级人民政府及其有关部门、企业事业单位和其他生产经营者应当依法做好湘江突发生态环境事件的预防准备、监测预警、应急处置、调查评估、事后恢复等工作。

“可能发生湘江水污染事故的企业事业单位，应当制定有关水污染事故的应急预案，依法完善湘江突发生态环境事件风险防控措施，储备必要的生态环境应急物资和装备，定期开展应急演练，做好应急准备，并开展隐患排查，及时消除隐患。

“企业事业单位发生湘江水污染事故或者其他突发事件，造成或者可能造成水污染事故的，应当立即启动本单位的应急预案，采取隔离等应急措施，切断或者控制污染源，防止水污染物进入水体、防止危害扩大，并向事故发生地县级以上人民政府或者生态环境主管部门报告。生态环境主管部门接到报告后，应当及时向本级人民政府报告，并抄送水行政、应急管理等有关部门。”

（九）在第五十六条第一款句末增加“或者处理，并可以向社会公开”。

二、对《遵义市市辖区集中式饮用水水源保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第七条中的“年度目标考核内容和领导干部考核评价体系”修改为“考核评价内容。考核结果应当向社会公开”。

（三）将第十三条第一款修改为：“市辖区集中式饮用水水源保护应当纳入水生态环境保护规划。”

（四）将第十八条中的“在市辖区集中式饮用水水源保护区划定之前经批准修建的，应当逐步拆除或者搬迁，并依法给予相应的补偿；未经批准的，依法进行处理。”修改为“由县级以上人民政府责令拆除或者关闭”。

（五）删去第二十三条第四项和第五项、第二十四条第三项中的“养殖小区”和第五项、第三十一条第二款中的“及乡、镇人民代表大会主席团”、第三十三条第一款中的“第四项”“第十四项”和第二款、第三十四条中的“第五项”、第三十五条。

（六）将第二十九条第二款修改为：“供水单位应当开展市辖区集中式饮用水水源取水口及出厂水的水质监测，发现取水口水质不符合饮用水水源水质标准或者出水口水质不符合饮用水卫生标准的，应当采取有效措施，并向所在地的市、县级人民政府供水主管部门报告。供水主管部门接到报告后，应当通报生态环境、卫生健康、水行政等有关部门。”

（七）将第三十六条中的“行政处分”修改为“处分或者处理，并可以向社会公开”。

三、对《遵义市城市文明建设若干规定》作出修改

（一）在第一条“为了培育和践行社会主义核心价值观”后增加“铸牢中华民族共同体意识”。

（二）将第十四条第十一项修改为：“不得在禁止吸烟的公共场所吸烟，对在禁止吸烟的公共场所吸烟的，公共场所的经营者、管理者应当予以劝阻。违反规定的，由综合行政执法部门对吸烟者给予批评教育，责令改正，并处十元以下罚款，不听劝告，拒不改正的，处十五元以上五十元以下罚款。”

（三）将第十四条第十二项修改为：“个人或者单位在噪声敏感建筑物集中区域及其附近的街道、广场、公园，不得从事超过区域环境噪声排放标准的活动，不得在22时至次日8时期间使用大音量音响、抽打陀螺、甩响鞭等方式进行文化娱乐、健身活动。违反规定的，由综合行政执法部门给予批评教育，责令改正；拒不改正的，给予警告，对个人可以处二百元以上一千元以下罚款，对单位可以处二千元以上二万元以下罚款。”

四、对《遵义历史文化名城保护条例》作出修改

（一）在第一条“践行社会主义核心价值观”后增加“铸牢中华民族共同体意识”。

（二）将第四十八条修改为：“违反本条例第十二条第三款规定的，由综合行政执法部门责令限期改正，逾期不改正的，对单位处一万元以上五万元以下的罚款，对个人处一千元以上一万元以下的罚款。”

（三）将第四十九条修改为：“违反本条例规定，有下列行为之一的，由相关行政主管部门责令停止违法行为、限期恢复原状或者采取其他补救措施；有违法所得的，没收违法所得；逾期不恢复原状或者不采取其他补救措施的，可以指定有能力的单位代为恢复原状或者采取其他补救措施，所需费用由违法者承担；造成严重后果的，并处以罚款，造成损失的，依法承担赔偿责任：

“（一）生产、储存、经营易燃、易爆和腐蚀性物品；

“（二）损坏建筑主体承重结构或者以其他方式危害建筑物主体安全。

“有前款第一项行为的，对单位并处五十万元以上一百万元以下的罚款，对个人并处五万元以上十万元以下的罚款；有前款第二项行为的，对单位并处二十万元以上五十万元以下的罚款，对个人并处十万元以上二十万元以下的罚款。”

本决定自2026年8月15日起施行。

《遵义市湘江保护条例》、《遵义市市辖区集中式饮用水水源保护条例》、《遵义市城市文明建设若干规定》、《遵义历史文化名城保护条例》根据本决定作相应修改，并对条文顺序作相应调整和文字技术处理，重新公布。
