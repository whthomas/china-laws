# 金昌市人民代表大会常务委员会关于修改《金昌市文明行为促进条例》《金昌市乡村清洁条例》《金昌市城市生活垃圾分类管理条例》的决定

金昌市人民代表大会常务委员会关于修改
《金昌市文明行为促进条例》《金昌市乡村
清洁条例》《金昌市城市生活垃圾
分类管理条例》的决定

（2026年6月29日金昌市第九届人民代表大会常务委员会第三十四次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

金昌市第九届人民代表大会常务委员会第三十四次会议决定：

一、对《金昌市文明行为促进条例》作出修改

（一）将第五条修改为：“市、县（区）承担精神文明建设工作的部门负责本行政区域内文明行为促进工作的指导、协调、监督、检查和宣传等事宜。”

（二）将第十条第五项修改为：“在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质”。

（三）将第十七条第二款修改为：“在校园周边进行施工作业以及其他可能产生噪声影响的活动，应当遵守国家和本省有关噪声污染防治的规定。在举行招生考试等特殊活动期间，应当遵守市、县（区）人民政府或者其指定部门作出的关于时间和区域的限制性规定。”

（四）将第三十条第一款修改为：“市、县（区）人民政府及其有关部门和组织，应当建立健全文明行为激励机制，及时选树表现突出的先进典型，弘扬新风正气。”

（五）将第三十一条修改为：“市、县（区）应当建立文明行为促进工作联席会议制度，统筹协调文明行为促进工作，研究解决有关重大问题，推进文明行为促进工作的开展。

联席会议成员单位应当指定专门机构负责组织实施有关文明行为促进的具体工作。

文明行为促进工作应当纳入群众性精神文明创建活动、精神文明建设年度工作要点及目标责任进行管理和考核。”

（六）将第三十六条第一款修改为：“市、县（区）人民政府及有关部门应当建立不文明行为举报、投诉、查处制度，向社会公布举报、投诉不文明行为的方式和途径。”

（七）将第三十七条第二款修改为：“违反本条例第十条第（二）（三）（四）（七）项规定的，由城市管理部门责令改正，处一百元以上一千元以下罚款。”

（八）将第三十七条第三款中的“（四）”删除。

（九）将第三十七条第五款修改为：“违反本条例第十条第（六）项规定的，由城市管理部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下罚款；拒不改正的，处五千元以上二万元以下罚款。”

二、对《金昌市乡村清洁条例》作出修改

（一）将第十九条第一款修改为：“乡村畜禽养殖场应当按照国家有关规定配套建设粪污收集处置设施，并正常运转。”

（二）增加一款作为第十九条第三款：“畜禽散养密集区所在地县（区）、乡（镇）人民政府应当组织对畜禽粪污进行分户收集、集中处理利用。县（区）人民政府组织确定本行政区域的畜禽散养密集区。”

（三）将第二十六条第二项修改为：“随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾”。

三、对《金昌市城市生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了规范城市生活垃圾分类管理，改善人居环境，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）将第六条第四款中的“环境影响评价审批”，修改为：“生态环境影响评价审批”。

（三）将第十六条第五款修改为：“禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（四）将第三十四条中的“情节严重的”，修改为：“拒不改正的”。

本决定自2026年8月15日起施行。

《金昌市文明行为促进条例》、《金昌市乡村清洁条例》、《金昌市城市生活垃圾分类管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
