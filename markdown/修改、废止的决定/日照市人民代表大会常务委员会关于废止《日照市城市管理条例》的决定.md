# 日照市人民代表大会常务委员会关于废止《日照市城市管理条例》的决定

日照市人民代表大会常务委员会关于废止
《日照市城市管理条例》的决定

（2026年6月25日日照市第十九届人民代表大会常务委员会第三十六次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

日照市第十九届人民代表大会常务委员会第三十六次会议决定，废止《日照市城市管理条例》（2017年6月28日日照市第十八届人民代表大会常务委员会第二次会议通过　2017年7月28日山东省第十二届人民代表大会常务委员会第三十一次会议批准）。

本决定自2026年8月15日起施行。
