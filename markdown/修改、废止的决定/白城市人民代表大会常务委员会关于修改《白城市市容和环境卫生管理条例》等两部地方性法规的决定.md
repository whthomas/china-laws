# 白城市人民代表大会常务委员会关于修改《白城市市容和环境卫生管理条例》等两部地方性法规的决定

白城市人民代表大会常务委员会
关于修改《白城市市容和环境卫生管理条例》
等两部地方性法规的决定

（2026年8月31日白城市第七届人民代表大会常务委员会第三十六次会议通过）

白城市第七届人民代表大会常务委员会第三十六次会议决定对下列地方性法规作出修改：

一、对《白城市市容和环境卫生管理条例》作出修改

（一）将第十六条第一款第三项修改为：“（三）乱倒污水、粪便；”

第四项修改为：“（四）在露天场所、垃圾容器内焚烧枝叶；”

第二款修改为：“违反前款规定的，由市容和环境卫生主管部门责令改正；有第一项、第二项行为拒不改正的，处二十元以上一百元以下罚款；有第三项行为的，处一百元以上五百元以下罚款；有第四项行为的，可以处五百元以上二千元以下罚款。”

（二）将第二十六条修改为：“个人产生的生活垃圾和建筑垃圾应当投放至指定收集处置场所，不得擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧。

违反前款规定的，由市容和环境卫生主管部门责令限期改正，处一百元以上一千元以下的罚款。”

二、对《白城市城市绿化条例》作出修改

（一）将第五条修改为：“市、县（市、区）人民政府应当将城市绿化的建设和维护纳入国民经济和社会发展计划，安排专项资金，用于城市绿化。”

（二）将第二十五条第二项修改为：“（二）在绿地、树池内堆放杂物，放养家畜家禽、遛放宠物；”

（三）删除第二十七条、第三十六条、第四十一条。

（四）将第四十二条改为第三十九条，修改为：“法律、法规对城市绿化以及古树名木等管理有规定的，从其规定。”

（五）对相关条文顺序做调整。

本决定自公布之日起施行。

《白城市市容和环境卫生管理条例》《白城市城市绿化条例》根据本决定作相应修改，重新公布。
