# 安阳市人民代表大会常务委员会关于修改《安阳市大气污染防治条例》等五部地方性法规的决定

安阳市人民代表大会常务委员会关于修改
《安阳市大气污染防治条例》等五部
地方性法规的决定

（2026年6月24日安阳市第十五届人民代表大会常务委员会第二十八次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

安阳市第十五届人民代表大会常务委员会第二十八次会议决定：

一、对《安阳市大气污染防治条例》作出修改

（一）将第一条修改为：“为了保护和改善大气环境，防治大气污染，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，全面推进美丽安阳建设，加快推进人与自然和谐共生的现代化，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（三）第四条增加一款，作为第二款：“市人民政府应当编制规划，采取有效措施，控制或者逐步削减大气污染物的排放量，使大气环境质量达到规定标准并逐步改善。”

（四）将第八条第一款修改为：“严格落实生态环境保护目标责任制和考核评价制度。将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。”

（五）删去第十一条。

（六）将第十三条改为第十二条，修改为：“实行排污许可重点管理和其他法定的应当披露生态环境信息的企业事业单位和其他生产经营者应当按照国家和省有关规定，向社会及时、真实、准确、完整披露污染物排放信息、温室气体排放信息等生态环境信息。”

（七）删去第十八条。

（八）将第二十九条改为第二十七条，第二款修改为：“在本市生产、销售、注册登记、使用的机动车船、非道路移动机械及其发动机，应当执行国家和省规定的污染物排放标准。禁止生产、进口或者销售不符合大气污染物排放标准的机动车船、非道路移动机械及其发动机。”

（九）将第三十条改为第二十八条，将第二款中的“机动车维修地”修改为“机动车停放地、维修地和重型汽车使用地”，在“进行监督抽测”前增加“排放控制系统运行情况”，在“进行监督抽测”后增加“在不影响正常通行的情况下，可以通过非接触式道路监测等技术手段对在道路上行驶的机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测，公安机关交通管理部门予以配合”。

将第三款修改为：“在用机动车、非道路移动机械等排放大气污染物超过标准的，应当进行维修；经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。”

（十）将第三十二条改为第三十条，第一款修改为：“禁止生产、进口或者销售不符合标准的机动车船、非道路移动机械用燃料和氮氧化物还原剂；禁止向机动车、非道路移动机械、内河直达船舶销售非机动车船用燃料；禁止机动车、非道路移动机械、内河直达船舶使用非机动车船用燃料。”

（十一）将第三十五条改为第三十三条，第一款修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

增加一款作为第二款：“禁止在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。”

将第三款中“禁止的区域”修改为“禁止的时段和区域”。

（十二）将第三十八条改为第三十六条，第一款修改为：“禁止生产、销售或者燃放不符合质量标准的烟花爆竹。任何单位和个人不得在县级以上地方人民政府禁止的时段和区域燃放烟花爆竹。”

（十三）将第四十条改为第三十八条，删去第一款中的“向社会公布并”，在“生态环境主管部门备案”后增加“并向社会公布”；将第二款中的“限制部分机动车行驶”修改为“限制部分机动车行驶和非道路移动机械使用”，在“停止工地土石方作业”前增加“禁止燃放烟花爆竹”，在“停止幼儿园和学校组织的户外活动”前增加“停止露天烧烤”。

（十四）将第四十五条改为第四十三条，修改为：“违反本条例第十一条规定，排放大气污染物的企业事业单位未建立大气环境保护责任制度的，由负有生态环境保护监督管理职责的部门、机构按照职责分工责令改正；拒不改正的，处五万元以上二十万元以下罚款；情节严重的，可以责令限制生产、停产整治。”

（十五）将第四十六条改为第四十四条，修改为：“违反本条例第十二条规定，实行排污许可重点管理和其他法定的应当披露生态环境信息的企业事业单位和其他生产经营者未按照规定公开生态环境信息的，由生态环境主管部门责令改正，处二万元以上二十万元以下的罚款；拒不改正的，责令限制生产、停产整治，并公告上述生态环境信息。”

（十六）删去第四十九条。

（十七）删去第五十一条。

（十八）将第五十四条改为第五十条，第一款修改为：“违反本条例第二十五条第一款第一项、第三项至第五项规定的，由城市管理综合执法、水行政、交通运输或者房屋征收等主管部门按照职责责令改正，处三万元以上十万元以下罚款；拒不改正的，责令停工整治；作出处罚决定的部门可以依法按日连续处罚。”

（十九）将第五十七条改为第五十三条，删去第一款。

第三款修改为：“违反本条例第三十三条第四款规定的，由城市管理综合执法部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

（二十）对部分条文作以下修改：

1.将第五条、第三十一条、第五十四条、第五十九条中的“水利”修改为“水行政”。

2.将第六条第一款中的“市、县（市、区）人民政府”修改为“各级人民政府及其有关部门”，“给予奖励”修改为：“按照国家和省有关规定给予表彰和奖励”。

3.将第十七条中的“市、县（市）人民政府”修改为“市人民政府”，在“液化石油气”前增加“页岩气”，将“等清洁能源”修改为“或者其他清洁低碳能源”。

4.将第二十三条第二款中的“绿色环保调度”修改为“重点行业环保绩效分级管理”，删去“绿色环保调度具体办法由市人民政府制定”。

5.将第三十一条第一款中的“重型柴油车”修改为“重型汽车”，在“非道路移动机械”前和“高排放机动车”后分别增加“船舶”，将“污染控制装置”修改为“排放控制系统”，在“鼓励和支持”前增加“或者采取其他有效措施”；在第二款“进行监督检查”前增加“排放控制系统运行情况”。

6.在第三十七条第三款“禁止在下列场所”前增加“本市各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。”

7.将第四十条、第四十一条、第五十九条、第六十条中的“应急”修改为“应对”。

8.将第四十七条第二款中的“三倍”修改为“五倍”。

9.将第四十八条中的“三倍”修改为“五倍”，在“高污染燃料的设施”后增加“并组织拆除”。

10.将第五十八条第三款中的“第三十七条第三款规定的”修改为“第三十五条第三款第一项、第二项、第三项规定的”，“予以关闭”修改为“责令关闭”。

二、对《安阳市卫河保护条例》作出修改

（一）将第一条修改为：“为了加强卫河流域水生态保护，防御、减轻洪涝灾害，推进生态文明建设和高质量发展，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国防洪法》、《中华人民共和国文物保护法》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第二十条第一款修改为：“市人民政府根据依法批准的流域水生态环境保护规划和实际需要，组织编制本行政区域的卫河水生态环境保护规划，并向社会公布。”

（三）对部分条文作以下修改：

1.删去第二十条第二款中的“流域”。

2.将第二十五条第一款中的“检测”修改为“监测”。

3.将第二十九条中的“环境影响评价”修改为“生态环境影响评价”。

4.将三十四条中的“水利”修改为“水行政”。

5.将第五十三条中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

三、对《安阳市城市市容和环境卫生管理条例》作出修改

（一）将第三十一条修改为“任何单位和个人不得损坏或者擅自关闭、闲置、拆除环境卫生收集、转运、处理设施。确有必要关闭、闲置或者拆除的，应当经市、县（市）、区城市市容和环境卫生主管部门同意，其中涉及生活垃圾处理设施的，应当依法商生态环境主管部门同意后核准，由建设单位按照先建后拆的原则负责重建，未建成替代设施的不得拆除。”

（二）删去第五十五条。

（三）对部分条文作以下修改：

1.将第三十五条中的“环境卫生专业”修改为“具备相应资质条件的”。

2.删去第五十三条中的“停用”，将“环境卫生设施”修改为“环境卫生收集、转运设施”。

3.将第五十六条中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

四、对《安阳市林州红旗渠保护条例》作出修改

（一）增加一条作为第二十九条：“违反本条例规定的其他行为，法律法规已有法律责任规定的，从其规定。”

（二）对部分条文作以下修改：

1.将第八条第三款中的“水利”修改为“水行政”，“国土”修改为“自然资源和规划”，“农业”修改为“农业农村”，“环保”修改为“生态环境”，“行政部门”修改为“部门”。

2.将第十六条中的“限期治理”修改为“依法处理”。

3.将第二十七条第二项中的“违反第（三）、（四）、（五）项规定的”修改为“违反第三项规定的”。

4.将第二十八条中的“负有责任的主管人员和其他直接责任人员依法给予行政处分”修改为“负有责任的领导人员和直接责任人员，依法给予处分”。

五、对《安阳市文明行为促进条例》作出修改

（一）将第二十七条中的“第十二条第二项至第五项”修改为“第十二条第二项至第四项”，删去“乱倒污水、厨余垃圾的”，将“五十元以上二百元以下罚款”修改为“一百元以上一千元以下罚款”。

（二）删去第二十九条。

（三）对部分条文作以下修改：

1.将第十二条第八项中的“减少废气、废水、固体废弃物等污染物排放”修改为“履行生活垃圾源头减量义务”。

2.将第三十二条中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

本决定自2026年8月15日起施行。

《安阳市大气污染防治条例》、《安阳市卫河保护条例》、《安阳市城市市容和环境卫生管理条例》、《安阳市林州红旗渠保护条例》、《安阳市文明行为促进条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
