# 厦门市人民代表大会常务委员会关于修改《厦门市环境保护条例》等两部法规和废止《厦门市城市供水节水条例》的决定

厦门市人民代表大会常务委员会
关于修改《厦门市环境保护条例》等两部法规
和废止《厦门市城市供水节水条例》的决定

（2026年8月27日厦门市第十六届人民代表大会常务委员会第三十八次会议通过　2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

厦门市第十六届人民代表大会常务委员会第三十八次会议决定：

一、对《厦门市环境保护条例》作出修改

（一）将第一条修改为：“为了保护生态环境，防治污染和其他公害，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，建设高颜值的生态花园之城，根据《中华人民共和国生态环境法典》和其他有关法律、法规，结合本市实际，制定本条例。”

（二）将第二条第一款改为两款，作为第二条第一款、第二款，修改为：“各级人民政府对本行政区域及其管理的海域的生态环境保护工作和生态环境质量负责。

“实行生态环境保护目标责任制和考核评价制度，落实领导干部自然资源资产离任审计制度。考核评价结果应当向社会公开。”

第二款改为第三款，修改为：“市、区人民政府应当每年向本级人民代表大会或者人民代表大会常务委员会报告本辖区生态环境状况和生态环境保护目标完成情况，对发生的重大生态环境事件应当及时向本级人民代表大会常务委员会报告，依法接受监督。”

（三）将第四条第一款修改为：“市生态环境主管部门在其职责范围内对全市生态环境保护工作实施统一监督管理。市生态环境主管部门派出机构在其职责范围内对辖区生态环境保护工作实施监督管理。”

增加一款，作为第二款：“市自然资源和规划主管部门在其职责范围内对全市自然资源开发利用和保护，以及国土空间开发保护工作实施监督管理。”

第二款改为第三款，修改为：“发展改革、工业和信息化、市政园林、农业农村、交通运输、港口、住房和建设、市场监督管理、公安、文化和旅游、商务、城市管理行政执法等有关部门在各自职责范围内对生态环境保护工作实施监督管理。”

第三款改为第四款，删去“机构和”。

（四）将第九条修改为：“市生态环境主管部门应当会同有关部门建立生态环境监测网络，组织开展生态环境质量监测、污染源监督性监测和突发生态环境事件的应急监测。

“市生态环境主管部门应当按照有关规定，每年确定实行排污许可重点管理的企业事业单位和其他生产经营者名录，并向社会公布。实行排污许可重点管理的企业事业单位和其他生产经营者应当按照有关规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，与生态环境主管部门联网，保证监测设备正常运行，保存原始监测记录，并对监测数据的真实性和准确性负责。”

（五）将第十条中的“具有相应资质”修改为“已依法备案”，“环境执法”修改为“生态环境执法”。

（六）将第十一条第一款中的“环境保护”修改为“生态环境保护”，第三款中的“商业秘密”修改为“商业秘密、个人隐私和个人信息”。

（七）将第十三条第二款中的“环境保护”修改为“生态环境保护”，“环境保护专职网格人员”修改为“生态环境网格员”，“环境违法”修改为“生态环境违法”，“环境监督”修改为“生态环境保护监督”。

（八）将第十五条中的“河（湖）长”修改为“河湖长”。

（九）删去第十七条第二款中的“现有的农业种植项目应当严格控制农药、化肥的使用，并逐步退出饮用水水源一级保护区”。

（十）将第二十二条第一款中的“海漂垃圾综合治理”修改为“海洋垃圾综合治理”，第二款中的“沙滩海漂垃圾”修改为“沙滩海洋垃圾”。

（十一）将第二十三条第一款中的“环境保护”修改为“生态环境保护”；第二款中的“农业农村主管部门”修改为“市、区人民政府及其农业农村等有关部门”，“施用”修改为“安全使用”。

（十二）将第二十四条修改为：“工程渣土等建筑垃圾应当进行资源化处理，具体办法由市人民政府制定。

“鼓励建设单位、施工单位优先采用建筑垃圾资源化处理产品。”

（十三）将第二十六条、第五十四条中的“排污单位”修改为“企业事业单位”；第三十一条、第三十二条中的“排污者”修改为“企业事业单位和其他生产经营者”。

（十四）将第三十三条第二款修改为：“船舶进入国家确定的船舶大气污染物排放控制区时，应当使用符合要求的燃油；船舶进港靠泊，具备岸电使用条件的，应当按照国家规定使用岸电，但是使用清洁低碳能源的除外。”

（十五）将第三十五条修改为：“产生污泥的单位和水体淤泥疏浚单位，应当按照国家规定的方式和标准对污泥进行安全处置，不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧污泥。”

（十六）将第三十六条第三款修改为：“存放工程渣土等建筑垃圾、建筑土方可能产生粉尘污染的物料，应当及时清运；在场地内存放的，应当采取封闭、覆盖、袋装以及其他有效粉尘污染防治措施。”

（十七）将第三十七条第二款中的“建设”修改为“住房和建设”，“资源规划”修改为“自然资源和规划”。

（十八）将第三十九条第一款中的“区域”修改为“时段和区域”。

（十九）将第四十条、第四十五条中的“住宅楼”修改为“居民住宅楼”，“商住楼”修改为“商住综合楼”。

（二十）将第四十一条第一项中的“油烟净化设施”修改为“油烟净化等污染防治设施”。

（二十一）将第四十二条修改为：“产生含挥发性有机物废气的生产和服务活动，应当在密闭空间或者设备中进行，并按照规定安装、使用污染防治设施；无法密闭的，应当采取废气逸散控制措施以及其他有效措施减少废气排放。”

（二十二）将第五十二条修改为：“企业事业单位和其他生产经营者应当按照国家有关规定，开展突发生态环境事件风险评估和应急资源调查，对生态环境风险和环境安全隐患进行排查，并制定相应的风险防控措施和应急预案。应急预案应当报生态环境主管部门备案，并做好应急准备，定期进行演练。

“在发生或者可能发生突发生态环境事件时，企业事业单位和其他生产经营者应当及时启动应急预案，采取防止危害扩大的必要措施，及时通报可能受到危害的单位和居民，并向市生态环境主管部门派出机构和应急管理等有关部门报告。”

（二十三）将第五十三条修改为：“市生态环境主管部门和其他负有生态环境保护监督管理职能的部门应当健全生态环境信息公开制度，依法公开生态环境信息。

“实行排污许可重点管理和其他法定的应当披露生态环境信息的企业事业单位和其他生产经营者应当按照有关规定公开污染物排放信息、温室气体排放信息等生态环境信息，接受社会监督，并对信息真实性负责。

“施工单位应当落实生态环境保护措施并予以公布。”

（二十四）增加一条，作为第五十八条：“法律、法规对不利于生态环境保护有关行为作出其他禁止性或者限制性规定的，从其规定。

“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（二十五）将第五十八条改为第五十九条，修改为：“有下列行为之一的，由市生态环境主管部门分别按照下列规定予以处罚：

“（一）违反本条例第四十二条规定，产生含挥发性有机物废气的生产和服务活动，未在密闭空间或者设备中进行的，未按照规定安装、使用污染防治设施的，或者未采取废气逸散控制措施以及其他有效措施减少废气排放的，责令改正，处二万元以上二十万元以下的罚款，拒不改正的，责令停产整治；

“（二）违反本条例第四十三条规定，从事服装干洗、机动车维修等服务活动，未设置异味和废气处理装置等污染防治设施并保持正常使用的，责令改正，处二千元以上二万元以下的罚款，拒不改正的，责令停业整治；

“（三）违反本条例第五十三条第二款规定，实行排污许可重点管理和其他法定的应当披露生态环境信息的企业事业单位和其他生产经营者不依法公开或者不如实公开污染物排放信息、温室气体排放信息等生态环境信息的，责令改正，处二万元以上二十万元以下的罚款，拒不改正的，责令限制生产、停产整治，并公告上述生态环境信息。

“违反本条例第二十八条第三款、第三十一条第一款和第三十二条第二款规定的，由市生态环境主管部门依法予以处罚。”

（二十六）将第五十九条改为第六十条，第一款第三项修改为：“违反本条例第三十九条第一款规定，露天烧烤食品或者为露天烧烤食品提供场地的，责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款，拒不改正的，处五千元以上二万元以下的罚款”；第四项中的“二万元”修改为“一万元”；增加四项，分别作为第五项、第六项、第七项、第八项，内容如下：

“（五）违反本条例第四十四条第一款规定，禁止时段在噪声敏感建筑物集中区域从事噪声、振动超标的经营、作业的，责令停止违法行为，限期改正，处二万元以上十万元以下的罚款，拒不改正的，可以责令暂停作业；

“（六）违反本条例第四十四条第二款规定，未按照规定取得连续进行建设施工作业证明的，责令停止违法行为，限期改正，处二万元以上十万元以下的罚款，拒不改正的，可以责令暂停作业；

“（七）违反本条例第四十四条第三款规定，中、高考前十五日内和考试期间在居住区、文教区以及居住、商业、工业混杂区从事产生噪声、振动超标活动的，责令停止违法行为，对单位处一万元以上五万元以下罚款，对个人处五百元以上二千元以下罚款；

“（八）违反本条例第四十五条第二款规定，在城市建成区的居民住宅楼（包括商住综合楼的住宅部分）从事产生噪声、振动的生产经营活动或者在商住综合楼新设可能产生噪声、振动超标的项目的，责令停止违法行为，限期改正，处二万元以上十万元以下的罚款，拒不改正的，可以责令暂停作业。”

第二款修改为：“违反本条例第四十一条、第四十五条第三款、第四十六条第二款规定的，由城市管理行政执法部门依法予以处罚。”

（二十七）将第六十条改为第六十一条，“处五千元以上二万元以下的罚款”修改为“处二千元以上二万元以下的罚款，拒不改正的，车辆不得上道路行驶”。

（二十八）删去第六十一条、第六十二条。

（二十九）将法规名称以及第三条、第六条、第七条、第十八条第二款、第三十一条第三款、第五十六条中的“环境”修改为“生态环境”。

（三十）将第十二条中的“环境保护”修改为“生态环境保护”，“环境法律”修改为“生态环境法律”；第十四条中的“环境监督”修改为“生态环境保护监督”，“环境问题”修改为“生态环境问题”；第二十八条中的“环境影响”修改为“生态环境影响”，“环境准入”修改为“生态环境准入”，“环境保护”修改为“生态环境保护”；第二十九条中的“环境影响”修改为“生态环境影响”，“环境保护”修改为“生态环境保护”；第五十四条第一款中的“环境保护”修改为“生态环境保护”，“环境监测”修改为“生态环境监测”；第五十五条中的“环境违法”修改为“生态环境违法”，“环境保护”修改为“生态环境保护”，“环境决策”修改为“生态环境决策”，“环境监督”修改为“生态环境保护监督”，“公民环境权益”修改为“公众生态环境权益”；第五十七条中的“环境公益诉讼”修改为“生态环境公益诉讼”。

二、对《厦门市市容环境卫生管理条例》作出修改

（一）将第四条第二款、第十五条第二款中的“规划”修改为“自然资源和规划”，“工商”修改为“市场监督管理”；第四条第二款中的“环保”修改为“生态环境”，“卫生”修改为“卫生健康”，“建设”修改为“住房和建设”，“海洋与渔业”修改为“海洋”，“交通”修改为“交通运输”。

（二）新增一条，作为第四十八条：“法律、法规对不利于市容环境卫生有关行为作出其他禁止性或者限制性规定的，从其规定。

“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（三）删去第四十八条第一项，将第四十八条中的“二百元以下罚款”修改为“一百元以上一千元以下罚款”。

（四）将第四十九条第二项、第五项、第六项中的“二百元以下罚款”修改为“一百元以上一千元以下罚款”，第四项中的“十元”修改为“一百元”，第六项中的“五十元以上五百元以下罚款”修改为“一百元以上一千元以下罚款”，第七项中的“可处以应缴生活垃圾处理费三倍以下”修改为“处以应缴生活垃圾处理费一倍以上三倍以下”。

三、废止《厦门市城市供水节水条例》

（2006年5月31日厦门市第十二届人民代表大会常务委员会第二十七次会议通过，2006年8月4日福建省第十届人民代表大会常务委员会第二十四次会议批准；根据2018年6月29日厦门市第十五届人民代表大会常务委员会第十四次会议《关于修改〈厦门市海域使用管理规定〉等五部法规的决定》修正，2018年9月30日福建省第十三届人民代表大会常务委员会第六次会议批准）

本决定自公布之日起施行。

《厦门市环境保护条例》、《厦门市市容环境卫生管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
