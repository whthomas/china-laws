# 福建省人民代表大会常务委员会关于废止《福建省沿海滩涂围垦办法》等六项地方性法规的决定

福建省人民代表大会常务委员会关于废止
《福建省沿海滩涂围垦办法》等六项
地方性法规的决定

（2026年7月24日福建省第十四届人民代表大会常务委员会第二十三次会议通过）

福建省第十四届人民代表大会常务委员会第二十三次会议决定废止六项地方性法规：

一、《福建省沿海滩涂围垦办法》

二、《福建省人民政府关于稳定山权林权若干具体政策的规定》

三、《福建省森林资源流转条例》

四、《福建省商品质量监督条例》

五、《福建省个体工商户和私营企业权益保护条例》

六、《福建省各级人民代表大会常务委员会信访条例》

本决定自公布之日起施行。
