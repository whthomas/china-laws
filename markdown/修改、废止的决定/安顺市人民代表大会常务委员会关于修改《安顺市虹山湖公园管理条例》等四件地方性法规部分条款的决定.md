# 安顺市人民代表大会常务委员会关于修改《安顺市虹山湖公园管理条例》等四件地方性法规部分条款的决定

安顺市人民代表大会常务委员会关于修改
《安顺市虹山湖公园管理条例》等四件
地方性法规部分条款的决定

（2026年6月29日安顺市第五届人民代表大会常务委员会第三十六次会议通过　2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

安顺市第五届人民代表大会常务委员会第三十六次会议决定，对下列地方性法规部分条款作出如下修改：

一、对《安顺市虹山湖公园管理条例》作出修改

（一）将第十九条第三项修改为：“（三）在水体清洗装贮过油类、有毒有害污染物的车辆或者容器；”

（二）将第二十五条修改为：“违反本条例第十八条规定的，由虹山湖公园管理机构或者有关行政主管部门按照下列规定予以处罚：

“（一）违反第三项、第五项、第七项、第八项规定的，给予警告，责令停止违法行为，限期恢复原状或者采取其他补救措施；情节严重的，处五十元以上五百元以下的罚款；

“（二）违反第四项规定的，说服教育，责令改正；拒不改正的，给予警告，对个人可以处二百元以上一千元以下的罚款，对单位可以处二千元以上二万元以下的罚款；

“（三）违反第九项规定的，给予警告，责令停止违法行为，采取其他补救措施；情节严重的，处五百元以上二千元以下的罚款；造成损失的，应当赔偿；

“（四）违反第十项、第十一项规定的，给予警告，责令停止违法行为，采取其他补救措施；情节严重的，处五百元以上五千元以下的罚款；造成损失的，应当赔偿；

“（五）违反第十三项规定的，责令改正，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭；

“（六）违反第十四项规定的，责令停止违法行为，限期恢复原状，没收违法所得，对单位处二万元以上二十万元以下的罚款，对个人处一千元以上一万元以下的罚款。”

（三）将第二十六条第二项修改为：“（二）违反第三项规定的，责令停止违法行为，采取治理措施消除污染，处二万元以上二十万元以下的罚款，可以责令采取限制生产、停产整治等措施；拒不采取治理措施的，可以指定有治理能力的单位代为治理，所需费用由违法者承担；情节严重的，报经有批准权的人民政府批准，责令停业、关闭；”

二、对《安顺市城镇绿化条例》作出修改

将第四十六条第三款修改为：“违反本条例第三十二条第八项规定的，对单位责令改正，拒不改正的，处五万元以上五十万元以下的罚款；对个人责令改正，处一百元以上一千元以下的罚款；造成损失的，应当承担赔偿责任。”

三、对《安顺市文明行为促进条例》作出修改

（一）将第一条修改为：“为了培育和践行社会主义核心价值观，铸牢中华民族共同体意识，传承和弘扬中华民族优秀传统文化，提升公民文明素养，促进社会文明进步，根据有关法律、法规的规定，结合本市实际，制定本条例。”

（二）将第十六条第七项修改为：“（七）禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质；”

（三）将第二十三条第六项修改为：“（六）随意倾倒和焚烧建筑、生活垃圾以及有毒、有害废弃物品；”

（四）将第三十五条修改为：“违反本条例第二十一条第一项规定的，由有关主管部门说服教育，责令改正；拒不改正的，给予警告，对个人可以处二百元以上一千元以下的罚款，对单位可以处二千元以上二万元以下的罚款。”

（五）将第三十六条修改为：“违反本条例第二十二条第一项、第二项、第四项、第五项、第六项规定的，行人、乘车人、非机动车驾驶人由公安交通管理部门处警告或者五元以上五十元以下的罚款；机动车驾驶人由公安交通管理部门处警告或者二十元以上二百元以下的罚款。”

四、对《安顺市亚鲁王非物质文化遗产保护条例》作出修改

将第四条修改为：“亚鲁王非物质文化遗产保护和传承工作实行保护为主、抢救第一、合理利用、传承发展的方针，坚持政府主导、社会参与的原则，体现铸牢中华民族共同体意识和促进民族团结进步的要求，注重真实性和整体性。”

本决定自2026年8月15日起施行。

《安顺市虹山湖公园管理条例》《安顺市城镇绿化条例》《安顺市文明行为促进条例》《安顺市亚鲁王非物质文化遗产保护条例》根据本决定作相应修改，部分条文按照立法技术规范作文字技术处理，条文顺序作相应调整，重新公布。
