# 孟村回族自治县人民代表大会关于废止《孟村回族自治县发展牛羊业条例》等两部单行条例的决定

孟村回族自治县人民代表大会关于废止
《孟村回族自治县发展牛羊业条例》等
两部单行条例的决定

（2026年7月19日孟村回族自治县第十八届人民代表大会第一次会议通过　2026年7月23日河北省第十四届人民代表大会常务委员会第二十二次会议批准）

孟村回族自治县第十八届人民代表大会第一次会议决定废止《孟村回族自治县发展牛羊业条例》和《孟村回族自治县清真食品管理条例》。

本决定自公布之日起生效。
