# 嘉峪关市人民代表大会常务委员会关于修改《嘉峪关市市容和环境卫生管理条例》《嘉峪关市绿化条例》的决定

嘉峪关市人民代表大会常务委员会关于修改
《嘉峪关市市容和环境卫生管理条例》
《嘉峪关市绿化条例》的决定

（2026年6月30日嘉峪关市第十一届人民代表大会常务委员会第三十五次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

嘉峪关市第十一届人民代表大会常务委员会第三十五次会议决定：

一、对《嘉峪关市市容和环境卫生管理条例》作出修改

（一）将第八条修改为：“任何单位和个人有权劝阻和举报破坏市容和环境卫生的行为。”

（二）删去第十五条第一款第四项。

将第十五条第二款修改为：“违反第一项、第四项、第五项规定的，由市城市管理执法部门责令改正；拒不改正的，可以处一千元以上五千元以下的罚款。”

将第三款修改为：“违反第二项、第三项规定的，由市城市管理执法部门责令改正；拒不改正的，处五十元以上二百元以下的罚款。”

（三）将第二十五条修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定路线行驶。违反规定的，由市城市管理执法部门责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。”

（四）删去第二十九条。

（五）删去第三十二条、第三十三条、第三十四条。

（六）删去第三十七条、第三十八条。

（七）删去第三十九条第四款。

（八）删去第四十条、第四十一条、第四十二条、第四十三条。

（九）将第四十八条改为第三十八条，修改为：“新建、改建、扩建工程时，施工单位或者建设单位应当按照规定设置水冲式临时厕所、垃圾收集容器和转运设备等环境卫生临时设施。建设工程竣工后，施工单位或者建设单位应当及时清除弃物弃料、临时厕所、垃圾收集容器等环境卫生临时设施。违反规定的，由市建设主管部门责令改正，并处五千元以上三万元以下罚款。”

（十）删去第五十条。

（十一）将第五十五条改为第四十四条，修改为：“市容和环境卫生主管部门应当对市容现状及各类垃圾、粪污无害化处理实行监测统计，并按照国家有关规定，配合生态环境主管部门定期向社会公布相关信息。”

（十二）将第五十七条改为第四十六条，修改为：“市城市管理执法部门、环境卫生主管部门等单位及其工作人员在市容和环境卫生管理工作中玩忽职守、滥用职权、徇私舞弊的，依法给予处分；构成犯罪的，依法追究刑事责任。”

二、对《嘉峪关市绿化条例》作出修改

（一）将第三十一条修改为：“水务、绿化行政主管部门应当合理配置生态绿化用水，优先使用符合标准要求的再生水，有序开展节水绿化。”

（二）将第三十四条第二项修改为：“在绿地内饲养动物、露营、搭棚；”

（三）删去第三十九条、第四十条、第四十六条。

本决定自2026年8月15日起施行。

《嘉峪关市市容和环境卫生管理条例》、《嘉峪关市绿化条例》根据本决定作相应修改，并对条文顺序作相应调整，重新公布。
