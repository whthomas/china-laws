# 陇南市人民代表大会常务委员会关于修改《陇南市饮用水水源地保护条例》《陇南市城乡环境卫生综合治理条例》的决定

陇南市人民代表大会常务委员会关于修改
《陇南市饮用水水源地保护条例》《陇南市
城乡环境卫生综合治理条例》的决定

（2026年6月12日陇南市第五届人民代表大会常务委员会第三十一次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

陇南市第五届人民代表大会常务委员会第三十一次会议决定：

一、对《陇南市饮用水水源地保护条例》作出修改

（一）将第一条修改为：“为了加强饮用水水源地保护，保障饮用水安全，维护人民群众身体健康和生命安全，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等法律、法规，结合本市实际，制定本条例。”

（二）将第七条第二款修改为：“市人民政府应当根据经济社会发展和饮用水水源地保护的实际需要，依法报请省人民政府调整饮用水水源保护区范围。”

（三）将第七条第三款修改为：“市人民政府依法确定的现有饮用水水源地不符合国家相关标准或者不能保障供水安全的，应当采取措施进行治理，经治理后仍不符合国家有关标准或者不能保障供水安全的，应当重新确定饮用水水源地。”

（四）将第十二条第一款修改为：“集中式饮用水水源保护区的划定，由生态环境主管部门会同有关部门进行科学论证，提出意见。市、县（区）集中式饮用水水源保护区的划定，由市、县（区）人民政府提出划定方案，报省人民政府批准。”

（五）将第十七条修改为：“在饮用水水源一级保护区、二级保护区以及准保护区内不得实施《中华人民共和国生态环境法典》等法律、法规规定的禁止性行为。”

（六）将第二十四条第五项修改为：“随意丢弃和处置农药包装物及清洗器械；”

（七）将第二十九条第一款修改为：“市、县（区）人民政府应当建立饮用水水质监测、信息共享及联动预警机制，组织生态环境、水行政、住房和城乡建设、卫生健康等部门至少每季度向社会公开一次饮用水安全状况信息。”

（八）删除第三十八条。

二、对《陇南市城乡环境卫生综合治理条例》作出修改

（一）将第一条修改为：“为了加强城乡环境卫生综合治理工作，创造和维护整洁、优美、文明、有序的城乡环境，保护人民身体健康，促进陇南经济社会高质量发展，根据《中华人民共和国生态环境法典》、国务院《城市市容和环境卫生管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第十八条第二款修改为：“城乡运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆和船舶应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定路线行驶。”

（三）将第十九条修改为：“施工现场应当按照规定设置隔离护栏、警示标志和施工公告牌。施工现场的材料、机具应当堆放整齐。施工中应当采取降尘、降噪等措施控制污染，产生的建筑废弃物应当按照规定清运。

暂时不能开工的建设用地，建设单位应当对裸露地面进行覆盖建设；超过三个月的，应当进行绿化、铺装或者遮盖。竣工后，应当及时清理和平整场地。”

（四）将第二十六条第一款修改为：“城乡生活垃圾推行单位、家庭和个人分类投放、村（社区）分类收集、乡（镇、街道）分类运输、县（区）分类处置的方式，村（居）民委员会或者村民小组应当有专人督促村（居）民开展生活垃圾分类投放。”

（五）将第二十七条第一款修改为：“市、县（区）人民政府应当对祭祀活动加强监督管理，引导城乡居民转变祭祀观念，改变祭祀方式，鼓励和倡导绿色、文明祭祀。”

本决定自2026年8月15日起施行。

《陇南市饮用水水源地保护条例》《陇南市城乡环境卫生综合治理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
