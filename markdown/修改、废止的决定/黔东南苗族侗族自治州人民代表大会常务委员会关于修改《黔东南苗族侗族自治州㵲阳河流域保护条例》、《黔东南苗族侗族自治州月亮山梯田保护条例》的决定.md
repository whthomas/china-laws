# 黔东南苗族侗族自治州人民代表大会常务委员会关于修改《黔东南苗族侗族自治州㵲阳河流域保护条例》、《黔东南苗族侗族自治州月亮山梯田保护条例》的决定

黔东南苗族侗族自治州人民代表大会
常务委员会关于修改《黔东南苗族侗族自治州
㵲阳河流域保护条例》、《黔东南苗族侗族
自治州月亮山梯田保护条例》的决定

（2025年10月30日黔东南苗族侗族自治州第十五届人民代表大会常务委员会第三十二次会议通过　2025年12月3日贵州省第十四届人民代表大会常务委员会第二十次会议批准）

黔东南苗族侗族自治州第十五届人民代表大会常务委员会第三十二次会议决定对《黔东南苗族侗族自治州㵲阳河流域保护条例》、《黔东南苗族侗族自治州月亮山梯田保护条例》作如下修改：

一、对《黔东南苗族侗族自治州㵲阳河流域保护条例》作出修改

（一）在第一条中的“《中华人民共和国水污染防治法》”后增加“《中华人民共和国长江保护法》”。

（二）删除第二十六条第一项中的“采沙”。

（三）增加一条作为第二十七条：“㵲阳河流域内的采砂活动，必须符合法律、法规有关采砂许可和禁采区、禁采期的相关规定，禁止任何单位和个人的非法采砂活动。”

（四）第二十九条修改为第三十条，第二款第二项修改为：“违法猎捕、运输、交易野生动物”。

（五）第三十四条修改为第三十五条，第一款修改为：“㵲阳河流域实行排污许可管理”，删除第三款。

（六）第三十八条修改为第三十九条，第三款修改为：“居民、村民在流域内新建住宅的，应当按照新的技术标准、技术规范同步建设污水处理设施，并限期改造原有住宅污水处理设施。”

（七）第四十二条改为第四十三条，将第三款中的“水行政”改为“生态环境”。

（八）第四十五条修改为第四十六条，第三款修改为：“禁止在河流等水体中网箱养殖；符合条件开展大水面养殖的，应当实行生态养殖。”

（九）第四十六条改为第四十七条，修改为：“在㵲阳河通航的船舶应当配备污水、废油、垃圾等污染物、废弃物收集设施，并持有合法有效的防止水域环境污染的证书与文书，进行涉污作业时如实记录操作情况，禁止向水体排放、弃置船舶污染物和废弃物。”

（十）第四十七条改为第四十八条，第一款修改为：“禁止在㵲阳河流域水上运输剧毒化学品和国家规定禁止通过内河运输的其他危险化学品。”

（十一）第四十八条改为第四十九条，第二款修改为：“㵲阳河流域水电站业主应当负责水库大坝管理保护范围内水域河面漂浮物的打捞，严禁向下游冲泄漂浮物。”

（十二）第五十二条改为第五十三条，修改为：“违反本条例第三十条第二款第一项、第三项规定的，由县级以上人民政府农业农村部门没收渔获物和违法所得，处以五万元以下的罚款；情节严重的，没收渔具，吊销捕捞许可证；情节特别严重的，可以没收渔船。”

（十三）第五十三条改为第五十四条，删除第二款中的“一百元以上”。

（十四）删除第五十五条。

二、对《黔东南苗族侗族自治州月亮山梯田保护条例》作出修改

（一）第十一条第二款中的“土地利用总体规划、城乡规划、月亮山自然保护区总体规划、从江加榜梯田湿地公园总体规划”修改为“国土空间规划、月亮山自然保护区总体规划、从江加榜梯田国家湿地公园总体规划”。

（二）第十三条修改为：“月亮山梯田保护范围分为月亮山自然保护区、从江加榜梯田国家湿地公园和梯田保护区。

“月亮山自然保护区的核心区、缓冲区以及从江加榜梯田国家湿地公园的保育区列为重点保护区域，重点保护区域以外的其他梯田保护范围列为一般保护区域。

“月亮山自然保护区、从江加榜梯田国家湿地公园和梯田保护区的具体范围，由自治州人民政府按照月亮山梯田保护与发展总体规划组织从江县、榕江县人民政府划定，并向社会公布。”

（三）删除第十四条。

（四）第十五条改为第十四条，修改为：“重点保护区域严格按照《中华人民共和国自然保护区条例》和《国家湿地公园管理办法》等法规执行。

“梯田保护区范围内的建设活动应当符合梯田保护与发展总体规划及相关规划。”

（五）第十六条、第十七条、第十九条、第二十条、第二十三条、第二十四条、第三十二条及第三十三条第二款中的“月亮山梯田保护区域”修改为“梯田保护区范围”。

（六）第十八条修改为第十七条，修改为：“梯田保护区范围内依法批准建设的建筑物、构筑物，其布局、外观设计和色彩应当与周边景观、环境相协调。”

（七）第二十一条修改为第二十条，第一款修改为：“梯田保护区范围内鼓励保护和利用特色动植物遗传资源。”

（八）第二十二条修改为第二十一条，第一款中的“月亮山梯田核心区、缓冲区内”修改为“梯田保护区范围内”。

（九）第二十六条、第二十七条、第二十八条合并为第二十五条，修改为：“梯田保护区范围内，禁止下列行为：（一）擅自改变梯田的农业用途；（二）弃耕抛荒；（三）占用耕地建窑、建坟或者擅自在耕地上建房、挖砂、采石、采矿、取土等；（四）侵占、损毁梯田灌溉设施；（五）建设生活垃圾填埋场和工业废物集中贮存、处置的设施、场所；（六）擅自倾倒、堆放、丢弃、遗撒固体废物；（七）擅自截流或者改变河流、溪流的自然状态；（八）法律、法规禁止的其他行为。”

（十）删除第二十九条。

（十一）第三十条改为第二十六条，第一款中的“月亮山梯田保护区域内”修改为“梯田保护区范围内”，删除第一款中的“政策”。

（十二）第三十三条修改为第二十九条，第二款修改为：“利用梯田文化景观资源、农作物季节性景观资源、民族特色村寨和传统村落景观资源等开展经营活动的单位、个人，应当与资源提供者建立收益分享机制或者补偿机制。”

（十三）删除第三十五条、三十六条、第三十七条、第四十条。

本决定自2025年12月15日起施行。

《黔东南苗族侗族自治州㵲阳河流域保护条例》、《黔东南苗族侗族自治州月亮山梯田保护条例》根据本决定修改后，重新公布。
