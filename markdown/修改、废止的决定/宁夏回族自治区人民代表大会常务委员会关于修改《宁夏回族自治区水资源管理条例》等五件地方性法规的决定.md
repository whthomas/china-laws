# 宁夏回族自治区人民代表大会常务委员会关于修改《宁夏回族自治区水资源管理条例》等五件地方性法规的决定

宁夏回族自治区人民代表大会常务委员会
关于修改《宁夏回族自治区水资源管理条例》
等五件地方性法规的决定

（2026年9月24日宁夏回族自治区第十三届人民代表大会常务委员会第二十七次会议通过）

宁夏回族自治区第十三届人民代表大会常务委员会第二十七次会议决定：

一、对《宁夏回族自治区水资源管理条例》作出修改

（一）将第二条、第四条第二款、第八条中的“开发、利用、节约、保护”修改为“保护、开发、利用、节约”。

（二）将第四条第一款、第六条第二款中的“开发、利用、节约和保护”修改为“保护、开发、利用、节约”。

（三）将第九条中的“由县级以上人民政府给予表彰和奖励”修改为“按照国家规定给予表彰和奖励”。

（四）将第十一条第一款修改为：“国民经济和社会发展规划、国土空间总体规划的编制以及重大产业政策的制定，应当与水资源条件和防洪要求相适应，并进行科学论证。”

（五）将第十四条第一款中的“鼓励开发、利用城市再生水、雨洪水、微咸水、矿井疏干水等”修改为“支持开发、利用再生水、集蓄雨水、矿井（坑）水、微咸水等非常规水”。

（六）将第二十一条中的“同时投产”修改为“同时投产使用”。

（七）将第二十三条修改为“工业和服务业企业应当采用先进适用节水技术、工艺和设备，增加循环用水次数，提高水的重复利用率。对取水工艺和设施落后，耗水量高，节水措施不力的企业，由水行政主管部门责令限期整改；逾期未整改的，核减其年计划用水总量。”

（八）删去第二十四条中的“支持雨洪水、再生水等非常规水资源利用”。

（九）将第二十七条、第三十五条中的“水环境”修改为“水生态环境”。

（十）将第二十八条中的“设区的市、县（市、区）人民政府”修改为“有关市、县人民政府”。

将第二款中的“批准并公告”修改为“批准”。

将第三款中的“跨设区的市、县（市、区）”修改为“跨市、县”；“批准并公告”修改为“批准”；“卫生、住房和城乡建设等主管部门提出方案，报自治区人民政府批准并公告”修改为“住房城乡建设、疾病预防控制等有关部门提出方案，征求有关部门的意见后，报自治区人民政府批准”。

（十一）将第三十条第二款修改为：“设区的市级以上人民政府生态环境主管部门应当对水功能区的水生态环境质量状况进行监测，发现水生态环境质量未达到要求的，应当及时报告有关人民政府采取治理措施。”

（十二）将第三十一条中的“县级以上”修改为“设区的市级以上”；“新建、改建或者扩大排污口”修改为“入河排污口”；

将第二款中的“在河流、湖泊、沟道设置排污口”修改为“入河排污口的设置”，将“防洪规划的要求”修改为“防洪要求”；

将第三款中的“确需在河流、湖泊、沟道新建、改建或者扩大排污口”修改为“新设、改设、扩大入河排污口”；

将第四款修改为：“水生态环境质量不达标的水功能区，除城乡污水集中处理设施等重要民生工程的入河排污口外，应当严格控制新设、改设、扩大入河排污口。”

（十三）将第三十二条中的“根据地下水分布及开采状况，划定地下水禁采区和限采区”修改为“统筹考虑地下水超采区划定、地下水利用情况以及地质环境条件等因素，依法组织划定本行政区域地下水禁止开采区、限制开采区”。

（十四）将第三十三条修改为：“单一水源供水城市的人民政府应当建设应急水源或者备用水源，有条件的地区可以开展区域联网供水。设区的市、县级人民政府应当组织编制饮用水安全突发事件应急预案。因饮用水水质发生重大变化，达不到饮用水标准，供水水量严重不足或者发生突发水污染事件，应当及时启动应急预案，启用应急备用水源。

“县级以上人民政府应当合理安排、布局农村饮用水水源，有条件的地区可以采取城镇供水管网延伸或者建设跨村、跨乡镇联片集中供水工程等方式，发展规模集中供水。”

（十五）将第三十四条中的“及时填封”修改为“实施封井或者回填”。

（十六）将第三十八条中的“《中华人民共和国水法》和《中华人民共和国水污染防治法》的规定”修改为“《中华人民共和国生态环境法典》、《中华人民共和国黄河保护法》和《中华人民共和国水法》等有关规定”；将第一项修改为：“（一）未经批准擅自新设、改设、扩大入河排污口的”。

二、对《宁夏回族自治区六盘山、贺兰山、罗山国家级自然保护区条例》作出修改

（一）将第三条修改为：“自然保护区所在地的县级以上人民政府林业草原主管部门负责本行政区域内自然保护区的监督管理工作。

“自然保护区所在地的县级以上人民政府自然资源、生态环境、水行政、农业农村、交通运输等有关部门在各自职责范围内负责自然保护区的有关监督管理工作。

“自然保护区管理机构按照工作职责，负责自然保护区的保护和管理工作。”

（二）将第四条修改为：“自然保护区所在地的县级以上人民政府应当加强对自然保护区建设的统筹协调，完善支持自然保护区建设的政策措施，将自然保护区建设纳入国民经济和社会发展相关规划。”

（三）将第五条修改为：“鼓励支持单位和个人依法参与自然保护区的保护、建设。”

（四）将第六条修改为：“自然保护区划分为核心保护区和一般控制区，实行分区管控。

“除《中华人民共和国自然保护区条例》和有关法律、行政法规规定或者国务院批准的人为活动外，自然保护区核心保护区内禁止人为活动。

“自然保护区一般控制区内仅允许开展《中华人民共和国自然保护区条例》和有关法律、行政法规规定或者国务院批准的人为活动。”

（五）将第七条修改为：“自然保护区主要保护对象是有代表性的自然生态系统和珍稀、濒危野生动植物物种等。”

（六）删去第八条、第十六条、第十七条、第十八条、第十九条、第二十条。

（七）将第九条改为第八条，修改为：“自然保护区内应当禁止或者限制引入外来物种；确需引入外来物种的，按照有关法律、法规规定办理。”

（八）将第十一条改为第十条，将其中的“由管理该自然保护区的人民政府给予补偿”修改为“由当地人民政府依法给予补偿”。

（九）将第十三条改为第十二条，修改为：“经批准在自然保护区内建设的工程项目，依法需要办理相关手续的，有关单位和个人应当依法办理。项目业主在项目实施期间应当服从自然保护区管理机构的监督和管理。”

（十）将第十五条改为第十四条，修改为：“自然保护区管理机构应当制定自然保护区突发事件应急预案，加强与所在地人民政府有关部门的协作配合，做好防灾减灾、安全管理和应急保障相关工作，提升应急保障能力。”

（十一）增加一条，作为第十五条：“违反本条例规定，法律法规已有法律责任规定的，从其规定；构成犯罪的，依法追究刑事责任。”

（十二）将第二十二条改为第十七条，修改为：“自然保护区管理机构及其工作人员违反本条例规定，有下列行为之一的，由自治区人民政府林业草原主管部门责令限期改正、恢复原状或者采取有效补救措施；对直接责任人员，依法给予处分：

“（一）未经批准，擅自将外来物种引入自然保护区的；

“（二）未经批准，擅自对自然保护区自然生态系统、野生动植物采取措施的；

“（三）未经批准，在自然保护区内建设工程项目的。”

（十三）将第二十三条改为第十八条，修改为：“县级以上人民政府及其有关部门、自然保护区管理机构工作人员在自然保护区保护和管理等工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分。”

三、对《宁夏回族自治区生态保护红线管理条例》作出修改

（一）在第一条中的“《中华人民共和国土地管理法》”前增加“《中华人民共和国生态环境法典》”，删去“《中华人民共和国环境保护法》”。

（二）将第七条修改为：“县级以上人民政府应当加强生态保护红线的宣传教育，健全公众参与机制。

“对在生态保护红线工作中做出显著成绩的单位和个人，按照国家规定给予表彰和奖励。”

（三）将第九条第一项中的“生态环境极敏感脆弱区域”修改为“生态极敏感脆弱区域”。

（四）将第十五条修改为：“生态保护红线内，在国家公园、自然保护区开展人为活动依照《中华人民共和国国家公园法》、《中华人民共和国自然保护区条例》有关规定执行；其他区域严格禁止开发性、生产性建设活动，在符合法律法规和国家规定的前提下，可以从事对生态功能不造成破坏的有限人为活动，具体按照国家有关规定和政策执行。”

（五）删去第十七条第一款中的“根据法律法规和国家有关规定”。

四、对《宁夏回族自治区绿色建筑发展条例》作出修改

（一）将第六条中的“县级以上人民政府应当给予表彰奖励”修改为“按照国家规定给予表彰和奖励”。

（二）将第七条第二款修改为“绿色建筑等级和相关技术指标纳入国土空间详细规划”。

（三）删去第八条。

（四）将第二十四条中的“编制改造规划和年度计划”修改为“编制改造计划”。

（五）删去第二十九条第二款中的“应当编制雨水利用专项规划”。

（六）删去第三十三条第二款中的“和自治区”、第四十二条中的“或者选用列入国家和自治区禁止使用目录的技术、工艺、材料和设备”、第四十四条中的“编制绿色建筑监理方案或者未按照绿色建筑监理方案”。

（七）删去第四十一条第二项、第四十三条第二项、第四十五条。

五、对《宁夏回族自治区实施〈中华人民共和国水土保持法〉办法》作出修改

（一）将第四条第一款中的“并将水土保持规划确定的任务纳入年度计划”修改为“并将水土保持任务纳入年度计划”；

将第二款中的“县级以上人民政府”修改为“各级人民政府”。

（二）删去第七条。

（三）删去第八条中的“工业园区开发、国土整治、农林综合开发、旅游开发”；在“公共服务设施建设等方面的规划”后增加“以及重大产业和工程布局等实施方案”；将“规划编制部门应当在规划中设立水土保持专章，提出水土流失预防和治理措施”修改为“规划的组织编制机关应当在规划中提出水土流失预防和治理的对策和措施”。

（四）将第十条第四项中的“沼气、节柴灶”修改为“生物质能”。

（五）将第十一条第二款中的“挖甘草”修改为“或者滥挖甘草、麻黄”。

（六）将第十二条第一款修改为：“禁止在二十五度以上陡坡地开垦种植农作物。在二十五度以上陡坡地种植经济林的，应当科学选择树种，合理确定规模，采取水土保持措施，防止造成水土流失。禁止开垦的陡坡地的范围由县级人民政府划定并公告。”

将第二款中的“应当按照国家有关规定退耕，植树种草”修改为“应当按照国家规定进行生态修复”。

（七）删去第十六条中的“根据水土保持规划”。

（八）将第二十二条中的“滑坡危险区和泥石流易发区”修改为“滑坡危险区或者泥石流易发区”。

（九）将第二十三条中的“挖甘草”修改为“滥挖甘草、麻黄”；“没有违法所得的，处五万元以下罚款”修改为“没有违法所得的，可以处五万元以下罚款”。

本决定自公布之日起施行。

《宁夏回族自治区水资源管理条例》、《宁夏回族自治区六盘山、贺兰山、罗山国家级自然保护区条例》、《宁夏回族自治区生态保护红线管理条例》、《宁夏回族自治区绿色建筑发展条例》、《宁夏回族自治区实施〈中华人民共和国水土保持法〉办法》根据本决定作相应修改（并对条文顺序作相应调整），重新公布。
