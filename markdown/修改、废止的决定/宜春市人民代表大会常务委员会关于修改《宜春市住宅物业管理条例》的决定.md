# 宜春市人民代表大会常务委员会关于修改《宜春市住宅物业管理条例》的决定

宜春市人民代表大会常务委员会
关于修改《宜春市住宅物业管理条例》的决定

（2025年12月10日宜春市第五届人民代表大会常务委员会第三十三次会议通过　2026年3月26日江西省第十四届人民代表大会常务委员会第二十二次会议批准）

宜春市第五届人民代表大会常务委员会第三十三次会议决定对《宜春市住宅物业管理条例》作如下修改：

一、将第五条第一款第三项修改为：“建筑物及其附属设施的维修资金交存、使用的监督管理。”

二、删去第七条第一款第五项、第六项。

三、删去第二十一条、第二十八条。

四、将第二十四条修改为第二十三条，并删去第三款。

五、将第四十条修改为第三十八条，并删去第二款。

六、将第五十四条修改为第五十二条，并删去第一款、第四款中的“或者其授权的业主委员会”，将第二款中的“或者其授权的业主委员会”修改为“、物业服务人”。

七、将第六十一条修改为第五十九条，第二项修改为：“不按要求移交资料和财物的，责令限期改正；逾期不改正的，予以通报，处一万元以上十万元以下罚款。”

本决定自公布之日起施行。

《宜春市住宅物业管理条例》根据本决定作相应修改并对条款顺序作相应调整后，重新公布。
