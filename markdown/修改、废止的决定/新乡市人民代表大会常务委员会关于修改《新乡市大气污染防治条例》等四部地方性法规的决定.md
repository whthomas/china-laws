# 新乡市人民代表大会常务委员会关于修改《新乡市大气污染防治条例》等四部地方性法规的决定

新乡市人民代表大会常务委员会关于修改
《新乡市大气污染防治条例》等四部
地方性法规的决定

（2026年6月30日新乡市第十四届人民代表大会常务委员会第三十四次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

新乡市第十四届人民代表大会常务委员会第三十四次会议决定：

一、对《新乡市大气污染防治条例》作出修改

（一）将第一条修改为：“为了保护和改善大气环境，防治大气污染，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，全面推进美丽新乡建设，加快推进人与自然和谐共生的现代化，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（三）将第八条修改为：“严格落实生态环境保护目标责任制和考核评价制度。将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。

“对在防治大气污染、保护和改善大气环境方面取得显著成绩的单位和个人，按照国家和省有关规定给予表彰和奖励。”

（四）将第十二条第二款中的“限制部分机动车行驶、停止工地土石方作业和建筑物拆除施工”修改为“限制部分机动车行驶和非道路移动机械使用、禁止燃放烟花爆竹、停止工地土石方作业和建筑物拆除施工、停止露天烧烤”。

（五）将第十九条第二款修改为：“生产、使用含挥发性有机物的原辅材料和产品，应当按照国家规定，在密闭空间、设备中进行并安装、使用污染防治设施，或者采取有效措施减少废气排放。”

（六）将第二十条修改为：“加油站、储油库和使用油罐车、铁路罐车等相关单位，应当按照国家规定安装油气回收装置并保持正常使用。

“禁止生产、进口或者销售不符合标准的机动车船、非道路移动机械用燃料和氮氧化物还原剂；禁止向机动车、非道路移动机械和内河船舶销售非机动车船用燃料；禁止机动车、非道路移动机械和内河船舶使用非机动车船用燃料。”

（七）将第二十二条第一款中的“按照国家和省有关规定”修改为“按照规定”；将“在用机动车排放大气污染物超过标准的”修改为“在用机动车、非道路移动机械等排放大气污染物超过标准的”；将“大气污染物排放仍不符合国家在用机动车排放标准的”修改为“大气污染物排放仍不符合国家排放标准的”。

在第二款中的“污染物排放状况”后增加“、排放控制系统运行情况”，将“遥感”修改为“非接触式道路”。

（八）删去第二十五条。

（九）将第二十八条第三款修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶、树枝、枯草等产生烟尘污染的物质。”

（十）增加一款，作为第三十一条第一款：“市、县（市、区）人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。”

将第一款修改为：“排放油烟污染物的餐饮服务业经营者，应当按照规定安装并正常使用油烟净化等污染防治设施，采取有效措施，确保污染物达标排放，并防止对附近居民的正常生活环境造成污染。大型餐饮服务单位应当安装油烟净化等污染防治设施在线监控，并与主管部门监控信息平台联网；位于环境敏感区的中、小型餐饮服务单位，限期安装油烟净化等污染防治设施在线监控。”

（十一）增加一条，作为第三十二条：“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（十二）删去第三十四条。

（十三）将第三十六条修改为：“违反本条例第二十七条第三款规定，在禁止焚烧的区域和时段露天焚烧秸秆、落叶、树枝、枯草等产生烟尘污染的物质的，由市、县（市、区）人民政府确定的监督管理部门责令改正，可以处五百元以上二千元以下的罚款。”

（十四）将第三十八条修改为：“违反本条例第二十九条规定，在禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地的，由城市管理部门或者其他有监管职责的部门责令改正，没收烧烤工具和违法所得，并处以五百元以上五千元以下罚款；拒不改正的，处以五千元以上二万元以下罚款。”

（十五）将第三十九条修改为：“违反本条例第三十条规定，排放油烟的餐饮服务业经营者未安装油烟净化等污染防治设施，未保持正常使用油烟净化等污染防治设施，或者未采取其他油烟净化措施，致使超过排放标准排放油烟污染物的，由市、县（市、区）人民政府确定的监督管理部门责令改正，处以五千元以上五万元以下罚款；拒不改正的，责令停业整治。

“在居民住宅楼、未配套设立专用烟道的商住综合楼、商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目的，由城市管理部门责令改正；拒不改正的，责令关闭，并处以一万元以上十万元以下罚款。”

（十六）对部分条文作以下修改：

1.将第十条、第十四条、第十六条中的“清洁能源”修改为“清洁低碳能源”。

2.将第十二条、第十三条中的“应急”修改为“应对”。

3.删去第十六条中的“民用”。

4.将第三十条中的“划定的禁止区域”修改为“禁止的时段和区域”。

二、对《新乡市北部矿山生态保护与修复条例》作出修改

（一）将第一条修改为：“为了保护和修复北部矿山生态环境，推进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国矿产资源法》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“北部矿山生态保护与修复应当遵循自然恢复为主、自然恢复与人工修复相结合的方针，坚持因地制宜、系统治理、生态优先、绿色发展、公众参与、损害担责的原则。”

（三）删去第六条第一款中的“统一”。

（四）将第八条修改为：“市、北部矿山所在地县级人民政府自然资源和规划部门应当会同有关部门将北部矿山生态保护与修复相关工作纳入国土空间生态修复规划。”

（五）删去第九条。

（六）将第十条中的“北部矿山生态保护与修复规划”修改为“国土空间生态修复规划”。

（七）删去第十一条第三项。

增加一项，作为第四项：“（四）法律、法规规定的其他禁止开采区域。”

（八）将第十四条修改为：“矿产资源开发企业应当采取集中收集处理、密闭、围挡、遮盖、清扫、洒水等措施，控制、减少粉尘和气态污染物的排放。”

（九）将第十九条修改为：“矿产资源开发企业应当按照有关规定提取矿山生态修复费用，专门用于矿山生态修复。矿山生态修复费用计入成本。

“矿产资源开发企业应当履行矿山生态修复义务，按照经批准的矿山生态修复方案进行矿山生态修复。能够边开采、边修复的，应当边开采、边修复；能够分区、分期修复的，应当分区、分期修复；不能边开采、边修复或者分区、分期修复的，应当在矿山闭坑前或者闭坑后的合理期限内及时修复。”

（十）将第三十一条修改为：“违反本条例第十三条规定，矿产资源开发企业未采取集中收集处理、密闭、围挡、遮盖、清扫、洒水等措施，控制、减少粉尘和气态污染物排放的，由生态环境部门责令改正，处以二万元以上二十万元以下罚款；拒不改正的，责令停产整治。”

（十一）将第三十三条修改为：“违反本条例第十八条第二款规定，不履行矿山生态修复义务或者未按照经批准的矿山生态修复方案进行矿山生态修复的，由自然资源和规划部门责令改正，可以处矿山生态修复所需费用二倍以下罚款；拒不改正的，处矿山生态修复所需费用二倍以上五倍以下罚款，由自然资源和规划部门确定有关单位代为修复，所需费用由矿产资源开发企业承担。”

三、对《新乡市城市建筑垃圾管理条例》作出修改

（一）将第一条修改为：“为了加强城市建筑垃圾管理，维护城市市容环境卫生，保护和改善生态环境，促进经济社会高质量发展，根据《中华人民共和国生态环境法典》、《城市市容和环境卫生管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第十条第四项修改为“采取覆盖、分段作业、择时施工、洒水抑尘、冲洗地面和车辆等有效防尘降尘措施”。

（三）删去第十七条中的“、第四项”。

（四）将第十八条中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

四、对《新乡市卫河保护条例》作出修改

（一）将第一条修改为：“为了加强卫河流域生态环境保护，防御、减轻洪涝灾害，推动高质量发展，实现人与自然和谐共生，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国防洪法》、《中华人民共和国文物保护法》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第二十一条第一款修改为：“市人民政府根据依法批准的流域水生态环境保护规划和实际需要，组织编制本行政区域卫河水生态环境保护规划，并向社会公布。”

（三）将第三十二条修改为：“市、卫河流域县级人民政府应当制定本行政区域的突发生态环境事件应急预案并按照规定备案。

“可能发生水污染事故的企业事业单位，应当制定有关水污染事故的应急预案，做好应急准备，并定期组织演练。

“生产、经营、储存、运输危险化学品的企业事业单位，应当采取必要措施，防止在处理安全生产事故过程中产生的可能严重污染水体的消防废物直接排入卫河。”

（四）删去第五十一条。

（五）对部分条文作以下修改：

1.删去第二十一条第二款中的“卫河流域县级”，将第二款、第三款中的“卫河流域”修改为“卫河”。

2.将第二十五条、第三十条中的“市、卫河流域县级生态环境主管部门”，第三十一条中的“卫河流域县级生态环境主管部门”，第五十二条中的“市人民政府生态环境主管部门”修改为“生态环境主管部门”。

3.将第三十条第二款中的“畜禽粪便污水”、第三款中的“畜禽粪便、污水”修改为“畜禽粪污”。

4.将第五十四条中的“直接负责的主管人员和其他直接责任人员”修改为“负有责任的领导人员和直接责任人员”。

本决定自2026年8月15日起施行。

《新乡市大气污染防治条例》、《新乡市北部矿山生态保护与修复条例》、《新乡市城市建筑垃圾管理条例》、《新乡市卫河保护条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
