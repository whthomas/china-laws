# 荆州市人民代表大会常务委员会关于集中修改涉及生态环境法典地方性法规的决定

荆州市人民代表大会常务委员会关于集中修改
涉及生态环境法典地方性法规的决定

（2026年6月25日荆州市第六届人民代表大会常务委员会第三十六次会议通过　2026年7月30日湖北省第十四届人民代表大会常务委员会第二十五次会议批准）

荆州市第六届人民代表大会常务委员会第三十六次会议决定：

一、对《荆州古城保护条例》作出修改

（一）删去第三十六条第一款中的“第四项”。

（二）删去第三十八条中的“行政”。

二、对《荆州市文明行为促进条例》作出修改

（一）删去第三十七条第一项中的“乱扔果皮纸屑等废弃物”。

（二）删去第四十一条中的“行政”。

三、对《荆州市扬尘污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第十二条第五项中的“绿化和铺装”修改为“绿化、铺装或者遮盖”。

（三）将第十七条修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料，应当符合下列扬尘污染防治要求：

“（一）运输车辆采取密闭或者其他有效措施防止物料遗撒；

“（二）运输车辆安装定位装置，按照规定的路线和时间行驶；

“（三）在规定的场所倾倒物料，装卸物料应当采取密闭或者喷淋等方式防治扬尘污染。”

（四）将第二十二条修改为：“重度污染天气条件下，相关单位应当根据市人民政府发布的重污染天气预警等级和应对预案，采取停止工地土石方作业和建筑物拆除施工等扬尘管理控制应对措施。”

（五）在第三十条中的“处五万元以上十万元以下罚款”后增加“拒不改正的，责令停工整治或者停业整治”。

（六）将第三十一条修改为：“违反本条例第十七条第一项、第二项规定，运输车辆未采取密闭或者其他措施防止物料遗撒，或者未按照规定的路线和时间行驶的，由城市管理部门责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。”

四、对《荆州市人民代表大会常务委员会关于加强生物多样性协同保护的决定》作出修改

将决定中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

五、对《荆州市长湖保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第七条修改为：“市人民政府应当完善长湖流域生态保护补偿机制，依法制定生态保护补偿办法，对按照规定或者约定开展生态环境保护的地区、单位和个人予以补偿。”

（三）将第十条第一款修改为：“人民检察院或者法律规定的社会组织对污染长湖流域水环境、破坏长湖流域水生态等损害社会公共利益的行为，依法提起诉讼。”

将第二款中的“支持检察机关”修改为“人民检察院”，删去“行政公益”。

（四）将第十八条第一款中的“环境影响评价”修改为“生态环境影响评价”。

（五）删去第二十六条第一款中的“限养区和适养区”。

（六）将第二十七条中的“水产养殖尾水排放应当符合水环境管理要求，不得直接排放和污染生态环境”修改为“水产养殖尾水排放应当符合污染物排放标准，防止污染水环境”。

（七）将第三十条第一款中的“保障城乡生活用水和生态用水，科学安排生产用水”修改为“优先满足城乡居民生活用水，保障基本生态用水、粮食安全用水，统筹农业、工业、生态修复用水等需要”。

（八）将第四十四条第一项修改为：“（一）在水体清洗装贮过油类、有毒有害污染物的车辆或者容器的，责令停止违法行为，采取治理措施消除污染，处二万元以上二十万元以下罚款，可以责令采取限制生产、停产整治等措施；拒不采取治理措施的，可以指定有治理能力的单位代为治理，所需费用由违法者承担；情节严重的，报经有批准权的人民政府批准，责令停业、关闭”。

六、对《荆州市沮漳河流域保护条例》作出修改

（一）将第一条中的“《中华人民共和国水法》、《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》、《中华人民共和国水法》”。

（二）将第九条修改为：“市、区人民政府编制本行政区域的水生态环境保护规划，应当与沮漳河流域水生态环境保护规划相衔接。”

（三）将第十三条中的“保障基本生态用水，统筹农业、工业用水等需求”修改为“保障基本生态用水、粮食安全用水，统筹农业、工业、生态修复用水等需要”。

（四）将第二十三条第一款中的“工业集聚区”修改为“工业园区等区域”，“监测系统”修改为“监控设备”。

第二款修改为：“向污水集中处理设施排放工业废水的，应当按照国家规定进行预处理，达到集中处理设施处理工艺要求后，方可排放。”

（五）将第四十条中的“支持法律规定的机关和有关组织”修改为“人民检察院或者法律规定的社会组织”。

（六）将第五十条修改为：“违反本条例第二十八条第二款规定，排放不符合标准的水产养殖尾水的，由生态环境主管部门责令改正，处十万元以上一百万元以下罚款，可以责令限制生产、停产整治；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

七、对《荆州市养犬管理条例》作出修改

将第二十九条第五项修改为：“（五）违反本条例第二十条第一款第二项规定，重点管理区内未采取有效措施制止犬吠，影响他人的，说服教育，责令改正；拒不改正的，予以警告，对个人可以处二百元以上一千元以下罚款，对单位可以处二千元以上二万元以下罚款”。

八、对《荆州市餐饮服务业油烟污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）在第七条中的“油烟”后增加“异味、废气”。

（三）在第十九条中的“油烟”后增加“异味、废气”，将“予以关闭”修改为“责令关闭”。

（四）将第二十一条中的“并处五百元以上二万元以下罚款”修改为“并处五百元以上五千元以下罚款；拒不改正的，处五千元以上二万元以下罚款”。

本决定自公布之日起施行。

相关法规根据本决定作相应修改，条款顺序作相应调整，并重新公布。
