# 濮阳市人民代表大会常务委员会关于修改《濮阳市大气污染防治条例》等九部地方性法规的决定

濮阳市人民代表大会常务委员会
关于修改《濮阳市大气污染防治条例》等
九部地方性法规的决定

（2026年6月26日濮阳市第九届人民代表大会常务委员会第二十七次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

濮阳市第九届人民代表大会常务委员会第二十七次会议决定：

一、对《濮阳市大气污染防治条例》作出修改

（一）将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，全面推进美丽濮阳建设，加快推进人与自然和谐共生的现代化，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）第二条增加一款，作为第二款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（四）将第六条修改为：“严格落实生态环境保护目标责任制和考核评价制度。将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。”

（五）将第十条修改为：“新建、改建、扩建对大气环境有影响的项目，应当依法进行生态环境影响评价，除国家规定不予公开的情形外，生态环境影响报告书应当全文公开。

“建设项目的生态环境影响报告书、生态环境影响报告表未依法经审批部门审查或者审查后未予批准的，或者未经原审批部门重新审核同意的，建设单位不得开工建设。”

（六）将第十四条改为第十三条，修改为：“市、县（区）人民政府应当制定重污染天气应对预案，向社会公布并向上一级人民政府生态环境主管部门备案。

“市、县（区）人民政府应当根据重污染天气预警等级，及时启动应对预案，根据应对需要采取责令有关企业停产或者限产、限制部分机动车行驶和非道路移动机械使用、禁止燃放烟花爆竹、停止工地土石方作业和建筑物拆除施工、停止露天烧烤、停止幼儿园和学校组织的户外活动、组织开展人工影响天气作业等应对措施。

“应对响应结束后，市、县（区）人民政府应当及时开展应对预案实施情况的评估，适时修改完善应对预案。

“纳入重污染天气应对预案的企业事业单位应当根据重污染天气预案要求编制应对响应操作方案，并按照规定采取相应的应对措施。”

（七）将第十八条改为第十七条，修改为：“市、县（区）人民政府应当采取措施，加强散煤使用管理，逐步减少煤炭使用量。开展城中村、城乡结合部和农村地区散煤治理，推行清洁低碳能源替代原煤散烧。

“鼓励、支持采取清洁低碳能源、集中供热替代等措施防治燃用散煤造成大气污染。”

（八）将第十九条改为第十八条，修改为：“市、县（区）人民政府应当按照国家和省规定，淘汰、拆除不符合大气污染防治标准或者要求的锅炉。

“市、县（区）人民政府市场监督管理部门会同生态环境主管部门对锅炉生产、进口、销售、使用环节执行大气污染防治标准或者要求的情况进行监督检查；不符合大气污染防治标准或者要求的，不得生产、进口、销售或者使用。”

（九）将第二十条改为第十九条，第二款修改为：“除热电联产外，严格控制新建燃煤发电项目。具备稳定热源的集中供热区域和联片采暖区域内的热力用户，应当使用集中供应的热源，不得新建、扩建分散的燃煤供热锅炉。”

（十）将第二十一条改为第二十条，修改为：“市人民政府可以划定并公布高污染燃料禁燃区，根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。

“在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施；已建成的，应当按照市人民政府规定的期限改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”

（十一）将第二十四条改为第二十三条，修改为：“石油、化工、电力、建材、有色金属、制药等企业和其他工业生产企业，应当加强大气污染物排放精细化管理，采取集中收集处理等措施，严格控制粉尘和气态污染物的排放。

“工业生产企业应当采取密闭、围挡、遮盖、清扫、洒水等处理措施，严格控制生产过程以及内部物料堆存、传输、装卸等环节产生的粉尘和气态污染物的排放。”

（十二）将第二十五条改为第二十四条，修改为：“下列生产、使用含挥发性有机物的原辅材料和产品的活动，应当按照国家规定，在密闭空间、设备中进行并安装、使用污染防治设施，或者采取有效措施减少废气排放：

“（一）石化、煤化工等含挥发性有机物原料的生产；

“（二）燃油、溶剂的储存、运输和销售；

“（三）涂料、油墨、胶粘剂、农药等以挥发性有机物为原料的生产；

“（四）涂装、印刷、粘合、工业清洗等含挥发性有机物的产品使用；

“（五）其他生产、使用含挥发性有机物的原辅材料和产品的活动。”

（十三）将第二十七条改为第二十六条，修改为：“石油、化工及其他生产、使用有机溶剂的企业应当建立泄漏检测与修复体系，对管道、设备等进行日常检修、维护，减少物料泄漏，及时收集处理泄漏物料，加强生产、输送、进出料、干燥以及采样等易泄漏环节的密闭性和安全性，对无组织排放的挥发性有机物废气应当进行收集和有效处理，对有组织排放的挥发性有机物废气应当进行回收利用或者进行催化燃烧、热力焚烧，提高有机废气净化效率。

“储油库、加油站、原油成品油运输油罐车、铁路罐车等，应当按照国家规定配套安装油气回收装置并保持正常使用。

“鼓励生产、进口、销售、使用低毒、低挥发性有机物含量的原辅材料和产品，工业涂装企业等应当按照规定使用低挥发性有机物含量的原辅材料和产品。”

（十四）将第三十条改为第二十九条，修改为：“在本市销售、办理注册登记的机动车、非道路移动机械及其发动机应当符合省执行的污染物排放标准。

“在用机动车、非道路移动机械等排放大气污染物超过标准的，应当进行维修；经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。

“鼓励、支持高排放机动车船、非道路移动机械等提前报废。”

（十五）将第三十三条改为第三十二条，第一款修改为：“建设单位应当将扬尘污染防治费用列入工程造价，在施工合同中明确施工单位的扬尘污染防治责任。”

（十六）将第三十七条改为第三十六条，修改为：“禁止在人口集中地区、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。

“各级人民政府应当科学精准加强秸秆、落叶等焚烧的组织、指导和管理，建立网格化监管制度。”

（十七）将第三十九条改为第三十八条，修改为：“禁止在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。”

（十八）将第四十条改为第三十九条，修改为：“各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

“禁止在下列场所新建、改建、扩建产生油烟、异味、废气的餐饮服务项目：

“（一）居民住宅楼；

“（二）未配套设立专用烟道的商住综合楼；

“（三）商住综合楼内与居住层相邻的商业楼层。

“排放油烟污染物的餐饮服务业经营者，应当按照规定安装油烟净化等污染防治设施并保证正常使用；采取有效措施确保油烟达标排放，并防止对附近居民的正常生活环境造成污染；不得将油烟废气排入地下管道。

“任何单位和个人不得在当地人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。在划定的特定场地内设置的露天烧烤饮食摊点，应当使用环保餐饮灶具，不得使用高污染燃料。”

（十九）将第四十一条改为第四十条，第一款修改为：“禁止生产、销售或者燃放不符合质量标准的烟花爆竹。任何单位和个人不得在县级以上人民政府禁止的时段和区域燃放烟花爆竹。”

（二十）将第四十三条改为第四十二条，修改为：“违反本条例第九条第二款规定，通过偷排、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放大气污染物的，由生态环境主管部门责令改正，处十万元以上一百万元以下的罚款，责令限制生产、停产整治，并将案件移送公安机关，由公安机关依法处罚；情节严重的，吊销排污许可证，报经有批准权的地方人民政府批准，责令停业、关闭，并由公安机关依法处罚。”

（二十一）将第四十六条改为第四十五条，修改为：“违反本条例第二十三条第二款、第二十四条、第二十六条规定的，由生态环境主管部门责令改正，处二万元以上二十万元以下罚款；拒不改正的，责令停产整治。”

（二十二）将第四十八条改为第四十七条，修改为：“违反本条例第三十六条第一款规定，在禁止焚烧的区域和时段露天焚烧秸秆、落叶等产生烟尘污染的物质的，由市、县（区）人民政府确定的监督管理部门责令改正，可以处五百元以上二千元以下罚款。”

（二十三）删去第九条第一款、第十二条。

（二十四）对部分条文作以下修改：

1.第五条删去第一款中的“市人民政府”，将第二款中的“市场监督管理”修改为“市场监管”。

2.将第十五条改为第十四条，将“清洁能源”修改为“清洁低碳能源”。

3.将第十六条改为第十五条，将“环评”修改为“生态环境影响评价”。

4.将第二十六条改为第二十五条，将“三年”修改为“五年”。

5.将第三十一条改为第三十条，删去第一款中的“省有关”；删去第二款中的“市人民政府”，在“污染物排放状况”后增加“排放控制系统运行情况”，将“遥感监测等”修改为“非接触式道路监测等技术”；在第三款中的“维修地”后增加“和重型汽车使用地”，在“排放状况”后增加“排放控制系统运行情况”。

6.将第四十四条改为第四十三条，将“违反本条例第十四条第二款规定”修改为“违反本条例第十三条第二款规定”，将“应急”修改为“应对”，将“二万元”修改为“一万元”。

7.将第四十五条改为第四十四条，将“违反本条例第二十一条第二款规定”修改为“违反本条例第二十条第二款规定”，删去“市人民政府”，在“高污染燃料的设施”后增加“并组织拆除”，将“五万元”修改为“二万元”。

8.将第四十七条改为第四十六条，将“违反本条例第二十九条规定”修改为“违反本条例第二十八条规定”。

9.将第四十九条改为第四十八条，将“违反本条例第四十条规定”修改为“违反本条例第三十九条规定”。

10.将第五十条改为第四十九条，将“环境保护”修改为“生态环境保护”，将“由其上级主管部门或者监察机关责令改正”修改为“对负有责任的领导人员和直接责任人员”。

二、对《濮阳市散煤污染防治条例》作出修改

（一）将第一条修改为：“为了防治散煤污染，积极有序推动散煤替代，保护和改善大气环境，推动绿色低碳发展，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）第二条增加一款，作为第三款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）将第十二条修改为：“违反本条例第九条第二款规定，在禁煤区内销售散煤的，由市场监督管理部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下罚款；单位燃用散煤的，由生态环境主管部门责令改正，处货值金额一倍以上五倍以下罚款。”

（四）对部分条文作以下修改：

1.将第四条第一款中的“并将散煤污染防治纳入大气污染防治考核内容”修改为“加强散煤管理”。

2.将第五条第八项中的“环境保护”修改为“生态环境保护”。

3.将第八条中的“市、县（区）人民政府应当逐步推进本行政区域内集中供热”修改为“市、县（区）人民政府应当逐步推进本行政区域内热电联产和集中供热”，将“清洁能源”修改为“清洁低碳能源”。

4.删去第九条第一款中的“市”后面的“县”，将第九条第一款中的“应当”修改为“可以”，“清洁能源”修改为“清洁低碳能源”，在“划定禁煤区”后增加“并向社会公布”。

5.将第十一条“防止遗撒造成环境污染”修改为“防止遗撒造成扬尘污染，并按照规定路线行驶”。

6.在第十四条“采用其他方式封盖严密”后增加“防止物料遗撒，或者未按照规定路线行驶”。

7.在第十六条“依法给予处分”前增加“对负有责任的领导人员和直接责任人员”。

三、对《濮阳市扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（一）第二条增加一款，作为第二款：“本条例未作规定的，适用有关法律、法规的规定。”

（二）将第九条第十三项修改为：“不在禁止的时段和区域内露天烧烤食品。”

（三）将第二十六条修改为：“违反本条例第八条第四项规定，开展健身、娱乐、宣传、销售、庆典、祭祀等活动时，未合理使用场地及设施设备，违反环境噪声有关规定，制造噪声干扰他人正常生活的，由城市管理行政执法部门进行说服教育，责令改正；拒不改正的，给予警告，对个人可以处二百元以上一千元以下的罚款，对单位可以处二千元以上二万元以下的罚款。

“违反本条例规定，产生社会生活噪声，经劝阻、调解和处理未能制止，持续干扰他人正常生活、工作和学习，或者有其他扰乱公共秩序、妨害社会管理等违反治安管理行为的，由公安机关依法给予治安管理处罚。”

（四）删去第二十九条。

（五）对部分条文作以下修改：

将第三十二条改为第三十一条，将“对直接负责的主管人员”修改为“对负有责任的领导人员”。
