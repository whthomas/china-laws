# 衡水市人民代表大会常务委员会关于修改《衡水市大气污染防治若干规定》的决定

衡水市人民代表大会常务委员会关于修改
《衡水市大气污染防治若干规定》的决定

（2026年6月30日衡水市第七届人民代表大会常务委员会第四十一次会议通过　2026年7月23日河北省第十四届人民代表大会常务委员会第二十二次会议批准）

衡水市第七届人民代表大会常务委员会第四十一次会议决定，对《衡水市大气污染防治若干规定》作如下修改：

原第一条修改为：为了保护和改善生态环境，防治大气污染，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《河北省大气污染防治条例》等有关法律法规，结合本市实际，制定本规定。

原第五条修改为：生态环境主管部门对本行政区域内的大气污染防治工作实施统一监督管理。

市、县级人民政府其他有关部门在各自职责范围内对大气污染防治工作实施监督管理：

（一）发展改革、工业和信息化部门负责煤炭消费总量控制，优化产业和能源结构以及布局调整，组织推动工业企业技术改造和升级、落后产能淘汰计划实施，加大清洁能源利用，发展循环经济，制定和完善大气环境保护等相关政策；

（二）公安、交通运输、商务等部门对机动车以及非道路移动机械、油气回收治理等实施监督管理；

（三）住房城乡建设、自然资源和规划、交通运输、城市管理、工业和信息化等部门对建筑扬尘、矿山扬尘、道路扬尘、企业料堆场等实施监督管理；

（四）城市管理、公安、市场监督管理、农业农村等部门对餐饮服务、露天烧烤、原煤散烧、秸秆禁烧等实施监督管理；

（五）农业农村、自然资源和规划等部门对农业生产、畜禽养殖造成的大气污染等实施监督管理；

（六）交通运输、农业农村主管部门对船舶大气污染物排放实施监督管理。

原第七条修改为：市、县级人民政府应当推广清洁能源的生产和使用。

市人民政府应当根据大气环境质量改善要求，划定并公布高污染燃料禁燃区，并逐步扩大高污染燃料禁燃区范围。

在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市级以上人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。

本市高污染燃料禁燃区内，对禁止燃烧的高污染燃料范围执行最严格控制标准。

原第八条修改为：钢铁、建材、有色金属、石油、化工、制药、矿产开采、玻璃钢、橡胶企业和其他工业生产企业，应当加强精细化管理，采取集中收集处理等措施，严格控制粉尘和气态污染物的排放。

工业生产企业应当采取密闭、围挡、遮盖、清扫、洒水等措施，减少内部物料的堆存、传输、装卸等环节产生的粉尘和气态污染物的排放。

原第九条修改为：实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家和本省有关规定安装、使用、维护大气污染物排放自动监测设备，并与生态环境主管部门的监控设备联网，保证自动监测设备正常运行并依法公开排放信息，接受社会监督。

禁止破坏、损毁或者擅自移动、拆除、闲置大气污染物排放自动监测设备，禁止干扰采样、改变监测条件，禁止篡改、伪造监测数据或者指使对监测数据弄虚作假。

原第十一条修改为：储油库、加油站、原油成品油码头、原油成品油运输船舶和油罐车、铁路罐车等，应当按照国家规定安装油气回收装置并保持正常使用。

原第十三条第二款修改为：禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶、枯草等产生烟尘污染的物质。

原第十四条修改为：禁止在人口集中地区和其他依法需要特殊保护的区域焚烧电子废弃物、沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。

原第十五条修改为：市、县级人民政府应当依据重污染天气的预警等级，及时启动应对预案，实施应急响应措施。

相关部门和排污单位应当严格落实应急响应措施。

原第十七条修改为：违反本规定第八条，钢铁、建材、有色金属、石油、化工、制药、矿产开采、玻璃钢、橡胶企业和其他工业生产企业，未采取集中收集处理、密闭、围挡、遮盖、清扫、洒水等措施，控制、减少粉尘和气态污染物排放的，由生态环境主管部门责令改正，处二万元以上五万元以下罚款；情节较重的，处五万元以上十万元以下罚款；情节严重的，处十万元以上二十万元以下罚款。拒不改正的，责令停产整治。

原第十九条修改为：违反本规定第十三条，在禁止焚烧的区域和时段露天焚烧秸秆、落叶、枯草等产生烟尘污染的物质的，由乡镇人民政府、街道办事处责令改正，可以处五百元以上二千元以下罚款。

原第二十二条修改为：违反本规定的行为，法律、法规已有法律责任规定的，从其规定。

原第二十三条修改为：本规定关于县级人民政府的规定，适用于衡水高新技术产业开发区管委会和滨湖新区管委会。

删除原第十八条、第二十条。

将法规全文中的“县（市、区）”修改为“县级”；“住房和城乡建设”修改为“住房城乡建设”；“市场监督”修改为“市场监督管理”；“乡镇人民政府（街道办事处）”修改为“乡镇人民政府、街道办事处”。

修订后法规条序做相应调整。

本决定自2026年8月15日起施行。

《衡水市大气污染防治若干规定》根据本决定做相应修改，重新公布。
