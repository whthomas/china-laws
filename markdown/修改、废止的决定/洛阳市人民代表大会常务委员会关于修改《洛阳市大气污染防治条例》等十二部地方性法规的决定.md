# 洛阳市人民代表大会常务委员会关于修改《洛阳市大气污染防治条例》等十二部地方性法规的决定

洛阳市人民代表大会常务委员会关于修改
《洛阳市大气污染防治条例》等十二部
地方性法规的决定

（2026年7月3日洛阳市第十六届人民代表大会常务委员会第三十一次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

洛阳市第十六届人民代表大会常务委员会第三十一次会议决定：

一、对《洛阳市大气污染防治条例》作出修改

（一）将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，全面推进美丽洛阳建设，加快推进人与自然和谐共生的现代化，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（三）将第六条修改为：“严格落实生态环境保护目标责任制和考核评价制度，将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。”

（四）将第十三条第四项修改为：“建立监测数据档案，原始监测记录和管理台账保存期限不得少于五年；”

（五）在第十四条第一款中的“安装、使用”后增加“维护”。

（六）删去第十五条。

（七）将第十八条第二款修改为：“市、县、区人民政府应当加强煤炭质量监督管理，鼓励燃用优质煤炭，禁止进口、销售或者燃用不符合质量标准的煤炭，减少煤炭生产、贮存、运输、使用、转化过程中的大气污染物排放。”

将第三款修改为：“推行煤炭洗选加工，降低煤炭硫分和灰分，限制高硫分、高灰分煤炭的开采。新建煤矿应当同步建设配套的煤炭洗选设施，使煤炭的硫分、灰分含量达到规定标准；已建成的煤矿除所采煤炭属于低硫分、低灰分或者根据已达标排放的燃煤电厂要求不需要洗选的外，应当限期建成配套的煤炭洗选设施。”

（八）将第十九条第一款中的“应当”修改为“可以”，在“公布高污染燃料禁燃区”后增加“并根据大气环境质量改善要求”，删去“县（市）”。

在第二款中的“天然气”后增加“页岩气”。

（九）将第二十条修改为：“集中供热区域内的单位和个人应当使用集中供应的热源，不得新建、扩建分散的燃煤供热锅炉，已建成的不能达标排放的燃煤供热锅炉，应当限期拆除。”

（十）删去第二十一条。

（十一）将第二十四条第一款修改为：“鼓励生产、进口、销售、使用低毒、低挥发性有机物含量的原辅材料和产品，印刷、家具制造、装修、工业涂装企业等应当按照规定使用低挥发性有机物含量的原辅材料和产品。”

（十二）将第二十六条修改为：“储油库、加油站、原油成品油码头、原油成品油运输船舶和油罐车、铁路罐车等，应当按照国家规定安装油气回收装置并保持正常使用。”

（十三）将第二十七条修改为：“在本市销售、办理注册登记及行驶的机动车船、非道路移动机械及其发动机，应当符合国家大气污染物排放标准和本省执行的大气污染物排放标准。”

（十四）将第二十八条第一款中的“遥感”修改为“非接触式道路”，在“污染物排放状况”后增加“排放控制系统运行情况”，删去“应当”。

将第二款修改为：“在用机动车应当按照有关规定，由机动车排放检验机构定期对其进行排放检验。经检验合格的，方可上道路行驶。在用机动车、非道路移动机械等排放大气污染物超过标准的，应当进行维修；经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。”

（十五）在第二十九条第一款中的“非道路移动机械”前增加“在用”，在“大气污染物排放状况”后增加“排放控制系统运行情况”。

（十六）将第三十一条修改为：“禁止生产、进口或者销售不符合标准的机动车船、非道路移动机械用燃料和氮氧化物还原剂；禁止向机动车、非道路移动机械、内河船舶销售非机动车船用燃料；禁止机动车、非道路移动机械、内河船舶使用非机动车船用燃料。”

（十七）将第三十二条修改为：“存放煤炭、煤矸石、煤渣、煤灰、水泥、石灰、石膏、砂土、铁矿石等易产生扬尘的物料应当按照有关规定密闭；不能密闭的，应当设置不低于堆放物高度的严密围挡并采取覆盖、喷淋等有效覆盖措施防治扬尘污染。

“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆和船舶应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定路线行驶。

“装卸物料应当采取密闭或者喷淋等方式防治扬尘污染。”

（十八）将第三十三条第一款修改为：“施工单位应当在施工工地设置硬质围挡，并采取覆盖、分段作业、择时施工、洒水抑尘、冲洗地面和车辆等有效防尘降尘措施。工程渣土等建筑垃圾、建筑土方应当及时清运；在场地内堆存的，应当采取密闭式防尘网遮盖。”

（十九）将第三十六条第一款中的“应当及时对污水、粪便、废弃物进行收集、贮存、处置和综合利用”修改为“应当采取有效措施，及时对畜禽粪污、尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，防止污染环境”。

（二十）将第三十七条修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧农作物秸秆、落叶、树枝、枯草等产生烟尘污染的物质。

“禁止在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。”

（二十一）在第三十八条中的“排放油烟”后增加“污染物”，将第一项修改为：“应当按照规定安装油烟净化等污染防治设施并保持正常使用，或者采取其他有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染；”

增加一款，作为第一款：“市、县、区人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。”

（二十二）将第三十九条中的“商用”修改为“商业”，“划定的禁止区域”修改为“禁止的时段和区域”，在“露天烧烤”后增加“食品”。

（二十三）将第四十条第一款修改为：“禁止生产、销售或者燃放不符合质量标准的烟花爆竹。任何单位和个人不得在市、县、区人民政府禁止的时段和区域燃放烟花爆竹。”

（二十四）将第四十二条修改为：“市人民政府以及可能发生重污染天气的县、区人民政府应当制定重污染天气应对预案，报上一级人民政府生态环境主管部门备案并公布。”

（二十五）将第四十三条第一款第二项修改为：“限制部分机动车行驶和非道路移动机械使用；”

将第一款第三项修改为：“停止工地土石方作业和建筑物拆除施工；”

增加一项，作为第一款第八项：“禁止燃放烟花爆竹；”

增加一项，作为第一款第九项：“停止露天烧烤；”

增加一款，作为第二款：“应对响应结束后，人民政府应当及时开展应对预案实施情况的评估，适时修改完善应对预案。”

（二十六）将第四十五条修改为：“违反本条例第十八条规定的，由生态环境主管部门没收燃用高污染燃料的设施、燃煤供热锅炉并组织拆除，处二万元以上二十万元以下罚款。”

（二十七）将第四十六条中“第三十三条”修改为“第三十一条”，在“依法作出处罚决定的部门”后增加“应当组织复查，发现其继续实施该违法行为、拒不改正或者拒绝、阻挠复查的”，将“处罚数额”修改为“罚款数额”，在“连续处罚”后增加“并及时采取措施制止违法行为”。

（二十八）将第四十七条第一款修改为：“生态环境主管部门和其他负有大气环境保护监督管理职责的部门及其工作人员有下列行为之一的，对负有责任的领导人员和直接责任人员，依法给予处分；构成犯罪的，依法追究刑事责任：”

（二十九）对部分条文作以下修改：

1.将相关条文中的“县（市、区）”修改为“县、区”，“县（市）”修改为“县、区”。

2.删去第五条、第十二条、第二十八条中的“市、县（市）人民政府”，第四十一条第一款、第四十五条中的“市人民政府”，第四十七条中的“市、县（市、区）人民政府”。

3.将第五条中的“发展改革”“水利”分别修改为“发展和改革”“水行政”，第二十九条中的“水利”修改为“水行政”。

4.将第九条中的“给予奖励”修改为“按照国家和省有关规定给予表彰和奖励”，第十三条第一项中的“环境监测机构”修改为“生态环境监测机构”，第十四条第一款中的“重点排污单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”，第十八条、第十九条中的“清洁能源”修改为“清洁低碳能源”，第二十五条中的“原料”修改为“原辅材料和产品”，第四十三条中的“应急预案”修改为“应对预案”。

二、对《洛阳市水资源条例》作出修改

（一）增加一款，作为第二条第四款：“本条例未作规定的，适用有关法律、法规的规定。”

（二）删去第二十七条。

（三）将第十五条中的“严禁”修改为“禁止”。

（四）在第二十八条中的“依法给予处分”前增加“对负有责任的领导人员和直接责任人员”。

三、对《洛阳市伊洛河保护条例》作出修改

（一）将第一条修改为：“为了加强伊洛河流域生态保护，改善水环境，保障水安全，推动高质量发展，根据《中华人民共和国生态环境法典》、《中华人民共和国黄河保护法》、《中华人民共和国水法》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第二十二条第二款修改为“畜禽散养密集区所在地县、区人民政府、乡镇人民政府应当组织对畜禽粪污进行分户收集、集中处理利用。县、区人民政府组织确定本行政区域的畜禽散养密集区。”

（三）对部分条文作以下修改：

删去第十七条中的“人民政府”，第二十七条中的“本级人民政府”。

四、对《洛阳市陆浑水库饮用水水源保护条例》作出修改

（一）将第一条修改为：“为了加强陆浑水库饮用水水源的保护，防止水质污染，保障居民饮用水安全，推进生态文明建设，根据《中华人民共和国生态环境法典》、《河南省水污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第十一条第二款修改为：“一级保护区：水库大坝消力池取水口小桥处至上游输水洞和电站泵房水渠渠内及硬化渠顶的区域；水库多年平均水位线（312.38米）以下，输水洞口外围500米的区域及多年平均水位线以上至水库大坝—路堤迎水坡坡顶的区域。”

将第三款修改为：“二级保护区：一级保护区外至多年平均水位线以下的区域及多年平均水位线以上至库坝东路—饭嵩路—叠翠街—洛栾线—省道322—陆浑镇主街—防洪堤坝—洛栾线—库坝西路的区域；伊河、高都川入库口至上游2000米防洪堤迎水坡坡顶内河道区域，赵村川入库口至上游2000米河道内及两岸纵深至一级阶地的区域。”

（三）将第二十一条修改为：“陆浑水库饮用水供水单位应当做好取水口和出水口的水质检测，并定期向有关部门报送供水水质检测资料。”

（四）在第二十二条第一款、第二款中的“应急预案”后增加“并按照规定备案”。

将第三款修改为：“陆浑水库饮用水供水单位应当按照国家规定制定突发生态环境事件应急预案，报生态环境等有关部门备案，并定期进行演练。”

（五）将第二十四条修改为：“市人民政府和嵩县、栾川县人民政府应当对陆浑水库汇水区域内有关企业事业单位和其他生产经营者的排污状况加强管理。饮用水水源受到污染可能威胁供水安全的，生态环境主管部门应当责令其采取停止排放污染物，限期治理等措施，并通报饮用水供水单位和供水、卫生健康、水行政等有关部门；治理后仍达不到排放标准的，由所在地人民政府依法予以关闭、拆除。”

（六）将第二十九条修改为：“负责陆浑水库饮用水水源保护的国家机关及其工作人员滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员，依法给予处分；构成犯罪的，依法追究刑事责任。”

（七）对部分条文作以下修改：

1.将第五条、第十二条、第十八条、第二十三条中的“水利”修改为“水行政”。

2.将第十条、第十七条、第十八条中的“市人民政府生态环境”修改为“市生态环境”。

3.将第二十二条第一款、第二款中的“突发环境事件应急预案”修改为“突发生态环境事件应急预案”。

五、对《洛阳市城市河渠管理条例》作出修改

（一）将第一条修改为：“为了加强城市河渠的建设、保护和管理，保障城市防洪安全，改善城市河渠环境，发挥城市河渠的综合功能和效益，促进城市生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国防洪法》和《中华人民共和国河道管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三十三条修改为：“市、区人民政府有关部门及其工作人员在城市河渠保护管理工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员，依法给予处分；构成犯罪的，依法追究刑事责任。”

六、对《洛阳市城市绿化条例》作出修改

（一）增加一款，作为第二条第二款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）将第三十五条修改为：“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”
