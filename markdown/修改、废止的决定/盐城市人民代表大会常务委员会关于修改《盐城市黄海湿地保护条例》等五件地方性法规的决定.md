# 盐城市人民代表大会常务委员会关于修改《盐城市黄海湿地保护条例》等五件地方性法规的决定

盐城市人民代表大会常务委员会关于修改
《盐城市黄海湿地保护条例》等五件
地方性法规的决定

（2026年6月24日盐城市第九届人民代表大会常务委员会三十八次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

盐城市第九届人民代表大会常务委员会第三十八次会议决定：

一、对《盐城市黄海湿地保护条例》作出修改

（一）将第五条修改为：“市、黄海湿地所在地县（市、区）人民政府（以下简称县（市、区）人民政府）应当将黄海湿地保护纳入国民经济和社会发展规划，加大湿地保护投入，加强湿地保护协调工作，研究解决湿地保护重大问题，并将开展黄海湿地保护工作所需经费按照事权划分原则列入本级财政预算。

“市、县（市、区）人民政府应当将黄海湿地保护工作纳入本级人民政府综合绩效评价和林长制考核评价内容，每年对下级人民政府、有关部门和单位黄海湿地保护工作目标完成情况进行考核评价。”

（二）删去第六条。

（三）将第七条改为第六条，修改为：“市、县（市、区）人民政府林业主管部门负责本行政区域内黄海湿地资源的监督管理，负责湿地保护规划的拟定和组织实施、湿地开发利用的监督管理、湿地生态保护修复工作。

“自然资源和规划、生态环境、住房和城乡建设、水利、农业农村等主管部门，按照职责负责黄海湿地保护、修复、管理有关工作。”

（四）将第八条改为第七条，修改为：“黄海湿地所在地镇人民政府、街道办事处组织群众做好黄海湿地保护工作，村民委员会、居民委员会依法予以协助。”

（五）将第十一条改为第十条，第三款修改为：“对在黄海湿地保护工作中做出突出贡献的组织和个人，按照国家和省有关规定给予表彰、奖励。”

（六）将第十二条改为第十一条，修改为：“市人民政府林业主管部门应当会同有关部门和县（市、区）人民政府，组织编制黄海湿地保护规划，保护规划报市人民政府批准后公布、实施。

“黄海湿地保护规划应当明确黄海湿地保护的区域范围、目标任务、总体布局、保护修复重点和保障措施等内容，落实国土空间规划要求，并与流域综合规划、防洪规划以及水资源管理、河道管理、湖泊保护、交通运输等方面的规划相衔接。

“有关部门编制涉及黄海湿地保护的专项规划，应当征求林业主管部门的意见。”

（七）将第十五条改为第十四条，修改为：“黄海湿地实行分级管理制度。

“湿地分为重要湿地和一般湿地。重要湿地包括国家重要湿地和省级重要湿地，重要湿地以外的湿地为一般湿地。重要湿地依法划入生态保护红线。

“黄海湿地名录中省级以上重要湿地的认定和调整，按照国家和省有关规定执行。一般湿地名录、范围及其调整，由市、县（市、区）人民政府或者其授权的部门发布。”

（八）删去第十六条。

（九）将第十七条改为第十五条，修改为：“市、县（市、区）人民政府应当根据国土空间规划、黄海湿地保护规划以及其他有关规划，划定生态保护红线，确保黄海湿地生态系统功能不退化、面积不减少、性质不改变。”

（十）将第十八条改为第十六条，第二款修改为：“任何组织和个人不得擅自移动或者破坏黄海湿地保护标志。”

（十一）将第十九条改为第十七条，修改为：“黄海湿地内的自然保护区、湿地公园、湿地保护小区的设立、调整和管理，依照有关法律、法规的规定执行。”

（十二）将第二十条改为第十八条，修改为：“禁止下列破坏黄海湿地及其生态功能的行为：

“（一）开（围）垦、排干自然湿地，永久性截断自然湿地水源。

“（二）擅自填埋自然湿地，擅自采砂、采矿、取土。

“（三）排放不符合水污染物排放标准的工业废水、生活污水以及其他污染湿地的废水、污水、其他有毒有害物质，倾倒、堆放、丢弃、抛撒、遗撒固体废物。

“（四）过度放牧或者滥采野生植物；过度捕捞或者灭绝式捕捞鱼类以及其他水生生物；过度施肥、投药、投放饵料等污染湿地的种植养殖行为；猎捕野生动物，破坏野生动物栖息地、迁徙通道以及鱼类洄游通道。

“（五）擅自引进外来物种或者放生动物。

“（六）其他破坏黄海湿地及其功能的行为。

“不得擅自采伐湿地上生长的林木，确需采伐的应当依法办理采伐许可证。”

（十三）将第二十三条改为二十一条，第二款修改为：“因公共利益或者重大自然灾害造成黄海湿地破坏，以及湿地修复责任主体灭失或者无法确定的，由市、县（市、区）人民政府组织实施修复。”

（十四）将第二十九条改为第二十七条，修改为：“建设项目确需临时占用黄海湿地的，应当依照土地管理、水资源管理、河道管理、水库管理、湖泊保护、森林、海域使用管理等有关法律、法规的规定办理。临时占用湿地的期限一般不得超过二年，并不得在临时占用的湿地上修建永久性建筑物。

“临时占用湿地期满后一年内，用地单位或者个人应当恢复湿地面积和生态条件。临时占用黄海湿地的审批部门应当对用地单位或者个人恢复湿地的情况进行监督。

“因抢险救灾、防洪、疫情防控等突发事件需要临时占用湿地的，依照有关法律、法规的规定执行。”

（十五）将第四十条改为第三十八条，修改为：“违反本条例第十六条第二款规定，擅自移动黄海湿地保护标志的，由林业等主管部门按照职责分工责令限期改正，处五百元以上二千元以下罚款；破坏黄海湿地保护标志的，由林业等主管部门按照职责分工责令限期改正，处二千元以上五千元以下罚款。”

（十六）将第四十一条改为第三十九条，修改为：“违反本条例第十八条规定，实施破坏黄海湿地及其生态功能的行为，其他法律、法规已经规定处罚的，由有关部门依法予以处罚；其他法律、法规未规定处罚的，由有关部门责令停止违法行为，限期恢复原状或者采取其他补救措施，可以处二千元以上五万元以下罚款；造成严重后果的，处五万元以上五十万元以下罚款。”

（十七）删去第四十二条。

（十八）将第四十三条改为第四十条，修改为：“违反本条例第二十七条规定，在临时占用湿地上修建永久性建筑物，或者临时占用湿地期满后没有恢复湿地面积和生态条件的，由有关部门依照土地管理、水资源管理、河道管理、水库管理、湖泊保护、森林、海域使用管理等法律、法规的规定处罚。”

（十九）将第四十四条改为第四十一条，修改为：“市、县（市、区）人民政府、有关部门的工作人员在黄海湿地保护工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任；给当事人造成损失的，依法承担赔偿责任。”

（二十）将有关条款中的“湿地生态红线”修改为“生态保护红线”、“湿地保护主管部门”修改为“林业主管部门”、“界标”修改为“标志”、“环境影响评价”修改为“生态环境影响评价”、“生态补偿机制”修改为“生态保护补偿机制”。

此外，对条文顺序作相应调整。

二、对《盐城市农作物秸秆综合利用条例》作出修改

（一）将第一条修改为：“为了加快推进农作物秸秆（以下简称秸秆）综合利用，提高资源利用效率，保护生态环境，维护公共安全，促进绿色发展，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）将第十七条修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省人民政府划定的其他区域和规定的时段露天焚烧秸秆（本条例统称禁止露天焚烧）；禁止随意弃置秸秆。”

（三）将第三十条修改为：“违反本条例第十七条规定，在禁止焚烧的区域和时段露天焚烧秸秆的，由生态环境部门责令改正，可以处五百元以上二千元以下罚款。”

（四）将第三十三条修改为：“市、县（市、区）人民政府、有关部门的工作人员在秸秆综合利用工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（五）将有关条款中的“农民合作社”修改为“农民专业合作社”、“环境保护公益活动”修改为“生态环境保护公益活动”。

此外，对部分条款作文字修改。

三、对《盐城市扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了有效防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）将第十条第二项修改为：“报批的建设项目生态环境影响报告书、生态环境影响报告表应当包括扬尘污染防治内容”。

（三）将第十四条第一项修改为：“施工工地周围按照规范要求设置硬质围挡”。

第二项修改为：“施工现场的物料装卸、堆放以及工程渣土等建筑垃圾、建筑土方不能及时清运的，应当采取覆盖、密封、洒水等防尘措施”。

（四）将第十八条第四项修改为：“拆除工程已完工的待建工地应当及时移交工程建设单位，暂时不能开工的建设用地，建设单位应当对裸露地面进行覆盖；超过三个月的，应当进行绿化、铺装或者遮盖”。

（五）将第二十二条修改为：“工程渣土等建筑垃圾、建筑土方的运输应当符合下列扬尘污染防治要求：

“（一）工程渣土等建筑垃圾、建筑土方运输车辆取得城市管理部门核发的准运手续；

“（二）工程建设单位、施工单位、运输单位在出土现场和渣土堆放场所配备现场管理设施和人员，负责运输车辆的保洁、装载卸载的验收工作；

“（三）运输车辆密闭，不得超载，不得散落滴漏，并按照规定路线行驶。”

（六）将第二十三条修改为：“市、县（市、区）人民政府应当规划、建设专用的工程渣土等建筑垃圾处置场，规范处置行为，推进资源综合利用。”

（七）将第二十五条修改为：“发生重污染天气时，市、县（市、区）人民政府应当根据预警等级启动应对预案，相关部门和重点扬尘污染源责任单位应当执行停止土方作业、拆除工程施工等相应的扬尘管控应急措施。应急响应解除后，应当及时恢复正常施工秩序，减少对合法施工活动的影响。”

（八）将第三十二条修改为：“违反本条例规定，施工单位有下列情形之一的，由住房和城乡建设等部门根据各自职责责令限期改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治：

“（一）未制定扬尘污染防治实施方案的；

“（二）施工工地未设置硬质围挡，或者未采取地面硬化、覆盖施工、洒水喷淋、冲洗地面和车辆等有效防尘措施的；

“（三）工程渣土等建筑垃圾、建筑土方未及时清运，或者未采取遮盖、封闭、洒水等防尘措施的；

“（四）拆除工程未采取全封闭施工，或者未采取有效防尘措施的。”

（九）将第三十三条修改为：“违反本条例规定，随意堆放或者高空抛撒装饰装修垃圾的，由城市管理部门责令改正，对施工单位处十万元以上一百万元以下罚款，对其他单位处一万元以上十万元以下罚款，没收违法所得；对个人处一百元以上一千元以下罚款。”

（十）将第三十四条修改为：“违反本条例规定，建设单位未对暂时不能开工的建设用地的裸露地面进行覆盖，或者未对超过三个月不能开工的建设用地的裸露地面进行绿化、铺装或者遮盖的，由住房和城乡建设等部门根据各自职责责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治。”

（十一）将第三十六条修改为：“违反本条例规定，运输工程渣土等建筑垃圾、建筑土方的车辆，未密闭运输或者散落滴漏的，或者未按照规定路线行驶的，由城市管理部门责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。”

（十二）将第三十七条修改为：“违反本条例规定，施工单位在五级以上大风天气进行建（构）筑物拆除、爆破作业的，由住房和城乡建设、生态环境等部门根据各自职责责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治。”

（十三）将第三十八条修改为：“违反本条例规定，在发生重污染天气时，拒不执行扬尘管理和控制应急措施的，由生态环境等部门根据各自职责责令改正，处一万元以上十万元以下罚款。”

（十四）将第三十九条修改为：“违反本条例规定，拒不配合负有扬尘污染防治监督管理职责的部门进行现场检查，或者在检查中弄虚作假的，由相关部门责令改正，处五万元以上二十万元以下罚款；对直接负责的主管人员和其他直接责任人员，处五千元以上五万元以下罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（十五）将第四十一条修改为：“市、县（市、区）人民政府、有关部门的工作人员在扬尘污染防治工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（十六）将有关条款中的“大气污染公共监测预警机制”修改为“重污染天气监测预警机制”、“环境影响评价”修改为“生态环境影响评价”。

此外，对部分条款作文字修改。

四、对《盐城市畜禽养殖污染防治条例》作出修改

（一）将第四条修改为：“畜禽养殖污染防治应当坚持政府主导、业主负责、部门监管、社会参与的原则，实行统筹规划、合理布局、预防为主、防治结合、激励引导。”

（二）将第十条第一款修改为：“畜禽养殖场（小区）、养殖户应当采取有效措施，及时对畜禽粪污、尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，防止、减少畜禽养殖污染，对环境造成的危害和破坏依法承担责任。”

（三）将第十三条修改为：“对在畜禽养殖污染防治工作中做出突出贡献的单位和个人，按照国家和省有关规定给予奖励。”

（四）将第十九条修改为：“畜禽养殖场（小区）应当根据养殖规模和污染防治需要，建设相应的畜禽粪便、污水和雨水分流设施，畜禽粪便、污水的贮存设施，粪污厌氧消化和堆沤、有机肥加工、制取沼气、沼渣沼液分离和输送、污水处理、畜禽尸体处理等无害化处理和综合利用设施，保证设施正常运行，保证粪污达标排放，防止污染水环境。已经委托其他生产经营者对畜禽养殖废弃物进行无害化处理和综合利用的，可以不自行建设无害化处理和综合利用设施。

“未建设无害化处理和综合利用设施、建设的设施不合格，或者未委托其他生产经营者对畜禽养殖废弃物进行无害化处理和综合利用的，畜禽养殖场（小区）不得投入生产。”

（五）将第二十条修改为：“畜禽养殖场（小区）建设无害化处理和综合利用设施应当符合经批准的生态环境影响报告书、生态环境影响报告表的要求，与主体工程同时设计、同时施工、同时投产使用，不得擅自拆除或者闲置。”

（六）将第三十二条修改为：“违反本条例规定，在禁养区内建设畜禽养殖场（小区）的，由生态环境部门责令停止建设；拒不停止的，处三万元以上十万元以下的罚款，并报市或者县（市、区）人民政府责令拆除或者关闭。”

（七）删去第三十三条。

（八）将第三十四条改为第三十三条，修改为：“违反本条例规定，畜禽养殖场（小区）未建设无害化处理和综合利用设施或者建设的设施不合格，也未委托其他生产经营者对畜禽养殖废弃物进行无害化处理和综合利用，或者建设的无害化处理和综合利用设施未正常运行的，由生态环境部门责令停止生产或者使用，可以处十万元以下的罚款。”

（九）将第三十五条改为第三十四条，修改为：“违反本条例规定，未对畜禽养殖废弃物进行无害化处理或者综合利用的，由生态环境部门责令改正，可以对畜禽养殖场（小区）处十万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。对畜禽养殖户，可以处一百元以上一千元以下的罚款。”

（十）将第三十八条改为第三十七条，修改为：“市、县（市、区）人民政府、有关部门的工作人员在畜禽养殖污染防治工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（十一）将有关条款中的“环境影响评价”修改为“生态环境影响评价”、“城乡总体规划、土地利用总体规划”修改为“国土空间规划”、“环境保护”修改为“生态环境保护”、“处置”修改为“处理”。

此外，对部分条款作文字修改，并对条文顺序作相应调整。

五、对《盐城市排水管理条例》作出修改

（一）将第一条修改为：“为了加强排水管理，改善水环境质量，保障公民生命财产安全和公共安全，促进绿色盐城和国际湿地城市建设，根据《中华人民共和国生态环境法典》和国务院《城镇排水与污水处理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第九条修改为：“市排水主管部门会同有关部门，根据国民经济和社会发展规划、国土空间规划、生态环境保护规划和防洪规划拟订市排水规划草案，报市人民政府批准后实施，并报省人民政府排水主管部门备案。

“县（市）和大丰区排水主管部门负责拟订本行政区域排水规划草案，报同级人民政府批准后实施，并报市排水主管部门备案。

“除大丰区外，其他区排水主管部门应当依据市排水规划，结合本地区实际情况编制实施方案，经市排水主管部门会同市自然资源和规划部门审查同意后实施。”

（三）将第十一条修改为：“市、县（市、区）人民政府应当编制内涝防治规划，并纳入本行政区域的排水规划。”

（四）将第三十八条第一款修改为：“建设工程施工范围内有公共排水设施的，建设单位应当与施工单位、设施维护运营单位在施工前共同制定保护方案，经排水主管部门同意后方可施工，所需费用由建设单位承担。”

（五）将第四十二条修改为：“市、县（市、区）人民政府、有关部门的工作人员在排水管理工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（六）将有关条款中的“排水工作协调机制”修改为“排水工作推进机制”、“列入重点排污单位名录的排水户”修改为：“列入排污许可重点管理的排水户”、“尾水湿地建设”修改为“尾水生态湿地建设”。

此外，对部分条款作文字修改。

本决定自2026年8月15日起施行。

《盐城市黄海湿地保护条例》、《盐城市农作物秸秆综合利用条例》、《盐城市扬尘污染防治条例》、《盐城市畜禽养殖污染防治条例》、《盐城市排水管理条例》根据本决定作相应修改，重新公布。
