# 陕西省人民代表大会常务委员会关于修改《陕西省渭河保护条例》等六部地方性法规的决定

陕西省人民代表大会常务委员会
关于修改《陕西省渭河保护条例》等六部
地方性法规的决定

（2026年9月23日陕西省第十四届人民代表大会常务委员会第二十五次会议通过）

陕西省第十四届人民代表大会常务委员会第二十五次会议决定：

一、对《陕西省渭河保护条例》作出修改

（一）将第一条修改为：“为了加强渭河流域生态环境保护和治理，防治水灾害和水污染，推进水资源节约集约利用，改善水环境，保障水安全，推动高质量发展，保护传承弘扬渭河流域文化，根据《中华人民共和国生态环境法典》、《中华人民共和国黄河保护法》、《中华人民共和国水法》等法律、行政法规，结合本省实际，制定本条例。”

（二）在第十条第二款末句增加“共同做好突发生态环境事件应对工作”。

（三）将第十四条第二款修改为：“对在渭河流域生态保护和高质量发展工作中做出显著成绩的单位和个人，按照国家和本省有关规定给予表彰奖励。”

（四）删去第六十条第二款。

（五）在第六十三条第一款增加建立和保存管理台账的内容，在第二款增加实行排污许可重点管理的涉水排污单位，开展监控、自动监测，保证自动监测设备正常运行，保存原始监测记录的内容。

（六）在第六十四条增加一款，作为第二款：“向水体排放含热废水，应当采取有效措施，保证水体的水温符合水生态环境质量标准，避免对珍稀濒危水生生物、水产资源造成危害。”

（七）在第六十六条第二款“堆放”后增加“丢弃、抛撒、遗撒或者焚烧”。

（八）将第七十条改为第六十九条，将第二项、第四项、第五项中的“有毒”修改为“有毒有害”，在第五项“渗井”前增加“暗管”，将第六项的“剧毒废渣”修改为“可溶性剧毒废渣”。

（九）将第七十七条改为第七十六条，删去第一款。

（十）将第八十条改为第七十九条，删去第一款中的“严格执行产业准入清单制度”，第二款中的“和产业准入清单”。

（十一）将第八十九条改为第八十八条，删去“支持社会资金设立科技成果转化基金，完善科技投融资体系，综合运用政府采购、技术标准、激励机制等促进科技成果转化”。

（十二）将第一百零一条改为第一百条，删去第二款中的“建立综合执法机构”。

（十三）将第一百零八条改为第一百零七条，删去“第八十一条”。

（十四）删去第六十九条、第一百一十二条。

二、对《陕西省地下水条例》作出修改

（一）将第一条修改为：“为加强地下水保护和管理，科学合理利用地下水，实现地下水安全和可持续利用，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、国务院《地下水管理条例》等法律、行政法规，结合本省实际，制定本条例。”

（二）将第十条修改为：“县级以上人民政府应当组织水利、自然资源、生态环境等主管部门开展地下水状况调查评价，包括地下水资源调查评价、地下水污染调查评价和水文地质勘查评价等。

“地下水状况调查评价结论是编制地下水保护利用和污染防治等规划以及管理地下水的重要依据，应当依法向社会公开。”

（三）将第十四条第二款修改为：“省生态环境主管部门会同省水利、自然资源等有关部门，根据本行政区域地下水污染防治的需要，划定地下水污染防治重点区，明确环境准入、隐患排查、风险管控等管理要求。”

（四）将第二十九条修改为：“县级以上人民政府应当根据地下水水源条件和需要，依法建设应急备用饮用水水源，开展地下水储备。

“应急备用地下水水源结束应急使用后，应当立即停止取水；除特殊干旱年份以及发生重大突发事件外，不得动用地下水储备。

“地下水应急水源、地下水储备，由水行政主管部门统一管理。”

（五）在第三十二条第二款“丢弃”后增加“抛撒”。

（六）将第三十八条第一款第一项修改为：“通过暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放水污染物；”

（七）删去第四十条第一款中“编制地下水监测站网建设规划”的内容。

（八）将第五十四条修改为：“违反本条例规定，造成地下水污染的，依照《中华人民共和国生态环境法典》、《中华人民共和国水法》的规定予以处罚。”

（九）将第五十五条中的“处二万元以上十万元以下罚款”修改为“处二万元以上二十万元以下罚款”。

三、对《陕西省生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了加强生活垃圾分类管理，改善人居环境，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《中华人民共和国循环经济促进法》等法律、行政法规，结合本省实际，制定本条例。”

（二）将第十四条第二款中的“逐步减少以卫生填埋的方式处理生活垃圾”修改为“最大限度减少生活垃圾填埋量”。

（三）在第十九条“优先使用电子运单”前增加“减少包装物的使用”。

（四）删去第二十条第一款中的“推行”，在第二十条第二款“企业事业单位”后增加“社会团体等”。

（五）将第二十二条第一款修改为：“任何单位和个人应当依法在指定的地点分类投放生活垃圾。禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（六）在第二十八条第一项末句增加“并采取防扬散、防流失、防渗漏或者其他防止污染环境的措施”，在第二项“丢弃”后增加“抛撒”。

（七）增加一条，作为第四十一条：“从生活垃圾中回收的物质应当按照国家规定的用途、标准使用，不得用于生产可能危害人体健康的产品。”

（八）将第四十九条改为第五十条，修改为：“违反本条例规定的行为，依照《中华人民共和国生态环境法典》等法律、行政法规规定执行。”

（九）删去第五十一条。

四、对《陕西省风景名胜区管理条例》作出修改

（一）将第一条修改为：“为加强风景名胜区管理，有效保护和合理利用风景名胜资源，根据《中华人民共和国生态环境法典》、国务院《风景名胜区条例》等法律、行政法规，结合本省实际，制定本条例。”

（二）将第五条修改为：“县级以上林业主管部门负责本行政区域内风景名胜区的监督管理工作。

“县级以上自然资源、农业农村、水利、生态环境、住房城乡建设、公安、文物、民族宗教、文化和旅游等有关部门按照各自的职责，做好风景名胜区的保护工作。”

（三）将第十一条第二款修改为：“编制风景名胜区规划应当符合国土空间总体规划，并与其他专项规划、国土空间详细规划相衔接。”

（四）删去第十二条第二款。

（五）将第十三条第一款修改为：“国家级风景名胜区的总体规划，由省人民政府审查后，省林业主管部门报国务院林业草原主管部门审批；详细规划由省林业主管部门报国务院林业草原主管部门审批。”

（六）将第十五条第三款修改为：“政府或者政府部门修改风景名胜区规划对公民、法人或者其他组织造成财产损失的，应当依法给予补偿。”

（七）将第十六条修改为：“在国家级风景名胜区内修建缆车、索道等重大建设工程，项目的选址方案应当报省林业主管部门核准。”

（八）将第十七条修改为：“建设单位、施工单位在风景名胜区内进行建设活动时，应当制定污染防治和水土保持方案，并采取有效措施，保护好周围的文物、景物、林草植被、水体、野生动物资源和地形地貌；工程竣工后，应当及时清理施工现场，恢复植被。”

（九）在第十八条中增加“应急管理、气象、气象灾害”的内容，将“国土资源”修改为“自然资源”、“环境保护”修改为“生态环境”。

（十）将第二十条第一项修改为：“乱扔废弃物，攀折林木花草，在景物或者设施上刻划、涂污”；第四项修改为：“开山、开矿、采石、挖砂、开荒、填堵自然水系等破坏景观、植被和地形地貌的活动”；第五项中的“砍伐”修改为“损害”。

增加一款，作为第二款：“法律、法规另有规定的，依照其规定。”

（十一）删去第二十一条第一项、第三项、第四项，将第五项修改为：“举办大型游乐等活动”。

（十二）将第二十三条第二款、第三款修改为：“风景名胜区的门票收入和风景名胜资源有偿使用费应当全额上缴财政，实行收支两条线管理。风景名胜区的门票收入和风景名胜资源有偿使用费应当专门用于风景名胜资源的保护和管理以及风景名胜区内财产的所有权人、使用权人损失的补偿。

“风景名胜资源有偿使用费的收取标准和风景名胜区门票价格的制定及调整，由省财政、价格主管部门会同省林业等有关部门核定。”

（十三）将第二十八条改为第二十七条，修改为：“违反本条例规定，在国家级风景名胜区内修建缆车、索道等重大建设工程，项目的选址方案未经省林业主管部门核准，县级以上人民政府有关部门核发选址意见书的，对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（十四）增加一条，作为第二十八条：“违反本条例规定的行为，法律、行政法规已有法律责任规定的，从其规定。”

（十五）将第八条第二款、第十一条第一款、第十三条第二款、第二十五条第一款中的“建设行政主管部门”修改为“林业主管部门”。

（十六）删去第二十七条、第三十条。

五、对《陕西省华山风景名胜区条例》作出修改

（一）将第一条修改为：“为了加强华山风景名胜区的管理，有效保护和合理利用风景名胜资源，根据《中华人民共和国生态环境法典》、国务院《风景名胜区条例》等法律、行政法规的规定，结合华山风景名胜区实际，制定本条例。”

（二）将第二条第二款修改为：“华山风景名胜区及其外围保护地带的具体范围按照华山风景名胜区总体规划确定。”

（三）将第九条改为第七条，第一款修改为：“华山风景名胜区规划分为总体规划和详细规划，由省林业主管部门负责组织编制。华山风景名胜区总体规划经省人民政府审查后，由省林业主管部门报国务院林业草原主管部门审批；详细规划由省林业主管部门报国务院林业草原主管部门审批。”

（四）将第十二条改为第十条，修改为：“华阴市人民政府编制本级国土空间总体规划和批准城镇开发边界内详细规划、村庄规划（含通则式规划管理规定），涉及华山风景名胜区及其外围保护地带内的，应当衔接华山风景名胜区规划，并书面征求华山风景名胜区管理机构的意见。”

（五）将第十三条改为第十二条，删去“除必需的保护设施、附属设施外，在华山风景名胜区重要景点不得兴建其他设施”。

（六）将第十四条改为第十三条，第二款修改为：“在华山风景名胜区内不得设立污染环境的建设项目。”

（七）将第十六条改为第十五条，修改为：“在华山风景名胜区内修建缆车、索道等重大建设工程的选址方案，由华山风景名胜区管理机构提交省林业主管部门核准。”

（八）将第十七条改为第十六条，删去第一款中的“已有的有碍景观的建筑物、构筑物，华山风景名胜区管理机构或者华阴市人民政府应当限期拆除”。

删去第二款。

（九）将第十九条改为第十八条，修改为：“在华山风景名胜区内进行建设，建设单位、施工单位应当制定污染防治和水土保持方案，并采取有效措施，保护好周围景物、水体、林草植被、野生动物资源、地形地貌和文物古迹。建设项目竣工后，应当及时清理场地，恢复植被等。”

（十）将第二十一条改为第二十条，第一款第一项修改为：“乱扔废弃物，攀折林木花草，在景物或者设施上刻划、涂污”；第四项修改为：“开山、采石、开矿、挖砂、取土、开荒、填堵自然水系等破坏景观、植被和地形地貌的活动”；第五项中的“采伐、毁坏、移植古树名木”修改为“损害古树名木”。

增加一项，作为第七项：“随意倾倒、堆放、贮存固体废物和其他污染物。”

增加一款，作为第二款：“法律、法规另有规定的，依照其规定。”

（十一）将第二十四条改为第二十三条，删去第一项、第三项、第四项、第七项，将第二项修改为：“举办大型游乐等活动。”

（十二）将第二十七条改为第二十六条，第一款修改为：“华山风景名胜区管理机构应当根据核定的景区、景点的游客容量合理设定游览路线，设置规范的地名标志、路标和说明标识，做好游客的疏导工作，并会同文化和旅游主管部门加强对旅行社、导游的管理。”

（十三）将第三十六条改为第三十五条，第二款、第三款修改为：“华山风景名胜区的门票收入和华山风景名胜资源有偿使用费应当全额上缴财政，实行收支两条线管理。华山风景名胜区的门票收入和华山风景名胜资源有偿使用费应当专门用于华山风景名胜资源的保护和管理以及华山风景名胜区内财产的所有权人、使用权人损失的补偿。

“华山风景名胜资源有偿使用费的收取标准和华山风景名胜区门票价格的制定及调整，由省财政、价格主管部门会同省林业等有关部门核定。”

（十四）将第四十三条改为第四十条，修改为：“违反本条例第二十条规定，个人在华山风景名胜区内进行开荒、修坟立碑等破坏景观、植被、地形地貌的活动的，由华山风景名胜区管理机构责令停止违法行为，限期恢复原状或者采取其他补救措施，没收违法所得，并处一千元以上一万元以下罚款。”

（十五）将第四十六条改为第四十三条，第一项、第二项修改为：“超过允许容量接纳游客，或者在没有安全保障的区域开展游览活动的；

“未设置风景名胜区标志、路标和安全警示等标牌的”。

（十六）删去第六条、第四十条、第四十二条。

（十七）将第四条、第七条第二款、第三十七条、第四十五条中的“住房和城乡建设行政主管部门”修改为“林业主管部门”。

六、对《陕西省秦始皇陵保护条例》作出修改

（一）将第十七条第五项修改为：“建设污染秦始皇陵及其周边环境的设施，违法排放污水，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物的；”

（二）将第十八条修改为：“在秦始皇陵保护范围内不得进行文物保护工程以外的其他建设工程或者爆破、钻探、挖掘等作业；因特殊情况需要进行的，应当报经国务院文物行政主管部门同意后，由省人民政府批准，并采取相应措施，确保文物安全。”

（三）删去第三十三条原第三款，增加一款作为第三款：“违反本条例第十七条第五项和第十九条第二项规定的，依照《中华人民共和国生态环境法典》等法律法规，由生态环境等主管部门依法予以处罚。”

（四）将第三十四条修改为：“有下列行为之一的，由临潼区文物行政主管部门责令改正，予以警告；造成文物损坏或者其他严重后果的，对单位处五十万元以上五百万元以下的罚款，对个人处五万元以上五十万元以下的罚款，责令承担相关文物修缮和复原费用，由原发证机关降低资质等级；情节严重的，对单位可以处五百万元以上一千万元以下的罚款，由原发证机关吊销资质证书：

“（一）擅自在秦始皇陵保护范围内进行文物保护工程以外的其他建设工程或者爆破、钻探、挖掘等作业；

“（二）在秦始皇陵的保护范围、建设控制地带内进行建设工程，未依法进行考古调查、勘探；

“（三）工程设计方案未经文物行政主管部门同意，擅自在秦始皇陵的建设控制地带内进行建设工程。”

（五）将第三十五条修改为：“违反本条例第十九条第一项、第三项规定的，由临潼区文物行政主管部门责令改正，造成严重后果的，处十万元以上五十万元以下罚款；情节严重的，由原发证机关吊销资质证书。”

根据修改情况，对修正的六部地方性法规的条文顺序、文字表述作了相应调整和完善。

本决定自公布之日起施行。
