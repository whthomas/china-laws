# 成都市人民代表大会常务委员会关于修改《成都市水污染防治条例》等十五件地方性法规的决定

成都市人民代表大会常务委员会关于修改
《成都市水污染防治条例》等十五件
地方性法规的决定

（2026年6月30日成都市第十八届人民代表大会常务委员会第二十四次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

成都市第十八届人民代表大会常务委员会第二十四次会议决定：

一、对《成都市水污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第十一条第二款修改为：“市和区（市）县人民政府根据依法批准的流域水生态环境保护规划和实际需要，可以组织编制本行政区域的水生态环境保护规划。”

（三）将第十五条第二款中的“排污单位”修改为“企业事业单位和其他生产经营者”。

二、对《成都市饮用水水源保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三十八条修改为：“违反本条例第十七条第一项、第七项规定的，由市或者区（市）县生态环境行政主管部门责令限期改正，并按照下列规定给予处罚：

“（一）违反第一项规定的，处以五万元以上二十万元以下的罚款；情节严重的，处以二十万元以上五十万元以下的罚款；

“（二）违反第七项规定的，没收违法所得，并处以三万元以上十万元以下的罚款。

“违反本条例第十七条第二项至第六项规定的，按照有关法律、法规处罚。”

（三）删去第四十二条。

三、对《成都市大气污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国大气污染防治法》《四川省〈中华人民共和国大气污染防治法〉实施办法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第六条中的“向大气排放污染物的重点排污单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”。

（三）将第三十条中的“大气污染物重点排放企业”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”。

（四）将第四十一条中的“禁止在本市行政区域内”修改为“禁止在本市人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段”。

（五）将第五十四条中的“处以五千元罚款”修改为“处每辆五千元罚款”。

（六）将第五十五条中的“限期安装；逾期不安装的，对机动车所有人或者驾驶人处每辆车一千元以上三千元以下罚款；对非道路移动机械使用人处每台非道路移动机械一千元以上三千元以下罚款”修改为“对机动车所有人或者驾驶人处每辆车五千元罚款；对非道路移动机械使用人处每台非道路移动机械五千元罚款”。

（七）将第五十六条中的“或者拒绝非道路移动机械排气污染监督检查的”删除。

（八）将第五十七条中的“并处货值金额一倍以上三倍以下罚款”修改为“并处货值金额一倍以上五倍以下罚款”。

（九）将第六十一条修改为：“违反本条例第四十一条第一款规定，在禁止焚烧的区域和时段露天焚烧农作物秸秆、落叶、杂草等产生烟尘污染的物质的，由市、区（市）县城市管理综合行政执法部门责令改正，可以处五百元以上二千元以下的罚款。”

四、对《成都市建筑垃圾处置管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第四十五条中的“责令限期改正，并处以三万元以上十万元以下罚款；逾期未改正的，查封建筑垃圾排放现场”修改为“责令改正，没收违法所得，并处以十万元以上一百万元以下的罚款”。

（三）将第四十七条修改为：“违反本条例第十六条第一款或者第十七条第一款规定的，由城市管理行政主管部门责令改正，对单位处以三千元以上一万元以下罚款；对个人处以二百元以上五百元以下罚款。

“违反本条例第十六条第二款规定的，按照有关法律、法规处罚。”

（四）删去第四十八条。

（五）将第四十九条第一款中的“并处以三万元以上十万元以下罚款；逾期未改正的，查封建筑垃圾排放现场”修改为“没收违法所得，并处以十万元以上一百万元以下的罚款”。

（六）删去第五十二条。

五、对《成都市生活垃圾管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第四十七条中的“养殖小区”删除。

（三）将第六十八条中的“情节严重的，按照《中华人民共和国固体废物污染环境防治法》进行处罚”修改为“拒不改正的，按照有关法律、法规处罚”。

（四）将第六十九条修改为：“违反本条例第四十条第五项或者第六项规定，在收集、运输过程中对生活垃圾进行敞开式压缩、分拣、转运或者混装混运的，由城市管理部门责令改正，没收违法所得，处以五万元以上二十万元以下罚款；情节严重的，处以二十万元以上五十万元以下罚款。擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的按照有关法律、法规处罚。”

（五）删去第七十一条。

六、对《成都市三岔湖水环境保护条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三十三条修改为：“违反本条例第十五条第二款、第三款规定，向湖中乱扔生活垃圾和在岛屿内丢弃生活垃圾的，或者将固体废物丢弃、倾倒湖中和就地掩埋、焚烧的，按照有关法律、法规处罚。”

（三）将第三十六条第二项作为第二款，修改为：“在绿化控制带和三岔湖水域范围内乱扔塑料泡沫、包装袋、玻璃瓶、饮料罐和其他污染物的，按照有关法律、法规处罚。”

七、对《成都市都江堰灌区保护条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三十八条、第四十四条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（三）将第四十五条第二款修改为：“违反本条例第三十三条第二款规定，未向社会公开或者不如实公开主要水污染物的名称、排放方式、排放浓度和总量情况，按照有关法律、法规处罚；未向社会公开或者不如实公开防治水污染设施的建设和运行情况的，由环境保护主管部门责令限期改正，并处五千元以上三万元以下罚款。”

八、对《成都市水资源管理条例》作出修改

将第三十三条修改为：“违反本条例第十九条第二款规定，降低水功能区水质类别和使用功能，由水行政主管部门责令改正，限期采取补救措施。对水域使用功能造成较大影响的，处五万元罚款；对水域使用功能造成严重影响的，处十万元罚款。在水域周边填埋、堆放、存储固体废弃物和其他污染物的，按照有关法律、法规处罚。”

九、对《成都市节约用水管理条例》作出修改

将第三十五条中的“由水行政主管部门责令停止使用，限期改正，并处以2万元以上10万元以下的罚款”修改为“按照有关法律、法规处罚”。

十、对《成都市兴隆湖区域生态保护条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二十九条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

十一、对《成都市龙泉山城市森林公园保护条例》作出修改

（一）将第一条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二条、第七条、第九条、第十一条、第十三条、第十四条、第十五条、第三十三条中的“总体规划”修改为“国土空间规划”；将第十条中的“城乡规划、土地利用规划”修改为“国土空间规划”；将第十六条中的“土地利用总体规划”修改为“国土空间规划”。

十二、对《成都市美丽宜居公园城市建设条例》作出修改

将第一条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

十三、对《成都市环城生态区保护条例》作出修改

将第一条中的“《中华人民共和国环境保护法》”修改为“《中华人民共和国生态环境法典》”。

十四、对《成都市城镇排水与污水处理条例》作出修改

将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

十五、对《成都市〈中华人民共和国渔业法〉实施办法》作出修改

将第二十五条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

本决定自2026年8月15日起施行。

《成都市水污染防治条例》、《成都市饮用水水源保护条例》、《成都市大气污染防治条例》、《成都市建筑垃圾处置管理条例》、《成都市生活垃圾管理条例》、《成都市三岔湖水环境保护条例》、《成都市都江堰灌区保护条例》、《成都市水资源管理条例》、《成都市节约用水管理条例》、《成都市兴隆湖区域生态保护条例》、《成都市龙泉山城市森林公园保护条例》、《成都市美丽宜居公园城市建设条例》、《成都市环城生态区保护条例》、《成都市城镇排水与污水处理条例》、《成都市〈中华人民共和国渔业法〉实施办法》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
