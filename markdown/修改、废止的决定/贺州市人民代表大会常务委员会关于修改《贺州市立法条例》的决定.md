# 贺州市人民代表大会常务委员会关于修改《贺州市立法条例》的决定

贺州市人民代表大会常务委员会
关于修改《贺州市立法条例》的决定

（2026年4月28日贺州市第五届人民代表大会常务委员会第三十五次会议通过　2026年7月30日广西壮族自治区第十四届人民代表大会常务委员会第二十六次会议批准）

贺州市第五届人民代表大会常务委员会第三十五次会议决定对《贺州市立法条例》作如下修改：

一、将第一条修改为：“为了规范本市立法活动，提高立法质量和效率，发挥立法的引领和推动作用，全面推进法治贺州建设，根据《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》、《中华人民共和国立法法》、《广西壮族自治区立法条例》等法律、法规的规定，结合本市实际，制定本条例。”

二、将第三条修改为：“制定本市地方性法规应当维护社会主义法制的统一、尊严、权威，不得与宪法、法律、行政法规和自治区的地方性法规相抵触；应当从实际出发，适应经济社会发展和全面深化改革的要求；应当坚持科学立法、民主立法、依法立法；应当坚持立法的及时性、针对性、有效性。”

三、将第六条修改为：“市人民代表大会及其常务委员会可以就城乡建设与管理、生态文明建设、历史文化保护、基层治理等方面的下列事项制定地方性法规：

“（一）为执行法律、行政法规、自治区的地方性法规的规定，需要根据本市的实际情况作出具体规定的事项；

“（二）属于本市地方性事务需要制定地方性法规的事项；

“（三）除《中华人民共和国立法法》规定的只能制定法律的事项外，其他事项国家尚未制定法律或者行政法规，自治区尚未制定地方性法规的，根据本市的具体情况和实际需要，可以先制定地方性法规。

“法律对设区的市制定地方性法规的事项另有规定的，从其规定。”

四、将第七条第一款修改为：“下列事项由市人民代表大会制定地方性法规：

“（一）法律规定由市人民代表大会作出规定的事项；

“（二）规定本市特别重大的事项。”

五、将第十条改为两条，作为第十条、第十一条，修改为：“第十条编制立法规划和年度立法计划应当遵循突出重点、区分轻重缓急、量力而行、积极而为的原则，认真研究代表议案和建议，广泛征集意见，科学论证评估，根据经济社会发展和民主法治建设的需要，按照加强重点领域、新兴领域立法等要求，确定立法项目。

“第十一条每届常务委员会任期第一年编制本届立法规划，由常务委员会主任会议通过并向社会公布。

“立法规划需要调整的，由常务委员会法制工作机构提出意见，报主任会议决定。”

六、将第十二条改为第十三条，修改为：“常务委员会法制工作机构应当会同有关的专门委员会、常务委员会有关工作机构、市人民政府有关部门，对各方面提出的年度立法计划项目建议进行研究、论证、评估，于每年第四季度拟订下一年度的立法计划草案。年度立法计划由主任会议通过，印发各有关机关和组织执行并向社会公布。

“年度立法计划需要调整的，由常务委员会法制工作机构提出意见，报主任会议决定。”

七、增加一条，作为第十四条：“常务委员会制定、调整立法规划和年度立法计划，应当在通过前报经自治区人民代表大会常务委员会主任会议同意。”

八、将第十三条改为第十五条，修改为：“向市人民代表大会及其常务委员会提出法规案，应当附有法规草案文本、法规草案说明、立法指引，以及必要的参阅资料。修改法规的还应当提交修改前后对照文本。

“法规草案说明应当包括制定或者修改法规的必要性、可行性、依据和主要内容，以及听取和采纳意见的情况、重大问题和重大分歧意见的协调处理情况。设定行政处罚、行政许可和行政强制措施的，应当阐明设立的必要性、论证听证情况以及对经济和社会可能产生的影响。

“立法指引应当包括法规草案各条款的立法目的、依据、参考、事实、理由等详细说明。

“对提请常务委员会审议的法规案，常务委员会法制工作机构应当按照前三款规定审查有关材料，材料符合规定的，将法规案送有关的专门委员会；材料不符合规定的，要求补充完善。”

九、将第十五条改为第十六条，第二款修改为：“专业性较强的法规草案，可以邀请相关领域的专家参与起草工作，或者委托有关专家、教学科研单位、社会组织等起草。”

增加一款，作为第三款：“重要立法项目可以由常务委员会和市人民政府分管领导共同担任组长，组织实施法规草案起草工作，协调解决立法中的重大问题和重要事项。”

十、删去第十六条。

十一、增加一条，作为第十八条：“市人民代表大会有关的专门委员会、常务委员会法制工作机构应当提前参与有关立法项目的调研、起草、论证等相关工作，了解起草工作的进展和动态，与起草单位及时沟通和交换意见。”

十二、将第十八条改为第二十条，修改为：“根据年度立法计划安排提请常务委员会审议的法规案，提案人应当按照年度立法计划确定的时间提请常务委员会审议，不能按时提出的，应当书面向主任会议说明理由。”

十三、将第十九条改为第二十一条，第一款修改为：“列入年度立法计划的立法项目，有关的专门委员会、常务委员会有关工作机构应当组织做好立法调研活动。”

十四、增加两条，作为第二十三条、第二十四条：“第二十三条向市人民代表大会提出的法规案，在市人民代表大会闭会期间，可以先向常务委员会提出，经常务委员会会议依照本条例第四章规定的有关程序审议后，决定提请市人民代表大会审议的，由常务委员会向大会全体会议作说明，或者由提案人向大会全体会议作说明。

“常务委员会依照前款规定审议法规案，应当通过多种形式征求市人民代表大会代表的意见，并将有关情况予以反馈。

“第二十四条常务委员会决定提请市人民代表大会审议的法规案，应当在会议举行的十五日前将法规草案发给代表，并可以适时组织代表研读讨论，征求代表的意见。”

十五、将第二十二条改为第二十六条，修改为：“列入市人民代表大会会议议程的法规案，由有关的专门委员会进行审议，向主席团提出审议意见，并印发会议。”

十六、将第二十七条改为第三十一条，修改为：“法规草案修改稿经各代表团审议，由法制监察司法委员会根据各代表团的审议意见进行修改，提出法规草案表决稿，由主席团提请大会全体会议表决，由全体代表的过半数通过。”

十七、将第三十条改为第三十四条，修改为：“常务委员会组成人员联名提出的法规案，由主任会议决定是否列入常务委员会会议议程，或者先交有关的专门委员会审议、提出意见，再决定是否列入常务委员会会议议程。不列入常务委员会会议议程的，应当向常务委员会会议报告或者向提案人说明。

“专门委员会审议法规案时，应当邀请提案人列席会议，发表意见。”

十八、将第三十二条改为第三十六条，修改为：“列入常务委员会会议议程的法规案，除特殊情况外，常务委员会办事机构应当在会议举行的七日前，将法规草案及其说明发给常务委员会组成人员。

“常务委员会会议审议法规案时，应当邀请有关的市人民代表大会代表列席会议。”

十九、将第三十三条改为第三十七条，修改为：“列入常务委员会会议议程的法规案，一般经三次常务委员会会议审议后再交付表决。

“常务委员会会议第一次审议法规案，在全体会议上听取提案人的说明和有关专门委员会的审议意见，并进行分组审议。

“常务委员会会议第二次审议法规案，在全体会议上听取法制监察司法委员会关于法规草案修改情况和主要问题的汇报，并进行分组审议。

“常务委员会会议第三次审议法规案，在全体会议上听取法制监察司法委员会关于法规草案审议结果的报告，由分组会议对法规草案修改稿进行审议。

“分组审议时，提案人应当派人听取意见，回答询问；常务委员会可以要求有关机关、组织派人介绍情况。”

二十、将第四十二条改为第三十八条，修改为：“列入常务委员会会议议程的法规案，各方面意见比较一致的，经主任会议决定，可以经过两次常务委员会会议审议后交付表决；调整事项较为单一或者部分修改的法规案，各方面意见比较一致的，或者遇有紧急情形的，经主任会议决定，也可以经一次常务委员会会议审议后即交付表决。

“经常务委员会会议一次审议即交付表决的法规案，在全体会议上听取提案人的说明和法制监察司法委员会关于法规草案审议结果的报告。”

二十一、将第三十四条改为第三十九条，修改为：“常务委员会法制工作机构根据常务委员会组成人员的审议意见和各方面提出的意见进行研究，向法制监察司法委员会提出法规草案建议修改稿。”

二十二、将第三十五条改为第四十条，修改为：“法制监察司法委员会根据常务委员会组成人员、有关的专门委员会的审议意见和各方面提出的意见，对法规案进行统一审议，提出法规草案修改情况的汇报或者审议结果报告和法规草案修改稿，对重要的不同意见应当在汇报或者审议结果报告中予以说明。”

二十三、将第三十六条改为第四十一条，第一款修改为：“有关的专门委员会审议法规案时，可以邀请其他专门委员会成员、常务委员会法制工作机构负责人列席会议，发表意见；也可以邀请市人民代表大会代表、有关部门人员、有关专家、法律工作者列席会议，提出意见建议。”

增加一款，作为第二款：“法制监察司法委员会或者有关的专门委员会审议法规案时，应当召开全体会议审议，根据需要，可以要求有关机关、组织派有关负责人说明情况。”

二十四、将第三十八条改为两条，作为第四十三条、第四十四条，修改为：“第四十三条列入常务委员会会议议程的法规案，法制监察司法委员会、有关的专门委员会和常务委员会法制工作机构应当采取座谈会、论证会、听证会等多种形式广泛听取各方面意见。

“法规案有关问题专业性较强，需要进行可行性评估的，应当召开论证会，听取有关专家、部门、市人民代表大会代表等方面的意见。论证情况应当向常务委员会报告。

“法规案有关问题存在重大意见分歧或者涉及利益关系重大调整，需要进行听证的，应当召开听证会，听取有关基层和群体代表、部门、人民团体、专家、市人民代表大会代表和社会有关方面的意见。听证情况应当向常务委员会报告。

“常务委员会法制工作机构应当将法规草案发送相关领域的市人民代表大会代表、县（区）人民代表大会常务委员会以及有关部门、组织和专家等征求意见。在常务委员会会议后，将法规草案及其起草、修改的说明等在贺州人大网或者其他媒体上公布，向社会公开征求意见，但是经主任会议决定不公布的除外。向社会公开征求意见的时间一般不少于三十日。

“向社会公开征求意见的情况，由常务委员会法制工作机构收集并研究处理。

“第四十四条拟提请常务委员会会议审议通过的法规案，在法制监察司法委员会提出审议结果报告前，常务委员会法制工作机构可以对法规草案中主要制度规范的可行性、法规出台时机、法规实施的社会效果和可能出现的问题进行评估。评估情况由法制监察司法委员会在审议报告中予以说明。”

二十五、将第四十五条改为第四十九条，修改为：“列入常务委员会会议议程的法规案，主任会议认为应当提交市人民代表大会会议审议的，应当提请常务委员会会议决定提交市人民代表大会会议审议。”

二十六、将第四十七条改为第五十一条，第一款修改为：“法规案经三次常务委员会会议审议后，仍有重大问题需要进一步研究的，由主任会议提出，经常务委员会全体会议同意，可以暂不付表决，交法制监察司法委员会和有关的专门委员会进一步审议，向主任会议提出报告。”

增加一款，作为第二款：“暂不交付表决的法规案，经过修改或者协调，法规草案中的重大问题得到解决的，由主任会议决定提请常务委员会会议继续审议。法制监察司法委员会根据会议审议意见进行修改，提出审议结果的报告和法规草案表决稿，由主任会议决定提请常务委员会全体会议表决。”

二十七、将第四十八条改为第五十二条，修改为：“列入常务委员会会议审议的法规案，因各方面对制定该法规的必要性、可行性等重大问题存在较大意见分歧搁置审议满两年的，或者因暂不付表决经过两年没有再次列入常务委员会会议议程审议的，主任会议可以决定终止审议，并向常务委员会报告；必要时，主任会议也可以决定延期审议。”

二十八、将第五十条改为第五十四条，修改为：“报请自治区人民代表大会常务委员会批准的法规，如果需要进一步研究的，属于市人民代表大会会议表决通过的，由常务委员会会议审议决定申请撤回；属于常务委员会会议表决通过的，由主任会议研究决定申请撤回。撤回后，可以由法制监察司法委员会提出修改意见，由主任会议提请常务委员会会议审议决定后，再报请批准；也可以由主任会议提请常务委员会会议审议决定不再报请批准。决定对市人民代表大会通过的法规不再报请批准的，应当向下一次市人民代表大会会议报告。

“报请批准的法规需要对一般性条款修改的，由常务委员会法制工作机构提出修改意见，报主任会议同意。

“报请批准的法规被自治区人民代表大会常务委员会退回的，适用本条第一款关于申请撤回后的处理规定。”

二十九、将第五十一条与第五十二条合并，作为第五十五条，修改为：“经自治区人民代表大会常务委员会批准的法规，由常务委员会及时在常务委员会公报、贺州人大网和《贺州日报》上发布公告予以公布，并将有关材料依法备案。

“在常务委员会公报上刊登的法规文本为标准文本。”

三十、将第五十三条改为第五十六条，修改为：“市人民代表大会及其常务委员会制定的地方性法规的解释权属于常务委员会。

“有下列情况之一的，由常务委员会解释：

“（一）地方性法规的规定需要进一步明确具体含义的；

“（二）地方性法规制定后出现新的情况，需要明确适用依据的。”

三十一、将第五十五条改为第五十八条，修改为：“对地方性法规解释的要求，需要进行解释的，由常务委员会法制工作机构会同有关的专门委员会研究拟订地方性法规解释草案，由主任会议决定列入常务委员会会议议程。

“不需要进行解释的，由常务委员会法制工作机构研究拟定不予解释的意见，由主任会议决定答复要求人。”

三十二、将第五十六条改为第五十九条，修改为：“列入常务委员会会议议程的地方性法规解释草案，由常务委员会法制工作机构在会议上作说明，分组会议对地方性法规解释草案进行审议。”

三十三、将第三十九条改为第六十二条，修改为：“法规案在提交市人民代表大会及其常务委员会会议表决前，应当先将法规案的有关书面材料报送自治区人民代表大会常务委员会征求意见。”

三十四、增加两条，作为第六十三条、第六十四条：“第六十三条地方性法规所依据的上位法已经修改或者废止、所规范的社会实际情况发生重大变化的，应当及时予以修改或者废止。

“地方性法规的修改程序，适用本条例的有关规定。

“地方性法规部分条文被修改的，应当公布新的地方性法规文本。

“第六十四条地方性法规明确要求有关国家机关对专门事项作出配套的具体规定的，有关国家机关应当自地方性法规施行之日起一年内作出规定，并将配套规定自公布之日起三十日内报市人民代表大会常务委员会备案。地方性法规对配套的具体规定制定期限另有规定的，从其规定。有关国家机关未能在期限内作出配套的具体规定的，应当向市人民代表大会常务委员会说明情况。”

三十五、将第五十九条改为第六十五条，修改为：“地方性法规实施后，有关的专门委员会、常务委员会有关工作机构可以组织对地方性法规或者地方性法规中的有关规定设定的科学性、可操作性以及有效性等方面进行立法后评估。评估情况应当向常务委员会报告。”

三十六、将第六十条改为第六十六条，第一款修改为：“常务委员会根据立法工作需要，可以与教学科研单位、社会组织等合作建立立法服务基地，开展地方立法研究评估、咨询服务；按照专业门类健全、知识结构合理、人员规模适度的原则，建立立法专家顾问库。”

增加一款，作为第二款：“专门委员会和有关工作机构应当通过发送法规草案，邀请参加立法调研、论证、起草等多种形式，听取立法服务基地和立法专家顾问的意见。”

三十七、增加三条，作为第六十七条、第六十八条、第六十九条：“第六十七条市人民代表大会及其常务委员会根据区域协调发展的需要，可以与有关设区的市人民代表大会及其常务委员会建立区域协同立法工作机制，协同制定地方性法规，在本行政区域或者有关区域内实施。

“第六十八条常务委员会根据立法工作需要，设立基层立法联系点，推动基层立法联系点与人大代表履职活动中心、人大代表联络站等融合建设，深入听取基层群众和有关方面对法规草案和立法工作的意见。”

“第六十九条市人民代表大会有关的专门委员会、常务委员会办事机构和工作机构应当加强立法宣传工作，通过多种形式发布立法信息、介绍情况、回应关切。”

三十八、对部分条文作以下修改：

（一）删去第五条中的“本市”、“市”。

（二）将第十一条改为第十二条，将第一款中的“下年度立法项目的建议”修改为“下年度的立法项目建议”，删去第二款中的“意见和”。

（三）将第十四条改为第十七条，将其中的“对涉及重大利益关系调整”修改为“对存在重大意见分歧或者涉及利益关系重大调整”。

（四）将第二十一条改为第二十五条，删去第一款中的“常务委员会或”，将第二款中的“听取意见、回答询问”修改为“听取意见，回答询问”。

（五）将第二十三条改为第二十七条，将其中的“法制委员会”修改为“法制监察司法委员会”，“有关专门委员会”修改为“有关的专门委员会”。

（六）将第二十六条改为第三十条，删去其中的“在大会闭幕后”。

（七）将第二十八条改为第三十二条，将其中的“下列机关或者人员”修改为“下列机关、单位或者人员”，在第三项中的“专门委员会”前增加“各”。

（八）将第二十九条改为第三十三条，将第二款中的“有关专门委员会”修改为“有关的专门委员会”。

（九）将第三十一条改为第三十五条，删去第二款中的“列入常务委员会会议议程的法规案，专门委员会审议后提出审议意见，印发常务委员会会议。”

（十）将第三十七条改为第四十二条，删去其中的“分别”。

（十一）将第四十一条改为第四十六条，将其中的“法规案”修改为“法规草案修改稿”，删去“第三次”，将“法制委员会”修改为“法制监察司法委员会”，“以”修改为“由”。

（十二）将第四十三条改为第四十七条，将第一款中的“法规草案”修改为“法规草案表决稿”，将第二款中的“法制委员会”修改为“法制监察司法委员会”。

（十三）将第五十四条改为第五十七条，在其中的“市人民政府”后增加“市监察委员会”。

（十四）将第五十七条改为第六十条，将第一款、第二款中的“法规解释草案”修改为“地方性法规解释草案”，第一款中的“法制委员会”修改为“法制监察司法委员会”、“进行修改”修改为“进行审议、修改”。

本决定自公布之日起施行。

《贺州市立法条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
