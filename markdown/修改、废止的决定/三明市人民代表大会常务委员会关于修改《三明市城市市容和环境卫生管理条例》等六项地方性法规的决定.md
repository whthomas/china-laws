# 三明市人民代表大会常务委员会关于修改《三明市城市市容和环境卫生管理条例》等六项地方性法规的决定

三明市人民代表大会常务委员会
关于修改《三明市城市市容和环境卫生管理
条例》等六项地方性法规的决定

（2026年8月25日三明市第十四届人民代表大会常务委员会第三十四次会议通过　2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

三明市第十四届人民代表大会常务委员会第三十四次会议决定对《三明市城市市容和环境卫生管理条例》等六项地方性法规作如下修改：

一、三明市城市市容和环境卫生管理条例

（一）将第五条第三款修改为：“自然资源、公安、卫生健康、交通运输、水行政、生态环境、市场监督管理等部门按照各自职责，做好市容和环境卫生管理的相关工作。”

（二）将第九条第一款修改为：“市容和环境卫生行政主管部门、城市管理行政执法部门、文化和旅游、卫生健康等部门应当加强市容和环境卫生科学知识的宣传教育，倡导文明行为规范，提高公民自觉维护市容和环境卫生的意识。”

（三）将第二十九条第一项修改为：“（一）随地吐痰；”

将第二项修改为：“（二）随地便溺，乱倒粪便；”

（四）将第四十三条第二项修改为：“（二）违反本条例第二十九条第（二）项规定的，责令清理，处一百元以上五百元以下罚款；”

（五）删去第四十三条第三项、第六项。

（六）将第四十三条第四项改为第三项，修改为：“（三）违反本条例第三十七条第一款规定的，责令改正，处五百元以上二千元以下罚款；”

（七）将第四十三条第五项改为第四项，修改为：“（四）违反本条例第三十三条规定的，责令改正；拒不改正的，处一百元以上五百元以下罚款”。

（八）将第四十四条修改为：“市容和环境卫生行政主管部门和其他有关职能部门违反本条例规定，有下列情形之一的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任；给当事人造成损失的，依法承担赔偿责任：

“（一）对依法应当受理的投诉、举报不受理，或者不依法处理的；

“（二）对依法应当予以制止或者处罚的违法行为不予制止、处罚，或者不依法处理的；

“（三）包庇、纵容违法行为人的；

“（四）法律、法规规定的其他违法情形。”

二、三明市东牙溪和薯沙溪水库饮用水水源保护条例

（一）将第一条修改为：“为了加强东牙溪和薯沙溪水库饮用水水源保护，防治水源污染，保障市区饮用水安全，维护公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》和有关法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“东牙溪和薯沙溪水库是三明市区重要饮用水水源，水库功能优先保障饮用水供水安全，兼顾防洪等，保障基本生态用水。”

（三）将第四条修改为：“水库水源保护应当遵循科学规划、保护优先、系统治理、绿色发展、生态补偿、公众参与、损害担责的原则。”

（四）将第七条第三款修改为：“发展和改革、公安、财政、自然资源、住房和城乡建设、交通运输、农业农村、卫生健康、林业、民政、国有资产监管等主管部门根据各自职责，做好水库水源保护工作。”

（五）将第九条第三款修改为：“对污染水库水源、破坏水库生态等损害社会公共利益的行为，法律规定的机关和有关组织可以依法向人民法院提起诉讼。”

（六）将第十条第二款修改为：“水库水源保护规划应当结合水库水源实际，与水资源保护、防洪等要求和本行政区域水生态环境保护规划、水中长期供求规划、城乡供水专项规划等相衔接。”

（七）将第三十四条修改为：“市、水库水源保护区域所在的县级人民政府应当组织生态环境、水行政、应急管理等主管部门定期开展水库水源周边生态环境安全隐患排查和生态环境风险评估工作，制定和完善水库水源安全突发事件应急预案。

“市人民政府水库水源保护管理机构、饮用水供水单位和水库水源保护区域内可能发生水污染事故的企事业单位，应当根据所在地饮用水安全突发事件应急预案，制定相应的突发事件应急预案，报市、所在的县级人民政府备案，并定期进行演练。

“饮用水水源发生水污染事故，或者发生其他可能影响饮用水安全的突发性事件，责任单位应当采取应急处理措施，排除或者减轻污染危害。饮用水供水单位应当向市、所在的县级人民政府报告，并向社会公开。有关人民政府应当根据实际情况及时启动应急预案，采取有效措施，保障供水安全。

“市、水库水源保护区域所在的县级人民政府应当按照有关法律法规的规定，及时发布突发生态环境事件及其应急处置工作信息。”

（八）将第三十七条第二项修改为：“（二）违反本条例第十七条第一款第四项规定，个人放养畜禽的，责令停止违法行为，可以处二百元以上五百元以下罚款。”

（九）删去第三十八条。

（十）将第三十九条改为第三十八条，修改为：“以拖延、围堵、滞留执法人员等方式拒绝、阻挠监督检查和突发生态环境事件调查处理，或者在接受监督检查和调查处理时弄虚作假或者拒不提供必要资料的，由负有生态环境保护监督管理职责的部门按职责分工责令改正，处五万元以上二十万元以下的罚款；对直接负责的主管人员和其他直接责任人员，处五千元以上五万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（十一）将第四十条改为第三十九条，修改为：“水库水源保护有关单位有下列情形之一的，对负有责任的领导人员和直接责任人员依法给予处分：

“（一）发现污染和破坏水库水源违法行为或者接到举报不依法调查处理的；

“（二）未依法公开水库水源水环境质量、预警等相关信息的；

“（三）怠于履行监测、巡查等职责，未能及时发现水库水源安全问题的；

“（四）截留、挤占或者挪用水库水源生态保护补偿资金和保护经费的；

“（五）法律、法规规定的其他违法情形。”

三、三明市城市园林绿化管理条例

（一）将第二十三条第四项修改为：“（四）在园林绿地内取土采石；”

（二）将第三十六条修改为：“城市园林绿化有关部门违反本条例规定，有下列情形之一的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任：

“（一）未按照规定对城市园林绿化有关事项进行审核、审批的；

“（二）对依法应当受理的投诉举报不受理的；

“（三）对依法应当予以制止、处罚的违法行为不予制止、处罚的；

“（四）法律、法规规定的其他违法情形。”

四、三明市城市扬尘污染防治条例

（一）将第一条修改为：“为了有效防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》、《福建省大气污染防治条例》等法律法规，结合本市实际，制定本条例。”

（二）在第十六条第一款中的“砂土”后增加“、铁矿石”。

（三）将第二十六条第二款修改为：“施工单位违反本条例第十二条第一项和第二项规定，受到罚款处罚，被责令改正的，依法作出处罚决定的主管部门应当组织复查，发现其继续实施该违法行为、拒不改正或者拒绝、阻挠复查的，可以自责令改正之日的次日起，按照原罚款数额按日连续处罚，并及时采取措施制止违法行为。”

（四）将第二十八条第二款修改为：“经营管理者违反本条例第十六条第一款规定，受到罚款处罚，被责令改正的，依法作出处罚决定的主管部门应当组织复查，发现其继续实施该违法行为、拒不改正或者拒绝、阻挠复查的，可以自责令改正之日的次日起，按照原罚款数额按日连续处罚，并及时采取措施制止违法行为。”

（五）将第二十九条修改为：“违反本条例第十七条规定，运输车辆未采取密闭、覆盖等措施防止物料抛撒滴漏，或者未按照规定路线行驶的，由城市管理、交通运输主管部门按照职责责令立即改正，处五千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。”

（六）将第三十一条修改为：“负有扬尘污染防治监督管理职责的部门在扬尘污染防治工作中有下列情形之一的，对负有责任的领导人员和直接责任人员依法给予处分：

“（一）怠于履行监测、巡查等监督管理职责，造成严重后果的；

“（二）对接到的投诉、举报，未按照规定及时调查处理或者及时移交有管辖权的部门处理的；

“（三）扬尘污染防治信息等应当依法公开而未公开的；

“（四）法律、法规规定的其他违法情形。”

五、三明市公共文明行为促进条例

将第二十八条修改为：“违反本条例规定，实施机动车乱停放、人行横道前不礼让行人，非机动车随意变道、逆行，行人闯红灯、跨越道路隔离设施，乱丢垃圾，随地吐痰、便溺，在禁烟场所吸烟，携犬出户不清理犬粪，社会生活噪声扰民，乱排油烟等行为的，依照《中华人民共和国生态环境法典》、《中华人民共和国道路交通安全法》等有关法律、法规的规定处罚。”

六、三明市三元区环城山体保护条例

（一）将第一条修改为：“为了加强三元区环城山体（以下简称山体）保护，优化人居环境，促进人与自然和谐共生，根据有关法律法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“山体保护应当坚持预防为主、生态优先、科学规划、系统治理、公众参与、损害担责的原则。”

（三）将第十四条第一款第四项修改为：“（四）倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾；”

（四）将第二十九条修改为：“违反本条例第十四条规定，擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾的，由城市管理主管部门依照《中华人民共和国生态环境法典》的规定处罚。”

（五）将第三十二条修改为：“负有山体保护管理职责的国家机关有下列情形之一的，对负有责任的领导人员和直接责任人员依法给予处分：

“（一）在山体保护范围内违法批准建设项目的；

“（二）未履行山体修复治理监督管理职责的；

“（三）未履行山体保护监测预警和巡查执法职责的；

“（四）发现破坏山体的违法行为或者接到有关投诉举报，未依法及时调查处理的；

“（五）法律法规规定的其他违法情形。”

本决定自公布之日起施行。

《三明市城市市容和环境卫生管理条例》等六项地方性法规根据本决定作相应修改后，重新公布。
