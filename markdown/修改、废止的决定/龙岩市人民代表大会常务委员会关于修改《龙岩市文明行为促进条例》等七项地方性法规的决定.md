# 龙岩市人民代表大会常务委员会关于修改《龙岩市文明行为促进条例》等七项地方性法规的决定

龙岩市人民代表大会常务委员会
关于修改《龙岩市文明行为促进条例》
等七项地方性法规的决定

（2026年9月11日龙岩市第六届人民代表大会常务委员会第三十二次会议通过　2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

龙岩市第六届人民代表大会常务委员会第三十二次会议决定对《龙岩市文明行为促进条例》等七项地方性法规作如下修改：

一、龙岩市文明行为促进条例

（一）将第十五条第三项修改为：“（三）不违反规定焚烧秸秆、树叶、杂草、垃圾等产生烟尘污染的物质”。

（二）将第四十四条修改为：“违反本条例规定，制造社会生活噪声，干扰他人正常生活、工作和学习的，依照《中华人民共和国生态环境法典》处罚；构成违反治安管理行为的，依照《中华人民共和国治安管理处罚法》处罚。”

（三）将第四十六条改为第四十五条，修改为：“单位或者个人违反市容环境卫生规定，由城市管理行政执法部门依照《福建省城市市容和环境卫生管理办法》处罚。”

（四）将第四十八条改为第四十六条，修改为：“排放油烟的餐饮服务业经营者未安装油烟净化等污染防治设施、未保持正常使用油烟净化等污染防治设施或者未采取其他油烟净化措施，致使超过排放标准排放油烟，或者将油烟直接排入下水管道的，由县级以上地方人民政府确定的监督管理部门责令改正，处五千元以上五万元以下的罚款；拒不改正的，责令停业整治。

“在当地人民政府禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地的，由城市管理行政执法部门责令改正，依法没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

（五）删去第四十五条、第四十七条。

此外，根据修改，对条文顺序作相应调整。

二、龙岩市饮用水水源保护条例

（一）将第一条修改为：“为了加强饮用水水源保护，保障饮用水安全，维护公众生命安全和身体健康，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《福建省水资源条例》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第十五条修改为：“在饮用水水源准保护区内，禁止下列行为：

“（一）新建、扩建对水体污染严重的建设项目，改建增加排污量或者改变排放污染物种类的建设项目；

“（二）使用含磷洗涤剂，滥用化肥；

“（三）破坏湿地、毁林开荒、损害植被等破坏水环境生态平衡的行为；

“（四）种植会引起土壤退化、地表水污染的速生树种；

“（五）从事可能严重影响饮用水水源水量或者水质的矿产勘查、开采活动；

“（六）向水体排放持久性有机污染物、病原微生物、放射性废水等有毒有害物质；

“（七）毒鱼、炸鱼、电鱼；

“（八）使用剧毒、高毒、高残留农药；

“（九）擅自排放、倾倒工业、生活污水和垃圾；

“（十）其他严重污染饮用水水源的行为。”

（三）将第十六条第一款修改为：“在饮用水水源二级保护区内，除第十五条规定的禁止行为外，还禁止下列行为：

“（一）新建、改建、扩建排放污染物的建设项目；

“（二）设置油库、加油站；

“（三）建设畜禽养殖场、养殖小区；

“（四）建设工业固体废物、建筑垃圾、危险废物集中贮存、利用、处置的设施、场所和生活垃圾填埋场；

“（五）设置装卸垃圾、粪便、油类和有毒有害物品的码头；

“（六）设置排污口；

“（七）围垦河道、滩地或者在河道、水库等采石、采砂、取土、弃置砂石；

“（八）经营水上餐饮业；

“（九）从事网箱养殖、旅游等活动，未按照规定采取有效措施防止污染饮用水水体的；

“（十）开采矿产；

“（十一）建造坟墓；

“（十二）堆放、存贮可能造成水体污染的固体废弃物或者其他污染物；

“（十三）法律、法规规定在饮用水水源二级保护区内的其他禁止行为。”

（四）第十七条第一款第一项后增加一项，作为第二项：“（二）堆置、存放和填埋工业废渣、城乡垃圾、粪便或者其他废弃物”。

（五）删去第三十七条、第三十九条、第四十条、第四十一条。

此外，根据修改，对条文顺序作相应调整。

三、龙岩市实施河长制条例

将第一条修改为：“为了推进和保障河长制实施，加强河湖保护管理，落实属地责任，健全长效机制，推进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《福建省水资源条例》、《福建省生态文明建设促进条例》等法律、法规，结合本市实际，制定本条例。”

四、龙岩市扬尘污染防治条例

（一）将第一条修改为：“为了有效防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《福建省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第四十条改为第三十五条，修改为：“违反本条例第二十条规定，运输易产生扬尘污染物料的车辆，未采取扬尘污染防治措施的，或者未按规定路线行驶的，在城市规划区内的由城市管理部门责令改正，处二千元以上二万元以下罚款；在城市规划区外的由交通运输主管部门责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶，违反的由公安机关交通管理部门依法处理。”

（三）删去第三十五条、第三十六条、第三十七条、第三十八条、第三十九条、第四十一条、第四十二条、第四十三条、第四十四条。

此外，根据修改，对条文顺序作相应调整。

五、龙岩市农村人居环境治理条例

将第三十九条第三项修改为：“（三）违反规定焚烧树叶或者其他农业废弃物”。

六、龙岩市汀江保护条例

（一）将第二十九条第二款修改为：“禁止在汀江流域水土流失严重、生态脆弱的区域开展可能造成水土流失的生产建设活动。确因国家发展战略和国计民生需要建设的，应当进行科学论证并依法办理审批手续。”

（二）将第三十六条第三款修改为：“禁止在汀江流域开放水域养殖、投放不符合生态要求的外来物种或者其他非本地物种种质资源。”

（三）将第四十九条第一款修改为：“违反本条例第二十条第二款规定，依照《中华人民共和国生态环境法典》处罚。”

（四）将第五十条修改为：“违反本条例第二十一条第一款规定，未经有管理权的生态环境主管部门批准，新建、扩建排污口，或者改建增加水污染物排放量的排污口的，除本条第二款规定外，由生态环境主管部门责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者负担，处二万元以上十万元以下的罚款；情节严重的，处十万元以上五十万元以下的罚款，责令限制生产、停产整治。

“违反本条例规定，在饮用水水源保护区内设置排污口的，或者在自然保护地水体等具有特殊经济文化价值的水体、生态保护红线区域及其他需要特别保护的区域新设排污口的，由县级以上地方人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由生态环境主管部门处十万元以上五十万元以下的罚款；情节严重的，处五十万元以上一百万元以下的罚款，责令限制生产、停产整治。”

七、龙岩市烟花爆竹燃放管理条例

（一）将第一条修改为：“为了加强烟花爆竹燃放管理，防治噪声污染、大气污染，保障公共安全和人身、财产安全，营造良好的生产生活环境，根据《中华人民共和国生态环境法典》、国务院《烟花爆竹安全管理条例》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第五条修改为：“市、县（市、区）人民政府应当建立烟花爆竹燃放管理工作联席会议制度，综合协调烟花爆竹燃放管理工作中的重大事项。

“公安机关负责烟花爆竹的公共安全管理，核发烟花爆竹运输许可证和焰火燃放许可证，依法查处非法运输和非法燃放的行为。

“应急管理主管部门负责烟花爆竹生产和经营环节的安全监督管理，核发烟花爆竹生产、经营许可证，依法查处非法生产、经营、储存烟花爆竹的行为。

“城市管理主管部门负责依法查处销售燃放烟花爆竹过程中违法占道、影响环境卫生、破坏城市园林绿地的行为。

“市场监管主管部门负责烟花爆竹的质量监督，依法查处无照经营、经营不符合国家标准或者行业标准烟花爆竹的行为。

“林业主管部门负责林地等重点防火区域野外用火的监督管理，指导防火巡护、火源管控和火情早期处理工作；协同公安机关做好林地禁止燃放烟花爆竹的相关工作。

“生态环境、住房和城乡建设、教育、交通运输、民政、宗教、文化等部门按照各自职责，做好烟花爆竹燃放管理的相关工作。”

（三）将第六条修改为：“乡镇人民政府和街道办事处应当将烟花爆竹燃放管理纳入基层社会治理工作，加强组织协调和指导监督，建立网格化管理机制，明确具体网格责任人，负责本辖区内烟花爆竹安全管理的宣传教育、巡查劝阻等工作。

“居民委员会、村民委员会、物业服务企业应当加强对居民、村民、业主的宣传教育，引导移风易俗和依法、文明、安全燃放烟花爆竹。”

（四）将第八条修改为：“禁止生产、销售或者燃放不符合质量标准的烟花爆竹。

“禁止从事烟花爆竹批发的经营者向从事烟花爆竹零售的经营者供应按照国家标准规定应当由专业燃放人员燃放的烟花爆竹。

“禁止从事烟花爆竹零售的经营者销售按照国家标准规定应当由专业燃放人员燃放的烟花爆竹。”

（五）将第九条修改为：“下列地点和区域任何时段禁止燃放烟花爆竹：

“（一）文物保护单位；

“（二）车站、码头、飞机场等交通枢纽以及铁路线路安全保护区内；

“（三）易燃易爆物品生产、储存单位；

“（四）输变电设施安全保护区内；

“（五）医疗机构、幼儿园、学校、敬（养）老院、图书馆、档案馆、博物馆；

“（六）城市主次干道（含人行道）及高架路、立交桥、人行天桥及地下通道；

“（七）风景名胜区和公共绿地、苗圃等重点防火区；

“（八）林地、自然保护区等重点防火区；

“（九）住宅小区的公共走廊、楼梯、电梯、屋顶、阳台、窗口等区域以及建筑物、构筑物室内；

“（十）商场、集贸市场、文化娱乐场所等人员密集场所；

“（十一）法律、法规以及县级以上地方人民政府规定的禁止燃放烟花爆竹的其他地点和区域。”

（六）将第十条修改为：“龙岩中心城区为限制燃放烟花爆竹区域，具体范围由市人民政府确定并公布。

“龙岩中心城区允许燃放烟花爆竹的时间为每年农历十二月二十三至正月十五每日六时至二十二时，其中除夕、正月初一和正月十五不限时，其他时间禁止燃放烟花爆竹。

“龙岩中心城区允许销售和燃放的烟花爆竹为国家标准《烟花爆竹安全与质量》中的C2级、D级烟花爆竹，其他种类的烟花爆竹禁止销售和燃放。

“在龙岩中心城区燃放烟花的，应当在新罗区人民政府划定的烟花集中燃放点燃放，其他地点禁止燃放。

“在住宅小区燃放爆竹的，应当在燃放点燃放。龙岩中心城区的居民委员会应当按照确保安全的原则，指导住宅小区指定燃放点并设置明显标志，引导居民安全燃放。住宅小区燃放点由物业服务企业负责日常安全管理，明确消防安全责任人，并向居民公示。无物业服务企业的住宅小区，由业主委员会负责日常安全管理。

“龙岩中心城区的殡仪馆、公墓等公共祭拜场所，可以在指定区域和时间燃放爆竹。”

（七）将第十一条修改为：“永定区、上杭县、武平县、连城县、长汀县、漳平市限制或者禁止燃放烟花爆竹的时间、地点和种类，由各县（市、区）人民政府确定并公布。”

（八）将第十二条修改为：“龙岩中心城区不得设置烟花爆竹批发场所及常设的零售点。

“龙岩中心城区的烟花爆竹临时销售点，由新罗区应急管理主管部门会同公安、城市管理等部门合理确定。临时销售点允许零售烟花爆竹的时间为农历十二月二十三至正月十五，其他时间不得销售。”

（九）将第十四条修改为：“燃放烟花爆竹应当遵守下列规定：

“（一）不得向他人、车辆、建筑物、化粪池、地下管网、公共绿地投掷烟花爆竹；

“（二）不得妨碍行人、车辆安全通行；

“（三）不得将点燃的烟花爆竹对准和指向容易引起燃烧、爆炸的物品；

“（四）不得使用无人机搭载燃放烟花爆竹；

“（五）不得采用其他危害公共安全和人身、财产安全的方式燃放烟花爆竹。”

（十）将第二十二条修改为：“违反本条例规定的行为，法律、法规已有法律责任规定的，从其规定。”

（十一）将第二十三条第一款修改为：“无民事行为能力人或者限制民事行为能力人燃放烟花爆竹的，应当由监护人陪同。”

（十二）将第二十五条修改为：“从事烟花爆竹批发的经营者向从事烟花爆竹零售的经营者供应本区域禁止经营的烟花爆竹的，由应急管理主管部门责令停止违法行为，处二万元以上十万元以下的罚款，并没收非法经营的物品及违法所得；情节严重的，吊销烟花爆竹经营许可证。

“从事烟花爆竹零售的经营者，销售本区域禁止经营的烟花爆竹的，由应急管理主管部门责令停止违法行为，处一千元以上五千元以下罚款，并没收非法经营的物品及违法所得；情节严重的，吊销烟花爆竹经营许可证。”

（十三）将第二十六条修改为：“在禁止燃放烟花爆竹的时间、地点和区域燃放烟花爆竹，或者以危害公共安全和人身、财产安全的方式燃放烟花爆竹的，由公安机关责令停止燃放，并处一百元以上五百元以下罚款；构成违反治安管理行为的，依法给予治安管理处罚。

“因违法燃放烟花爆竹产生社会生活噪声，干扰他人正常生活、工作和学习，构成违反治安管理行为的，由公安机关依照《中华人民共和国治安管理处罚法》处罚。”

（十四）将第三十一条修改为：“公安、应急管理、城市管理等部门的工作人员，在烟花爆竹燃放管理工作中，不依法履行职责，滥用职权、徇私舞弊、玩忽职守的，由其所在单位或者上级主管部门对直接负责的主管人员和其他直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（十五）对部分条文作以下修改：

1.将第二条中的“燃放管理”修改为“燃放及其相关管理活动”。

2.将第二十四条中的“公务”修改为“公职”。

3.将第十三条、第十九条、第二十条、第二十一条、第二十七条、第二十八条、第二十九条、第三十条中“公安部门”修改为“公安机关”。

4.将第十六条、第十八条、第二十八条的“限制燃放烟花爆竹区域”修改为“禁止、限制燃放烟花爆竹区域”。

本决定自公布之日起施行。
