# 无锡市人民代表大会常务委员会关于废止《无锡国家高新技术产业开发区条例》《无锡市商品交易市场管理条例》的决定

无锡市人民代表大会常务委员会关于废止
《无锡国家高新技术产业开发区条例》《无锡市
商品交易市场管理条例》的决定

（2025年10月29日无锡市第十七届人民代表大会常务委员会第三十三次会议通过　2025年11月27日江苏省第十四届人民代表大会常务委员会第十九次会议批准）

无锡市第十七届人民代表大会常务委员会第三十三次会议决定，废止《无锡国家高新技术产业开发区条例》《无锡市商品交易市场管理条例》。

本决定自2026年1月1日起生效。
