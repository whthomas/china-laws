# 新乡市人民代表大会常务委员会关于修改《新乡市城市市容和环境卫生管理条例》、《新乡市居民住宅区消防安全管理条例》的决定

新乡市人民代表大会常务委员会关于修改
《新乡市城市市容和环境卫生管理条例》、
《新乡市居民住宅区消防安全管理
条例》的决定

（2026年4月28日新乡市第十四届人民代表大会常务委员会第三十一次会议通过　2026年5月28日河南省第十四届人民代表大会常务委员会第二十四次会议批准）

新乡市第十四届人民代表大会常务委员会第三十一次会议决定：

一、对《新乡市城市市容和环境卫生管理条例》作出修改

（一）在第二条中增加一款，作为第三款：“本条例未作规定的，适用有关法律、法规的规定。”

（二）将第五条、第十三条、第二十三条中的“乡（镇）”修改为“乡镇”。

（三）将第六条中的“城市总体规划”修改为“国土空间总体规划”。

（四）在第十条第三款中增加“按照国家和省有关规定，”。

（五）删去第十八条第一款中的“加强对共享交通工具的准入和经营服务管理”，修改为：“建立与城市空间承载能力、公众出行需求等相适应的共享交通工具投放机制，科学施划配套的停车点位，完善共享交通工具服务质量评价制度，定期评估调整，及时向社会公布”。

将第二款修改为：“共享交通工具经营者应当遵守市、县（市、区）人民政府及其有关部门的管理要求，有序投放符合有关技术标准规定的车辆，采取先进技术手段规范运营和服务，对车辆规范停放实施跟踪管理，加强车辆日常维护，及时清理妨碍市容和公共交通秩序的共享交通工具。”

将第三款修改为：“共享交通工具承租者应当文明用车、安全骑行、规范停放。”

（六）将第三十四条第二款修改为：“本市推行生活垃圾分类投放、分类收集、分类运输、分类处理制度，实现生活垃圾分类制度有效覆盖。”

（七）增加一条，作为第四十九条：“违反第十八条规定，共享交通工具经营者有下列行为之一，按照下列规定处罚：

“（一）投放的车辆不符合有关技术标准规定的，由交通运输主管部门责令限期改正；逾期不改正的，处以一万元以上五万元以下的罚款；

“（二）未及时清理妨碍市容和公共交通秩序的共享交通工具的，由城市市容和环境卫生行政主管部门责令限期改正；逾期不改正的，处以一万元以上三万元以下的罚款。”

（八）删去第五十二条。

（九）删去第五十三条中的“、第三十五条”和“第一项”。

（十）将第五十六条修改为：“违反第四十一条规定，运输垃圾、渣土、砂石、土方、灰浆、粪便等散装、流体物料的车辆，未采取密闭或者其他措施防止物料遗撒，或者未按照规定路线行驶的，由市、县（市）人民政府确定的监督管理部门按照职责分工责令改正，处以二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶。”

二、对《新乡市居民住宅区消防安全管理条例》作出修改

（一）在第五条第二款中的“自然资源和规划”后增加“、城市管理”。

删去第三款中的“城市管理、”。

（二）增加一条，作为第十三条：“城市管理部门依法对居民住宅区户外广告妨碍消防安全疏散、灭火救援、建筑防排烟等问题进行监督管理；督促燃气经营者指导用户安全用气并对燃气设施定期进行安全检查，依法查处燃气违法行为；负责对住房城乡建设部门发现并移交的消防安全违法行为实施行政处罚。”

（三）将第十三条修改为：“乡镇人民政府、街道办事处应当确定消防安全管理人，建立健全消防安全组织；依法开展消防行政执法工作，加强居民住宅区的消防安全检查，协调相关职能部门解决公共消防设施建设和维护管理问题，及时将无权查处的消防安全违法行为移交消防救援机构或者公安派出所；组织开展经常性的消防宣传教育，定期检查指导村（居）民委员会开展群众性消防工作。”

（四）删去第十四条第一款中的“建立微型消防站，”。

在“开展消防演练”后增加“和群众性自防自救工作”。

（五）将第十九条中的“市、县（市）人民政府自然资源和规划部门、应急管理部门、消防救援机构依法共同组织编制”，修改为“市、县（市）消防救援机构应当会同应急管理部门、自然资源和规划部门编制”。

（六）增加一条，作为第二十一条：“市、县（市）人民政府有关部门应当将公共消防设施、电动自行车、电动三轮车集中停放场所和充电设施纳入城镇老旧小区改造、城市更新专项规划和年度实施计划，提升居民住宅区消防安全水平。”

（七）将第二十条中的“村民委员会”修改为“村（居）民委员会”。

（八）在第二十二条第四款中的“应当”后增加“立即组织应急维修，”。

（九）在第二十四条中增加一款，作为第二款：“建设单位、施工单位应当严格落实消防安全规定，使用符合消防安全要求的材料、工艺和设备，加强对动火作业和用电的安全管理。”

将第三款修改为：“鼓励在居民住宅区电梯安装电动自行车智能阻止系统，在居民住宅户内安装独立式火灾探测报警器。”

（十）将第二十五条第一款修改为：“新建居民住宅区应当规划和配套建设电动自行车、电动三轮车集中停放场所和充电设施，明确布局和配建比例，将配建要求纳入新建项目规划条件，在建设工程设计方案审查、建设工程规划许可阶段严格审查，并依法进行规划核实。”

在第三款中的“日常管理维护”后增加“，合理确定充电服务价格”。

（十一）在第二十七条第一款中的“住房城乡建设部门”后增加“、城市管理部门以及乡镇人民政府、街道办事处”。

（十二）将第三十三条第六项中的“安装、改装、拆除燃气设备和用具”修改为“擅自安装、改装、拆除户内燃气设施和燃气计量装置”。

增加两项，作为第八项、第九项：“（八）携带电动自行车或者其充电电池进入电梯轿厢；（九）损坏电缆井、管道井的防火分隔或者在电缆井、管道井内堆放杂物”。

（十三）删去第三十六条第一款中的“第二项”、“第五项”。

增加一款，作为第二款：“居民住宅区的物业服务企业或者管理单位违反本条例第十七条第一款第二项、第五项规定，由乡镇人民政府、街道办事处责令限期改正；逾期不改正的，处以二千元以上五千元以下罚款。”

（十四）将第三十六条第二款、第三十七条中的“消防救援机构”修改为“乡镇人民政府、街道办事处”。

本决定自2026年9月1日起施行。

《新乡市城市市容和环境卫生管理条例》、《新乡市居民住宅区消防安全管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
