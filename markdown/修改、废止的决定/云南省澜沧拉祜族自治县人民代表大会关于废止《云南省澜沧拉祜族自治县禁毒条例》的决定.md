# 云南省澜沧拉祜族自治县人民代表大会关于废止《云南省澜沧拉祜族自治县禁毒条例》的决定

云南省澜沧拉祜族自治县人民代表大会
关于废止《云南省澜沧拉祜族自治县
禁毒条例》的决定

（2026年3月2日云南省澜沧拉祜族自治县第十六届人民代表大会第五次会议第四次全体会议通过　2026年5月28日云南省第十四届人民代表大会常务委员会第二十三次会议批准）

云南省澜沧拉祜族自治县第十六届人民代表大会第五次会议对《云南省澜沧拉祜族自治县人民代表大会关于废止〈云南省澜沧拉祜族自治县禁毒条例〉的决定（草案）》进行了审议，决定废止《云南省澜沧拉祜族自治县禁毒条例》（1994年3月24日云南省澜沧拉祜族自治县第十届人民代表大会第二次会议通过，1994年6月2日云南省第八届人民代表大会常务委员会第七次会议批准。2011年1月21日云南省澜沧拉祜族自治县第十三届人民代表大会第四次会议修订，2011年3月30日云南省第十一届人民代表大会常务委员会第二十二次会议批准），并依照法定程序报请云南省人民代表大会常务委员会审议批准。

本决定自公布之日起施行。
