# 泸州市人民代表大会常务委员会关于修改《泸州市生活垃圾分类管理条例》、《泸州市中心城区山体保护条例》的决定

泸州市人民代表大会常务委员会关于
修改《泸州市生活垃圾分类管理条例》、
《泸州市中心城区山体保护条例》的决定

（2026年7月14日泸州市第九届人民代表大会常务委员会第四十次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

泸州市第九届人民代表大会常务委员会第四十次会议决定：

一、对《泸州市生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了加强生活垃圾分类管理，提高生活垃圾减量化、资源化、无害化水平，改善人居环境，促进社会文明，维护生态安全，根据《中华人民共和国生态环境法典》等法律法规，结合泸州市实际，制定本条例。”

（二）将第三十六条修改为：“违反本条例第十二条第一款规定，未在指定的地点分类投放生活垃圾的，由县（区）人民政府环境卫生主管部门责令改正；拒不改正的，对单位处五万元以上五十万元以下罚款，对个人处一百元以上五百元以下罚款。”

（三）将第三十八条第一款第一项修改为：“（一）分类收集、运输车辆未喷涂分类标识，运输车辆未安装定位和监控系统并与生活垃圾分类管理信息平台联网的，责令改正，逾期未改正的，处二千元以上二万元以下罚款；运输车辆未保持密闭的，责令改正，处二千元以上二万元以下罚款，拒不改正的，车辆不得上道路行驶。”

第二项修改为：“（二）未按照规定的时间、频次收集、运输生活垃圾的，责令改正，处二千元以上二万元以下罚款；未按照规定路线行驶的，责令改正，处二千元以上二万元以下罚款，拒不改正的，车辆不得上道路行驶。”

二、对《泸州市中心城区山体保护条例》作出修改

将第一条修改为：“为了加强中心城区山体保护，优化人居环境，彰显山水城市特色，推进生态文明建设，根据有关法律法规，结合泸州市实际，制定本条例。”

本决定自2026年8月15日起施行。

《泸州市生活垃圾分类管理条例》、《泸州市中心城区山体保护条例》根据本决定作相应修改，重新公布。
