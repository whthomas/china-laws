# 焦作市人民代表大会常务委员会关于修改《焦作市国土空间规划管理条例》的决定

焦作市人民代表大会常务委员会关于修改
《焦作市国土空间规划管理条例》的决定

（2026年2月4日焦作市第十四届人民代表大会常务委员会第二十八次会议通过　2026年4月1日河南省第十四届人民代表大会常务委员会第二十三次会议批准）

焦作市第十四届人民代表大会常务委员会第二十八次会议决定对《焦作市国土空间规划管理条例》作如下修改：

将第十四条第一款第一项修改为：“生态修复、耕地保护等专项规划，由市、县（市）自然资源和规划主管部门会同有关部门组织编制，报同级人民政府审批；地质灾害防治、矿产资源专项规划编制、审批等程序，按照国家和省有关规定执行”。

本决定自公布之日起施行。

《焦作市国土空间规划管理条例》根据本决定作相应修改，重新公布。
