# 吉林市人大常委会关于废止《吉林市外商投资企业和私营企业工会条例》的决定

吉林市人大常委会关于废止《吉林市
外商投资企业和私营企业工会条例》的决定

（2026年5月28日吉林市第十七届人民代表大会常务委员会第三十六次会议审议通过　2026年7月30日吉林省第十四届人民代表大会常务委员会第二十四次会议批准）

2026年5月28日，吉林市第十七届人大常委会第三十六次会议对《吉林市人大社会建设委员会关于提请废止〈吉林市外商投资企业和私营企业工会条例〉的议案》进行了审议。

会议决定：废止《吉林市外商投资企业和私营企业工会条例》。

本决定自公告之日起施行。
