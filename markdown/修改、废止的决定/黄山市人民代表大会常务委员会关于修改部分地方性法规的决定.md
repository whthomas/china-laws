# 黄山市人民代表大会常务委员会关于修改部分地方性法规的决定

黄山市人民代表大会常务委员会关于修改
部分地方性法规的决定

（2026年6月30日黄山市第八届人民代表大会常务委员会第三十四次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为维护国家法制的统一、尊严和权威，促进经济社会发展，保证国家法律、行政法规在我市的贯彻实施，黄山市第八届人民代表大会常务委员会第三十四次会议决定，对《黄山市制止餐饮浪费行为条例》等四件地方性法规作出如下修改。

一、对《黄山市制止餐饮浪费行为条例》作出修改

（一）将第十条修改为：“餐饮经营者应当主动对消费者进行防止食品浪费提示提醒，在醒目位置张贴或者摆放反食品浪费标识，或者由服务人员提示说明，引导消费者按需适量点餐。

旅游服务企业应当按照游客需求合理安排用餐，提醒游客适量取餐，杜绝浪费。”

（二）将第十一条修改为：“餐饮经营者应当明示食品份量和价格，建议消费者合理搭配食品。

餐饮经营者应当提示消费者打包剩余食品，并提供打包服务。

鼓励餐饮经营者通过积分奖励、停车优惠及其他创新方式开展光盘有奖活动，对节约用餐的消费者给予奖励。”

（三）将第二十三条修改为：“违反本条例第十条规定，餐饮经营者未主动对消费者进行防止食品浪费提示提醒的，由市场监督管理部门责令改正，给予警告。”

二、对《黄山市太平湖风景名胜区条例》作出修改

（一）将第十四条修改为：“在太平湖风景区内进行下列活动，应当经管委会审核后，依照有关法律、法规的规定报有关主管部门批准：

（一）在户外设置、张贴商业广告；

（二）拍摄电影、电视，举办大型文化、体育、宣传活动；

（三）占用、围圈、遮掩水体，设置水上浮动设施；

（四）引进、投放外来生物物种；

（五）其他可能影响生态、环境的。”

（二）将第二十四条修改为：“违反第十三条第一项规定中的开荒、修坟立碑等破坏景观、植被和地形地貌的活动，属个人行为的，由管委会责令停止违法行为、限期恢复原状或者采取其他补救措施，没收违法所得，并处一千元以上一万元以下的罚款。

违反本条例第十三条第一项规定中的开山、采石、开矿等破坏景观、植被和地形地貌的活动或者第二项规定的，由管委会责令停止违法行为、恢复原状或者限期拆除，没收违法所得，并处五十万元以上一百万元以下的罚款。

违反本条例第十三条第三项规定的，由管委会责令恢复原状或者采取其他补救措施，处五十元的罚款。

违反本条例第十三条第四项规定的，由管委会责令改正，处一百元以上一千元以下的罚款。

违反本条例第十三条第七项规定非法猎捕受保护野生动物的，由管委会责令停止违法行为，没收猎获物、猎捕工具和违法所得，并处猎获物价值一倍以上五倍以下的罚款；没有猎获物的，并处一千元以下罚款。

违反本条例第十三条第八项规定非法采集受保护野生植物的，由管委会没收所采集的野生植物和违法所得，可以并处违法所得十倍以下的罚款。

违反本条例第十三条第九项规定在风景区水域新建、扩建围网、围栏养殖的，由管委会责令停止违法行为、限期拆除，并处二万元以上五万元以下罚款。

违反本条例第十三条第十一项规定在防火期内，未经批准擅自在野外用火的，由管委会责令停止违法行为，对个人处三百元以上五千元以下罚款，对单位处二万元以上十万元以下罚款。”

三、对《齐云山风景名胜区保护管理条例》作出修改

将第十八条修改为：“核心景区内禁止下列行为：

（一）开荒、开山、开矿、采石、淘沙和取土，烧制砖瓦，建坟立碑；

（二）猎捕野生动物；

（三）在景物或者设施上刻划、涂污；

（四）在非指定的时间、地点野炊或露天烧烤；

（五）燃放烟花爆竹；

（六）在非宗教活动场所室外燃烛烧香；

（七）乱扔乱倒垃圾、乱堆乱放杂物；

（八）占道经营，强行兜售商品、提供服务；

（九）其他有损景观、破坏生态的行为。”

将第二十四条修改为：“违反本条例第十八条第一项规定，在核心景区内烧制砖瓦的，由管委会责令停止违法行为，限期恢复原状或者采取其他补救措施，没收违法所得，并处一千元以上一万元以下的罚款。

违反本条例第十八条第四项的规定，由管委会责令改正，没收野炊、烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。

违反本条例第十八条第八项规定占道经营的，由管委会责令停止违法行为；拒不改正的，处一百元以上五百元以下罚款。”

四、对《黄山市农药安全管理条例》作出修改

（一）将第一条修改为：“为了加强农药安全管理，保障农产品质量安全，保护生态环境，根据《中华人民共和国生态环境法典》《农药管理条例》和有关法律、行政法规规定，结合本市实际，制定本条例。”

（二）将十九条修改为：“农药经营者和使用者应当及时回收农药包装废弃物，并将农药包装废弃物交由专门的机构或者组织进行无害化处理。”

（三）将第二十六条修改为：“违反本条例第十九条规定，农药经营者、使用者未及时回收农药包装废弃物，或者未将农药包装废弃物交由专门的机构或者组织进行无害化处理的，由农业农村主管部门责令改正，处一万元以上十万元以下的罚款；农药使用者为个人的，可以处二百元以上二千元以下的罚款。”

本决定自2026年8月15日起生效。

《黄山市制止餐饮浪费行为条例》《黄山市太平湖风景名胜区条例》《齐云山风景名胜区保护管理条例》《黄山市农药安全管理条例》根据本决定作相应修改，重新公布。
