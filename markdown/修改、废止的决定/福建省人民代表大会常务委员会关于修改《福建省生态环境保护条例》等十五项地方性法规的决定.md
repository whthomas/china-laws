# 福建省人民代表大会常务委员会关于修改《福建省生态环境保护条例》等十五项地方性法规的决定

福建省人民代表大会常务委员会关于修改
《福建省生态环境保护条例》等十五项
地方性法规的决定

（2026年7月24日福建省第十四届人民代表大会常务委员会第二十三次会议通过）

福建省第十四届人民代表大会常务委员会第二十三次会议决定对《福建省生态环境保护条例》等十五项地方性法规作如下修改：

一、福建省生态环境保护条例

（一）将第一条修改为：“为贯彻新发展理念，深入实施生态省战略，保护和改善生态环境，防治污染和其他公害，保障公众健康，推进实现碳达峰、碳中和，加强生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》和其他有关法律、行政法规，结合本省实际，制定本条例。”

（二）将第三条修改为：“生态环境保护应当坚持中国共产党的领导，贯彻习近平生态文明思想，遵循人与自然和谐共生、山水林田湖草沙是生命共同体的理念，坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责的原则。”

（三）将第五条第一款修改为：“省、设区的市人民政府生态环境主管部门在其职责范围内对本行政区域生态环境保护工作实施统一监督管理；县级以上地方人民政府自然资源主管部门在其职责范围内对本行政区域自然资源开发利用和保护，以及国土空间开发保护工作实施监督管理；县级以上地方人民政府其他有关部门在其职责范围内对资源保护和污染防治等生态环境保护工作实施监督管理。”

（四）删去第十条第二款。

将第十条第四款修改为：“各类声环境质量标准的适用区域由县级以上地方人民政府根据国家声环境质量标准划定。”

（五）将第十六条修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者应当按照国家和本省有关规定，安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，保存原始监测记录，并与省、设区的市人民政府生态环境主管部门监测监控联网。

“实行排污许可重点管理的企业事业单位和其他生产经营者应当定期检定、校准自动监测设备，确保监测设备正常运行，监测数据真实准确。经审核认定真实有效的自动监测数据可以作为环境行政执法监管的证据。”

（六）将第二十条修改为：“省、设区的市人民政府生态环境主管部门及其派出机构、县级以上地方人民政府其他负有生态环境保护监督管理职责的部门依法对管辖范围内的排放污染物的企业事业单位和其他生产经营者以及生态环境技术服务机构等进行现场监督检查。

“对违反法律、法规的规定造成或者可能造成严重污染、破坏生态等后果，或者有关证据可能灭失、被隐匿的，省、设区的市人民政府生态环境主管部门及其派出机构或者县级以上地方人民政府其他负有生态环境保护监督管理职责的部门可以依法查封、扣押有关场所、船舶、设施、设备、工具、物品。”

（七）将第三十九条第三款修改为：“严禁通过暗管、渗井、渗坑、灌注、裂隙、溶洞和其他偷排方式，或者篡改、伪造监测数据，或者以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放污染物。”

（八）将第四十八条第一款修改为：“居民住宅楼、未配套设立专用烟道的商住综合楼、商住综合楼内与居住层相邻的商业楼层内禁止新建、改建、扩建排放油烟、异味、废气的餐饮服务项目。”

（九）将第五十二条修改为：“企业事业单位和其他生产经营者应当在开展突发环境事件风险评估和应急资源调查的基础上，制定突发环境事件应急预案并依法备案，定期组织应急演练。

“企业事业单位和其他生产经营者在发生或者可能发生突发环境事件时，应当立即启动应急预案，采取防止危害扩大的必要措施，及时通报可能受到危害的单位和居民，并向所在地设区的市人民政府生态环境主管部门派出机构和有关部门报告。”

（十）将第五十七条第一款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当如实公开主要污染物的名称、排放方式、排放种类、排放浓度、排放总量、超标排放情况、污染防治设施建设和运行情况、自行监测数据、突发环境事件应急预案等环境信息，接受社会监督。”

（十一）将第五十八条修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照国家和本省有关规定和监测规范，对其排放污染物进行自行监测，建立管理台账，保存完整的原始监测记录和监测报告等资料，并对监测数据的真实性和准确性负责。原始监测记录和管理台账保存时间不得少于五年。

“不具备监测能力的企业事业单位和其他生产经营者，应当委托依法备案的环境监测机构进行监测，保存完整的委托合同、原始监测记录和监测报告等资料。监测结果超过国家和本省污染物排放标准的，企业事业单位和其他生产经营者应当及时报告当地生态环境主管部门。

“环境监测机构和从事在线监测设备维护、运营的机构以及企业事业单位及其负责人应当对其监测数据的真实性、准确性和完整性负责，不得篡改、伪造。”

（十二）删去第六十四条、第六十七条、第七十条、第七十一条。

（十三）将第六十六条改为第六十五条，第一款修改为：“违反本条例规定，建设单位、施工单位于午间、夜间在噪声敏感建筑物集中区域内未按照规定取得证明，进行产生环境噪声的建筑施工作业的，由县级以上地方人民政府确定的监督管理部门责令立即改正，处二万元以上十万元以下罚款；拒不改正的，可以责令暂停施工。”

（十四）将第六十八条改为第六十六条，修改为：“违反本条例规定，企业事业单位和其他生产经营者未定期组织环境应急演练的，由省、设区的市人民政府生态环境主管部门或其派出机构责令限期改正，处一万元以上三万元以下罚款。”

（十五）将第六十九条改为第六十七条，修改为：“违反本条例规定，实行排污许可重点管理的企业事业单位和其他生产经营者未定期检定、校准或者未保证监测设备正常运行的，由负有生态环境保护监督管理职责的部门、机构按照职责分工依法责令改正，处二万元以上二十万元以下罚款；拒不改正的，可以责令限制生产、停产整治。”

（十六）将第七十三条改为第六十九条，第二项修改为：“（二）‘噪声敏感建筑物’是指用于居住、科学研究、医疗卫生、文化教育、机关团体办公、社会福利等需要保持安静的建筑物。”

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

二、福建省大气污染防治条例

（一）将第一条修改为：“为了保护和改善环境，防治大气污染，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》和其他有关法律、行政法规，结合本省实际，制定本条例。”

（二）将第三条第一款修改为：“防治大气污染，应当以改善和提升大气环境质量为目标，坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责的原则。”

（三）将第十七条第二款修改为：“省、设区的市人民政府生态环境主管部门及其派出机构应当发布本行政区域大气环境质量状况信息和实时监测数据，依法及时公开大气污染突发环境事件等信息。”

（四）将第二十一条修改为：“省、设区的市人民政府生态环境主管部门及其派出机构和环境执法机构、县级以上地方人民政府其他负有大气环境保护监督管理职责的部门有权依法对管辖范围内的排放大气污染物的企业事业单位和其他生产经营者进行现场监督检查。对违反法律、法规的规定排放大气污染物造成或者可能造成严重大气污染，或者可能导致有关证据灭失、被隐匿的，可以依法对企业事业单位和其他生产经营者的有关场所、船舶、设施、设备、工具、物品采取查封、扣押等行政强制措施，措施实施应当适当，采取非强制手段可以停止相关行为的，不得实施行政强制。被检查对象应当予以配合，如实反映情况，不得拒绝、阻挠和拖延。”

（五）将第二十五条第一款修改为：“企业事业单位和其他生产经营者应当按照国家有关规定和监测规范，对其排放的工业废气和有毒有害大气污染物进行监测，保存完整的原始记录和监测报告，并对监测数据的真实性负责。”

第二款修改为：“不具备监测能力的企业事业单位和其他生产经营者，应当委托依法备案的监测机构进行监测。监测数据超过国家和本省大气污染物排放标准的，企业事业单位和其他生产经营者应当及时报告当地生态环境主管部门。”

第三款修改为：“环境监测机构和企业事业单位及其负责人应当对监测数据和报告的真实性、准确性和完整性负责，不得篡改、伪造。”

（六）将第二十六条修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者应当按照国家和本省有关规定，安装、使用、维护大气污染物排放自动监测设备，开展监控、自动监测，保存原始监测记录，并与省、设区的市人民政府生态环境主管部门监测监控网络联网。

“实行排污许可重点管理的企业事业单位和其他生产经营者应当定期检定、校准自动监测设备，确保监测设备正常运行，监测数据完整准确有效。自动监测数据可以作为环境行政处罚等执法监管的依据。”

（七）将第三十一条修改为：“省、设区的市人民政府应当在本行政区域划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大禁燃区范围。

“在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在省、设区的市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”

（八）将第四十一条第二款修改为：“储油库、加油站、原油成品油码头、原油成品油运输船舶和油罐车、铁路罐车等，应当按照国家规定安装油气回收装置并保持正常使用。”

（九）将第五十条第二款修改为：“待开发场地在进行土地平整时，平整作业单位应当及时洒水降尘，场地管理单位应当在平整作业结束后设置围挡。暂不能开工的建设用地和已平整待开发场地，场地管理单位应当对裸露地面进行覆盖；超过三个月的，应当进行绿化、透水铺装或者遮盖。”

（十）将第五十七条第二款修改为：“省、设区的市人民政府生态环境主管部门及其派出机构可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测。机动车集中停放地、维修地和重型汽车使用地管理部门应当予以配合。”

第三款修改为：“省、设区的市人民政府生态环境主管部门及其派出机构在不影响正常通行的情况下，可以通过非接触式道路监测等技术手段对在道路上行驶的机动车的污染物排放状况进行监测，监测取得的数据，可以作为环境执法的依据，公安机关交通管理部门予以配合。”

（十一）将第六十条第一款修改为：“在用机动车船和非道路移动机械排放大气污染物不得超过国家和本省排放标准；超过排放标准的，应当进行维修；经维修或者采用污染控制技术后仍不符合排放标准的，应当强制报废。”

（十二）将第六十一条修改为：“禁止生产、进口、销售不符合标准的机动车船、非道路移动机械用燃料。燃料销售者应当在其经营场所明示其所销售燃料的质量指标。

“禁止生产、进口、销售不符合标准的机动车船、非道路移动机械发动机油、氮氧化物还原剂、燃料和润滑油添加剂以及其他添加剂。

“禁止向机动车、非道路移动机械、内河和江海直达船舶销售非机动车船用燃料；禁止机动车、非道路移动机械、内河和江海直达船舶使用非机动车船用燃料。”

（十三）将第六十二条第一款修改为：“船舶向大气排放污染物，应当符合有关排放标准。具备岸电使用条件的船舶靠港应当按照国家规定使用岸电，但是使用清洁低碳能源的除外。”

（十四）将第六十三条第三款修改为：“禁止在居民住宅楼、未配套设立专用烟道的商住综合楼、商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建排放油烟、异味、废气的饮食服务项目。”

第四款修改为：“不得在当地人民政府禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地。”

（十五）将第六十四条第二款修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

（十六）将第七十一条第一款修改为：“地方各级人民政府及其有关部门和企业事业单位，应当依照《中华人民共和国生态环境法典》和《中华人民共和国突发事件应对法》等法律、法规的规定，做好大气突发环境事件的风险控制、应急准备、应急处置和事后恢复等工作。”

第三款修改为：“可能发生大气突发环境事件的单位应当按照国家和省有关规定编制应急预案，报所在地生态环境主管部门和相关部门备案。在发生或者可能发生大气突发环境事件时，单位应当立即采取措施处理，及时向所在地生态环境、应急管理等有关部门报告，接受调查处理，并告知可能受到危害的单位和居民。”

（十七）删去第七十二条、第七十四条、第七十五条、第七十六条、第八十二条、第八十三条、第八十四条第一款、第八十四条第二款、第八十四条第四款。

（十八）将第七十七条改为第七十三条，第一款第三项修改为：“（三）储油库、加油站和油罐车等，未按照国家规定安装并正常使用油气回收装置的；”

（十九）将第七十九条改为第七十五条，删去第一款。

第二款修改为：“违反本条例规定，港口码头的物料堆放场未采取有效措施防治扬尘污染的，由县级以上地方人民政府交通运输（港口）主管部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治或者停业整治。”

将第三条第一款修改为：“保护、开发、利用、配置、节约、管理水资源，应当坚持全面规划、生态优先、统筹兼顾、标本兼治、综合利用、科学配置、讲求效益的原则，协调好生活、生产经营和生态环境用水。”

十、福建省河道保护管理条例

将第三条修改为：“河道保护管理应当遵循全面规划、生态优先、统筹兼顾、系统治理、合理利用的原则，并服从防洪的总体安排。”

十一、福建省城乡生活垃圾管理条例

（一）将第一条修改为：“为了加强城乡生活垃圾管理，促进生活垃圾减量化、资源化和无害化，改善城乡人居环境，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》和其他有关法律、行政法规，结合本省实际，制定本条例。”

（二）将第十七条修改为：“任何单位和个人不得擅自关闭、闲置、拆除生活垃圾转运、处置设施、场所；确需关闭、闲置、拆除的，应当依法核准，并按照先建后拆的原则，重建、补建或者提供替代设施。”

（三）将第二十四条第一款第二项修改为：“（二）厨余垃圾，指易腐烂的、含有机质的生活垃圾，主要包括家庭厨余垃圾、餐厨垃圾、其他厨余垃圾等。”

（四）将第二十六条第一款修改为：“生活垃圾应当分类投放至指定收集点的收集容器内，禁止随意倾倒、堆放、丢弃、抛撒、遗撒、焚烧。”

（五）将第二十七条修改为：“产生、收集厨余垃圾的单位和其他生产经营者，应当将厨余垃圾交由具备相应资质条件的单位进行无害化处理，不得直接排入公共水域、厕所、市政管道或者混入其他类型生活垃圾。”

（六）将第二十九条修改为：“电器电子产品生产者应当按照国家规定，以自建或者委托等方式建立与产品销售量相匹配的废旧产品回收体系。回收的废弃电器电子产品应当交由具备法定条件的企业处理。”

（七）删去第三十七条第五项、第六十五条、第六十八条、第六十九条。

（八）增加一条，作为第六十一条：“违反本条例规定的行为，法律、行政法规已有法律责任规定的，从其规定。”

（九）将第六十三条改为第六十四条，修改为：“单位违反本条例第十七条规定，擅自关闭、闲置、拆除生活垃圾集中转运、处置设施、场所的，由设区的市、县（市、区）人民政府城乡生活垃圾监督管理部门责令改正，没收违法所得，处十万元以上一百万元以下的罚款。”

（十）将第六十四条改为第六十五条，修改为：“违反本条例第二十六条第一款规定，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的，由设区的市、县（市、区）人民政府城乡生活垃圾监督管理部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。

“个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾的，由城乡生活垃圾监督管理部门责令改正，处一百元以上一千元以下的罚款。

“未在指定的地点分类投放生活垃圾的，由城乡生活垃圾监督管理部门责令改正；拒不改正的，对单位处五万元以上五十万元以下的罚款，对个人处二百元以下的罚款。”

（十一）将第六十六条修改为：“违反本条例第二十八条第一款规定，未将大件废弃家具交由收集、运输单位处理的，由设区的市、县（市、区）人民政府城乡生活垃圾监督管理部门责令限期改正，逾期不改正的，对单位处五千元以上五万元以下的罚款，对个人处二百元以下的罚款。”

（十二）对部分条文的表述作以下修改：

将第十四条、第二十条、第二十四条第一款第四项、第二十五条、第二十六条第二款、第三十六条、第三十九条、第四十四条中的“易腐垃圾”修改为“厨余垃圾”，将第四十二条中的“餐饮垃圾”修改为“餐厨垃圾”。

此外，根据修改，对条文顺序作相应调整。

十二、福建省城市市容和环境卫生管理办法

（二）将第十六条改为第十五条，修改为：“用作农田灌溉和养殖的水体，其水质必须符合国家或者地方规定的水质标准。
