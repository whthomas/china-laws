# 贵阳市人民代表大会常务委员会关于修改《贵阳市城市节约用水管理条例》等九件地方性法规部分条款的决定

贵阳市人民代表大会常务委员会
关于修改《贵阳市城市节约用水管理条例》等
九件地方性法规部分条款的决定

（2026年6月25日贵阳市第十五届人民代表大会常务委员会第三十六次会议通过　2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

贵阳市第十五届人民代表大会常务委员会第三十六次会议决定：

一、对《贵阳市城市节约用水管理条例》作修改

（一）删去第十一条、第二十八条。

（二）将第二十六条第一项修改为：“（一）节约用水设施未与主体工程同时设计、同时施工、同时投入使用的，节约用水设施未经验收或者验收不合格而投入使用的，责令停止使用，限期改正，处以5万元以上10万元以下罚款”；将第三项修改为：“（三）工业企业的生产设备、空调冷却水未回收利用的，责令改正，可以处以5万元以下罚款，拒不改正的，处以5万元以上10万元以下罚款”；增加一项作为第四项：“（四）使用国家明令淘汰的用水器具的，责令停止使用，处以2万元以上10万元以下罚款”。

二、对《贵阳市环城林带建设保护办法》作修改

将第十七条第六项中的“毁坏”修改为“擅自移动或者损坏”。

三、对《贵阳市城市市容和环境卫生管理办法》作修改

（一）删去第二十八条、第三十二条。

（二）将第三十一条中的“责令限期清理、拆除或者予以取缔”修改为“责令停止违法行为，限期清理、拆除或者采取其他补救措施”。

（三）将第三十三条修改为：“禁止毁损城市环境卫生设施。未经依法批准，单位和个人不得将城市环境卫生设施擅自停用、占用、拆除、移动或者改变用途。单位擅自关闭、闲置或者拆除生活垃圾处理设施、场所的，责令改正，没收非法所得，处以10万元以上100万元以下罚款。单位和个人有违反规定的其他情形，责令其恢复原状；不能恢复的，应当补建或者按照市场评估价格赔偿，可以处以市场评估价格3倍以上5倍以下罚款”。

四、对《贵阳市公园和绿化广场管理办法》作修改

删去第二十七条。

五、对《贵阳市建设生态文明城市条例》作修改

（一）删去第十七条第一款。

（二）删去第二十五条、第四十八条中的“阿哈水库”。

（三）删去第三十六条第二款中“环保公益组织”。

（四）删去第四十三条。

（五）将第四十四条第二项修改为：“（二）随意倾倒垃圾、污水的，由综合行政执法部门责令改正，处以100元以上1000元以下罚款”。

六、对《贵阳市大气污染防治办法》作修改

（一）将第一条中“保护和改善环境”修改为“保护和改善生态环境”；将“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第四条第四款修改为：“约谈整改情况应当向社会公开”。

（三）将第八条修改为：“县级以上人民政府应当根据大气污染状况和防治要求，编制未达标区域大气环境质量限期达标规划，明确治理目标、任务、计划和措施，依法向社会公布。市人民政府编制的大气环境质量限期达标规划应当报国务院生态环境主管部门备案”。

（四）将第十三条中的“大气环境质量在线监控与发布平台和污染源自动监控平台”和“大气环境质量在线监控与发布平台”修改为“大气环境质量和大气污染源监测网络”。

（五）将第十五条、第十八条第二项、第三十六条第二项中的“重点排污单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”。

（六）将第十七条第一款中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（七）将第二十五条第二款修改为：“堆放、转运煤炭、水泥、砂土等易产生扬尘污染物料的场、站，除遵守前款第二项至第四项、第六项、第七项的规定外，还应当采用密闭方式贮存物料，不能密闭的，设置不低于堆放物高度的严密围挡，并采取有效覆盖措施防治扬尘污染”。

（八）将第三十三条中的“从事产生有油烟的食品加工和餐饮服务的生产经营户”修改为“从事产生有油烟的餐饮服务的生产经营户”。

（九）删去第三十四条、第四十三条、第四十五条第七项中的“养殖小区”。

（十）在第三十七条增加一款作为第二款：“有前款第一项的，由生态环境主管部门没收燃煤锅炉。”

（十一）将第三十八条第三款修改为：“违反本办法第二十二条第三款规定，在城市道路、公共区域，堆放、装卸水泥、砂石等易产生扬尘污染的物料，进行搅拌灰浆等作业，未采取铺垫等降尘、抑尘、防尘措施，或者未及时清除散落物料，清扫现场，保持用地整洁的，由综合行政执法部门责令改正，对单位处以1万元以上10万元以下罚款，对个人处以1万元以上2万元以下罚款”。

（十二）将第四十二条中的“生态环境主管部门”修改为“综合行政执法部门”；删去第四十二条第二项规定。

（十三）将第四十三条中的“处以2000元以上1万元以下罚款”修改为“处以1万元以上10万元以下罚款”。

七、对《贵阳市青岩古镇保护条例》作修改

（一）在第三条“科学管理的原则”后增加“体现铸牢中华民族共同体意识的要求”。

（二）将第二十四条第二项修改为：“（二）擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾和生活垃圾”；删去第二十四条第三项。

（三）将第二十五条第五项修改为：“（五）在商业经营活动中使用高音广播喇叭或者采用其他持续反复发出高噪声的方法进行广告宣传”。

（四）将第三十八条第二项修改为：“（二）擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾和生活垃圾，按照有关法律法规的规定处罚”。

（五）将第三十九条第四项修改为：“（四）在商业经营活动中使用高音广播喇叭或者采用其他持续反复发出高噪声的方法进行广告宣传，按照有关法律法规的规定处罚”。

八、对《贵阳市城镇生活垃圾分类管理条例》作修改

将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

九、对《贵阳市农村生活垃圾治理条例》作修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二十二条中的“情节严重的”修改为“拒不改正的”。

本决定自2026年8月15日起施行。

《贵阳市城市节约用水管理条例》《贵阳市环城林带建设保护办法》《贵阳市城市市容和环境卫生管理办法》《贵阳市公园和绿化广场管理办法》《贵阳市建设生态文明城市条例》《贵阳市大气污染防治办法》《贵阳市青岩古镇保护条例》《贵阳市城镇生活垃圾分类管理条例》《贵阳市农村生活垃圾治理条例》根据本决定作相应修改并对条文顺序作相应调整，按照立法技术规范对部分文字作技术处理，重新公布。
