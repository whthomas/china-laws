# 孝感市人民代表大会常务委员会关于集中修改涉及生态环境法典地方性法规的决定

孝感市人民代表大会常务委员会关于
集中修改涉及生态环境法典
地方性法规的决定

（2026年6月18日孝感市第七届人民代表大会常务委员会第四十次会议通过　2026年7月30日湖北省第十四届人民代表大会常务委员会第二十五次会议批准）

孝感市第七届人民代表大会常务委员会第四十次会议决定：

一、对《孝感市城乡规划条例》作出修改

（一）将第十一条中的“环境保护”修改为“生态环境保护”。

（二）将第十四条第一款修改为：“涉及空间利用的基础设施、公共服务设施，以及生态环境保护、文物保护、林业资源等专项规划，由相关行业主管部门会同城乡规划主管部门根据需要组织编制，报本级人民政府审批。”

（三）将第二十五条第二款中的“环境影响评价”修改为“生态环境影响评价”。

二、对《孝感市城市综合管理条例》作出修改

（一）将第四十五条第二款中的“设置”修改为“新建、改建、扩建”。

将第三款修改为：“任何单位和个人不得在市、县（市、区）人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。”

（二）将第四十七条第一款修改为：“市人民政府可以划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。在禁燃区内，禁止销售、燃用高污染燃料。”

在第二款“人口集中地区”后增加“和其他依法需要特殊保护的区域”。

（三）将第五十八条修改为：“违反本条例第二十三条第三款规定的，由城市管理主管部门依照《中华人民共和国广告法》、《城市市容和环境卫生管理条例》等法律、法规予以处罚。”

三、对《孝感市城市绿化条例》作出修改

（一）将第二十六条第六项修改为：“（六）擅自在绿地内倾倒、堆放、丢弃、抛撒、遗撒或者焚烧废弃物”。

（二）将第三十一条第六项和第七项合并，作为第六项，修改为：“（六）违反本条例第二十六条规定的，按照《中华人民共和国生态环境法典》等法律、法规予以处罚”。

四、对《孝感市饮用水水源保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第四条中的“水资源保护规划和水污染防治规划”修改为“水生态环境保护规划”。

（三）将第六条中的“生态补偿”修改为“生态保护补偿”；将第二款修改为：“鼓励饮用水水源保护受益地区与保护地区之间通过资金补偿、对口协作、产业转移、人才培训、共建园区、购买生态产品和服务等方式进行横向生态保护补偿。”

（四）在第十九条第二款“保护水源”前增加“供水设施和”。

（五）将第二十条第一项修改为：“（一）禁止通过暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放污染物”。

（六）将第二十四条第一款和第二款中的“饮用水水源污染事故”修改为“饮用水安全突发事件”；将第二款中的“重点水污染排放单位、供水单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者、供水单位”。

（七）将第二十五条第一款中的“水环境”修改为“水生态环境”；在第二款“及时”前增加“按照有关规定”。

（八）将第二十六条第一款修改为：“市、县（市、区）人民政府应当组织生态环境等有关部门对饮用水水源水质、水量和水生态环境保护情况进行定期评估，筛查可能存在的污染风险因素，并采取相应的风险防范措施。”

（九）将第三十一条第一项修改为：“（一）向水体排放、倾倒工业废渣、城镇垃圾或者其他废弃物，或者在水体清洗装贮过油类、有毒有害物品的车辆、容器的，由生态环境主管部门依照《中华人民共和国生态环境法典》的有关规定予以处罚”。

将第二项修改为：“（二）违法使用农药的，由农业农村主管部门依照《农药管理条例》的有关规定予以处罚”。

（十）在第三十二条第一项中的“罚款”后增加“并报经有批准权的人民政府批准，责令拆除或者关闭”。

（十一）将第三十四条修改为：“违反本条例规定，在地下水饮用水水源保护区内，通过暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放污染物的，由生态环境主管部门责令改正，处十万元以上一百万元以下的罚款，责令限制生产、停产整治，并由公安机关对其直接负责的主管人员和其他直接责任人员依法予以处罚；情节严重的，吊销排污许可证，报经有批准权的人民政府批准，责令停业、关闭，并由公安机关对其直接负责的主管人员和其他直接责任人员依法予以处罚。”

本决定自公布之日起施行。

相关法规根据本决定作相应修改，文字表述和条款顺序作相应调整，并重新公布。
