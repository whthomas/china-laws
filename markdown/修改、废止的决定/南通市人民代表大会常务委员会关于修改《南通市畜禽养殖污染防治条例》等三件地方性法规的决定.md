# 南通市人民代表大会常务委员会关于修改《南通市畜禽养殖污染防治条例》等三件地方性法规的决定

南通市人民代表大会常务委员会关于修改
《南通市畜禽养殖污染防治条例》等三件
地方性法规的决定

（2026年7月24日南通市第十六届人民代表大会常务委员会第三十四次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

南通市第十六届人民代表大会常务委员会第三十四次会议决定：

一、对《南通市畜禽养殖污染防治条例》作出修改

（一）将第一条修改为：“为了防治畜禽养殖污染，推进畜禽养殖废弃物的综合利用和无害化处理，保护生态环境，保障公众身体健康，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）将第四条修改为：“生态环境主管部门负责畜禽养殖污染防治的统一监督管理。

“农业农村主管部门负责畜禽养殖废弃物综合利用的指导与服务。

“其他有关部门按照各自职责，做好畜禽养殖污染防治的相关工作。”

（三）将第八条第三项修改为：“符合生态环境保护管理要求”。

（四）将第十条第一款修改为：“畜禽养殖专业户、畜禽散养户应当及时对畜禽粪便、污水、尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，防止污染环境。”

（五）将第十一条修改为：“鼓励和支持畜禽养殖专业户、畜禽散养户采用先进适用技术，对畜禽粪便进行综合利用。”

（六）增加一条，作为第十四条：“对违反本条例规定的行为，法律、法规已有处罚规定的，从其规定。”

（七）将第十六条改为第十七条，删去第二款。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

二、对《南通市生态环境损害赔偿程序规定》作出修改

（一）将第一条修改为：“为了规范生态环境损害赔偿案件办理程序，推进生态文明建设，根据《中华人民共和国民法典》、《中华人民共和国生态环境法典》、《江苏省生态环境保护条例》等法律、法规，结合本市实际，制定本规定。”

（二）将第三条第二款修改为：“市、县级生态环境、自然资源和规划、住房和城乡建设、城市管理、交通运输、水行政、农业农村、海事等有关部门和机构，受市人民政府指定具体负责各自职责范围内的生态环境损害赔偿工作。”

第三款修改为：“县级人民政府和南通经济技术开发区、江苏省通州湾江海联动开发示范区等园区管理机构，受市人民政府指定分别负责本行政区域、管理区域内有重大影响的生态环境损害赔偿工作。”

（三）将第十四条第二项修改为：“经三次磋商，或者从磋商告知书送达之日起满九十日，未能就生态环境损害赔偿达成一致意见”。

（四）删去第十七条。

（五）将第十八条改为第十七条，修改为：“市、县级人民政府每年向本级人民代表大会或者人民代表大会常务委员会报告生态环境状况和生态环境保护目标完成情况时，应当包含生态环境损害赔偿工作开展情况。”

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

三、对《南通市烟花爆竹燃放管理条例》作出修改

（一）将第一条修改为：“为了加强烟花爆竹燃放管理，改善生态环境质量，保障公共安全和人身、财产安全，根据《中华人民共和国生态环境法典》、国务院《烟花爆竹安全管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条第一款修改为：“市、县（市、区）人民政府应当加强烟花爆竹燃放管理工作的组织领导、统筹协调和经费保障。”

第二款修改为：“公安、应急管理、市场监督管理、城市管理、生态环境、住房和城乡建设、交通运输、教育、民政、财政、数据、邮政管理等部门应当按照各自职责，做好烟花爆竹燃放管理以及宣传等相关工作。”

第三款中的“镇人民政府（街道办事处）”修改为“镇人民政府、街道办事处”。

（三）将第四条第二款修改为：“本市市区其他禁止燃放烟花爆竹的区域，由市人民政府根据实际情况确定，并向社会公布。”

增加一款，作为第三款：“需要对本市市区禁止燃放烟花爆竹的区域和时间临时调整的，由市人民政府决定并向社会公布。”

（四）将第五条第一款第二项修改为：“林地、苗圃、公共绿地、饮用水源保护区、河道水利工程管理范围，文物保护、保存单位”。

第八项中的“市、县（市、区）人民政府”修改为“市、县（市）人民政府”。

（五）将第七条第一款中的“第五条”修改为“第五条第一款”。

（六）将第八条修改为：“县（市）人民政府可以根据实际情况，确定本行政区域内禁止燃放烟花爆竹的区域或者限制燃放烟花爆竹的区域、时间和种类，并向社会公布。”

（七）将第十条中的“应当遵循合理布局、总量控制、逐步减少的原则”修改为“应当遵循保障安全、统一规划、合理布局、总量控制、逐步减少的原则”。

（八）将第十一条中的“安全、环保”修改为“符合质量标准”。

（九）将第十二条第三款中的“市、县（市）人民政府”修改为“市、县（市、区）人民政府”。

（十）将第十四条中的“‘110’或者‘12345’市民服务热线”修改为“110报警服务台或者12345热线”。

（十一）将第十六条中的“安全生产监督管理部门”修改为“应急管理部门”。

此外，对有关条款作文字、技术修改。

本决定自2026年8月15日起施行。

《南通市畜禽养殖污染防治条例》、《南通市生态环境损害赔偿程序规定》、《南通市烟花爆竹燃放管理条例》根据本决定作相应修改，重新公布。
