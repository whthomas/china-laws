# 德州市人民代表大会常务委员会关于废止《德州市城乡容貌和环境卫生管理条例》《德州市湿地保护条例》的决定

德州市人民代表大会常务委员会关于废止
《德州市城乡容貌和环境卫生管理条例》
《德州市湿地保护条例》的决定

（2026年6月24日德州市第十九届人民代表大会常务委员会第三十九次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

德州市第十九届人民代表大会常务委员会第三十九次会议决定，废止下列地方性法规：

一、废止《德州市城乡容貌和环境卫生管理条例》（2017年11月17日德州市第十八届人民代表大会常务委员会第六次会议通过　2018年1月23日山东省第十二届人民代表大会常务委员会第三十五次会议批准）

二、废止《德州市湿地保护条例》（2017年11月17日德州市第十八届人民代表大会常务委员会第六次会议通过　2018年1月23日山东省第十二届人民代表大会常务委员会第三十五次会议批准）

本决定自2026年8月15日起施行。
