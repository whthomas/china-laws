# 黔南布依族苗族自治州人民代表大会常务委员会关于修改《黔南布依族苗族自治州樟江流域保护条例》、《黔南布依族苗族自治州涟江流域保护条例》部分条款的决定

黔南布依族苗族自治州人民代表大会
常务委员会关于修改《黔南布依族苗族自治州
樟江流域保护条例》、《黔南布依族苗族自治州
涟江流域保护条例》部分条款的决定

（2026年7月8日黔南布依族苗族自治州第十五届人民代表大会常务委员会第四十二次会议通过　2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

黔南布依族苗族自治州第十五届人民代表大会常务委员会第四十二次会议决定，对下列两件地方性法规部分条款作如下修改：

一、对《黔南布依族苗族自治州樟江流域保护条例》作出修改

（一）将第一条修改为：“为了加强樟江流域生态环境保护，合理开发利用自然资源，促进流域内经济社会可持续发展，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等有关法律、法规的规定，结合自治州实际，制定本条例。”

（二）将第六条、第二十四条、第二十八条中的“环境保护、国土资源、旅游、农业”修改为“生态环境、自然资源、文化和旅游、农业农村”，删去“城乡规划”。

（三）将第七条中的“土地利用总体规划、城乡规划”修改为“国土空间规划”。

（四）将第二十二条第一项调整为第二项，第二项调整为第一项。第四项修改为：“采砂、采矿、采石”，第五项修改为：“取土、爆破、钻探、挖筑鱼塘、修路、打井”。

（五）将第二十九条第一项调整为第七项；第三项调整为第六项；第四项调整为第三项；第五项调整为第四项；第六项调整为第一项；第七项调整为第五项。将第二项修改为：“在水体清洗装贮过油类或者有毒有害污染物的车辆和容器”。增加一项作为第八项，内容为：“法律、法规规定的其他行为”。

（六）将第三十条第二款第四项修改为：“施用化肥，使用农药”；第五项修改为：“法律、法规规定的其他行为”。

（七）将第三十一条中的“环境保护行政主管部门”修改为“生态环境主管部门”。

（八）将第三十三条和第三十九条中的“行政处分”修改为“处分”。

（九）将第三十四条中的“林业行政主管部门”修改为“林业主管部门”。

（十）将第三十五条第一项修改为：“违反第一项规定的，由县级人民政府水行政主管部门责令停止违法行为、限期拆除违法建筑物、构筑物，并恢复原状；逾期不拆除的依法强制拆除，所需费用由违法者承担，并处一万元以上五万元以下罚款”，第三项修改为：“违反第三项规定的，由县级人民政府农业农村主管部门没收装置、器具、有毒物质、渔获物和违法所得，并处二十万元以下的罚款；情节严重的，并处二十万元以上二百万元以下的罚款，吊销捕捞许可证，可以没收船舶。”

（十一）将第三十六条修改为：“违反本条例第二十二条第一项规定的，由生态环境主管部门责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，处二万元以上十万元以下的罚款；情节严重的，处十万元以上五十万元以下的罚款，责令限制生产、停产整治。

“违反本条例第二十二条第二、三、四、五项规定的，由县级人民政府水行政主管部门责令停止违法行为，并处罚款：

“（一）违反第二项规定的，责令限期补办有关手续；逾期不补办或补办未被批准的，责令限期拆除；逾期不拆除的，依法强制拆除，所需费用由违法者承担，并处一万元以上十万元以下罚款；

“（二）违反第三项规定的，限期采取补救措施，并处二万元以上十万元以下的罚款。情节严重的，吊销其取水许可证；

“（三）违反第四项规定的，没收违法所得以及用于违法活动的船舶、设备、工具，并处货值金额二倍以上二十倍以下罚款。货值金额不足十万元的，并处二十万元以上二百万元以下罚款。已经取得河道采砂许可证的，吊销河道采砂许可证；

“（四）违反第五项规定的，采取补救措施，没收违法所得，并可处警告或者一万元以上五万元以下罚款。”

（十二）将第三十七条修改为：“违反本条例第二十九条第一项规定的，由县级以上人民政府水行政主管部门责令停止违法行为，限期改正，并处一万元以上三万元以下罚款。

“违反第二、三、四、五、六、七项规定的，由县级人民政府生态环境主管部门责令停止违法行为，采取治理措施消除污染，并处罚款，可以责令采取限制生产、停产整治等措施；拒不采取治理措施的，可以指定有治理能力的单位代为治理，所需费用由违法者承担；情节严重的，报经有批准权的人民政府批准，责令停业、关闭：

“（一）违反第二项规定的，处二万元以上二十万元以下罚款；

“（二）违反第三、五项规定的，处十万元以上一百万元以下罚款；

“（三）违反第四项规定的，处十万元以上一百万元以下的罚款，并将案件移送公安机关，由公安机关对其直接负责的主管人员和其他直接责任人员，处五日以上十日以下拘留。情节严重的，吊销排污许可证，处十日以上十五日以下拘留；

“（四）违反第六项规定的，处二十万元以上二百万元以下罚款；

“（五）违反第七项规定向水体排放油类、酸液、碱液的处十万元以上一百万元以下罚款；排放剧毒废液的，处二十万元以上二百万元以下罚款。”

（十三）将第三十八条修改为：“违反本条例第三十条规定的，由县级人民政府有关行政主管部门责令停止违法行为并按照下列规定处罚：

“（一）在饮用水水源一级保护区内违反第一、二项规定的，处二万元以上十万元以下罚款；

“（二）在饮用水水源一级保护区内违反第三项规定的组织者，处二万元以上十万元以下罚款。在饮用水水源一级保护区内违反第三项规定的个人，处五百元以下罚款；

“（三）违反第四项规定的农产品生产企业、食品和食用农产品仓储企业、专业化病虫害防治服务组织和从事农产品生产的农民专业合作社等单位，处五万元以上十万元以下罚款。违反第四项规定的个人，处一万元以下罚款。农业农村主管部门还应当没收禁用的农药。构成犯罪的，依法追究刑事责任。”

（十四）将第四十条修改为：“违反本条例规定的其他行为，法律、法规有处罚规定的，从其规定。”

二、对《黔南布依族苗族自治州涟江流域保护条例》作出修改

（一）将第一条修改为：“为了保护涟江流域生态环境，科学合理开发利用自然资源，促进涟江流域经济社会可持续发展，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《贵州省河道条例》等法律法规的规定，结合本州实际，制定本条例。”

（二）将第十九条第七项修改为：“堆放、倾倒、掩埋、排放污染水体的物体以及在河道内清洗装贮过油类或者有毒有害污染物的车辆、容器”。

（三）将第三十六条中“养殖小区”删去。

（四）将第三十七条第三款删去。

（五）将第四十一条中的“生态环境行政主管部门”修改为“生态环境主管部门”。

本决定自2026年8月15日起施行。

《黔南布依族苗族自治州樟江流域保护条例》、《黔南布依族苗族自治州涟江流域保护条例》根据本决定作相应修改，并对条文顺序作相应调整，重新公布。
