# 四平市人民代表大会常务委员会关于修改《四平市河道管理条例》等两部地方性法规的决定

四平市人民代表大会常务委员会关于
修改《四平市河道管理条例》等两部地方性
法规的决定

（2026年8月18日四平市第九届人民代表大会常务委员会第三十三次会议通过　2026年9月29日吉林省第十四届人民代表大会常务委员会第二十五次会议批准）

四平市第九届人民代表大会常务委员会第三十三次会议决定：

一、对《四平市河道管理条例》作出修改：

（一）将第七条第二款修改为“新设、改设、扩大可能影响防洪、供水、堤防安全、河势稳定的入河排污口的，审批时应当征求水行政主管部门的意见”。

（二）将第九条修改为“农业农村主管部门应当指导农业生产经营者科学合理安全使用农药、兽药、饲料和饲料添加剂、肥料等农业投入品，科学处置农用薄膜、农作物秸秆、农业投入品包装废弃物等农业废弃物，加强对农业生产经营活动排放污染物的控制，防止农业面源污染”。

（三）删去第十条第一项，将第五项修改为“倾倒矿渣、石渣、煤灰、泥土、垃圾等，影响河势稳定、危害河岸堤防安全、妨碍河道行洪”。

（四）删去第十七条。

（五）将第十八条“违反本条例第十条第二至八项规定的”修改为“违反本条例第十条规定的”，将第一项修改为“违反第一至四项规定之一的，责令其纠正违法行为，恢复原状或者采取其他补救措施，并视情节和危害程度，可以处一万元以上五万元以下罚款。对可能导致生态环境污染的行为，由相关行政主管部门依据生态环境保护的法律法规进行处罚”。

二、对《四平市市区饮用水水源地保护条例》作出修改：

（一）在第六条第二项后增加“已建成的，由县级以上人民政府责令拆除或者关闭”。

（二）在第七条第二项后增加“已建成的，由县级以上人民政府责令拆除或者关闭”，将第三项修改为“从事网箱养殖的，应当保护水域生态环境，采取制定养殖和捕捞计划、确定养殖品种和密度、合理投饵等有效措施，防止污染水体”，在第四项后增加“防止污染水体”。

（三）删去第九条第四项、第六项、第七项，增加“禁止违反国家规定或者标准，向水体排放含热废水或者含病原体的污水”作为第五项，增加“禁止向水体排放油类、酸液、碱液”作为第六项，增加“禁止向水体排放、倾倒工业废渣、城镇垃圾或者其他废弃物，或者向河湖、渠道、水库及其最高水位线以下的滩地、岸坡以及法律法规规定的其他地点倾倒、堆放、贮存固体废物或者其他污染物”作为第七项，增加“禁止向水体排放剧毒废液，或者将含有汞、镉、砷、铬、铅、氰化物、黄磷等的可溶性剧毒废渣向水体排放、倾倒或者直接埋入地下”作为第八项，增加“其他法律法规的规定”作为第九项。

（四）将第十六条“水主管部门”修改为“水行政主管部门”。

（五）删去第十七条第二项“依据本条例查处相关违法行为”，删去“其他”。

（六）将第十八条修改为“违反本条例第六条第一项、第七条第一项规定，设置排污口的，由市、县人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由市、县生态环境主管部门处十万元以上五十万元以下罚款；情节严重的，处五十万元以上一百万元以下罚款，责令限制生产、停产整治”。

（七）在第十九条第一款后增加“并报经有批准权的人民政府批准，责令拆除或者关闭”，删去第二款。

（八）将第二十条第二款“水源管理机构”修改为“市水行政主管部门”。

（九）将第二十一条修改为“违反本条例第九条规定的，按照相关法律法规的规定予以处罚”。

（十）将第二十二条“水源管理机构”修改为“市水行政主管部门”。

此外，对地方性法规中的有关条款作文字、技术修改，并对条文顺序作相应调整。

本决定自公布之日起施行。

《四平市河道管理条例》《四平市市区饮用水水源地保护条例》根据本决定作相应修改，重新公布。
