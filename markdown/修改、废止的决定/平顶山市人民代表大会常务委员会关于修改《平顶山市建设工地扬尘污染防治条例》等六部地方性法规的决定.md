# 平顶山市人民代表大会常务委员会关于修改《平顶山市建设工地扬尘污染防治条例》等六部地方性法规的决定

平顶山市人民代表大会常务委员会关于修改
《平顶山市建设工地扬尘污染防治条例》
等六部地方性法规的决定

（2026年6月25日平顶山市第十二届人民代表大会常务委员会第三十二次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

平顶山市第十二届人民代表大会常务委员会第三十二次会议决定：

一、对《平顶山市建设工地扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了有效防治建设工地扬尘污染，保护和改善大气环境质量，保障公众健康，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）在第三条第二款中的“建筑物、构筑物拆除”后增加“以及物料堆放”，“粉尘颗粒物”修改为“颗粒物”。

（三）将第十二条第六项修改为：“施工过程中产生的建筑土方、建筑垃圾、工程渣土应当及时清运干净；在场地内堆存的，应当采用密闭式防尘网遮盖。”

（四）将第十八条中的“并实行分级分类动态管理”修改为“实行分级分类动态管理，并将相关信息按照国家和省有关规定纳入生态环境监测网络”。

（五）将第二十条、第二十三条中的“应急”修改为“应对”。

（六）将第二十一条中的“拒不改正的，责令停工整治，依法作出处罚决定的部门可以自责令改正之日起，按照原处罚数额按日连续处罚”修改为“拒不改正的，责令停工整治；作出处罚决定的部门可以依法按日连续处罚”。

（七）将第二十二条中的“二万元以上”修改为“五万元以上”；在“构成违反治安管理行为的”前面增加“对直接负责的主管人员和其他直接责任人员，处五千元以上五万元以下的罚款”。

二、对《平顶山市河道保护条例》作出修改

（一）将第一条修改为：“为了加强河道保护，保障防洪安全，改善河道生态环境，促进生态文明建设，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国河道管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）在第二条增加一款，作为第四款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）在第二十三条增加一项，作为第九项：“（九）法律、法规禁止的其他行为。”

三、对《平顶山市节约用水条例》作出修改

（一）将第一条修改为：“为了加强节约用水管理，科学合理利用水资源，提高用水效率和效益，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等法律、法规，结合本市实际，制定本条例。”

（二）将第十九条中的“应当配套建设节水设施”修改为“应当制定节水措施方案，配套建设节水设施”。

（三）将第二十六条第二款修改为：“城市绿化、道路清扫、车辆冲洗、建筑施工以及生态景观等用水，应当优先使用符合标准要求的再生水。”

四、对《平顶山市城市市容和环境卫生管理条例》作出修改

（一）将第一条修改为：“为了加强城市市容和环境卫生管理，创建和维护整洁、优美、文明、宜居的城市环境，根据《中华人民共和国生态环境法典》、国务院《城市市容和环境卫生管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）删去第十七条中的“不得造成噪声污染，并且”。

（三）将第十八条第一款中的“禁止区域”修改为“当地人民政府禁止的时段和区域”；将第二款中的“禁止区域”修改为“禁止的时段和区域”。

（四）将第二十九条修改为：“任何单位和个人不得损坏或者擅自关闭、闲置、拆除环境卫生设施。确有必要关闭、闲置或者拆除的，应当经市、县（市）、石龙区城市市容和环境卫生行政主管部门同意，其中涉及生活垃圾处理设施的，应当依法商生态环境主管部门同意后核准，由建设单位按照先建后拆的原则负责重建，未建成替代设施的不得拆除。原地重建确有困难需要易地建设的，由建设单位按重置价补偿。”

（五）将第四十七条修改为：“违反第十八条第一款规定，在当地人民政府禁止的时段和区域进行露天烧烤或者为露天烧烤提供场所的，责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

（六）将第五十二条第三项修改为：“（三）擅自关闭、闲置、拆除生活垃圾处置设施的，责令改正，没收违法所得，并处十万元以上一百万元以下罚款；擅自关闭、闲置、拆除生活垃圾处置设施以外的其他环境卫生设施的，处以三千元以上一万元以下罚款；造成损失的，依法承担赔偿责任。”

（七）将第五十三条修改为：“违反第三十五条规定的，责令改正，处二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶。”

（八）删去第五十四条。

（九）将第五十五条改为第五十四条，修改为：“违反第三十八条、第三十九条第一项至第四项规定的，责令改正，处一百元以上一千元以下的罚款。”

五、对《平顶山市城市绿化条例》作出修改

（一）将第二十条中的“裸露空地”修改为“裸露地面”，“明确责任”修改为“明确责任单位”。

（二）将第四十四条第一项修改为：“（一）违反第一项、第二项、第四项、第五项规定的，责令改正；逾期不改正的，处以一百元以上一千元以下罚款”。

六、对《平顶山市文明行为促进条例》作出修改

（一）在第二条增加一款，作为第三款：“本条例未作规定的，适用有关法律、法规的规定。”

（二）删去第十四条第一项。

（三）删去第三十八条。

本决定自2026年8月15日起施行。

《平顶山市建设工地扬尘污染防治条例》、《平顶山市河道保护条例》、《平顶山市节约用水条例》、《平顶山市城市市容和环境卫生管理条例》、《平顶山市城市绿化条例》、《平顶山市文明行为促进条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
