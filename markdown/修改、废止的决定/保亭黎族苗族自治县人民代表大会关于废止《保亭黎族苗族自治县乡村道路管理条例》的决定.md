# 保亭黎族苗族自治县人民代表大会关于废止《保亭黎族苗族自治县乡村道路管理条例》的决定

关于废止《保亭黎族苗族自治县乡村
道路管理条例》的决定

（2026年2月8日保亭黎族苗族自治县第十六届人民代表大会第六次会议通过　2026年3月31日海南省第七届人民代表大会常务委员会第二十三次会议批准）

保亭黎族苗族自治县第十六届人民代表大会第六次会议决定废止《保亭黎族苗族自治县乡村道路管理条例》（2000年3月24日保亭黎族苗族自治县第十一届人民代表大会第三次会议通过，2000年5月26日海南省第二届人民代表大会常务委员会第十四次会议批准）。

本决定自公布之日起施行。
