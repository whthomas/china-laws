# 玉屏侗族自治县人民代表大会关于废止《玉屏侗族自治县个体经济私营经济发展保护条例》的决定

玉屏侗族自治县人民代表大会关于废止
《玉屏侗族自治县个体经济私营经济
发展保护条例》的决定

（2026年2月28日玉屏侗族自治县第十届人民代表大会第五次会议通过　2026年3月26日经贵州省第十四届人民代表大会常务委员会第二十二次会议批准）

玉屏侗族自治县第十届人民代表大会第五次会议审议了《玉屏侗族自治县人民代表大会常务委员会关于提请废止〈玉屏侗族自治县个体经济私营经济发展保护条例〉的议案》，决定废止《玉屏侗族自治县个体经济私营经济发展保护条例》。

本决定自公布之日起施行。
