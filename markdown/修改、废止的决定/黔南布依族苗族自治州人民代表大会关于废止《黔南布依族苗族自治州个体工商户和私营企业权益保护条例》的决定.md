# 黔南布依族苗族自治州人民代表大会关于废止《黔南布依族苗族自治州个体工商户和私营企业权益保护条例》的决定

黔南布依族苗族自治州人民代表大会关于废止
《黔南布依族苗族自治州个体工商户和
私营企业权益保护条例》的决定

（2026年3月2日黔南布依族苗族自治州第十五届人民代表大会第五次会议通过　2026年3月26日贵州省第十四届人民代表大会常务委员会第二十二次会议批准）

黔南布依族苗族自治州第十五届人民代表大会第五次会议审议了《黔南布依族苗族自治州人民代表大会常务委员会关于提请审议废止〈黔南布依族苗族自治州个体工商户和私营企业权益保护条例〉的议案》，决定废止《黔南布依族苗族自治州个体工商户和私营企业权益保护条例》。

本决定自公布之日起施行。
