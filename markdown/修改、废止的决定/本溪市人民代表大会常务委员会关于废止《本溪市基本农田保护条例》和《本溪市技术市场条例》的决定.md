# 本溪市人民代表大会常务委员会关于废止《本溪市基本农田保护条例》和《本溪市技术市场条例》的决定

本溪市人民代表大会常务委员会
关于废止《本溪市基本农田保护条例》和
《本溪市技术市场条例》的决定

（2025年12月25日本溪市第十七届人民代表大会常务委员会第三十一次会议通过　2026年3月25日辽宁省第十四届人民代表大会常务委员会第二十二次会议批准）

本溪市第十七届人民代表大会常务委员会第三十一次会议审议了市政府提出的《本溪市人民政府关于2025年地方性法规废止建议的议案》，决定废止《本溪市基本农田保护条例》和《本溪市技术市场条例》。

本决定自公布之日起施行。
