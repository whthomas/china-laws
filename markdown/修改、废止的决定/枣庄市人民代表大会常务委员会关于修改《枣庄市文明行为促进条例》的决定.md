# 枣庄市人民代表大会常务委员会关于修改《枣庄市文明行为促进条例》的决定

枣庄市人民代表大会常务委员会关于修改
《枣庄市文明行为促进条例》的决定

（2026年6月29日枣庄市第十七届人民代表大会常务委员会第三十八次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

枣庄市第十七届人民代表大会常务委员会第三十八次会议决定对《枣庄市文明行为促进条例》作如下修改：

一、将第五条修改为：“市、区（市）精神文明建设工作机构负责本行政区域内文明行为促进工作的组织协调和督促落实。”

二、将第十条第三项修改为：“不在建筑内的公用走道、楼梯间、安全出口等公共区域停放电动车或者为其充电”。

三、将第十三条第三项修改为：“不得使用高音广播喇叭或者采用其他持续反复发出高噪声的方法进行广告宣传”。

将第四项修改为“不得在禁止的时段和区域摆摊设点、露天烧烤食品或者为露天烧烤食品提供场地”。

四、将第十五条第三项修改为：“不得在禁止的时段和区域露天焚烧秸秆、落叶等产生烟尘污染的物质”。

五、将第二十一条第三款修改为：“市、区（市）社会工作部门应当会同有关部门建立志愿服务组织和志愿者的注册、记录评价等保障激励制度。”

六、将第二十三条修改为：“倡导鼓励单位和个人积极参与和开展文明城市、文明村镇、文明单位、文明校园、文明家庭等群众性精神文明创建活动，对表现突出、成效显著的按照有关规定予以褒扬激励。”

七、将第三十六条改为第三十三条，修改为：“报纸、广播、电视、网络等大众传播媒介，公共场所的广告设施和公共交通工具的广告介质应当按照规定刊播公益广告，规范使用广告用语。”

八、将第四十四条改为第四十条，修改为：“违反本条例第九条第六项规定，巡游出租车驾驶员拒载、随意涨价的，由交通运输部门责令改正，并处二百元以上五百元以下罚款。”

九、将第四十七条改为第四十三条，修改为：“政府和有关部门及其工作人员在文明行为促进工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

十、删除第二十四条、第二十五条、第二十六条、第四十二条。

此外，对条文顺序和个别文字作相应调整和修改。

本决定自2026年8月15日起施行。

《枣庄市文明行为促进条例》根据本决定作相应修改，重新公布。
