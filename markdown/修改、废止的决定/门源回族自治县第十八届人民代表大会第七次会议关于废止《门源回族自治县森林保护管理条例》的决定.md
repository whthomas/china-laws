# 门源回族自治县第十八届人民代表大会第七次会议关于废止《门源回族自治县森林保护管理条例》的决定

门源回族自治县第十八届人民代表大会
第七次会议关于废止《门源回族
自治县森林保护管理条例》
的决定

（2026年3月6日门源回族自治县第十八届人民代表大会第七次会议通过　2026年4月1日青海省第十四届人民代表大会常务委员会第二十一次会议批准）

经门源回族自治县第十八届人民代表大会第七次会议审议，决定废止《门源回族自治县森林保护管理条例》，报请青海省人民代表大会常务委员会批准后废止。
