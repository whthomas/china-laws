# 贵阳市人民代表大会常务委员会关于废止《贵阳市禁止生产销售使用含磷洗涤剂规定》的决定

贵阳市人民代表大会常务委员会
关于废止《贵阳市禁止生产销售使用
含磷洗涤剂规定》的决定

（2026年6月25日贵阳市第十五届人民代表大会常务委员会第三十六次会议通过　2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

贵阳市第十五届人民代表大会常务委员会第三十六次会议决定：

废止《贵阳市禁止生产销售使用含磷洗涤剂规定》。

本决定自公布之日起施行。
