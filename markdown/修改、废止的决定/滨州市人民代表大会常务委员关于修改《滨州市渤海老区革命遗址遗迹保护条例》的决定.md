# 滨州市人民代表大会常务委员关于修改《滨州市渤海老区革命遗址遗迹保护条例》的决定

滨州市人民代表大会常务委员会
关于修改《滨州市渤海老区革命遗址遗迹
保护条例》的决定

（2026年9月3日滨州市第十二届人民代表大会常务委员会第三十四次会议通过　2026年9月23日山东省第十四届人民代表大会常务委员会第二十六次会议批准）

滨州市第十二届人民代表大会常务委员会第三十四次会议决定对《滨州市渤海老区革命遗址遗迹保护条例》作如下修改：

一、将第一条修改为：“为了加强对渤海老区革命遗址遗迹的保护，发挥革命遗址遗迹的爱国主义和革命传统教育作用，弘扬革命精神，传承红色文化，培育和践行社会主义核心价值观，根据有关法律、法规，结合本市实际，制定本条例。”

二、将第二条修改为：“本市行政区域内革命遗址遗迹的保护活动，适用本条例。

“法律、法规对革命遗址遗迹中涉及文物、历史建筑和烈士纪念设施等已有规定的，适用其规定。”

三、将第四条修改为：“革命遗址遗迹保护应当坚持中国共产党的领导，遵循统筹协调、规范管理、科学保护、合理利用的原则，保持历史真实性、风貌完整性和文化延续性。”

四、将第五条修改为：“市、县（市、区）人民政府负责本行政区域内的革命遗址遗迹保护工作，乡镇人民政府按照职责做好相关工作。

“市、县（市、区）人民政府应当将革命遗址遗迹保护纳入国民经济和社会发展规划、国土空间规划，并将革命遗址遗迹保护所需经费列入本级财政预算，统筹协调解决革命遗址遗迹保护工作中的重大问题。”

五、将第八条改为第七条，第一款修改为：“任何组织和个人都有保护革命遗址遗迹的义务，并有权对损毁、侵占、破坏、污损革命遗址遗迹的行为进行劝阻、举报。”

六、将第九条改为第八条，第一项修改为：“（一）市、县（市、区）人民政府文化和旅游部门会同同级退役军人事务、党史研究等部门，定期组织开展革命遗址遗迹普查工作，建立数据库；”

七、将第十条改为第九条，第一款修改为：“市、县（市、区）人民政府文化和旅游部门应当会同住房城乡建设、自然资源规划等部门，根据革命遗址遗迹保护单位的规模、内容以及周围环境的历史和现实情况，合理划定保护范围和建设控制地带，报本级人民政府批准并予以公布。”

八、增加两条，作为第十一条、第十二条：

“第十一条在革命遗址遗迹保护单位的保护范围内不得从事下列行为：

“（一）擅自进行建设工程或者爆破、钻探等作业；

“（二）采石、采矿、挖砂、开荒、砍伐、取土；

“（三）倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物；

“（四）生产、储存或者使用易燃、易爆、有毒、腐蚀性等物品；

“（五）其他影响、危害、破坏革命遗址遗迹保护单位安全和环境的行为。

“第十二条在革命遗址遗迹保护单位建设控制地带内进行工程建设，应当确保建设规模、体量、风格、色调与革命遗址遗迹保护单位历史风貌相协调，不得破坏革命遗址遗迹保护单位历史风貌。

“对革命遗址遗迹保护单位建设控制地带内已经存在的与其历史风貌不相协调的建筑物、构筑物，应当依法逐步改造。”

九、将第十二条改为第十三条，增加一款，作为第二款：“因重大公共利益必须对革命遗址遗迹保护单位进行异地保护的，应当依照有关法律、法规执行。”

十、将第十四条改为第十五条，第一款修改为：“县（市、区）人民政府文化和旅游部门应当定期或者在重大自然灾害发生后，对革命遗址遗迹保护单位的保护利用情况开展排查，及时记入排查档案。排查结果报市人民政府文化和旅游部门备案。”

十一、将第十五条改为第十六条，修改为：“革命遗址遗迹保护单位应当按照下列规定确定保护责任人：

“（一）国家所有的，其使用权人或者管理人为保护责任人；

“（二）非国家所有的，其所有权人或者所有权人委托的人为保护责任人；

“（三）权属不明确的，由县（市、区）人民政府指定保护责任人。”

十二、将第二十条改为第十九条，删去“保护管理责任人应当在施工前，将设计、施工方案报相应的文物行政部门批准。文物行政部门在批准前应当征求同级党史研究机构的意见。”

十三、将第二十二条改为两条，作为第二十条、第二十一条，修改为：

“第二十条市、县（市、区）人民政府应当合理利用革命遗址遗迹资源，梳理、研究、编纂和出版革命遗址遗迹相关资料，深入挖掘和展示革命文化和历史价值，充分发挥社会教育功能。

“国家机关、企业事业单位和社会组织可以利用革命遗址遗迹开展爱国主义和革命传统教育。

“各类学校和干部培训机构可以将革命遗址遗迹所承载的革命文化和历史价值纳入教育培训内容，利用革命遗址遗迹开展研学实践教育活动。

“第二十一条市、县（市、区）人民政府文化和旅游部门应当开发、推广红色文化特色的旅游线路、旅游服务，深化红色旅游区域合作，促进革命遗址遗迹资源利用与旅游融合发展。

“民政、自然资源规划、交通运输、文化和旅游等部门制作辖区地图、开发公众服务平台、建设公共交通站台、设置旅游交通标志和设施标牌时，应当包含革命遗址遗迹相关内容。”

十四、增加一条，作为第二十二条：“各类革命遗址遗迹应当逐步实现向社会公众开放。

“具备条件的国有革命遗址遗迹应当免费向社会公众开放。

“鼓励非国有革命遗址遗迹免费向社会公众开放。”

十五、删去第六条、第七条第一款、第十条第二款、第十一条第二款、第十二条第二款、第三款、第十七条、第十八条第三项、第十九条、第二十一条、第二十四条、第二十七条、第二十八条、第二十九条。

此外，根据机构改革职能调整情况对有关单位名称和职责进行调整，同时对标点符号使用、部分语言文字表述和条文、款项序号等作了修改。

本决定自2027年1月1日起施行。

《滨州市渤海老区革命遗址遗迹保护条例》根据本决定作相应修改，重新公布。
