# 宁夏回族自治区人民代表大会常务委员会关于修改《宁夏回族自治区实施〈中华人民共和国村民委员会组织法〉办法》、《宁夏 回族自治区实施〈中华人民共和国城市居民委员会组织法〉办法》的决定

宁夏回族自治区人民代表大会常务委员会
关于修改《宁夏回族自治区实施〈中华人民
共和国村民委员会组织法〉办法》、《宁夏
回族自治区实施〈中华人民共和国城市
居民委员会组织法〉办法》的决定

（2026年9月24日宁夏回族自治区第十三届人民代表大会常务委员会第二十七次会议通过）

宁夏回族自治区第十三届人民代表大会常务委员会第二十七次会议决定：

一、对《宁夏回族自治区实施〈中华人民共和国村民委员会组织法〉办法》作出修改

（一）删去第一条中的“（以下简称组织法）”。

（二）将第二条第一款中的“自我管理、自我教育、自我服务”修改为“自我管理、自我服务、自我教育、自我监督”，在“实行民主选举”后面增加“民主协商”。

（三）删去第三条中的“发挥领导核心作用”。

增加一款，作为第一款：“村民委员会工作坚持中国共产党的领导，坚持以铸牢中华民族共同体意识为主线，坚持和发展全过程人民民主，坚持自治、法治、德治相结合。”

（四）增加一条，作为第四条：“县级以上基层群众自治指导监督部门负责指导和监督农村基层群众自治工作。”

（五）将第五条改为第六条，在第二款中增加“村民委员会每届任期五年。”

（六）将第六条改为第七条，修改为：“村民委员会履行下列职责：

“（一）宣传宪法、法律、法规，宣传党和国家的政策，支持和推动村民履行法律规定的义务，维护村民的合法权益；

“（二）支持和引导村民践行社会主义核心价值观，遵循公序良俗，摒除陈规陋习，倡导村民在衣食住行、生活交往、婚丧嫁娶、礼仪习俗等方面追求现代文明方式，培育文明乡风；

“（三）支持和引导村民铸牢中华民族共同体意识，增进团结、互相尊重、互相帮助，维护、巩固和发展平等团结互助和谐的社会主义民族关系；

“（四）发展文化教育，普及科技知识，促进男女平等和家庭和睦，关心关爱老年人、留守儿童、残疾人和困难村民；

“（五）办理本村的公共事务和公益事业，开展便民利民的服务活动；

“（六）召集村民会议、村民代表会议，执行村民会议和村民代表会议的决定、决议，组织实施村民自治章程和村规民约；

“（七）支持和组织村民依法发展各种形式的合作经济和其他经济，承担本村生产的服务和协调工作，促进农村生产建设和经济发展；

“（八）尊重并支持农村集体经济组织依法独立进行经济活动的自主权，维护以家庭承包经营为基础、统分结合的双层经营体制，保障农村集体经济组织和村民、承包经营户、联户或者合伙的财产权和其他合法权益；

“（九）依照法律规定，引导村民合理利用自然资源，保护和改善生态环境，推进美丽乡村建设；

“（十）协助维护社会治安，协助组织村民参与群防群治，协助处理信访事项和协调化解矛盾纠纷，协助做好社区矫正工作和刑满释放人员帮教工作，协助做好突发事件应对工作；

“（十一）支持和引导社会组织、社会工作者、志愿者等社会力量参与乡村治理和服务；

“（十二）向人民政府反映村民的意见、要求和提出建议；

“（十三）其他依法应当履行的职责。”

（七）将第九条改为第十条，第二项修改为：“（二）执行村民会议、村民代表会议和村民小组会议的决定、决议”。

增加一项，作为第七项：“（七）办理与本村民小组有关的其他事项。”

（八）将第十条改为第十一条，第二款中的“应当提前十天通知村民拟讨论的具体事项”修改为“应当提前十日将会议时间、地点和拟讨论的事项等通知村民；遇有特殊情况的，可以临时通知村民。”

（九）将第十一条改为第十二条，删去第二款。

将第三款修改为：“村民会议有权撤销或者变更村民代表会议和村民委员会不适当的决定。经村民会议授权，村民代表会议可以撤销或者变更村民委员会不适当的决定”，作为第二款。

增加一款，作为第三款：“需由村民会议或者村民代表会议决定的重要事项，应当先经村党组织研究讨论。”

（十）将第十二条改为第十三条，“妇女代表”修改为“妇女村民代表”，删去“多民族居住的村，应当有人数较少的民族的代表”。

（十一）将第十三条改为第十四条，第一款中的“为五年”修改为“与村民委员会的任期相同”，删去“户数较少的村每五户至九户推选一人；户数较多的村每十户至十五户推选一人；或者由每个村民小组推选五至十人。”

（十二）将第十四条改为第十五条，删去“（二）受到刑事处罚的；”将第三项改为第二项，修改为：“（二）户口迁出、不在本村长期居住等不能正常履行职责的”。

增加一款，作为第二款：“村民代表丧失行为能力或者被判处刑罚的，其资格自行终止。”

（十三）将第十六条改为第十七条，在第一款中增加“召集村民代表会议，应当提前五日将会议时间、地点和拟讨论的事项等通知会议组成人员；遇有特殊情况的，可以临时通知”。

将第二款中的“村民代表意见和建议”修改为“参加会议人员意见和建议”。

（十四）将第十七条改为第十八条，删去第三款。

（十五）增加一条，作为第十九条：“村民委员会应当建立村级民主协商机制，根据协商议题内容和工作需要，合理确定协商形式和参与主体，规范协商程序，健全协商成果采纳、落实、反馈、公示、评价等制度。

“对协商确定的事项，需要提交村民会议或者村民代表会议的，村民委员会应当召集会议讨论决定。

“鼓励和支持运用信息化手段开展协商。”

（十六）将第二十一条、第二十三条、第二十七条中的“村民监督委员会”修改为“村务监督委员会”。

（十七）将第二十一条改为第二十三条，删去第二款中的“村民监督委员会应当有妇女成员”，将“村民监督委员会成员应当列席村民委员会会议”修改为“村务监督委员会成员可以列席村民委员会会议和村民代表会议，参与各项协商活动”。

增加一款，作为第三款：“村务监督委员会成员实行近亲属回避。村民委员会成员及其近亲属不得担任村务监督委员会成员。”

增加一款，作为第四款：“村务监督委员会主任可以由非村民委员会成员的村党组织领导班子成员通过法定程序担任。”

（十八）将第二十七条改为第二十四条，删去其中的“村民委员会成员”。

（十九）将第二十二条改为第二十五条，第一项中的“政策”修改为“党和国家的政策”，在“实行民主选举”后面增加“民主协商”。

（二十）增加一章“村民委员会工作的保障”，作为第五章。

（二十一）将第二十五条第二款改为第二十八条，作为第二款，删去其中的“开展社区建设”，将“支持”修改为“适当支持”。

增加一款，作为第一款：“村民委员会日常运转经费、成员基本报酬标准由县级以上人民政府规定，并由县级人民政府给予适当补助。”

增加一款，作为第三款：“村集体经济收入应当适当用于村公共事务和公益事业、村民委员会运转保障以及误工人员补贴。”

（二十二）将第二十五条第一款改为第二十九条，“人民政府对村民委员会协助政府开展工作应当提供必要的条件”修改为“乡镇人民政府对村民委员会协助政府开展工作应当提供必要的经费和条件”，作为第一款。

将“人民政府有关部门委托村民委员会开展工作需要经费的，由委托部门承担”修改为“各级人民政府应当建立健全整治形式主义为基层减负长效机制，有关部门委托村民委员会协助开展工作的事项，应当符合法律、法规规定，所需经费由委托部门承担”，作为第二款。

（二十三）增加一条，作为第三十条：“自治区基层群众自治指导监督部门按照国家和自治区有关规定组织编制村工作事项指导目录，明确依法自治事项、依法协助事项，进行动态调整并向社会公布。”

（二十四）增加一条，作为第三十一条：“村级综合服务设施建设应当纳入相关规划。县级以上人民政府应当对村级综合服务设施建设给予支持，整合完善服务功能，方便村民生产生活。

“县级以上人民政府应当对乡村治理信息化建设进行统筹规划和实施，推进数字乡村建设，提高乡村治理数字化智能化水平。”

（二十五）将第二十六条改为第三十二条，修改为：“乡镇人民政府或者县级人民政府应当建立健全村务工作者培训机制，制定和实施培训计划，为村民委员会成员以及其他村务工作者提供培训，帮助其提升政治素质、法治意识、政策水平和服务能力。培训经费由县级人民政府解决。”

（二十六）增加一条，作为第三十三条：“街道设有村民委员会的，街道办事处履行本办法规定的应当由乡镇人民政府履行的职责。”

二、对《宁夏回族自治区实施〈中华人民共和国城市居民委员会组织法〉办法》作出修改

（一）将第一条中的“为了实施”修改为“根据”。

（二）将第二条第一款中的“自我管理、自我教育、自我服务”修改为“自我管理、自我服务、自我教育、自我监督”，增加“实行民主选举、民主协商、民主决策、民主管理、民主监督”。

将第二款中的“镇人民政府”修改为“乡镇人民政府”。

（三）增加一条，作为第三条：“居民委员会工作坚持中国共产党的领导，坚持以铸牢中华民族共同体意识为主线，坚持和发展全过程人民民主，坚持自治、法治、德治相结合。

“中国共产党在社区的基层组织，按照中国共产党章程进行工作，领导和支持居民委员会行使职权；依照宪法和法律，支持和保障居民开展自治活动、直接行使民主权利。”

（四）增加一条，作为第四条：“县级以上基层群众自治指导监督部门负责指导和监督城市基层群众自治工作。”

（五）将第四条改为第五条，第一款中的“100户至700户”修改为“一千户至三千户”，增加“有利于基层治理”和“也可以根据实际需要在适当范围内设立”。

将第二款中的“镇人民政府”修改为“乡镇人民政府”，“决定”修改为“批准”。

（六）将第五条改为第六条，删去第一款中的“成员职数由所在地的县（市、区）人民政府根据居民委员会的规模和经济条件等情况确定。”

删去第二款。

（七）将第十四条改为第七条第一款，增加“环境和物业管理、老年人和妇女儿童工作”。

将第二十四条第二款改为第七条第二款，增加“并提供相应的支持和帮助”。

（八）将第三条改为第八条，修改为：“居民委员会履行下列职责：

“（一）宣传宪法、法律、法规，宣传党和国家的政策，支持和推动居民履行法律规定的义务，维护居民的合法权益；

“（二）支持和引导居民践行社会主义核心价值观，遵循公序良俗，摒除陈规陋习，倡导居民在衣食住行、生活交往、婚丧嫁娶、礼仪习俗等方面追求现代文明方式；

“（三）支持和引导居民铸牢中华民族共同体意识，增进团结、互相尊重、互相帮助，维护、巩固和发展平等团结互助和谐的社会主义民族关系；

“（四）办理本社区居民的公共事务和公益事业，开展便民利民的社区服务活动，关心关爱老年人、儿童、残疾人和困难居民；

“（五）调解民间纠纷，促进家庭和睦、邻里和谐、社区安宁；

“（六）协助维护社会治安，组织居民参与群防群治，协助处理信访事项和协调化解矛盾纠纷，协助做好社区矫正工作和刑满释放人员帮教工作，协助做好突发事件应对工作；

“（七）支持和引导社会组织、社会工作者、志愿者等社会力量参与社区治理，提供社区服务；

“（八）指导和协助设立业主大会和选举业主委员会，协助指导和监督业主大会和业主委员会依法履行职责，协助调解物业纠纷；

“（九）协助人民政府或者街道办事处做好与居民利益有关的其他工作；

“（十）向人民政府或者街道办事处反映居民的意见、要求和提出建议；

“（十一）其他依法应当履行的职责。”

（九）将第十六条改为第九条，修改为：“居民委员会及其成员应当遵守宪法、法律、法规，遵守党和国家的政策，遵守并组织实施居民自治章程、居民公约，执行居民会议、居民代表会议的决定、决议，办事公道，廉洁奉公，热心为居民服务，接受居民监督。”

（十）将第十七条改为第十条，删去其中的“根据居民居住的状况”，“由居民推选”修改为“由居民小组从居民代表中推选”。

（十一）将第六条改为第十一条，第一款中的“居住地区”修改为“社区”，“每个居民小组选举代表2至3人”修改为“居民代表”。

将第二款修改为：“居民委员会的选举由居民选举委员会主持。”

（十二）将第七条改为第十二条，“依法享有选举权的居民10人以上、户派代表5人以上或者居民小组推选的代表3人以上联名提出，也可以由镇人民政府或者街道办事处”修改为“社区党组织或者十名以上选民联合提名”。

删去第二款中的“本居住地区的”。

（十三）将第九条改为第十三条第一款，删去其中的“被提名的候选人数与应选人数相等时，也可实行等额选举”。

将第八条改为第十三条第二款，修改为：“居民选举委员会应当在选举日的七日前，以姓名笔画为序公布被提名的候选人名单。”

（十四）将第十条改为第十四条，修改为：“居民委员会选举实行无记名投票。采取全体有选举权的居民选举方式的，有选民的过半数参加投票，选举有效；采取每户派代表选举方式的，有户的代表的过半数参加投票，选举有效；采取居民代表选举方式的，有超过三分之二的居民代表参加投票，选举有效。

“候选人获得参加投票的人员过半数的选票，始得当选。获得过半数选票的人数超过应选名额时，以得票多的当选；票数相等不能确定当选人时，就票数相等的人再次投票，以得票多的当选。”

（十五）将第十九条改为第十五条，将第一款修改为：“居民委员会成员因故不能继续担任职务的，可以书面向居民委员会提出辞职申请，其职务自居民会议或者居民代表会议审议通过之日起终止。”

删去第二款。

（十六）将第十一条改为第十六条，修改为：“居民会议由本社区十八周岁以上的居民组成。召开居民会议，应当有全体十八周岁以上的本社区居民或者户的代表的过半数参加。居民会议所作决定，应当经到会人员的过半数通过。

“居民代表会议由居民委员会成员和居民代表组成，有三分之二以上的组成人员参加方可召开。居民代表会议所作决定，应当经到会组成人员的过半数通过。

“召开居民会议、居民代表会议，根据需要可以邀请驻本社区的机关、团体、部队、企业事业组织等派代表列席。”

（十七）将第十二条改为第十七条，在第一款“居民会议”后面增加“居民代表会议”。

将第二款修改为：“居民会议、居民代表会议由居民委员会召集和主持。居民委员会应当提前将会议时间、地点和拟讨论的事项等通知会议组成人员；遇有特殊情况的，可以临时通知。”

（十八）将第十三条改为第十八条，修改为：“居民会议讨论决定下列事项：

“（一）听取并审议居民委员会的年度工作报告，评议居民委员会成员的工作；

“（二）制定或者修改居民自治章程、居民公约；

“（三）本社区公益事业发展规划；

“（四）其他涉及全体居民利益的重要事项。

“居民会议有权撤销或者变更居民代表会议和居民委员会不适当的决定。”

（十九）增加一条，作为第十九条：“居民委员会应当建立社区民主协商机制，根据协商议题内容和工作需要，合理确定协商形式和参与主体，规范协商程序，健全协商成果采纳、落实、反馈、公示、评价等制度。

“对协商确定的事项，需要提交居民会议或者居民代表会议的，居民委员会应当召集会议讨论决定。

“鼓励和支持运用信息化手段开展协商。”

（二十）将第十五条改为第二十条，修改为：“居民委员会的工作应当坚持群众路线，实行少数服从多数的民主决策机制和公开透明的工作原则，建立健全居务公开、民主评议等工作制度。”

（二十一）增加一条，作为第二十一条：“社区应当建立居务监督委员会。居务监督委员会由三至五人组成，设主任一人。居务监督委员会主任可以由非居民委员会成员的社区党组织领导班子成员通过法定程序担任。

“居务监督委员会成员实行近亲属回避。居民委员会成员及其近亲属不得担任居务监督委员会成员。”

（二十二）删去第十八条、第二十条。

（二十三）将第二十一条改为第二十二条，修改为：“居民委员会日常运转经费、成员报酬及其标准，由县（市、区）人民政府或者上级人民政府规定并拨付。”

（二十四）将第二十四条第一款改为第二十三条，修改为：“各级人民政府应当建立健全整治形式主义为基层减负长效机制，有关部门委托居民委员会协助开展工作的事项，应当符合法律、法规规定，所需经费由委托部门承担。”

（二十五）增加一条，作为第二十四条：“自治区基层群众自治指导监督部门按照国家和自治区有关规定组织编制社区工作事项指导目录，明确依法自治事项、依法协助事项，进行动态调整并向社会公布。”

（二十六）将第二十二条改为第二十五条，将“居民委员会的办公用房和设施，由当地人民政府统筹解决”修改为“社区综合服务设施由县级以上人民政府统筹解决”，作为第一款。

将“凡新建居民住宅区或对老居民区进行小区改造的，必须将居民委员会办公用房纳入建设规划，并按照居住区公共设施配套建设的有关规定建设”修改为“新建居民住宅区或者对老旧居民区进行改造，应当将社区综合服务设施纳入建设规划，并按照居住区公共设施配套建设的有关规定建设”，作为第二款。

增加一款，作为第三款：“县级以上人民政府应当对社区信息化建设进行统筹规划和实施，推进智慧社区建设，提高社区治理数字化智能化水平。”

（二十七）将第二十三条改为第二十六条，修改为：“机关、团体、部队、企业事业组织等驻社区单位，不参加本社区的居民委员会，但是应当支持居民委员会的工作。居民委员会组织讨论同驻社区单位有关的问题，需要驻社区单位参加会议时，驻社区单位应当派代表参加。驻社区单位在参与社区治理、提供社区服务中接受居民委员会指导，遵守居民公约，促进社区共建共治共享。”

（二十八）删去第二十五条、第二十六条。

本决定自公布之日起施行。
