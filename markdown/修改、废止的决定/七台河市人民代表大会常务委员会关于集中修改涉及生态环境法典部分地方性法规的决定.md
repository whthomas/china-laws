# 七台河市人民代表大会常务委员会关于集中修改涉及生态环境法典部分地方性法规的决定

七台河市人民代表大会常务委员会
关于集中修改涉及生态环境法典
部分地方性法规的决定

（2026年7月23日七台河市第十二届人民代表大会常务委员会第三十二次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

七台河市第十二届人民代表大会常务委员会第三十二次会议决定：

一、对《七台河市煤矸石污染环境防治和综合利用条例》作出修改

（一）将第一条修改为：“为了防治煤矸石污染环境，促进煤矸石综合利用，推进生态文明建设，根据《中华人民共和国生态环境法典》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第四条第一款修改为：“煤矸石污染环境防治坚持减量化、资源化、无害化和损害担责的原则，实行统筹规划、源头防控、分类管理、数字赋能、社会共治、全过程管控。”

（三）将第十一条第一款修改为：“产生、收集、贮存、运输、利用、处置煤矸石的单位和其他生产经营者，应当采取防扬散、防流失、防渗漏或者其他防止污染环境的措施，不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧煤矸石。”

（四）将第二十一条第一款修改为：“煤炭采选企业应当采用有利于保护生态环境和防止煤矸石污染的勘查、开采方法和工艺技术，减少煤矸石的产生量和贮存量。”

（五）将第二十三条第二款修改为：“依法利用煤矸石和从煤矸石中回收原料生产产品的，按照国家规定享受税收等优惠。”

（六）将第二十四条第一款修改为：“鼓励、引导公民、法人和其他组织使用有利于保护生态环境的煤矸石产品、技术和工艺，减少煤矸石的产生，促进煤矸石综合利用。”

（七）将第二十四条第二款修改为：“本市各级国家机关和其他使用财政性资金的公共机构应当按照采购要求，在建筑物、市政建设工程、环境保护及绿化工程、农田水利工程等采购活动中，优先采购和使用有利于保护生态环境的煤矸石等综合利用产品。”

（八）将第二十七条修改为：“违反本条例规定，有下列情形之一，由生态环境主管部门责令改正，处十万元以上一百万元以下的罚款：

“（一）擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧煤矸石的；

“（二）未采取防范措施，造成煤矸石扬散、流失、渗漏或者其他环境污染的；

“（三）贮存煤矸石未采取符合国家生态环境保护标准的防护措施，或者临时堆放场（库）堆放超过其储存量造成环境污染的；

“（四）产生煤矸石的单位，违反本条例第十六条第一款规定委托他人运输、利用、处置煤矸石的。

“有第一项情形的，还应当采取治理措施消除污染，没收违法所得；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。

“有第二项、第三项、第四项情形之一，情节严重的，报经有批准权的人民政府批准，责令停业、关闭；有第三项、第四项情形之一的，应当同时没收违法所得。”

二、对《七台河市倭肯河流域水环境保护条例》作出修改

（一）将第一条修改为：“为了保护倭肯河流域水环境，防治水污染，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第四条修改为：“倭肯河流域水环境保护坚持预防为主、系统治理、生态优先、绿色发展、公众参与、损害担责的原则。”

（三）将第十条第一款修改为：“市、县（区）人民政府、乡（镇）人民政府、街道办事处以及其他有关部门，应当加强倭肯河流域水环境保护的宣传教育，弘扬生态文化，增强公众的生态环境保护意识和法治素养。”

（四）将第十七条改为第十六条，第一项修改为：“通过暗管、渗井、渗坑、灌注、裂隙、溶洞、篡改或者伪造监测数据、以逃避现场检查为目的的临时停产、非紧急情况下开启应急排放通道、不正常运行污染防治设施等逃避监管的方式排放污染物”。

第二项修改为：“使用炸鱼、毒鱼、电鱼等破坏渔业资源和渔业水域生态环境的方法进行捕捞，制造、销售、使用禁用的渔具，使用小于最小网目尺寸的网具进行捕捞，捕捞的渔获物中幼鱼不得超过规定的比例”。

（五）将第二十三条改为第二十二条，修改为：“工业园区等区域应当配套建设相应的污水集中处理设施、按照相关规定安装自动监测设备，与生态环境主管部门的监控设备联网，并保证污水处理设施、监测设备正常运行、污染物达标排放。”

（六）将第二十五条改为第二十四条，第一款修改为：“畜禽散养密集区内的畜禽养殖专业户、散养户等规模以下畜禽养殖户应当建设畜禽粪污临时贮存设施，临时收集畜禽粪污，不得在集中处理设施外倾倒、排放，防止污染水体。”

增加一款，作为第二款：“畜禽散养密集区外的畜禽养殖专业户、散养户等规模以下畜禽养殖户应当及时对畜禽粪便、污水等进行收集、贮存、清运，不得渗出、泄漏，防止污染水体。”

将第二款改为第三款，修改为：“规模以下养殖户应当采取粪肥还田等有效措施，对畜禽养殖废弃物进行无害化处理或者资源化利用。”

将第三款改为第四款，修改为：“畜禽散养密集区所在地县、乡级人民政府应当组织对畜禽粪污进行分户收集、集中处理利用。”

（七）将第二十八条改为第二十七条，第二款修改为：“住房城乡建设主管部门应当按照城镇污水处理设施建设相关规划，组织建设城镇污水集中处理设施及配套管网、污泥无害化处理处置设施，并加强监督管理。”

（八）将第三十三条改为第三十二条，修改为：“畜禽散养密集区内的畜禽养殖专业户、散养户等规模以下畜禽养殖户在集中处理设施外倾倒、排放畜禽粪污，污染水体的，由乡镇人民政府、街道办事处责令改正，处一千元以上三千元以下的罚款。畜禽散养密集区外的畜禽养殖专业户、散养户等规模以下养殖户未及时对畜禽粪污等进行收集、贮存、清运，导致渗出、泄漏，污染水体的，由乡镇人民政府、街道办事处责令改正，处五百元以上二千元以下的罚款。属于初次违法且危害后果轻微并及时改正的，可以不予处罚。”

（九）将第三十四条改为第三十三条，将“对个人处一百元以上五百元以下罚款”修改为“对个人处一百元以上一千元以下罚款”。

（十）删去第十二条。

三、对《七台河市文明祭祀条例》作出修改

（一）将第一条修改为：“为了促进精神文明和生态文明建设，鼓励和倡导文明、绿色祭祀，防止环境污染，树立文明祭祀新风，根据《中华人民共和国生态环境法典》、《殡葬管理条例》等有关法律、法规，结合本市实际，制定本条例。”

（二）将第八条、第十条、第十二条、第十六条中的“封建迷信”修改为“违反法律法规或者违背公序良俗”。

（三）将第十条修改为：“本市行政区域内禁止制造、销售违反法律法规或者违背公序良俗的祭祀用品。”

（四）将第十二条修改为：“违反本条例制造、销售违反法律法规或者违背公序良俗祭祀用品的，依据有关法律法规规定进行处罚。”

（五）将第十三条修改为：“在禁止区域内焚烧祭祀用品的，由城市管理主管部门责令改正，可以处五百元以上二千元以下罚款。”

（六）将第十四条修改为：“在禁止区域内抛撒祭祀用品的，由城市管理主管部门责令改正，处一百元以上一千元以下罚款。”

四、对《七台河市医疗废物管理若干规定》作出修改

（一）将第一条修改为：“为了加强对医疗废物的管理，防止危害公众健康、污染环境，根据《中华人民共和国生态环境法典》、《中华人民共和国传染病防治法》、《医疗废物管理条例》等有关法律、法规，结合本市实际，制定本规定。”

（二）将第四条第一款修改为：“医疗废物按照国家危险废物名录管理。县级以上地方人民政府应当加强医疗废物集中处置能力建设。”

（三）将第五条修改为：“禁止任何单位和个人转让、买卖医疗废物；禁止以丢弃、抛撒、遗撒、倾倒、掩埋、焚烧以及其他方式擅自处置医疗废物；禁止在非贮存地点倾倒、堆放医疗废物或者将医疗废物混入其他废物和生活垃圾；禁止将医疗废物交给未取得经营许可证的单位或者个人收集、运输、贮存、利用、处置。”

（四）将第十一条中“县级以上人民政府”删除。

（五）增加一条，作为第十四条：“法律、法规对医疗废物管理已有规定的，从其规定。”

（六）删去第十三条、第十五条。

五、对《七台河市建筑垃圾管理条例》作出修改

（一）将第十七条修改为：“任何单位和个人不得随意倾倒、堆放、丢弃、抛撒、遗撒、焚烧建筑垃圾。禁止将建筑垃圾混入生活垃圾，禁止向林地、耕地、荒地、河道等区域倾倒、堆放、丢弃、抛撒、遗撒建筑垃圾。”

（二）删去第二十九条。

本决定自公布之日起施行。

《七台河市煤矸石污染环境防治和综合利用条例》、《七台河市倭肯河流域水环境保护条例》、《七台河市文明祭祀条例》、《七台河市医疗废物管理若干规定》、《七台河市建筑垃圾管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
