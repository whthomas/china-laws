# 海南省人民代表大会常务委员会关于修改《海南省船舶污染防治条例》的决定

海南省人民代表大会常务委员会
关于修改《海南省船舶污染防治条例》的决定

（2026年7月29日海南省第七届人民代表大会常务委员会第二十五次会议通过）

海南省第七届人民代表大会常务委员会第二十五次会议决定，对《海南省船舶污染防治条例》作如下修改：

一、将第九条中的“水域”修改为“海域”。

二、将第三章章名修改为“船舶海洋和水污染防治”。

三、将第二十一条第一款修改为：“船舶运输、装卸固体废物，应当采取相应的污染防治措施，不得违法向海洋和水体倾倒、弃置、处理固体废物。取得废弃物倾倒许可的作业船舶，应当依法开展倾倒作业。”

四、将第三十二条第四款中的“环境保护主管部门”修改为“生态环境主管部门”。

五、将第四十四条修改为：“违反本条例，船舶向依法划定的海洋自然保护区、海滨风景名胜区、重要渔业海域以及其他需要特别保护的海域排放压载水和沉积物的，由海事管理机构责令改正，处二万元以上十万元以下的罚款。”

六、将第四十六条第二款修改为：“有前款行为、造成违法向海洋和水体排放污染物的，依照相关法律、法规规定进行处罚。”

本决定自2026年8月15日起施行。

《海南省船舶污染防治条例》根据本决定作相应修改，重新公布。
