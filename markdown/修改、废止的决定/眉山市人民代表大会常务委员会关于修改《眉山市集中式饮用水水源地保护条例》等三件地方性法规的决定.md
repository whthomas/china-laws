# 眉山市人民代表大会常务委员会关于修改《眉山市集中式饮用水水源地保护条例》等三件地方性法规的决定

眉山市人民代表大会常务委员会
关于修改《眉山市集中式饮用水水源地保护
条例》等三件地方性法规的决定

（2026年6月30日眉山市第五届人民代表大会常务委员会第四十一次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

眉山市第五届人民代表大会常务委员会第四十一次会议决定：

一、对《眉山市集中式饮用水水源地保护条例》作出修改

（一）将第一条修改为：“为了加强集中式饮用水水源地保护，保障饮用水安全，维护公众健康，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《四川省饮用水水源保护管理条例》等法律、法规，结合眉山市实际，制定本条例。”

（二）将第十一条第一款中的“在保护区外”修改为“在保护区外围”，删去第十一条第二款、第三款。

（三）删去第十二条第二款、第十三条至第十五条、第十七条。

（四）将第二十条改为第十六条，修改为：“市人民政府应当依法加强备用水源或者应急水源建设，有条件的地区可以开展区域联网供水。”

（五）将第二十三条改为第十九条，修改为：“地表水型集中式饮用水水源准保护区内，除遵守法律、法规的规定外，还应当遵守下列规定：

“（一）禁止使用炸药、毒药、电具等捕杀各种水生动物；

“（二）禁止使用动植物、畜禽粪便等窝料诱饵进行垂钓活动；

“（三）装载剧毒化学品或者危险废物的船舶、车辆禁止驶入；装载其他危险品的船舶、车辆确需驶入的，应当配备防止污染物散落、溢流、渗漏的设施设备，落实专人保障危险品运输安全，并在驶入前二十四小时内向当地公安机关交通管理部门报告。

“禁止在集中式饮用水水源准保护区内新建、扩建对水体污染严重的建设项目；改建建设项目，不得增加排污量。”

（六）删去第二十四条第二款、第二十六条第一款第二项。

（七）将第五十一条改为第四十七条，修改为：“违反本条例第十九条规定，在集中式饮用水水源准保护区内有下列行为之一的，按照规定给予处罚：

“（一）违反第一款第一项规定，使用炸药、毒药、电具等捕杀各种水生动物的，由市、区县人民政府农业和畜牧主管部门没收渔获物和违法所得，情节严重的，处一千元以上五万元以下的罚款；

“（二）违反第一款第二项规定，使用窝料诱饵进行垂钓活动的，由市、区县人民政府环境保护主管部门责令停止违法行为，可以处二百元以上五百元以下罚款。”

（八）删去第五十四条。

二、对《眉山市农村人居环境治理条例》作出修改

（一）将第二十九条修改为：“市、区县人民政府应当因地制宜推进城乡统筹区域集中供水，减少分散供水，改善农村饮用水条件。

“市、区县人民政府及其有关部门应当建立完善农村饮用水水源地巡查监测和应急处置机制。

“饮用水供水单位应当做好取水口和出水口的水质检测工作，对供水水质负责。”

（二）将第三十一条第三项修改为：“（三）随意丢弃泡沫塑料餐饮具、塑料袋等生活垃圾”。

（三）将第三十四条第二款修改为：“市人民政府环境卫生主管部门应当结合生活垃圾的种类特点，按照前款规定公布农村生活垃圾分类目录和指南。”

（四）将第五十二条第三款修改为：“乡镇人民政府、街道办事处应当指导村（居）民有序回收、堆放、利用秸秆，并配合市、区县人民政府生态环境主管部门依法查处在禁止区域和时段露天焚烧秸秆的行为。”

（五）删去第五十三条第三项。

（六）将第六十七条修改为：“违反本条例第三十一条第三项规定，个人随意丢弃泡沫塑料餐饮具、塑料袋等个人产生的生活垃圾的，由市、区县人民政府环境卫生主管部门责令改正，处一百元以上二百元以下罚款。”

（七）将第六十八条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（八）删去第六十九条。

三、对《眉山市大气污染防治条例》作出修改

（一）将第一条修改为：“为了保护和改善环境，防治大气污染，保障公众健康和生态环境权益，推动绿色低碳发展，建设生态文明，促进经济社会高质量发展，根据《中华人民共和国生态环境法典》等有关法律法规，结合眉山市实际，制定本条例。”

（二）将第二十三条修改为：“市人民政府应当按照国家、省有关规定，依法划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”

（三）将第三十三条第一款修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府依法划定的其他区域和规定的时段露天焚烧秸秆、落叶、杂草等产生烟尘污染的物质。”

本决定自2026年8月15日起施行。

《眉山市集中式饮用水水源地保护条例》、《眉山市农村人居环境治理条例》、《眉山市大气污染防治条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
