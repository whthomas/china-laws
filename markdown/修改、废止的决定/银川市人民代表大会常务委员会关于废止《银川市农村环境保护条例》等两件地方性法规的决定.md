# 银川市人民代表大会常务委员会关于废止《银川市农村环境保护条例》等两件地方性法规的决定

银川市人民代表大会常务委员会
关于废止《银川市农村环境保护条例》等
两件地方性法规的决定

（2025年10月21日银川市第十六届人民代表大会常务委员会第三十二次会议通过　2025年11月21日宁夏回族自治区第十三届人民代表大会常务委员会第二十一次会议批准）

银川市第十六届人民代表大会常务委员会第三十二次会议决定，废止《银川市农村环境保护条例》、《银川市拥军优属条例》。

本决定自公布之日起施行。
