# 遂宁市人民代表大会常务委员会关于修改《遂宁市集中式饮用水水源保护条例》等五件地方性法规的决定

遂宁市人民代表大会常务委员会关于
修改《遂宁市集中式饮用水水源保护条例》等
五件地方性法规的决定

（2026年6月30日遂宁市第八届人民代表大会常务委员会第四十八次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

遂宁市第八届人民代表大会常务委员会第四十八次会议决定：

一、对《遂宁市集中式饮用水水源保护条例》作出修改

将第一条修改为：“为了加强集中式饮用水水源保护，保障集中式饮用水水源安全，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《四川省饮用水水源保护管理条例》等法律法规，结合遂宁市实际，制定本条例。”

二、对《遂宁市城市生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了加强城市生活垃圾分类管理，提高城市生活垃圾减量化、资源化、无害化水平，根据《中华人民共和国生态环境法典》、《四川省固体废物污染环境防治条例》、《四川省城乡环境综合治理条例》等法律法规，结合遂宁市实际，制定本条例。”

（二）将第四条第二款修改为：“市人民政府市容环境卫生部门应当发布生活垃圾的具体分类目录。”

三、对《遂宁市观音湖保护条例》作出修改

将第一条修改为：“为了加强观音湖保护，防治环境污染和生态破坏，促进绿色、可持续发展，根据《中华人民共和国生态环境法典》等法律法规，结合遂宁市实际，制定本条例。”

四、对《遂宁市海绵城市建设管理条例》作出修改

将第三十条修改为：“违反本条例第二十七条第二项规定，由公安、生态环境等部门，依据《中华人民共和国治安管理处罚法》、《中华人民共和国生态环境法典》等法律予以处罚。”

五、对《遂宁市城市管理条例》作出修改

（一）将第四十条修改为：“市、县（区）人民政府可以根据需要，确定禁止燃放烟花爆竹的区域和时段，并向社会公布。

“任何单位和个人不得在当地人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。

“禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。

“禁止在人口集中地区和其他依法需要特殊保护的区域内焚烧沥青、油毡、橡胶、塑料、皮革、垃圾以及其他产生有毒有害烟尘和恶臭气体的物质。

“排放油烟的餐饮服务经营者应当安装油烟净化设施并保持正常使用，或者采取其他油烟净化措施，使油烟达标排放，并防止对附近居民的正常生活环境造成污染。”

（二）将第四十一条第一款第四项修改为：“（四）晚上十点至次日早晨六点在学校、医院和居住区等噪声敏感区域内进行产生环境噪声污染的施工作业，但是抢修、抢险等工程及特殊需要必须连续作业的除外；”。

本决定自2026年8月15日起施行。

《遂宁市集中式饮用水水源保护条例》、《遂宁市城市生活垃圾分类管理条例》、《遂宁市观音湖保护条例》、《遂宁市海绵城市建设管理条例》、《遂宁市城市管理条例》根据本决定作相应修改，重新公布。
