# 商洛市人民代表大会常务委员会关于修改《商洛市农村居民饮水安全管理条例》等三部地方性法规的决定

商洛市人民代表大会常务委员会
关于修改《商洛市农村居民饮水安全管理条例》
等三部地方性法规的决定

（2026年6月24日商洛市第五届人民代表大会常务委员会第三十次会议通过　2026年7月29日陕西省第十四届人民代表大会常务委员会第二十四次会议批准）

商洛市第五届人民代表大会常务委员会第三十次会议决定：

一、对《商洛市农村居民饮水安全管理条例》作出修改

（一）将第一条修改为：“为了保障农村居民饮水安全，加强农村居民饮水安全管理，维护供水用水双方的合法权益，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》等法律法规，结合本市实际，制定本条例。”

（二）将第九条第二款修改为：“农村居民饮水水源地实行保护区制度，分为一级保护区和二级保护区；必要时，可以在饮水水源保护区外围划定一定的区域作为准保护区。

新增一款作为第三款：“市、县（区）人民政府应当根据保护饮水水源的需要，在准保护区内采取工程措施或者建造湿地、水源涵养林等生态保护措施，防止水污染物直接排入饮水水体，确保饮水安全。”

（三）将第十条第二款修改为：“市、县（区）人民政府应当组织编制饮水水源地保护总体规划和重点饮水水源地保护详细规划。规划建设和保护备用饮水水源地或者应急水源，保障应急状态下的饮水供应。有条件的地区可以采取城镇供水管网延伸或者建设跨村、跨镇联片集中供水工程等方式，发展规模集中供水。”

（四）第十二条第一款中新增一项，作为第二项：“改建建设项目，增加排污量”。第二款修改为：“禁止运输危险化学品的车辆通过饮水地表水水源保护区；确需通过的，依照国家和省有关规定执行。”

（五）将第十三条第二款改为：“保护区内排放的污水必须达到规定标准，固体废弃物必须及时运出保护区处理；已建成的排放污染物的建设项目，应当拆除或者关闭；从事网箱养殖、旅游等活动的，应当按照规定采取有效措施，防止污染饮水水体。”

（六）新增一条作为十六条：“市、县（区）人民政府应当组织生态环境等有关部门，对饮水水源保护区、地下水型饮水源的补给区以及供水单位周边区域的生态环境状况和污染风险进行调查评估，筛查可能存在的污染风险因素，并采取相应的风险防范措施。

饮水水源受到污染可能威胁供水安全的，生态环境部门应当责令有关企业事业单位和其他生产经营者采取停止排放水污染物等措施，并通报饮水供水单位和供水、卫生健康、水行政等有关部门；跨行政区域的，还应当通报有关地方人民政府。”

（七）将三十七条改为三十八条，修改为：“在饮水水源保护区内设置排污口的，由县级以上地方人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由生态环境部门处十万元以上五十万元以下的罚款；情节严重的，处五十万元以上一百万元以下的罚款，责令限制生产、停产整治。

违反本条例第十二条第一款第一项，第十三条第一款第一项，第十四条第一款第一项、第三项、第四项、第七项规定，依照《中华人民共和国生态环境法典》的有关规定处罚。”

（八）将四十条改为四十一条，修改为：“供水单位违反本条例规定，供水水质不符合国家规定标准的，由供水主管部门责令改正，处二万元以上二十万元以下的罚款；情节严重的，报经有批准权的人民政府批准，可以责令停业整顿。

供水单位违反本条例规定，有下列行为之一的，由县（区）以上供水主管部门责令限期改正，可处五千元以上五万元以下罚款；造成损失的，赔偿损失：

（一）在正常供水情况下，供水水压达不到国家规定标准的；

（二）擅自停止供水或者未履行停水通知义务的；

（三）供水设施发生故障，未及时组织抢修的。”

（九）将第七条、第十五条、第十六条、第二十六条、第三十四条、第三十五条中的“环保部门”修改为“生态环境部门”，“卫计部门”修改为“卫生健康部门”，“国土部门”修改为“自然资源部门”、“水务部门”修改为“水行政主管部门”；将第二十二条、第二十三条、第四十条、第四十一条、第四十二条中的“供水行政主管部门”修改为“供水主管部门”。

二、对《商洛市烟花爆竹燃放管理条例》作出修改

（一）将第一条修改为：“为了加强烟花爆竹燃放管理，保护和改善生态环境，防治大气污染，保障公共安全和人身、财产安全，根据《中华人民共和国生态环境法典》、国务院《烟花爆竹安全管理条例》等有关法律法规，结合本市实际，制定本条例。”

（二）删除第五条第五款中的“生态环境”，新增一款，作为第三款：“生态环境部门应当加强对烟花爆竹燃放影响大气环境质量监测和分析，在重污染天气预警期间及时向公安机关通报空气质量预报预警信息。”

（三）将第九条第（二）项修改为：“重污染天气预警期间；”。

三、对《商洛市城市排水管理条例》作出修改

（一）将第一条修改为：“为了加强城市排水管理工作，保障城市排水设施安全运行，防治城市内涝，保护和改善生态环境，促进绿色低碳发展，根据《中华人民共和国生态环境法典》、国务院《城镇排水与污水处理条例》等法律法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“城市排水管理工作应当遵循生态优先、系统治理、因地制宜、统筹规划、建管并重、保障安全、综合利用、绿色发展的原则。”

（三）新增一条，作为第四条：“城市排水管理应当贯彻绿色低碳发展理念，在排水设施规划建设、运营维护过程中，推广节能降碳技术，减少能源消耗和温室气体排放。”

（四）将第四条改为第五条，将第二款修改为“市城市管理部门是全市城市排水管理工作的主管部门，负责城市排水与污水处理设施规划建设、运营维护、内涝防控等监督管理工作。会同商州区、商洛高新区做好中心城区排水管理工作。”

新增一款，作为第三款：“生态环境部门对水污染防治工作实施统一监督管理，依法对城市污水集中处理设施的出水水质和水量进行监督检查。”

本决定自2026年8月15日起施行。

《商洛市农村居民饮水安全管理条例》、《商洛市烟花爆竹燃放管理条例》、《商洛市城市排水管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
