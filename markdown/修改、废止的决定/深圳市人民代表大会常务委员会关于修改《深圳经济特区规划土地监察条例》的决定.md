# 深圳市人民代表大会常务委员会关于修改《深圳经济特区规划土地监察条例》的决定

深圳市人民代表大会常务委员会关于修改
《深圳经济特区规划土地监察条例》的决定

（2026年9月1日深圳市第七届人民代表大会常务委员会第五十次会议通过）

深圳市第七届人民代表大会常务委员会第五十次会议决定对《深圳经济特区规划土地监察条例》作如下修改：

一、将第四条修改为：“市人民政府应当建立健全规划土地监察统筹协调工作机制，督促规划土地监察机构和相关部门依法履行职责。

“区人民政府（含新区管理机构，下同）负责组织、协调本行政区域内的规划土地监察工作。”

二、将第五条修改为：“市规划和自然资源部门是市规划土地监察机构，负责协调、指导、监督全市规划土地监察工作。

“区人民政府承担规划土地监察职责的部门是区规划土地监察机构，按照职责开展本辖区内的规划土地监察工作。

“住房建设、交通运输、水务、卫生健康、市场监管、城管和综合执法、消防救援、人口和房屋综合管理等部门和机构，应当在各自职责范围内协助开展规划土地监察工作。”

三、增加一条，作为第六条：“街道办事处按照街道履行职责事项清单要求，负责本辖区内规划违法行为和土地违法行为的投诉举报处理、日常巡查等工作，及时制止相关违法行为并向区规划土地监察机构报告。

“街道办事处按照国家和省有关规定承接区规划土地监察机构的行政处罚权、行政检查权和行政强制措施权的，适用本条例关于区规划土地监察机构的有关规定。”

四、将第十一条修改为第十二条，第四项修改为：“（四）组织开展本辖区内的执法行动”。

增加一款，作为第二款：“区规划土地监察机构可以依法委托具有管理公共事务职能的组织实施涉及规划违法行为和土地违法行为的行政处罚。”

五、将第十三条第一款修改为：“规划违法行为和土地违法行为的查处实行属地管辖。”

第三款修改为：“区规划土地监察机构、街道办事处对规划违法行为和土地违法行为案件发生管辖争议的，争议各方应当协商解决。协商不成的，属于同一行政区域的，由区人民政府指定管辖；属于不同行政区域的，由市规划土地监察机构指定管辖。”

六、将第十四条修改为：“建设工程违反城市规划和土地管理法律、法规、规章，同时违反其他法律、法规、规章的，规划土地监察机构和其他有关部门应当在各自职权范围内依法查处。”

七、将第二十一条第二款修改为：“监察人员的回避，由本级规划土地监察机构决定。区规划土地监察机构负责人的回避，由区人民政府决定；市规划土地监察机构负责人的回避，由市人民政府决定。”

八、第三十三条增加一款，作为第四款：“受送达人同意并签订确认书的，规划土地监察机构可以采用传真、电子邮件等方式送达有关法律文书。”

九、将第三十六条修改为：“因行政处罚需要对建筑物、构筑物、设施进行价值评估的，由规划土地监察机构依法确定的评估机构实施。评估费用由规划土地监察机构承担。”

十、将第五十四条修改为：“当事人因规划违法行为或者土地违法行为受到行政处罚的，规划土地监察机构应当按照相关规定将违法行为信息纳入公共信用信息系统。”

十一、对部分条文作以下修改：

（一）删去第二条中“规划土地监察机构”的表述。

（二）将第八条修改为第九条，第二款中的“街道办事处规划土地监察机构”修改为“街道办事处”。

（三）将第十条修改为第十一条，删去第四项中“区、街道规划土地监察机构”的表述以及第五项中“考核”的表述。

（四）删去第十二条。

（五）将第十八条中的“全市统一的规划土地监察平台”修改为“统一的信息化平台”。

（六）将第二十二条、第二十五条第三款中的“鉴定结论”修改为“鉴定意见”。

（七）将第三十三条第三款中的“被送达人”修改为“受送达人”。

（八）删去第四十八条第一款中“公安、”的表述。

（九）删去第五十五条第二款。

（十）删去第五十六条中“和共同责任考核制，将规划违法和土地违法行为的查处工作作为绩效考核的重要内容”的表述。

（十一）将第六十条中的“其所在单位、上级行政机关或者监察机关”修改为“其所在单位、有关机关”。

（十二）将第六十一条中的“其所在部门或者单位、上级行政机关或者监察机关”修改为“其所在部门或者单位、有关机关”。

本决定自公布之日起施行。

《深圳经济特区规划土地监察条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
