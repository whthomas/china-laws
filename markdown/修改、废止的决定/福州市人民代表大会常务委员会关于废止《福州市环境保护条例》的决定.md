# 福州市人民代表大会常务委员会关于废止《福州市环境保护条例》的决定

福州市人民代表大会常务委员会
关于废止《福州市环境保护条例》的决定

（2026年8月25日福州市第十六届人民代表大会常务委员会第三十三次会议通过　2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

福州市第十六届人民代表大会常务委员会第三十三次会议决定：

废止《福州市环境保护条例》（1996年11月28日福州市第十届人民代表大会常务委员会第二十五次会议通过　1997年5月29日福建省第八届人民代表大会常务委员会第三十二次会议批准　2000年12月28日福州市第十一届人民代表大会常务委员会第二十一次会议第一次修正　2010年10月28日福州市第十三届人民代表大会常务委员会第三十一次会议第二次修正　2012年4月27日福州市第十四届人民代表大会常务委员会第三次会议第三次修正）。

本决定自公布之日起施行。
