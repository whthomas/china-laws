# 佳木斯市人民代表大会常务委员会关于集中修改废止涉及生态环境法典部分地方性法规的决定

佳木斯市人民代表大会常务委员会
关于集中修改废止涉及生态环境法典
部分地方性法规的决定

（2026年8月10日佳木斯市第十七届人民代表大会常务委员会第四十三次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

佳木斯市第十七届人民代表大会常务委员会第四十三次会议对下列地方性法规作出决定：

一、对《佳木斯市文明祭祀条例》作出修改

（一）将第一条修改为：“为了树立文明祭祀新风，鼓励和倡导文明、绿色祭祀，促进社会主义精神文明和生态文明建设，根据《中华人民共和国生态环境法典》、《殡葬管理条例》等有关法律法规，结合本市实际，制定本条例。”

（二）将第二条修改为：“本市行政区域内制造、销售、使用祭祀用品等活动适用本条例。”

（三）将第四条修改为：“市、县（市、区）人民政府应当做好文明祭祀管理工作；应当建立议事协调机制，统筹协调文明祭祀管理中的重大事项。

“乡（镇）人民政府、街道办事处及居（村）民委员会应当协助做好文明祭祀管理工作。

“鼓励物业服务企业协助做好文明祭祀管理工作。”

（四）将第五条修改为：“市、县（市、区）人民政府民政部门是文明祭祀管理的主管部门，负责辖区文明祭祀的管理工作，监督指导殡葬服务机构为文明祭祀活动提供服务。

“市场监督管理、城市管理综合执法、公安、消防救援、林业和草原、生态环境等部门应当按照各自职责做好文明祭祀的相关工作。”

（五）将第九条修改为：“本市行政区域内禁止制造、销售违反法律法规或者违背公序良俗的祭祀用品。”

（六）将第十一条修改为：“任何组织和个人有权对违反本条例制造、销售违反法律法规或者违背公序良俗的祭祀用品和在禁止区域内焚烧、抛撒祭祀用品等向民政及有关部门进行投诉和举报。民政及有关部门在接到投诉和举报后，应当及时进行处理，并将处理结果告知投诉人或者举报人。”

（七）将第十二条修改为：“制造、销售违反法律法规或者违背公序良俗的祭祀用品的，由民政部门会同市场监管部门依据相关法律法规处理。

“祭祀用品仿制或者使用人民币图样的，依照人民币管理有关法律、行政法规给予处罚。”

（八）将第十三条修改为：“在禁止区域内焚烧祭祀用品的，由城市管理综合执法部门责令改正，可以处五百元以上二千元以下罚款。

“在禁止区域内抛撒祭祀用品的，由城市管理综合执法部门责令改正，处一百元以上一千元以下罚款。”

（九）将第十四条修改为：“在具有火灾、爆炸危险的场所焚烧祭祀用品的，由消防救援机构责令停止违法行为，处以警告或者五百元以下罚款，情节严重的，移交公安机关依法处理。

“森林草原防火期内，擅自在森林防火区和草原野外焚烧祭祀用品的，由林业草原行政管理部门责令停止违法行为，依据相关法律法规处理。”

（十）将第十六条修改为：“公职人员使用违反法律法规或者违背公序良俗的祭祀用品造成不良社会影响的，由其所在单位或者相关部门依法给予相应处分。”

（十一）删去第十七条。

增加一条作为第十七条：“法律法规对祭祀活动有规定的，从其规定。”

（十二）将第十八条修改为：“本条例所称祭祀是指对逝者进行的追悼、安葬、葬后祭奠和悼念等活动。”

二、废止《佳木斯市餐饮业油烟污染防治条例》

本决定自公布之日起施行。

《佳木斯市文明祭祀条例》根据本决定作相应修改，重新公布。
