# 齐齐哈尔市人民代表大会常务委员会关于废止《齐齐哈尔市环境噪声污染防治条例》等三部地方性法规的决定

齐齐哈尔市人民代表大会常务委员会关于废止
《齐齐哈尔市环境噪声污染防治条例》等
三部地方性法规的决定

（2026年6月17日齐齐哈尔市第十七届人民代表大会常务委员会第三十五次会议通过　2026年7月30日黑龙江省第十四届人民代表大会常务委员会第二十九次会议批准）

齐齐哈尔市第十七届人民代表大会常务委员会第三十五次会议决定：

废止《齐齐哈尔市环境噪声污染防治条例》、《齐齐哈尔市机动车排气污染防治条例》、《齐齐哈尔市大气污染防治条例》。

本决定自公布之日起施行。
