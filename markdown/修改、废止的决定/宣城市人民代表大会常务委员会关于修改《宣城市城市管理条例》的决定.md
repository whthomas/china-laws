# 宣城市人民代表大会常务委员会关于修改《宣城市城市管理条例》的决定

宣城市人民代表大会常务委员会关于修改
《宣城市城市管理条例》的决定

（2026年6月30日宣城市第五届人民代表大会常务委员会第三十五次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为了贯彻落实《中华人民共和国生态环境法典》，保证国家法律、行政法规在我市的贯彻实施，维护国家法治统一，宣城市第五届人民代表大会常务委员会第三十五次会议决定对《宣城市城市管理条例》作如下修改：

一、删去第二十三条第一款中的“临时占用结束后，应当委托具有资质的单位在规定期限内恢复原状”，删去第二款中的“除正常养护外”“修剪、移植和”，增加“并按照国家有关规定补植树木或者采取其他补救措施”。

二、删去第二十四条第三项。

三、删去第三十条第一项“文化娱乐”，“游艺”后增加“餐饮”；删去第三项“在商业经营活动中”；第四项增加“但是紧急情况以及地方人民政府规定的特殊情形除外”；第五项“娱乐”后增加“健身”；第七项修改为“对已竣工交付使用的住宅楼、商铺、办公楼等建筑物进行室内装修活动，应当在十二时至十四时、十九时至次日七时以外的时间开展，并采取有效措施，防止、减轻噪声污染”；删去第九项中的“生产经营”。

四、将第三十一条修改为“餐饮油烟污染防治应当符合下列要求：（一）排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用。禁止在居民住宅楼、未配套设立专用烟道的商住综合楼以及商住综合楼内与居住层相邻的商业楼层内新建、改建、扩建产生油烟、异味、废气的餐饮服务项目；（二）排放油烟污染物的餐饮服务业经营者应当采取有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染；（三）任何单位和个人不得在当地人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。”

五、删去第五十三条。

六、删去第五十四条。

七、删去第五十七条第二款“修剪、移植”。

八、将第六十二条修改为“违反本条例第三十条第一项、第三项、第八项、第九项规定的，由城市管理部门责令改正，依法给予处罚。违反本条例第三十条第二项、第四项、第五项、第六项、第七项规定的，由公安机关责令改正，依法给予处罚。”

本决定自2026年8月15日起施行。

《宣城市城市管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
