# 泰州市人民代表大会常务委员会关于修改《泰州市垛田保护条例》等三件地方性法规的决定

泰州市人民代表大会常务委员会
关于修改《泰州市垛田保护条例》等三件
地方性法规的决定

（2026年8月28日泰州市第六届人民代表大会常务委员会第三十二次会议通过　2026年9月30日江苏省第十四届人民代表大会常务委员会第二十五次会议批准）

泰州市第六届人民代表大会常务委员会第三十二次会议决定：

一、对《泰州市垛田保护条例》作出修改

（一）删去第五条第一款中的“市人民政府应当将垛田保护工作纳入地方年度综合考核体系”。

将第二款中的“协调机制”修改为“工作推进机制”。

（二）将第七条第二款修改为：“鼓励依法制定完善村规民约、居民公约、合作社章程等，对垛田保护作出规定，引导村（居）民、合作社成员自觉保护垛田。”

（三）将第八条第三款修改为：“对在垛田保护工作中做出突出贡献的单位和个人，按照国家和省有关规定给予表彰、奖励。”

（四）将第十九条第一款第三项修改为：“倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物，排放未经处理达标的污水以及其他有毒有害物质”。

删去第二款第一项中的“养殖小区”。

（五）将第二十六条修改为：“违反本条例第十一条第二款规定，掩盖或者擅自移动垛田保护界桩或者标识牌的，由农业农村主管部门责令限期改正，处以五百元以上二千元以下罚款；涂改或者损毁垛田保护界桩或者标识牌的，由农业农村主管部门责令限期改正，处以二千元以上五千元以下罚款。”

（六）将第二十七条第一项中的“一倍以上二倍以下”修改为“五倍以上十倍以下”。

删去第三项中的“养殖小区”。

（七）将第二十八条修改为：“垛田保护有关部门及其工作人员在垛田保护工作中滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分。”

此外，还对有关条款作文字、技术修改。

二、对《泰州市农业面源污染防治条例》作出修改

（一）将第一条中的“中华人民共和国环境保护法”修改为“中华人民共和国生态环境法典”。

（二）删去第五条第一款中的“加强对农业面源污染防治工作的考核评价”。

（三）将第九条和第十条合并，作为第九条，修改为：“市、县级市（区）人民政府应当推动农业面源污染防治和农业清洁生产领域标准化建设。

“标准化、生态环境、农业农村等部门应当按照各自职责，做好农业面源污染防治和农业清洁生产领域标准化建设的相关工作。”

（四）将第十一条改为第十条，修改为：“鼓励生态环境保护和农业方面的社会团体依法制定完善农业面源污染防治和农业清洁生产领域的团体标准；鼓励企业依法制定完善农业面源污染防治和农业清洁生产领域的企业标准。

“农业面源污染防治和农业清洁生产领域的团体标准、企业标准应当符合推进农业投入品减量化、生产清洁化、废弃物资源化、生产模式生态化的要求。”

（五）将第十三条改为第十二条，修改为：“市生态环境、农业农村等部门应当及时对农业面源污染防治和农业清洁生产领域的相关标准实施情况进行汇总分析。”

（六）将第三章章名修改为“预防”。

（七）删去第十四条。

（八）将第十五条改为第十三条，第一款修改为：“生态环境主管部门应当会同农业农村主管部门，制定农业面源污染防治实施方案，明确污染防治目标、任务和治理措施等内容。”

（九）将第十九条改为第十七条，修改为：“畜禽养殖禁养区和水产养殖限养区、养殖区的划定和调整，应当根据相关规划和生态环境保护要求，由生态环境主管部门、农业农村主管部门按照各自职责提出方案，报本级人民政府同意后公布实施。

“畜禽养殖禁养区内禁止畜禽养殖场、畜禽养殖户从事畜禽养殖活动。

“水产养殖限养区内严格控制养殖规模、养殖容量。

“畜禽养殖户的认定标准由市人民政府制定并公布。”

（十）将第二十一条改为第十九条，第三款修改为：“水产养殖户应当科学确定养殖品种、规模、密度和养殖方式，采取与养殖规模相匹配的养殖尾水处理措施。排放水产养殖尾水污染物等应当符合污染物排放标准，防止污染水环境。”

（十一）将第二十四条改为第二十二条，第一款修改为：“市、县级市（区）人民政府应当建立完善农作物秸秆综合利用体系，推进农作物秸秆肥料化、饲料化、能源化、工业原料化、食用菌基料化等综合利用。”

（十二）将第二十六条改为第二十四条，第二款修改为：“农用薄膜使用者应当在使用期限到期前，捡拾田间的非全生物降解农用薄膜废弃物，交至回收网点或者回收工作者，不得随意弃置、掩埋或者焚烧。”

（十三）将第二十八条改为第二十六条，修改为：“农药经营者、废旧农用薄膜和农药包装废弃物回收主体应当建立回收台账，如实记录废旧农用薄膜和农药包装废弃物的出售人、出售数量、回收时间、去向等内容。回收台账应当保存两年以上。”

（十四）删去第四十条。

此外，还对有关条款作文字、技术修改，并对条文顺序作相应调整。

三、对《泰州市市区烟花爆竹燃放管理条例》作出修改

（一）将第一条中的“根据《中华人民共和国大气污染防治法》、国务院《烟花爆竹安全管理条例》等有关法律法规”修改为“根据《中华人民共和国生态环境法典》、国务院《烟花爆竹安全管理条例》等法律、法规”。

（二）删去第四条第一款中的“建立烟花爆竹燃放管理工作联席会议制度”，将“协调烟花爆竹燃放管理工作中的重大事项”修改为“协调解决烟花爆竹燃放管理工作中的重大事项”。

（三）将第五条修改为：“市、区公安机关负责烟花爆竹燃放的监督管理工作。

“市、区应急管理、市场监督管理、城市管理、生态环境、交通运输、教育、气象、住房和城乡建设、数据等部门和供销合作社按照各自职责，共同做好烟花爆竹燃放管理相关工作。”

（四）删去第七条第二款。

（五）将第八条第一款第七项中的“饮用水源保护区”修改为“饮用水水源保护区”。

（六）将第十条中的“在禁止燃放烟花爆竹的区域和地点外”修改为“在禁止燃放烟花爆竹的区域、地点和时段外”。

（七）将第十六条中的“安全生产监督管理等部门”修改为“应急管理等部门”。

（八）将第十七条第一款第三项修改为：“违反本条例第十条规定，在禁止燃放烟花爆竹的区域、地点和时段外不按照规定时间燃放的”。

（九）将第四条第三款、第六条第四款、第十三条中的“物业服务企业”修改为“物业服务人”。

此外，还对有关条款作文字、技术修改。

本决定自公布之日起施行。

《泰州市垛田保护条例》、《泰州市农业面源污染防治条例》、《泰州市市区烟花爆竹燃放管理条例》根据本决定作相应修改，重新公布。
