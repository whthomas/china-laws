# 成都市人民代表大会常务委员会关于废止《成都市罚没财产管理规定》的决定

《成都市罚没财产管理规定》的决定

> （2022年7月1日成都市第十七届人民代表大会常务委员会第三十六次会议通过
> 2022年9月30日四川省第十三届人民代表大会常务委员会第三十七次会议批准）

本决定自公布之日起施行。
