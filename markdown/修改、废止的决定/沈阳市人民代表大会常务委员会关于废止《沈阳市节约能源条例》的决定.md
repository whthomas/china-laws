# 沈阳市人民代表大会常务委员会关于废止《沈阳市节约能源条例》的决定

沈阳市人民代表大会常务委员会关于废止
《沈阳市节约能源条例》的决定

（2025年10月27日沈阳市第十七届人民代表大会常务委员会第二十七次会议通过　2025年11月27日辽宁省第十四届人民代表大会常务委员会第十九次会议批准）

沈阳市第十七届人民代表大会常务委员会第二十七次会议审议了《关于废止〈沈阳市节约能源条例〉的议案》，决定自2025年12月15日起废止《沈阳市节约能源条例》。
