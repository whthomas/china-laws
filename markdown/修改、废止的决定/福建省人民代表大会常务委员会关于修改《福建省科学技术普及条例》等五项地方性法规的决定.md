# 福建省人民代表大会常务委员会关于修改《福建省科学技术普及条例》等五项地方性法规的决定

福建省人民代表大会常务委员会关于修改
《福建省科学技术普及条例》等五项
地方性法规的决定

（2026年7月24日福建省第十四届人民代表大会常务委员会第二十三次会议通过）

福建省第十四届人民代表大会常务委员会第二十三次会议决定对《福建省科学技术普及条例》等五项地方性法规作如下修改：

一、福建省科学技术普及条例

（一）增加两条，作为第三条、第四条：

“第三条坚持中国共产党对科普事业的全面领导。开展科普，应当以人民为中心，坚持面向世界科技前沿、面向经济主战场、面向国家重大需求、面向人民生命健康，培育和弘扬创新文化，推动形成崇尚科学、追求创新的风尚，服务高质量发展，为建设科技强国奠定坚实基础。

“第四条科普是国家创新体系的重要组成部分，是实现创新发展的基础性工作。各级地方人民政府应当把科普放在与科技创新同等重要的位置，加强科普工作总体布局、统筹部署，推动科普与科技创新紧密协同，充分发挥科普在一体推进教育科技人才事业发展中的作用。”

（二）将第三条改为第五条，整合第二款和第三款作为第二款，修改为：“科普工作应当践行社会主义核心价值观，弘扬科学精神和科学家精神，遵守科技伦理，反对和抵制伪科学。任何组织和个人不得以科普为名从事损害国家利益、社会公共利益或者他人合法权益的活动。”

（三）将第八条改为第十条，修改为：“县级以上地方人民政府科学技术、教育、工业和信息化、自然资源、生态环境、农业农村、文化和旅游、卫生健康、体育、气象、地震等部门，科学技术协会及其他有关单位、社会团体应当结合本行业特点和实际情况，组织开展相关科普活动。”

（四）将第十条改为第十二条，修改为：“鼓励在干部教育培训中增加科普内容，提高公职人员科学履职能力。”

（五）将第二十一条改为第二十三条，第一款修改为：“县级以上地方人民政府应当支持科普产业发展，鼓励社会力量兴办科普企业，投资兴建科普场所、提供科普展品和教具、维护场所运行，促进科普与文化、旅游、体育、卫生健康、农业、生态环保等产业融合发展。”

（六）删去第二十六条。

（七）对部分条文表述作以下修改：

1.将第二十四条中的“少数民族地区”修改为“民族地区”、“边远贫困地区”修改为“经济欠发达地区”。

2.将第二十五条中的“城乡建设规划、土地利用总体规划”修改为“国土空间规划”。

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

二、福建省实施《中华人民共和国会计法》办法

（一）增加一款，作为第二条第一款：“会计工作应当贯彻落实党和国家路线方针政策、决策部署，维护社会公共利益，为国民经济和社会发展服务。”

（二）将第五条修改为：“对在会计工作中作出突出贡献的单位和个人，按照有关规定给予表彰、奖励。”

（三）将第十条修改为：“地方各级人民政府应当支持各单位加强会计信息化、智能化建设。

“运用会计信息化手段进行会计核算的，其软件及其生成的会计凭证、会计账簿、财务会计报告和其他会计资料，必须符合国家统一的会计制度和会计信息化工作规范。单位应当促进会计信息系统与业务信息系统的一体化，提高业务数据与会计数据的一致性。”

（四）将第十四条修改为：“各单位应当根据法律、法规和国家统一的会计制度建立和实施适合本单位业务特点和管理要求的内部会计监督制度，并将其纳入本单位内部控制制度。”

（五）将第十八条第一款修改为：“财政、审计、税务、金融管理等部门应当依照有关法律、法规规定的职责，对有关单位的会计资料实施监督检查，并出具检查结论。财政、审计、税务、金融管理等部门应当加强监督检查协作，有关监督检查部门已经作出的检查结论能够满足其他监督检查部门履行职责需要的，其他监督检查部门应当加以利用，避免重复检查。”

（六）将第二十一条修改为：“各单位应当根据会计业务的需要，依法采取下列一种方式组织本单位的会计工作：

“（一）设置会计机构；

“（二）在有关机构中设置会计岗位并指定会计主管人员；

“（三）委托经批准设立从事会计代理记账业务的中介机构代理记账；

“（四）国务院财政部门规定的其他方式。”

（七）将第二十四条修改为：“从事会计工作的人员应当具备从事会计工作所需要的专业能力，遵守职业道德，提高业务素质，严格遵守国家有关保密规定。

“依法对有关单位的会计资料实施监督检查的部门及其工作人员对在监督检查中知悉的国家秘密、工作秘密、商业秘密、个人隐私、个人信息负有保密义务。”

（八）删去第三十条、第三十一条、第三十二条、第三十三条、第三十五条。

（九）将第三十六条改为第三十一条，修改为：“违反本办法规定的行为，法律、行政法规已有法律责任规定的，从其规定。”

（十）对部分条文表述作以下修改：

1.将第十一条中的“使用电子计算机”、第十七条中的“采用电子计算机”修改为“运用会计信息化手段”。

2.将第十一条第一款中的“电算化”修改为“信息化”。

3.将第十一条第二款、第二十二条、第二十八条中的“国有资产”修改为“国有资本”。

4.将第十条第二款、第十一条第二款、第二十二条中的“必须”修改为“应当”。

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

三、福建省矿产资源条例

（一）删去第九条、第十一条第一款、第十八条第四款、第三十一条、第三十二条、第四十二条、第四十五条、第四十六条。

（二）将第一条修改为：“为规范矿产资源的勘查、开发、利用和保护工作，维护矿产资源国家所有者权益和矿业权人合法权益，促进矿业的可持续发展，根据《中华人民共和国矿产资源法》和其他有关法律、法规，结合本省实际，制定本条例。”

（三）将第十六条改为第十五条，修改为：“探矿权人在登记的勘查区域内，享有勘查有关矿产资源并依法取得采矿权的权利。”

（四）将第四章章名修改为“矿权的转让、抵押”。

（五）将第二十七条改为第二十六条，修改为：“矿业权可以依法转让或者出资、抵押等，国家另有规定或者矿业权出让合同另有约定的除外。”

（六）将第三十条改为第二十九条，修改为：“探矿权、采矿权的转让应由转让人与受让人签订转让合同，并报原颁发勘查许可证、采矿许可证的地质矿产主管部门批准。

“探矿权、采矿权转让时，探矿权人、采矿权人的权利、义务随之转移，国家另有规定或者矿业权出让、转让合同另有约定的除外。”

（七）将第三十四条改为第三十一条，第一款修改为：“采矿权抵押应签订抵押合同。抵押双方当事人应当在签订抵押合同之日起三十日内，凭采矿许可证和抵押合同向矿区所在地的县级地质矿产主管部门办理采矿权抵押登记手续。”

（八）将第三十九条改为第三十六条，第一款修改为：“开采矿产资源，必须采取合理的开采顺序、开采方法和选矿工艺。矿山企业的开采回采率、选矿回收率和综合利用率应达到设计要求。”

此外，对个别文字及标点符号进行调整，根据修改对条文顺序作相应调整。

四、福建省实施《中华人民共和国消费者权益保护法》办法

（一）将第十九条修改为：“经营者应当在经营场所的显著位置标明其真实名称和标记，悬挂行政许可证照。”

（二）删去第二十二条、第四十四条。

（三）将第二十三条改为第二十二条，第二款第一项修改为：“（一）自消费者提出履行义务要求之日起十五日内不作答复或者承诺履行义务之日起十五日内仍不履行的”。

第二款第三项修改为：“（三）接到有关机关或者消费者权益保护委员会要求处理消费者投诉通知之日起十五日内不作答复的”。

第二款增加一项，作为第五项：“（五）法律、法规规定的其他情形。”

（四）增加五条，作为第三十八条、第四十七条、第四十八条、第四十九条、第六十二条：

“第三十八条以预收款方式提供商品或者服务的经营者，决定停业或者迁移服务场所的，应当提前三十日以电话、短信、微信、电子邮件等方式通知已交预付款的消费者，并在其经营场所、网站、网店首页、公众号等的醒目位置持续公告经营者的有效联系方式、退款时间、退款方式以及其他补救措施等信息。

“第四十七条对侵害众多消费者合法权益的行为，省消费者权益保护委员会可以依法向人民法院提起公益诉讼。

“省消费者权益保护委员会为前款规定的公益诉讼收集证据确有困难的，可以依法提请有关行政管理部门协助。

“省消费者权益保护委员会提起公益诉讼，可以依法提请人民检察院支持起诉。

“第四十八条鼓励建立消费者权益保护公益诉讼赔偿金管理制度，依法管理和使用公益诉讼赔偿金。

“第四十九条鼓励支持消费者权益保护委员会加强与台湾地区消费者权益保护组织的联系，促进闽台消费维权协作，优化闽台消费者权益保护环境。

“第六十二条经营者违反本条例第三十八条规定的，由有关行政部门责令改正，可以根据情节单处或者并处警告、没收违法所得、处以违法所得一倍以上十倍以下的罚款，没有违法所得的，处以五十万元以下的罚款；情节严重的，责令停业整顿，依照《中华人民共和国消费者权益保护法实施条例》的规定吊销营业执照。”

（五）将第五十一条改为第五十三条，修改为：“消费者权益保护委员会对消费者请求调解的，应当在收到调解申请之日起七个工作日内决定是否受理；不属于受理范围的，应当告知理由；经调解达成协议的，应当制作调解协议书；调解不成的，应当告知当事人其他解决途径。”

（六）将第五十二条改为第五十四条，修改为：“有关行政管理部门应当自收到消费者的投诉或者消费者权益保护委员会转交的投诉之日起七个工作日内，予以处理并告知消费者或者转交投诉的消费者权益保护委员会，对不符合规定的投诉决定不予受理的，应当告知消费者或者转交投诉的消费者权益保护委员会不予受理的理由和其他解决争议的途径；对消费者权益保护委员会查询的事项，应当在十日内作出答复。”

（七）将第六十条改为第六十三条，修改为：“经营者违反本办法规定，侵害消费者权益，其他有关法律、法规对处罚机关和处罚方式有规定的，从其规定。法律、法规未作规定的，由市场监督管理部门或者其他有关行政管理部门责令改正，并根据情节单处或者并处警告、没收违法所得、处以违法所得一倍以上五倍以下的罚款；没有违法所得或者违法所得难以计算的，处以一万元以下的罚款；构成犯罪的，依法追究刑事责任。”

此外，对个别文字及标点符号进行调整，根据修改对条文顺序作相应调整。

五、福建省专利促进与保护条例

（一）将第四条第二款修改为：“县级以上地方人民政府应当加大专利促进与保护的资金投入，多渠道筹集资金，用于专利技术开发推广。”

（二）将第五条第二款中的“工商”修改为“市场监督管理”。

（三）将第九条修改为：“对在专利工作中作出突出贡献的单位和个人，按照有关规定给予表彰、奖励。”

（四）删去第十二条、第二十一条。

（五）将第十八条改为第十七条，修改为：“被授予专利权的单位依照法律、法规的规定对职务发明创造的发明人或者设计人给予奖励；发明创造专利实施后，根据其推广应用的范围和取得的经济效益，对发明人或者设计人给予合理的报酬。鼓励被授予专利权的单位实行产权激励，采取股权、期权、分红等方式，使发明人或者设计人合理分享创新收益。”

（六）将第二十五条改为第二十三条、第二十六条改为第二十四条，其中的“专利代理人”修改为“专利代理师”。

（七）将第三十条改为第二十八条，修改为：“管理专利工作的部门自收到专利侵权纠纷处理请求书之日起五个工作日内，对符合条件的，应当作出立案决定；对不符合条件的，不予立案并书面说明理由。案情特别复杂或者有其他特殊情况的，经管理专利工作的部门负责人批准，立案期限可以延长五个工作日。

“管理专利工作的部门应当自立案之日起五个工作日内，将请求书及其附件的副本送达被请求人。被请求人应当自收到请求书副本后十五日内提交答辩书及其副本。被请求人在中华人民共和国内没有固定住所的，应当自收到之日起三十日内提交答辩书及其副本。被请求人逾期未提交答辩书的，不影响处理程序的进行。

“被请求人提交答辩书的，管理专利工作的部门应当自收到之日起五个工作日内将答辩书副本送达请求人。”

（八）将第三十一条改为第二十九条，第一款修改为：“管理专利工作的部门处理专利侵权纠纷，应当自立案之日起三个月内结案。案件复杂需要延长期限的，应当由管理专利工作的部门负责人批准，延长的期限不超过一个月。案件特别复杂或者有其他特殊情况，延期后仍不能结案，应当由上一级管理专利工作的部门批准，继续延长的期限不超过两个月。”

第二款修改为：“被请求人在答辩期内提出宣告专利权无效请求并被国务院专利行政部门受理的，可以向管理专利工作的部门提出中止处理的书面申请。是否中止处理，由管理专利工作的部门审查后书面通知当事人。”

第三款修改为：“案件处理过程中的公告、中止、检验鉴定、管辖异议和当事人申请的延长举证期限与和解期间不计算在专利侵权纠纷处理期限内。”

（九）将第三十二条改为第三十条，修改为：“管理专利工作的部门根据已经取得的证据，对涉嫌假冒专利行为进行查处时，有权采取下列措施：

“（一）询问有关当事人，调查与涉嫌违法行为有关的情况；

“（二）对当事人涉嫌违法行为的场所实施现场检查；

“（三）查阅、复制与涉嫌违法行为有关的合同、发票、账簿以及其他有关资料；

“（四）检查与涉嫌违法行为有关的产品；

“（五）对有证据证明是假冒专利的产品，可以依法查封或者扣押。

“管理专利工作的部门应专利权人或者利害关系人的请求处理专利侵权纠纷时，可以采取前款第一项、第二项、第四项所列措施。

“管理专利工作的部门依法行使前两款规定的职权时，有关单位和个人应当予以协助、配合，不得拒绝、阻挠。”

（十）将第三十三条改为第三十一条，修改为：“管理专利工作的部门认定专利侵权成立，责令侵权人立即停止侵权行为的，应当采取下列措施制止侵权行为：

“（一）对未经专利权人许可制造其专利产品的，责令立即停止制造并销毁用于制造侵权产品的专用设备、模具；并不得销售、许诺销售、使用尚未出售的侵权产品或者以任何形式将该产品投放市场；侵权产品难以保存的，责令侵权人销毁该产品；

“（二）对未经专利权人许可使用其专利方法的，责令立即停止使用该专利方法，销毁实施专利方法的专用设备、模具，并不得销售、许诺销售、使用尚未出售的侵权产品或者以任何形式将该产品投放市场；依照专利方法所直接获得的侵权产品难以保存的，责令侵权人销毁该产品；

“（三）对未经专利权人许可销售其专利产品或者依照其专利方法直接获得的产品的，责令立即停止销售，并不得许诺销售、使用尚未出售的侵权产品或者以任何形式将该产品投放市场；尚未出售的侵权产品难以保存的，责令侵权人销毁该产品；

“（四）对未经专利权人许可许诺销售其专利产品或者依照其专利方法直接获得的产品的，责令立即停止许诺销售行为，消除影响，并且不得进行任何实际销售行为；

“（五）对以生产经营为目的使用专利侵权产品的，责令立即停止使用行为；但为生产经营目的使用不知道是未经专利权人许可而制造并售出的专利侵权产品，且举证证明该产品合法来源的，对于权利人请求停止上述使用的主张，管理专利工作的部门应予支持，但被诉侵权产品的使用者举证证明其已支付该产品的合理对价的除外；

“（六）对未经专利权人许可进口其专利产品或者依照其专利方法直接获得的产品的，责令立即停止进口；侵权产品已经入境的，不得销售、使用该产品，并不得以任何形式将该产品投放市场；侵权产品难以保存的，责令侵权人销毁该产品；侵权产品尚未入境的，可以将行政裁决通知海关部门；

“（七）责令侵权的参展方采取从展会上撤出侵权展品、销毁或者封存相应的宣传材料、更换或者遮盖相应的展板等撤展措施；

“（八）停止侵权行为的其他必要措施。”

（十一）将第四十三条改为第四十一条，修改为：“违反本条例第三十条规定，有关单位或者个人拒不提供或者隐瞒、转移、销毁与案件有关的合同、发票、账簿以及其他有关资料或者转移、销毁被查封扣押的物品，由管理专利工作的部门对有关单位或者个人处以五千元以上五万元以下的罚款。”

此外，对个别文字进行调整，根据修改对条文顺序作相应调整。

本决定自公布之日起施行。
