# 淮安市人民代表大会常务委员会关于修改《淮安市文明行为促进条例》等七件地方性法规的决定

淮安市人民代表大会常务委员会关于修改
《淮安市文明行为促进条例》等七件
地方性法规的决定

（2026年6月30日淮安市第九届人民代表大会常务委员会第三十四次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

淮安市第九届人民代表大会常务委员会第三十四次会议决定：

一、对《淮安市文明行为促进条例》作出修改

将第十六条第四项修改为：“不得违法露天焚烧秸秆、落叶”。

增加一项，作为第五项：“不得在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质”。

二、对《淮安市永久性绿地保护条例》作出修改

（一）将第五条中的“给予奖励”修改为“按照国家和省有关规定给予表彰、奖励”。

（二）将第二十四条中的“生态环境主管部门”修改为“生态环境主管部门、城镇排水主管部门、城市管理主管部门按照职责分工”。

三、对《淮安市大运河文化遗产保护条例》作出修改

（一）将第七条第一款中的“给予表彰、奖励”修改为“按照国家和省有关规定给予表彰、奖励”。

（二）将第二十三条第五项修改为：“向大运河河道擅自排放污染物或者未按排污许可的要求排放污染物”。

将第六项修改为：“在大运河航道从事圈圩、围网、网箱养殖”。

四、对《淮安市市容管理条例》作出修改

（一）将第六条中的“作出突出贡献”修改为“做出突出贡献”，“给予奖励”修改为“按照国家和省有关规定给予表彰、奖励”。

（二）删去第二十一条第一款第一项中的“倾倒垃圾”。

（三）将第三十一条第二款修改为：“违反前款规定，由城市管理行政执法部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下罚款；拒不改正的，处五千元以上二万元以下罚款。”

（四）将第三十五条修改为：“推行生活垃圾分类制度。

“产生生活垃圾的单位、家庭和个人应当依法履行生活垃圾源头减量和分类投放义务，承担生活垃圾产生者责任。任何单位和个人都应当依法在指定的地点分类投放生活垃圾。

“已经分类投放的生活垃圾，应当按照规定分类收集、分类运输、分类处理。”

（五）将第三十七条第一款中的“处置建筑垃圾的单位”修改为“施工单位、建设单位、运输建筑垃圾的单位”。

删去第二款中的“并按照城市管理部门的规定处置，防止污染环境”。

将第四款修改为：“违反前三款规定的，由城市管理行政执法部门依照相关法律、法规的规定进行处罚。”

（六）将第三十九条第二款修改为：“违反前款第一项、第二项规定的，由城市管理行政执法部门依照相关法律、法规的规定进行处罚。违反前款第三项、第四项规定的，由城市管理行政执法部门责令改正，可以处五百元以上三千元以下罚款。违反前款第五项规定的，由城市管理行政执法部门责令运输单位采取补救措施，处二百元以上一千元以下罚款。”

此外，对有关条款作文字、技术修改。

五、对《淮安市建筑垃圾管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第十条修改为：“任何单位和个人不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧建筑垃圾。”

（三）删去第三十条。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

六、对《淮安市古淮河保护条例》作出修改

（一）将条例中的“饮用水源”修改为“饮用水水源”。

（二）将第十条第三款中的“给予表彰”修改为“按照国家和省有关规定给予表彰、奖励”。

（三）删去第十七条第二款。

（四）将第十九条修改为：“禁止在古淮河饮用水水源准保护区内新建、扩建对水体污染严重的建设项目，以及从事法律、法规禁止的其他活动；改建建设项目，不得增加排污量。”

（五）将第二十条第三项修改为：“围垦河道和滩地，从事圈圩、围网、网箱养殖”。

将第四项修改为：“新建、改建、扩建排放污染物的其他建设项目，或者从事法律、法规禁止的其他活动”。

（六）将第二十一条第四项修改为：“新建、改建、扩建与供水设施和保护水源无关的建设项目”。

（七）增加一条，作为第三十六条：“对违反本条例规定的行为，法律、法规已有处罚规定的，从其规定。”

（八）删去第三十六条、第三十七条、第四十条。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

七、对《淮安市乡村人居环境改善促进条例》作出修改

（一）将第四条第一款中的“作出显著成绩”修改为“做出显著成绩”，“按照有关规定给予表彰和奖励”修改为“按照国家和省有关规定给予表彰、奖励”。

（二）将第二十九条第二款修改为：“镇人民政府、街道办事处应当加强巡查，及时制止违法露天焚烧秸秆和弃置秸秆污染水体的行为。”

（三）删去第三十二条、第三十三条。

此外，对条文顺序作相应调整。

本决定自2026年8月15日起施行。

《淮安市文明行为促进条例》、《淮安市永久性绿地保护条例》、《淮安市大运河文化遗产保护条例》、《淮安市市容管理条例》、《淮安市建筑垃圾管理条例》、《淮安市古淮河保护条例》、《淮安市乡村人居环境改善促进条例》根据本决定作相应修改，重新公布。
