# 循化撒拉族自治县第十八届人民代表大会第八次会议关于废止《循化撒拉族自治县水利工程设施管护条例》的决定

循化撒拉族自治县第十八届人民代表大会
第八次会议关于废止《循化撒拉族自治县
水利工程设施管护条例》的决定

（2026年2月12日循化撒拉族自治县第十八届人民代表大会第八次会议通过　2026年5月29日青海省第十四届人民代表大会常务委员会第二十二次会议批准）

经循化撒拉族自治县第十八届人民代表大会第八次会议审议，决定废止《循化撒拉族自治县水利工程设施管护条例》，报请青海省人民代表大会常务委员会批准后废止。
