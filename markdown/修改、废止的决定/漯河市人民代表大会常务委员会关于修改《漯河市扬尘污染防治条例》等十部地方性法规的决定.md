# 漯河市人民代表大会常务委员会关于修改《漯河市扬尘污染防治条例》等十部地方性法规的决定

漯河市人民代表大会常务委员会关于修改
《漯河市扬尘污染防治条例》等十部
地方性法规的决定

（2026年6月24日漯河市第八届人民代表大会常务委员会第三十一次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

漯河市第八届人民代表大会常务委员会第三十一次会议决定：

一、对《漯河市扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了有效防治扬尘污染，保护和改善大气环境质量，保障公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第二条第一款修改为：“本条例适用于本市行政区域内的扬尘污染防治与监督管理活动。”

（三）将第三条修改为：“扬尘污染防治坚持政府主导、部门监管、属地管理、公众参与、损害担责，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（四）将第十三条第三项修改为：“（三）及时清运工程渣土等建筑垃圾、建筑土方，不能及时清运的应当采用密闭式防尘网遮盖；禁止抛撒和在围挡外堆放”。

删去第六项。

（五）将第十九条中的“城镇建成区内的裸露地面，应当采取有效的扬尘污染防治措施。超过三个月不能开工建设的，应当进行绿化；不具备绿化条件的，应当进行铺装或者覆盖”修改为“暂时不能开工的建设用地，建设单位应当对裸露地面进行覆盖；超过三个月的，应当进行绿化、铺装或者遮盖”。

（六）第二十一条增加一款，作为第三款：“实施现场检查的部门及其工作人员应当为被检查者保守商业秘密、个人隐私和个人信息。”

（七）将第二十七条第一款修改为：“违反本条例第十三条第一项至第六项、第十四条、第十五条、第十六条、第十九条规定的，由住房城乡建设主管部门或者其他负有扬尘污染防治监督管理职责的部门责令限期改正，处三万元以上十万元以下的罚款，并组织复查；发现其继续实施该违法行为、拒不改正或者拒绝、阻挠复查的，责令停工整治，作出处罚决定的部门可以依法按日连续处罚，并及时采取措施制止违法行为。”

（八）删去第二十八条、第二十九条、第三十条。

（九）将第三十二条改为第二十九条，其中的“拒不执行应急控制措施的”修改为“拒不执行停止工地土石方作业或者建（构）筑物拆除施工等重污染天气应对措施的”。

（十）将第三十三条改为第三十一条，修改为：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

（十一）对部分条文作以下修改：

1.删去第四条第一款中的“将扬尘污染防治工作纳入环境保护责任制考核”。

2.将第五条第二款中的“水利”修改为“水行政”。

3.将第九条第一项中的“建设项目环境影响评价文件”修改为“建设项目的生态环境影响评价”。

4.将第十条、第二十五条中的“应急”修改为“应对”。

5.将第二十五条中的“停止土方作业”修改为“停止工地土石方作业”。

6.将第十六条、第二十七条第二款中的“第八项”修改为“第七项”。

二、对《漯河市散煤污染防治条例》作出修改

（一）将第一条修改为：“为了防治散煤污染，保护和改善大气环境质量，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）第二条增加一款，作为第三款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）将第三条修改为：“散煤污染防治坚持政府主导、部门实施、公众参与、防治结合、损害担责，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（四）删去第四条第一款中的“并将散煤污染防治纳入环境保护责任制考核体系予以考核”。

（五）将第八条第一款修改为：“禁止销售、燃用不符合质量标准的散煤。市人民政府划定的高污染燃料禁燃区内禁止销售、燃用散煤。”

（六）将第九条、第十条中的“清洁能源”修改为“清洁低碳能源”。

（七）将第十一条第一款修改为：“违反本条例第八条第一款规定，销售不符合质量标准的散煤或者在禁燃区内销售散煤的，由市场监督管理部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下的罚款；单位燃用不符合质量标准的散煤的，由生态环境主管部门责令改正，处货值金额一倍以上五倍以下的罚款；在禁燃区内未停止燃用散煤的，由生态环境主管部门没收燃煤设施、燃煤供热锅炉并组织拆除，处二万元以上二十万元以下的罚款。”

将第二款中的“责令停产整治”修改为“责令停工整治或者停业整治”。

（八）增加一条，作为第十三条：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

三、对《漯河市机动车和非道路移动机械排气污染防治条例》作出修改

（一）将第一条修改为：“为了防治机动车和非道路移动机械排气污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会高质量发展，根据《中华人民共和国生态环境法典》、《河南省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第十一条修改为：“在用重型汽车和非道路移动机械未安装排放控制系统或者排放控制系统不符合要求，不能达标排放的，应当加装或者更换符合要求的排放控制系统，或者采取其他有效措施。

“禁止破坏、拆除、篡改、屏蔽、伪造在用重型汽车和非道路移动机械排放控制系统。”

（三）将第十五条第一款修改为：“本市行政区域内的机动车、非道路移动机械及其发动机不得超过标准排放大气污染物。”

（四）在第十七条第一款“生态环境主管部门”后增加“可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测”，在第一款、第二款“排气污染状况”后增加“排放控制系统运行情况”。

（五）将第十八条中的“经维修或者采用污染控制技术后，排气污染仍不符合标准的，机动车应当依法强制报废，非道路移动机械不得使用”修改为“经维修或者采用污染控制技术后，排气污染仍不符合标准的，应当依法强制报废。其所有人应当将机动车、非道路移动机械等交售给报废回收拆解企业，由报废回收拆解企业按照国家规定进行登记、拆解、销毁等处理”。

（六）将第二十条修改为：“机动车、非道路移动机械排放检验机构应当依法通过计量认证，使用经依法检定合格的机动车、非道路移动机械排放检验设备，按照国务院生态环境主管部门制定的规范，对机动车、非道路移动机械进行排放检验，出具真实、准确、完整的检验报告，并与生态环境主管部门联网，实现检验数据实时共享。机动车、非道路移动机械排放检验机构及其负责人应当对检验数据的真实性、准确性和完整性负责。”

（七）将第二十一条第一款修改为：“机动车、非道路移动机械的维修单位应当按照防治大气污染的要求和国家有关技术规范对在用机动车、非道路移动机械进行维修，使其符合排放标准。交通运输、生态环境等有关部门应当在各自职责范围内依法加强监督管理。”

将第二款中的“提供临时更换污染控制装置等弄虚作假的维修服务”修改为“提供临时更换、篡改、屏蔽、伪造排放控制系统等弄虚作假的维修服务”。

（八）将第二十二条改为第二十六条，修改为：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

（九）将第二十三条改为第二十二条，修改为：“违反本条例第十一条第二款、第二十一条第二款规定的，由生态环境主管部门责令改正，对所有人处每辆五千元的罚款，对维修单位处每辆五千元的罚款。”

（十）将第二十四条改为第二十三条，其中的“处五千元罚款”修改为“处每辆五千元的罚款”。

（十一）将第二十五条改为第二十四条，修改为：“违反本条例第二十条规定，从事机动车排放检验的生态环境技术服务机构，未使用符合法律、行政法规规定和国家标准的设备，或者未遵守有关技术规范导致数据失真的，由生态环境主管部门责令改正，没收违法所得，并处二万元以上二十万元以下的罚款；拒不改正的，报经有批准权的人民政府批准，责令停业。

“前款所列机构在机动车排放检验活动中弄虚作假、出具虚假报告的，由生态环境主管部门没收违法所得，并处十万元以上五十万元以下的罚款；情节严重的，并处五十万元以上二百万元以下的罚款，有许可证的吊销许可证，禁止从事上述业务，报经有批准权的人民政府批准，责令停业、关闭。

“有前款规定情形的，对直接负责的主管人员和其他直接责任人员处一万元以上五万元以下的罚款，五年内禁止从事前款规定的业务；情节严重的，十年内禁止从事前款规定的业务。”

（十二）删去第二十六条、第二十八条。

（十三）对部分条文作以下修改：

1.删去第三条第一款中的“实施目标考核”。

2.将第四条第二款中的“水利”修改为“水行政”。

3.将第六条中的“环境保护”修改为“生态环境保护”。

4.将第十三条中的“市人民政府”修改为“市、县人民政府”。

5.将第十四条中的“应急”修改为“应对”。

四、对《漯河市黑臭水体防治条例》作出修改

（一）将第一条修改为：“为了预防和消除黑臭水体，防治水污染，保护和改善生态环境，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《河南省水污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条第一款修改为：“各级人民政府应当组织开展本行政区域的黑臭水体调查和治理工作，建立健全长效机制，实行河湖长制管理，科学制定黑臭水体治理方案，系统推进黑臭水体整治，防止水体返黑返臭。”

删去第二款。

（三）将第十二条第二款中的“违反前款规定的”修改为“违反前款规定，向雨水收集口、雨水管网排放污水的”。

（四）将第十三条第二款修改为：“从事畜禽养殖的单位和个人应当采取有效措施，及时对畜禽粪污、尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，防止污染环境。”

将第三款修改为：“违反本条第二款规定，从事畜禽规模养殖未及时收集、贮存、清运、处理或者利用养殖过程中产生的畜禽粪污、尸体等废弃物的，由生态环境主管部门、环境卫生主管部门按照职责分工责令改正，可以处一万元以上十万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

（五）在第十四条第二款“丢弃”前增加“倾倒”。

删去第三款。

（六）将第十八条修改为：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

（七）将相关条文中的“水利”修改为“水行政”。

五、对《漯河市河湖保护管理条例》作出修改

（一）将第五条第一款中的“河长制”修改为“河湖长制”。

将第二款中的“总河长、河长”修改为“河湖长”。

删去第三款。

（二）将第三十七条中的“总河长、河长”修改为“河湖长”。

六、对《漯河市澧河集中式饮用水水源地保护条例》作出修改

（一）将第一条修改为：“为了加强澧河集中式饮用水水源地保护，防治水源污染，保障饮用水安全，维护公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》、《河南省水污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第六条第二款中的“水利”修改为“水行政”。

（三）在第七条第二款“指导农业生产者科学施用肥料、农药”后增加“推广高效低毒低残留农药和测土配方施肥技术，控制农药和化肥的过量使用”。

（四）将第八条第三款中的“环境公益诉讼”修改为“生态环境公益诉讼”。

（五）增加一条，作为第十三条：“市人民政府及澧河干支流所在地县、区人民政府应当根据保护饮用水水源的需要，在准保护区内采取工程措施或者建造湿地、水源涵养林等生态保护措施，防止水污染物直接排入饮用水水体，确保饮用水安全。”

（六）将第十三条改为第十四条，第二款修改为：“饮用水供水单位应当根据所在地的饮用水安全突发事件应急预案，制定相应的突发事件应急预案，报所在地的市、县级人民政府备案，并定期进行演练。”

（七）将第十五条改为第十六条，第一款第三项中的“养殖小区”修改为“畜禽散养密集区”。

（八）将第十七条改为第十八条，增加一项，作为第二项：“（二）违反第十五条第一项、第十六条第一款第二项、第十七条第一款第一项规定的，由生态环境主管部门责令停止违法行为，处十万元以上五十万元以下的罚款，并报经有批准权的县级以上人民政府批准，责令拆除或者关闭”。

将第二项改为第三项，其中的“第十五条”修改为“第十六条”；删去“在二级保护区内经营有污染物排放的餐饮、住宿和娱乐场所”。

将第三项改为第四项，其中的“第十六条”修改为“第十七条”；在“个人”前增加“在一级保护区内从事网箱养殖或者组织进行旅游、垂钓或者其他可能污染饮用水水体的活动的，由生态环境主管部门责令停止违法行为，处二万元以上十万元以下的罚款”。

七、对《漯河市城市生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了加强城市生活垃圾分类管理，保护和改善人居环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》、《河南省固体废物污染环境防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第三条修改为：“城市生活垃圾分类坚持政府推动、全民参与，统筹推进、科学实施，因地制宜、简便易行的原则，实现城市生活垃圾减量化、资源化和无害化。”

（四）将第二十七条第五项修改为：“（五）建立生态环境信息公开制度，依法及时、真实、准确、完整向社会披露生活垃圾处理设施主要污染物排放信息、温室气体排放信息等生态环境信息”。

（六）增加一条，作为第三十三条：“违反本条例第十条规定，擅自关闭、闲置或者拆除生活垃圾处理设施、场所的，由城市市容和环境卫生主管部门责令改正，没收违法所得，对单位并处十万元以上一百万元以下的罚款。”

（七）将第三十四条改为第四十条，修改为：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

（八）将第三十五条改为第三十四条，删去其中的“方式”；将“情节严重的”修改为“拒不改正的”。

（九）将第三十八条改为第三十七条，删去其中的“逾期未改正的”。

将第二项修改为：“（二）未按照规定的线路行驶的，处二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶”。

（十）将第三十九条改为第三十八条，删去第二项。

八、对《漯河市沙澧河风景名胜区条例》作出修改

（三）将第十六条修改为：“生态环境主管部门应当适时对沙澧河水体进行监测，确保水质稳定达标。风景区管理机构应当协助做好相关工作。”

（四）将第二十八条改为第三十五条，修改为：“违反本条例规定的其他行为，法律、法规已有法律责任规定的，从其规定。”

（五）将第三十二条改为第三十一条。

将第六项修改为：“（六）使用禁用的渔具进行捕捞的，没收渔获物、违法所得和渔具，并处二十万元以下的罚款；情节严重的，移交渔业渔政主管部门依法处理。炸鱼、毒鱼、电鱼的，移交渔业渔政主管部门依法处理”。

删去第七项中的“在饮用水水源地一级保护区内从事畜禽饲养、水产养殖的，处二万元以上五万元以下罚款；在其他地域、水域”。

将第十一项修改为：“（十一）燃放烟花爆竹的，处一百元以上五百元以下的罚款。露天焚烧秸秆、落叶等产生烟尘污染的物质的，责令改正，可以处五百元以上二千元以下的罚款。焚烧沥青、油毡、橡胶、塑料、皮革、垃圾以及其他产生有毒有害烟尘和恶臭气体的物质的，责令改正，对单位处一万元以上十万元以下的罚款，对个人处五百元以上二千元以下的罚款。露天烧烤食品的，责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款”。

（六）删去第三十五条。

（六）将第三十七条修改为：“运输流体、散装物料的车辆，应当采取密闭、覆盖、清洗等有效措施，防止物料遗撒造成污染，并按照规定路线行驶。”
