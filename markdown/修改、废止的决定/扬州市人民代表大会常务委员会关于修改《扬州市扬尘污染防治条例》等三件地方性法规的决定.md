# 扬州市人民代表大会常务委员会关于修改《扬州市扬尘污染防治条例》等三件地方性法规的决定

扬州市人民代表大会常务委员会关于修改
《扬州市扬尘污染防治条例》等三件
地方性法规的决定

（2026年6月30日扬州市第九届人民代表大会常务委员会第三十六次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

扬州市第九届人民代表大会常务委员会第三十六次会议决定：

一、对《扬州市扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》、《江苏省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第六条第七款修改为：“公安机关交通管理部门负责工程渣土等建筑垃圾运输车辆通行、超载运输等扬尘污染防治的监督管理工作。”

（三）将第七条第三款修改为：“鼓励、支持企业事业单位、基层群众性自治组织、社会组织以及生态环境保护志愿者等宣传扬尘污染防治法律、法规和科学防治知识。”

（四）将第十条第一项修改为：“依法进行生态环境影响评价的建设项目，落实生态环境影响报告书、生态环境影响报告表规定的扬尘污染防治措施”。

（五）将第十一条修改为：“工程施工单位应当承担扬尘污染防治直接责任，采取下列防治措施：

“（一）制定具体的施工扬尘污染防治实施方案。从事房屋建筑、市政基础设施建设、河道整治以及建筑物拆除等施工单位，报负有扬尘污染防治监督管理职责的主管部门备案；

“（二）根据施工扬尘污染防治实施方案，落实扬尘污染防治措施；

“（三）扬尘污染防治费用专款专用，不得挪作他用；

“（四）在施工工地出入口等显著位置公示扬尘污染防治措施、负责人、监督管理部门等信息。”

（六）将第十三条修改为：“建设工程施工，应当采取下列扬尘污染防治措施：

“（一）施工工地周围按照规范要求设置硬质围挡，并采取覆盖、分段作业、择时施工、洒水抑尘、冲洗地面和车辆等有效防尘降尘措施。

“（二）施工工地内工程渣土等建筑垃圾、建筑土方及时清运；在场地内堆存的，采用密闭式防尘网遮盖。

“（三）施工工地内的主要道路进行硬化处理或者铺设与硬化功能相当的材料，并辅以洒水抑尘等防尘措施。

“（四）施工工地出入口设置车辆冲洗设施，并对驶出车辆进行清洗。

“（五）法律、法规的其他相关规定。”

（七）将第十九条修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆，应当采取下列扬尘污染防治措施防止物料遗撒造成扬尘污染：

“（一）采取密闭或者其他有效措施防止物料遗撒，并按照规定路线行驶；

“（二）及时冲洗，上路行驶过程中保持清洁；

“（三）法律、法规的其他相关规定。

“工程渣土等建筑垃圾运输车辆应当按照规定时间行驶，不得超载。”

（八）将第二十五条第一款修改为：“市、县（市、区）人民政府应当制定扬尘污染防治工作规范，协调处理有关扬尘污染防治工作中的重大问题。”

（九）将第二十六条修改为：“依据重污染天气的预警等级，市、县（市、区）人民政府应当及时启动应对预案。负有扬尘污染防治监督管理职责的部门和重点扬尘污染源责任单位应当落实相应的扬尘污染防治应对措施。

“重污染天气的预警解除后，生态环境主管部门和其他负有扬尘污染防治监督管理职责的部门应当及时告知相关责任单位，终止执行应对措施。”

（十）将第二十九条修改为：“负有扬尘污染防治监督管理职责的部门应当将企业事业单位和其他生产经营者关于扬尘污染的违法信息依法记入信用记录。”

（十一）将第三十二条修改为：“违反本条例规定，工程施工单位有下列行为之一的，由住房和城乡建设、交通运输、水利、生态环境等主管部门按照职责责令限期改正，处一万元以上十万元以下的罚款；拒不改正的，责令停工整治：

“（一）施工工地未设置硬质围挡，或者未采取覆盖、分段作业、择时施工、洒水抑尘、冲洗地面和车辆等有效防尘降尘措施的；

“（二）建筑土方未及时清运，或者在场地内堆存时未采用密闭式防尘网遮盖的。”

（十二）将第三十四条修改为：“违反本条例规定，运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆，未采取密闭或者其他措施防止物料遗撒的，或者未按照规定路线行驶的，由城市管理、公安机关交通管理部门、交通运输等主管部门按照职责分工责令改正，处以二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶。”

（十三）将第三十七条修改为：“违反本条例规定，以拖延、围堵、滞留执法人员等方式拒不接受监督检查，或者在接受监督检查和调查处理时弄虚作假或者拒不提供必要资料的，由负有扬尘污染防治监督管理职责的部门责令改正，处五万元以上二十万元以下的罚款；对直接负责的主管人员和其他直接责任人员，处五千元以上五万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（十四）将第三十八条修改为：“企业事业单位和其他生产经营者违反本条例规定，未对建筑施工或者贮存易产生扬尘的物料采取有效措施防治扬尘污染，受到罚款处罚，被责令改正的，依法作出处罚决定的行政机关应当组织复查，发现其继续实施该违法行为、拒不改正或者拒绝、阻挠复查的，可以自责令改正之日的次日起，按照原罚款数额按日连续处罚，并及时采取措施制止违法行为。”

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

二、对《扬州市公园条例》作出修改

（一）将第七条第一款修改为：“市城乡规划主管部门应当会同市公园行政主管部门、县（市、区）人民政府，依照国民经济和社会发展规划、国土空间规划，编制市公园体系发展和保护规划。”

（二）将第十二条修改为：“公园设计应当保护并合理利用原有地形地貌、水体植被等自然条件，注重人文景观和文化艺术教育内涵。”

（三）将第十九条第二款修改为：“各县（市、区）人民政府确定的部门是本级公园行政主管部门。”

（四）将第四十四条修改为：“公园建设单位违反本条例规定，有下列行为之一的，由有关机关责令改正，依法给予处罚：

“（一）不按照公园规划和设计方案建设的；

“（二）不按照依法批准的土地用途和规划建设的；

“（三）未组织竣工验收或者验收不合格擅自交付使用的，以及对不合格的建设工程按照合格工程验收的。”

此外，对有关条款作文字、技术修改。

三、对《扬州市生活垃圾分类管理条例》作出修改

（一）将第一条修改为：“为了加强生活垃圾分类管理，改善人居环境，促进可持续发展，根据《中华人民共和国生态环境法典》、《中华人民共和国循环经济促进法》、国务院《城市市容和环境卫生管理条例》等法律、法规，结合本市实际，制定本条例。”

（二）将第四条修改为：“生活垃圾分类管理以减量化、资源化、无害化为目标，遵循政府推动、全民参与、城乡统筹、因地制宜、简便易行的原则。”

（三）将第九条修改为：“市、县（市、区）人民政府依照《中华人民共和国生态环境法典》的有关规定，按照产生者付费原则，建立健全生活垃圾处置收费制度。”

（四）将第二十一条第一款修改为：“任何单位和个人都应当依法在指定的地点分类投放生活垃圾。”

将第三款修改为：“禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

（五）删去第三十九条第二款。

（六）将第四十四条修改为：“违反本条例第二十一条第一款规定，未在指定的地点分类投放生活垃圾的，由城市管理部门责令改正；拒不改正的，对单位处五万元以上五十万元以下的罚款，对个人处二十元以上二百元以下的罚款。

“违反本条例第二十一条第三款规定，擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾的，由城市管理部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。

“违反本条例第二十一条第三款规定，个人擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧个人产生的生活垃圾的，由城市管理部门责令改正，处一百元以上一千元以下的罚款。”

（七）将第四十六条修改为：“违反本条例第二十八条第二款第二项规定，生活垃圾收集、运输单位将已分类的生活垃圾混合收集、运输的，由城市管理部门责令改正，处五千元以上五万元以下的罚款。

“违反本条例第三十条第一款第一项规定，生活垃圾处置单位未按照国家、省有关规定和技术标准分类处置生活垃圾的，由城市管理部门责令限期改正，处三万元以上十万元以下的罚款。

“生活垃圾收集、运输、处置单位违反有关约定的，还应当依法承担违约责任。

“市城市管理部门应当将企业事业单位和其他生产经营者关于生活垃圾分类管理的违法信息依法记入信用记录。”

（八）将第四十七条修改为：“负有生活垃圾分类管理工作职责的部门及其工作人员滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（九）将第四十八条修改为：“对违反本条例规定的行为，法律、法规另有规定的，从其规定。

“本条例规定的行政处罚，按照相对集中行政处罚权的规定应当由其他执法主体实施的，依照其规定执行。”

（十）删去第四十九条。

此外，对有关条款作文字、技术修改，并对条文顺序作相应调整。

本决定自2026年8月15日起施行。

《扬州市扬尘污染防治条例》、《扬州市公园条例》、《扬州市生活垃圾分类管理条例》根据本决定作相应修改，重新公布。
