# 铁岭市人民代表大会常务委员会关于废止《铁岭市饮用水水源保护条例》的决定

铁岭市人民代表大会常务委员会关于废止
《铁岭市饮用水水源保护条例》的决定

（2026年6月30日铁岭市第九届人民代表大会常务委员会第三十七次会议通过　2026年7月29日辽宁省第十四届人民代表大会常务委员会第二十四次会议批准）

铁岭市第九届人民代表大会常务委员会第三十七次会议决定，废止《铁岭市饮用水水源保护条例》（2016年4月28日铁岭市第七届人民代表大会常务委员会第三十一次会议通过，2016年5月25日辽宁省第十二届人民代表大会常务委员会第二十六次会议批准）。

本决定自公布之日起施行。
