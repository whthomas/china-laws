# 甘南藏族自治州人民代表大会常务委员会关于修改《甘南藏族自治州洮河流域生态保护条例》的决定

甘南藏族自治州人民代表大会常务委员会
关于修改《甘南藏族自治州洮河流域
生态保护条例》的决定

（2026年6月30日甘南藏族自治州第十七届人民代表大会常务委员会第三十四次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

甘南藏族自治州第十七届人民代表大会常务委员会第三十四次会议决定对《甘南藏族自治州洮河流域生态保护条例》作如下修改：

一、将第一条修改为：“为了加强洮河流域生态保护和修复，促进资源合理高效利用，保障生态安全，促进绿色发展，根据《中华人民共和国生态环境法典》《中华人民共和国黄河保护法》等法律法规，结合自治州洮河流域实际，制定本条例。”

二、将第十条第二款、第三十一条第一款、第三十二条、第三十四条、第三十六条第二款、第四十三条第一款、第四十六条中“环境”修改为“生态环境”。

三、将第四十八条、第五十二条中“清洁能源”修改为“清洁低碳能源”。

四、将第二十三条第四款修改为：“禁止在荒漠、半荒漠和严重退化、沙化、盐碱化、荒漠化、水土流失的草原以及生态脆弱区的草原上采挖植物和从事破坏草原植被的其他活动，法律、行政法规另有规定的除外。”

五、将第二十七条第一款修改为：“自治州人民政府生态环境主管部门按照相关规定开展洮河流域水生态环境质量监测，定期向社会公布监测评价结果。”

六、将第三十条修改为：“自治州、卓尼县、临潭县人民政府应当落实省人民政府九甸峡库区规范化管理建设要求，根据专项规划，按照规定合理预留水库库容，加强九甸峡库区生态的保护与修复，保护良好生态功能，增强生态产品供给能力和生态系统服务功能。”

七、将第三十三条第三款中“清洁能源和环保燃料。”修改为“清洁低碳能源；”。

八、将第三十九条第二款修改为：“洮河流域内新建、改建、扩建畜禽养殖场、定点屠宰企业等的选址、建设和管理应当符合畜牧业发展规划、畜禽养殖污染防治规划，满足动物防疫条件，并依法进行生态环境影响评价。建设雨污分流设施和养殖规模相匹配的畜禽养殖粪污处理与资源化利用设施，满足防渗、防溢流和安全防护要求，并确保正常运行，保证粪污达标排放。从事畜禽养殖和屠宰的单位和个人应当采取有效措施，及时对畜禽尸体、粪便、废水等进行收集、贮存、清运、无害化处理和资源化利用，防止污染生态环境。”

第三款修改为：“畜禽散养密集区所在地县、乡级人民政府应当组织对畜禽粪污进行分户收集、集中处理利用。县级人民政府组织确定本行政区域的畜禽散养密集区。”

九、将第四十条修改为：“自治州、洮河流域县（市）人民政府及农业农村等有关部门和机构应当指导农业生产经营者科学种植和养殖，科学合理安全使用农药、兽药、饲料和饲料添加剂、肥料等农业投入品，科学处置农用薄膜、农作物秸秆、农业投入品包装废弃物等农业废弃物，加强对农业生产经营活动排放污染物的控制，防止农业面源污染。”

十、将第四十一条修改为：“自治州、洮河流域县（市）、乡（镇）人民政府应当提高农村生态环境保护公共服务水平，推动农村生态环境综合整治，完善生活污水处理、生活垃圾无害化处理、供排水、集中供热等公共设施。组织村（居）民委员会实施生态环境保护工作和公共卫生清洁工作，持续改善农村人居环境。

“鼓励减少煤炭等高污染能源的使用，推广和普及使用电能、太阳能、风能、沼气、天然气等清洁低碳能源。加强生态文明宣传教育，引导公众新建建筑采用绿色建材、绿色居住，倡导简约适度、绿色低碳的生活方式。”

十一、在第四十七条“国土空间规划”后增加“和生态环境分区管控”。

十二、删除第五十四条中“警告、”和“，其主要负责人应当引咎辞职”。

本决定自2026年8月15日起施行。

《甘南藏族自治州洮河流域生态保护条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
