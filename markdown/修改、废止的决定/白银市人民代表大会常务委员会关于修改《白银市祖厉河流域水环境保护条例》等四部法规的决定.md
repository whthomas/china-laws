# 白银市人民代表大会常务委员会关于修改《白银市祖厉河流域水环境保护条例》等四部法规的决定

白银市人民代表大会常务委员会关于修改
《白银市祖厉河流域水环境保护条例》等
四部法规的决定

（2026年6月30日白银市第十届人民代表大会常务委员会第四十一次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

白银市第十届人民代表大会常务委员会第四十一次会议决定：

一、对《白银市祖厉河流域水环境保护条例》作出修改

（一）将第二十五条第二款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照规定取得排污许可证，未取得排污许可证的不得排放污染物。”

（二）在第二十六条“环境影响评价”前增加“生态”。

（三）将第三十条修改为：“排放工业废水的企业应当采取有效措施，收集和处理产生的全部废水，防止污染环境。含有毒有害水污染物的工业废水应当分类收集和处理，防止渗漏、流失，不得稀释排放。

“工业园区等区域应当配套建设相应的污水集中处理设施，按照规定安装自动监测设备，与生态环境主管部门的监控设备联网，并保证监测设备正常运行。

“向污水集中处理设施排放工业废水的，应当按照国家规定进行预处理，达到集中处理设施处理工艺要求后，方可排放。

“排污企业排放污染物的，应当依照法律法规和国务院生态环境主管部门的规定设置、使用污染物排放口。”

（四）将第三十一条中的“计划”修改为“规划”。

（五）将第三十二条修改为：“市人民政府、祖厉河流域县级人民政府应当对流域内的入河排污口组织开展排查整治，明确责任主体，实施分类管理。

“祖厉河流域多个单位和个人共用入河排污口的责任主体，应当加强入河排污口监测，按照规定开展监控、自动监测。

“入河排污口的责任主体应当加强源头治理、排污通道巡查维护和入河排污口整治、规范化建设、维护管理等。”

（六）将第三十三条修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，并与生态环境主管部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。”

（七）将第三十四条第二款中的“加强对水环境监测的管理”修改为“并依法向社会公开水环境监测信息”。

（八）在第三十六条第二款“企业事业单位”后增加“和其他生产经营者”，“突发”后增加“生态”。

（九）将第三十七条第二款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照规定向社会公开污染物排放种类、排放浓度和排放量，以及污染防治设施的建设运行情况、自行监测数据等污染物排放信息，接受社会监督。”

二、对《白银市农作物秸秆露天禁烧和利用条例》作出修改

（一）将第一条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第七条第三项修改为：“（三）工业和信息化部门负责农作物秸秆饲料化、肥料化、能源化、食用菌基料化、工业原料化利用相关技术推广等工作”。

（三）增加一条，作为第十条：“禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧农作物秸秆。”

（四）将第十一条改为第十二条，修改为：“市、县（区）人民政府应当完善农作物秸秆利用方式，促进农作物秸秆饲料化、肥料化、能源化、食用菌基料化、工业原料化等综合利用。”

（五）将第十五条改为第十六条，第一款第四项修改为：“（四）农作物秸秆饲料化、肥料化、能源化、食用菌基料化、工业原料化利用项目”。

（六）将第十六条改为第十七条，将“单位和个人给予表彰奖励”修改为“单位和个人，按照国家规定给予表彰和奖励”。

（七）将第十九条改为第二十条，修改为：“违反本条例规定，在禁止焚烧的区域和时段露天焚烧农作物秸秆的，由市生态环境主管部门或者其派出机构责令改正，可以处五百元以上二千元以下的罚款。”

（八）将第二十条改为第二十一条，在“职务”后增加“，构成违反治安管理行为”。

三、对《白银市烟花爆竹燃放管理办法》作出修改

（一）将第一条修改为：“为了加强烟花爆竹燃放管理，防治大气污染和噪声污染，保障生态环境安全与公共安全，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本办法。”

（二）将第五条第一款中的“、乡（镇）”删除。

（三）删除第八条。

（四）将第九条改为第八条，修改为：“市、县（区）人民政府可以根据本行政区域的实际情况，依法确定、变更或者调整禁止燃放烟花爆竹的时段和区域，设置禁止燃放标志，并及时向社会公布。

“下列区域和场所全时段禁止燃放烟花爆竹：

“（一）重要军事设施区、饮用水水源保护区、风景名胜区、文物保护单位；

“（二）车站、码头等交通枢纽及铁路、公路线路安全保护区；

“（三）加油（气）站、液化气供应站（点）、油库、仓库、输油（气）管道等禁火区或者其他生产、经营、储存易燃易爆危险物品安全保护区；

“（四）输变电设施、架空线路安全保护区；

“（五）林地、公共绿地、草原、湿地、自然保护地等区域；

“（六）图书馆、档案馆、博物馆、美术馆、展览馆、纪念馆、学校、医院及敬（养）老机构所在区；

“（七）党政机关、企业事业单位工作区；

“（八）城市主次干道、立交桥、人行天桥、地下通道及地下综合管廊；

“（九）公园、商场、集贸市场、公共娱乐场所等人群密集场所；

“（十）法律、法规规定禁止燃放烟花爆竹的其他区域和场所。”

（五）删除第十条。

（六）将第十二条改为第十条，修改为：“禁止在城市市区布设烟花爆竹批发场所。城市市区的烟花爆竹零售网点，应当按照严格控制的原则合理布设。”

（七）删除第十五条。

（八）将第十六条改为第十三条，修改为：“从事婚庆、殡仪等服务的单位或者个人，不得在禁止燃放烟花爆竹的时段和区域内提供燃放烟花爆竹服务。”

（九）将第十七条改为第十四条，将“在禁止燃放烟花爆竹区域”修改为“在禁止燃放烟花爆竹的时段和区域内，”。

（十）将第十八条改为第十五条，修改为：“在禁止燃放烟花爆竹的时段和区域内，宗教活动场所的管理人员应当做好相关人员不得违法燃放烟花爆竹的提醒、劝导和监督工作。”

（十一）将第十九条改为第十六条，修改为：“在禁止燃放烟花爆竹的时段和区域内，物业服务人应当对其物业管理区域内违法燃放烟花爆竹的行为予以劝阻，劝阻无效的，应当及时向公安部门报告。”

（十二）将第二十条改为第十七条，修改为：“违反本《办法》规定，在禁止燃放的时段和区域内燃放烟花爆竹的，由市、县（区）公安部门依法予以处罚。”

（十三）删除第二十一条、第二十二条、第二十三条、第二十四条。

四、对《白银市爱国卫生条例》作出修改

（一）删除第四条第三款中的“，组织本辖区单位和个人参加爱国卫生活动”。

（二）将第五条第一款修改为：“市、县（区）人民政府领导本行政区域内的爱国卫生工作。”

将第二款中的“市、县（区）爱卫会履行下列职责：”修改为“市、县（区）卫生健康主管部门负责爱国卫生工作的组织协调和监督管理工作，履行下列职责：”

删除第三款、第四款。

（三）将第七条第二款中的“国家机关和企业事业单位”修改为“国家机关、社会团体、企业事业单位”。

（四）将第十条第一项中的“废弃物”修改为“垃圾”。

（五）将第十五条第三款中的“爱卫会成员单位”修改为“卫生健康主管部门及其他负有爱国卫生工作职责的部门”。

（六）将第十六条修改为：“市、县（区）疾病预防控制机构应当定期开展病媒生物密度监测，并向同级卫生健康主管部门报告监测结果。”

（七）将第十九条第一款修改为：“在本市行政区域从事病媒生物预防控制服务的机构应当向市卫生健康主管部门备案，由市卫生健康主管部门对其相关备案信息进行公示。”

（八）在第二十五条“乡（镇）”后增加“人民政府”。

（九）将第二十二条、第二十六条、第二十七条中的“爱卫会”修改为“卫生健康主管部门”。

（十）将第二十八条中的“爱卫办及爱卫会成员”修改为“市、县（区）卫生健康主管部门及其他负有爱国卫生工作职责的”。

本决定自2026年8月15日起施行。

《白银市祖厉河流域水环境保护条例》、《白银市农作物秸秆露天禁烧和利用条例》、《白银市烟花爆竹燃放管理办法》、《白银市爱国卫生条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
