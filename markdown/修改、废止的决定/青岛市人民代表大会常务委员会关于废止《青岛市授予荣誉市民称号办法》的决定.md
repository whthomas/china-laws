# 青岛市人民代表大会常务委员会关于废止《青岛市授予荣誉市民称号办法》的决定

青岛市人民代表大会常务委员会关于

废止《青岛市授予荣誉市民称号办法》的决定

（2023年8月25日青岛市第十七届人民代表大会常务委员会第十一次会议通过　2023年9月27日山东省

第十四届人民代表大会常务委员会第五次会议批准）

青岛市第十七届人民代表大会常务委员会第十一次会议决定，废止《青岛市授予荣誉市民称号办法》。

本决定自公布之日起施行。
