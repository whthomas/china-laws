# 铜仁市人民代表大会常务委员会关于修改《铜仁市锦江流域保护条例》等四件地方性法规部分条款的决定

铜仁市人民代表大会常务委员会关于修改
《铜仁市锦江流域保护条例》等四件
地方性法规部分条款的决定

（2026年6月30日铜仁市第三届人民代表大会常务委员会第三十七次会议通过　2026年7月29日贵州省第十四届人民代表大会常务委员会第二十五次会议批准）

铜仁市第三届人民代表大会常务委员会第三十七次会议决定，对下列四件地方性法规部分条款作出修改：

一、对《铜仁市锦江流域保护条例》作出修改

（一）第一条中的“根据《中华人民共和国环境保护法》《中华人民共和国水法》《中华人民共和国水污染防治法》等法律法规的规定”修改为“根据《中华人民共和国生态环境法典》《中华人民共和国水法》等法律法规的规定”。

（二）第十二条第六项修改为：“（六）施用化肥，使用农药；”

（三）在第二十三条第一款中的“基础设施”后增加“和经依法批准的农村村民符合一户一宅条件且只能在原宅基地上拆除危旧房屋重建住宅”。

（四）第二十六条修改为：“在河岸保护区内，禁止开山采石等破坏地形地貌、植被的活动；有山体滑坡、崩岸、泥石流等自然灾害的河段，除适用前述规定外，还禁止采矿、开荒等危及山体稳定的活动。

“前款规定的开山采石、采矿等活动遗留的废弃场地，由采矿权人负责治理；采矿权人灭失或者无法确认的，由所在地市、县级人民政府统筹规划、治理修复。”

（五）第三十六条增加一项，作为第三项：“（三）硬化滩涂或者在滩涂上搭建烧烤屋（棚）、灶台等设施；”

（六）第三十八条第五项修改为：“（五）违反第六项规定的，由县级人民政府农业农村主管部门责令改正，农药使用者为农产品生产企业、食品和食用农产品仓储企业、专业化病虫害防治服务组织和从事农产品生产的农民专业合作社等单位的，处5万元以上10万元以下的罚款，农药使用者为个人的，处1万元以下的罚款；使用禁用的农药的，县级人民政府农业农村主管部门还应当没收禁用的农药；使用国家明令禁止的农药，被责令改正，拒不改正的，由农业农村主管部门依照有关法律法规的规定予以处罚，并将案件移送公安机关，由公安机关依法处理；”

（七）第四十七条修改为：“违反本条例第三十条第二款规定的，由县级人民政府交通运输主管部门责令限期改正，处5000元以上2万元以下的罚款；逾期不改正的，责令船舶临时停航。”

（八）第四十九条修改为：“违反本条例第三十四条第二款规定的，由县级人民政府渔业渔政主管部门没收渔获物和违法所得，并处1万元以上20万元以下的罚款；情节严重的，并处20万元以上200万元以下的罚款，可以没收渔具、船舶。

“违反本条例第三十四条第三款规定的，由县级人民政府公安机关、渔业渔政主管部门没收装置、器具、有毒物质、渔获物和违法所得，并处20万元以下的罚款；情节严重的，并处20万元以上200万元以下的罚款，吊销捕捞许可证，可以没收船舶。”

（九）第五十一条第二项修改为：“（二）违反第二项、第三项、第六项规定的，由生态环境主管部门责令停止违法行为，排除阻碍或者采取其他补救措施，可以处5万元以下的罚款；”第三项修改为：“（三）违反第四项规定的，由县级人民政府水行政主管部门责令停止违法行为，没收违法所得；危及河道安全的，对个人处以1000元以上1万元以下的罚款，对单位处以2万元以上20万元以下的罚款。”

二、对《铜仁市农村饮用水管理条例》作出修改

第一条中的“根据《中华人民共和国水法》《中华人民共和国水污染防治法》等法律、法规的规定”修改为“根据《中华人民共和国生态环境法典》《中华人民共和国水法》等法律、法规的规定”。

三、对《铜仁市锦江干流大江沿岸建设管理条例》作出修改

（一）在第十五条第一款中的“基础设施”后增加“和经依法批准的农村村民符合一户一宅条件且只能在原宅基地上拆除危旧房屋重建住宅”。

（二）第十九条第三项修改为：“（三）违反第五项规定的，由县级人民政府林业、园林绿化主管部门按照有关法律、法规的规定进行处罚。”

四、对《铜仁市传统村落保护发展条例》作出修改

（一）第三条句末增加：“体现铸牢中华民族共同体意识的要求”。

（二）第三十条修改为：“违反本条例第十八条第一项、第三项、第四项规定的，由县级人民政府有关主管部门责令停止违法行为、恢复原状；造成严重后果的，对单位处以二十万元以上五十万元以下的罚款，对个人处以一万元以上五万元以下的罚款。

“违反本条例第十八条第二项规定的，由县级人民政府有关主管部门按照有关法律、法规的规定进行处罚。”

本决定自2026年8月15日起施行。

《铜仁市锦江流域保护条例》《铜仁市农村饮用水管理条例》《铜仁市锦江干流大江沿岸建设管理条例》《铜仁市传统村落保护发展条例》根据本决定作相应修改，部分条文作文字技术处理，条文顺序作相应调整，重新公布。
