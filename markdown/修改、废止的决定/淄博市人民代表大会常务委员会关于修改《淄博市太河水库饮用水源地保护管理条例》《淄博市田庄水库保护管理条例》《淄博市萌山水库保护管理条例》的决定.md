# 淄博市人民代表大会常务委员会关于修改《淄博市太河水库饮用水源地保护管理条例》《淄博市田庄水库保护管理条例》《淄博市萌山水库保护管理条例》的决定

淄博市人民代表大会常务委员会关于修改
《淄博市太河水库饮用水源地保护管理条例》《淄博市田庄水库保护管理条例》《淄博市
萌山水库保护管理条例》的决定

（2026年6月29日淄博市第十六届人民代表大会常务委员会第三十四次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

淄博市第十六届人民代表大会常务委员会第三十四次会议决定：

一、对《淄博市太河水库饮用水源地保护管理条例》作出修改

1.将第二条第二款修改为：“水源地保护范围，包括太河水库饮用水水源地一级保护区、二级保护区、准保护区。”

2.将第九条第二款修改为：“对在水源地保护管理工作中做出显著成绩的单位和个人，由市人民政府按照国家和省有关规定给予表彰和奖励。”

3.删去第十一条、第三十二条至第三十六条、第三十八条至第四十一条、第四十三条、第四十四条。

4.将第十二条改为第十一条，将第一项中的“三点二米至十米之间”修改为“十米以内”；将第三项中的“四米至十米之间”修改为“十米以内”。

5.删去第十六条至第十八条、第二十九条、第三十一条、第三十七条中的“库区”。

6.将第十六条改为第十五条，将第三项修改为：“（三）爆破、打井、采石、采矿、取土、挖沙、建墓、放牧、围垦”；将第八项修改为：“（八）使用船只、排筏以及各类自制工具进行水上休闲娱乐活动”；将第十一项修改为：“（十一）游泳、垂钓、放生、露营、野炊等”；将第十六项修改为：“（十六）其他违反法律、法规规定危害一级保护区安全的行为”。

7.将第二十四条改为第二十三条，删去“建立目标责任制和考核评价制度”。

8.将第二十九条改为第二十八条，删去第二项、第三项中的“灌区工程”。

9.将第三十一条改为第三十条，将第四项修改为：“（四）在准保护区内新建、改建、扩建有毒有害、放射性物质、无隔离设施的输油、输气管道以及其他对水质有严重污染的建设项目，或者改建建设项目增加排污量的”。

10.将第三十七条改为第三十一条，修改为：“违反本条例规定，个人在一级保护区内有下列行为之一的，由有关部门根据各自职责责令停止违法行为，可以处罚款：

（一）洗刷车辆、衣物和其他器具的；

（二）游泳、垂钓、放生的；

（三）放牧的；

（四）在坝体堆放杂物、晾晒粮草，在供水工程引水渠覆盖面停放车辆、堆放杂物、作业的。

“有前款第一项、第二项行为之一的，由生态环境主管部门处五百元以下罚款；有前款第三项行为的，由市水行政主管部门处一百元以上五百元以下罚款；有前款第四项行为的，由市水行政主管部门处二百元以上一千元以下罚款。

“违反本条例规定，在一级保护区内捕鱼、捕虾的，由农业农村部门依照《中华人民共和国渔业法》的规定处罚。”

二、对《淄博市田庄水库保护管理条例》作出修改

1.删去第三条第二款、第十条至第十五条、第十八条至第二十条、第二十五条、第二十六条、第三十一条、第三十二条、第三十四条、第三十七条、第三十八条。

2.将第八条第六项修改为：“（六）非水库管理人员操作大坝的泄洪闸门、输水闸门以及其他设施”；将第十一项修改为：“（十一）排放、倾倒工业废渣、城镇垃圾和其他废弃物”；将第十六项修改为：“（十六）游泳、垂钓、水上训练等水上活动”。

3.将第二十二条改为第十三条，修改为：“公安机关、交通运输部门应当加强对进入保护区内运输危险、有害化学物品车辆的管理。发生危险、有害化学物品泄漏事故时，驾驶人员、押运人员应当立即采取措施，并依法及时报告有关部门。”

4.将第二十九条改为第十八条，修改为：“违反本条例规定的行为，法律、法规已经规定法律责任的，适用其规定。”

5.将第三十三条改为第二十条，修改为：“违反本条例规定，在水库管理范围内有下列行为之一的，由县水行政主管部门责令停止违法行为，按照下列规定予以处罚；造成损失的，依法承担赔偿责任：

“（一）非水库管理人员擅自操作大坝的泄洪闸门、输水闸门以及其他设施，破坏水库正常运行的，可以处一万元以上五万元以下的罚款；

“（二）防汛期间，在坝体上擅自停放车辆的，可以处五十元以上一百元以下的罚款；

“（三）从事游泳、垂钓等活动的，可以处一百元以上三百元以下的罚款。”

三、对《淄博市萌山水库保护管理条例》作出修改

1.将第四条修改为：“市水行政主管部门负责水库保护管理的监督和指导工作；周村区人民政府水行政管理部门负责水库的保护管理工作；萌山水库管理机构负责水库的日常保护管理工作。

“周村、淄川、博山、张店区人民政府以及有关行政管理部门应当按照各自职责，做好水库的保护管理工作。”

2.删去第六条、第二十五条、第三十二条、第三十五条中的“文昌湖区管委会”。

3.删去第七条第一款、第十条、第十七条、第十八条第一款、第二十一条至第二十四条、第二十五条第二项、第二十八条、第三十条、第三十三条、第三十四条、第三十六条至第三十九条、第四十一条。

4.将第八条中的“保护管理范围”修改为“管理、保护范围”。

5.将第九条第三项修改为：“（三）爆破、打井、采石、采矿、挖沙、取土、挖筑池塘、垦植、放牧”；将第五项修改为：“（五）非水库管理人员操作水库的泄洪闸门、输水闸门以及其他设施”；将第八项修改为：“（八）排放、倾倒工业废渣、城镇垃圾和其他废弃物，种植阻碍行洪的林木和高秆作物”。

增加四项，分别作为第十二项至第十五项，内容为：“（十二）擅自从水库中提水、引水或者从输水干渠和输水管道中截水、提水、引水；

“（十三）擅自设置餐饮、经营摊点；

“（十四）违反管理规定系固浮动设施或者使用橡皮艇、皮划艇、摩托艇、桨板等进行水上休闲娱乐活动；

“（十五）违反管理规定进行水上训练、比赛、垂钓、游泳等活动”。

6.将第十二条改为第十一条，修改为：“周村区人民政府和相关区人民政府应当加强水库保护区域环境保护基础设施建设，配备污水、垃圾收集设施，并进行集中处理。”

7.将第十三条改为第十二条，修改为：“萌山水库管理机构应当对水库水量进行日常监测，并会同生态环境部门对水库水质进行评价。”

8.将第十四条改为第十三条，将第一款修改为：“水库保护范围内的单位排放污染物，应当符合污染物排放标准、重点污染物排放总量控制指标、排污许可管理和有关法律、法规、规章的要求。”

将第二款中“环境保护行政主管部门”修改为“生态环境部门”。

9.将第十五条改为第十四条，修改为：“市生态环境部门根据水库水质要求，对水库保护范围内的污染源实行重点污染物排放总量控制。”

10.将第十六条改为第十五条，修改为：“萌山水库管理机构应当按照有关技术标准，对水库工程设施进行安全监测。发现危及水库安全的隐患，应当及时采取措施，并立即报告周村区人民政府和市水行政主管部门。对达不到标准或者损坏的工程设施，应当及时进行抢修、养护、加固或者更新。”

11.将第十八条改为第十六条，修改为：“在水库管理、保护范围内从事开发利用活动的，应当服从萌山水库岸线利用管理规划，符合水污染防治、防洪安全和水资源保护的总体要求。”

12.将第十九条改为第十七条，将第二款修改为：“市及相关区人民政府应当支持水库保护范围内镇村集体和个人发展绿色经济。”

13.将第二十条改为第十八条，修改为：“在水库管理范围内从事开发利用活动的单位和个人，应当依法办理审批手续，并履行保障水库工程安全、维护水生态环境、服从防洪调度的义务。”

14.将第二十六条改为第二十条，修改为：“水行政管理部门在水库保护管理中应当履行下列职责：

“（一）监督指导水库的保护和管理；

“（二）协调配合有关部门和单位做好水库的保护和管理；

“（三）设立保护管理标志；

“（四）依法查处相关违法行为；

“（五）宣传贯彻相关法律、法规；

“（六）其他应当依法履行的职责。”

15.将第二十七条改为第二十一条，修改为：“生态环境部门在水库保护管理中应当履行下列职责：

“（一）编制水库水污染防治方案，并指导和监督实施；

“（二）负责建设项目环境影响评价文件审批，并做好监督工作；

“（三）依法实施水污染物排放许可制度，调查处理水污染纠纷和事故；

“（四）依法查处水环境污染等违法行为；

“（五）其他应当依法履行的职责。”

16.增加一条，作为第二十三条，内容为：“违反本条例规定的行为，法律、法规已经规定法律责任的，适用其规定。”

17.将第三十一条改为第二十四条，修改为：“违反本条例规定，在水库管理范围内有下列行为的，由相关部门按照下列规定予以处罚：

“（一）从事网箱养殖的，由生态环境部门责令停止违法行为，处二万元以上十万元以下的罚款；

“（二）擅自设置餐饮、经营摊点的，由水行政管理部门责令改正；拒不改正的，处五百元以上二千元以下的罚款；

“（三）违反管理规定系固浮动设施或者使用橡皮艇、皮划艇、摩托艇、桨板等进行水上休闲娱乐活动的，由水行政管理部门责令停止违法行为，处一千元以上五千元以下的罚款；

“（四）违反管理规定进行水上训练、比赛等活动的，由水行政管理部门责令停止违法行为，处一千元以上五千元以下的罚款；

“（五）违反管理规定垂钓的，由水行政管理部门责令停止违法行为，可以处五百元以下的罚款；违反管理规定游泳的，由水行政管理部门责令停止违法行为，可以处三百元以下的罚款。”

18.将第四十条改为第二十七条，修改为：“有关行政管理部门及水库管理机构工作人员在水库保护管理工作中滥用职权、徇私舞弊、玩忽职守的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

此外，对条文顺序、标点符号和文字表述作出相应的修改。

本决定自2026年8月15日起施行。

《淄博市太河水库饮用水源地保护管理条例》《淄博市田庄水库保护管理条例》《淄博市萌山水库保护管理条例》根据本决定作相应修改，重新公布。
