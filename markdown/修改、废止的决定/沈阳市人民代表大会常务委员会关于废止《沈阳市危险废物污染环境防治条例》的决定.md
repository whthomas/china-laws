# 沈阳市人民代表大会常务委员会关于废止《沈阳市危险废物污染环境防治条例》的决定

沈阳市人民代表大会常务委员会关于废止
《沈阳市危险废物污染环境防治条例》的决定

（2026年6月29日沈阳市第十七届人民代表大会常务委员会第三十二次会议通过　2026年7月29日辽宁省第十四届人民代表大会常务委员会第十一次会议批准）

沈阳市第十七届人民代表大会常务委员会第三十二次会议审议了《关于废止〈沈阳市危险废物污染环境防治条例〉的议案》，决定自2026年8月15日起废止《沈阳市危险废物污染环境防治条例》。
