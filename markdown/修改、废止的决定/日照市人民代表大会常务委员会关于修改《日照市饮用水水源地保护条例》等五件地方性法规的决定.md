# 日照市人民代表大会常务委员会关于修改《日照市饮用水水源地保护条例》等五件地方性法规的决定

日照市人民代表大会常务委员会关于修改
《日照市饮用水水源地保护条例》等
五件地方性法规的决定

（2026年6月25日日照市第十九届人民代表大会常务委员会第三十六次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

日照市第十九届人民代表大会常务委员会第三十六次会议决定：

一、对《日照市饮用水水源地保护条例》作出修改

1.将第一条修改为：“为了加强饮用水水源地保护，保障饮用水安全，维护公众健康，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》《中华人民共和国水法》《山东省水污染防治条例》等有关法律、法规，结合本市实际，制定本条例。”

2.将第四条修改为：“市、县（区）人民政府应当建立统一领导、属地管理、分级负责、协调联动的体制和机制，统筹饮用水水源地保护工作。

市、县（区）人民政府应当建立饮用水水源地保护和生态保护补偿长效机制，合理确定生态保护补偿范围，科学评估生态保护补偿标准，统筹安排生态保护补偿资金，并将饮用水水源地保护经费纳入本级财政预算，保障饮用水水源地保护工作需要。”

3.将第五条改为第七条，修改为：“饮用水水源保护区、准保护区内的各级河湖长，应当按照河湖长制的有关规定组织领导饮用水水源地保护、水域岸线管理、水污染防治、水环境治理等工作。”

4.将第六条改为第五条，修改为：“市人民政府生态环境部门负责饮用水水源保护区有关环境管理的具体工作，对饮用水水源地污染防治实施统一监督管理。

市、县（区）人民政府水利部门负责饮用水水源地水源工程建设的监督管理工作，对饮用水水资源实施统一监督管理。

市、县（区）人民政府住房城乡建设、城市管理部门根据职责负责对排污管网及生活污水、垃圾处理设施建设、排水与污水处理设施覆盖范围内排水户的监督管理。

市、县（区）人民政府自然资源和规划部门负责饮用水水源保护区及其周边湿地和林地的监督管理。

市、县（区）人民政府农业农村部门负责饮用水水源地汇流区域农业面源污染防控、畜禽养殖污染防控的指导与监督。

市、县（区）人民政府疾病预防控制部门负责饮用水卫生的监督监测。

发展改革、公安、财政、交通运输、文化和旅游、海洋发展等其他有关部门，应当按照各自职责做好饮用水水源地保护有关工作。”

5.将第七条改为第六条，修改为：“乡镇人民政府、街道办事处按照职责做好饮用水水源地保护有关工作。

村（居）民委员会通过村规民约或者居民公约等形式对村（居）民保护饮用水水源地的义务作出约定，开展宣传教育，落实保护措施。”

6.将第十条修改为：“饮用水水源选址应当符合水功能区划。本市饮用水水源地名录按照国家和省有关规定执行。”

7.将第十八条第一款第三项修改为：“建设工业固体废物、建筑垃圾、危险废物集中贮存、利用、处置的设施、场所和生活垃圾填埋场”。

8.将第二十三条第一款、第二款修改为：“县（区）人民政府生态环境、住房城乡建设、农业农村、城市管理等部门应当根据职责组织实施乡镇和农村污水处理设施和管网以及垃圾收集处理设施建设，逐步改善饮用水水源汇水区的水质和生态环境。

市、县（区）人民政府应当加强饮用水水源保护区外调水沿线污染综合治理，参照饮用水水源地保护有关要求实施管理。”

9.将第二十四条修改为：“市、县（区）人民政府农业农村部门和其他有关部门，应当采取措施，指导农业生产者科学、合理施用化肥和农药，推广测土配方施肥技术和高效低毒低残留农药，加强农业面源污染防治。

畜禽散养密集区所在地县、乡级人民政府应当组织对畜禽粪便、污水进行分户收集、集中处理利用。”

10.将第三十六条改为第三十三条，修改为：“违反本条例规定，有下列行为之一的，由生态环境部门责令停止违法行为，处十万元以上五十万元以下罚款；并报经有批准权的人民政府批准，责令拆除或者关闭：

（一）在饮用水水源一级保护区内新建、改建、扩建与供水设施和水源保护无关的建设项目的；

（二）在饮用水水源二级保护区内新建、改建、扩建排放污染物的建设项目的；

（三）在饮用水水源准保护区内新建、扩建对水体污染严重的建设项目，或者改建建设项目增加排污量的。”

11.将第三十七条改为第三十四条，修改为：“违反本条例规定，在饮用水水源保护区内从事围网、网箱养殖，或者在饮用水水源一级保护区内组织进行旅游、游泳、垂钓、水上训练或者其他可能污染饮用水水体的活动的，由生态环境部门责令停止违法行为，处二万元以上十万元以下罚款。个人在饮用水水源一级保护区内游泳、垂钓或者从事其他可能污染饮用水水体的活动的，由生态环境部门责令停止违法行为，可以处五百元以下罚款。”

12.将第三十八条改为第三十五条，修改为：“违反本条例规定，在饮用水水源保护区内设置排污口的，由市、县（区）人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由生态环境部门处十万元以上五十万元以下的罚款；情节严重的，处五十万元以上一百万元以下的罚款，责令限制生产、停产整治。”

13.将第四十条改为第三十六条，修改为：“违反本条例规定，农药使用者有下列行为之一的，由农业农村部门责令改正，农药使用者为农产品生产企业、食品和食用农产品仓储企业、专业化病虫害防治服务组织和从事农产品生产的农民专业合作社等单位的，处五万元以上十万元以下罚款，农药使用者为个人的，处一万元以下罚款：

（一）在饮用水水源准保护区内使用剧毒、高毒、高残留农药的；

（二）在饮用水水源保护区内使用农药的。”

14.删去第十八条第一款第六项、第十八条第四款、第二十六条、第三十四条、第三十五条、第三十九条、第四十一条、第四十二条、第四十三条。

二、对《日照市海岸带保护与利用管理条例》作出修改

1.将第二十四条第二款第二项修改为：“倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾、建筑垃圾等固体废物。”

2.将第二十七条第三款修改为：“沿海防护林内禁止毁林开垦、采石、采砂、采土以及其他毁坏林木和林地行为。在森林防火期内，除依法批准的计划用火外，禁止在沿海防护林内和距离森林边缘五百米范围内实施烧荒、焚烧农作物废弃物料、燃放烟花爆竹、吸烟、野炊、祭祀用火、投放空中移动火源、爆破等工程用火以及其他易引发森林火灾的行为。”

3.将第三十条修改为：“市、区人民政府应当划定海岸带范围内水产养殖区、限养区。海上养殖区应当避开港口、航道、海上安全作业区，不得影响通航安全。海岸带范围内从事养殖生产应当依法办理养殖证。限养区的近岸海域，市、区人民政府可以划定一定的范围禁止筏式养殖、网箱养殖等水面设施养殖。”

4.将第三十一条第三款修改为：“畜禽散养密集区所在地县、乡级人民政府应当组织对畜禽粪便污水进行分户收集、集中处理利用。未实现分户收集、集中处理利用的散养户，应当采取必要的污染防治措施，妥善处理养殖废弃物，达到防渗、防雨、防溢流的要求。”

5.将第三十三条第二款修改为：“海岸带范围内从事生产、经营活动的单位和个人应当设置垃圾回收装置或者设施，及时收集清理垃圾，保持海岸带干净整洁。”

6.将第三十五条第一款修改为：“从事海水养殖，应当科学确定养殖密度和养殖规模，防止和减少病害，合理投饵、投饲、投药，养殖排放尾水应当符合有关污染物排放标准，防止造成海洋环境污染。”

7.将第三十八条第一款和第二款合并，作为第一款，修改为：“市、区人民政府应当建立台风、风暴潮、海浪、海啸、海冰等自然灾害预警预防体系，建设渔港、避风港等避灾避险设施。”

8.将第四十五条第二款修改为：“陆域水产养殖集中区所在地的区人民政府应当制定具体政策，支持、鼓励传统海水养殖业转型升级、高质量发展。加快限养区内不符合用水、环保等要求的养殖业升级改造，发展生态、安全、高效海水养殖，建设现代渔业园区。”

9.将第四十六条修改为：“市、区人民政府应当加强对海岸带保护、利用的监督管理，组织海洋发展、自然资源和规划、生态环境、发展改革、文化和旅游、交通运输、水利、应急管理、城市管理等有关部门定期研究海岸带保护与利用的现状与形势，讨论决定重大事项，全面高效落实海岸带保护与利用的属地责任。”

10.将第五十五条改为第五十二条，修改为：“违反本条例第二十三条规定，在严格保护区域开采海砂的，由负有生态环境保护监督管理职责的部门、机构按照职责分工责令改正，处货值金额二倍以上二十倍以下的罚款，货值金额不足十万元的，处二十万元以上二百万元以下的罚款。”

11.将第五十七条改为第五十四条，修改为：“违反本条例第三十条规定，在海岸带海域范围内未依法取得养殖证从事养殖生产的，或者在限养区内从事禁止的养殖活动的，由海洋发展部门责令限期改正，补办养殖证或者拆除养殖设施并恢复原状；逾期不改正的，依法强制拆除、代为恢复原状，所需费用由违法者承担。”

12.删去第五十二条、第五十三条、第五十四条、第五十八条。

三、对《日照市大气污染防治条例》作出修改

1.将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》《山东省大气污染防治条例》等有关法律、法规，结合本市实际，制定本条例。”

2.将第六条第二款修改为：“生态环境部门应当会同其他负有大气污染防治监督管理职责的部门，建立大气污染防治信息共享制度、案件移送制度，协同解决大气污染防治问题。”

3.将第九条修改为：“按照国务院生态环境主管部门制订并公布的排污许可分类管理名录，加强排污许可的监督管理。”

4.将第十一条改为第十条，第二款、第三款修改为：“生态环境监测应当使用符合法律、行政法规规定和国家标准的监测设施、设备，遵守有关监测规范。

禁止通过侵占、损毁或者擅自移动、改变等方式干扰、破坏生态环境监测设施、设备或者指使干扰、破坏生态环境监测设施、设备。”

5.将第十二条改为第十一条，修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照排污许可证的要求和有关标准规范，依法开展自行监测，建立管理台账，并保存原始监测记录和管理台账。原始监测记录和管理台账保存期限不得少于五年。

实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，并与生态环境部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。

实行排污许可重点管理的企业事业单位和其他生产经营者发现污染物排放自动监测设备传输数据异常，应当及时报告生态环境主管部门，并进行检查、修复。生态环境部门发现实行排污许可重点管理的企业事业单位和其他生产经营者的污染物排放自动监测设备传输数据异常，应当及时进行调查。”

6.将第十四条改为第十二条，第二款修改为：“市人民政府制定和调整生态环境分区管控方案，报省级人民政府生态环境主管部门备案后公布实施。”

7.将第二十一条改为第十八条，修改为：“市、县（区）人民政府应当制定本行政区域锅炉、窑炉整治计划，按照国家和省有关规定淘汰、拆除整治计划规定的直接燃煤、重油、渣油和直接燃用生物质的小锅炉、小型窑炉等设施。”

8.将第二十三条改为第二十条，第三款修改为：“工业企业大气污染物防治设施因突发故障不能正常使用的，应当立即抢修，采取应急措施确保排放达标。”

9.将第二十六条改为第二十三条，修改为：“生产、使用含挥发性有机物的原辅材料和产品，应当按照国家规定，在密闭空间、设备中进行并安装、使用污染防治设施，或者采取有效措施减少废气排放。”

10.将第三十一条改为第二十八条，第二款、第三款修改为：“机动车所有人和使用人应当保持机动车排气污染控制装置的正常运行。禁止破坏、拆除、篡改、屏蔽、伪造机动车排放控制系统。

机动车不得排放目视可见烟等排气污染物。”

11.将第三十二条改为第二十九条，修改为：“生态环境部门可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测；在不影响正常通行的情况下，可以通过非接触式道路监测等技术手段对在道路上行驶的机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测，公安机关交通管理部门予以配合。”

12.将第三十三条改为第三十条，修改为：“非道路移动机械所有人或者使用人应当定期对作业机械进行维修养护和排放检测，保证作业机械达到规定的排放标准；经维修或者采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当强制报废。”

13.将第三十四条改为第三十一条，修改为：“新建码头应当按照规定规划、设计和建设岸基供电设施；已建成的码头应当按照规定逐步实施岸基供电设施改造。具备岸电使用条件的船舶靠港应当按照国家规定使用岸电，但是使用清洁低碳能源的除外。”

14.将第四十二条改为第三十九条，第四款修改为：“禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。”

15.将第四十三条改为四十条，修改为：“从事畜禽养殖、屠宰生产经营活动的单位和个人，应当对畜禽养殖、屠宰产生的污水、废弃物进行及时收集、贮存、处理、处置和综合利用，防止对周边环境造成恶臭影响。

在居民住宅区、医院、学校、幼儿园、养老院等区域及其周边，禁止建设畜禽养殖场、屠宰场（厂），禁止从事烘干、晾晒畜禽粪便等活动。”

16.将第四十四条改为第四十一条，增加一款作为第一款：“市、县（区）人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。”

17.将第五十一条改为第四十五条，修改为：“违反本条例规定，石油炼化、有机化工、油脂以及生产、使用和储存挥发性有机溶剂的企业在计划开工、维修、检修、停工过程中，未对生产装置系统的停运、倒空、清洗等环节实施挥发性有机物排放控制的，由生态环境部门责令改正，处二万元以上二十万以下的罚款；拒不改正的，责令停产整治。”

18.将第五十二条改为第四十六条，修改为：“违反本条例规定，有下列行为之一，造成扬尘污染的，由住房城乡建设、城市管理等部门按照职责分工责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治：

（一）施工工地未对土方进行集中堆放并采取覆盖或者固化措施的；

（二）易产生扬尘的物料未进行覆盖的；

（三）拆迁工地未设立围挡，施工中未采取湿法作业等降尘措施的；

（四）爆破工程、基坑开挖、石方钻孔、路面切割、破碎、风钻挖掘地面、道路刨掘等土石方工程作业时，未采取相应的防尘、抑尘措施，带尘作业的。”

19.删去第十条、第十三条、第十七条、第三十八条第二款第一项、第四十八条、第四十九条、第五十条、第五十四条。

四、对《日照市生活垃圾分类管理条例》作出修改

1.将第一条修改为：“为了加强生活垃圾分类管理，改善人居环境，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》《中华人民共和国循环经济促进法》《山东省生活垃圾管理条例》等法律、法规，结合本市实际，制定本条例。”

2.将第三条修改为：“生活垃圾分类管理工作遵循政府推动、全民参与、城乡统筹、因地制宜、简便易行的原则，促进生活垃圾减量化、资源化和无害化。”

3.删去第六条。

4.将第十一条改为第十条，第三款修改为：“任何单位和个人不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾，不得将园林绿化垃圾、建筑垃圾、工业固体废物、农业固体废物等与生活垃圾混合投放。”

5.将第三十五条改为第三十四条，修改为：“鼓励社会组织、志愿者开展生活垃圾分类宣传、引导和服务等实践活动，倡导绿色生活方式，普及生活垃圾分类知识，促进公众养成生活垃圾分类习惯。”

6.将第四十二条改为第四十一条，修改为：“违反本条例第十条规定，未在指定的地点分类投放生活垃圾的，由综合行政执法部门责令改正；拒不改正的，对单位处五万元以上五十万元以下的罚款，对个人处五十元以上二百元以下的罚款。”

五、对《日照市阳光海岸生态保护条例》作出修改

1.将第一条修改为：“为了保护阳光海岸生态环境，规范阳光海岸自然资源管理与利用，根据《中华人民共和国生态环境保护法典》《中华人民共和国森林法》《中华人民共和国湿地保护法》等法律、法规，结合本市实际，制定本条例。”

2.将第五条第一款修改为：“市人民政府应当加强对阳光海岸生态保护工作的组织领导，研究解决阳光海岸生态保护的重大事项。”

3.将第二十条第二项修改为：“倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾、建筑垃圾等固体废物。”

4.将第二十二条第一款修改为：“东港区人民政府、山海天管委会应当加强污水协同治理，完善阳光海岸范围内的市政污水管网建设。禁止在阳光海岸范围内新设排污口。”

5.将第二十五条修改为：“市、区人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

阳光海岸范围内排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用，采取有效措施，使污染物达标排放。

任何单位、个人不得在阳光海岸范围内禁止的时段和区域露天烧烤食品，或者为露天烧烤食品提供场地。”

6.将第三十七条改为第三十六条，修改为：“违反本条例第十九条规定，在地下水限制开采区范围内擅自取用地下水的，由水行政主管部门或者综合行政执法部门依据职权责令停止违法行为，限期采取补救措施，处五万元以上五十万元以下的罚款。”

7.将第三十八条改为第三十七条，修改为：“违反本条例第二十条第一项规定，由生态环境部门、海洋发展部门、自然资源和规划部门或者综合行政执法部门依照《中华人民共和国生态环境法典》《中华人民共和国城乡规划法》《中华人民共和国海域使用管理法》的有关规定予以处罚。”

8.将第四十条改为第三十九条，修改为：“违反本条例第二十五条第三款规定，在阳光海岸范围内禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地的，由城市管理或者综合行政执法部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

9.删去第八条第四款、第三十六条、第三十九条。

此外，根据机构改革职能调整情况对有关部门单位职责和名称进行了调整，同时对相关条文顺序和个别文字作了修改。

本决定自2026年8月15日起施行。
