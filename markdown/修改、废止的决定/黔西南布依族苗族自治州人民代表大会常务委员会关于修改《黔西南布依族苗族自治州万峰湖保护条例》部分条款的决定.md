# 黔西南布依族苗族自治州人民代表大会常务委员会关于修改《黔西南布依族苗族自治州万峰湖保护条例》部分条款的决定

黔西南布依族苗族自治州
人民代表大会常务委员会关于修改
《黔西南布依族苗族自治州万峰湖保护条例》
部分条款的决定

（2026年6月30日黔西南布依族苗族自治州第九届人民代表大会常务委员会第三十五次会议通过）

黔西南布依族苗族自治州第九届人民代表大会常务委员会第三十五次会议决定对《黔西南布依族苗族自治州万峰湖保护条例》部分条款作如下修改：

一、将第一条中的“《中华人民共和国环境保护法》《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

二、将第五条第三款中的“本级人民代表大会常务委员会”修改为“本级人民代表大会或者人民代表大会常务委员会”；增加“对发生的重大生态环境事件应当及时向本级人民代表大会常务委员会报告，依法接受监督。”

三、第七条第一款修改为：“黔西南州人民政府和万峰湖保护区域县级人民政府根据依法批准的珠江流域水生态环境保护规划和万峰湖保护实际需要，可以组织编制万峰湖生态环境保护与发展规划。”

四、将第十八条第三项、第四项、第五项、第六项修改为七项，分别作为第三项、第四项、第五项、第六项、第七项、第八项、第九项，内容为：

“（三）向水体排放油类、酸液、碱液；

“（四）向水体排放剧毒废液，或者将含有汞、镉、砷、铬、铅、氰化物、黄磷等的可溶性剧毒废渣向水体排放、倾倒或者直接埋入地下；

“（五）在水体清洗装贮过油类、有毒有害污染物的车辆或者容器；

“（六）违反国家规定或者标准，向水体排放含热废水或者含病原体的污水；

“（七）向水体排放、倾倒工业废渣、城镇垃圾或者其他废弃物，或者向万峰湖及其最高水位线以下的滩地、岸坡以及法律法规规定的其他地点倾倒、堆放、贮存固体废物或者其他污染物；

“（八）擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物；

“（九）制造、销售禁用的渔具，销售非法捕捞的渔获物”。

五、删去第十九条第一项。

六、将第十九条第二项修改为两项，分别作为第一项、第二项，内容为：

“（一）船舶未配备相应的防污设备和器材，或者未持有合法有效的防止水域环境污染的证书与文书；

“（二）船舶向水体倾倒垃圾或者排放船舶的残油、废油、含油污水、生活污水”。

七、将第十九条第五项修改为两项，分别作为第五项、第六项，内容为：

“（五）使用炸鱼、毒鱼、电鱼等破坏渔业资源和渔业水域生态环境的方法进行捕捞；

“（六）使用禁用的渔具、小于最小网目尺寸的网具进行捕捞”。

八、将第二十条第三项、第四项、第五项、第六项合并修改为三项，作为第三项、第四项、第五项，内容为：

“（三）违反第三项、第四项、第五项、第六项、第七项的，由生态环境主管部门责令停止违法行为，采取治理措施消除污染，处以罚款，可以责令采取限制生产、停产整治等措施；拒不采取治理措施的，可以指定有治理能力的单位代为治理，所需费用由违法者承担；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。违反第五项、第六项的，处二万元以上二十万元以下的罚款。违反第三项、第七项的，处十万元以上一百万元以下的罚款。违反第四项的，处二十万元以上二百万元以下的罚款。

“（四）违反第八项，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物的，由生态环境主管部门、城镇排水主管部门、环境卫生主管部门按照职责分工责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。上述规定的固体废物为危险废物、城镇污水处理设施产生的污泥和处理后的污泥的，处二十万元以上二百万元以下的罚款；对直接负责的主管人员和其他直接责任人员处二万元以上十万元以下的罚款；造成严重后果的，处二百万元以上五百万元以下的罚款。个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾、建筑垃圾的，由环境卫生主管部门责令改正，处一百元以上一千元以下的罚款。

“（五）违反第九项的，由渔业渔政主管部门没收渔获物、违法所得和渔具，并处一万元以上十万元以下的罚款。”

九、第二十一条第一项、第二项、第五项修改为：

“（一）违反第一项的，由海事管理机构、渔业渔政主管部门按照职责分工责令限期改正，处五千元以上五万元以下的罚款；逾期不改正的，责令船舶临时停航。

“（二）违反第二项的，由海事管理机构、渔业渔政主管部门按照职责分工责令停止违法行为，处一万元以上十万元以下的罚款；造成水污染的，责令限期采取治理措施消除污染，处二万元以上二十万元以下的罚款；逾期不采取治理措施的，指定有治理能力的单位代为治理，所需费用由船舶承担。

“（五）违反第五项、第六项、第七项的，由渔业渔政主管部门没收装置、器具、渔具、有毒物质、渔获物和违法所得，并处二十万元以下的罚款；情节严重的，并处二十万元以上二百万元以下的罚款，吊销捕捞许可证，可以没收船舶。”

本决定自2026年8月15日起施行。

法规文本根据本决定作相应修改，部分条文作文字技术处理，条文顺序作相应调整，重新公布。
