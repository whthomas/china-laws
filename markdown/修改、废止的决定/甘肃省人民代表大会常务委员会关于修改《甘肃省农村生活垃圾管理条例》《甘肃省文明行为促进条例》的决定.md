# 甘肃省人民代表大会常务委员会关于修改《甘肃省农村生活垃圾管理条例》《甘肃省文明行为促进条例》的决定

甘肃省人民代表大会常务委员会关于修改
《甘肃省农村生活垃圾管理条例》《甘肃省
文明行为促进条例》的决定

（2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议通过）

甘肃省第十四届人民代表大会常务委员会第二十四次会议决定：

一、对《甘肃省农村生活垃圾管理条例》作出修改

（一）将第一条修改为：“为了加强和规范农村生活垃圾管理，保护和改善农村人居环境，推进乡村振兴战略实施，根据《中华人民共和国生态环境法典》等法律、行政法规，结合本省实际，制定本条例。”

（二）将第十三条第三款中的“物业服务企业”修改为“物业服务人”。

（三）将第三十三条修改为：“违反本条例规定，在生态保护红线区域、永久基本农田集中区域和其他需要特别保护的区域内建设农村生活垃圾填埋场的，由生态环境主管部门责令改正，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

（四）删去第三十四条。

（五）删去第三十五条第二款。

二、对《甘肃省文明行为促进条例》作出修改

（一）将第五条修改为：“县级以上承担精神文明建设工作的部门负责本行政区域内文明行为促进工作的指导、协调、监督、检查和宣传等事宜。”

（二）将第三十四条修改为：“承担精神文明建设工作的部门在开展精神文明建设先进典型选树宣传活动中，应当将文明行为表现情况作为推荐条件，依据有关规定，对文明行为促进工作进行文明程度指数测评。”

（三）将第四十七条第三款修改为：“违反本条例第十一条第五项规定，在当地人民政府禁止的时段和区域内露天烧烤食品或者为露天烧烤食品提供场地的，由县级以上人民政府确定的监督管理部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下的罚款；拒不改正的，处五千元以上二万元以下的罚款。”

本决定自2026年8月15日起施行。

《甘肃省农村生活垃圾管理条例》、《甘肃省文明行为促进条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
