# 深圳市人民代表大会常务委员会关于修改《深圳经济特区养老服务条例》的决定

深圳市人民代表大会常务委员会关于修改
《深圳经济特区养老服务条例》的决定

（2026年7月9日深圳市第七届人民代表大会常务委员会第四十八次会议通过）

深圳市第七届人民代表大会常务委员会第四十八次会议决定对《深圳经济特区养老服务条例》作如下修改：

一、将第十一条第二款修改为：“在符合国土空间规划和确保安全的前提下，鼓励利用商业、办公、工业、仓储存量房屋以及社区用房等举办养老服务机构。”

二、将第十四条第一款中的“新建或者城市更新项目”修改为“新建、改建或者扩建项目”。

三、将第十六条修改为：“市、区人民政府应当完善居家和社区养老服务体系，优先利用现有公共服务设施的闲置空间和资源，提升国有资产综合使用效益和养老服务水平，推动和支持社会力量，依托社区，按照就近便利、安全优质、价格合理的原则，为老年人提供下列服务：

“（一）日间托养、助餐、助浴、助洁、助行、代缴代购等；

“（二）居家护理、健康体检、健康管理、医疗康复、安宁疗护等；

“（三）关怀访视、心理咨询、情绪疏导等；

“（四）教育培训、文化娱乐、体育健身、休闲养生等；

“（五）安全指导、应急救助等；

“（六）法律和政策咨询、识骗防骗宣传、人民调解、法律援助等。”

四、将第四十一条第三款修改为：“市、区人民政府通过完善就业、志愿服务、社区治理等政策措施，鼓励和支持老年人根据其身体状况、知识技能特长、个人兴趣等情况，参与文明实践、公益慈善、志愿服务、科教文卫等事业。”

五、删去第四十四条中的“长期护理保险待遇、”。

六、将第四十六条修改为：“市、区人民政府应当统筹推进养老服务人才队伍建设，将养老服务人才培养纳入本市人才政策体系，培养和引进优秀养老服务人才，对符合条件的人才在居住落户、住房保障等方面提供政策支持。”

七、第五十一条增加一款，作为第二款：“长期护理保险具体办法由市医疗保障部门会同有关部门按照国家、广东省有关规定另行制定。”

八、删去第五十二条至第五十六条、第五十九条第一款、第七十一条第三款、第八十一条。

九、将第八十四条改为第七十八条，删去其中的“本条例规定的长期护理保险费自2021年10月1日起征缴，具体办法由市人民政府另行制定。”

本决定自公布之日起施行。

《深圳经济特区养老服务条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
