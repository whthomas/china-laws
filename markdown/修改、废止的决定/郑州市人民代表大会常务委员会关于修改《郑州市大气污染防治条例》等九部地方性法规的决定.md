# 郑州市人民代表大会常务委员会关于修改《郑州市大气污染防治条例》等九部地方性法规的决定

郑州市人民代表大会常务委员会
关于修改《郑州市大气污染防治条例》等
九部地方性法规的决定

（2026年6月30日郑州市第十六届人民代表大会常务委员会第二十九次会议通过　2026年8月1日河南省第十四届人民代表大会常务委员会第二十五次会议批准）

郑州市第十六届人民代表大会常务委员会第二十九次会议决定：

一、对《郑州市大气污染防治条例》作出修改

（一）将第一条修改为：“为了防治大气污染，保护和改善大气环境，保障公众健康和生态环境权益，维护生态安全，推动绿色低碳发展，建设生态文明，根据《中华人民共和国生态环境法典》等法律、法规，结合本市实际，制定本条例。”

（二）在第二条增加一款，作为第二款：“本条例未作规定的，适用有关法律、法规的规定。”

（三）将第三条修改为：“大气污染防治应当以改善大气环境质量为目标，坚持精准治污、科学治污、依法治污的方针，坚持统筹规划、源头防控、分类管理、社会共治。”

（四）将第五条修改为：“严格落实生态环境保护目标责任制和考核评价制度，将大气环境主要目标、大气污染治理重点任务完成情况纳入考核评价内容。考核评价工作应当增强针对性、实效性，力戒形式主义。考核结果应当向社会公开。”

（五）删去第六条第二款中的“市、县（市、区）”。

第三款修改为：“发展和改革、工业和信息化、公安、交通运输、城乡建设、城市管理、农业农村、林业、气象、卫生健康、市场监管、应急管理、园林、水行政、财政、商务、自然资源和规划等部门和机构应当在各自职责范围内，共同做好大气污染防治监督管理工作。”

（六）将第七条第一款修改为：“市人民政府应当组织生态环境、发展和改革、自然资源和规划等有关部门和县（市）、区人民政府，根据本市国土空间规划和国家、省有关规定，编制本市大气污染防治相关规划。”

删去第二款。

第三款改为第二款，其中的“防治规划”修改为“防治相关规划”。

（七）将第十条修改为：“市、县（市）、区人民政府应当制定重污染天气应对预案和突发大气污染事件应急预案，并按照规定备案；建立应急处理机制，设立环境应急指挥机构，组织、协调、指挥大气污染应急处理工作。”

（八）在第十一条第一款中的“完善大气环境”后增加“质量和大气污染源”。

第二款中的“气象行政主管部门”修改为“气象主管机构”。

（九）将第十四条第二款修改为：“公民、法人和其他组织发现各级人民政府及生态环境主管部门或者其他有关部门、机构不依法履行大气环境监督管理职责的，有权向其上级机关或者监察机关举报。”

（十）删去第十五条第二款中的“；举报内容经查证属实的，应当按照规定给予举报人表彰或者奖励”。

（十一）删去第十八条。

（十二）将第十九条改为第十八条，第二款修改为：“对大气污染物产生量、排放量或者对生态环境的影响程度较大的实行排污许可重点管理，对大气污染物产生量、排放量和对生态环境的影响程度都较小的实行排污许可简化管理。”

删去第三款。

（十三）将第二十一条改为第二十条，修改为：“新建、改建、扩建向大气排放污染物的建设项目，应当依法进行生态环境影响评价。

“建设项目中的污染防治设施，应当与主体工程同时设计、同时施工、同时投产使用。污染防治设施应当符合经批准的生态环境影响报告书、生态环境影响报告表的要求，不得擅自拆除或者闲置。

“建设项目在投入生产或者使用前，建设单位应当按照国家规定，对配套建设的污染防治设施进行验收。”

（十四）将第二十四条改为第二十三条，第一款修改为：“实行排污许可管理的企业事业单位和其他生产经营者应当按照排污许可证的要求和有关标准规范，依法开展自行监测，建立管理台账，并保存原始监测记录和管理台账。原始监测记录和管理台账保存期限不得少于五年。”

第二款修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，并与生态环境主管部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。”

删去第三款。

（十五）将第二十六条改为第二十五条，删去其中的“，并按照应急预案采取责令有关企业停产或者限产、限制部分机动车行驶、禁止燃放烟花爆竹、停止工地土石方作业和建筑拆除施工、停止露天烧烤、减少或者停止幼儿园和学校户外体育课等应急措施”。

增加一款，作为第二款：“市、县（市）、区人民政府应当依据重污染天气的预警等级，及时启动应对预案，根据应对的需要可以采取责令有关企业停产或者限产、限制部分机动车行驶和非道路移动机械使用、禁止燃放烟花爆竹、停止工地土石方作业和建筑物拆除施工、停止露天烧烤、停止幼儿园和学校组织的户外活动、组织开展人工影响天气作业等应对措施。”

（十六）将第二十七条改为第二十六条，第二款中的“市发展和改革行政主管部门”修改为“市发展和改革部门”。

（十七）将第二十八条改为第二十七条，删去第一款中的“市区”和“；县（市）、上街区的高污染燃料禁燃区范围由县（市）、上街区人民政府划定并公布”。

第二款修改为：“在禁燃区内，禁止销售、燃用高污染燃料；禁止新建、扩建燃用高污染燃料的设施，已建成的，应当在市人民政府规定的期限内改用天然气、页岩气、液化石油气、电或者其他清洁低碳能源。”

（十八）删去第二十九条。

（十九）将第三十一条改为第二十九条，在第一款中的“机动车船”后增加“、非道路移动机械及其发动机”。

删去第二款。

（二十）将第三十二条改为第三十条，修改为：“在用机动车排放污染物实行定期检验制度。未经检验合格的，公安机关交通管理部门不得核发安全技术检验合格标志。”

（二十一）将第三十三条改为第三十一条，第二款修改为：“生态环境主管部门在不影响正常通行的情况下，可以通过非接触式道路监测等技术手段对在道路上行驶的机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测，公安机关交通管理部门予以配合。”

（二十二）将第三十四条改为第三十二条，修改为：“生态环境主管部门可以在机动车集中停放地、维修地和重型汽车使用地对在用机动车的大气污染物排放状况、排放控制系统运行情况进行监督抽测。抽测不合格的，责令限期治理并复检。被抽测的机动车停放地管理单位、机动车所有人或者驾驶人员应当配合。”

（二十三）将第三十五条改为第三十三条，修改为：“机动车、非道路移动机械维修企业应当按照防治大气污染的要求和国家有关技术规范对在用机动车、非道路移动机械进行维修，使维修后的机动车、非道路移动机械达到规定的排放标准。交通运输、生态环境等有关部门应当在各自职责范围内依法加强监督管理。”

（二十四）将第三十六条改为第三十四条，在“机动车”后增加“、非道路移动机械”。

（二十五）将第三十七条改为第三十五条，第二款修改为：“禁止生产、进口、销售不符合标准的机动车船、非道路移动机械用燃料和氮氧化物还原剂。”

（二十六）将第三十八条改为第三十六条，第三款修改为：“市生态环境主管部门会同财政、交通运输、公安、商务、市场监管等部门，根据本市大气环境质量状况和机动车排放污染状况，制定高排放在用机动车淘汰、治理和限制使用方案，报市人民政府批准后实施。”

（二十七）将第三十九条改为第三十七条，修改为：“本市按照国家规定对机动车、非道路移动机械实行强制报废制度。机动车、非道路移动机械经维修、采用污染控制技术后，大气污染物排放仍不符合国家排放标准的，应当依法强制报废。”

（二十八）将第四十条改为第三十八条，修改为：“建设单位应当将扬尘污染防治费用列入工程造价，在施工合同中明确施工单位的扬尘污染防治责任。施工单位应当制定具体的施工扬尘污染防治实施方案。

“进行房屋建筑和市政基础设施施工、河道整治、建筑物拆除、园林绿化等活动，施工单位应当报负有扬尘污染防治监督管理职责的部门备案。”

（二十九）删去第四十一条。

（三十）将第四十二条改为第三十九条，在第一项中的“环保监督员”后增加“监督管理部门”。

删去第六项中的“进出口周边一百米以内的道路应当保持清洁，不得存留泥土和建筑垃圾”。

（三十一）将第四十六条改为第四十三条，第一项修改为：“（一）暂时不能开工的建设用地，建设单位负责对裸露地面进行覆盖；超过三个月的，应当进行绿化、铺装或者遮盖”。

删去第二项中的“绿化”。

（三十二）将第四十九条改为第四十六条，修改为：“在人口集中地区和其他依法需要特殊保护的区域内，不得开设产生恶臭、粉尘污染的修理、加工等场所，不得贮存、加工、制造或者使用产生恶臭气体的物质。在其他区域产生恶臭气体的，应当设置合理的防护距离，并安装净化装置或者采取其他有效措施，防止排放恶臭气体。”

（三十三）将第五十条改为第四十七条，删去第二款。

（三十四）将第五十一条改为第四十八条，第一款中的“；无法密闭的除外”修改为“，或者采取有效措施减少废气排放”。

（三十五）将第五十二条改为第四十九条，修改为：“禁止在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。

“禁止在人口集中地区、机场周围、交通干线附近以及省以上人民政府划定的其他区域和规定的时段露天焚烧农作物秸秆、落叶、枯草等产生烟尘污染的物质。”

（三十六）将第五十三条改为第五十条，第一款修改为：“任何单位和个人不得在当地人民政府禁止的时段和区域露天烧烤食品或者为露天烧烤食品提供场地。”

（三十七）将第五十四条改为第五十一条，修改为：“各级人民政府应当加强对餐饮服务业布局和设置的引导，在经营主体登记注册环节提示选址禁止性要求。

“排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用。专用油烟排放通道的排放口应当高于相邻建筑物高度或者接入其公用烟道。

“居民住宅楼内、未配套设立专用烟道的商住综合楼、商住综合楼内与居住层相邻的商业楼层内，禁止新建、改建、扩建产生油烟、异味、废气的餐饮服务项目。”

（三十八）将第五十六条改为第五十三条，删去其中的“市、县（市、区）”。

删去第一项。

删去第二项。

第三项改为第一项，修改为：“（一）违反本条例第二十七条第二款规定，在禁燃区内新建、扩建燃用高污染燃料设施的，没收燃用高污染燃料的设施并组织拆除，处二万元以上二十万元以下罚款”。

删去第四项。

第六项改为第三项，修改为：“（三）违反本条例第四十四条规定，未采取措施防治扬尘污染的，责令限期改正，处二万元以上二十万元以下罚款；逾期未改正的，责令停产整治”。

第七项改为第四项，修改为：“（四）违反本条例第四十六条规定的，责令限期改正，处一万元以上十万元以下罚款；逾期不改正的，责令停工整治或者停业整治”。

删去第八项。

（三十九）将第五十七条改为第五十四条，第一款修改为：“违反本条例第二十五条第二款规定，拒不执行停产、限产决定的，由生态环境主管部门处一万元以上十万元以下罚款；拒不执行停止工地土石方作业、建筑物拆除施工的，由城乡建设行政主管部门处一万元以上十万元以下罚款。”

（四十）将第五十八条改为第五十五条，第一款第一项修改为：“（一）违反本条例第二十七条第二款规定，在高污染燃料禁燃区内销售高污染燃料的，由市场监管部门责令改正，没收原材料、产品和违法所得，并处货值金额一倍以上五倍以下罚款；在禁燃区内未停止燃用高污染燃料的，由生态环境主管部门没收燃用高污染燃料的设施并组织拆除，处二万元以上二十万元以下罚款”。

第一款第三项修改为：“（三）违反本条例第四十条第一款规定，堆存、装卸作业单位或者个人未采取扬尘污染防治措施的，由市容和环境卫生行政主管部门、生态环境主管部门、城乡建设行政主管部门按照各自职责责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治或者停业整治”。

第一款第五项修改为：“（五）违反本条例第四十九条第一款规定的，由县（市）、区人民政府确定的监督管理部门责令改正，对单位处一万元以上十万元以下罚款，对个人处五百元以上二千元以下罚款；违反本条例第四十九条第二款规定的，由市、县（市）、区人民政府确定的监督管理部门责令改正，可以处五百元以上二千元以下罚款”。

第一款第六项修改为：“（六）违反本条例第五十条第一款规定的，由市容和环境卫生行政主管部门责令改正，没收烧烤工具和违法所得，并处五百元以上五千元以下罚款；拒不改正的，处五千元以上二万元以下罚款”。

第一款第七项修改为：“（七）违反本条例第五十一条第二款规定，排放油烟的餐饮服务业经营者未安装油烟净化等污染防治设施，未保持正常使用油烟净化等污染防治设施，或者未采取其他油烟净化措施，致使超过排放标准排放油烟污染物的，由生态环境主管部门责令改正，处五千元以上五万元以下罚款；拒不改正的，责令停业整治。”

（四十一）删去第五十九条。

（四十二）将第六十条改为第五十六条，删去第一项。
