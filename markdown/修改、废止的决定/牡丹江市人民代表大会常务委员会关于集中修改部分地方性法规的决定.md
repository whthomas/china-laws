# 牡丹江市人民代表大会常务委员会关于集中修改部分地方性法规的决定

牡丹江市人民代表大会常务委员会关于
集中修改部分地方性法规的决定

（2026年7月14日牡丹江市第十七届人民代表大会常务委员会第三十三次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

牡丹江市第十七届人民代表大会常务委员会第三十三次会议决定：

一、对《牡丹江市餐厨废弃物管理条例》作出修改

（一）将第一条修改为：“为了加强餐厨废弃物管理，促进餐厨废弃物资源化利用和无害化处理，维护城市环境卫生，保障食品安全和公众身体健康，根据有关法律、法规，结合本市实际，制定本条例。”

（二）删去第十二条第四项中的“在运输过程中不得遗撒、丢弃，”。

（三）将第二十二条修改为：“对于违反餐厨废弃物管理的行为，有关法律、法规已有行政处罚规定的，从其规定。”

（四）将法规中的“市容环境卫生行政主管部门”修改为“市人民政府环境卫生主管部门”。将第六条第二款中的“发展和改革”修改为“发展改革”。将第十条中的“收运”修改为“经营性收运”。将第二十五条中的“相关部门”修改为“有权机关”、“政务处分”修改为“处分”。

二、对《牡丹江市城市绿化条例》作出修改

（一）第二条增加一款，作为第二款：“城市古树名木的保护，依照《古树名木保护条例》的规定执行。”

删去第三十条、第三十九条。

（二）将第五条第一款修改为：“市城市绿化行政主管部门主管本市中心城区的城市绿化工作。”

将第十六条第三款、第三十五条、第三十六条、第三十七条、第三十八条中的“市城市绿化行政主管部门”修改为“城市绿化行政主管部门”。将第三十二条第一款中的“市城市绿化行政主管部门应当责令其养护管理单位及时根除”修改为“城市绿化行政主管部门应当责令其养护管理单位及时根除”。

（三）第十五条增加一款，作为第一款：“城市绿化应当科学选择绿化树种草种，加强监测评估，满足健康、安全、宜居的需求。”

（四）将第十三条、第十四条、第三十五条、第三十六条中的“建设工程项目”修改为“工程建设项目”。将第十四条中的“易地补建”修改为“异地补建”。

三、对《牡丹江市文明行为促进条例》作出修改

（一）将第十五条第七项修改为：“在商业经营活动中使用高音广播喇叭或者采用其他持续反复发出高噪声的方法进行广告宣传。”

（二）将第三十五条修改为：“对于本条例规定的不文明行为，有关法律、法规已有行政处罚规定的，由有关部门依法予以处罚。”

（三）将法规中的“行政机关”修改为“部门”。

四、对《镜泊湖水域船舶管理条例》作出修改

（一）将第一条修改为：“为了加强镜泊湖水域船舶管理，维护镜泊湖水域交通运输秩序，保护镜泊湖水域生态环境，根据有关法律、法规，结合实际，制定本条例。”

（二）删去第五条第一款中的“、航道”，将第五条第二款中的“防治”修改为“防治工作”。

（三）删去第十一条中的“防污、”。

第十一条增加一款，作为第一款：“镜泊湖水域的船舶应当按照国家规定配备相应的防污设备和器材，并持有合法有效的防治水域环境污染的证书与文书。”

（四）将第十二条第一款修改为：“禁止向镜泊湖水体排放船舶的残油、废油、含油污水、生活污水。”

增加一款，作为第二款：“禁止向镜泊湖水体倾倒船舶垃圾。”

（五）将第二十二条修改为：“违反本条例第十一条、第十二条规定，有下列情形之一的，由牡丹江海事管理机构、牡丹江市人民政府有关部门按照职责分工依法予以处罚或者处理：

“（一）船舶未配备相应的防污设备和器材，或者未持有合法有效的防治水域环境污染的证书与文书；

“（二）船舶向镜泊湖水体倾倒垃圾或者排放船舶的残油、废油、含油污水、生活污水；

“（三）船舶未配置相应的救生、通讯、消防、定位、应急等设备和器材，并保持良好的技术状态。”

五、对《牡丹江市废弃食用菌菌包污染环境防治和综合利用条例》作出修改

（一）将法规名称修改为“牡丹江市废弃食用菌菌包污染防治和综合利用条例”。将法规中的“污染环境防治”修改为“污染防治”。

（二）将第一条修改为：“为了加强废弃食用菌菌包污染防治，促进废弃食用菌菌包综合利用，保障食用菌产业可持续发展，推进生态文明建设，根据有关法律、法规，结合本市实际，制定本条例。”

（三）将第三条改为两条，作为第三条、第四条，修改为：

“第三条废弃食用菌菌包污染防治坚持减量化、资源化和无害化的原则，加强产生、收集、贮存、运输、利用、处置等全过程管控。

“第四条市、县（市）区、乡镇人民政府应当加强废弃食用菌菌包污染防治和综合利用工作，正确处理食用菌产业发展和生态环境保护的关系，建立政府主导、部门协同、社会参与、因地制宜的工作体系。”

（四）将第四条改为第五条，第一款修改为：“市、县（市）区人民政府应当组织、协调、督促有关部门依法履行废弃食用菌菌包污染防治和综合利用监督管理职责。”

（五）将第五条改为第六条，第一款中的“本市”修改为“本市行政区域”。

第三款修改为：“市、县（市）区人民政府发展改革、财政、工业和信息化、自然资源、林业草原、水务、公安等有关部门，在各自职责范围内对废弃食用菌菌包污染防治工作实施监督管理。”

（六）删去第八条、第九条、第十条。

（七）将第二十条修改为：“产生废弃食用菌菌包的单位和其他生产经营者，应当采取回收利用和其他防止污染环境的措施。”

（八）将第二十一条改为三条，作为第九条、第十条、第二十一条，修改为：

“第九条禁止向江河湖泊、运河、渠道、水库及其最高水位线以下的滩地和岸坡以及法律法规规定的其他地点倾倒、堆放、贮存废弃食用菌菌包。

“第十条禁止向水体倾倒废弃食用菌菌包。

“第二十一条产生、收集、贮存、运输、利用、处置废弃食用菌菌包的单位和其他生产经营者，应当采取防扬散、防流失、防渗漏或者其他防止污染环境的措施，不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧废弃食用菌菌包。”

（九）将第二十四条修改为：“违反本条例规定，有下列情形之一的，由生态环境主管部门依法予以处罚：

“（一）向江河湖泊、运河、渠道、水库及其最高水位线以下的滩地、岸坡以及法律法规规定的其他地点倾倒、堆放、贮存废弃食用菌菌包；

“（二）向水体倾倒废弃食用菌菌包；

“（三）擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧废弃食用菌菌包。

“擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧废弃食用菌菌包，造成严重后果的，由公安机关依法予以处罚。”

本决定自公布之日起施行。

《牡丹江市餐厨废弃物管理条例》、《牡丹江市城市绿化条例》、《牡丹江市文明行为促进条例》、《镜泊湖水域船舶管理条例》、《牡丹江市废弃食用菌菌包污染环境防治和综合利用条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
