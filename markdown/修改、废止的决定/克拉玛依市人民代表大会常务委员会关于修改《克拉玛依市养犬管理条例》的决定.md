# 克拉玛依市人民代表大会常务委员会关于修改《克拉玛依市养犬管理条例》的决定

克拉玛依市人民代表大会常务委员会关于修改
《克拉玛依市养犬管理条例》的决定

（2026年6月24日克拉玛依市第十五届人民代表大会常务委员会第三十五次会议通过　2026年7月29日新疆维吾尔自治区第十四届人民代表大会常务委员会第三十次会议批准）

克拉玛依市第十五届人民代表大会常务委员会第三十五次会议决定对《克拉玛依市养犬管理条例》作如下修改：

一、将第二条中的“管理活动”修改为“经营和管理活动”。

二、将第五条第一款修改为：“市住房和城乡建设部门主管本市养犬管理工作，组织实施本条例。区城市管理部门负责本行政区域内的犬只登记、收容、流浪犬治理等工作，查处养犬相关违法行为。”

第二款修改为：“公安机关负责捕杀狂犬，依法处理犬只扰民、放任犬只恐吓他人、驱使犬只伤害他人，出售、饲养烈性犬等违法行为，协助做好流浪犬治理工作。”

第三款修改为：“农业农村部门负责犬只诊疗、防疫的监督管理，指导死亡犬只无害化处理，查处违反犬只强制免疫规定的行为。”

第五款中的“发展和改革”修改为“发展改革”。

三、将第六条中“物业服务企业”修改为“物业服务人”。

四、将第八条第一款中的“从事”修改为“开展”。

在第八条中增加一款，作为第二款：“鼓励养犬人、犬只诊疗机构、相关经营者等成立养犬协会，加强行业规范和自律，开展文明养犬宣传、犬只收容救助等公益活动，引导养犬人依法养犬、文明养犬。”

第二款改为第三款，修改为：“提倡养犬人对饲养的犬只实施绝育措施。鼓励养犬人购买犬只相关保险。”

五、将第十一条第四款修改为：“烈性犬名录由市农业农村部门会同市公安机关、市住房和城乡建设部门确定，报市人民政府批准后向社会公布，并定期更新名录。”

六、将第十二条第一款中的“狂犬病免疫点”修改为“狂犬病免疫接种点”。

删去第二款中的“犬只在接种狂犬病疫苗时，应当植入电子身份标识。”

增加一款，作为第四款：“犬只在接种狂犬病疫苗时，无电子身份标识的，应当植入电子身份标识，电子身份标识载明的信息应当与免疫证明内容一致。”

七、将第十三条第三款修改为：“区城市管理部门可以将农业农村部门依法确定的狂犬病免疫接种点作为养犬登记场所，为犬只免疫和养犬登记提供‘一站式’便民服务。”

八、将第十四条第一款修改为：“养犬人姓名或者单位名称、联系方式、养犬地址等信息发生变更的，养犬人应当自信息变更之日起十五日内办理养犬变更登记手续。”

九、删去第十六条第一款中的“住房和城乡建设”和“定期治理辖区内的流浪犬，对捕获的流浪犬只，应当送交犬只收容机构”。

十、增加一条，作为第十七条：“区人民政府应当开展流浪犬只的专项治理，支持执法队伍配备必要的专业抓捕工具和防护装备。对捕获的流浪犬只，除养犬人领回的，应当送交犬只收容机构；必要时，对危害群众生命和财产安全的狂犬、野犬进行捕杀。”

十一、将第十七条改为第十八条，并将第一款第三项中的“延续”修改为“变更”。

十二、将第二十条改为第二十一条，并将第一款修改为：“下列区域除设有为犬只提供服务的场所外，禁止携带犬只进入：

“（一）机关、团体、企事业单位的办公场所；

“（二）学校、幼儿园及其他少年儿童活动场所；

“（三）医院、诊所等医疗场所，但动物诊疗机构除外；

“（四）金融、通讯、市场、商场（超市）、饭店等经营场所；

“（五）体育场（馆）、科技馆、博物馆、展览馆、影剧院、图书馆等文体活动场所；

“（六）公共交通工具和候车室、候机室；

“（七）文物保护单位、养老机构及宗教活动场所；

“（八）区人民政府划定的其他公共场所。”

增加一款作为第二款：“宾馆、旅游景区、公园、广场等公共户外休闲场所禁止携带犬只进入的，应当设置明显的禁入标志。”

删除第四款。

十三、将第二十二条改为第二十三条，并删去第二款中的“养犬人接到领回通知之日起满一个月未领回犬只的，视为遗弃。”

十四、将第二十四条改为第二十五条，修改为：“区人民政府可以设置专门的犬只交易市场。区市场监督管理、城市管理、农业农村部门和公安机关依法对犬只交易进行规范管理，及时发现和查处违法交易犬只的行为。”

十五、将第二十七条改为第二十八条，将第一款第一项中的“延续”修改为“变更”；

删去第三项；

将第七项改为第六项，删去其中的“未佩戴犬牌”和“之一”；

删去第十项；

将第十一项改为第九项，删去其中的“扰民或者”。

十六、将第二十九条改为第三十条，将“依法处理”修改为“依法处分”。

此外，对条文序号作了相应调整。

本决定自公布之日起施行。

《克拉玛依市养犬管理条例》根据本决定作相应修改，并对条文顺序作相应调整，重新公布。
