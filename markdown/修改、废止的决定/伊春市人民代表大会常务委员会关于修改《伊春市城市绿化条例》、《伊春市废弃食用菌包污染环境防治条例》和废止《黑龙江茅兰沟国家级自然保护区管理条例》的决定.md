# 伊春市人民代表大会常务委员会关于修改《伊春市城市绿化条例》、《伊春市废弃食用菌包污染环境防治条例》和废止《黑龙江茅兰沟国家级自然保护区管理条例》的决定

伊春市人民代表大会常务委员会
关于修改《伊春市城市绿化条例》、《伊春市
废弃食用菌包污染环境防治条例》和废止
《黑龙江茅兰沟国家级自然保护区管理
条例》的决定

（2026年8月28日伊春市第十五届人民代表大会常务委员会第三十七次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

伊春市第十五届人民代表大会常务委员会第三十七次会议决定：

一、对《伊春市城市绿化条例》作出修改

（一）删去第二十八条。

（二）删去第三十五条第二款。

（三）删去第四十条。

（四）将第四十一条中的“第三十一条”修改为“第三十条”。

（五）将第四十二条中的“给予行政处分”修改为“依法给予处分”。

（六）增加一条，作为第四十一条：“违反本条例，法律、法规另有规定的，从其规定。”

二、对《伊春市废弃食用菌包污染环境防治条例》作出修改

（一）删去第六条第一款中的“、县（市）区”。

（二）将第十六条第一款修改为：“产生、收集、贮存、运输、利用、处置废弃食用菌包的单位和个人应当承担污染环境防治主体责任，建立健全污染环境防治责任制度，采取防扬散、防流失、防渗漏或者其他防止污染环境的措施，不得擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧废弃食用菌包。”删去第二款中的“、填埋”。

三、废止《黑龙江茅兰沟国家级自然保护区管理条例》

本决定自公布之日起施行。

《伊春市城市绿化条例》、《伊春市废弃食用菌包污染环境防治条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
