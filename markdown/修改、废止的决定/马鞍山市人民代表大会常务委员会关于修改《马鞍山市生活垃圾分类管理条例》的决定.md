# 马鞍山市人民代表大会常务委员会关于修改《马鞍山市生活垃圾分类管理条例》的决定

马鞍山市人民代表大会常务委员会关于修改《马鞍山市生活垃圾分类管理
条例》的决定

（2026年6月25日马鞍山市第十七届人民代表大会常务委员会第三十七次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

马鞍山市第十七届人民代表大会常务委员会第三十七次会议决定对《马鞍山市生活垃圾分类管理条例》作如下修改：

一、将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

二、将第三十六条修改为“违反本条例第十九条规定，未在指定的地点分类投放生活垃圾的，由城市管理行政执法部门责令改正；拒不改正的，对个人处一百元以上一千元以下罚款，对单位处五万元以上五十万元以下罚款。”

三、将第三十七条修改为“违反本条例第二十一条规定，未按照规定配置生活垃圾分类收集容器的，或者将分类过的生活垃圾混合驳运的，由城市管理行政执法部门责令立即改正；拒不改正的，处一千元以上五千元以下罚款。”

四、将第三十八条修改为“违反本条例规定，从事生活垃圾分类收集、运输的单位有下列行为之一的，由城市管理行政执法部门按照下列规定处理：

（一）违反本条例第二十六条第二款规定，未按照城市管理行政主管部门规定的路线运输的，责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。

（二）违反本条例第二十七条第二项规定，将已经分类交付的生活垃圾随意倾倒的，责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治。

（三）违反本条例第二十七条第三项规定，收集运输车辆未保持密闭等措施防止抛撒滴漏的，责令改正，处二千元以上二万元以下罚款；拒不改正的，车辆不得上道路行驶。”

本决定自2026年8月15日起施行。

《马鞍山市生活垃圾分类管理条例》根据本决定作相应修改，重新公布。
