# 安庆市人民代表大会常务委员会关于修改部分地方性法规的决定

安庆市人民代表大会常务委员会关于
修改部分地方性法规的决定

（2026年6月29日安庆市第十八届人民代表大会常务委员会第三十二次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为保证《中华人民共和国生态环境法典》在我市的贯彻实施，维护国家法制的统一、尊严和权威，促进经济社会发展，安庆市第十八届人民代表大会常务委员会第三十二次会议决定，对《安庆市城市管理条例》《安庆市天柱山风景名胜区条例》《安庆市花亭湖风景名胜区条例》《安庆市菱湖风景区条例》四部地方性法规作如下修改：

一、对《安庆市城市管理条例》作出修改

（一）将第十二条第一款修改为：“从事建筑垃圾运输的单位，应当依法向城市管理主管部门申请办理核准手续；未取得核准的，不得从事建筑垃圾运输活动。”

（二）将第二十一条第二款修改为：“任何单位和个人不得擅自砍伐城市绿化树木。确需砍伐的，应当经城市绿化主管部门批准。”

（三）将第二十四条第一款第（八）项修改为：“十二时至十四时、二十二时至次日六时除抢修、抢险作业外，禁止在噪声敏感建筑物集中区域内从事产生环境噪声污染的建筑施工作业；因为特殊施工需要必须连续作业的应当报经城市管理主管部门批准并公布。”

（四）将第五十五条修改为：“违反本条例第二十四条第一款第一、二、四项规定的，由城市管理主管部门责令改正，处五千元以上五万元以下的罚款；拒不改正的，处五万元以上二十万元以下的罚款，并可以报经有批准权的人民政府批准，责令停业；违反本条例第二十四条第一款第三、五、七项规定的，由城市管理主管部门说服教育，责令改正，拒不改正的，给予警告，对个人可以处二百元以上一千元以下的罚款，对单位可以处二千元以上二万元以下的罚款；违反本条例第二十四条第一款第六项规定的，由城市管理主管部门责令改正，可以并处二百元以上五百元以下的罚款；违反本条例第二十四条第一款第八项规定的，由城市管理主管部门责令改正，处一万元以上十万元以下的罚款；拒不改正的，可以责令暂停施工。

违反本条例第二十四条第二款规定，中考、高考期间以及市、县（市）人民政府规定的其他特殊时段在噪声敏感建筑物集中区域内从事产生噪声的施工作业的，由城市管理主管部门责令改正，并处一万元以上三万元以下的罚款。”

二、对《安庆市天柱山风景名胜区条例》作出修改

（一）将第二十一条第（八）项修改为：“擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧垃圾以及其他固体废物；”

（二）将第三十八条第（五）项修改为：“违反第八项规定，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物的，处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担；个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾、建筑垃圾的，处一百元以上一千元以下的罚款。”

三、对《安庆市花亭湖风景名胜区条例》作出修改

（一）将第二十条第（四）项修改为：“擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧垃圾以及其他固体废物；”

（二）将第二十条第（五）项修改为：“在道路、水上运输易飘洒散装货物不采取密闭或者其他措施防止物料遗撒；”

（三）删去第二十条第（七）项。

（四）将第三十六条第（二）项修改为：“违反第四项规定，在风景区内擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧固体废物的，处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担；个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾、建筑垃圾的，处一百元以上一千元以下的罚款；”

（五）将第三十六条第（三）项修改为：“违反第五项规定，在风景区道路、水上运输易飘洒散装货物未采取密闭或者其他措施防止物料遗撒，处二千元以上二万元以下的罚款；拒不改正的，车辆不得上道路行驶；”

（六）将第三十六条第（四）项修改为：“违反第六项规定，在风景区内景物上刻划、涂污的，处五十元的罚款；刻划、涂污或者以其他方式故意损坏文物、名胜古迹，构成违反治安管理行为的，按照治安管理处罚法的有关规定予以处罚；构成犯罪的，依法追究刑事责任；”

四、对《安庆市菱湖风景区条例》作出修改

（一）将第十二条第一项修改为：“擅自占用、围圈、填埋、遮掩、堵截水体或者水面，挖砂取土，倾倒、堆放、丢弃、抛撒、遗撒垃圾以及其他固体废物，改变风景区建成区地形地貌、水体形状；”

本决定自2026年8月15日起施行。

《安庆市城市管理条例》《安庆市天柱山风景名胜区条例》《安庆市花亭湖风景名胜区条例》《安庆市菱湖风景区条例》根据本决定作相应修改，重新公布。
