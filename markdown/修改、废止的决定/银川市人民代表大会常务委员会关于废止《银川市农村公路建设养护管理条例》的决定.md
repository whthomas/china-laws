# 银川市人民代表大会常务委员会关于废止《银川市农村公路建设养护管理条例》的决定

银川市人民代表大会常务委员会
关于废止《银川市农村公路建设养护管理
条例》的决定

（2026年7月2日银川市第十六届人民代表大会常务委员会第三十八次会议通过　2026年7月31日宁夏回族自治区第十三届人民代表大会常务委员会第二十六次会议批准）

银川市第十六届人民代表大会常务委员会第三十八次会议决定，废止《银川市农村公路建设养护管理条例》（2006年3月22日银川市第十二届人民代表大会常务委员会第十四次会议通过　2006年5月12日宁夏回族自治区第九届人民代表大会常务委员会第二十二次会议批准）。

本决定自公布之日起施行。
