# 黑龙江省人民代表大会常务委员会关于修改、废止《黑龙江省大气污染防治条例》等二十一部地方性法规和法规性质决定的决定

黑龙江省人民代表大会常务委员会关于
修改、废止《黑龙江省大气污染防治条例》等
二十一部地方性法规和法规性质决定的决定

（2026年7月30日黑龙江省第十四届人民代表大会常务委员会第二十九次会议通过）

黑龙江省第十四届人民代表大会常务委员会第二十九次会议决定：

一、修改5部地方性法规

（一）修改《黑龙江省大气污染防治条例》

第一条修改为：“为了保护生态环境，防治大气污染，保障公众健康，推进生态文明建设，根据有关法律、行政法规，结合本省实际，制定本条例。”

第三条修改为：“防治大气污染，应当以改善大气环境质量为目标，转变经济发展方式，优化产业结构和布局，调整能源结构、交通运输结构。”

第四条第一款修改为：“设区的市级以上人民政府编制规划，采取有效措施，控制或者逐步削减大气污染物的排放量，使大气环境质量达到规定标准并逐步改善。”删去第二款中的“优化产业结构和布局，”。

第五条第一款中的“县级以上生态环境主管部门”修改为“设区的市级以上人民政府生态环境主管部门”；第二款中的“县级以上其他有关行政主管部门”修改为“县级以上人民政府其他有关部门”，“发展和改革”修改为“发展改革”，“住房和城乡建设”修改为“住房城乡建设”，“农业行政主管部门”修改为“农业农村主管部门”。

第六条修改为：“企业事业单位和其他生产经营者应当采取有效措施，防止和减少大气污染和生态破坏，节约集约利用资源，控制温室气体排放，履行绿色低碳发展义务，对所造成的损害依法承担责任。

“公民应当增强大气环境保护意识，采取简约适度、绿色低碳的生活方式，自觉履行大气环境保护义务，遵守生态环境法律法规，配合实施大气环境保护措施。”

删去第八条、第九条。

第十条改为第八条，其中的“环境影响评价”修改为“生态环境影响评价”，删去“、公开环境影响评价文件”。

第十一条改为第九条，第二款修改为：“配套建设的大气污染防治设施，应当与主体工程同时设计、同时施工、同时投产使用，污染防治设施应当符合经批准的生态环境影响报告书、生态环境影响报告表的要求，不得擅自拆除或者闲置。”增加一款，作为第三款：“建设项目在投入生产或者使用前，建设单位应当按照国家规定，对配套建设的污染防治设施进行验收。”

第十二条改为第十条，删去第一款；第二款中的“应当按照排污许可证的要求排放大气污染物；”修改为“应当按照规定取得排污许可证，”。

第十三条改为第十一条，删去第一款；第二款中的“按照国务院下达的总量控制目标”修改为“分解落实国务院下达的总量控制指标”。

第十四条改为第十二条，修改为：“省生态环境主管部门对超过重点大气污染物排放总量控制指标或者未完成大气环境质量目标的地区，应当暂停审批该地区新增重点大气污染物排放总量的建设项目的生态环境影响报告书、生态环境影响报告表。”

删去第十五条。

第十六条改为第十三条，修改为：“未达到国家大气环境质量标准的地区所在设区的市级、县级人民政府，应当按照国家和省大气污染防治目标要求和区域大气环境质量状况，及时编制大气环境质量限期达标规划，并采取有效措施，按照规定的期限达到大气环境质量标准。”

第十七条改为第十四条，第一款修改为：“设区的市级以上人民政府生态环境主管部门负责组织建设与管理本行政区域大气环境质量和大气污染源监测网络，开展大气环境质量和大气污染源监测。”第二款中的“站（点）”修改为“站点”，“有关监测技术规范要求”修改为“法律法规规定和有关监测规范要求”；第三款中的“站（点）”修改为“站点”。

第十九条改为第十六条，其中的“县级以上生态环境主管部门”修改为“生态环境主管部门”。

删去第二十条至第二十二条。

第二十三条改为第十七条，第二款中的“县级以上生态环境主管部门”修改为“设区的市级以上人民政府生态环境主管部门”。

第二十四条改为第十八条，修改为：“任何单位和个人有权对污染大气环境的行为，向生态环境主管部门或者其他负有大气环境保护监督管理职责的部门举报。

“生态环境主管部门和其他负有大气环境保护监督管理职责的部门，应当公布举报电话、电子邮箱等高效便捷的举报渠道，方便公众举报。举报的违法行为属于本部门职责范围的，应当及时核实、处理，并答复实名举报人；不属于本部门职责范围的，应当及时移交有权处理的部门，并告知实名举报人。

“县级以上人民政府可以公布统一的举报方式。

“接受举报的机关应当及时处理并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。”

第二十五条改为第十九条，第一款中的“县级以上生态环境主管部门”修改为“生态环境主管部门”，“并将大气环境违法信息记入社会诚信档案，及时通过省信用信息共享交换平台等向社会公布”修改为“依法将企业事业单位和其他生产经营者有关大气环境违法信息记入信用记录”；增加一款，作为第二款：“企业事业单位和其他生产经营者纠正失信行为、消除不良影响、符合信用修复条件的，可以提出信用修复申请，有关国家机关应当按照规定开展信用修复。”

第二十七条改为第二十一条，其中的“县级以上生态环境主管部门”修改为“生态环境主管部门”。

删去第二十八条。

第二十九条改为第二十二条，修改为：“各级人民政府应当优化煤炭使用方式，减少煤炭生产、贮存、运输、使用、转化过程中的大气污染物排放。”

第三十三条改为第二十六条，修改为：“工业和信息化、供热行政主管、生态环境主管部门分别负责工业锅炉、供热锅炉、商业经营锅炉淘汰的具体工作。”

第三十六条改为第二十九条，修改为：“各级人民政府应当采取有效措施，加强散煤管理，禁止销售不符合散煤质量标准的煤炭，鼓励、支持采取清洁低碳能源、集中供热替代等措施防治燃用散煤造成大气污染。”

删去第三十八条至第四十条。

第四十一条改为第三十一条，第一款修改为：“石油化工及其他生产、使用有机溶剂的企业应当采取有效措施，对管道、设备进行日常维护、维修，减少物料泄漏，及时收集处理泄漏物料。”第二款中的“垃圾填埋活动”修改为“工业生产、垃圾填埋和其他活动”。

第四十三条改为第三十三条，其中的“农业行政主管部门”修改为“农业农村主管部门”，“科学合理使用农药、化肥和除草剂等农业投入品”修改为“科学合理安全使用农业投入品”。

第四十四条改为第三十四条，第一款修改为：“各级人民政府应当制定鼓励和支持政策，推广秸秆肥料化、饲料化、能源化、原料化、基料化等综合利用，组织建立健全秸秆收集、贮存、运输、处置和综合利用服务体系，采用财政补贴等措施支持农村集体经济组织、农民专业合作社、企业等开展秸秆收集、贮存、运输、处置和综合利用服务。”第二款中的“发展和改革”修改为“发展改革”；第三款中的“农业行政主管部门”修改为“农业农村主管部门”。

第四十五条改为第三十五条，修改为：“各级人民政府应当科学精准加强秸秆等焚烧的组织、指导和管理。禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆等产生烟尘污染的物质。

“设区的市级、县级、乡（镇）人民政府对辖区内秸秆焚烧管控工作负总责，政府主要负责人是第一责任人，分管负责人是具体责任人，建立和完善秸秆焚烧管控工作责任制，逐级签订责任状，明确单位和个人的具体责任。设区的市级以上人民政府生态环境主管部门具体负责秸秆焚烧管控工作。”

第四十六条改为第三十六条，第一款修改为：“从事畜禽养殖和屠宰的单位和个人应当采取有效措施，及时对畜禽粪污和尸体等废弃物进行收集、贮存、清运、无害化处理和资源化利用，根据养殖规模和污染防治需要，建设相应的恶臭气体和其他大气污染物防治设施，并按照规定标准排放大气污染物。”第二款中的“畜禽粪便”修改为“畜禽粪污”。

第四十七条改为第三十七条，其中的“城市人民政府”修改为“县级以上人民政府”。

第五十一条改为第四十一条，第一款、第二款修改为：“达到国家强制报废标准的在用机动车、非道路移动机械等，应当按照国家有关规定进行登记、拆解、销毁等处理。

“县级以上人民政府可以根据大气环境质量状况，划定并公布禁止使用高排放非道路移动机械的区域。”

删去第五十二条第二款。

第五十四条改为第四十四条，第二款第一项中的“住房和城乡建设”修改为“住房城乡建设”。

第五十五条改为第四十五条，其中的“施工承包合同”修改为“施工合同”；第二项中的“扬尘监督管理主管部门”修改为“监督管理部门”。

第五十六条改为第四十六条，第二款修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆和船舶，应当采取密闭或者其他有效措施防止物料遗撒、泄漏造成扬尘污染，并按照规定的路线和时间行驶。”

第五十九条改为第四十九条，第一款修改为：“排放油烟污染物的餐饮服务业经营者应当按照规定安装油烟净化等污染防治设施并保持正常使用，采取有效措施，使污染物达标排放，并防止对附近居民的正常生活环境造成污染。”第三款中的“禁止的区域内”修改为“禁止的时段和区域”。

第六十四条改为第五十四条，删去第二款中的“重点排污单位、”。

删去第六十六条、第六十八条。

第七十条改为第五十八条，修改为：“设区的市级以上人民政府生态环境主管部门会同气象等有关部门建立健全本行政区域重污染天气监测预警、会商和信息通报等机制，完善重污染天气预测预报体系。”

第七十一条改为第五十九条，第一款修改为：“设区的市级以上人民政府和可能发生重污染天气的县级人民政府，应当制定重污染天气应对预案，报上一级人民政府生态环境主管部门备案，向社会公布，并根据实际需要和情势变化适时修订。”删去第二款。

第七十二条改为第六十条，第一款修改为：“设区的市级以上人民政府负责重污染天气预警的发布、调整和解除，任何单位和个人不得擅自发布重污染天气预报预警信息。”第二款中的“县级以上人民政府”修改为“人民政府”。

第七十三条改为第六十一条，第一款中的“应急”修改为“应对”，第一款第二项修改为“限制部分机动车行驶和非道路移动机械使用”；第二款中的“应急措施”修改为“应对措施”。

删去第七十五条至第八十二条。

第八十三条改为第六十三条，修改为：“违反本条例规定，在禁止露天焚烧秸秆的区域和时段内露天焚烧秸秆的，由设区的市级以上人民政府生态环境主管部门责令改正，并可以处五百元以上二千元以下的罚款。”

第八十六条改为第六十六条，修改为：“违反本条例规定，施工单位有下列情形之一的，由县级以上住房城乡建设部门按照职责分工责令改正，处一万元以上十万元以下的罚款；拒不改正的，责令停工整治：

“（一）违反本条例规定，未在施工工地设置硬质围挡并负责维护，或者未在施工工地出入口、主要通道、加工区等采取硬化处理措施，或者未对施工工地内堆存的建筑土方、工程渣土、建筑垃圾采取密闭式防尘网遮盖，或者未在施工工地建筑结构脚手架外侧设置有效抑尘密闭式防尘网的；

“（二）违反本条例规定，未在施工工地公示扬尘污染防治措施、负责人、扬尘监督管理主管部门等信息，或者未在施工工地出口设置车辆冲洗设施，或者在施工工地通道以及出入口周边的道路存放建筑垃圾，或者未采取封闭方式及时清运建筑垃圾的。”

删去第八十九条、第九十一条、第九十二条、第九十五条至第九十七条。

（二）修改《黑龙江省野生动物保护条例》

第二条第二款修改为：“本条例规定保护的野生动物，是指珍贵、濒危的陆生、水生野生动物和有重要生态、科学、社会价值的陆生野生动物。”第四款修改为：“珍贵、濒危的水生野生动物以外其他水生野生动物的保护，适用《中华人民共和国渔业法》等有关法律的规定。”

第四条第一款中的“县级以上人民政府应当加强野生动物及其栖息地保护和管理”修改为“县级以上人民政府应当对本行政区域内野生动物保护工作负责，加强野生动物及其栖息地保护和管理”。

第八条修改为：“省重点保护野生动物名录由省野生动物保护主管部门提出，省人民政府组织科学论证评估，征求国务院野生动物保护主管部门意见后制定、公布。省林业草原主管部门应当在有关网站向社会公示相关信息。

“省重点保护野生动物名录应当每五年组织科学论证评估，根据论证评估情况进行调整，也可以根据野生动物保护的实际需要及时进行调整。”

第四十五条改为第四十条，修改为：“生态环境主管部门或者其他负有固体废物污染防治监督管理职责的部门、机构未依照本条例规定履行职责的，由有权机关对负有责任的领导人员和其他直接责任人员依法给予处分。”

删去第四十六条、第四十七条。

（五）修改《黑龙江省森林植物园保护条例》

删去第一条中的“、《中华人民共和国自然保护区条例》”。

删去第二条中的“位于哈尔滨市动力区，”。

第五条中的“国民经济和社会发展计划”修改为“国民经济和社会发展规划”。

第十二条修改为：“在植物园内进行科学研究、教学实习和拍摄影视作品等活动，应当经植物园管理机构同意后，在指定的范围内进行。

“确因科研需要对植物进行采样的，须经植物园管理机构同意。”

第十三条修改为：“不得采伐植物园的林木。确因防治病虫害、促进林木生长等必须采伐林木的，须依法办理相关手续。”

删去第十八条至第二十条。

第二十一条改为第十八条，修改为：“植物园管理机构及其工作人员有下列行为之一的，由植物园管理机构或者省林业草原主管部门对主管负责人和直接责任人依法给予处分：

“（一）不严格执行植物园发展建设规划的；

“（二）不认真履行植物园管理机构主要职责的；

“（三）其他违反本条例的行为。”
