# 昌吉回族自治州人民代表大会常务委员会关于废止《昌吉回族自治州准东经济技术开发区生态环境保护条例》的决定

昌吉回族自治州人民代表大会常务委员会关于
废止《昌吉回族自治州准东经济技术开发区
生态环境保护条例》的决定

（2026年6月15日昌吉回族自治州第十六届人民代表大会常务委员会第三十九次会议通过　2026年7月29日新疆维吾尔自治区第十四届人民代表大会常务委员会第三十次会议批准）

昌吉回族自治州第十六届人民代表大会常务委员会第三十九次会议决定，废止《昌吉回族自治州准东经济技术开发区生态环境保护条例》（2019年8月27日昌吉回族自治州第十五届人民代表大会常务委员会第二十六次会议通过　2019年9月20日自治区第十三届人民代表大会常务委员会第十二次会议审查批准）。

本决定自公布之日起施行。
