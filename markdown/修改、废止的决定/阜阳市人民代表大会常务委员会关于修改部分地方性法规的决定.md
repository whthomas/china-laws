# 阜阳市人民代表大会常务委员会关于修改部分地方性法规的决定

阜阳市人民代表大会常务委员会关于修改
部分地方性法规的决定

（2026年6月26日阜阳市第六届人民代表大会常务委员会第三十八次会议通过　2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议批准）

为深入贯彻习近平生态文明思想，保证《中华人民共和国生态环境法典》全面有效贯彻实施，维护国家法治统一，阜阳市第六届人民代表大会常务委员会第三十八次会议决定对下列地方性法规作出修改：

一、对《阜阳市地下水保护条例》作出修改

（一）将第三十二条修改为：“违反本条例第十一条规定，在地下水禁止开采区、限制开采区范围内擅自取用地下水的，由县级以上水行政主管部门责令停止违法行为，限期采取补救措施，处以五万元以上五十万元以下的罚款。”

（二）删除第三十三条中的“责令其补缴应当缴纳的水资源费”，将第三十三条中的“十万元”修改为“二十万元”。

（三）将第三十六条中的“《中华人民共和国环境保护法》第六十三条”修改为“有关法律法规”。

二、对《阜阳市生活垃圾管理条例》作出修改

（一）将第二十三条第一项中的“倾倒、抛撒、堆放或者焚烧”修改为“倾倒、堆放、丢弃、抛撒、遗撒、焚烧”。

（二）删除第二十八条第二项中的“，不得随意倾倒、丢弃、遗撒、堆放、焚烧”。

（三）删除第二十九条第六项，增加一项“法律、法规的其他规定”作为第二十九条的最后一项。

（四）将第三十七条中的“倾倒、抛洒、堆放”修改为“倾倒、堆放、丢弃、抛撒、遗撒、焚烧”，“二百元以下”修改为“一百元以上一千元以下”，删除“，对单位处五千元以上五万元以下的罚款”。

三、对《阜阳市城市市容和环境卫生管理条例》作出修改

（一）在第二十九条“防止物料遗撒”后面增加“造成扬尘污染，并按照规定路线行驶”。

（二）在第四十条第四项“防止物料遗撒”后面增加“，或者未按照规定路线行驶”。

四、对《阜阳市饮用水水源保护条例》作出修改

将第三十二条修改为：“违反本条例规定，在饮用水水源保护区内设置排污口的，由市、县（市、区）人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由生态环境主管部门处十万元以上五十万元以下的罚款；情节严重的，处五十万元以上一百万元以下的罚款，责令限制生产、停产整治。”

本决定自2026年8月15日起施行。

《阜阳市地下水保护条例》《阜阳市生活垃圾管理条例》《阜阳市城市市容和环境卫生管理条例》《阜阳市饮用水水源保护条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
