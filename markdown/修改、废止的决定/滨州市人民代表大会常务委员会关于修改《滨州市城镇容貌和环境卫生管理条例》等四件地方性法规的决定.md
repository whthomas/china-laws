# 滨州市人民代表大会常务委员会关于修改《滨州市城镇容貌和环境卫生管理条例》等四件地方性法规的决定

滨州市人民代表大会常务委员会关于修改
《滨州市城镇容貌和环境卫生管理条例》
等四件地方性法规的决定

（2026年7月2日滨州市第十二届人民代表大会常务委员会第三十三次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

滨州市第十二届人民代表大会常务委员会第三十三次会议决定：

一、对《滨州市城镇容貌和环境卫生管理条例》作出修改

1.将第一条修改为：“为了加强城镇容貌和环境卫生管理，创造清洁、优美、文明的城镇宜居环境，提高居民生活质量，根据有关法律、法规，结合本市实际，制定本条例。”

2.将第九条修改为：“市、县（市、区）、镇人民政府应当定期对城镇容貌和环境卫生管理工作进行检查，对在工作中成绩显著的单位和个人按照有关规定给予表扬和奖励。”

3.将第十四条改为第十五条，第二款修改为：“城镇建筑物、构筑物以及独立庭院的所有权人、使用人或者管理人不得室（院）外经营、制作或者屠宰。”

第三款修改为：“在城镇建筑物、构筑物外墙、顶部架设线路，安装空调、太阳能热水器、防盗网、遮阳罩等设施，应当符合城镇容貌标准；封闭阳台不得超出阳台底面及顶部外沿和层高。任何单位和个人不得擅自搭建建筑物、构筑物。”

4.将第十五条改为第十六条，修改为：“禁止擅自在建筑物、构筑物、公共设施、路面、线杆、树木等处张贴、悬挂、涂写、刻画；禁止擅自在道路、广场、公园等公共区域实施商业流动宣传、经营、表演等影响城镇容貌的行为。

“建筑物、构筑物、公共设施、路面、线杆、树木等以及公共区域的所有权人、使用人或者管理人，发现张贴、悬挂、涂写、刻画或者商业流动宣传、经营、表演的，应当立即制止或者清理。”

5.将第二十一条改为第二十二条，修改为：“在城镇道路两侧和公共场地不得擅自堆放物料，搭建建筑物、构筑物或者其他设施。临时堆放物料，搭建临时性的建筑物、构筑物或者其他设施的，应当向城镇容貌和环境卫生行政主管部门提出申请，经审查同意后方可按照规定办理相关手续。”

6.将第二十四条改为第二十五条，修改为：“再生资源回收企业和个体经营者，应当保持经营场所整洁，并采取围挡、遮盖等措施。”

7.将第二十五条改为第二十六条，修改为：“城市建成区内不得饲养鸡、鸭、鹅、兔、牛、马、羊、猪等家禽家畜和食用鸽等。依法从事教学、科研或者其他特殊活动的除外。”

8.将第二十八条第二款修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆和船舶应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定路线行驶。”

增加一款作为第三款：“装卸物料应当采取密闭或者喷淋等方式防治扬尘污染。”

9.将第三十四条修改为：“任何单位和个人不得占用、损坏环境卫生设施。”

10.将第三十五条第一款修改为：“城镇环境卫生保洁由城镇容貌和环境卫生行政主管部门统一组织管理，推行清洁动力机械化清扫和其他科学合理的低尘作业方式。”

11.将第四十二条改为第四十一条，第一款修改为：“产生生活垃圾的单位、家庭和个人应当依法履行生活垃圾源头减量和分类投放义务，按照规定的方式、时间和地点，将生活垃圾分类投放至指定地点或者指定收集容器、设施。”

12.将第四十五条改为第四十三条，修改为：“产生生活垃圾、建筑垃圾的单位和个人，应当按照市、县（市、区）人民政府物价部门核定的收费标准缴纳处理费用。”

13.将第四十七条改为第十条。

14.将第五十条改为第四十四条，修改为：“违反本条例规定的行为，法律、法规已经规定法律责任的，适用其规定。”

15.将第五十一条改为第四十五条，修改为：“违反本条例规定，有下列行为之一的，由城镇容貌和环境卫生行政主管部门根据违法行为的性质、后果等情况责令停止违法行为，限期清理、拆除或者采取其他补救措施；逾期未清理、拆除或者采取其他补救措施的，可以按照下列规定予以处罚：

“（一）违反本条例第十五条规定，在城镇道路两侧建筑物、构筑物顶部、阳台（窗）外堆放、吊挂、晾晒有碍城镇容貌的物品的，在透明临街幕墙、门窗内侧设置电子显示屏等广告标识的，设置警示腰线不符合城镇容貌标准的，处五十元以上二百元以下罚款；在室（院）外经营、制作或者屠宰的，处二百元以上二千元以下罚款；在城镇建筑物、构筑物外墙、顶部架设线路，安装空调、太阳能热水器、防盗网、遮阳罩等设施以及封闭阳台不符合城镇容貌标准的，处二千元以上一万元以下罚款；

“（二）违反本条例第十七条规定，架设电力、有线电视、通信等各类管线、杆体、箱体等不符合城镇容貌标准的，或者废弃的管线、杆体、箱体等设施未及时拆除的，处一千元以上一万元以下罚款；

“（三）违反本条例第二十二条规定，擅自搭建临时性的建筑物、构筑物或者其他设施的，处二千元以上二万元以下罚款；

“（四）违反本条例第二十三条规定，未及时清理淤泥、污物的，处五百元以上二千元以下罚款；

“（五）违反本条例第二十四条规定，放置设置渔网、渔箱或者其他阻鱼装置的，处二百元以上二千元以下罚款；

“（六）违反本条例第二十五条规定，经营场所未采取围挡、遮盖等措施的，对个人处五十元以上二百元以下罚款，对单位处五百元以上五千元以下罚款；

“（七）违反本条例第二十九条规定，机动车停车场、非机动车停车点（亭、棚）未硬化，不符合城镇容貌标准的，处二千元以上二万元以下罚款；

“（八）违反本条例第三十条第一款规定，未落实维护城镇容貌环境秩序责任的，处二千元以上二万元以下罚款。”

16.将第五十二条改为第四十六条，修改为：“违反本条例第二十六条规定，饲养鸡、鸭、鹅、兔、牛、马、羊、猪等家禽家畜和食用鸽等的，责令限期处理；逾期未处理的，可以处每只（头、匹）二十元以上一百元以下罚款，最高不超过二千元。”

17.将第五十三条改为第四十七条，修改为：“违反本条例第三十四条规定，损坏保洁车、垃圾桶、果皮箱等环境卫生设施的，依法赔偿，可以处五百元以上二千元以下罚款。”

18.将第五十六条改为第四十八条，修改为：“各级人民政府和有关部门及其工作人员在城镇容貌和环境卫生管理工作中，滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

19.删去第二十六条，第三十九条第四项，第四十一条，第四十三条，第四十四条第一款、第三款，第四十六条，第四十八条，第四十九条，第五十一条第二项、第四项、第五项、第六项，第五十二条第二项、第三项，第五十三条第一项、第三项、第四项、第五项，第五十四条，第五十五条，第五十七条。

二、对《滨州市生活垃圾分类管理条例》作出修改

1.将第一条修改为：“为了加强生活垃圾分类管理，改善人居环境，促进生态文明建设和经济社会可持续发展，根据《中华人民共和国生态环境法典》《山东省生活垃圾管理条例》等法律、法规，结合本市实际，制定本条例。”

2.将第三条修改为：“生活垃圾分类管理工作应当坚持政府推动、全民参与、城乡统筹、因地制宜、简便易行的原则。”

3.将第十条第二款修改为：“禁止随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾。”

4.将第十三条第二项修改为：“（二）按照生活垃圾类别、数量、作业时间等要求，将生活垃圾运输至集中收集设施或者符合规定的转运设施，不得混装混运，不得随意倾倒、堆放、丢弃、抛撒、滴漏、遗撒或者焚烧生活垃圾”。

5.将第十四条第五项修改为：“（五）按照国家规定，安装使用监测设备，实时监测污染物的排放情况，将污染排放数据实时向社会公开。监测设备应当与所在地生态环境主管部门的监控设备联网。”

6.将第十九条修改为：“各级人民政府和有关部门及其工作人员在生活垃圾分类管理工作中，滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

7.删去第十条第三款、第四款，第十五条第三款。

三、对《滨州市海岸带生态保护与利用条例》作出修改

1.将第一条修改为：“为了有效保护海岸带生态环境，加强海岸带综合管理，在经略海洋战略实施中合理利用海岸带资源，推进海洋生态文明建设，根据《中华人民共和国生态环境法典》《中华人民共和国海域使用管理法》等法律、法规，结合本市实际，制定本条例。”

2.将第六条第一款修改为：“自然资源规划部门负责自然资源调查监测，海岸带陆域内湿地和沿海防护林的保护、修复与管理。”

3.将第十一条第一款修改为：“编制海岸带生态保护与利用专项规划应当遵循生态保护红线，广泛征求社会各方面的意见建议，符合国土空间规划，并与生态环境保护规划等相衔接。”

4.将第十二条第一项修改为：“（一）自然保护区的核心保护区”。

第五项修改为：“（五）其他按照法律、法规应当严格保护的区域。”

5.将第十三条第六项改为第五项，修改为：“（五）其他按照法律、法规应当限制开发的区域。”

6.将第十六条第二款修改为：“在严格保护区域内，除因国防安全需要外，禁止开展与保护无关的活动。”

7.将第十七条第二款修改为：“海洋发展渔业、自然资源规划、生态环境等相关部门应当根据职责整治修复受损岸线，不断增加自然岸线长度和保有率，加强岸线资源节约利用，严格控制占用岸线的开发利用活动。”

增加一款作为第三款：“禁止破坏自然岸线、沙滩、海岸景观，防止自然岸线破碎化。”

8.将第二十三条第一款修改为：“市、县（区）人民政府应当规范海岸带内水产养殖用海管理。任何单位和个人不得擅自新增水产养殖项目、改变养殖方式或者扩大养殖规模。”

第四款改为第二款，修改为：“在海岸带区域内从事水产养殖，应当保护水域、滩涂生态环境，科学确定养殖密度和养殖规模，合理投饵、投饲、投药，养殖排放尾水应当符合有关污染物排放标准，不得破坏水域、滩涂的生态环境。”

9.增加一条作为第四十条：“市、县（区）人民政府和有关部门及其工作人员在海岸带生态保护与利用工作中，滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

10.删去第五条第二款，第十三条第一项，第二十三条第二款、第三款、第五款，第三十九条，第四十条。

四、对《滨州市扬尘污染防治条例》作出修改

1.将第一条修改为：“为了防治扬尘污染，保护和改善大气环境，保障公众健康和生态环境权益，根据《中华人民共和国生态环境法典》《山东省大气污染防治条例》等法律、法规，结合本市实际，制定本条例。”

2.将第五条第一款修改为：“市人民政府应当建立统筹协调、长效管理和信息共享工作机制，制定总体工作方案，组织开展重污染天气应对工作，协调跨区域扬尘污染防治工作。”

3.将第六条修改为：“生态环境主管部门应当协调和督促其他监督管理部门履行扬尘污染防治管理职责；负责工业生产企业扬尘污染防治的监督管理；负责监测扬尘污染和大气环境质量状况，并定期发布监测信息。

“住房城乡建设部门负责房屋建筑工程施工及拆除、有关市政基础设施建设等建设工程扬尘污染防治的监督管理。

“城市管理部门负责城区道路、垃圾填埋场、建筑垃圾消纳场等扬尘污染防治的监督管理；负责城区内散装水泥、石灰、渣土、砂石、煤炭、垃圾等易产生扬尘的货物贮存场所和运输车辆防尘措施的监督管理。

“公安机关交通管理部门会同城市管理部门负责设定渣土、建筑垃圾等易产生扬尘的物料运输车辆的行驶路线、禁行和限行区域、时间。

“交通运输部门负责公路桥梁施工和配套工程建设扬尘污染防治的监督管理；负责车站和码头物流园区、堆场扬尘污染防治的监督管理；负责国道、省道、县道扬尘污染防治的监督管理。

“城乡水务部门负责河道整治、水利工程建设、有关涉水市政基础设施建设扬尘污染防治的监督管理。

“自然资源规划部门负责露天矿开采区域扬尘污染防治的监督管理。

“其他相关部门在各自职责范围内做好扬尘污染防治的监督管理工作。”

4.将第九条改为第八条，第一款修改为：“相关单位和个人应当根据市、县（市、区）人民政府启动的重污染天气应对预案，执行停止工地土石方作业和建筑物拆除施工等应对措施。”

5.将第十五条改为第十二条，第一款第一项修改为：“（一）施工现场实行硬质围挡封闭”。

第五项修改为：“（五）建筑垃圾和易产生扬尘的建筑材料不得凌空抛洒抛掷”。

第二款修改为：“违反本条规定的，由市、县（市、区）人民政府住房城乡建设部门或者其他监督管理部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治，可以自责令改正之日的次日起，按照原处罚数额按日连续处罚，并及时采取措施制止违法行为。”

6.将第十六条改为第十三条，修改为：“建设单位应当对暂时不能开工的裸露地面进行覆盖；超过三个月不能开工的，应当进行临时绿化、透水铺装或者遮盖。

“违反本条规定的，由市、县（市、区）人民政府城市管理部门责令改正，处一万元以上十万元以下罚款；逾期未改正的，城市管理部门依据裸露地块的具体情况，确定绿化建设标准，可以委托第三人代为履行，所需费用由建设单位承担。”

7.将第十七条改为第十四条，第一款第四项修改为：“（四）道路或者绿地内各类管线敷设工程完工后，七日内恢复路面或者景观。”

第二款修改为：“违反本条规定的，由市、县（市、区）人民政府确定的监督管理部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治，可以自责令改正之日的次日起，按照原处罚数额按日连续处罚，并及时采取措施制止违法行为。”

8.将第十八条改为第十五条，第二款修改为：“违反本条规定的，由市、县（市、区）人民政府确定的监督管理部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治，可以自责令改正之日的次日起，按照原处罚数额按日连续处罚，并及时采取措施制止违法行为。”

9.将第十九条改为第十六条，第二款修改为：“违反本条规定的，由市、县（市、区）人民政府城市管理部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治。”

10.将第二十条改为第十七条，第一款修改为：“运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆和船舶应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定时间、路线行驶。”

11.将第二十二条改为第十九条，第一款修改为：“易产生扬尘污染的物流园区、物料堆场、预拌混凝土、沥青搅拌站等生产经营场所，应当符合下列防尘要求：

“（一）堆场的场坪、路面采取硬化处理；

“（二）密闭贮存易产生扬尘的物料；不能密闭的，设置不低于堆放物高度的严密围挡，并采取有效覆盖措施；

“（三）出入口设置冲洗设施，运输车辆在冲洗干净后方可驶出；

“（四）装料、卸料处采取吸尘、喷淋、洒水等措施。”

12.将第二十四条改为第二十一条，第二款修改为：“违反本条规定的，由市、县（市、区）人民政府城市管理部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治。”

13.将第二十五条改为第二十二条，修改为：“违反本条例规定的行为，法律、法规已经规定法律责任的，适用其规定。”

14.增加一条作为第二十三条：“市、县（市、区）人民政府和有关部门及其工作人员在扬尘污染防治工作中，滥用职权、玩忽职守、徇私舞弊的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

15.删去第五条第三款、第四款，第八条，第九条第二款，第十条，第十一条，第二十条第二款，第二十二条第二款、第三款、第四款、第五款。

此外，根据机构改革职能调整情况对有关单位职责和名称进行调整，同时对以上四件地方性法规章节条文顺序和个别文字作了修改。

本决定自2026年8月15日起施行。
