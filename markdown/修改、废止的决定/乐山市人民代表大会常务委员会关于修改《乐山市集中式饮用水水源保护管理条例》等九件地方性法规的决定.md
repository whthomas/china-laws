# 乐山市人民代表大会常务委员会关于修改《乐山市集中式饮用水水源保护管理条例》等九件地方性法规的决定

乐山市人民代表大会常务委员会
关于修改《乐山市集中式饮用水水源保护管理
条例》等九件地方性法规的决定

（2026年6月29日乐山市第八届人民代表大会常务委员会第四十一次会议通过　2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议批准）

乐山市第八届人民代表大会常务委员会第四十一次会议决定：

一、对《乐山市集中式饮用水水源保护管理条例》作出修改

（一）将第一条修改为“为了加强集中式饮用水水源保护和管理，保障集中式饮用水水源安全，维护公众健康，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《四川省饮用水水源保护管理条例》等法律、法规的规定，结合乐山市实际，制定本条例。”

（二）将第十一条第一款、第二款合并修改为“集中式饮用水水源保护区的划定和调整，按照有关法律、法规规定办理。”

二、对《乐山市中心城区绿心保护条例》作出修改

删除第二十四条第二款“倾倒生活垃圾或者建筑垃圾的，由城市管理行政执法部门责令停止违法行为、限期改正或者清除，对单位处五千元以上五万元以下罚款，对个人处二百元以下罚款”的规定。

三、对《乐山大佛世界文化和自然遗产保护条例》作出修改

将第一条修改为“为了加强对乐山大佛世界文化和自然遗产的保护和管理，确保世界遗产的原真性和完整性，推进生态文明建设，促进经济社会可持续发展，根据《保护世界文化和自然遗产公约》、《中华人民共和国生态环境法典》、《中华人民共和国文物保护法》、《四川省世界遗产保护条例》等有关法律、法规，结合乐山实际，制定本条例。”

四、对《峨眉山世界文化和自然遗产保护条例》作出修改

将第一条修改为“为了加强对峨眉山世界文化和自然遗产的保护和管理，确保世界遗产的原真性和完整性，推进生态文明建设，促进经济社会可持续发展，根据《保护世界文化和自然遗产公约》、《中华人民共和国生态环境法典》、《中华人民共和国文物保护法》、《四川省世界遗产保护条例》等有关法律、法规，结合乐山实际，制定本条例。”

五、对《乐山市扬尘污染防治条例》作出修改

将第一条修改为“为了防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，促进经济社会可持续发展，根据《中华人民共和国生态环境法典》等法律、法规，结合乐山市实际，制定本条例。”

六、对《乐山市城市管理条例》作出修改

将第二十七条第二项修改为“违规露天焚烧秸秆、落叶、杂草等产生烟尘污染的物质”。

七、对《乐山市三江岸线保护条例》作出修改

（一）将第二条第二款修改为“河道管理范围边界内的区域按照《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国防洪法》、《中华人民共和国河道管理条例》等有关法律法规的规定执行。”

（二）将第十九条第五项修改为“焚烧沥青、油毡、橡胶、塑料、皮革、垃圾以及其他产生有毒有害烟尘和恶臭气体的物质，违规露天焚烧秸秆、落叶等产生烟尘污染的物质。”

八、对《乐山市文明行为促进条例》作出修改

将第十二条第六项修改为“不违规露天焚烧垃圾、秸秆、落叶等产生烟尘污染的物质，控制化学洗涤剂、化肥、农药的过量使用，防止环境污染。”

九、对《乐山市畜禽水产养殖污染防治条例》作出修改

将第一条修改为“为了防治畜禽、水产养殖污染，统筹推进养殖业高质量发展和生态环境高水平保护，促进乡村振兴，根据《中华人民共和国生态环境法典》、《中华人民共和国乡村振兴促进法》等有关法律法规，结合乐山实际，制定本条例。”

本决定自2026年8月15日起施行。

《乐山市集中式饮用水水源保护管理条例》等九件地方性法规根据本决定作相应修改后，重新公布。
