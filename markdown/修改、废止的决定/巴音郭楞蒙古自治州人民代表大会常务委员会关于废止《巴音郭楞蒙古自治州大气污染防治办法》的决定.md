# 巴音郭楞蒙古自治州人民代表大会常务委员会关于废止《巴音郭楞蒙古自治州大气污染防治办法》的决定

巴音郭楞蒙古自治州人民代表大会
常务委员会关于废止《巴音郭楞蒙古自治州
大气污染防治办法》的决定

（2026年6月25日巴音郭楞蒙古自治州第十五届人民代表大会常务委员会第三十三次会议通过　2026年7月29日新疆维吾尔自治区第十四届人民代表大会常务委员会第三十次会议批准）

巴音郭楞蒙古自治州第十五届人民代表大会常务委员会第三十三次会议决定，废止《巴音郭楞蒙古自治州大气污染防治办法》（2019年5月26日自治州第十四届人民代表大会常务委员会第十七次会议通过，2019年7月25日自治区第十三届人民代表大会常务委员会第十一次会议批准）。

本决定自公布之日起施行。
