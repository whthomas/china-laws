# 鹤岗市人民代表大会常务委员会关于修改《鹤岗市饮用水水源保护条例》等五部地方性法规的决定

鹤岗市人民代表大会常务委员会关于
修改《鹤岗市饮用水水源保护条例》等五部
地方性法规的决定

（2026年7月28日鹤岗市第十七届人民代表大会常务委员会第三十四次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

鹤岗市第十七届人民代表大会常务委员会第三十四次会议决定对《鹤岗市饮用水水源保护条例》等五部地方性法规作如下修改：

一、对《鹤岗市饮用水水源保护条例》作出修改

（一）将第一条修改为：“为了加强地表水饮用水水源保护，保障饮用水水源安全，根据《中华人民共和国生态环境法典》、《黑龙江省水污染防治条例》等法律、法规的规定，结合本市实际，制定本条例。”

（二）将第十一条修改为：“在饮用水水源二级保护区内从事旅游等活动的，应当按照《中华人民共和国生态环境法典》等法律、法规的规定采取措施，防止污染饮用水水体。”

二、对《鹤岗市河道管理条例》作出修改

将第三十一条修改为：“违反本条例第二十五条第一款规定，在污水收集管网覆盖的区域，新设置生活污水入河排污口的，除《中华人民共和国生态环境法典》第一千一百零九条第二款规定外，由生态环境主管部门责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，处二万元以上十万元以下的罚款；情节严重的，处十万元以上五十万元以下的罚款，责令限制生产、停产整治。”

三、对《鹤岗市农村人居环境卫生管理条例》作出修改

（一）将第一条修改为：“为优化农村人居环境，树立农村居民环境卫生保护意识，提高农村居民生产生活质量，全面推进乡村振兴，根据《中华人民共和国生态环境法典》、《中华人民共和国乡村振兴促进法》等法律、法规的规定，结合本市实际，制定本条例。”

（二）将第十五条修改为：“市、县（区）、乡（镇）人民政府应当科学精准加强秸秆、落叶等焚烧的组织、指导和管理。禁止在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质。

“未还田秸秆应当打包离田进行综合利用，另有规定的除外。

“市、县（区）、乡（镇）人民政府对辖区内秸秆焚烧管控工作负总责，政府主要负责人是第一责任人，分管负责人是具体责任人，建立和完善秸秆焚烧管控工作责任制，逐级签订责任状，明确单位和个人的具体责任。市人民政府生态环境主管部门具体负责秸秆焚烧管控工作。

“农业生产中产生的根茬、果皮、碎屑等可以采取粉碎还田、生产有机肥及其他资源化利用的方式进行处置。”

（三）将第二十条第三项修改为：“随意倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾。”

第四项修改为：“擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧建筑垃圾、炉灰等。”

（四）将第二十四条修改为：“擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾、建筑垃圾的，由环境卫生主管部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下的罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，指定有治理能力的单位代为治理，所需费用由违法者承担。

“个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾、建筑垃圾的，由环境卫生主管部门责令改正，处一百元以上一千元以下的罚款。”

四、对《鹤岗市文明祭祀条例》作出修改

（一）将第一条中“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三条修改为：“祭祀管理工作应当坚持教育引导、源头治理、疏堵结合、绿色文明的原则，抵制违背公序良俗祭祀行为，引导和规范城乡居民文明祭祀。”

（三）将第五条、第十三条中“封建迷信祭祀行为”修改为“违背公序良俗祭祀行为”。

（四）将第六条中“封建迷信祭祀用品”修改为“违反法律法规或者违背公序良俗的丧葬用品”。

（五）将第七条修改为：“本市行政区域内禁止制造、销售违反法律法规或者违背公序良俗的丧葬用品。”

（六）删去第十一条。

（七）删去第十六条第三款。

五、对《鹤岗市餐厨垃圾管理条例》作出修改

（一）将第一条修改为：“为加强餐厨垃圾管理，维护市容环境卫生，保障食品安全，促进资源循环利用，根据《中华人民共和国生态环境法典》、《黑龙江省食品安全条例》、《黑龙江省城市市容和环境卫生管理条例》等法律、法规的规定，结合本市实际，制定本条例。”

（二）删去第十五条、第十六条、第十七条。

本决定自公布之日起施行。

《鹤岗市饮用水水源保护条例》、《鹤岗市河道管理条例》、《鹤岗市农村人居环境卫生管理条例》、《鹤岗市文明祭祀条例》、《鹤岗市餐厨垃圾管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
