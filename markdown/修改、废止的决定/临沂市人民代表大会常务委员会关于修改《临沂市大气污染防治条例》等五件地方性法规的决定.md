# 临沂市人民代表大会常务委员会关于修改《临沂市大气污染防治条例》等五件地方性法规的决定

临沂市人民代表大会常务委员会关于修改
《临沂市大气污染防治条例》等五件
地方性法规的决定

（2026年6月23日临沂市第二十届人民代表大会常务委员会第三十六次会议通过　2026年7月23日山东省第十四届人民代表大会常务委员会第二十五次会议批准）

临沂市第二十届人民代表大会常务委员会第三十六次会议决定：

一、对《临沂市大气污染防治条例》作出修改

1.将第十五条改为第十四条，修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者应当按照国家规定安装大气污染物排放自动监测设备，与生态环境主管部门的自动监测监控系统联网，保证正常运行，并保存原始监测记录。”

2.将第二十四条改为第二十一条，第一款修改为：“市人民政府生态环境主管部门应当确定挥发性有机物年度总量削减目标。”

3.将第二十八条改为第二十五条，修改为：“市人民政府可以划定并公布高污染燃料禁燃区，并根据大气环境质量改善要求，逐步扩大高污染燃料禁燃区范围。”

4.将第三十条改为第二十六条，修改为：“各级人民政府应当采取有效措施，加强散煤的管理，禁止销售不符合散煤质量标准的煤炭，鼓励、支持采取清洁低碳能源、集中供热替代等措施防治燃用散煤造成大气污染。”

5.将第三十五条改为第三十一条，第一款修改为：“在本市行政区域内行驶的机动车和使用的非道路移动机械不得超过标准排放大气污染物。”

6.将第四十三条改为第三十七条，修改为：“禁止在人口集中地区和其他依法需要特殊保护的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质。”

7.删去第十二条、第十四条第二款、第十六条、第二十条、第二十九条、第三十八条、第四十二条、第四十四条、第四十九条。

8.对部分条文作以下修改：

（1）将第一条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（2）删去第四条第二款中的“建立健全大气污染防治协调机制”。

（3）将第五条第三款中的“按照上级人民政府和有关部门的工作安排”修改为“按照职责”。

（4）删去第十一条中的“制定大气污染防治计划”。

（5）将第十八条中的“应急预案”修改为“应对预案”，“应急措施”修改为“应对措施”；第一款中的“应急需要”修改为“应对的需要”，在“限制部分机动车行驶”后增加“和非道路移动机械使用”，在“学校”后增加“组织”；第二款中的“应急响应”修改为“应对响应”。

（6）将第四十八条中的“应急措施”修改为“应对措施”。

（7）将第五十条中的“玩忽职守”调整到“滥用职权”之后。

二、对《临沂市饮用水水源地保护条例》作出修改

1.第五条增加一款，作为第四款：“乡镇人民政府、街道办事处应当按照职责做好本辖区内饮用水水源地保护的有关工作。”

2.将第三十七条改为第二十八条，修改为：“市、县（区）人民政府应当组织制定饮用水安全突发事件应急预案。

“饮用水供水单位应当根据所在地饮用水安全突发事件应急预案，制定相应的突发事件应急预案，报市、县（区）人民政府备案，并定期进行演练。”

3.删去第六条至第十一条、第十四条、第十五条、第三十二条、第四十条、第四十三条。

4.对部分条文作以下修改：

（1）在第一条中的“根据”后增加“《中华人民共和国生态环境法典》”，删去“《中华人民共和国水污染防治法》”。

（2）将第二十二条中的“第二十一条”修改为“第十三条”，第二十三条中的“第二十一条、第二十二条”修改为“第十三条、第十四条”。

（3）删去第三十四条第二款中的“村（居）民委员会”。

（4）将第四十四条中的“玩忽职守”调整到“滥用职权”之后。

三、对《临沂市蒙山保护条例》作出修改

1.将第七条修改为：“市、有关县人民政府确定的部门（以下统称风景名胜区主管部门）按照职责做好本行政区域内蒙山风景名胜区的监督管理工作和蒙山保护相关工作。

“蒙山风景名胜区管理机构按照职责负责蒙山风景名胜区的保护、管理、利用的具体工作和蒙山保护相关工作。

“发展改革、公安、财政、人力资源社会保障、自然资源和规划、生态环境、住房城乡建设、城市管理、交通运输、水利、农业农村、文化和旅游、应急管理、市场监督管理、体育等部门按照各自职责，共同做好蒙山风景名胜区的保护、管理和蒙山保护相关工作。”

2.将第十条改为第九条，第一款修改为：“市人民政府自然资源和规划部门应当会同有关县人民政府和生态环境、水利、文化和旅游等部门组织编制蒙山保护总体规划，由市人民政府通过后，报市人民代表大会常务委员会决定。”

3.将第十一条改为第十条，第一款修改为：“蒙山风景名胜区规划的编制和审批，依照《风景名胜区条例》和《山东省风景名胜区条例》的规定办理。”

4.将第十五条改为第十三条，修改为：“蒙山保护总体规划和蒙山风景名胜区规划应当与国土空间规划、生态环境保护规划等有关规划相衔接。”

5.将第二十六条改为第二十三条，第三项修改为：“（三）建立森林防火责任制，确定森林防火期，划定森林防火区，落实森林防火措施”。

6.将第五十八条改为第四十二条，修改为“国家机关及其工作人员违反本条例，在蒙山保护工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分；构成犯罪的，依法追究刑事责任。”

7.删去第八条、第十二条、第十六条、第三十二条、第三十七条、第四十五条至第四十九条、第五十一条、第五十二条、第五十四条至第五十七条、第五十九条。

8.对部分条文作以下修改：

（1）删去第六条第一款中的“建立蒙山保护协调机制”，在第三款中的“乡（镇）人民政府”后增加“按照职责”。

（2）将第十条第三款中的“市城乡规划部门”修改为“市人民政府自然资源和规划部门”。

（3）将第二十二条第一款中的“审核同意”修改为“审核后”，“城乡规划许可、施工许可等”修改为“审批”；第二款和第三款中的“市城乡规划部门”修改为“市风景名胜区主管部门”。

（4）删去第二十五条、第二十六条、第三十四条、第三十五条、第三十六条中的“和临沂蒙山旅游度假区管理委员会”。

（5）删去第二十七条第二款中的“或者临沂蒙山旅游度假区管理委员会”。

四、对《临沂市文明行为促进条例》作出修改

1.将第四条修改为：“市、县（区）精神文明建设工作机构负责本行政区域内文明行为促进工作的规划计划、指导协调等工作。”

2.将第十二条第八项修改为：“（八）违反规定在禁止的区域和时段露天烧烤食品或者为露天烧烤食品提供场地”。

将第九项修改为：“（九）违反规定在禁止的区域焚烧沥青、油毡、橡胶、塑料、皮革、垃圾及其他产生有毒有害烟尘和恶臭气体的物质，在禁止的区域和时段露天焚烧秸秆、落叶等产生烟尘污染的物质”。

3.将第二十一条第一款修改为：“对做出显著成绩和贡献的无偿献血者，市、县（区）人民政府和红十字会应当按照有关规定给予表彰、奖励。”

4.将第五十六条改为第四十八条，删去第一项。

将第五项改为第四项，修改为：“（四）在居民生活区饲养列入禁养名录的烈性犬和大型犬，驱使或者放任犬只伤害、恐吓他人的，由公安机关依照《中华人民共和国治安管理处罚法》的有关规定予以处罚；犬只对他人造成损害的，养犬人应当依法承担相应的民事责任；构成犯罪的，依法追究刑事责任”。

5.删去第二十八条、第四十四条、第四十七条、第四十九条、第五十一条至第五十三条、第五十五条、第五十七条至第六十条、第六十二条。

6.对部分条文作以下修改：

（1）将第十七条第二款、第六款中的“畜牧”修改为“农业农村”。

（2）将第十八条、第二十条中的“表彰奖励”和“表彰、奖励”修改为“褒扬激励”。

（3）在第二十二条中的“给予表彰”前增加“按照有关规定”。

（4）将第三十条中的“文化广电新闻出版”修改为“文化和旅游”。

（5）将第三十二条中的“国土资源”修改为“自然资源和规划”，在“住房城乡建设”前增加“生态环境”，删去“城乡规划”“环境保护”“城市绿化”“房产”。

（6）将第三十四条中的“卫生主管部门”修改为“卫生健康主管部门”。

（7）将第三十五条中的“旅游”修改为“文化和旅游”，“工商行政管理”修改为“市场监督管理”，删去“质量技术监督”“食品药品监督管理”“价格”。

（8）将第四十三条中的“曝光”修改为“舆论监督”。

五、对《临沂市美丽乡村条例》作出修改

1.将第四十一条改为第三十九条，第二项修改为：“（二）随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾、建筑垃圾”。

2.将第六十五条改为第六十一条，修改为：“违反本条例规定，擅自在农村村庄内的建筑物、构筑物外墙或者公共设施上喷涂、张贴经营性广告的，由环境卫生主管部门责令限期改正；逾期不改正的，处一百元以上五百元以下的罚款。”

3.删去第十三条、第十四条、第十六条第二款、第十七条第二款、第十九条第三款、第五十一条、第五十七条第一款、第五十九条第三款、第六十三条。

4.对部分条文作以下修改：

（1）删去第四条第一款中的“建立联席会议制度”。

（2）删去第五条第一款中的“和考核评估”。

（3）删去第九条第二款中的“市、县（区）人民政府”。

（4）将第二十六条第一款中的“生态环境、农业农村、水利、林业等部门”修改为“有关部门”。

本决定自2026年8月15日起施行。

《临沂市大气污染防治条例》《临沂市饮用水水源地保护条例》《临沂市蒙山保护条例》《临沂市文明行为促进条例》《临沂市美丽乡村条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
