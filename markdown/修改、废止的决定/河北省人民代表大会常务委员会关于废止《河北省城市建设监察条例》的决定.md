# 河北省人民代表大会常务委员会关于废止《河北省城市建设监察条例》的决定

河北省人民代表大会常务委员会关于
废止《河北省城市建设监察条例》的决定

（2026年9月23日河北省第十四届人民代表大会常务委员会第二十三次会议通过）

河北省第十四届人民代表大会常务委员会第二十三次会议决定，废止《河北省城市建设监察条例》。

该条例2003年7月18日河北省第十届人民代表大会常务委员会第四次会议通过，2016年9月22日河北省第十二届人民代表大会常务委员会第二十三次会议修正。

本决定自公布之日起施行。
