# 张家界市人民代表大会常务委员会关于修改《张家界市扬尘污染防治条例》等地方性法规的决定

张家界市人民代表大会常务委员会关于
修改《张家界市扬尘污染防治条例》
等地方性法规的决定

（2026年8月27日张家界市第八届人民代表大会常务委员会第三十六次会议通过　2026年9月23日湖南省第十四届人民代表大会常务委员会第二十五次会议批准）

张家界市第八届人民代表大会常务委员会第三十六次会议决定：

一、对《张家界市扬尘污染防治条例》作出修改

（一）将第一条修改为：“为了防治扬尘污染，保护和改善大气环境，保障公众健康，推进生态文明建设，根据《中华人民共和国生态环境法典》《湖南省大气污染防治条例》等法律法规，结合本市实际，制定本条例。”

（二）将第六条环境保护主管部门修改为生态环境主管部门，国土资源主管部门修改为自然资源主管部门；将第二十九条、第三十三条、第三十五条环境保护主管部门修改为生态环境主管部门及其派出机构。

（三）将第二十条第三项修改为：“采用不低于堆放物高度的严密围挡或者其他封闭仓储设施，配备喷淋或者其他抑尘设施；”

（四）将第三十条第一款修改为“市人民政府生态环境主管部门及其派出机构应当会同有关主管部门确定并公布本年度辖区重点扬尘污染源。”

（五）删除第三十二条第二项、第四项、第八项；删除第三项中“第一项、第二项、第三项、第四项、第五项”，规范表述。

（六）删除第三十六条。

（七）新增兜底条款“违反本条例规定的其他行为，法律法规已经规定法律责任的，从其规定。”，作为第三十六条。

二、对《张家界市生活垃圾分类管理规定》作出修改

将第十六条第一款修改为：“违反本规定第十条规定，单位和个人不按照规定投放生活垃圾的，由城市管理部门或者乡镇人民政府、街道办事处责令改正；情节严重的，对单位按照《中华人民共和国生态环境法典》规定处罚，对个人处二十元以上一百元以下罚款。”

三、对《张家界市溶洞天坑污染防治规定》作出修改

将第九条修改为：“违反本规定，由市、县（区）人民政府生态环境等主管部门责令停止违法行为，限期采取治理措施消除污染，依照《中华人民共和国生态环境法典》和国务院《畜禽规模养殖污染防治条例》等有关规定予以处罚。”

本决定自2026年12月1日起施行。

《张家界市扬尘污染防治条例》等地方性法规根据本决定作相应修改并对条文顺序作相应调整，重新公布。
