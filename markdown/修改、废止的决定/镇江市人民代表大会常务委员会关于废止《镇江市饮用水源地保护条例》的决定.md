# 镇江市人民代表大会常务委员会关于废止《镇江市饮用水源地保护条例》的决定

镇江市人民代表大会常务委员会
关于废止《镇江市饮用水源地
保护条例》的决定

（2026年6月26日镇江市第九届人民代表大会常务委员会第三十二次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

镇江市第九届人民代表大会常务委员会第三十二次会议决定，废止《镇江市饮用水源地保护条例》。

本决定自公布之日起生效。
