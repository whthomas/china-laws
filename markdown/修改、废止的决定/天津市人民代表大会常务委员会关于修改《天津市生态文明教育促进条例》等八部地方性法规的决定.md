# 天津市人民代表大会常务委员会关于修改《天津市生态文明教育促进条例》等八部地方性法规的决定

天津市人民代表大会常务委员会关于修改
《天津市生态文明教育促进条例》等
八部地方性法规的决定

（2026年7月30日天津市第十八届人民代表大会常务委员会第二十七次会议通过）

天津市第十八届人民代表大会常务委员会第二十七次会议决定：

一、对《天津市生态文明教育促进条例》作出修改

（一）将第一条中的“中华人民共和国环境保护法”修改为“中华人民共和国生态环境法典”。

（二）将第十一条第二款中的“重点排污单位”修改为“实行排污许可重点管理的企业事业单位和其他生产经营者”。

（三）将第十九条第二款修改为：“市生态环境主管部门组织做好生态文明教育基地建设工作。”

（四）将第二十一条第三款修改为：“在生态文明教育宣传周、全国生态日、世界环境日、世界地球日、世界森林日、世界水日、世界海洋日和全国节能宣传周等期间，各相关部门应当按照各自职责组织开展生态文明教育。”

二、对《天津市绿色生态屏障管控地区管理若干规定》作出修改

（一）将第十七条第二项修改为：“（二）开（围）垦、填埋或者排干自然湿地”，第三项修改为：“（三）永久性截断自然湿地水源”，第四项修改为：“（四）擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧危险废物”。

（二）将第二十六条修改为：“违反本规定，在绿色生态屏障管控地区内开（围）垦、填埋自然湿地的，由市和相关区有关主管部门责令停止违法行为，限期修复湿地或者采取其他补救措施，没收违法所得，并按照破坏湿地面积，处每平方米五百元以上五千元以下罚款；破坏国家重要湿地的，并按照破坏湿地面积，处每平方米一千元以上一万元以下罚款。

“违反本规定，在绿色生态屏障管控地区内排干自然湿地或者永久性截断自然湿地水源的，由市规划资源主管部门或者相关区湿地保护管理部门责令停止违法行为，限期修复湿地或者采取其他补救措施，没收违法所得，并处五万元以上五十万元以下罚款；造成严重后果的，并处五十万元以上一百万元以下罚款。”

（三）将第二十七条修改为：“违反本规定，在绿色生态屏障管控地区内擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧危险废物的，由市和相关区生态环境主管部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处二十万元以上二百万元以下罚款；对直接负责的主管人员和其他直接责任人员处二万元以上十万元以下罚款；造成严重后果的，处二百万元以上五百万元以下罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，依法指定有治理能力的单位代为治理，所需费用由违法者承担。”

三、对《天津市绿化条例》作出修改

（一）删去第十二条。

（二）将第二十九条改为第二十八条，删去其中的“禁止在保护区内进行与保护无关的建设活动”。

（三）将第四十七条改为第四十六条，第一款修改为：“本市加强对古树名木的保护。本条例所称古树，是指树龄一百年以上的树木，不包括人工培育、以生产木材为主要目的的商品林中的树木。本条例所称名木，是指具有重要历史、文化、科学、景观价值或者具有重要纪念意义的树木。城市管理主管部门、林业行政主管部门应当按照国家和本市有关规定对古树名木建立档案、设置标志，划定保护范围，明确养护管理责任，实行严格保护。”

（四）将第四十八条改为第四十七条，修改为：“禁止下列破坏古树名木及其生存的生态环境的行为：

“（一）非法采伐或者移植古树名木；

“（二）买卖、运输、加工非法采伐、移植的古树名木；

“（三）挖根、攀树折枝、剥损树皮、过度修剪枝干；

“（四）向古树名木灌注有毒有害物质；

“（五）在古树名木保护范围内铺设非通透性硬化地面、使用明火、堆放重物、倾倒易燃易爆物品或者有毒有害物质；

“（六）在古树名木上刻划、钉钉、架设线缆、缠绕或者悬挂物体等；

“（七）借树搭棚或者做支撑物；

“（八）破坏古树名木保护设施、保护标志；

“（九）其他破坏古树名木及其生存的生态环境的行为。”

（五）将第四十九条改为第四十八条，第二款中的“迁移”修改为“移植”、“作出保护古树名木成活的承诺”修改为“提交相应的移植和养护方案”，第三款修改为：“移植古树名木所需费用的承担，按照国家有关规定执行。”

（六）将第六十三条改为第六十二条，修改为：“违反本条例规定，非法采伐、移植古树名木或者有其他破坏古树名木及其生存的生态环境的行为的，由城市管理主管部门、林业行政主管部门按照职责分工，依照《古树名木保护条例》的有关规定予以处理。”

（七）将第六十四条改为第六十三条，修改为：“违反本条例规定，未提交古树名木保护和避让方案或者未按照古树名木保护和避让方案施工的，由城市管理主管部门、林业行政主管部门按照职责分工，依照《古树名木保护条例》的有关规定予以处理。”

四、对《天津市碳达峰碳中和促进条例》作出修改

（一）将第四条第二款修改为：“市人民政府应当科学编制并组织落实本市碳达峰碳中和行动方案，确保本市碳达峰、碳中和各项目标任务落实。”

（二）将第五十五条第二款修改为：“禁止开（围）垦、填埋或者排干自然湿地，禁止永久性截断自然湿地水源。”

（三）将第五十六条第二款修改为：“禁止在依法划定的海洋自然保护区、海滨风景名胜区、重要渔业水域及其他需要特别保护的区域，违法建设污染环境、破坏生态的海岸工程和海洋工程建设项目或者从事其他活动。”

（四）将第七十三条修改为：“违反本条例规定，重点排放单位未清缴或者未足额清缴碳排放配额的，由市生态环境部门责令改正，处一百万元以上五百万元以下罚款；限期内未完成清缴的，处未清缴的碳排放配额清缴时限前一个月市场交易平均成交价格五倍以上十倍以下罚款，可以责令停产整治。”

（五）将第七十四条修改为：“违反本条例规定，重点排放单位有下列行为之一的，由市生态环境部门责令改正，处五万元以上五十万元以下罚款；拒不改正的，可以责令停产整治：

“（一）未按照规定制定并执行温室气体排放数据质量控制方案的；

“（二）未按照规定报送排放统计核算数据、温室气体排放报告的；

“（三）未按照规定向社会公开温室气体排放报告中的排放量、排放设施、统计核算方法等信息的；

“（四）未按照规定保存温室气体排放报告所涉数据的原始记录和管理台账的。”

（六）将第七十五条第三款修改为：“使用国家或者本市明令淘汰的用能设备或者生产工艺的，由节能主管部门依照有关法律、法规的规定予以处理。”

（七）将第七十八条修改为：“违反本条例规定，开（围）垦、填埋自然湿地的，由市和相关区有关主管部门责令停止违法行为，限期修复湿地或者采取其他补救措施，没收违法所得，并按照破坏湿地面积，处每平方米五百元以上五千元以下罚款；破坏国家重要湿地的，并按照破坏湿地面积，处每平方米一千元以上一万元以下罚款。

“违反本条例规定，排干自然湿地或者永久性截断自然湿地水源的，由市规划资源主管部门或者相关区湿地保护管理部门责令停止违法行为，限期修复湿地或者采取其他补救措施，没收违法所得，并处五万元以上五十万元以下罚款；造成严重后果的，并处五十万元以上一百万元以下罚款。”

（八）将第七十九条修改为：“违反本条例规定，造成海洋生态系统破坏的，由负有生态环境保护监督管理职责的部门、机构责令改正、采取补救措施，处每平方米一千元以上一万元以下罚款；有违法所得的，没收其违法所得。”

五、对《天津市生活垃圾管理条例》作出修改

（一）将第一条中的“中华人民共和国固体废物污染环境防治法”修改为“中华人民共和国生态环境法典”。

（二）将第二十四条中的“不得随意倾倒、抛撒、堆放或者焚烧”修改为“不得随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧”。

（三）将第三十条第一款第四项修改为：“（四）不得在收集、运输过程中随意倾倒、堆放、丢弃、抛撒、遗撒或者焚烧生活垃圾”。

（四）将第六十三条修改为：“违反本条例规定，未遵守国家有关禁止、限制使用不可降解塑料袋等一次性塑料制品的规定，或者未按照国家有关规定报告塑料袋等一次性塑料制品使用、回收情况的，由商务、邮政等部门按照职责分工责令改正，对企业事业单位处一万元以上十万元以下罚款，对其他生产经营者处五百元以上五千元以下罚款。”

（五）将第六十五条第三款修改为：“违反本条例规定，产生生活垃圾的单位擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的，由城市管理部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，依法指定有治理能力的单位代为治理，所需费用由违法者承担。个人擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧个人产生的生活垃圾的，由城市管理部门责令改正，处一百元以上一千元以下罚款。”

（六）将第六十七条修改为：“违反本条例规定，生活垃圾分类投放管理责任人将生活垃圾交由不符合规定的单位或者其他经营者进行收集、运输、处理的，由城市管理部门责令改正，处一万元以上十万元以下罚款。

“违反本条例规定，产生、收集厨余垃圾的单位和其他生产经营者将厨余垃圾交由不具备相应资质条件的单位进行处理的，由城市管理部门责令改正，没收违法所得，处十万元以上一百万元以下罚款；个人有该项行为的，由城市管理部门责令改正，没收违法所得，处一百元以上五百元以下罚款。

“违反本条例规定，畜禽养殖场、养殖小区将未经无害化处理的厨余垃圾饲喂畜禽的，由城市管理部门责令改正，可以处十万元以下罚款；情节严重的，报经有批准权的人民政府批准，责令停业、关闭。”

（七）将第六十九条修改为：“违反本条例规定，生活垃圾收集、运输单位将已分类的生活垃圾混合收集、混合运输的，由城市管理部门责令改正，处五万元以上五十万元以下罚款，没收违法所得；情节严重的，吊销其生活垃圾经营性收集、运输服务许可证。

“违反本条例规定，生活垃圾收集、运输单位在收集、运输过程中擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的，由城市管理部门责令停止违法行为，采取治理措施消除污染，没收违法所得，并处十万元以上一百万元以下罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，依法指定有治理能力的单位代为治理，所需费用由违法者承担。”

六、对《天津市城镇排水和再生水利用管理条例》作出修改

（一）将第二十二条第一款第四项中的“列入重点排污单位名录的排水户已安装主要水污染物排放自动监测设备”修改为“实行排污许可重点管理的排水户已按照规定安装自动监测设备”。

（二）将第三十二条第一款中的“禁止擅自倾倒、堆放、丢弃、遗撒城镇污水处理设施产生的污泥和处理处置后的污泥”修改为“禁止擅自倾倒、堆放、丢弃、抛撒、遗撒或者焚烧城镇污水处理设施产生的污泥和处理处置后的污泥”。

（三）将第六十二条第二款修改为：“违反本条例规定，擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧城镇污水处理设施产生的污泥和处理处置后的污泥的，由城镇排水主管部门、生态环境主管部门按照职责分工责令停止违法行为，采取治理措施消除污染，没收违法所得，并处二十万元以上二百万元以下罚款；对直接负责的主管人员和其他直接责任人员处二万元以上十万元以下罚款；造成严重后果的，处二百万元以上五百万元以下罚款；情节严重的，责令限制生产、停产整治；拒不采取治理措施的，依法指定有治理能力的单位代为治理，所需费用由违法者承担。”

七、对《天津市人民代表大会常务委员会关于禁止燃放烟花爆竹的决定》作出修改

（一）将第一段中的“中华人民共和国大气污染防治法”修改为“中华人民共和国生态环境法典”。

（二）将第五条中的“安全生产监督管理”修改为“应急管理”，“环境保护”修改为“生态环境”，“城市管理综合执法”修改为“城市管理”。

八、对《天津市人民代表大会常务委员会关于加强滨海新区与中心城区中间地带规划管控建设绿色生态屏障的决定》作出修改

（一）将第三条第一款和第八条第三款中的“城乡规划”修改为“规划资源”。

（二）将第七条修改为：“滨海新区与中心城区中间地带规划管控地区与本市生态保护红线重叠的，按照最严格的管控标准实施保护和管理。”

（三）将第八条第四款修改为：“发展改革、财政、住房城乡建设、城市管理、水务、生态环境等部门按照各自职责做好相关工作，确保绿色生态屏障建设和规划管控要求落实。”

本决定自2026年8月15日起施行。

《天津市生态文明教育促进条例》、《天津市绿色生态屏障管控地区管理若干规定》、《天津市绿化条例》、《天津市碳达峰碳中和促进条例》、《天津市生活垃圾管理条例》、《天津市城镇排水和再生水利用管理条例》、《天津市人民代表大会常务委员会关于禁止燃放烟花爆竹的决定》、《天津市人民代表大会常务委员会关于加强滨海新区与中心城区中间地带规划管控建设绿色生态屏障的决定》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
