# 酒泉市人民代表大会常务委员会关于修改《酒泉市饮用水水源地保护条例》等六部法规的决定

酒泉市人民代表大会常务委员会关于修改
《酒泉市饮用水水源地保护条例》等六部
法规的决定

（2026年6月30日酒泉市第五届人民代表大会常务委员会第三十九次会议通过　2026年7月30日甘肃省第十四届人民代表大会常务委员会第二十四次会议批准）

酒泉市第五届人民代表大会常务委员会第三十九次会议决定：

一、对《酒泉市饮用水水源地保护条例》作出修改

（一）将第一条中的“《中华人民共和国水污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第九条第一款修改为：“市、县（市、区）人民政府编制国民经济和社会发展规划、生态保护与建设规划、国土空间规划等综合规划，应当优先考虑饮用水水源地保护。”

（三）删去第十一条第三款。

（四）将第十五条第一款中的“适时依法调整饮用水水源保护区、保护范围”修改为“制定饮用水水源保护区、保护范围调整方案，并报省人民政府批准”。

（五）删去第十七条第一款第三项。

将第八项改为第七项，修改为：“（七）法律、法规和本条例禁止的其他行为。”

（六）删去第十八条第一款第六项。

将第九项改为第八项，修改为：“（八）法律、法规和本条例禁止的其他行为。”

删去第十八条第四款。

（七）将第二十一条中的“就项目实施对饮用水水源保护区环境影响进行专题评价”修改为“进行生态环境影响评价”；“批准”修改为“审批”。

（八）删去第二十四条。

（九）删去第三十条。

（十）将第三十一条改为第二十九条，修改为：“市、县（市、区）人民政府应当组织生态环境、水行政、城乡建设、卫生健康等部门，建立饮用水水源信息管理系统和共享机制。统一发布本行政区域内的饮用水水源地设置、饮用水水源保护区、保护范围划分、饮用水水质等信息，至少每季度向社会公开一次饮用水安全状况信息。”

（十一）将第三十四条改为第三十二条，第二款修改为：“饮用水供水单位应当按照国家规定配备应急设备和器材，并根据所在地饮用水安全突发事件应急预案，制定相应的突发事件应急预案，报市、县（市、区）人民政府备案，并定期进行应急演练。”

第三款修改为：“饮用水水源保护区内的企业事业单位和其他生产经营者应当按照国家规定配备应急设备和器材，制定饮用水安全突发事件应急预案，报市、县（市、区）人民政府生态环境等有关部门备案。”

（十二）将第三十八条改为第三十六条，修改为：“违反本条例第十六条的规定，在饮用水水源保护区内设置排污口的，由市、县（市、区）人民政府责令限期拆除，逾期不拆除的，强制拆除，所需费用由违法者承担，由市人民政府生态环境主管部门或者其派出机构处十万元以上五十万元以下的罚款；情节严重的，处五十万元以上一百万元以下的罚款，责令限制生产、停产整治；构成犯罪的，依法追究刑事责任。”

（十三）将第三十九条改为第三十七条，第一款修改为：“违反本条例第十七条、第十八条、第十九条的规定，在饮用水水源一级保护区内新建、改建、扩建与供水设施和保护水源无关的建设项目的，在二级保护区内新建、改建、扩建排放污染物的建设项目的，在准保护区内新建、扩建对水体污染严重的建设项目或者改建建设项目增加排污量的，由市人民政府生态环境主管部门或者其派出机构责令停止违法行为，处十万元以上五十万元以下的罚款，并报经有批准权的人民政府批准，责令拆除或者关闭。构成犯罪的，依法追究刑事责任。”

（十四）将第四十条改为第三十八条，删去第一项。

（十五）将第四十一条改为第三十九条，删去第一款第三项。

（十六）删去第四十二条。

（十七）将第四十四条改为第四十一条，修改为：“违反本条例第三十二条第二款、第三款的规定，不按照规定制定饮用水安全突发事件应急预案、应急预案未按规定备案、未配备应急设备器材的，由负有生态环境保护监督管理职责的部门、机构按照职责分工责令改正；情节严重的，处一万元以上五万元以下的罚款。”

（十八）将第四十六条改为第四十三条，修改为：“违反本条例规定，法律、法规已有处罚规定的，依照其规定。”

二、对《酒泉市锁阳城遗址保护条例》作出修改

（一）删去第十七条第一项。

（二）将第十八条修改为：“在锁阳城遗址保护范围内不得进行文物保护工程以外的其他建设工程或者爆破、钻探、挖掘等作业；因特殊情况需要进行的，必须保证锁阳城遗址的安全，并依法办理审批手续。”

（三）将第十九条第一款修改为：“在锁阳城遗址建设控制地带内进行建设工程，不得破坏锁阳城遗址的历史风貌；工程设计方案应当经相应的文物行政部门同意后，依法取得建设工程规划许可。”

（四）删去第二十五条第一款。

（五）将第二十六条修改为：“违反本条例的规定，有下列行为之一，尚不构成犯罪的，由瓜州县文物行政部门依照《中华人民共和国文物保护法》的规定予以处罚：

“（一）擅自在锁阳城遗址保护范围内进行文物保护工程以外的其他建设工程或者爆破、钻探、挖掘等作业；

“（二）工程设计方案未经文物行政部门同意，擅自在锁阳城遗址建设控制地带内进行建设工程。”

（六）删去第二十七条。

（七）将第二十八条改为第二十七条，修改为：“违反本条例规定，法律、法规已有处罚规定的，依照其规定。”

三、对《酒泉市城市建筑垃圾管理条例》作出修改

（一）将第一条中的“《中华人民共和国固体废物污染环境防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第三条修改为：“本条例所称建筑垃圾，是指建设单位、施工单位新建、改建、扩建和拆除各类建筑物、构筑物、管网等，以及居民装饰装修房屋过程中产生的弃土、弃料和其他固体废物。

“建筑垃圾中属于危险废物的，依照相关法律、法规的规定处置。”

（三）将第六条第二款修改为：“县（市、区）城市管理主管部门负责建筑垃圾处置的日常监督检查。”

（四）将第九条中的“倾倒、抛撒或者堆放建筑垃圾”修改为“倾倒、堆放、丢弃、抛撒、遗撒、焚烧建筑垃圾”。

（五）将第十条修改为：“任何单位和个人都有权对违法处置建筑垃圾的行为进行劝阻、投诉和举报。住房和城乡建设主管部门收到投诉、举报后，应当及时处理，并对举报人的相关信息予以保密；对实名举报的，应当反馈处理结果等情况。举报人举报所在单位的，该单位不得以解除、变更劳动合同、聘用合同，或者以其他方式对举报人进行打击报复。”

（六）将第十一条第二款修改为：“建设单位应当按照规定将建筑垃圾污染防治费用列入工程造价，在施工合同中明确施工单位的建筑垃圾污染防治责任。”

（七）将第十三条修改为：“住房和城乡建设主管部门发放《建筑垃圾处置（排放）许可证》时，应当根据实际承运建筑垃圾的运输车辆配发相应的《建筑垃圾处置（排放）许可证》副本。”

（八）将第十五条第五项修改为：“（五）法律、法规规定的其他要求。”

（九）将第十八条第一款第三项修改为：“（三）法律、法规规定的其他条件。”

（十）将第二十四条第一款第四项修改为：“（四）法律、法规规定的其他材料。”

（十一）将第二十五条修改为：“禁止在下列区域设置建筑垃圾消纳场：

“（一）生态保护红线区域、永久基本农田集中区域和自然保护区、风景名胜区、湿地；

“（二）饮用水水源保护区、水源林地；

“（三）河流、湖泊、水库、渠道、山体等保护范围；

“（四）法律、法规规定的其他需要特别保护的区域。”

（十二）将第二十六条第六项修改为：“（六）法律、法规的其他规定。”

（十三）删去第四十条、第四十一条、第四十二条、第四十三条、第四十四条、第四十五条。

（十四）将第四十八条改为第四十二条，修改为：“违反本条例规定，法律、法规已有处罚规定的，依照其规定。”

四、对《酒泉市城市绿化管理条例》作出修改

（一）将第三十一条第三款修改为：“禁止采伐古树名木。古树名木原则上实行原地保护，不得移植。确需移植古树名木的，建设单位应当提出移植申请并提交相应的移植和养护方案，按照涉及古树名木的最高保护等级，经认定古树名木的县级以上人民政府古树名木主管部门审核并报本级人民政府批准。”

（二）将第三十二条第一项修改为：“（一）绿地内倾倒废弃物、垃圾的”。

增加一项，作为第二项：“（二）绿地内倾倒生活污水的”。

（三）将第三十九条修改为：“违反本条例规定，采伐、移植古树名木，或者有其他危害古树名木行为的，依照《古树名木保护条例》的规定进行处罚；造成损失的，应当负赔偿责任；应当给予治安管理处罚的，依照《中华人民共和国治安管理处罚法》的有关规定处罚；构成犯罪的，依法追究刑事责任。”

（四）将第四十条修改为：“违反本条例第三十二条第一项规定，依据《中华人民共和国生态环境法典》相关规定进行处罚。

“违反本条例第三十二条其他规定的，由城市绿化行政主管部门责令停止侵害，情节轻微的，可以并处警告或者五十元以下罚款；情节较重的，可以并处五十元以上五百元以下罚款；情节严重的，可以并处五百元以上五千元以下罚款；造成损失的，应当负赔偿责任；应当给予治安管理处罚的，依照《中华人民共和国治安管理处罚法》的有关规定处罚；构成犯罪的，依法追究刑事责任。”

（五）将第四十一条修改为：“违反本条例规定，法律、法规已有处罚规定的，依照其规定。”

五、对《酒泉市扬尘污染防治条例》作出修改

（一）将第一条中的“《中华人民共和国大气污染防治法》”修改为“《中华人民共和国生态环境法典》”。

（二）将第二条中的“城市绿化工程施工，城市道路清扫保洁”修改为“绿化工程施工，道路清扫保洁”。

（三）将第十一条第一款中的“从事房屋建筑及其附属设施、市政工程、建（构）筑物拆除、城市绿化等施工单位”修改为“从事房屋建筑、市政基础设施建设、河道整治以及建（构）筑物拆除等施工单位”；将“制定具体的施工扬尘污染防治实施方案，落实扬尘污染防治措施”修改为“制定具体的施工扬尘污染防治实施方案，报负有扬尘污染防治监督管理职责的部门备案，落实扬尘污染防治措施。”

（四）将第二十一条第一款中的“煤炭、煤矸石、煤渣、煤灰、水泥、石灰、砂土、有机肥料”修改为“煤炭、煤矸石、煤渣、煤灰、水泥、石灰、石膏、砂土、铁矿石”。

（五）将第二十七条第二款修改为：“接到投诉举报，属于本部门职责的，应当即时处理。对不属于本部门管辖的，应当转交有监管职责的部门处置，并明确告知投诉举报人。对实名举报的，应当反馈处理结果等情况。接受举报的机关应当对举报人的相关信息予以保密。举报人举报所在单位的，该单位不得以解除、变更劳动合同、聘用合同，或者以其他方式对举报人进行打击报复。”

（六）将第二十八条修改为：“违反本条例规定，以拖延、围堵、滞留执法人员等方式拒绝、阻挠依法开展的监督检查和调查处理，或者在接受监督检查和调查处理时弄虚作假或者拒不提供必要资料的，由负有生态环境保护监督管理职责的部门、机构按照职责分工责令改正，处五万元以上二十万元以下罚款；对直接负责的主管人员和其他直接责任人员，处五千元以上五万元以下的罚款；构成违反治安管理行为的，由公安机关依法予以处罚。”

（七）删去第二十九条。

（八）将第三十一条改为第三十条，第一款修改为：“违反本条例第十三条、第十四条、第十五条、第十六条、第十八条规定，未采取扬尘污染防治措施的，由住房和城乡建设等主管部门责令改正，处一万元以上十万元以下罚款；拒不改正的，责令停工整治或者停业整治。”

（九）将第三十五条改为第三十四条，修改为：“违反本条例规定，法律、法规已有处罚规定的，依照其规定。”

六、对《酒泉市电动车管理条例》作出修改

（一）删去第十四条。

（二）将第十五条改为第十四条，修改为：“电动车所有人或者管理人应当将电动车废旧蓄电池交由具有相应危险废物经营资质的单位进行收集、贮存、利用、处置，不得随意丢弃。

“电动车及其蓄电池的生产者、销售者、维修者应当设置与其业务规模相适应的专门场所贮存、收集废旧蓄电池，落实国家关于危险废物和化学物质风险防控的各项要求，建立可追溯的全过程信息台账，将收集的废旧蓄电池依法移交给具备相应资质的单位进行处置。

“涉及重点管控新污染物清单所列物质的废旧蓄电池，其回收、运输、处置等活动应当严格遵守国家有关风险管控措施的规定。”

本决定自2026年8月15日起施行。

《酒泉市饮用水水源地保护条例》《酒泉市锁阳城遗址保护条例》《酒泉市城市建筑垃圾管理条例》《酒泉市城市绿化管理条例》《酒泉市扬尘污染防治条例》《酒泉市电动车管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
