# 丽水市人民代表大会常务委员会关于修改《丽水市物业管理条例》的决定

丽水市人民代表大会常务委员会关于修改
《丽水市物业管理条例》的决定

（2025年11月28日丽水市第五届人民代表大会常务委员会第三十一次会议通过　2025年12月23日浙江省第十四届人民代表大会常务委员会第二十一次会议批准）

丽水市第五届人民代表大会常务委员会第三十一次会议决定对《丽水市物业管理条例》作如下修改：

一、将第五条第一款修改为：“街道办事处、乡（镇）人民政府负责指导、监督本辖区业主大会、业主委员会等业主组织的组建和日常运行，协调物业管理与社区治理、社区建设的关系，调解物业管理纠纷。”

二、将第十八条第三款中的“公示期内提出书面反对意见的业主少于业主总人数的三分之一且其专有部分少于建筑物总面积三分之一的，业主代表大会作出的决议生效”修改为“业主代表大会作出决议不得违反《中华人民共和国民法典》规定的业主共同决定重大事项的表决程序”。

三、在第三十八条第一款中的“物业服务合同签订”后增加“或者变更”。

第二款增加一项，作为第一项：“（一）按照物业服务合同的约定提供相应服务并指派项目负责人负责物业服务项目的运营和管理”。

四、删去第五十一条、第五十二条。

五、将第五十五条改为第五十三条，第二款、第三款修改为：“发生前款所列紧急情况，需要立即对房屋共用部位、共用设施设备进行维修和更新的，业主委员会可以向县（市、区）物业主管部门提出物业专项维修资金使用需求。县（市、区）物业主管部门可以直接拨付申请额度百分之五十至七十的维修资金。工程竣工验收后，按实结算。物业专项维修资金拨付完成十五日内，申请人应当将维修资金使用总额以及业主分摊情况在物业管理区域内显著位置公布。

“业主委员会未及时组织修缮的，街道办事处、乡（镇）人民政府应当通知业主大会或者业主委员会限期组织修缮；逾期未修缮的，街道办事处、乡（镇）人民政府可以组织代为修缮，维修费用由相关业主共同承担，可以在物业专项维修资金中列支。”

六、将第六十二条改为第六十条，删去第一款中的“物业保修金管理使用办法”。

七、将条例中的“物业管理用房”修改为“物业服务用房”。

此外，对个别文字表述作修改。

本决定自公布之日起施行。

《丽水市物业管理条例》根据本决定作相应修改并对条文顺序作相应调整，重新公布。
