# 云南省人民代表大会常务委员会关于修改《云南省赤水河流域保护条例》的决定

云南省人民代表大会常务委员会关于修改
《云南省赤水河流域保护条例》的决定

（2026年7月28日云南省第十四届人民代表大会常务委员会第二十四次会议通过）

云南省第十四届人民代表大会常务委员会第二十四次会议决定对《云南省赤水河流域保护条例》作如下修改：

一、将第一条修改为：“为了加强赤水河流域保护，践行绿水青山就是金山银山理念，促进资源合理高效利用，维护生态安全，推动绿色发展，推进人与自然和谐共生，根据《中华人民共和国生态环境法典》、《中华人民共和国长江保护法》等法律、行政法规，结合本省实际，制定本条例。”

二、将第十六条第二款修改为：“禁止非法侵占和违法利用、占用赤水河流域水域和岸线、围垦河道、填埋河湖。”

三、将第二十五条第一款修改为：“排放污染物，应当符合污染物排放标准、重点污染物排放总量控制指标、排污许可管理和有关法律、法规、规章的要求。”

四、将第三十三条第三款修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护污染物排放自动监测设备，开展监控、自动监测，并与生态环境部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。”

五、将第六十三条第一款改为两款，修改为：“违反本条例第三十九条第五项规定，使用国家明令禁止使用的农药，被责令改正，拒不改正的，由县级人民政府农业农村部门依照有关法律、法规的规定予以处罚，并将案件移送公安机关，由公安机关依法处理。

“违反本条例第三十九条第五项规定，向河道内丢弃农药、农药包装物的，由县级人民政府农业农村部门责令改正，农药使用者为单位的，处5万元以上10万元以下罚款，农药使用者为个人的，处1万元以下罚款。”

六、将第六十六条修改为：“违反本条例规定的行为，法律、行政法规已有法律责任规定的，从其规定。”

七、对部分条文中的有关表述作以下修改：

（一）将第三十五条第一款中的“环境影响评价”修改为“生态环境影响评价”。

（二）将第三十七条第一款中的“可能发生水污染事故的企业事业单位”修改为“企业事业单位和其他生产经营者”、“应当做好”修改为“应当依法做好”；将第二款中的“应急方案”修改为“应急预案”。

（三）将第三十九条第二项中的“有毒污染物”修改为“有毒有害污染物”；在第四项中的“堆放”后增加“贮存”；将第五项中的“使用禁用的农药”修改为“使用国家明令禁止使用的农药”。

本决定自2026年8月15日起施行。

《云南省赤水河流域保护条例》根据本决定作相应修改，重新公布。
