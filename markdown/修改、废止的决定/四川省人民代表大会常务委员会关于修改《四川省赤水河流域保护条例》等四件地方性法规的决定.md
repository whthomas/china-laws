# 四川省人民代表大会常务委员会关于修改《四川省赤水河流域保护条例》等四件地方性法规的决定

四川省人民代表大会常务委员会
关于修改《四川省赤水河流域保护条例》等
四件地方性法规的决定

（2026年7月29日四川省第十四届人民代表大会常务委员会第二十八次会议通过）

四川省第十四届人民代表大会常务委员会第二十八次会议决定对《四川省赤水河流域保护条例》等四件地方性法规作如下修改：

一、对《四川省赤水河流域保护条例》作出修改

（一）将第一条修改为：“为了加强赤水河流域保护，促进资源合理高效利用，保障生态安全，推进绿色发展，实现人与自然和谐共生，根据《中华人民共和国生态环境法典》、《中华人民共和国长江保护法》等法律、行政法规，结合四川省实际，制定本条例。”

（二）将第三十四条第一款修改为：“排放污染物，应当符合污染物排放标准、重点污染物排放总量控制指标、排污许可管理和有关法律、法规、规章的要求。”

（三）将第三十六条第三款修改为：“实行排污许可重点管理的企业事业单位和其他生产经营者，应当按照国家规定安装、使用、维护水污染物排放自动监测设备，开展监控、自动监测，并与生态环境主管部门的监控设备联网，保证自动监测设备正常运行，保存原始监测记录。”

（四）将第六十四条修改为：“赤水河流域地方各级人民政府、负有生态环境保护监督管理职责的部门、机构未履行本条例规定职责，有玩忽职守、滥用职权、徇私舞弊行为的，对负有责任的领导人员和直接责任人员依法给予处分；涉嫌犯罪的，移送司法机关，依法追究刑事责任。”

（五）将第六十八条第一款第一项修改为：“（一）未依法取得排污许可证排放水污染物的”；增加一项，作为第二项：“（二）违反排污许可证规定排放污染物的”；将第二项、第三项、第四项分别改为第三项、第四项、第五项。

增加一款，作为第二款：“有前款第二项、第四项行为之一，情节严重的，并处吊销排污许可证。”

将第二款改为第三款，修改为：“企业事业单位和其他生产经营者违法排放水污染物，受到罚款处罚，被责令改正的，依法作出处罚决定的部门或者机构应当组织复查，发现其继续违法排放水污染物或者拒绝、阻挠复查的，依照《中华人民共和国生态环境法典》的规定按日连续处罚。”

（六）将第六十九条第一款修改为：“违反本条例第四十三条第五项规定的，由赤水河流域县级人民政府农业农村主管部门责令改正，没收国家明令禁止使用的农药，农药使用者为单位的，并处五万元以上十万元以下罚款，农药使用者为个人的，处一万元以下罚款。”

增加一款，作为第二款：“使用国家明令禁止使用的农药，被责令改正，拒不改正的，由赤水河流域县级人民政府农业农村主管部门依照有关法律法规的规定予以处罚，并将案件移送公安机关，由公安机关依法处理。”

（七）删除第七十条。

（八）对部分条文中的有关表述作以下修改：

1.将第三十八条第一款中的“环境影响评价”修改为“生态环境影响评价”。

2.在第四十条第一款中的“企业事业单位”后增加“和其他生产经营者”，“应当”后增加“依法”；将第二款中的“应急方案”修改为“应急预案”。

3.将第四十三条第二项中的“有毒污染物”修改为“有毒有害污染物”；在第四项中的“堆放”后增加“贮存”；将第五项中的“禁用”修改为“国家明令禁止使用”。

此外，对条文顺序作相应调整。

二、对《四川省嘉陵江流域生态环境保护条例》作出修改

（一）将第一条修改为：“为了加强嘉陵江流域生态环境保护和修复，促进资源合理高效利用，主动融入和服务长江经济带发展战略，促进绿色发展，保障生态安全，实现人与自然和谐共生，根据《中华人民共和国生态环境法典》、《中华人民共和国长江保护法》等法律、行政法规，结合四川省实际，制定本条例。”

（二）将第十九条第二款修改为：“对超过重点水污染物排放总量控制指标或者未完成水生态环境质量目标的地区，省人民政府生态环境主管部门应当暂停审批该地区新增重点水污染物排放总量的建设项目的生态环境影响报告书、生态环境影响报告表。”

增加一款，作为第三款：“省人民政府生态环境主管部门会同有关部门对水环境污染问题突出、防治工作不力、群众反映强烈的地区，约谈县级以上地方人民政府及其有关部门主要负责人，要求其采取有效措施及时整改。约谈整改情况应当向社会公开。”

（三）将第九十八条修改为：“嘉陵江流域地方各级人民政府、负有生态环境保护监督管理职责的部门、机构，未依法履行管理职责或者滥用职权、徇私舞弊、玩忽职守的，对负有责任的领导人员和直接责任人员依法给予处分；构成犯罪的，依法追究刑事责任。”

（四）将第一百零三条第二项修改为：“（二）船舶经营者未将餐厨垃圾贮存在专门的容器中，收集上岸集中处置的，或者未如实记录处置情况的，责令改正，处五千元以上五万元以下罚款”。

（五）对部分条文中的有关表述作以下修改：

1.将第七条、第十五条、第一百零二条中的“县级以上”删除。

2.将第十六条第二款中的“县级以上地方”修改为“设区的市级”。

3.将第二十七条第一项中的“环境质量状况”修改为“生态环境质量状况”，第四项中的“环境监测情况”修改为“生态环境监测情况”。

4.在第七十三条中的“堆放”后增加“贮存”，“固体废物”后增加“和其他污染物”。

5.将第八十条第一款中的“落后”删除；在“工艺”前增加“技术”，“设备”后增加“材料、产品”。

三、对《四川省泸沽湖保护条例》作出修改

（一）将第一条修改为：“为了加强泸沽湖的保护和管理，促进生态文明建设和经济社会高质量发展，牢固树立和践行绿水青山就是金山银山的理念，实现人与自然和谐共生，根据《中华人民共和国生态环境法典》、《中华人民共和国水法》、《中华人民共和国长江保护法》、《中华人民共和国湿地保护法》、国务院《风景名胜区条例》等法律、行政法规和国家关于自然保护地管理的相关规定，结合泸沽湖实际，制定本条例。”

（二）将第六十七条第一款第十四项修改为：“（十四）擅自倾倒、堆放、丢弃、抛撒、遗撒、焚烧生活垃圾的，责令改正，没收违法所得，对单位处十万元以上一百万元以下的罚款，对个人处一百元以上一千元以下的罚款”。

增加一项，作为第十五项：“（十五）随意填埋生活垃圾、丢弃畜禽尸体等废弃物的，责令改正，造成环境污染的，并处五千元以上二万元以下的罚款”。

将第十五项、第十六项分别改为第十六项、第十七项。

四、对《四川省城乡环境综合治理条例》作出修改

（一）将第二十六条第二款修改为：“城乡道路上行驶的各种机动车辆应当保持车容整洁。运输煤炭、垃圾、渣土、砂石、土方、灰浆等散装、流体物料的车辆应当采取密闭或者其他有效措施防止物料遗撒造成扬尘污染，并按照规定路线行驶。”

（二）在第四十条中的“工业固体废物”后增加“农业固体废物”。

（三）将第四十五条第五项修改为：“（五）在人口集中地区、机场周围、交通干线附近以及省级以上人民政府划定的其他区域和规定的时段露天焚烧秸秆、落叶等产生烟尘污染的物质”。

（四）将第六十七条修改为：“违反本条例第二十六条第二款规定，车辆未采取密闭或者其他措施，或者未按照规定路线行驶，造成泄漏遗撒的或者违规倾倒的，责令清除改正，处二千元以上二万元以下罚款；拒不采取清除措施的，指定有清除能力的单位代为清除，其费用由违法行为人承担；拒不改正的，车辆不得上道路行驶。”

（五）删除第六十八条。

（六）将第七十一条改为第七十条，修改为：“单位或者个人有本条例第四十五条第一项、第二项、第六项、第七项规定影响城镇环境卫生行为之一的，责令改正或者清除；拒不改正或者清除的，指定有清除能力的单位代为清除，其费用由违法行为人承担；情节严重或者造成严重后果的，并处个人五十元以上二百元以下罚款，单位五百元以上二千元以下罚款。”

此外，对条文顺序作相应调整。

本决定自2026年8月15日起施行。

《四川省赤水河流域保护条例》、《四川省嘉陵江流域生态环境保护条例》、《四川省泸沽湖保护条例》、《四川省城乡环境综合治理条例》根据本决定作相应修改后，重新公布。
