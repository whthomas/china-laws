# 辽宁省契税具体适用税率的调整方案

辽宁省契税具体适用税率的调整方案

根据《中华人民共和国契税法》第三条规定，结合我省实际，对契税具体适用税率调整方案规定如下：

一、我省契税适用税率为3%。

二、本方案自2023年1月1日起施行。
