# 青海省人民代表大会常务委员会关于批准青海省资源税税目税率及优惠政策实施方案的决定

青海省人民代表大会常务委员会

关于批准青海省资源税税目税率及优惠

政策实施方案的决定
(2020年7月22日青海省第十三届人民代表大会

常务委员会第十八次会议通过)
青海省第十三届人民代表大会常务委员会第十八次会议决定：批准省人民政府关于《青海省资源税税目税率及优惠政策实施方案》，适用税目税率按照方案所附的《青海省资源税税目税率表》执行。

本决定自2020年9月1日起施行。
