# 南平市气象灾害预警与响应条例

南平市气象灾害预警与响应条例

（2026年7月30日南平市第六届人民代表大会常务委员会第三十三次会议通过2026年9月23日福建省第十四届人民代表大会常务委员会第二十四次会议批准）

第一章总则

第一条为了规范气象灾害预警与响应活动，提升气象灾害防御能力，保障人民生命财产安全，服务经济和社会发展，根据

－1－

《中华人民共和国气象法》、国务院《气象灾害防御条例》和《福建省气象条例》等有关法律、法规，结合本市实际，制定本条例。第二条本条例适用于本市行政区域内气象灾害预警与响应及相关管理活动。本条例所称气象灾害，是指暴雨（雪）、台风、寒潮、大风、低温、高温、干旱、雷电、冰雹、霜冻、冰冻和大雾等所造成的灾害。水旱灾害、地质灾害、森林火灾等因气象因素引发的衍生、次生灾害的预警与响应工作，适用有关法律、法规的规定。第三条气象灾害预警与响应工作遵循以人为本、科学防御，政府主导、部门联动，区域协作、社会参与的原则。第四条市、县（市、区）人民政府应当加强对气象灾害预警与响应工作的组织、领导和协调，做好气象灾害监测、预警系统建设，将气象灾害预警与响应工作纳入气象灾害防御规划，所需经费列入本级财政预算。乡镇人民政府、街道办事处应当明确气象灾害防御工作责任人员，做好本辖区内气象灾害预警信息传播、风险隐患排查管控、灾情险情即时报送等气象灾害防御工作。第五条气象主管机构负责本行政区域内灾害性天气的监测、预报和预警等工作。应急管理部门负责本行政区域内气象灾害应急救援救助的统筹协调工作，统筹推进避灾安置场所和应急救援力量建设。

－2－

自然资源、生态环境、住房和城乡建设、交通运输、水利、农业农村、林业、发展改革、财政、科技、公安、教育、文化旅游、体育、国防动员、卫生健康、城市管理、民政、工信、水文等部门应当按照职责分工，做好气象灾害预警与响应相关工作。第六条村（居）民委员会应当依法协助当地人民政府及其有关部门做好气象灾害风险隐患排查、预警信息传递、人员转移避险、灾情险情收集上报等工作。鼓励村（居）民委员会依法将气象灾害防御工作相关要求纳入村规民约、居民公约。第七条市、县（市、区）人民政府及其有关部门，乡镇人民政府、街道办事处应当推进气象科普设施建设，加强气象灾害防御知识宣传，提高社会公众防灾避险和自救互救的意识和能力。广播、电视、报纸、网络等应当开展气象灾害预警、应急防范、自救互救等知识的公益宣传。

第二章监测预警

第八条本条例所称气象灾害预警信息，包括灾害性天气警报（预警）和气象灾害预警信号。灾害性天气警报（预警）划分为四级、三级、二级和一级，一级为最高级别；气象灾害预警信号划分为Ⅳ级（一般）、Ⅲ级（较重）、Ⅱ级（严重）、Ⅰ级（特别严重），依次用蓝色、黄色、橙色

－3－

和红色表示，Ⅰ级为最高级别。第九条市、县（市、区）气象主管机构应当加强本行政区域内气象台站的行业管理和业务指导，组织所属气象台站以及与灾害性天气监测有关的单位，对气象灾害实施跨地区、跨部门联合监测，做好农村、重要江河流域、林区、地质灾害和山洪灾害易发区等区域的气象灾害监测工作。气象主管机构应当根据国家有关规定，与其他从事气象工作的机构交换有关气象信息资料。自然资源、生态环境、农业农村、交通运输、水利、水文、电力等部门和单位应当做好气象、地质、水文等行业监测工作，依法向气象主管机构汇交气象探测资料。第十条市、县（市、区）人民政府应当利用突发事件信息系统，汇集、储存、分析、传输有关气象灾害的信息，加强跨部门、跨地区的信息共享与情报合作。市、县（市、区）气象主管机构及其所属气象台站应当完善灾害性天气预警系统，建立智能化气象灾害预报预警平台，做好强台风、暴雨、大雾、雷电、冰雹等重大天气预报和趋势预测，提高灾害性天气预警的准确率和时效性。第十一条气象灾害预警信息由市、县（市、区）气象主管机构所属气象台站统一发布，其他组织或者个人不得向社会发布气象灾害预警信息。市、县（市、区）人民政府应当健全预警信息发布机构，完

－4－

善突发事件预警信息发布系统，在交通枢纽、公共活动场所等人口密集区域和气象灾害易发区域建立气象灾害预警信息接收和播发设施，实现气象灾害预警信息的快速传播。第十二条广播、电视、报纸、电信、网络等应当准确、及时、无偿地向社会播发或者刊登当地气象主管机构所属气象台站发布的适时气象灾害预警信息，不得更改和增减预警信息的内容，不得拒绝传播气象灾害预警信息，不得传播虚假、失效的气象灾害预警信息。对台风、暴雨红色预警信号等重大气象灾害预警信息，广播、电视、报纸、电信、网络等应当建立快速通道或者安排优先通道，采用滚动字幕、加开视频窗口以及插播、短信提示、信息推送等方式及时播发。第十三条建立县、乡、村、户直通的气象灾害预警信息传播渠道。县（市、区）人民政府及其有关部门、乡镇人民政府以及学校、医院、社区、养老机构、工矿企业、建筑工地等应当指定专人负责气象灾害预警信息接收传递工作。乡镇人民政府、街道办事处、村（居）民委员会收到气象灾害预报预警信息后，应当利用有线广播、高音喇叭、鸣锣吹哨、社交网络等多种方式及时传播气象灾害预警信息。村（居）民委员会应当明确责任人，及时将预警信息传达到老年人、未成年人、孕（产）妇、残疾人、伤病人员等特殊群体和偏远住户。

－5－

第十四条市、县（市、区）人民政府应当加强机场、高速公路、铁路等交通要道的有关监测设施建设，及时向公众发布监测信息，保障交通安全。机场、客运码头、车站、景区、学校、医院、高速公路、大型商场、文化体育场（馆）、宾馆、饭店等人员密集场所应当设立电子显示装置、公众广播或者警报器等气象灾害预警信息传播装置，并保证设施的正常运转。其经营、管理单位应当及时向公众传播气象灾害预警信息和应急防御指南。

第三章响应措施

第十五条市、县（市、区）人民政府应当根据气象灾害预警信息种类级别，组织气象、应急管理、水利、自然资源等有关部门开展联合会商，依照气象灾害应急预案及时启动相应级别的应急响应，并报告上一级人民政府。气象灾害应急响应启动后，市、县（市、区）人民政府有关部门应当根据气象灾害发生情况，依照《中华人民共和国突发事件应对法》和有关法律、法规的规定，及时采取相应的应急处置措施。气象灾害应急响应的启动、变更和终止，应当及时向社会公布。第十六条启动四级、三级灾害性天气应急响应后，市、县

－6－

（市、区）人民政府应当针对即将发生的气象灾害的特点和可能造成的危害，组织有关灾害防御、救援部门开展联合会商、隐患排查、划定风险区等工作，对地质灾害点和风险区、低洼地带、危旧房屋等进行重点巡查监测，视情预置应急力量和物资，做好防御准备。第十七条启动二级、一级灾害性天气应急响应后，市、县（市、区）人民政府除采取前条规定的措施外，还应当针对即将发生的气象灾害的特点和可能造成的危害，依法采取组织受威胁人员提前转移避险，对危险区域实施管控、警示或者临时封闭，统筹调配应急物资和生活物资等措施，做好应急救援准备。第十八条乡镇人民政府、街道办事处接收到二级、一级灾害性天气警报（预警）或者橙色、红色气象灾害预警信号，或者发现险情灾情征兆，以及已经发生险情灾情的，应当立即组织开展风险隐患排查、人员转移安置、先期处置，并及时、准确上报险情灾情，不得迟报、漏报、瞒报、谎报。村（居）民委员会应当做好预警传递、巡查警示、群众动员、协助转移等工作。情况紧急的，应当立即组织群众开展自救互救等先期处置工作。第十九条气象灾害防御重点单位应当根据气象灾害预警信息启动本单位应急预案，加强对重点部位的巡查管控，保障运营安全。台风、大风预警信息生效期间，建（构）筑物、户外广告牌、

－7－

玻璃幕墙的所有人、管理人或者使用人应当采取加固和除险措施，防止坠物伤人；工程施工单位应当设置必要警示标识，停止高空作业，加固脚手架和围挡等临时设施。暴雨预警信息生效期间，排水设施运营单位应当做好排水管网和防涝设施的巡检与维护，加强排涝值守，在易涝点设置警示标识，预置排涝装备。大型群众性活动和赛事的承办者应当将气象灾害风险防控纳入安全方案，收到预警信息后，及时采取停止活动、疏散人员、安全管控等应急措施。第二十条公民、法人和其他组织应当服从各级人民政府发布的气象灾害应急处置决定、命令，配合落实有关应急措施，不得阻挠、抗拒依法实施的应急处置行动；发现险情灾情应当及时报告。鼓励具有专业救援能力的志愿服务组织有序参与气象灾害应急救援，帮助群众做好防灾避险。第二十一条市、县（市、区）人民政府应当依法建立与气象灾害预警信息相配套的停工、停产、停业、停运、停课或者调整工作时间等应急响应触发机制。气象灾害可能对人民群众生命财产安全、公共安全、环境安全或者社会秩序造成严重危害，触发停工、停产、停业、停运、停课或者调整工作时间等应急响应措施条件时，市、县（市、区）人民政府应当依法采取相应的应急处置措施，有关单位和个人应

－8－

当严格执行。第二十二条市、县、乡三级人民政府应当建立流域水情、雨情通报制度，统筹流域水库、河道、调蓄设施的科学调度，协同开展流域山洪灾害防御。气象、水利、自然资源、生态环境、农业农村、林业、水文等部门应当加强小流域山洪灾害的联合监测、会商研判，协同开展小流域山洪灾害监测、预报、预警，指导乡镇人民政府、街道办事处做好山洪风险排查防范工作。第二十三条市、县（市、区）人民政府应当加强气象灾害防御工作的舆情引导，统一、准确、及时发布气象灾害防范处置信息，做好相关事项的科学解释和说明工作，增强公众抗御气象灾害的信心。第二十四条气象主管机构所属的气象台站应当根据灾害性天气发生发展趋势，及时更新或者解除气象灾害预警信息。市、县（市、区）人民政府及其有关部门应当根据气象主管机构提供的灾害性天气变化信息以及灾情发展情况，及时调整气象灾害应急响应级别或者作出解除气象灾害应急响应的决定。

第四章区域协作

第二十五条市人民政府应当加强与浙江省衢州市、安徽省黄山市、江西省上饶市等地人民政府在气象灾害预警与响应领域

－9－

的协作，组织有关部门协同开展气象灾害联防联控，提升气象灾害跨区域防御能力。第二十六条鼓励市气象主管机构与浙江省衢州市、安徽省黄山市、江西省上饶市气象主管机构探索制定和依法适用四市统一的灾害性天气警报（预警）区域协同标准。第二十七条市气象主管机构应当与浙江省衢州市、安徽省黄山市、江西省上饶市等气象工作协作区气象主管机构加强跨区域气象灾害监测、预警协作，建设完善区域气象灾害预警服务平台，实行气象监测、预报和预警信息实时共享。第二十八条市应急管理部门应当加强与浙江省衢州市、安徽省黄山市、江西省上饶市等气象工作协作区应急管理部门的联系，开展气象灾害联合救援演练，探索气象灾害的联合救援、物资互助、力量协同等，指导县（市、区）、乡镇加强与毗邻县（市、区）、乡镇应急救援沟通与协作。第二十九条市气象、自然资源、生态环境、住房和城乡建设、交通运输、水利、农业农村、林业等部门应当加强与浙江省衢州市、安徽省黄山市、江西省上饶市等气象工作协作区相应部门的交流与合作，建立行业气象灾害风险联合预警机制，开展气象服务等领域的科学研究、技术攻关和成果共享。第三十条县（市、区）、乡镇人民政府应当加强与毗邻地区县（市、区）、乡镇人民政府的协作，做好气象灾害联合预警、会商研判、医疗救援、物资调配、设施抢修、交通组织等工作。

第五章保障措施

第三十一条市、县（市、区）人民政府应当加强气象灾害应急救援队伍和乡镇（街道）、村（社区）等基层气象信息员队伍建设，定期开展预案演练，切实增强气象灾害应急处置能力。人员密集场所应当明确气象灾害应急救援联系人，定期开展相关应急救援知识和技能培训。第三十二条市、县（市、区）人民政府应当加强公共数据平台建设，归集和共享气象监测、预报和预警数据，推动人工智能、大数据、区块链等信息技术在气象灾害防御工作中的融合应用。鼓励和支持社会力量开展气象灾害防御工作相关的科技创新、产品研发、成果运用。第三十三条市、县（市、区）人民政府应当根据气象灾害防御的需要，按照国家标准或者行业标准，组织建设和完善气象监测站网，在气象灾害易发和防御重点区域，以及重点林区、农作物主产区等区域，增设气象灾害监测站（点），完善气象灾害监测设施。乡镇人民政府、街道办事处应当协助做好气象监测设施选址、建设和维护等工作。第三十四条市、县（市、区）人民政府应当利用公共场所、

第六章法律责任

第三十九条违反本条例的行为，法律、法规已有法律责任规定的，从其规定。第四十条违反本条例第十二条规定，未按照要求播发、刊登气象灾害预警信息的，由气象主管机构给予警告并责令限期改正；逾期不改正的，可以处五千元以上五万元以下的罚款；构成违反治安管理行为的，由公安机关依法给予处罚；构成犯罪的，依法追究刑事责任。第四十一条违反本条例第三十八条规定，侵占、损毁或者擅自移动气象灾害防御设施的，由气象主管机构责令停止违法行为，限期恢复原状或者采取其他补救措施，可以并处五万元以下的罚款；造成损失的，依法承担赔偿责任；构成违反治安管理行为的，由公安机关依法给予处罚；构成犯罪的，依法追究刑事责任。第四十二条违反本条例规定，各级人民政府、气象主管机构和其他有关部门及其工作人员，在气象灾害预警与响应工作中玩忽职守、滥用职权、徇私舞弊行为的，依法给予处分；构成犯罪的，依法追究刑事责任。
