# 太原市城市更新条例

太原市城市更新条例

（2026年8月25日太原市第十五届人民代表大会常务委员会第三十七次会议通过2026年9月24日山西省第十四届人民代表大会常务委员会第三十次会议批准）

第一章总则

第一条为了规范和推进城市更新活动，优化城市空间，完善城市功能，赓续城市文脉，提升城市品质，推动城市高质量发展，建设创新、宜居、美丽、韧性、文明、智慧的现代化人民城市，再现锦绣太原城盛景，根据有关法律、法规，结合本市实际，

－1－

制定本条例。第二条本市行政区域内的城市更新活动及其监督管理，适用本条例。本条例所称城市更新，是指在城镇开发边界内，对城市空间形态和城市功能持续完善和优化调整的活动，主要包括既有建筑改造利用，城镇老旧小区整治改造，完整社区建设和老旧街区、老旧厂区、城中村等更新改造，完善城市功能，建设改造城市基础设施，修复城市生态系统，保护传承城市历史文化以及国家、省和本市确定的城市更新其他任务。第三条城市更新工作坚持中国共产党的领导，坚持以人民为中心，坚持统筹发展和安全，坚持治山、治水、治气、治城一体推进，坚持系统观念、规划引领、民生优先、绿色生态、传承文化，坚持实事求是、因地制宜，尽力而为、量力而行，实行政府引导、市场运作、公众参与，建立可持续的城市更新模式。城市更新工作应当统筹生态、生活、生产空间布局，推动文化、科教、旅游、体育和商业等多元业态深度融合、适度转换，推进基础设施互联互通、公共服务共建共享、产业功能协同互助。第四条市、县（市、区）人民政府应当加强对城市更新工作的领导，将城市更新工作纳入国民经济和社会发展规划，研究决定城市更新重大事项，统筹推进城市更新工作。乡镇人民政府、街道办事处按照职责做好城市更新相关工作。第五条住房和城乡建设部门是城市更新工作的主管部门，

－2－

负责城市更新的综合协调、监督指导等工作，研究制定相关政策和规范，推动城市更新项目实施。规划和自然资源部门负责其职责范围内城市更新相关的规划、土地管理、不动产登记等工作。审批服务管理部门负责城市更新项目审批，优化项目审批流程，提升审批效率。发展改革、教育、工信、公安、民政、财政、生态环境、城乡管理、交通运输、水务、商务、文旅、卫健、应急、国资、体育、文物、国防动员、房产、园林、消防等有关部门和单位在各自职责范围内做好城市更新相关工作。第六条市人民政府应当建立全市统一的城市更新信息系统，推进全市城市更新工作信息化、数字化、智能化管理。县（市、区）人民政府应当完善数据共享机制，依托城市更新信息系统，为城市更新项目的实施和全生命周期管理提供服务保障。第七条本市建立城市更新专家委员会制度，为城市更新决策、政策制定提供咨询意见。专家委员会应当由规划、建筑、土地、产业、交通、市政、水务、园林、生态环境、公共安全、历史文化、社会治理、经济和法律等相关方面专业人士组成。鼓励规划师、建筑师等专业技术人员参与城市更新，为城市更新工作提供技术咨询服务。第八条市、县（市、区）人民政府建立健全城市更新公众

－3－

参与机制，畅通意见表达渠道，依法保障利益相关人以及公众在城市更新工作中的知情权、参与权、建议权和监督权。鼓励市场主体通过投资、建设、运营城市更新项目等方式参与城市更新活动。

第二章城市更新规划

第九条市、县（市）人民政府应当定期开展城市体检评估工作，统筹组织住房、小区、社区、街区、城区、城市等层级的综合体检，结合实际开展城市基础设施、公共服务设施、历史文化保护传承、人居环境等方面的专项体检，形成城市体检评估报告，作为编制城市更新专项规划、片区策划、项目实施方案、年度计划的重要依据。第十条市、县（市）住房和城乡建设主管部门会同相关部门组织编制城市更新专项规划，报本级人民政府批准后实施，并报上一级住房和城乡建设主管部门备案。编制城市更新专项规划应当根据国民经济和社会发展规划、国土空间总体规划，衔接有关专项规划和国土空间详细规划，主要包括规划目标、重点任务、城市设计、片区指引、项目库、保障措施等内容。第十一条市、县（市、区）住房和城乡建设主管部门会同相关部门依据城市更新专项规划，组织编制城市更新片区策划，

－4－

报本级人民政府批准后实施。片区策划应当综合考虑相关规划要求，明确边界范围、片区体检、发展定位、功能业态、更新方式、设计引导、更新项目、土地供应、规划调整、实施步骤等内容。无法单独出具规划条件或者难以独立开发的零星地块，应当纳入相邻片区统筹策划。第十二条城市更新项目实施主体应当根据城市更新专项规划和片区策划，编制城市更新项目实施方案，报项目所在地县（市、区）住房和城乡建设主管部门审查，并报县（市、区）人民政府审定。涉及重大城市更新项目的，应当报市人民政府审定。城市更新项目实施方案应当明确基础条件、更新目标、更新方式、设计方案、建设计划、资金测算、资金筹措、运营模式、权益分配等内容。涉及历史文化保护的，应当制定具体保护措施。需要开展生态环境影响评价、交通影响评价的，应当书面征求相关部门意见。符合国家和省有关规定的社会投资简易低风险城市更新建设项目，可以直接编制项目设计方案用于更新实施。第十三条市、县（市、区）住房和城乡建设主管部门应当会同有关部门，结合城市体检、城市更新专项规划、片区策划以及更新需求调查情况，建立城市更新项目库，并实行常态申报和动态调整。第十四条市、县（市、区）住房和城乡建设主管部门应当

－5－

会同相关部门，依据城市更新专项规划和城市更新项目库，编制城市更新年度计划，报本级人民政府批准后组织实施。第十五条在编制城市更新专项规划、片区策划过程中，应当通过座谈会、论证会、听证会等方式，广泛听取相关单位和利益相关人的意见。城市更新专项规划、片区策划报送批准前，组织编制机关应当予以公告；报送批准时，应当附意见采纳情况及理由。第十六条市、县（市、区）人民政府应当强化城市设计对城市更新的引导作用，明确设计管理要求，融入城市更新专项规划、片区策划、项目实施方案全过程，完善城市风貌管理，保护城市独特的历史文脉、人文地理、自然景观特色，推进城市更新项目落地实施。

第三章城市更新实施

第十七条城市更新项目应当确定实施主体。涉及单一物业权利人的，由物业权利人自行确定实施主体；涉及两个以上物业权利人的，通过协商或者表决的方式确定实施主体。涉及公共利益确需实施的城市更新项目，无法依据前款规定方式确定实施主体的，由市、县（市、区）人民政府充分征询物业权利人、利益相关人意见，依法确定实施主体，并通过政府门户网站公示。

－6－

第十八条市、县（市、区）人民政府依据城市更新专项规划和片区策划，可以将区域综合性城市更新项目或者多个城市更新项目划定为一个城市更新实施单元，统一规划、统筹实施，并确定与实施单元范围相适应的主体作为实施单元统筹主体。第十九条实施既有建筑改造利用的，应当对老旧建筑进行调查检测与安全评估，提升抗震、消防安全性能，持续改善建筑功能，统筹推进居住建筑和公共建筑节能改造，加强建筑保温材料管理，消除既有建筑安全隐患。实施危险住房更新改造的，应当按照有关规定以加固、改建、重建、拆除等方式进行更新。支持危险住房、老旧住房自主更新、原拆原建。第二十条实施老旧小区更新改造的，应当充分考虑居民意愿，改造提升燃气、供水、供电、排水、污水、供热、消防、道路、通信等基础设施，因地制宜推进公共空间和配套设施的适老化、适儿化、无障碍改造。支持具备条件的楼栋加装电梯。推进老旧小区及其周边区域连片改造，建设完整社区，构建城市便民生活圈。第二十一条实施老旧街区更新改造的，应当完善配套设施，优化交通组织，提升公共空间品质，促进商业服务业和消费层级的多样化发展，推动老旧街区活力提升。实施低效楼宇、传统商业设施等更新改造的，应当加强存量房屋改造利用，推动建筑功能转换和混合使用，鼓励根据实际需

－7－

求合理转换为文化、体育、教育、医疗、社会福利等功能。第二十二条实施老旧厂区更新改造的，应当注重工业遗产保护和活化利用，依法开展修缮维护。盘活利用闲置低效厂区、厂房和设施，推动老旧厂区功能转换，重点发展新产业、新业态。第二十三条实施城中村更新改造的，应当采取拆除新建、拆整结合、整治提升等方式，消除安全风险隐患，改善居住条件和生活环境。第二十四条实施公共服务设施更新改造的，应当优先补齐民生领域公共服务设施短板，完善养老托育、公共医疗、全民健身、公共文化、社会福利、绿地广场等设施，推进公共场所适老化、适儿化和无障碍设施建设改造，建设全龄友好型城市。推进公共设施平急两用改造，合理规划布局应急避难、医疗场所，完善应急交通体系，提高城市安全风险防控和应急救援能力。第二十五条实施城市基础设施更新改造的，应当优化城市基础设施布局、结构、功能，推进数字城市、智慧城市建设。推进市政管线管网以及综合管廊建设，加强排水防涝、环境卫生、污水收集处理和再生利用等设施建设改造，加快城市基础设施生命线安全工程建设，强化对基础设施运行风险的监测和动态预警。优化城市交通网络，畅通道路交通微循环，完善公共交通体系，合理布局公共交通站点，推进绿色慢行系统建设。

－8－

鼓励和支持统筹利用桥下空间、地下空间等城市附属空间资源，增加公共空间供给，完善城市功能。第二十六条实施城市生态系统修复，应当加强城市绿地系统、绿道网络体系建设，增加社区公园和口袋公园，提升城市生态环境品质。推进海绵城市、韧性城市建设，加强受损山体和采煤沉陷区治理修复，提高城市防涝防洪、防灾减灾等能力。第二十七条市、县（市、区）人民政府应当加强对历史文化名城、历史文化街区等的保护和活化利用，保持太原府城和晋阳古城文化核心区等传统格局、街巷肌理、历史风貌，彰显和延续地方历史文化特色。实施历史城区、历史文化街区和历史文化风貌区更新改造的，应当开展历史文化资源调查评估，采用小规模、渐进式、微改造等方式，保护传承城市历史文脉。对历史建筑的活化利用，应当在保持现有传统格局、外观风貌、典型构件的基础上，依法通过加建、改建和添加设施等方式适应现代生产生活需要。鼓励采用原材料、原工艺、原形制、原结构进行修缮、维护和加固。第二十八条城市更新改造应当充分利用闲置土地、低效空间，建设机动车停车位、立体停车设施、公共停车场、电动自行车集中停放场所和智能安全充电设施。支持在老旧小区以及周边道路依法设置限时停车、夜间停车、错时共享停车泊位。

第四章城市更新保障

第二十九条市、县（市、区）人民政府有关部门应当加强对城市更新项目实施过程和后期运营的监督管理，确保项目按照实施方案确定的更新目标、方向和要求进行建设和运营。城市更新项目实施主体应当建立质量安全管理制度，完善质量安全管理体系，落实质量安全管理责任。第三十条市、县（市）人民政府应当完善适应城市更新的多元土地供应体系，探索通过土地租赁、带方案出让、盘活存量低效用地等方式，为城市更新项目提供土地。城市更新项目用于发展国家支持产业和行业的，在不改变用地主体和规划条件的前提下，根据国家有关规定，可以享受按照原用途和土地权利类型使用土地的过渡期政策。鼓励在符合国土空间详细规划的前提下，采取分层开发的方式，合理利用地上、地下空间，开展土地立体开发。第三十一条对多产权主体、多宗地块实施成片更新的，涉及国有土地使用权以及房屋所有权变动的，可以依法通过房屋征收、协议搬迁等方式，实施产权归集。第三十二条为满足安全、环保、无障碍标准等要求，城市更新项目增设必要的楼梯、电梯、坡道、走廊、无障碍设施、风道、外墙保温、自行车棚、充电桩等附属设施时，其新增建筑量

－10－

可以不计入规划容积率。为保障居民基本生活需求、补齐城市短板，实施城市基础设施、公共服务设施、公共安全设施以及老旧住宅成套化改造的，在对周边不产生负面影响的前提下，其新增建筑规模可以不受规划容积率指标的制约。对增加非营利性城市基础设施、公共服务设施等的城市更新项目，在符合国土空间详细规划的前提下，可以给予容积率奖励，并在整体区域内统筹使用。在规划条件之外，对多保留不可移动文物和历史风貌建筑、多无偿移交政府的公共服务设施等公益性贡献，其建筑面积可以按照贡献的相应建筑面积补足。第三十三条存量建筑在符合规划和管控要求的前提下，经依法批准后可以转换用途。鼓励各类存量建筑转换为城市基础设施、公共服务设施、公共安全设施。第三十四条市、县（市、区）人民政府应当建立房屋安全体检、房屋安全管理资金、房屋质量安全保险等房屋全生命周期安全管理制度，完善住宅专项维修资金政策，推动建立完善既有房屋安全管理公共资金筹集、管理、使用模式。第三十五条市、县（市、区）人民政府应当建立城市更新项目资金筹措机制，统筹利用中央、地方各类预算资金和超长期特别国债、地方政府债券等财政金融资源，支持城市更新。鼓励金融机构依法开展多样化金融产品和服务创新，满足城

－11－

市更新融资需求。鼓励社会资本参与城市更新，推动符合条件的城市更新项目发行基础设施领域不动产投资信托基金、资产证券化产品、公司信用类债券等。第三十六条符合条件的城市更新项目，按照有关规定享受行政事业性收费减免、政府性基金减免，相关纳税人依法享受税收优惠政策。第三十七条违反本条例规定，法律、行政法规以及山西省人民代表大会及其常务委员会制定的地方性法规已有法律责任规定的，从其规定。第三十八条国家工作人员在城市更新工作中滥用职权、玩忽职守、徇私舞弊的，依法给予处分；构成犯罪的，依法追究刑事责任。

第五章附则

第三十九条本条例所称物业权利人，是指不动产所有权人、土地使用权人、合法建造或者依法取得不动产但尚未办理不动产登记的单位和个人、承担城市公共空间和设施建设管理责任的单位。第四十条本条例自2026年12月1日起施行。

－12－
