# 安顺市避暑康养旅居促进条例

安顺市避暑康养旅居促进条例

（2026年8月26日安顺市第五届人民代表大会常务委员会第三十七次会议通过2026年9月23日贵州省第十四届人民代表大会常务委员会第二十六次会议批准）

第一条为了打造知名避暑康养旅居目的地，促进经济社会高质量发展，根据有关法律、法规的规定，结合本市实际，制定本条例。第二条本市行政区域内避暑康养旅居设施建设、产业发展、服务保障、监督管理等活动，适用本条例。本条例所称避暑康养旅居，是指依托本市气候优势、优良生态资源和人文资源，以避暑、康养等为目的的旅居活动。第三条促进避暑康养旅居发展工作应当坚持政府引导、市场主导、因地制宜、产业融合、主客共享、绿色发展的原则，体现铸牢中华民族共同体意识的要求。第四条市人民政府应当加强对促进避暑康养旅居发展工作的组织领导，将促进避暑康养旅居发展工作纳入国民经济和社会发展规划，制定并完善政策措施，健全服务保障体系，协调处

－1－

理重大问题，定期向市人民代表大会常务委员会报告促进避暑康养旅居发展工作情况。县级人民政府负责本行政区域内促进避暑康养旅居发展工作的组织实施，统筹协调解决相关具体问题。乡镇人民政府、街道办事处在职责范围内配合有关部门做好本辖区内促进避暑康养旅居发展工作，指导和支持村民委员会、居民委员会协助开展相关工作。第五条旅游主管部门负责统筹协调促进避暑康养旅居发展工作，其他有关部门在职责范围内做好促进避暑康养旅居发展相关工作。第六条旅游主管部门应当会同民政等部门培育和发展避暑康养旅居行业组织，并依法加强监督管理。鼓励行业组织加强行业自律，根据法律、行政法规和章程的规定，制定行业经营规范和团体标准，组织从业人员开展政策法规、职业道德、安全知识、服务技能等培训，督促会员诚信经营，促进行业健康有序发展。第七条县级以上人民政府应当根据国土空间规划，依托旅游景区、旅游度假区、乡村旅游重点村镇等优良资源，统筹推进避暑康养旅居特色小镇和特色村居建设。避暑康养旅居特色小镇和特色村居建设应当依托气候优势，注重与城乡自然山水、景观视廊、历史文化、民族文化相协调，挖掘小镇、村居特色；以存量设施改造提质为主，改善餐饮住宿、

－2－

休闲娱乐、供水供电、垃圾处理、无障碍设施等生活条件。旅游主管部门应当会同住房城乡建设、自然资源等部门，制定避暑康养旅居特色小镇和特色村居建设指引。第八条交通运输部门应当会同有关部门，优化机场、车站与避暑康养旅居特色小镇、特色村居等旅居者相对集中区域之间的公共交通线路布局；加强公交站点、停车场、充电桩（站）、交通标识以及交通安全防护设施的配置与维护，提升旅居出行服务保障能力。第九条医疗保障、卫生健康部门应当做好异地就医结算服务，常态化开展异地医保政策宣传。卫生健康部门应当依托现有医疗资源，优化旅居者相对集中区域医疗设施配置，提供健康管理和多元化医疗康养服务。民政部门应当合理布局养老机构，推动养老机构基础设施提质改造，支持有条件的养老机构拓展康养服务供给。第十条旅游主管部门应当会同投资促进等部门制定实施避暑康养旅居领域市场主体培育计划，推动依法简化相关经营证照办理流程，实行一次性告知、一站式办理，提高政务服务效率。第十一条县级以上人民政府应当制定避暑康养旅居产业政策，推动产业转型升级。旅游、农业农村、工业和信息化、商务等部门应当采取以下措施，支持经营者依托本地气候优势、优良生态资源和人文资源发展避暑康养旅居产业，构建本地特色旅居产品体系：

－3－

（一）合理利用森林、温泉、喀斯特地貌等自然资源，开发生态观光、休闲度假等避暑旅居业态，建强民宿体系，促进旅居产业与农业、文体领域融合发展；（二）挖掘红色文化、民族文化、屯堡文化和三线文化、桥梁文化、农耕文化、非物质文化遗产等人文资源，支持开展研学探访、民俗体验等活动，推动旅居产业与餐饮、文娱、商贸领域融合发展；（三）用好民族医药等康养资源，开发健康管理、康复疗养、食养保健等康养旅居产品；（四）其他促进避暑康养旅居产业发展的措施。第十二条县级以上人民政府应当建立健全宣传推广工作机制，营造文明诚信、友善和谐的避暑康养旅居社会氛围。旅游主管部门应当会同商务等部门，统筹策划避暑康养旅居城市形象宣传和品牌推广，深化与主要客源地交流合作，依托文体赛事、民俗节庆、会议会展等活动，开展本市避暑康养旅居资源和政策的宣传推介，提升知名度和美誉度。鼓励旅居经营者、旅居者、本地居民运用传统媒体和短视频、直播等新媒体，宣传本市避暑康养旅居资源、特色产品。第十三条旅游主管部门应当会同有关部门依托智慧文旅综合服务云平台，运用大数据、人工智能等新技术，为避暑康养旅居线上营销、预订管理与客户服务提供便利。第十四条市人民政府应当制定相关措施，保障旅居者与本

－4－

地居民平等享有公共交通、文化体育等公共服务。县级以上人民政府应当提升基础公共服务稳定供给水平，加强避暑康养旅居区域协调合作，推进跨区域公共服务互通共享。第十五条县级以上人民政府应当加大对旅居者相对集中区域公共文化服务供给，因地制宜开展传统饮食文化交流、民俗活动和文体赛事，鼓励非遗传承人定期开展教学、表演等文化活动。第十六条旅游主管部门应当会同有关部门建立旅居志愿服务机制，鼓励志愿者为旅居者提供本地生活咨询、文化导览等志愿服务。第十七条县级以上人民政府应当合理安排资金，支持避暑康养旅居产业基础设施建设和市场主体培育，完善政府引导、市场主导的资金投入机制。鼓励社会资本以股权投资、项目合作等方式，依法参与避暑康养旅居项目建设、运营。鼓励金融机构开发适合避暑康养旅居产业特点的信贷产品，优化配套担保服务，提供多样化金融服务。指导保险机构开发相关保险产品和服务，鼓励旅居经营者投保火灾责任、公众责任相关保险。第十八条县级以上人民政府应当合理统筹避暑康养旅居项目用地工作。自然资源部门应当依据国土空间规划，探索创新供地方式，

－5－

保障避暑康养旅居项目用地需求。自然资源、住房城乡建设部门根据项目改造实际需要，依法依规调整存量建设用地和闲置房屋用途，用于建设避暑康养旅居地产以及相关配套设施，促进存量资源高效利用。鼓励经营者依法利用城镇存量建设用地和闲置房屋，通过功能置换、改扩建等方式发展避暑康养旅居项目，结合老旧小区改造等因地制宜开展适老化、适儿化改造，完善旅居生活服务功能。鼓励农村集体经济组织及其成员、其他经营者依法通过租赁、入股、合作等方式盘活农村闲置宅基地、住宅和集体经营性建设用地，发展避暑康养旅居新业态。盘活利用前款资源应当尊重村民意愿，保障村民合法权益，严格落实用途管制制度。第十九条发展改革、自然资源、住房城乡建设等部门应当引导经营者盘活存量闲置资产，开发适合避暑康养旅居需求的地产项目，合理布局家庭型、小户型等宜居生活空间，依法依规做好项目配套保障，强化项目全流程监管。住房公积金管理中心应当优化住房公积金异地贷款的服务流程，提升办理便利度。鼓励房地产开发企业由单一开发向综合服务延伸，拓展旅居地产运营业务，构建全链条避暑康养旅居服务体系。鼓励引进专业企业参与避暑康养旅居项目的建设运营。第二十条旅游、人力资源社会保障、教育、商务等部门应

－6－

当加强避暑康养旅居经营管理人才的引进和培育，发挥航空、旅游等产业优势集聚青年人才，拓宽旅居领域创业就业渠道，支持高等院校和中等职业学校加强避暑康养旅居产业人才培养。第二十一条县级以上人民政府统一负责避暑康养旅居安全工作。应急管理部门统筹旅居经营场所安全生产与消防安全监督指导、旅居安全突发事件应急处置。住房城乡建设部门负责旅居经营场所建筑工程质量、城镇燃气安全监督管理。卫生健康部门根据旅居者相对集中区域特点，加强公共卫生监督管理。市场监督管理部门负责旅居经营场所食品安全、特种设备安全监督管理。旅游、公安、商务、自然资源、交通运输、水务等部门和气象机构按照各自职责保障旅居安全。第二十二条旅居经营者应当节约集约利用资源，履行绿色低碳发展义务，依法经营、诚信经营，落实安全生产主体责任，依法履行残疾人、老年人和未成年人保护义务，遵守法律、法规关于未成年人住宿安全保护的各项规定。旅居者应当践行文明旅居理念，增强生态环境保护意识，尊重旅居地风俗习惯，自觉维护生产生活秩序。第二十三条旅游主管部门和有关部门的工作人员在履行

监督管理职责中滥用职权、玩忽职守、徇私舞弊，尚不构成犯罪的，依法给予处分。第二十四条违反本条例规定的行为，法律、法规有处罚规定的，从其规定。第二十五条本条例自2027年1月1日起施行。
