# 全国人民代表大会常务委员会关于植树节的决议

全国人民代表大会常务委员会
关于植树节的决议

（1979年2月23日通过）

第五届全国人民代表大会常务委员会第六次会议，根据国务院的提议，为了动员全国各族人民植树造林，加速绿化祖国，决定三月十二日为我国的植树节。
