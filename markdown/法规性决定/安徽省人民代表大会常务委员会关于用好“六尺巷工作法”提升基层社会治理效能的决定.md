# 安徽省人民代表大会常务委员会关于用好“六尺巷工作法”提升基层社会治理效能的决定

安徽省人民代表大会常务委员会关于用好
“六尺巷工作法”提升基层社会治理效能
的决定

（2026年7月24日安徽省第十四届人民代表大会常务委员会第二十五次会议通过）

为了深入学习贯彻习近平总书记考察安徽重要讲话精神，坚持和发展新时代“枫桥经验”，用好“六尺巷工作法”，推进基层治理体系和治理能力现代化，建设更高水平的平安安徽、法治安徽，服务和保障“三地一区”建设，根据有关法律、行政法规，结合本省实际，作出如下决定。

一、本决定所称“六尺巷工作法”，是指传承中华民族讲求礼让、以和为贵的传统美德，学习借鉴先人化解矛盾的历史智慧，注重用调解的办法解决人民内部矛盾，以党建领事、礼让和事、群众说事、多元解事、网格管事、群力防事为基本内容，以矛盾不上交、平安不出事、服务不缺位为基本目标的基层社会治理方法。

二、用好“六尺巷工作法”，应当坚持以习近平新时代中国特色社会主义思想为指导，全面贯彻习近平法治思想、习近平总书记关于基层治理的重要论述，坚持党对基层治理的全面领导，坚持以人民为中心，坚持和发展全过程人民民主，健全基层治理体制机制，提升基层社会治理效能。

三、用好“六尺巷工作法”，应当弘扬中华优秀传统文化，因地制宜推动本地优秀传统文化创造性转化、创新性发展，深入挖掘其当代价值，培育崇德向善、礼让和事的社会风尚，促进优秀传统文化赋能基层社会治理。

四、用好“六尺巷工作法”，应当健全党组织领导的自治、法治、德治相结合的城乡基层治理体系。

发挥人民群众主体作用，丰富基层民主协商实现形式，改进网格化管理服务，支持、引导群众有序参与社会治理，依靠自身力量解决治理问题，推动实现群众的自我管理、自我服务、自我教育、自我监督。

统筹推进基层治理法治化，加大法治宣传教育力度，加强公共法律服务，提升公民法治素养。加强基层综治中心规范化建设，建立健全矛盾纠纷协同化解闭环工作机制，推动矛盾纠纷源头化解、多元化解、有序化解。

践行社会主义核心价值观，依法完善村规民约、居民公约，将礼让和谐、互助服务等融入基层社会治理。注重家庭家教家风建设，弘扬道德风尚，培育文明新风。

五、用好“六尺巷工作法”，应当充分发挥调解的作用，倡导互谅互让，将听、劝、让、和落实到调解全过程，坚持法理情相统一，提升调解质效，促进社会和谐。

行政机关、司法机关和有关组织应当加强协调配合，促进人民调解、行政调解、司法调解等有机衔接，完善纠纷化解机制。健全人民调解组织，加强调解员队伍建设，培育“法律明白人”等社会调解力量，推动矛盾就地发现、就地调处、就地化解。

六、用好“六尺巷工作法”，应当引导群众积极参与，广泛听取社会公众的意见，畅通和规范群众诉求表达、利益协调、权益保障通道，及时发现、化解矛盾纠纷。

支持群团组织、企业事业单位、社会组织等参与基层社会治理，推动物业服务企业融入社区治理，建设人人有责、人人尽责、人人享有的社会治理共同体。

七、用好“六尺巷工作法”，应当健全社会风险防控工作体系，坚持预防为主、专群结合、群防群治，形成城乡统筹、线上线下融合、人防物防技防心防并举的防控格局。

加强社会心理服务体系建设，完善社会心理疏导和危机干预机制，开展社会心态监测、心理健康指导、心理健康知识宣传等活动，培育自尊自信、理性平和、积极向上的社会心态。

对社区矫正对象、安置帮教对象、社区戒毒和社区康复人员等群体，落实相应的教育矫正、帮扶救助、就业指导、职业培训等措施。

加强基层社会治理数智化建设，运用现代信息技术，创新治理和服务模式，加快信息数据互通共享，提升社会治理数字化、智能化水平。

八、加强对“六尺巷工作法”以及实践中探索形成的“作退一步想工作法”“一杯茶调解法”等基层社会治理工作经验的总结提炼，打造具有安徽特色的基层社会治理创新品牌。

宣传、文化和旅游、教育等部门应当加强“六尺巷工作法”的宣传推广，鼓励创作以“六尺巷工作法”为主题的文艺作品，营造人人知晓六尺巷故事、事事懂得礼让道理、处处彰显和谐精神的浓厚氛围。

支持开展“六尺巷工作法”理论研究和交流；将“六尺巷工作法”纳入国家工作人员、基层社会治理工作人员的教育培训内容。

九、县级以上人民政府应当将用好“六尺巷工作法”纳入基层社会治理工作格局，做好实施“六尺巷工作法”的保障工作。

人民法院、人民检察院应当按照各自职责做好“六尺巷工作法”运用相关工作。

十、人大及其常委会应当通过听取和审议专项工作报告、执法检查、专题询问、调查研究等方式，推动本决定贯彻执行。鼓励和引导人大代表依托全过程人民民主实践站、基层立法联系点等平台参与基层社会治理，做好畅通社情民意、议事协商、矛盾纠纷化解等工作。

本决定自2026年10月17日起施行。
