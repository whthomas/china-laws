# 大庆市人民代表大会常务委员会关于大庆高新技术产业开发区（国家级）行政管理有关事项的决定

大庆市人民代表大会常务委员会
关于大庆高新技术产业开发区（国家级）
行政管理有关事项的决定

（2026年8月25日大庆市第十一届人民代表大会常务委员会第四十一次会议通过　2026年9月22日黑龙江省第十四届人民代表大会常务委员会第三十次会议批准）

为了规范大庆高新技术产业开发区（国家级）（以下简称大庆高新区）行政管理活动，推动高质量发展，根据有关法律、法规的规定，结合本市实际，现就大庆高新区行政管理有关事项决定如下：

一、本决定适用于大庆高新区范围内的行政管理活动。

大庆高新区的具体范围由大庆市人民政府依法向社会公布。

二、大庆高新技术产业开发区管理委员会（以下简称大庆高新区管委会）是大庆市人民政府的派出机构，对大庆高新区实行统一管理。

三、大庆市人民政府遵循依法、按需、精简、高效的原则，可以将与经济管理领域相关以及其他必需的市级、县级行政管理职权，授予大庆高新区管委会。

大庆高新区管委会所属的具有管理公共事务职能的组织，可在前款授权范围内依法行使相应行政执法权。

未经授权的行政职权，大庆高新区管委会及其所属具有管理公共事务职能的组织不得行使。

四、大庆高新区管委会行政管理职权、具体管理事项和管理区域，由大庆市人民政府向社会公布。

五、大庆高新区管委会及其所属具有管理公共事务职能的组织行使行政职权，应当严格遵守《中华人民共和国地方各级人民代表大会和地方各级人民政府组织法》及相关法律、法规。

经授权由大庆高新区管委会及其所属具有管理公共事务职能的组织行使的行政职权，大庆市人民政府有关主管部门、相关县级人民政府及其有关部门、机构在大庆高新区管委会管理区域内不再行使。

六、大庆市人民政府有关主管部门依法在大庆高新区设立的机构，接受大庆高新区管委会统筹协调。

七、大庆高新区管委会及其所属具有管理公共事务职能的组织行使行政职权，应当接受黑龙江省人民政府及其有关主管部门的指导。

大庆市人民政府对大庆高新区管委会及其所属具有管理公共事务职能的组织行使行政职权进行监督管理，大庆市人民政府有关主管部门应当加强指导。

八、对大庆高新区管委会及其所属具有管理公共事务职能的组织依据大庆市人民政府的授权作出的行政行为不服的，有权依法向大庆市人民政府申请行政复议或者向人民法院提起行政诉讼。

九、大庆高新区管委会的预算纳入大庆市人民政府的预算并单独列示。

十、大庆高新区管委会行使行政管理职权、开展预算管理活动，依法接受大庆市人民代表大会及其常务委员会的监督。

十一、本决定自2026年10月1日起施行。
