# 河南省人民代表大会常务委员会关于加快构建现代化城市体系深入推进以人为本的新型城镇化建设的决定

河南省人民代表大会常务委员会
关于加快构建现代化城市体系深入推进
以人为本的新型城镇化建设的决定

（2026年9月24日河南省第十四届人民代表大会常务委员会第二十六次会议通过）

城镇化是现代化的必由之路，是解决农业、农村、农民问题的重要途径，是推动区域协调发展的有力支撑，是扩大内需和促进产业升级的重要抓手。为加快构建现代化城市体系、深入推进以人为本的新型城镇化建设，根据党中央、省委有关部署要求，结合河南实际，作出如下决定。

一、把握原则要求，确保正确政治方向

1.指导思想。以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记在河南考察时重要讲话精神和关于河南工作的重要论述，全面落实习近平总书记关于城市工作的重要论述和中央城市工作会议精神，聚焦“1+2+4+N”目标任务体系，紧扣河南“十五五”规划和省委城市工作会议部署，加快构建“一主两副、一圈两带、四域多点”的城镇化发展格局，着力建设创新、宜居、美丽、韧性、文明、智慧的现代化人民城市，推动城乡融合、区域协调发展，在推进新型城镇化上探索新路径，为奋力谱写中原大地推进中国式现代化新篇章提供强劲动力和坚实支撑。

2.工作原则。坚持党的领导，把党的领导贯穿城市工作和新型城镇化建设全过程各环节，树立和践行正确政绩观，确保党中央决策部署和省委工作要求落到实处。坚持以人为本，全面践行人民城市理念，充分尊重人的意愿，调动和发挥好人的积极性主动性创造性，促进人的全面发展和社会公平正义，使全体人民共享现代化发展成果。坚持因地制宜，立足各地资源禀赋、功能定位、发展阶段、人口规模，遵循城市发展规律，尽力而为、量力而行，因城施策、分类推进，形成符合实际、体现优势、各具特色的城镇化发展路径。坚持集约高效，优化国土空间发展格局，有效集聚各类要素，提升资源和空间集约节约利用水平，促进城镇发展与产业支撑、就业转移、人口集聚、生活改善相统一，构建科学合理的城镇化格局。坚持系统推进，统筹发展和安全，统筹全局和一域，坚持投资于物和投资于人紧密结合，强化制度衔接和政策配套，加强跨部门跨层级跨区域协调联动，凝聚各方力量、形成工作合力。

二、聚焦结构优化，完善城镇化发展格局

3.发挥“一主两副”引领带动作用。加快郑州国家中心城市建设，强化枢纽开放、科技创新、教育文化、金融服务等核心功能，加强重大创新与产业平台建设，推进高水平制度型开放，着力打造先进制造业基地、科技创新高地、枢纽经济高地、对外开放门户；深入推进要素市场化配置综合改革试点工作，形成一批标志性、突破性改革成果；加快转变特大城市发展方式，优化开发强度和人口密度，引导一般性制造业、区域性物流基地和专业市场等非核心功能设施向周边转移。建强洛阳中原城市群副中心城市，发挥洛阳产业、科技、区位、文化、生态等方面优势，推进洛阳与济源同城化发展，加快建设国家重要创新高地和先进制造业基地、现代生态宜居城市、文化旅游名城、人文交往中心。提升南阳省域副中心城市功能，做大做强中心城区，深化京豫南水北调对口协作，加强汉江生态经济带上下游合作联动，打造以高效生态经济为引领的现代化省域副中心城市。

4.推动“一圈”“两带”联动发展。建设现代化郑州都市圈，构建跨行政区合作发展新机制，做强郑（港）汴许主引擎，推动郑开同城化提质发展，加强郑洛错位联动，强化新乡、焦作、平顶山、漯河、济源与郑州功能对接、产业配套、创新联动，持续提升郑州都市圈综合实力、核心竞争力、区域影响力。加快建设沿京广铁路城市发展带，依托京广通道，发挥郑州辐射带动作用，提升安阳、鹤壁、新乡、许昌、漯河、驻马店、信阳等京广铁路沿线城市产业、要素集聚功能，打造贯通南北的城镇产业密集带。加快建设沿陇海铁路城市发展带，依托陆桥通道优势，提升商丘、开封、洛阳、三门峡等“一带一路”建设重要节点城市功能，形成具有较强实力的先进制造业和城镇集聚带。充分发挥“两带”上安阳、商丘、信阳、三门峡四个端点城市对内联动、对外开放的桥头堡作用，打造区域中心城市。

5.促进“四域”“多点”协同发展。以黄河、淮河、海河、长江四大流域为脉络塑造流域联动发展片区，以“两带”为牵引打造东北、西北、西南、东南四个区域城市发展片区，将生态保护、经济发展与利益共享融为一体，形成流域联动、区域协同的“四域”城市发展新格局。黄河流域城市深化与山东沿海港口群合作联动，共建沿黄陆海大通道，加快建设晋冀鲁豫大宗商品骨干流通走廊。淮河流域城市积极融入长三角城市群，构建中部便捷水运出海通道，培育壮大临港产业集群，纵深推进淮河生态经济带建设。海河流域城市加快绿色转型发展，强化海河源头综合治理，筑牢流域防洪减灾安全屏障。长江流域城市加强与成渝地区、长江经济带、汉湘桂水运大通道对接协作，加快水运航道、高铁通道建设。东北区域对接山东半岛城市群，加强鲁豫毗邻地区合作发展，支持濮阳建设现代化工新材料基地。西北区域深化与山西产业协作、生态共治、文旅融合，加快陕晋豫毗邻地区合作发展，支持焦作、济源建设豫西北晋东南交通和物流枢纽。西南区域加强与长江经济带及成渝双城经济圈对接联动，支持南阳、平顶山建设综合交通枢纽及豫鄂陕毗邻地区中心城市。东南区域深入开发淮河航运，积极对接长三角港口群，支持周口建设港口型国家物流枢纽。促进县域经济“多点”竞相发展，大城市周边县承接人口、产业、功能疏解转移，区域重点县壮大主导产业，专业功能县发展特色经济和支柱产业，农业大县做强农产品精深加工业和生产性服务业，重点生态功能区县提升重要生态产品供给能力，打造带动城乡融合发展的重要节点。培育发展特色鲜明、经典美丽的小城镇。

三、突出内涵提升，建设现代化人民城市

6.建设富有活力的创新城市。强化科技创新、产业创新、体制创新协同，培育一批人才友好型、青年发展型和创新型城市。推动郑洛新国家自主创新示范区建设提质增效。实施省级重大科技专项和重点研发专项，集中突破一批关键技术。实施制造业重点产业链高质量发展行动，推动制造业高端化、智能化、绿色化转型。激活城市存量资源潜力，开展城市资产资源调查，推动土地混合开发利用、用途合理转换，盘活利用存量闲置房屋和低效用地，推动城市开发建设方式转型升级。统筹利用财政资金、社会资本和金融等资金渠道，创新财政金融政策工具，建立可持续的城市建设运营投融资体系。积极融入服务全国统一大市场，充分发挥地缘区位、交通物流、市场规模、市场体系、产业基础等比较优势，着力破卡点、强联通、建枢纽、增动力、提能级，加快建设全国统一大市场循环枢纽、打造国内国际市场双循环支点。

7.建设舒适便利的宜居城市。提升城市宜居水平，深入开展城市体检，高质量推进城市更新，优化城市基础设施布局、结构、功能，加快建设新型城市基础设施，稳步推进老旧小区（厂区、街区）、城中村及城市危旧房改造，扩面提质建设完整社区，分批打造高品质城市一刻钟便民生活圈。提升城市住房品质，因城施策控增量、去库存、优供给，着力稳定房地产市场，加快构建房地产发展新模式，建设安全、舒适、绿色、智慧的“好房子”。提升公共服务水平，推动基础教育扩优提质，实施医疗卫生强基工程，扩大普惠养老服务供给，加强社会保障和分层分类社会救助。

8.建设绿色低碳的美丽城市。扎实推进重点行业企业环境绩效等级提升，加快传统产业绿色低碳转型，积极培育绿色工厂、零碳工厂、零碳园区、循环经济产业园。加强城市生态和湿地水环境修复，健全城市公园和绿道网络体系。倡导绿色低碳生活方式，积极开展无废城市、低碳城市、节水型城市建设，建设节约型机关、绿色社区。持续打好蓝天、碧水、净土保卫战，推动城市空气质量持续改善，提升城镇生活污水收集处理和再生水利用能力，完善生活垃圾收运处置体系，加强城市噪声污染、餐饮油烟污染、新污染物等治理。

9.建设安全可靠的韧性城市。增强城市综合防灾减灾救灾能力，加强应急指挥、处置和救援体系建设，构建覆盖省市县乡村的应急避难场所发展布局。针对城市防洪设施短板和气候变化影响，统筹城市防洪体系和内涝治理，开展中小河流治理和蓄滞洪区建设。构建城市应急备用水源体系，因地制宜逐步推行城镇供排水一体化。加强水网、新型电网、算力网、新一代通信网、城市地下管网、物流网等规划建设。加快城市基础设施生命线安全工程建设。推动重要设施、能源、水源等分布式布局，完善抗灾设防标准。建立房屋全生命周期安全管理制度，提升建筑安全保障水平。强化重点行业领域安全生产管理，分级、智能、精准管控重大风险源，常态化开展安全生产隐患排查整治和从业人员安全培训。

10.建设崇德向善的文明城市。加强历史文脉保护和传承，强化城市规划管控引导，加强建筑设计管理，塑造城市特色风貌，提升城市吸引力和辨识度。推动公共文化服务提质增效，完善城市文化设施，拓展新型公共文化空间。推进文旅深度融合，结合城市更新有序开发城市文旅资源，培育“文旅+百业”新业态新模式，持续提升河南文旅品牌影响力。培育和践行社会主义核心价值观，大力弘扬焦裕禄精神、红旗渠精神、大别山精神，坚持不懈以文化人、以文润城。

11.建设便捷高效的智慧城市。深化大数据、云计算、人工智能等信息技术在城市治理中的融合应用，推进人工智能赋能千行百业，不断提升城市治理智慧化精细化水平。加快城市全域数字化转型，打造集约统一、数据融合、高效协同的城市数字底座，完善城市信息模型平台。深化数据资源开发和多场景应用，推动政务服务“一网通办”、城市运行“一网统管”、公共服务“一网通享”。完善基层数智治理体系，打造纵横贯通、直达网格的治理平台，推动网格高效顺畅运行。统筹推进主次干道、背街小巷、城乡接合部、小微公共空间环境综合整治，疏堵并举规范便民经营活动。

四、推动城乡融合，促进共同繁荣发展

12.推进农业转移人口市民化。畅通农业转移人口进城落户渠道，提高户籍登记、迁移便利度，促进在城镇稳定就业和生活的农业转移人口进城落户。推动相关公共服务随人走，重点解决好农业转移人口的子女教育、医疗保障、住房保障、社会保险等问题，稳步实现基本公共服务由常住地供给。推动转移支付、要素配置等与农业转移人口市民化挂钩。依法维护进城落户农民的土地承包权、宅基地使用权、集体收益分配权。促进农业转移人口稳定就业，常态化开展技能培训、岗位推介、创业帮扶，构建覆盖劳动者就业创业全过程的一体化、数字化信息平台。

13.推进城乡产业发展协同化。统筹城乡之间产业分布和产业关联，构建多元、协同的产业发展体系。把县域作为城乡融合发展的重要切入点，优化县域产业空间布局，坚持因地制宜、突出特色、错位发展，整合优质资源、强化协同赋能，培育壮大优势产业集群，提升县域产业发展能级。着力发展乡村富民产业，打造粮食、畜牧渔业、油脂油料、特色果蔬、乡村农文旅、乡村商贸流通服务业等产业集群，统筹发展科技农业、绿色农业、质量农业、品牌农业，推动农村一二三产业深度融合，形成兴业、强县、富民一体发展格局。

14.推进城乡基础设施一体化。根据地方财力、人口分布、产业布局、民生需求等因素，推动交通、供水、供电、供气等县域基础设施一体化规划建设管护，加快城镇基础设施向基层下沉、向农村覆盖。推动农村公路提质改造，积极发展联结城乡的冷链物流、配送投递、电商平台和农贸市场网络。完善水资源配置体系，扩大南水北调中线工程受益范围。加强农村电力基础设施改造，推进农村地区源网荷储一体化。推动城乡数字基础设施互联互通、数据资源整合共享。

15.推进城乡基本公共服务均等化。加强县域基本公共服务供给统筹，完善投入保障长效机制，推动城乡基本公共服务普惠共享，逐步使农村基本具备现代生活条件。健全与人口变化相适应的教育资源配置机制，合理优化城乡中小学校和幼儿园布局，推动基础教育公平优质发展。完善乡村、城市社区医疗卫生体系，推进紧密型县域医共体建设，实现人才、技术、管理等资源共享。统筹城乡公共文化设施布局、服务提供、队伍建设，完善农村群众文艺扶持机制。深入推进多元化、可持续的养老服务，完善覆盖城乡的养老服务网络，鼓励有条件的地方发展老年助餐、日间照料、医养康养等养老服务。

16.推进城乡要素配置合理化。实施乡村振兴人才支持计划，扎实推进科技特派员、特岗计划等基层服务项目，有序引导大学毕业生到乡、能人回乡、企业家入乡。节约集约利用农村集体经营性建设用地，探索发展农村产权流转交易平台，推进市县乡村农村产权流转交易服务体系建设。健全多元化城乡融合发展投入保障机制，鼓励各地因地制宜探索创新乡村振兴投融资模式，引导社会力量规范有序投资农业农村，加大金融支持乡村振兴力度。建立科技成果入乡转化机制，完善科技成果转化和技术服务网络。

17.推进城乡社会治理现代化。坚持和发展新时代“枫桥经验”“浦江经验”，推动构建党组织统一领导、政府依法履责、各类组织积极协同、群众广泛参与，自治、法治、德治相结合的基层治理体系。突出抓基层、强基础、固根本，全面推行“党建+网格+大数据”模式，扎实推进“五基四化”，推动资源、服务、管理下沉。拓宽人民群众参与社会治理的渠道和途径，支持人大代表、政协委员做好畅通社情民意、议事协商、矛盾纠纷化解等工作。深化运用“四议两公开”，鼓励农民群众多渠道参与乡村治理。积极探索社区党组织领导下的居委会、业委会、物业服务企业协调运行新模式。完善居民、企业、群团组织、社会组织参与基层治理制度机制，充分发挥志愿服务作用，拓宽新就业群体参与渠道。

五、加强统筹实施，充分凝聚各方合力

18.充分发挥人大职能作用。全省各级人大及县级以上人大常委会要扎实履行宪法法律赋予的职责，突出重点、精准发力、同题共答，以高质量履职助力新型城镇化建设高质量推进。不断完善与新型城镇化建设相适应的地方性法规，坚持“小切口”、精细化、真管用，深入推进城乡规划、城市管理、城市更新、公共服务、社会保障、基层治理等方面立法，围绕构建“一主两副、一圈两带、四域多点”城镇化发展格局探索推进区域协同立法。加强对新型城镇化建设的监督，聚焦法规政策实施、重大项目落地、城乡治理难题、重点民生关切等，综合运用听取审议专项工作报告、执法检查、专题询问、专题调研等方式，实行正确监督、有效监督、依法监督，推动有关方面切实解决问题、改进工作、完善制度。加强和改进代表工作，以开展代表主题活动为主线，以代表联络站点为平台，以民生实事项目人大代表票决制为抓手，支持和保障人大代表密切联系服务群众、广泛收集民情民意、积极建言献策，充分发挥人大代表模范带头和桥梁纽带作用，为新型城镇化建设凝聚智慧和力量。

19.全面落实政府实施责任。省人民政府要深入贯彻党中央、国务院关于以人为本的新型城镇化战略部署，全面落实省委工作要求，强化规划引领、政策支撑和要素保障，完善规章制度和工作举措，压紧压实各方责任，建立健全协调推进机制，确保各项任务落地落实。省发展改革委要做好新型城镇化建设综合协调工作，强化重要政策、重大问题研究，抓好重大工程、重点项目组织实施；各相关部门要按照职能职责，加强协同配合，制定出台配套政策措施，提升财政、金融、土地、住房、教育、医疗等方面政策的协调性。市、县人民政府要扛牢主体责任，统筹当下与长远，谋划好任务举措，因地制宜抓好工作落实。

20.广泛动员全社会共同参与。全省各级国家机关、社会团体、企事业单位和其他组织要强化责任担当，立足职能职责积极发挥作用，充分调动全社会投身新型城镇化建设的积极性主动性创造性。建立健全政府引导、市场运作、多元参与的制度机制，鼓励以市场化手段促进多方合作，引导各类市场主体积极参与新型城镇化建设。尊重人民群众主体地位和首创精神，深入践行全过程人民民主，充分吸纳民意、汇集民智，营造全社会关心支持、主动参与的浓厚氛围，凝聚加快构建现代化城市体系、深入推进以人为本的新型城镇化建设的强大合力。

本决定自公布之日起施行。
