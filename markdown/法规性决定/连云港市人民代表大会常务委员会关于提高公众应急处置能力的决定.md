# 连云港市人民代表大会常务委员会关于提高公众应急处置能力的决定

连云港市人民代表大会常务委员会关于
提高公众应急处置能力的决定

（2026年6月26日连云港市第十五届人民代表大会常务委员会第三十五次会议通过　2026年7月31日江苏省第十四届人民代表大会常务委员会第二十三次会议批准）

为了提高公众应急处置能力，保障人民群众生命财产安全，维护公共安全和社会稳定，根据有关法律、法规，结合本市实际，作出如下决定：

一、本决定适用于本市行政区域内公众应急处置能力建设及其相关活动。

本决定所称公众应急处置能力，是指公众在突发事件应对中，具备风险识别、预警响应、自救互救、避险逃生、配合救援等方面的知识、技能和素质。

二、提高公众应急处置能力坚持党委领导、政府负责、社会协同、全民参与、法治保障的原则，构建统一领导、综合协调、分类管理、分级负责、属地管理的工作格局，增强全社会安全意识和风险防范能力，营造人人讲安全、个个会应急的社会氛围。

三、市、县（区）人民政府应当将公众应急处置能力建设纳入国民经济和社会发展规划、应急管理体系和能力建设规划，建立健全跨部门联动工作机制，统筹协调解决重大问题，将提高公众应急处置能力建设所需经费纳入本级预算。

乡（镇）人民政府、街道办事处应当按照上级人民政府及其有关部门的部署，做好辖区内提高公众应急处置能力相关工作。村（居）民委员会应当协助人民政府以及有关部门做好相关工作。

应急管理部门负责公众应急处置能力建设的统筹协调与综合监督管理工作。

社会工作、网信、发展改革、教育、科技、工业和信息化、公安、民政、财政、人力资源社会保障、自然资源和规划、生态环境、住房城乡建设、城市管理、交通运输、水利、农业农村、商务、文化广电和旅游、卫生健康、数据、市场监督管理、体育、机关事务管理、消防救援等部门应当按照各自职责做好提高公众应急处置能力相关工作。

四、机关、企业事业单位和其他组织应当建立健全应急管理制度，开展经常性的应急知识宣传教育和技能培训，配备必要的应急救援设备、设施，增强工作人员的安全意识和应急处置技能。

个人应当主动学习应急知识，接受应急知识教育，参加应急培训和演练。鼓励个人参加应急救援专业培训，取得应急救援员、救护员等资格证书。

突发事件发生后，公众应当服从各级人民政府、村（居）民委员会或者所属单位的指挥和安排，配合人民政府采取的应急处置措施，积极参加应急救援、事后恢复与重建等工作。

鼓励具备应急救助知识和专业技能的人员，对需要急救的人员实施紧急救助。因自愿实施紧急救助行为造成受助人损害的，救助人依法不承担民事责任。对确认为见义勇为的救助人，应当依法给予奖励和保障。

五、鼓励和支持社会力量开展或者参与公众应急处置能力建设的公益活动。

应急管理部门应当会同社会工作、教育、公安、卫生健康、消防救援、志愿者协会等部门和单位，搭建应急公益活动平台，引导公益组织、社会工作者和志愿者参与应急宣传、培训、教育等活动。

六、鼓励有条件的村（居）民委员会依托党群服务中心、便民服务场所等公共资源，设立应急驿站，配备应急照明、应急通讯、应急医疗、消防器材、逃生避险等必要应急设备物资，做好日常管理、设备检查、制度更新等相关工作。

村（居）民委员会应当依托应急驿站常态化开展防灾避险、自救互救等应急知识培训和宣传普及活动。乡（镇）人民政府、街道办事处应当加强对应急驿站建设运行的指导、支持和监督。

七、本市建立应急第一响应人制度。

本决定所称应急第一响应人，是指具备一定应急处置能力，在专业应急救援队伍到达前先期到达突发事件现场，开展疏散引导、组织自救互救、信息收集报告等初期就近应急处置工作的人员。

市、县（区）人民政府应当在化工园区、沿海（含港口）、沿河、洪涝灾害威胁区域、旅游景区等突发事件高风险区域，以及公共交通工具、公共场所和其他人员密集场所，建立应急第一响应人网络体系。

应急第一响应人制度实施办法由市人民政府组织应急管理、公安、消防救援、卫生健康等部门制定，并向社会公布。

八、市、县（区）人民政府及其有关部门、乡（镇）人民政府、街道办事处应当每年至少组织开展两次面向公众的应急知识宣传教育活动，提升公众应急意识和能力。

应急管理部门应当会同公安、生态环境、住房城乡建设、交通运输、卫生健康、市场监督管理、消防救援等部门建立突发事件案例库，用于应急宣传教育等工作。文化广电和旅游部门应当采取多种形式，推动创作以公众应急处置能力建设为主题的影视、文学等各类艺术作品。

红十字会、工会、共青团、妇联、残联等社会组织应当结合各自工作对象的特点，组织开展有针对性的公众应急处置能力建设工作，每年至少开展一次应急救护、防灾避险等应急知识宣传普及活动。

村（居）民委员会、机关、企业事业单位和其他组织应当结合实际情况，组织应急知识讲座，通过楼宇电视、户外显示屏、广播等方式，面向居民、村民、职工等群体开展安全风险告知、预防与应急、自救与互救知识宣传普及活动。

广播、电视、报刊、网络等新闻媒体应当开展应急法律法规、应急处置方式方法等方面的应急知识公益宣传。

九、公安、卫生健康、应急管理、消防救援等部门应当根据各自职责制定公众应急培训计划、公布培训大纲、明确培训内容，建立应急培训师资库，每年至少组织开展一次面向公众的防灾避险、自救互救技能培训，并为机关、企业事业单位和其他组织的应急培训提供指导和支持。

民政、人力资源社会保障、交通运输、市场监督管理、应急管理、残联等部门和单位应当按照各自职责，针对残疾人、老年人、新业态从业人员等群体的应急培训需求，采取无障碍宣讲、上门培训、线上课堂、行业专场实训等方式，分类组织开展应急教育培训，提升其风险防范和应急处置能力。

机关、企业事业单位和其他组织应当每年至少组织一次对本单位工作人员的应急培训，培训内容包括应急预案、突发疾病抢救、避险逃生和自救互救技能等。

应急管理部门应当会同公安、卫生健康、消防救援、自然资源和规划、水利等部门编制公众应急知识普及指南，明确不同区域、不同群体应当掌握的应急知识要点。公众应急知识普及指南应当结合本市沿海地理特点和产业特色，包含台风、地震、暴雨洪涝、地质灾害、火灾、危险化学品泄漏、海上突发事件等应急避险知识。

十、教育部门应当对学校、幼儿园开展应急教育进行指导和监督，指导其制定应急知识教育计划。

学校、幼儿园应当根据不同年龄阶段学生的认知能力、身心特点，将防溺水、应急救护、避险逃生能力提升教育纳入教育教学活动或者社会实践。学校应当每学期至少开展一次全员应急知识教育活动，每学期至少开展一次针对洪水、地震、火灾等灾害事故的紧急疏散演练。

学校、幼儿园应当组织教职工接受应急救援培训。

十一、市、县（区）人民政府应当统筹规划、合理布局，科学设立应急教育培训实践基地，开展应急演练、培训、教育等工作。政府投资建设的应急教育培训实践基地应当免费向公众开放。

鼓励和支持机关、企业事业单位和其他组织建设或者共享应急教育培训实践基地。

十二、本市建立健全突发事件应急预案体系，为提高公众应急处置能力提供制度保障。

市、县（区）人民政府及其有关部门、乡（镇）人民政府、街道办事处应当根据法律、法规、规章、上级人民政府及其有关部门的应急预案，结合本地区、本部门实际，制定相应的突发事件应急预案。

村（居）民委员会在所在地人民政府的指导下，制定应急预案。机关、社会团体、企业事业单位和其他组织应当制定本单位应急预案。

应急预案编制单位、成员单位应当根据应急预案内容，制定应急简明操作流程或者操作指南，并按照规定向社会公布或者在本单位以及可能受影响的其他单位和地区公开。

十三、本市各级人民政府以及有关部门应当推进全民应急演练。应急管理部门应当会同有关部门，建立应急演练统筹协调机制，制定并组织实施年度应急演练计划，加强对应急演练的评估指导。各有关部门应当加强对本行业、本领域应急演练的指导和监督。

道路运输、建筑施工单位，危险物品的生产、经营、储存、装卸、运输单位，使用危险物品从事生产且使用量达到规定数量等高危生产经营单位，以及宾馆、商场、娱乐场所、旅游景区等人员密集场所经营单位，每半年至少组织一次综合或者专项应急预案演练，每两年对本单位编制的所有专项应急预案至少组织一次演练，每半年对本单位编制的现场处置方案至少组织一次演练。

消防安全重点单位、公众聚集场所和人员密集场所应当每半年至少组织一次消防和突发事件应急疏散演练。

高层公共建筑的业主单位、使用单位，接受委托的高层住宅建筑的物业服务企业和大型商业综合体的产权单位、使用单位，应当每年至少组织一次消防和应急疏散演练；建筑高度超过一百米的，应当每半年至少组织一次综合演练。

应急演练组织单位应当对应急演练效果进行评估，针对发现的问题，及时优化应急预案和应急演练。

十四、市、县（区）人民政府及其有关部门可以组织开展“双盲”（不提前通知演练时间和演练内容）应急演练，检验应急救援实战能力，提升突发事件应急处置水平。

鼓励乡（镇）人民政府、街道办事处、村（居）民委员会、企业事业单位等结合各自实际，开展“双盲”应急演练。

十五、市应急管理部门应当会同公安、卫生健康和消防救援等部门引导公众制定家庭应急计划，指导家庭开展风险评估、隐患排查、应急疏散等活动。

乡（镇）人民政府、街道办事处应当组织村（居）民委员会、物业服务企业、社会组织和志愿者等，通过隐患排查、应急宣传和应急演练等方式，指导家庭储备药品、饮用水、方便食品、灭火器、呼吸面罩、手电筒、救生哨子等应急物资，协助家庭提高应急处置能力。

十六、市、县（区）人民政府应当统筹规划、合理确定应急避难场所和应急疏散通道，并设置统一、规范的标志标识。

应急避难场所和应急疏散通道的所有权人或者管理者应当加强维护和管理，保障其正常使用。

应急管理部门应当加强对应急避难场所和应急疏散通道建设与管理的统筹协调和监督指导。住房城乡建设、城市管理等部门应当按照各自职责做好应急避难场所和应急疏散通道建设与管理相关工作。

十七、公共交通工具、公共场所和其他人员密集场所应当配备报警装置和必要的应急救援设备设施，注明其使用方法，并显著标明安全撤离的通道、路线，保证安全通道、出口的畅通。

池塘、河流、湖泊、水库、码头、渡口等有较高溺水风险水域的所有人、经营者或者管理者应当落实防溺水的安全责任，设置安全防护设施，配备救生圈、救生衣等安全防护与自救互救设备并保持完好有效。

十八、市、县（区）人民政府统一领导、组织、协调本行政区域内公共场所自动体外除颤器的配置工作。卫生健康部门负责公共场所自动体外除颤器的配置及其监督管理工作，会同有关部门制定配置方案和年度配置计划，建立政府主导投入与社会捐赠、场所单位自行购置相结合的模式，按照急需程度，分批分阶段组织实施。

发展改革、教育、公安、民政、财政、交通运输、文化广电和旅游、应急管理、体育、机关事务管理等有关部门，按照配置方案及相关规定，督促指导相关公共场所配置并维护自动体外除颤器相关工作。

火车站、机场、长途汽车客运站、高速公路服务区、养老机构、学校、幼儿园、医疗机构、旅游景区、政务服务中心、体育场馆、图书馆、博物馆等公共场所，以及市、县（区）人民政府确定的一定数量的公共交通工具、执法执勤车辆和船舶，其经营管理者或者所属单位应当按照配置方案配置自动体外除颤器；卫生健康部门应当建立自动体外除颤器信息管理系统；信息管理系统建设经费以及配置方案确定的由政府保障的场所配置自动体外除颤器经费，纳入政府保障范围。

鼓励大型商场超市、大型农贸市场、大型宾馆饭店等人员密集场所自行配置自动体外除颤器。

配置自动体外除颤器的单位，应当履行自动体外除颤器的日常维护职责，确保其正常使用。

十九、卫生健康部门、红十字会应当为配置自动体外除颤器的单位提供培训技术支持，组织开展自动体外除颤器使用等急救知识和技能培训。配置单位应当组织本单位全体人员参加自动体外除颤器使用、维护和相关急救知识技能的培训，受训人员应当定期参加复训。

支持有资质的社会组织开展使用自动体外除颤器和相关急救知识技能的宣传教育和公益培训。

卫生健康部门应当将公共场所配置的自动体外除颤器纳入信息管理系统管理，并公布自动体外除颤器分布信息，方便公众需要时发现获取。

二十、应急管理、科技、工业和信息化、公安、交通运输、数据等部门应当推广应用无人驾驶航空器、人工智能、虚拟现实、大数据等科技和信息化手段，强化系统集成，加强数据融合与分析应用，为公众提供隐患识别辅助、预警预报自动提醒、突发事件报告等应急处置服务。

二十一、本市建立公众应急处置能力评估制度。各有关部门应当定期开展本行业、本领域公众应急处置能力评估。市应急管理部门应当会同有关部门至少每两年组织一次覆盖不同年龄段、职业群体的抽样评估，并向社会公布评估结果。评估内容应当包括应急知识和技能掌握程度、实战演练参与度、应急物资储备等。各有关部门应当根据评估结果，及时调整监管措施、完善培训内容、优化宣传方式。

市、县（区）人民代表大会常务委员会，乡（镇）人民代表大会主席团可以通过听取专项工作报告、执法检查、组织代表视察等方式，加强对公众应急处置能力建设工作的监督。

二十二、本决定自2026年10月1日起施行。
