# 深圳市人民代表大会常务委员会关于授权市人民政府为保障亚太经合组织第三十三次领导人非正式会议筹备和举办工作规定临时性行政措施的决定

深圳市人民代表大会常务委员会关于
授权市人民政府为保障亚太经合组织第三十三
次领导人非正式会议筹备和举办工作规定
临时性行政措施的决定

（2026年9月30日深圳市第七届人民代表大会常务委员会第五十二次会议通过）

亚太经合组织第三十三次领导人非正式会议将于2026年11月18日至19日在广东省深圳市举行。为了保障会议筹备和举办工作，确保会议的顺利举行，特作出如下决定：

在会议筹备和举办期间，市人民政府可以按照依法、必要、适度、精准、科学的原则，在不与本市法规基本原则相违背的前提下，通过发布决定或者命令的形式，在公共安全、城市管理、交通运输等方面规定临时性行政措施。相关决定或者命令应当明确具体实施期限，及时向社会公布，并按照有关规定报市人民代表大会常务委员会备案。

本决定自公布之日起施行，实施期限至2026年11月30日。
