# 西藏自治区人民代表大会常务委员会关于巩固拓展提升国家意识、公民意识、法治意识教育的决定

西藏自治区人民代表大会常务委员会
关于巩固拓展提升国家意识、公民意识、法治
意识教育的决定

（2026年9月23日西藏自治区第十二届人民代表大会常务委员会第二十五次会议通过）

为了全面提升全区各族人民的国家意识、公民意识、法治意识（以下简称“三个意识”），巩固各民族团结奋斗的共同思想政治基础，根据《中华人民共和国民族团结进步促进法》等法律、行政法规，结合西藏实际，作出如下决定：

一、巩固拓展提升“三个意识”教育，应当坚持中国共产党的领导，坚持以习近平新时代中国特色社会主义思想为指导，深入贯彻习近平总书记关于西藏工作的重要指示和新时代党的治藏方略，贯彻落实党中央决策部署以及自治区党委工作要求，铸牢中华民族共同体意识，推进中华民族共同体建设，以社会主义核心价值观为引领，以创建全国民族团结进步模范区为抓手，常态化长效化推进“三个意识”教育，引导各族人民自觉维护国家统一、反对分裂、促进民族团结进步。

二、巩固拓展提升“三个意识”教育，应当组织开展中国共产党史、新中国史、改革开放史、社会主义发展史、中华民族发展史以及西藏地方与祖国关系史宣传教育，引导各族人民牢固树立正确的国家观、历史观、民族观、文化观、宗教观，坚定对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义的认同；坚持公民在法律面前人人平等、各民族一律平等，加强宪法、《中华人民共和国民族团结进步促进法》等法律法规的学习宣传，引导各族人民依法履行宪法法律规定的公民义务，自觉维护国家统一和民族团结，维护中华民族根本利益和整体利益，维护国家主权、安全和发展利益；深入开展全民普法，引导各族人民自觉在法律法规规定的范围内开展活动，推动形成办事依法、遇事找法、解决问题用法、化解矛盾靠法的社会共识和行为习惯。

三、自治区建立健全党委领导、政府负责、宣传工作部门协调、各部门实施、全社会参与的“三个意识”教育工作格局，将“三个意识”教育工作融入民族团结进步创建工作，坚持与中心工作同谋划、同部署、同检查，坚持互动性、实践性、针对性相统一，创新载体、丰富内涵、灵活方式，巩固教育成果，拓展教育深度，提升教育质效。

四、宣传工作部门应当将“三个意识”教育纳入宣传思想文化工作总体布局，建立健全工作协调机制和评价制度、通报制度，构建自治区、设区的市（地区）、县（区、市）、乡镇（街道）、村（居）五级宣讲体系，总结推广先进经验和做法，发挥典型的示范引领作用。

报刊、广播、电视等新闻媒体和出版单位、网络服务提供者应当开展有关“三个意识”教育的宣传报道、成就展示。

五、统一战线工作部门、宗教事务部门应当强化思想政治引领，巩固拓展提升宗教团体、宗教院校、宗教活动场所“三个意识”教育，引导宗教与社会主义社会相适应，促进民族和睦、宗教和顺、社会和谐。

宗教活动场所管理机构应当坚持集中教育与融入日常相结合，聚焦解决突出问题，一体推进学习教育、检视整改、建章立制，推动“三个意识”要求融入寺规僧约。

六、教育主管部门应当结合不同学段青少年学生的认知特点，通过组织开展专题宣讲、专题辅导、专题讲座等方式，将“三个意识”教育纳入学校思想政治理论教育内容。

各级各类学校应当将“三个意识”教育融入日常教学活动。

七、社会工作、人力资源和社会保障、经济和信息化等部门应当将“三个意识”教育纳入新经济组织和新社会组织宣传教育工作体系，指导中小微企业和个体工商户积极参与，引导新经济组织和新社会组织成员、新就业群体自觉维护国家利益，依法诚信经营，履行社会责任。

八、文化和旅游主管部门应当将“三个意识”教育融入公共文化和旅游服务体系，充分利用历史遗迹、红色资源和文化场馆等，发挥文艺团体作用，因地制宜采取多种形式深入开展“三个意识”教育。

九、司法行政部门应当将“三个意识”教育融入法治宣传教育规划，加大“三个意识”教育在普法工作中的权重，聚焦“三个意识”开展以案释法宣传教育活动。

十、民族工作部门应当完善铸牢中华民族共同体意识常态化宣传教育机制，将“三个意识”教育作为全国民族团结进步模范区创建的重要内容，融入中华民族共有精神家园建设、促进各民族交往交流交融、推动共同繁荣发展的全过程。

十一、工会、共产主义青年团、妇女联合会、工商业联合会、哲学社会科学界联合会等群团组织应当发挥各自优势，面向所联系的领域开展“三个意识”教育活动，团结所联系的群体为中华民族共同体建设贡献力量。

十二、县（区、市）、乡镇（街道）应当利用国家宪法日、全民国家安全教育日、民族团结进步宣传周等重要节点，依托新时代文明实践中心（所、站）和基层各类文化活动场所等，采取运用群众身边的典型案例等群众喜闻乐见的方式，开展“三个意识”宣传教育活动。

村（居）民委员会应当发挥驻村工作队、文艺宣传队、普法宣讲员的作用，增强“三个意识”教育感染力，推动村规民约、居民公约体现“三个意识”的要求。

十三、自治区鼓励和支持科研院所、高等院校组织开展“三个意识”理论和实践研究，编写教育读本、撰写理论文章、培训教育人才，支持运用互联网、大数据、人工智能等现代技术赋能“三个意识”教育。

宣传、民族等工作部门和教育、科学技术等部门按照各自职责，指导爱国主义教育基地、民族团结进步教育基地、铸牢中华民族共同体意识教育实践基地等开展以“三个意识”为主题的教育活动。

十四、各机关、各部门应当加强本单位的“三个意识”教育。公职人员应当在“三个意识”教育工作中发挥模范带头作用。

全区各族人民应当主动参与“三个意识”教育，铸牢中华民族共同体意识，推进中华民族共同体建设。

十五、县级以上人民政府应当加强“三个意识”教育方面的人才培养、理论研究、经验交流等工作，将“三个意识”教育相关经费列入同级财政预算。

十六、县级以上人民代表大会常务委员会，应当综合运用听取和审议专项工作报告、执法检查、专题询问、专题调研等方式，加强对“三个意识”教育工作实施情况的监督。

本决定自公布之日起施行。
