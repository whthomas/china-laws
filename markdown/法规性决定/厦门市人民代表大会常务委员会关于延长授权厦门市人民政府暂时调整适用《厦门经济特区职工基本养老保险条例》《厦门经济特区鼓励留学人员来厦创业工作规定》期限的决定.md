# 厦门市人民代表大会常务委员会关于延长授权厦门市人民政府暂时调整适用《厦门经济特区职工基本养老保险条例》《厦门经济特区鼓励留学人员来厦创业工作规定》期限的决定

厦门市人民代表大会常务委员会
关于延长授权厦门市人民政府暂时调整适用
《厦门经济特区职工基本养老保险条例》《厦门
经济特区鼓励留学人员来厦创业工作规定》
期限的决定

（2026年10月22日厦门市第十六届人民代表大会常务委员会第四十次会议通过）

为持续深化企业职工基本养老保险制度改革工作，厦门市第十六届人民代表大会常务委员会第四十次会议决定：将《厦门市人民代表大会常务委员会关于授权厦门市人民政府暂时调整适用〈厦门经济特区职工基本养老保险条例〉〈厦门经济特区鼓励留学人员来厦创业工作规定〉的决定》规定的暂时调整适用有关法规规定的期限延长至2029年12月31日。

本决定自公布之日起施行。
