# 重庆市人民代表大会常务委员会关于一体推进教育科技人才发展的决定

重庆市人民代表大会常务委员会
关于一体推进教育科技人才发展的决定

（2026年7月30日重庆市第六届人民代表大会常务委员会第二十五次会议通过）

为了深入学习贯彻习近平总书记关于一体推进教育科技人才发展的重要论述和视察重庆重要讲话重要指示精神，坚持中国共产党的领导，坚持“四个面向”战略导向，聚焦做实“两大定位”、发挥“三个作用”，认真落实市委六届历次全会精神以及大力实施教育强市、创新强市、人才强市建设的工作要求，强化教育、科技、人才的基础性、战略性支撑，形成一体推进我市教育科技人才发展机制，推动科技创新和产业创新深度融合，更好实现教育培养人才、人才支撑创新、创新赋能产业的正向循环，为现代化新重庆建设提供坚实支撑，结合本市实际，作出如下决定。

一、健全统筹协调机制。本市探索建立市级教育科技人才统筹协调机制，强化规划衔接、政策协同、资源统筹、评价联动，推动教育供给、科技创新与人才支撑一体贯通。市人民政府及有关部门应当编制实施教育科技人才一体发展规划，促进科技自主创新和人才自主培养良性互动；强化政策的一致性和匹配度，加强教育科技人才政策一体协同实施；建立教育科技人才一体发展的重大事项清单，推动资金、项目、平台、人才等创新资源同向配置；建立以创新能力、质量、实效、贡献为导向的激励评价联动机制，激发创新创造动力活力。

二、健全产教融合、科教融汇机制。市人民政府应当聚焦科技创新、产业发展和国家战略需求重点领域，强化平台建设与学科建设联动，加快推动高等学校“双一流”和优势学科建设。支持和引导高等学校超常或提前布局急需学科、新兴产业、未来产业专业，加强基础学科、新兴学科、交叉学科建设；提高学科专业与产业需求的适配度，优化学科专业结构；建设卓越工程师学院、教育部重庆高等研究院、重庆人工智能学院、现代产业学院和市域产教联合体等跨学科专业综合育人平台。

本市加强校企地联动发展，深化区县（自治县）、高新技术产业开发区与高等学校、科研机构协同创新；支持行业企业、科研机构深度参与办学，开放技术平台与生产场景，共建实验室、实训基地、中试基地，促进技术创新、场景应用与人才培育深度融合。

三、健全平台基地建设联动机制。市人民政府应当聚力推进“203060”重点攻坚突破体系，紧扣“416”科技创新布局和“33618”现代制造业集群体系融合发展需求，聚焦数智科技、生命健康、新材料、绿色低碳等重点领域，优化市域科创布局和整体空间格局，支持各类创新平台集聚创新人才队伍、一体协同开展有组织科研。

本市探索建立以政府投入为引导，多元共建、多方投入机制和灵活管理模式，推动高等学校、科研机构和企业联动建设金凤、嘉陵江、明月湖、三峡等重庆实验室和在渝国家实验室、全国重点实验室、市级重点实验室，加快建设技术创新中心、产业创新中心和新型研发机构等战略引领创新平台，积极争取国家实验室基地来渝布局，促进教育科技人才供需精准对接、要素顺畅流动、发展深度融合。

四、优化科教协同引才育人机制。市人民政府及有关部门应当构建以科技创新和产业需求为导向的人才培养机制，推动高等学校、科研机构和企业开展创新型人才共育、共引、共享；建立重点产业紧缺人才和技术攻关产才对接机制，促进跨学科、跨部门、跨地区、跨行业高效调配产业人才集智推进创新突破；注重在科研一线发现和培养人才，加大对基础研究人才、青年科技人才等人才的接力培养和长周期支持力度，着力培养造就卓越工程师、大国工匠、高技能人才。支持高等学校、科研机构、企业发挥人才集聚效应，引进和培育战略科学家、科技领军人才和高水平创新团队。

高等学校、科研机构和企业应当着眼于全球视野，围绕创新需求加大高层次人才引进力度，完善项目引才、平台引才制度，健全校（院）企人才“双聘双用”机制。

五、构建产学研用协同创新机制。市人民政府应当优化基础研究战略性、前瞻性、体系化布局，加强新兴领域、交叉融合和跨学科基础研究；加强企业创新主体地位，以产业为导向，健全“产业出题、科技答题”攻关体系，加强政府引导、企业主导、创新平台支撑、高等学校与科研机构协同联动，深化拓展人工智能应用，推动先进制造业、新兴产业和未来产业重点领域关键核心技术攻关。

支持链主企业、高等学校和科研机构组建产业创新综合体，联合产业上下游创新资源，聚力开展关键核心技术协同攻关，一体推进技术研发、标准研制、产业培育，加快攻关成果应用和产品迭代升级，实现创新要素与产业需求的双向互动循环。

六、构建多方投入机制。市人民政府应当强化市级财政资金撬动作用，积极引导区县（自治县）、国有企业和社会力量等加大创新投入。统筹整合教育经费、科技投入、人才发展资金，一体化保障高等学校“双一流”和学科建设、高能级科创平台建设、高水平人才引育、基础研究和前沿颠覆性研究、重大技术攻关，压实全周期绩效评价。推动全社会研发经费投入提升，扩大基础研究经费占比。完善“股贷债保担租”联动的科技金融服务机制，建立市级政府科创投资母基金，推广“拨改投”模式，引导金融资本投早、投小、投长期、投硬科技，以多元资金赋能创新链产业链资金链人才链深度融合。

七、健全科技成果高效转化应用机制。市人民政府应当大力推动科技成果转化，突出科技创新供给和产业需求牵引，增强产学研用协同、搭建服务平台、打通转化堵点，培育壮大科技服务业，提升科技成果转化和产业化水平。鼓励区县（自治县）因地制宜推动科技成果转化。支持企业、高等学校、科研机构参与场景需求挖掘和重大场景建设，推动开放应用场景，促进新技术、新产品规模化落地。

市科技、教育、财政、经济信息、人力社保、国有资产管理、知识产权、审计、监察等部门和单位应当依法履行各自工作职责，建立健全职务科技成果单列管理、科技成果转化尽职免责制度，支持高等学校、科研机构以“先赋权后行权”、先使用后付费等多种方式开展科技成果转化，支持科技人员在科技成果转化收益分配上有更大自主权。

八、建立联动评价机制。市人民政府及有关部门应当全面整合多方要素，设立多维评价指标，采取多样化评价方式，构建教育筑基、科技赋能、人才聚力的一体联动评价体系。深化分类评价，开展以成果原创性和学术价值为主的基础研究评价，建立长周期、宽松式考核机制。推行以用户和市场反馈为主的应用研究和技术开发评价，将新技术新产品作为业绩考核、职称评定、人才计划支持的重要依据。加快“破四唯”，赋予用人单位更大人才评价自主权，有效发挥科技评价指挥棒作用。深化科教界“帽子”治理，防止简单以称号头衔确定薪酬待遇、配置资源。建立激发创新活力、知识价值导向、管理规范有效、保障激励兼顾的薪酬制度，推动薪酬分配向作出突出贡献人才和一线关键岗位倾斜。

九、建立营造一流创新生态的服务机制。市人民政府及有关部门应当健全人才创新创业全周期服务机制，升级打造“渝才荟”综合场景，建设人才科创产业园、国家人力资源服务产业园，强化人才创新创业服务港功能。完善高等学校毕业生等青年留渝来渝就业创业服务体系，为各类人才提供高效便捷服务。强化科研诚信管理，持续加强师德师风、学风作风建设。完善科技创新容错和尽职免责机制，探索“沙盒监管”、触发式监管等新型监管方式，营造鼓励探索、宽容失败的良好环境。

本市积极培育创新文化，大力弘扬践行科学家精神、教育家精神、企业家精神、工匠精神，构建崇尚创新、尊重人才、褒奖奉献的社会风尚。优化适配人工智能发展的人才培养模式，提升青少年科学素养、批判性思维和创新能力。强化科技教育与人文教育协同，建强高水平智库和哲学社会科学重点研究基地。

十、建立工作闭环落实机制。市、区县（自治县）人民政府应当制定一体推进教育科技人才发展任务清单，围绕创新平台建设、人才引育、学科专业建设、关键核心技术攻关、科技成果转化、创新投入、科技金融服务、创新生态营造等重点任务，统筹推进协同发展，实行台账管理、限期办理等，推动重点任务落实。

十一、强化监督问效机制。市、区县（自治县）人大常委会应当充分发挥监督作用，围绕教育科技人才一体发展重点工作，综合运用听取和审议专项工作报告、执法检查、专题询问、专题调研等方式，增强监督实效，推动教育科技人才一体发展重要任务落实落地。

对怠于履职、滥用职权，妨碍一体推进教育科技人才发展的，依法追究法律责任。

本决定自2026年9月1日起施行。
