# 西藏自治区人民代表大会常务委员会关于全面贯彻实施《中华人民共和国民族团结进步促进法》的决定

西藏自治区人民代表大会常务委员会
关于全面贯彻实施《中华人民共和国
民族团结进步促进法》的决定

（2026年9月23日西藏自治区第十二届人民代表大会常务委员会第二十五次会议通过）

为了全面贯彻实施《中华人民共和国民族团结进步促进法》（以下简称民族团结进步促进法），夯实铸牢中华民族共同体意识、推进中华民族共同体建设的法治根基，凝聚起建设社会主义现代化新西藏的强大合力，结合西藏实际，作出如下决定：

一、切实增强贯彻实施民族团结进步促进法的政治责任。全面贯彻实施民族团结进步促进法，对于依法治理民族事务、全面推进民族团结进步事业，推动各族人民为以中国式现代化全面推进强国建设、民族复兴伟业团结奋斗具有重大意义。各机关、各部门应当坚持中国共产党的领导，坚持以习近平新时代中国特色社会主义思想为指导，深入学习贯彻习近平法治思想、习近平总书记关于加强和改进民族工作的重要思想、习近平总书记关于西藏工作的重要指示和新时代党的治藏方略，深刻领悟“两个确立”的决定性意义，增强“四个意识”、坚定“四个自信”、做到“两个维护”，以高度的政治责任感和历史使命感，扎实推进民族团结进步促进法全面有效实施，巩固各民族团结奋斗的共同思想政治基础和法治基础，不断将制度优势和法治优势转化为推进西藏长治久安和高质量发展的治理效能。

二、贯彻实施民族团结进步促进法的总体要求。国家机关、社会团体、企业事业组织和其他社会组织以及各族人民应当依照宪法和法律，将铸牢中华民族共同体意识、推进中华民族共同体建设作为共同任务，聚焦“四件大事”聚力“四个创建”，以法律实施护航长治久安、服务创建全国民族团结进步模范区，助推经济转型升级、服务创建高原经济高质量发展先行区，守护绿水青山、服务创建国家生态文明高地，强化固边兴边、服务创建固边兴边富民行动示范区，牢固树立中华民族共同体理念，坚定维护国家主权、安全、发展利益，共建中华民族共同体、书写美丽西藏新篇章。

三、完善全面贯彻实施民族团结进步促进法的工作格局。自治区坚持和完善党委统一领导、政府依法管理、统一战线工作部门牵头协调、民族工作部门履职尽责、各部门通力合作、全社会共同参与的民族工作格局，健全民族工作协调机制。

统一战线工作部门、民族工作部门负责本地区铸牢中华民族共同体意识、推动民族团结进步事业高质量发展等工作的协调推动、组织实施、督促落实。各机关、各部门应当将学习宣传贯彻民族团结进步促进法纳入工作部署并组织落实。

四、健全铸牢中华民族共同体意识制度机制。自治区人民代表大会及其常务委员会、人民政府，设区的市人民代表大会及其常务委员会、人民政府应当围绕贯彻实施民族团结进步促进法，完善民族工作领域法规政策，将铸牢中华民族共同体意识作为审议审查法规规章和规范性文件的重要内容，持续推动铸牢中华民族共同体意识要求入法入规，有序推进民族工作领域法规规章和规范性文件的立改废释。

各机关、各部门应当将民族事务纳入共建共治共享的社会治理机制，加强宗教事务治理法治化，深入开展反分裂斗争，有效防范和化解民族领域重大风险隐患，对标对表民族团结进步促进法等法律法规，认真查找民族工作领域存在的突出问题，研究提出政策举措，推进民族事务治理体系和治理能力现代化。

村（居）民委员会、行业组织和宗教团体、宗教活动场所等应当将铸牢中华民族共同体意识要求融入村规民约、居民公约、行业规范、寺规僧约及管理制度。

五、全面推进中华民族共同体建设。国家机关、社会团体、企业事业组织和其他社会组织应当依法履行构筑中华民族共有精神家园、促进各民族全方位互嵌和广泛交往交流交融、推动各民族共同繁荣发展的各项职责任务，将铸牢中华民族共同体意识融入稳定、发展、生态、强边工作实践，统筹社会主义新西藏经济、政治、文化、社会和生态文明建设，有形有感有效推进中华民族共同体建设。

自治区将创建全国民族团结进步模范区作为贯彻实施民族团结进步促进法的有效载体，促进各民族在政治、经济、文化上的交流，持续深化民族团结进步创建活动，发挥领导干部示范带头作用，加强新时代爱国主义和民族团结进步宣传教育，提高国家通用语言文字推广普及质效，构建互嵌式社会结构和社区环境，增强各族人民对伟大祖国、中华民族、中华文化、中国共产党、中国特色社会主义的认同，推动全国民族团结进步模范区创建工作提质增效。

自治区赋予所有改革发展以彰显中华民族共同体意识的意义，以维护统一、反对分裂的意义，以改善民生、凝聚人心的意义，将铸牢中华民族共同体意识、推进中华民族共同体建设纳入国民经济和社会发展规划及年度计划，完整准确全面贯彻新发展理念，全面融入国家发展战略，做好国家重大项目建设服务保障，因地制宜推动高原经济高质量发展。

自治区坚持生态优先、绿色发展，落实保护好青藏高原生态就是对中华民族生存和发展的最大贡献的理念，严格落实《中华人民共和国生态环境法典》、《中华人民共和国青藏高原生态保护法》等法律法规，科学推进南北山绿化，全面推进美丽西藏建设，筑牢国家生态安全屏障。

自治区以培育中华民族共同体意识实现团结固边，以推动边境地区高质量发展实现产业兴边，以保障和改善边民生活实现民生安边，统筹推进新时代固边兴边富民行动，持续加强边境治理，着力打造边境地区民族团结进步示范带，努力建设繁荣稳固的祖国边疆。

六、广泛开展民族团结进步促进法宣传教育。自治区将民族团结进步促进法纳入普法规划、计划，加大普法工作力度，引导各族群众增强国家意识、公民意识、法治意识，牢固树立正确的国家观、历史观、民族观、文化观、宗教观。

组织、宣传、民族等工作部门和司法行政、教育等部门应当推动构建铸牢中华民族共同体意识常态化宣传教育机制，将民族团结进步促进法的宣传教育与社会主义核心价值观教育、爱国主义教育、反分裂斗争教育、新旧西藏对比教育和党史、新中国史、改革开放史、社会主义发展史、中华民族发展史以及西藏地方和祖国关系史教育结合起来，将铸牢中华民族共同体意识融入国民教育、干部教育、社会教育全过程，组织编写符合新时代要求的通俗读本。

各机关、各部门应当将民族团结进步促进法等法律法规的宣传教育列入普法重点内容，依托民族团结进步宣传周、自治区民族团结进步宣传活动月等，采取多种形式，综合运用各类平台载体，广泛宣传民族团结进步促进法精神实质和主要内容，持续推动法律法规宣传教育全覆盖。

各级各类学校及其他教育机构应当将铸牢中华民族共同体意识要求贯穿教育全过程，在教育教学中增加民族团结进步促进法的相关内容。

报刊、广播、电视等新闻媒体和出版单位、网络服务提供者应当开设专题专栏，大力开展法治宣传报道，讲好中华民族共同体西藏故事，营造浓厚法治氛围和良好社会环境。

七、加大保障支持力度。县级以上人民政府应当将铸牢中华民族共同体意识、促进民族团结进步等相关工作经费列入本级预算，支持和鼓励科研院所、高等院校、自治区铸牢中华民族共同体意识研究中心（基地）等组织开展民族工作领域政策解读、铸牢中华民族共同体意识理论和实践研究、宣传教育人才培训等工作，推动成果转化运用。

八、大力推进执法司法。各级人民政府、有关部门以及司法机关应当认真履行法定职责、加大促进民族团结进步的执法司法力度，依法及时制止和查处破坏民族团结进步、制造民族分裂行为的违法行为；对不履行或者不正确履行促进民族团结进步法定职责的国家机关及其工作人员，依法追究责任。

九、强化监督检查。县级以上人民代表大会常务委员会依照法定职权，听取和审议本级人民政府关于民族团结进步促进工作情况报告，完善执法检查等工作机制，督促有关部门依法履职，确保民族团结进步促进法得到有效贯彻实施。县级以上人民政府及其有关部门按照职责分工，认真贯彻实施民族团结进步促进法的各项规定，主动向本级人民代表大会常务委员会报告工作情况。

本决定自公布之日起施行。
