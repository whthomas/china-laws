# 商洛市人民代表大会常务委员会关于加强在校中小学生使用手机等智能终端产品管理的决定

商洛市人民代表大会常务委员会关于
加强在校中小学生使用手机等
智能终端产品管理的决定

（2026年8月27日商洛市第五届人民代表大会常务委员会第三十一次会议通过　2026年9月23日陕西省第十四届人民代表大会常务委员会第二十五次会议批准）

为了保护学生身心健康，维护学校教学秩序，规范在校中小学生使用手机等智能终端产品管理，依据有关法律法规，结合本市实际，作出如下决定：

一、本决定所称手机等智能终端产品，是指可以接入网络、具有操作系统、能够由用户自行安装应用软件的手机、智能手表、学习机、平板电脑等具有游戏、社交、娱乐功能的便携式智能终端产品（以下简称手机）。

二、禁止全市普通中小学、中等职业学校学生携带手机进入学校。

三、学生因身患疾病、留守照料、监护缺失等特殊需要，由其父母或者其他监护人向学校提出书面申请，经学校审核同意后，可以携带手机进入学校。

经审核同意带入学校的手机，应当及时交由学校统一管理。学生需要使用的，可以向学校申请临时使用。

学校开展信息化教学、科技创新、教学实践等活动，确需学生使用手机的，应当严格限定使用时段和区域，由教师监管使用。

四、学校应当在校园内按照教学区、宿舍区、活动区等公共区域合理设置公用通讯设施，保障学校、监护人、学生之间通讯畅通。

五、学校应当结合本校实际，依法制定手机管理办法。

制定管理办法时，应当听取学生、监护人、教职工等各方面代表的意见。

六、学校应当将科学、文明、安全、合理使用手机纳入学生素质教育内容，开展手机使用、网络文明、网络安全、信息辨别、隐私保护等教育，培养学生科学文明使用手机的意识和能力。

学校应当通过家长会等途径向学生父母或者其他监护人宣传手机管理要求，建立家校协同机制，共同引导、规范学生使用手机行为。

七、学生父母或者其他监护人应当履行家庭教育主体责任，加强对学生使用手机行为的引导和监督，支持、配合学校手机管理工作。

八、发现学生违规携带手机进入学校、使用的，学校应当代为保管，并及时告知其父母或者其他监护人。

九、本决定自公布之日起施行。
