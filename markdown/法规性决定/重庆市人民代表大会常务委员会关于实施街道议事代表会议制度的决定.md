# 重庆市人民代表大会常务委员会关于实施街道议事代表会议制度的决定

重庆市人民代表大会常务委员会
关于实施街道议事代表会议制度的决定

（2026年7月30日重庆市第六届人民代表大会常务委员会第二十五次会议通过）

为了加强街道民主协商，实施街道议事代表会议制度，推动街道居民有序参与公共事务管理，践行全过程人民民主，根据有关法律法规，结合本市实际，作出如下决定。

一、本市街道全面实施街道议事代表会议制度。

本决定所称街道议事代表会议制度，是指由区县（自治县）人民代表大会常务委员会街道工作委员会（简称人大街道工委）通过民主推荐和协商，从街道居民中产生街道议事代表，并组织召开街道议事代表会议，围绕本街道经济社会发展、民生服务保障、基层社会治理等事项，开展议事协商活动的制度。

二、实施街道议事代表会议制度，应当坚持中国共产党的领导，坚持依法办事，坚持基层协商民主，坚持密切联系群众。

三、街道议事代表应当具有广泛的代表性，一般由生活、工作在本街道的居民以及社会各方面人士构成，辖区内的区县（自治县）人民代表大会代表原则上推荐为街道议事代表人选。

街道议事代表的名额，应当根据街道人口规模及其村、社区、辖区内的单位分布情况等因素确定，一般不少于三十名，不超过一百名。街道议事代表的名额、条件、推荐、确定和退出等工作，由区县（自治县）人民代表大会常务委员会依照本决定指导街道作出规定。

街道议事代表每届任期五年。

四、街道议事代表会议由人大街道工委组织召开，每年至少召开两次。

街道议事代表会议可以就街道重大事项、年度民生实事项目、居民普遍反映的热点难点问题等开展议事协商。根据需要，街道议事代表会议可以对年度民生实事项目进行票选推荐。

街道议事代表会议应当根据议事协商情况形成书面意见，由人大街道工委交有关方面研究处理。

五、人大街道工委可以组织街道议事代表，按照方便、有效的原则，根据地域、领域等编组开展联系群众活动。

人大街道工委根据工作需要，可以依托全过程人民民主巴渝实践站、人大代表之家和代表联络站等阵地，组织街道议事代表围绕有关议题开展专项议事活动。

六、人大街道工委应当建立健全工作制度，加强对街道议事代表的培训和指导，丰富街道议事代表联系群众的内容和形式，支持街道议事代表开展议事活动，运用全市统一开发建设的数字化应用场景，为实施街道议事代表会议制度赋能。

七、街道应当为实施街道议事代表会议制度提供必要的经费保障。无固定工资收入的街道议事代表参加议事活动，根据实际情况给予适当补贴。

八、本决定自2026年9月1日起施行。
